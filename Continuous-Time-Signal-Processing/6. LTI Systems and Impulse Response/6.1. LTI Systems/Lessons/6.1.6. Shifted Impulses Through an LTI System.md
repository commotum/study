## Introduction to Shifted Impulses Through an LTI System

The reference relationship for this lesson is the impulse-response definition: when the input to an LTI system is the unit impulse $\delta(t)$, the output is the impulse response $h(t)$. We write that input-output relationship as

$$
\delta(t) \to h(t)
$$

Time invariance says that if an input is shifted in time, the corresponding output is shifted by the same amount. So the action is to copy the impulse's time shift onto h. If the input is the shifted unit impulse $\delta(t - tau_0)$, then the output is $h(t - tau_0)$.

$$
\delta(t - \tau_0) \to h(t - \tau_0)
$$

For the base case, $\delta(t - 2)$ is the unit impulse delayed by 2. Because the system is time-invariant, the output is the same delay applied to the impulse response.

$$
\delta(t - 2) \to h(t - 2)
$$

The sign inside the argument stays matched: $\delta(t - a)$ produces $h(t - a)$, and $\delta(t + a)$ produces $h(t + a)$. In this lesson, the impulses are unit impulses, so only the time shift is copied onto h; amplitude scaling is handled in the next lesson.

## Finding the Output for a Delayed Unit Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output when the input is $\delta(t - 3)$.

**Explanation**

The cue is the input $\delta(t - 3)$. It is still a unit impulse, but it is delayed by 3 relative to $\delta(t)$. The reference input-output relationship for this LTI system is

$$
\delta(t) \to h(t)
$$

Time invariance says that the same delay applied to the input must appear on the output. So copy the shift from the impulse argument onto the impulse response: $\delta(t - 3)$ maps to $h(t - 3)$.

$$
\delta(t - 3) \to h(t - 3)
$$

Therefore the output is the impulse response delayed by the same amount as the input impulse.

$$
y(t) = h(t - 3)
$$

## Finding the Output for an Advanced Unit Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output when the input is $\delta(t + 2)$.

**Explanation**

The cue is the plus sign in $\delta(t + 2)$. This is still a unit impulse, but it is advanced by 2 instead of delayed. The reference input-output relationship is

$$
\delta(t) \to h(t)
$$

To use the same time-invariance rule, read the advance as a shift of -2. That is, $\delta(t + 2)$ is the same shift pattern as $\delta(t - (-2)$), so the output receives that same shift on h.

$$
\delta(t + 2) = \delta(t - (-2)) \to h(t - (-2))
$$

Now simplify the output argument. A shift of -2 in the rule appears as a plus sign inside the response argument.

$$
h(t - (-2)) = h(t + 2)
$$

Therefore the output is the impulse response advanced by the same amount as the input impulse.

$$
y(t) = h(t + 2)
$$

## Mapping a Symbolic Shift Through the Impulse Response

**Example:** An LTI system has impulse response $h(t)$. Find the output when the input is $\delta(t - T)$.

**Explanation**

The cue is the symbolic shift T in $\delta(t - T)$. This has the same structure as the numeric delayed impulse $\delta(t - 3)$, except the shift amount is left as a parameter. Start from the reference relationship

$$
\delta(t) \to h(t)
$$

Time invariance does not require assigning a number to T. The action is to preserve the symbolic shift exactly and copy it from the impulse argument onto the impulse response.

$$
\delta(t - T) \to h(t - T)
$$

Therefore the output is the impulse response shifted by the same symbolic amount T.

$$
y(t) = h(t - T)
$$

## Matching the Input Shift to the Output Shift

**Example:** An LTI system has impulse response $h(t)$. Which output matches the input $\delta(t + 6)$?

**Explanation**

The cue is the input $\delta(t + 6)$. This is an advanced unit impulse, so the matching output must use the impulse response h with the same plus-six shift. Start from the reference relationship

$$
\delta(t) \to h(t)
$$

By time invariance, the output receives the same shift as the input impulse. Since the input has t + 6 inside $\delta$, the matching response has t + 6 inside h.

$$
\delta(t + 6) \to h(t + 6)
$$

This rules out a sign-reversed response like $h(t - 6)$, an unchanged response like $h(t)$, and an expression that keeps $\delta$ instead of giving the system output. The matching output is

$$
h(t + 6)
$$
