## Introduction to Impulse Response as a System Description

For an LTI system, the impulse response $h(t)$ is more than one output expression. It is the response template for the system: once you know what the system does to the unit impulse, you can reuse that response for related impulse inputs.

The base case is the unshifted unit impulse. By definition, when the input is $\delta(t)$, the output is $h(t)$.

$$
\delta(t) \to h(t)
$$

Time invariance says that moving the impulse in time moves the response by the same amount. So a delayed impulse $\delta(t - T)$ produces the delayed response $h(t - T)$.

$$
\delta(t - T) \to h(t - T)
$$

Linearity says that scaling the impulse scales the whole response by the same constant. So an input $a\delta(t)$ produces the output $a h(t)$.

$$
a\delta(t) \to a h(t)
$$

Putting both properties together gives the reusable mapping for one impulse component: copy the impulse's coefficient and time shift onto $h(t)$. This is the local mechanism behind later impulse decomposition and convolution, but here the move is only this single-component mapping.

$$
a\delta(t - T) \to a h(t - T)
$$

## Reading $h(t)$ as the Response Template for the Unit Impulse

**Example:** An LTI system has impulse response $h(t) = e^{-2t}u(t)$. What is the output when the input is $\delta(t)$?

**Explanation**

The cue is the input $\delta(t)$. This is the unshifted, unscaled unit impulse, so we use the base impulse-response mapping.

$$
\delta(t) \to h(t)
$$

The problem already gives the system's impulse response as $h(t) = e^{-2t}u(t)$. Since the input is exactly $\delta(t)$, the output is exactly that same function.

$$
y(t) = h(t) = e^{-2t}u(t)
$$

So the output is $e^{-2t}u(t)$. No time shift or amplitude scale has been applied yet; this is the response template before any modification.

## Mapping a Time-Shifted Impulse Component to a Time-Shifted Copy of $h(t)$

**Example:** An LTI system has impulse response $h(t) = e^{-t}u(t)$. What is the output when the input is $\delta(t - 4)$?

**Explanation**

The cue is the input $\delta(t - 4)$. This is a unit impulse delayed by 4, with no amplitude scale, so only the time-invariance part of the response-template rule is active.

$$
\delta(t - 4) \to h(t - 4)
$$

Time invariance says the output receives the same delay as the impulse input. The system output is not another impulse; it is the impulse response template shifted by the same amount.

$$
y(t) = h(t - 4)
$$

Now substitute $t - 4$ wherever $t$ appears in the given formula $h(t) = e^{-t}u(t)$.

$$
y(t) = h(t - 4) = e^{-(t - 4)}u(t - 4)
$$

So the output is $e^{-(t - 4)}u(t - 4)$. It is the same response shape as $h(t)$, delayed by 4.

## Mapping an Amplitude-Scaled Impulse Component to an Amplitude-Scaled Copy of $h(t)$

**Example:** An LTI system has impulse response $h(t) = e^{-3t}u(t)$. What is the output when the input is $5\delta(t)$?

**Explanation**

The cue is the input $5\delta(t)$. This is an amplitude-scaled unit impulse at $t = 0$, so there is no time shift to apply.

Use linearity: scaling the impulse input by 5 scales the entire impulse-response output by 5.

$$
5\delta(t) \to 5h(t)
$$

Now multiply the given impulse response by 5. The multiplier changes the response amplitude; it does not change the time variable inside $h(t)$.

$$
y(t) = 5h(t) = 5e^{-3t}u(t)
$$

So the output is $5e^{-3t}u(t)$. It is an amplitude-scaled copy of $h(t)$ with no delay or advance.

## Mapping a Scaled and Shifted Impulse Component to a Scaled and Shifted Copy of $h(t)$

**Example:** An LTI system has impulse response $h(t) = e^{-t}u(t)$. What is the output when the input is $3\delta(t - 2)$?

**Explanation**

The cue is the input $3\delta(t - 2)$. It is one impulse component with two pieces to copy: the scalar coefficient $3$ and the delay $2$.

For an LTI system, time invariance copies the delay onto $h(t)$, and linearity copies the scalar onto the whole shifted response.

$$
a\delta(t - T) \to a h(t - T)
$$

Here, $a = 3$ and $T = 2$. So $\delta(t - 2)$ becomes $h(t - 2)$, and the multiplier $3$ stays attached to that shifted response.

$$
3\delta(t - 2) \to 3h(t - 2)
$$

Now substitute $t - 2$ into the given impulse response $h(t) = e^{-t}u(t)$, then keep the outside multiplier $3$.

$$
y(t) = 3h(t - 2) = 3e^{-(t - 2)}u(t - 2)
$$

So the output is $3e^{-(t - 2)}u(t - 2)$. It is one scaled and delayed copy of the response template $h(t)$.
