## Introduction to Impulse Response

For an LTI system, the unit impulse is the canonical probe input. In this section, the only input we need is the unshifted impulse at the origin.

$$
x(t)=\delta(t)
$$

The direct definition is this: when the input to the system is $\delta(t)$, the output is called the impulse response and is written as $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

The input and the response play different roles. The signal $\delta(t)$ is what enters the system; the signal $h(t)$ is what the system produces in response to that input.

$$
y(t)=h(t)
$$

So, for the base impulse input, identifying the output is the whole move: the output to $\delta(t)$ is $h(t)$. Later sections will use this same $h(t)$ as the reference response for shifted, scaled, and decomposed impulse inputs.

## Finding $h(t)$ from a Given $\Delta$-Input Output

**Example:** An LTI system has output $y(t)=e^{-2t}u(t)$ when the input is $x(t)=\delta(t)$. Find $h(t)$.

**Explanation**

The cue is the stated input. Since the input is exactly the unit impulse, this is the base case that defines the impulse response.

$$
x(t)=\delta(t)
$$

For an LTI system, the output produced by $\delta(t)$ is named $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

The problem tells us that the output for this same input is $y(t)=e^{-2t}u(t)$. Therefore that output expression is the impulse response.

$$
h(t)=e^{-2t}u(t)
$$

So the system's impulse response is $e^{-2t}u(t)$. No shifting or scaling rule is needed here because the input is the unshifted, unscaled impulse.

<a id="finding-ht-by-applying-a-system-rule-to-deltat"></a>
## Finding $h(t)$ by Applying a System Rule to $\delta$(t)

**Example:** For the LTI system $y(t)=2x(t)+x(t-1)$, find $h(t)$.

**Explanation**

The cue is that the system rule is given, but the output to $\delta(t)$ is not given directly. To find the impulse response, evaluate the system at the unit impulse input.

$$
h(t)=T\{\delta(t)\}
$$

Set the input signal in the rule to $x(t)=\delta(t)$. Then each occurrence of $x$ becomes the matching impulse expression.

$$
x(t)=\delta(t),\qquad x(t-1)=\delta(t-1)
$$

Substitute those impulse expressions into the system rule.

$$
y(t)=2\delta(t)+\delta(t-1)
$$

Because this is the output produced when the input is $\delta(t)$, this output is the impulse response.

$$
h(t)=2\delta(t)+\delta(t-1)
$$

So the system's impulse response is $2\delta(t)+\delta(t-1)$. This example only evaluates the system rule at $\delta(t)$; it does not use convolution or impulse decomposition.

## Distinguishing the Impulse Input from the Impulse Response

**Example:** An LTI system has impulse response $h(t)=e^{-t}u(t)$. Identify the impulse input and the impulse response in this statement.

**Explanation**

The cue is the phrase impulse response. It names the output produced by the unit impulse input, not the input itself.

$$
T\{\delta(t)\}=h(t)
$$

The impulse input is the probe signal that would be applied to the LTI system.

$$
\text{impulse input}=\delta(t)
$$

The impulse response is the output signal named by $h(t)$. In the statement, that response is the function given after $h(t)=$.

$$
\text{impulse response}=h(t)=e^{-t}u(t)
$$

So $\delta(t)$ is the impulse input, while $h(t)=e^{-t}u(t)$ is the resulting output response. The common error is to call $\delta(t)$ the impulse response, but $\delta(t)$ is the input that defines it.

## Interpreting $h(t)$ as the Reference Response for Later Impulse Inputs

**Example:** An LTI system has output $y(t)=e^{-t}u(t)$ when $x(t)=\delta(t)$. Identify the reference response that later shifted or scaled impulse inputs will modify.

**Explanation**

The cue is that the given output is produced when the input is the unit impulse. That means the output is the impulse response.

$$
x(t)=\delta(t)\quad \Longrightarrow \quad y(t)=e^{-t}u(t)
$$

By definition, the output to $\delta(t)$ is named $h(t)$. So the given output expression becomes the system's impulse response.

$$
h(t)=e^{-t}u(t)
$$

This $h(t)$ is the reference response for the system. Later shifted, scaled, and decomposed impulse inputs will reuse modified copies of this same response pattern.

So the reference response is $h(t)=e^{-t}u(t)$. In this section, the task is only to name that response and state its role, not to compute any shifted or scaled outputs yet.

  $$
