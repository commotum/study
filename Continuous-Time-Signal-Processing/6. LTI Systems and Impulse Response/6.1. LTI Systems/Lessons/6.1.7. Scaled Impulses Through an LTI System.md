## Introduction to Scaled Impulses Through an LTI System

The object to recognize is a scaled shifted impulse entering an LTI system. Start from the impulse-response definition: if the input is the unit impulse $\delta(t)$, then the output is the impulse response $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

Homogeneity handles the coefficient. If the impulse is multiplied by a constant $a$, then the output is multiplied by the same constant. The system response changes from $h(t)$ to $a h(t)$.

$$
T\{a\delta(t)\}=a h(t)
$$

Time invariance handles the shift. If the unit impulse is shifted to $\delta(t-t_0)$, then the impulse response is shifted by the same amount.

$$
T\{\delta(t-t_0)\}=h(t-t_0)
$$

For a scaled shifted impulse, apply both ideas. The coefficient $a$ copies onto the output by homogeneity, and the shift $t_0$ copies onto $h$ by time invariance.

$$
T\{a\delta(t-t_0)\}=a h(t-t_0)
$$

So the concrete action is: replace $\delta$ with $h$, keep the same coefficient, and keep the same time shift. Do not change the impulse into a convolution integral; the LTI system is already represented by its impulse response $h(t)$.

## Finding the Output for a Scaled Unshifted Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output $y(t)$ when the input is $x(t)$ = 3$\delta$(t).

**Explanation**

The cue is that the input is a scalar multiple of the unshifted impulse. Since the system has impulse response $h(t)$, the output to the unit impulse $\delta(t)$ is $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

The coefficient multiplying the impulse is $3$. Because the system is linear, homogeneity says that multiplying the input by $3$ multiplies the output by the same factor.

$$
T\{3\delta(t)\}=3T\{\delta(t)\}
$$

Now substitute the impulse-response relationship into that scaled output.

$$
T\{3\delta(t)\}=3h(t)
$$

Therefore, the system output is $y(t)=3h(t)$. The coefficient copies onto $h(t)$, and there is no time shift because the input impulse is unshifted.

## Finding the Output for a Scaled Delayed Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output $y(t)$ when the input is $x(t)$ = 4$\delta$(t - 2).

**Explanation**

The cue is that the input is a scaled delayed impulse. The coefficient is $4$, and the impulse part $\delta(t-2)$ is the unit impulse delayed by $2$.

Start from the impulse-response relationship: the unshifted impulse $\delta(t)$ produces the output $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

Use time invariance for the delay. Since $\delta(t-2)$ is delayed by $2$, the output is the same delay applied to the impulse response. The minus sign in the input argument stays a minus sign in the output argument.

$$
T\{\delta(t-2)\}=h(t-2)
$$

Now apply homogeneity to keep the multiplier $4$ on the delayed response.

$$
T\{4\delta(t-2)\}=4h(t-2)
$$

Therefore, the system output is $y(t)=4h(t-2)$. The scalar and the delay both transfer from the impulse input to the impulse response.

## Finding the Output for a Scaled Advanced Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output $y(t)$ when the input is $x(t)$ = 5$\delta$(t + 1).

**Explanation**

The cue is that the input is a scaled advanced impulse. The coefficient is $5$, and the impulse part $\delta(t+1)$ is advanced by $1$ because it can be read as $\delta(t-(-1))$.

Start from the impulse-response relationship: the unshifted impulse $\delta(t)$ produces the output $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

Use time invariance for the advance. The output receives the same shift as the input impulse, so the plus sign in $\delta(t+1)$ stays a plus sign in $h(t+1)$.

$$
T\{\delta(t+1)\}=h(t+1)
$$

Now apply homogeneity to keep the multiplier $5$ on the advanced impulse response.

$$
T\{5\delta(t+1)\}=5h(t+1)
$$

Therefore, the system output is $y(t)=5h(t+1)$. The positive coefficient stays attached to the response, and the advance remains an advance.

## Finding the Output for a Negative Scaled Shifted Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output $y(t)$ when the input is $x(t)$ = -2$\delta$(t - 3).

**Explanation**

The cue is that the input is a negative scaled shifted impulse. The coefficient is $-2$, and the impulse part $\delta(t-3)$ is delayed by $3$.

Keep the coefficient and the shift separate. The negative sign belongs to the amplitude multiplier $-2$; it does not change the delay inside $\delta(t-3)$.

Start from the impulse-response relationship: the unshifted impulse $\delta(t)$ produces the output $h(t)$.

$$
T\{\delta(t)\}=h(t)
$$

Use time invariance for the shift. The delayed impulse $\delta(t-3)$ maps to the delayed impulse response $h(t-3)$.

$$
T\{\delta(t-3)\}=h(t-3)
$$

Now apply homogeneity to keep the full multiplier $-2$ on that shifted response.

$$
T\{-2\delta(t-3)\}=-2h(t-3)
$$

Therefore, the system output is $y(t)=-2h(t-3)$. The negative sign changes the response amplitude, not the shift direction.
