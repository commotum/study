## Introduction to From Impulse Decomposition to System Output

For an LTI system, the impulse response $h(t)$ is the output produced by the input $\delta(t)$. Once you know $h(t)$, a shifted impulse input uses the same response shape with the same shift: $\delta(t-t_k)$ produces $h(t-t_k)$.

If the shifted impulse is multiplied by a weight $a_k$, homogeneity carries that same weight to the output response. The weight multiplies the whole shifted response; it does not change the time shift.

$$
a_k\delta(t-t_k) \longmapsto a_k h(t-t_k)
$$

For a finite impulse decomposition, apply this rule to each impulse component separately. For example, if $x(t)=2\delta(t-1)-\delta(t-3)$, the two component responses are $2h(t-1)$ and $-h(t-3)$.

Linearity then adds the component responses. So a finite sum of weighted shifted impulses becomes the matching finite sum of shifted, scaled copies of the impulse response.

$$
x(t)=\sum_k a_k\delta(t-t_k) \quad \longmapsto \quad y(t)=\sum_k a_k h(t-t_k)
$$

## Output from a Single Shifted Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output when $x(t)=\delta(t-2)$.

**Explanation**

The cue is that the input is one shifted impulse with unit weight. Since the system is LTI, the response to $\delta(t)$ is $h(t)$, and a delay in the impulse produces the same delay in the impulse response.

$$
\delta(t-t_k) \longmapsto h(t-t_k)
$$

Here the input is $\delta(t-2)$, so the shift is $t_k=2$. Replace the shifted impulse with the matching shifted impulse response.

$$
x(t)=\delta(t-2) \quad \Longrightarrow \quad y(t)=h(t-2)
$$

Therefore, the output is $y(t)=h(t-2)$. The impulse is replaced by $h$, and the shift stays the same.

## Output from a Scaled Shifted Impulse

**Example:** An LTI system has impulse response $h(t)$. Find the output when $x(t)=3\delta(t-1)$.

**Explanation**

The cue is that the input is still one shifted impulse, but now it has a coefficient. In $3\delta(t-1)$, the shift is $t_k=1$ and the weight is $3$.

$$
a_k\delta(t-t_k) \longmapsto a_k h(t-t_k)
$$

First use time invariance on the shifted impulse: $\delta(t-1)$ produces $h(t-1)$. Then use homogeneity to carry the factor $3$ to the output response.

$$
x(t)=3\delta(t-1) \quad \Longrightarrow \quad y(t)=3h(t-1)
$$

Therefore, the output is $y(t)=3h(t-1)$. The coefficient scales the whole shifted response; it does not change the time shift.

<a id="output-from-a-finite-sum-of-weighted-shifted-impulses"></a>
## Output from a Finite Sum of Weighted Shifted Impulses

**Example:** An LTI system has impulse response $h(t)$. Find the output when $x(t)=2\delta(t)-\delta(t-3)+4\delta(t-5)$.

**Explanation**

The cue is that the input is a finite sum of weighted shifted impulses. Treat each impulse term separately, convert it to the matching shifted and scaled copy of $h(t)$, and then add the response terms.

$$
a_k\delta(t-t_k) \longmapsto a_k h(t-t_k)
$$

Separate the input into three terms: $2\delta(t)$, $-\delta(t-3)$, and $4\delta(t-5)$. The first term has shift $0$, the second has weight $-1$ and shift $3$, and the third has weight $4$ and shift $5$.

$$
\begin{aligned} 2\delta(t) &\longmapsto 2h(t) \\ -\delta(t-3) &\longmapsto -h(t-3) \\ 4\delta(t-5) &\longmapsto 4h(t-5) \end{aligned}
$$

Because the system is linear, the output to the full input is the sum of these component responses.

$$
y(t)=2h(t)-h(t-3)+4h(t-5)
$$

So the output is $y(t)=2h(t)-h(t-3)+4h(t-5)$. Each impulse was replaced by $h$ with the same shift, and each coefficient stayed attached to its own response term.

<a id="superposing-responses-from-a-weighted-impulse-decomposition"></a>
## Superposing Responses from a Weighted Impulse Decomposition

**Example:** An LTI system has impulse response $h(t)$, and $x(t)=\sum_{k=1}^{3}a_k\delta(t-t_k)$ with $a_1=2$, $t_1=0$, $a_2=-1$, $t_2=2$, and $a_3=3$, $t_3=5$. Write $y(t)$.

**Explanation**

The cue is that the input is given as a compact indexed impulse decomposition. Read each coefficient $a_k$ and shift $t_k$, then make one output term $a_kh(t-t_k)$ for each index.

$$
x(t)=\sum_{k=1}^{3}a_k\delta(t-t_k) \quad \Longrightarrow \quad y(t)=\sum_{k=1}^{3}a_k h(t-t_k)
$$

Now substitute the listed $a_k$ and $t_k$ values into the output terms. The index $k$ only labels each component; the coefficient comes from $a_k$, and the shift comes from $t_k$.

$$
\begin{aligned} k=1:\quad a_1h(t-t_1) &= 2h(t-0)=2h(t) \\ k=2:\quad a_2h(t-t_2) &= (-1)h(t-2)=-h(t-2) \\ k=3:\quad a_3h(t-t_3) &= 3h(t-5) \end{aligned}
$$

Superpose the three component responses to form the full output.

$$
y(t)=2h(t)-h(t-2)+3h(t-5)
$$

Therefore, $y(t)=2h(t)-h(t-2)+3h(t-5)$. This is the same finite-sum rule as before; the only difference is that the weights and shifts were provided in indexed form.
