## Introduction to Weighted Impulse Decomposition

In the continuous-time sifting representation, a signal is rebuilt from shifted impulses indexed by $\tau$. The expression $\delta(t-\tau)$ marks the impulse located at the time selected by $\tau$, so each value of $\tau$ names one impulse in the decomposition.

The weighting rule is local: the impulse at location $\tau$ receives the signal value at that same location as its coefficient. For example, if $x(2)=5$, then the shifted impulse at $\tau=2$ is weighted by 5, giving the component $5\delta(t-2)$.

$$
\text{component at }\tau=\tau_0:\quad x(\tau_0)\delta(t-\tau_0)
$$

The symbol $\tau_0$ means one selected location. First identify the shifted impulse $\delta(t-\tau_0)$, then evaluate the signal at that same location. The value $x(\tau_0)$ is the weight, and the shift $t-\tau_0$ gives the impulse location.

$$
x(t)=\displaystyle\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau
$$

This integral is the continuum version of adding all weighted shifted impulses. For every possible location $\tau$, the decomposition uses the component $x(\tau)\delta(t-\tau)$, and the integral collects all of those components to reconstruct $x(t)$.

This structure matters because an LTI system can later handle the weighted impulse continuum by superposition. For now, the move is only to match each shifted impulse $\delta(t-\tau)$ with its weight $x(\tau)$, not to compute the system output yet.

## Matching a Shifted Impulse to Its Signal Value

**Example:** Given $x(\tau)=2\tau+1$, match the shifted impulse $\delta(t-3)$ to its signal value weight.

**Explanation**

The cue is the shifted impulse $\delta(t-3)$. Match it to the standard shifted-impulse form $\delta(t-\tau_0)$, where $\tau_0$ is the impulse location.

$$
\delta(t-3)=\delta(t-\tau_0)\quad\Rightarrow\quad \tau_0=3
$$

The weight is the signal value at that same location. Substitute $\tau=3$ into $x(\tau)=2\tau+1$.

$$
x(3)=2(3)+1=7
$$

Therefore, the shifted impulse $\delta(t-3)$ is matched with the scalar weight 7. For this step, stop at the weight; the full weighted impulse component comes next.

## Writing a Single Weighted Impulse Component

**Example:** For a signal with $x(\tau)=4-\tau$, write the weighted impulse component located at $\tau=1$.

**Explanation**

The cue is the requested impulse location $\tau=1$. For one selected location $\tau_0$, the weighted impulse component has the form $x(\tau_0)\delta(t-\tau_0)$.

$$
\text{component at }\tau=\tau_0:\quad x(\tau_0)\delta(t-\tau_0)
$$

Here $\tau_0=1$, so first evaluate the signal at that location.

$$
x(1)=4-1=3
$$

Attach that value as the coefficient of the shifted impulse located at the same $\tau$-value. Since the location is $1$, the impulse factor is $\delta(t-1)$.

$$
x(1)\delta(t-1)=3\delta(t-1)
$$

Therefore, the weighted impulse component is $3\delta(t-1)$. The sign inside the impulse agrees with the location: a component at $\tau=1$ uses $t-1$, not $t+1$.

## Writing Several Weighted Impulse Components

**Example:** Using $x(\tau)=\tau+3$, write the weighted impulse components at $\tau=0$, $\tau=1$, and $\tau=2$.

**Explanation**

The cue is the list of requested impulse locations: $\tau=0$, $\tau=1$, and $\tau=2$. Apply the same single-component rule at each location: evaluate the signal value, then attach that value to the shifted impulse at the same location.

$$
\text{component at }\tau=\tau_0:\quad x(\tau_0)\delta(t-\tau_0)
$$

First evaluate $x(\tau)=\tau+3$ at each requested location.

$$
\begin{aligned}x(0)&=0+3=3\\x(1)&=1+3=4\\x(2)&=2+3=5\end{aligned}
$$

Now pair each weight with the shifted impulse centered at the same location. At $\tau=0$, the shifted impulse is $\delta(t-0)=\delta(t)$.

$$
\begin{aligned}\tau_0=0&:\quad 3\delta(t)\\\tau_0=1&:\quad 4\delta(t-1)\\\tau_0=2&:\quad 5\delta(t-2)\end{aligned}
$$

So the weighted impulse components can be written as the finite sum

$$
3\delta(t)+4\delta(t-1)+5\delta(t-2)
$$

Each term uses the same rule: the coefficient is the signal value $x(\tau_0)$, and the impulse shift $t-\tau_0$ records the matching location.

## Handling Zero and Negative Impulse Weights

**Example:** Using $x(\tau)=\tau-1$, write the weighted impulse components at $\tau=0$, $\tau=1$, and $\tau=3$.

**Explanation**

The cue is still a list of impulse locations, so use the same component rule at each location. The new issue is that some evaluated weights may be zero or negative.

$$
\text{component at }\tau=\tau_0:\quad x(\tau_0)\delta(t-\tau_0)
$$

Evaluate $x(\tau)=\tau-1$ at each requested location.

$$
\begin{aligned}x(0)&=0-1=-1\\x(1)&=1-1=0\\x(3)&=3-1=2\end{aligned}
$$

Now attach each weight to the shifted impulse at the same location. A negative weight stays as a negative coefficient; it does not change the impulse location.

$$
\begin{aligned}\tau_0=0&:\quad -1\delta(t-0)=-\delta(t)\\\tau_0=1&:\quad 0\delta(t-1)=0\\\tau_0=3&:\quad 2\delta(t-3)\end{aligned}
$$

The zero-weight component contributes nothing to the finite sum, so it can be omitted from the final expression.

$$
-\delta(t)+2\delta(t-3)
$$

This is the weighted impulse decomposition for the listed locations. The coefficient sign records the signal value, while the shift records the impulse location.

```quiz
  Using $x(\tau)=2-\tau$, write the weighted impulse components at $\tau=0$, $\tau=2$, and $\tau=4$.

correct: |-
  2$\delta$(t)-2$\delta$(t-4)

feedback: |-
  Evaluate the signal at each listed location.

  $$
  \begin{aligned}x(0)&=2-0=2\\x(2)&=2-2=0\\x(4)&=2-4=-2\end{aligned}
  $$

  The zero-weight component contributes nothing, and the negative weight stays as a negative coefficient at the same impulse location.

  $$
  2\delta(t)+0\delta(t-2)-2\delta(t-4)=2\delta(t)-2\delta(t-4)
  $$
```
