## Introduction to Deriving the Convolution Integral

The object to recognize is the weighted shifted-impulse representation of the input. It says that the signal $x(t)$ can be built by superposing shifted impulses $\delta(t - \tau)$, where the weight on the impulse at location $\tau$ is the signal value $x(\tau)$.

$$
x(t)=\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau
$$

To derive the output of an LTI system, handle one shifted impulse component at a time. Linearity lets us separate the components, and time invariance says that if $\delta(t)$ produces $h(t)$, then a shifted impulse $\delta(t - \tau)$ produces the same shift in the impulse response.

$$
\delta(t-\tau)\mapsto h(t-\tau)
$$

The weight stays attached to that shifted response. So the component $x(\tau)$$\delta(t - \tau)$ contributes $x(\tau)$$h(t - \tau)$ to the output; the weight multiplies the response, not the time argument.

$$
x(\tau)\delta(t-\tau)\mapsto x(\tau)h(t-\tau)
$$

Finally, superpose all of the component responses over $\tau$. That continuous superposition gives the convolution integral for the LTI system output.

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
$$

The core move is to replace each shifted impulse in the input decomposition with the matching shifted impulse response, keep the weight $x(\tau)$, and then add every component response by integration.

## Mapping a Shifted Impulse to a Shifted Impulse Response

**Example:** For an LTI system with impulse response $h(t)$, determine the output produced by the input $\delta(t-3)$.

**Explanation**

The cue is that the input is a shifted impulse with no extra weight. Since $h(t)$ is the response to the unshifted impulse $\delta(t)$, the only rule needed is time invariance.

$$
\delta(t)\mapsto h(t)
$$

The impulse $\delta(t - 3)$ is the unshifted impulse delayed by 3. For an LTI system, delaying the input by 3 delays the output by the same amount.

$$
\delta(t-3)\mapsto h(t-3)
$$

Therefore, the output produced by the input $\delta(t - 3)$ is the shifted impulse response $h(t - 3)$.

$$
y(t)=h(t-3)
$$

<a id="applying-the-input-weight-to-the-shifted-response"></a>
## Applying the Input Weight to the Shifted Response

**Example:** For an LTI system with impulse response $h(t)$, determine the output produced by the weighted shifted impulse $4\delta(t-2)$.

**Explanation**

The cue is that the input is still one shifted impulse, but now it has a scalar weight. Separate the coefficient 4 from the unweighted shifted impulse $\delta(t - 2)$.

$$
4\delta(t-2)=4\cdot\delta(t-2)
$$

First map the shifted impulse itself. Since $\delta(t - 2)$ is delayed by 2, time invariance shifts the impulse response by the same amount.

$$
\delta(t-2)\mapsto h(t-2)
$$

Now apply homogeneity from linearity. Multiplying the input component by 4 multiplies the entire shifted response by 4; the coefficient does not change the time argument of h.

$$
4\delta(t-2)\mapsto 4h(t-2)
$$

Therefore, the output produced by the weighted shifted impulse is the shifted impulse response scaled by 4.

$$
y(t)=4h(t-2)
$$

## Superposing Responses from the Impulse Decomposition

**Example:** For an LTI system with impulse response $h(t)$, write the output produced by the input $2\delta(t-1)-\delta(t-4)$.

**Explanation**

The cue is that the input is now a finite sum of weighted shifted impulses. Use the same single-component rule on each term, then add the resulting responses by linearity.

$$
x(t)=2\delta(t-1)-\delta(t-4)
$$

For the first component, $\delta(t - 1)$ maps to $h(t - 1)$ by time invariance, and the coefficient 2 multiplies the entire shifted response.

$$
2\delta(t-1)\mapsto 2h(t-1)
$$

For the second component, $\delta(t - 4)$ maps to $h(t - 4)$. The coefficient is -1, so the response term is negative.

$$
-\delta(t-4)\mapsto -h(t-4)
$$

Finally, superpose the component responses. This is the finite-sum version of the same add-the-responses idea that will become continuous superposition.

$$
y(t)=2h(t-1)-h(t-4)
$$

<a id="identifying-the-continuous-time-convolution-integral"></a>
## Identifying the Continuous-Time Convolution Integral

**Example:** Starting from $x(t)=\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau$, derive the expression for the output $y(t)$ of an LTI system with impulse response $h(t)$.

**Explanation**

The cue is that the input is already written as a continuous superposition of weighted shifted impulses. Each value of $\tau$ gives one small component to pass through the LTI system.

$$
x(t)=\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau
$$

Track one generic component. The shifted impulse is $\delta(t - \tau)$, so time invariance replaces it with the shifted impulse response $h(t - \tau)$.

$$
\delta(t-\tau)\mapsto h(t-\tau)
$$

The weight $x(\tau)$ and the infinitesimal width d $\tau$ stay attached to that component response. The weight multiplies the response; it does not change the time argument of h.

$$
x(\tau)\delta(t-\tau)\,d\tau\mapsto x(\tau)h(t-\tau)\,d\tau
$$

Now superpose all of those component responses over the same $\tau$ range. Replacing the input integrand with the response integrand gives the LTI system output.

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
$$

This is the continuous-time convolution integral. The move here is to identify the output formula from the impulse decomposition, not to evaluate the integral.
