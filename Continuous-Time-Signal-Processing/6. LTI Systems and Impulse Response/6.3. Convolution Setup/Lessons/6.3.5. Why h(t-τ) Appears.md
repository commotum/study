## Introduction to Why $h(t-\tau)$ Appears

Convolution is built by tracking one tiny input contribution at a time. The key question in this lesson is: if an input contribution is located at time $\tau$, what shifted copy of the impulse response does it produce?

Start with the basic impulse-response fact for an LTI system. If the input is the unit impulse at time $0$, the output is the impulse response $h(t)$.

$$
\delta(t) \longmapsto h(t)
$$

Now move the impulse to a fixed time $\tau_0$. Because the system is time-invariant, shifting the input impulse by $\tau_0$ shifts the output response by the same amount.

$$
\delta(t-\tau_0) \longmapsto h(t-\tau_0)
$$

In the convolution integral, the impulse location is not one fixed number. The variable $\tau$ scans through all possible input times, so the response to an impulse located at $\tau$ is $h(t-\tau)$.

The input does not contribute a plain unit impulse at time $\tau$. It contributes a small weighted impulse with weight $x(\tau)d\tau$, so the shifted response is scaled by that same weight.

$$
x(\tau)d\tau\,\delta(t-\tau) \longmapsto x(\tau)h(t-\tau)d\tau
$$

So $h(t-\tau)$ appears because it is the impulse response shifted to match the input contribution located at time $\tau$. The factor $x(\tau)h(t-\tau)d\tau$ is one output contribution, and convolution accumulates all such contributions over every $\tau$.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

## Tracing the Response to an Impulse at $\tau$

**Example:** For an LTI system with impulse response $h(t)$, identify the output produced by the input $\delta(t-2)$.

**Explanation**

The cue is the shifted impulse $\delta(t-2)$. This is the unit impulse moved from time $0$ to time $2$.

For this LTI system, the response to the unit impulse at time $0$ is the impulse response $h(t)$.

$$
\delta(t) \longmapsto h(t)
$$

Because the system is time-invariant, shifting the input impulse by $2$ shifts the output response by the same amount. The shift stays in the same form: $t-2$.

$$
\delta(t-2) \longmapsto h(t-2)
$$

Therefore, the output produced by the input $\delta(t-2)$ is $h(t-2)$.

## Scaling the Shifted Response by $x(\tau)d\tau$

**Example:** For an LTI system with impulse response $h(t)$, write the output contribution from the weighted impulse $x(2)\Delta\tau\,\delta(t-2)$.

**Explanation**

The cue is still the shifted impulse $\delta(t-2)$. From the previous section, an unweighted impulse at time $2$ produces the shifted response $h(t-2)$.

$$
\delta(t-2) \longmapsto h(t-2)
$$

Now the impulse is multiplied by the scalar weight $x(2)\Delta\tau$. Because the system is linear, the same scalar multiplies the output response.

$$
x(2)\Delta\tau\,\delta(t-2) \longmapsto x(2)\Delta\tau\,h(t-2)
$$

Therefore, the output contribution from $x(2)\Delta\tau\,\delta(t-2)$ is $x(2)\Delta\tau\,h(t-2)$. The shift is still determined by the impulse location; the new factor only scales the shifted response.

## Reading $h(t-\tau)$ at a Fixed Output Time

**Example:** With the output time fixed at $t=5$, rewrite the shifted impulse-response factor $h(t-\tau)$ as a function of $\tau$.

**Explanation**

The cue is the phrase "output time fixed at $t=5$". This means $t$ is held at one output time, while $\tau$ remains the variable input location.

Start with the shifted response factor from the convolution integrand.

$$
h(t-\tau)
$$

Substitute $5$ only for the fixed output time $t$. Do not replace $\tau$, because $\tau$ still scans the possible input locations.

$$
h(t-\tau)\big|_{t=5}=h(5-\tau)
$$

Therefore, with the output time fixed at $t=5$, the response factor becomes $h(5-\tau)$. This is the shifted response value observed at output time $5$ from each input location $\tau$.

<a id="connecting-weighted-shifted-responses-to-the-convolution-integrand"></a>
## Connecting Weighted Shifted Responses to the Convolution Integrand

**Example:** Identify the convolution integrand that comes from accumulating the weighted shifted-response contributions $x(\tau)h(t-\tau)d\tau$ over all input times $\tau$.

**Explanation**

The cue is the word integrand. We are not computing the output yet; we are identifying the expression that will be accumulated over $\tau$.

Start from one output contribution caused by the small input piece at time $\tau$. The input weight is $x(\tau)d\tau$, and the shifted response factor is $h(t-\tau)$.

$$
x(\tau)h(t-\tau)\,d\tau
$$

In this contribution, $d\tau$ is the small accumulation width. The integrand is the factor multiplying that width.

$$
x(\tau)h(t-\tau)\,d\tau=\bigl[x(\tau)h(t-\tau)\bigr]\,d\tau
$$

So the convolution integrand is $x(\tau)h(t-\tau)$. It combines the input value at the scanning time with the impulse response shifted to match that same input location.

$$
\text{integrand}=x(\tau)h(t-\tau)
$$

Accumulating all of these infinitesimal contributions over every $\tau$ gives the LTI output. The integral sign belongs to the full accumulation, not to the integrand by itself.

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
$$
