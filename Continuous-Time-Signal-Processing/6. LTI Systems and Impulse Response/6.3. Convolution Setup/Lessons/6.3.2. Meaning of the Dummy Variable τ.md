## Introduction to Meaning of the Dummy Variable $\tau$

In the continuous-time convolution integral, the two time symbols have different jobs. The symbol $t$ names the output time, while the integral scans through input-time locations using $\tau$.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

The differential $d\tau$ tells you that $\tau$ is the variable of integration. As the integral runs, $\tau$ sweeps through the possible input-time values.

For a chosen output time $t$, the factor $x(\tau)$ reads the input value at the scanning time $\tau$. The factor $h(t-\tau)$ reads the shifted impulse-response value paired with that same $\tau$.

$$
\text{integrate with respect to }\tau,\quad \text{leave a function of }t
$$

After the integration is complete, $\tau$ has been summed out, so it should not remain as a free variable. The result is an output value or output formula indexed by $t$.

<a id="identifying-tau-as-the-variable-of-integration"></a>
## Identifying $\tau$ as the Variable of Integration

**Example:** In $y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau$, identify the variable of integration and the notation that tells you.

**Explanation**

The cue is the integral notation. To find the variable of integration, look at the differential at the end of the integrand.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

The differential is $d\tau$, so the integral is taken with respect to $\tau$. That means $\tau$ is the symbol being swept through the integral.

The symbol $t$ is not being integrated here. It labels the output time in $y(t)$ and stays fixed while $\tau$ scans through the integral.

Therefore, $\tau$ is the dummy variable of integration, and $d\tau$ is the notation that tells you.

## Reading $x(\tau)$ Along the Scanning Time Axis

**Example:** Use the plotted signal $x(\tau)$ to read $x(2)$ and identify the interval of $\tau$ values where $x(\tau)$ is nonzero.

**Explanation**

The cue is the axis label. Because the horizontal axis is labeled $\tau$, each horizontal location is a scanning-time value for the input signal $x(\tau)$.

![](<../Source/6.3.2. The Dummy Variable in Convolution/Images/l002-s003-te-section-003.png>)

To read $x(2)$, locate $\tau=2$ on the horizontal axis and read the height of the plotted signal at that location. The graph has height $2$ there, so $x(2)=2$.

$$
x(2)=2
$$

To identify where $x(\tau)$ is nonzero, scan along the $\tau$ axis and look for where the plotted signal is not on the zero line. The signal is above zero from $\tau=0$ through $\tau=4$ and is zero outside that interval.

$$
x(\tau)\ne 0\quad \text{for }0\le \tau\le 4
$$

So reading $x(\tau)$ means reading the input signal along the scanning $\tau$ axis: at $\tau=2$ the input value is $2$, and the visible nonzero interval is $0\le \tau\le 4$.

<a id="reading-ht-tau-along-the-same-tau-axis"></a>
## Reading $h(t-\tau)$ Along the Same $\tau$ Axis

**Example:** For fixed $t=4$, use the plotted impulse response $h(u)$ to read $h(t-\tau)$ at $\tau=1$ and $\tau=3$.

**Explanation**

The new cue is the argument of $h$. Since the plotted impulse response is $h(u)$, first convert each scanning value $\tau$ into the input argument $u=t-\tau$, then read the height of $h(u)$ at that $u$ value.

![](<../Source/6.3.2. The Dummy Variable in Convolution/Images/l002-s004-te-section-004.png>)

$$
u=t-\tau=4-\tau
$$

For $\tau=1$, the argument of $h$ is $u=4-1=3$. On the plotted $h(u)$ signal, the height at $u=3$ is $3$, so $h(t-\tau)$ has value $3$ at $\tau=1$.

$$
h(4-1)=h(3)=3
$$

For $\tau=3$, the argument of $h$ is $u=4-3=1$. On the same plotted $h(u)$ signal, the height at $u=1$ is $1$, so $h(t-\tau)$ has value $1$ at $\tau=3$.

$$
h(4-3)=h(1)=1
$$

Thus the same scanning values of $\tau$ are used, but $h$ is read at the transformed argument $t-\tau$. For fixed $t=4$, the requested values are $3$ at $\tau=1$ and $1$ at $\tau=3$.

<a id="distinguishing-the-scanning-variable-tau-from-the-output-time-t"></a>
## Distinguishing the Scanning Variable $\tau$ from the Output Time $t$

**Example:** In $y(3)=\int_{-\infty}^{\infty} x(\tau)h(3-\tau)\,d\tau$, identify what scans during integration and what output time is being computed.

**Explanation**

The cue for what scans is the differential at the end of the integral. Since the differential is $d\tau$, the integration is with respect to $\tau$.

$$
y(3)=\int_{-\infty}^{\infty} x(\tau)h(3-\tau)\,d\tau
$$

The expression $y(3)$ asks for the output at one specific time. That means the output-time value is fixed at $3$ while the integral runs.

$$
\text{scanning variable: }\tau\qquad \text{fixed output time: }3
$$

The factor $h(3-\tau)$ changes as the integral scans because $\tau$ changes. The number $3$ does not scan; it stays fixed as the output time being computed.

So during this integration, $\tau$ scans through the input-time axis, and the output time being computed is $t=3$, which is the value named by $y(3)$.

## Recognizing That Integration Over $\tau$ Leaves a Function of $t$

**Example:** Explain why $y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau$ can still be a function of $t$ after the integration over $\tau$ is complete.

**Explanation**

The cue is the differential $d\tau$. It tells you that the integral is taken with respect to $\tau$, so $\tau$ is the dummy variable being summed out.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

A dummy variable does not remain as a free variable after integration. Once the integration over $\tau$ is complete, the result should not still depend on $\tau$.

$$
\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau \quad \text{integrates out }\tau\text{ and leaves an output indexed by }t
$$

The symbol $t$ is different: it is a parameter in the integrand, not the variable named by the differential. While $\tau$ is scanned and summed out, $t$ remains as the output-time label.

Therefore, integrating over $\tau$ removes the dummy variable $\tau$ but can leave a result that depends on $t$. That is why the output is written as $y(t)$.
