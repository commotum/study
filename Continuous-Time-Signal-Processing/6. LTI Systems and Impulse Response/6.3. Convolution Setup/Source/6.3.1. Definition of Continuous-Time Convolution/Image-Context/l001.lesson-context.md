Tutorial blocks:
- paragraph:
  text: Continuous-time convolution describes the output of an LTI system from its input and impulse response. The key idea is to view the input $x(t)$ as an accumulation of tiny weighted impulse contributions, one contribution near each input time $\tau$.
- image:
  image_slot_id: section-001
- paragraph:
  text: The contribution near time $\tau$ has weight $x(\tau)$ d $\tau$. Since the system is LTI, an impulse located at $\tau$ produces a shifted impulse response $h(t-\tau)$, so the weighted contribution to the output at time t is $x(\tau)$$h(t-\tau)$ d $\tau$.
- paragraph:
  text: To form the total output at time t, add the contributions from all input times $\tau$. This accumulated output is called the convolution of x and h.
- display-math:
  latex: y(t)=(x*h)(t)
- display-math:
  latex: y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
- paragraph:
  text: Read this formula as an accumulation of weighted, shifted impulse responses: $x(\tau)$ gives the input weight at time $\tau$, $h(t-\tau)$ gives the corresponding shifted impulse response observed at time t, and d $\tau$ tells us to integrate over all input times. For now, the goal is to formulate and interpret the definition, not to compute overlap intervals or evaluate the integral.
