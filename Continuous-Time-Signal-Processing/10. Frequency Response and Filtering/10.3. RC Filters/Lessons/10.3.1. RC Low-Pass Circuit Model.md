## Introduction to RC Low-Pass Circuit Model

The canonical RC low-pass circuit is the physical model you will use for the rest of this lesson. It is the source-$R$-$C$-to-ground topology that turns a circuit diagram into an LTI system description.

![](<../Source/10.3.1. RC Low-Pass Circuit Model/Images/l001-s001-te-section-001.png>)

In the schematic, $v_{in}(t)$ enters a series resistor $R$, the capacitor $C$ goes from the output node to ground, and the output is the capacitor voltage at that same node.

$$
v_{out}(t)=v_C(t)
$$

That output convention is the key identification step: $v_{out}(t)$ is the voltage across $C$, so $v_{out}(t)=v_C(t)$. Keep this topology fixed as the base case; later steps will use the same circuit for the differential equation and the frequency response.

## Identifying the Series Resistor and Shunt Capacitor

**Example:** In the standard RC low-pass circuit, which component is the series resistor and which component is the shunt capacitor?

**Explanation**

Use the same canonical RC low-pass schematic from the tutorial: $v_{in}(t)$ enters a resistor on the signal path, and a capacitor connects from the output node to ground.

![](<../Source/10.3.1. RC Low-Pass Circuit Model/Images/l001-s002-te-section-002.png>)

To identify the low-pass topology, trace the path from the source to the first component. That first component is the series resistor. Then look at the branch that leaves the output node and goes to ground; that branch is the shunt capacitor.

$$
v_{out}(t)=v_C(t)
$$

So in this model, $R$ is the series element and $C$ is the shunt element. That wiring pattern is the RC low-pass model you will carry into the differential-equation and frequency-response steps.

## Identifying the Capacitor Voltage as the Output Signal

**Example:** In the standard RC low-pass circuit, which voltage is the output signal measured across the capacitor?

**Explanation**

Use the same canonical RC low-pass schematic, now with the output marker placed across the capacitor. The cue is the capacitor branch, because the output is measured across $C$, not across the input source or the resistor.

![](<../Source/10.3.1. RC Low-Pass Circuit Model/Images/l001-s003-te-section-003.png>)

Trace the voltage across the capacitor and name that signal $v_C(t)$. Since the output marker is across the same element, the output signal is the capacitor voltage.

$$
v_{out}(t)=v_C(t)
$$

So the output is $v_C(t)$, while $v_{in}(t)$ stays the input and $v_R(t)$ stays the resistor voltage. That output convention is the one you will use in the next RC low-pass steps.

## Interpreting the RC Low-Pass Circuit as an Input-Output Filter

**Example:** In the standard RC low-pass circuit, identify the input signal, the output signal, and the circuit as an input-output filter.

**Explanation**

Use the same canonical RC low-pass schematic, now annotated with an input arrow at the source and an output arrow across the capacitor. The cue is the signal flow from source to capacitor, because the circuit is being read as a two-signal filter.

![](<../Source/10.3.1. RC Low-Pass Circuit Model/Images/l001-s004-te-section-004.png>)

Mark the source-side signal as the input and the capacitor voltage as the output. The resistor and capacitor together are the system elements that sit between those two signals.

$$
v_{out}(t)=v_C(t)
$$

So the model is a driven LTI filter: $v_{in}(t)$ enters on one side, $v_C(t)$ leaves on the other, and the RC network maps one to the other. That system boundary is the interpretation you will reuse in the later differential-equation and frequency-response steps.
