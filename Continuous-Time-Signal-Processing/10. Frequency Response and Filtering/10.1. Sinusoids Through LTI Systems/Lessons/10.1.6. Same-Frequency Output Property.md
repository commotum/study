## Introduction to Same-Frequency Output Property

A continuous-time LTI system does not create a new angular frequency from a single sinusoidal input. The output keeps the same coefficient of $t$; only the gain and phase can change.

$$
x(t)=e^{j\omega_0 t}
$$

That is the eigenfunction form: if the input is $x(t)=e^{j\omega_0 t}$, then the output is $y(t)=H(j\omega_0)e^{j\omega_0 t}$. The factor $H(j\omega_0)$ can change magnitude and phase, but it does not change $\omega_0$.

$$
x(t)=A\cos(\omega_0 t+\phi) \quad \Rightarrow \quad y(t)=B\cos(\omega_0 t+\phi+\theta)
$$

So for a real sinusoid, read the input frequency from the coefficient of $t$ and keep that same $\omega_0$ in the output. The amplitude may become $B$, and the phase may shift by $\theta$, but the angular frequency stays fixed for the later examples in this lesson.

<a id="identifying-the-output-angular-frequency-from-a-single-sinusoidal-input"></a>
## Identifying the Output Angular Frequency from a Single Sinusoidal Input

**Example:** An LTI system receives $x(t)=2\cos(5t-\pi/3)$. What angular frequency must appear in the output sinusoid?

**Explanation**

The cue is the coefficient of $t$ inside the input sinusoid. For $x(t)=2\cos(5t-\pi/3)$, that coefficient is $5$, so the input angular frequency is $\omega_0=5$.

$$
x(t)=2\cos(5t-\pi/3) \;\Rightarrow\; y(t)=B\cos(5t+\theta)
$$

For a continuous-time LTI system, the amplitude $2$ and the phase $-\pi/3$ can change, but the angular frequency does not. So the output must still use $5$ as the coefficient of $t$.

Therefore, the output angular frequency is $\omega_0=5$.

## Recognizing Same Frequency Despite Amplitude Changes

**Example:** An LTI system turns $x(t)=\cos(7t)$ into $y(t)=3\cos(7t-\pi/4)$. Which part of the output changed, and which part stayed the same?

**Explanation**

The cue is the coefficient of $t$ in the input cosine. Here $x(t)=\cos(7t)$, so the input angular frequency is $\omega_0=7$.

$$
x(t)=\cos(7t) \quad \Rightarrow \quad y(t)=3\cos(7t-\pi/4)
$$

The factor $3$ changes only the amplitude, and the phase shift $-\pi/4$ changes only the starting angle. The coefficient of $t$ is still $7$, so the output keeps the same angular frequency.

So the part that changed is amplitude, and the part that stayed the same is the angular frequency $7$.

## Recognizing Same Frequency Despite Phase Shifts

**Example:** An LTI system turns $x(t)=4\sin(3t+\pi/6)$ into $y(t)=4\sin(3t-\pi/3)$. What changed, and what stayed fixed?

**Explanation**

The cue is the coefficient of $t$ in the input sine. Here $x(t)=4\sin(3t+\pi/6)$, so the input angular frequency is $\omega_0=3$.

$$
x(t)=4\sin(3t+\pi/6) \quad \Rightarrow \quad y(t)=4\sin(3t-\pi/3)
$$

The phase changes from $\pi/6$ to $-\pi/3$, so the starting angle shifts. The coefficient of $t$ is still $3$, so the output keeps the same angular frequency.

So the phase changed, and the angular frequency stayed fixed at $3$.

<a id="rejecting-output-sinusoids-with-new-frequencies"></a>
## Rejecting Output Sinusoids with New Frequencies

**Example:** An LTI system receives $x(t)=\cos(2t)$. Which proposed output cannot be correct because it changes the angular frequency?

**Explanation**

The cue is the coefficient of $t$ in the input. Here $x(t)=\cos(2t)$, so the input angular frequency is $\omega_0=2$.

$$
x(t)=\cos(2t) \quad \Rightarrow \quad y(t)=A\cos(2t+\phi)
$$

Any proposed output with a different coefficient of $t$ is impossible. For example, a term like $\cos(4t-\pi/3)$ or $\cos(t+\pi/6)$ would change the angular frequency, so it cannot come from this input.

Keep the candidates that preserve $2t$, even if their amplitude or phase changes. A sign flip such as $-\cos(2t)$ still has angular frequency $2$ because it only adds a phase shift.
