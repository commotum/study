## Introduction to Periodic Inputs Through an LTI System

A periodic input is handled one harmonic at a time. Start by writing the Fourier-series form of the input, where each coefficient $X_k$ belongs to the harmonic at frequency $k\omega_0$.

$$
x(t)=\sum_{k=-\infty}^{\infty}X_k e^{jk\omega_0 t}
$$

For a single complex exponential $e^{j\omega t}$, an LTI system keeps the same frequency and scales the signal by $H(j\omega)$. So the harmonic with index $k$ keeps its index and picks up the factor $H(jk\omega_0)$.

$$
Y_k=H(jk\omega_0)X_k
$$

The DC term is just the $k=0$ harmonic, so it uses $H(0)$. Positive and negative harmonics follow the same rule, with each coefficient scaled by the response value at its own frequency.

The operational takeaway is simple: compute each $Y_k$ separately, then rebuild the periodic output from the scaled coefficients.

$$
y(t)=\sum_{k=-\infty}^{\infty}Y_k e^{jk\omega_0 t}
$$

## Scaling One Fourier-Series Harmonic by $H(jk\omega_0)$

**Example:** A periodic input has one nonzero harmonic coefficient $X_2=3-2j$, and the system response at that harmonic is $H(j2\omega_0)=1+j$. Find the output coefficient $Y_2$.

**Explanation**

The cue is a single Fourier-series harmonic with index $k=2$. Use the harmonic-scaling rule from the tutorial: keep the same harmonic index and change only the coefficient.

Here the input coefficient is $X_2=3-2j$ and the matching response value is $H(j2\omega_0)=1+j$. Substitute those values directly into $Y_k=H(jk\omega_0)X_k$.

$$
Y_2=H(j2\omega_0)X_2=(1+j)(3-2j)=5+j
$$

So the output coefficient is $Y_2=5+j$. The harmonic frequency itself does not change; only the coefficient attached to the $k=2$ harmonic changes.

That is the pattern to reuse for every other harmonic: match the index, multiply by the response value at that frequency, and simplify the product.

## Computing Output Coefficients for Several Harmonics

**Example:** A periodic input has coefficients $X_{-1}=1+j$, $X_0=2$, and $X_1=1-j$, and the system response values are $H(-j\omega_0)=2$, $H(0)=\tfrac12$, and $H(j\omega_0)=1-j$. Find $Y_{-1}$, $Y_0$, and $Y_1$.

**Explanation**

The cue is a small Fourier-series table with one DC term and two side harmonics. Match each harmonic index to its own response value before multiplying.

Use the same scaling rule for each index: $Y_k=H(jk\omega_0)X_k$. Here that means one computation for $k=-1$, one for $k=0$, and one for $k=1$.

$$
\begin{aligned}
Y_{-1} &= H(-j\omega_0)X_{-1} = 2(1+j) = 2+2j \\
Y_0 &= H(0)X_0 = \tfrac12 \cdot 2 = 1 \\
Y_1 &= H(j\omega_0)X_1 = (1-j)(1-j) = -2j
\end{aligned}
$$

So the output coefficients are $Y_{-1}=2+2j$, $Y_0=1$, and $Y_1=-2j$. Each harmonic keeps its index; only the coefficient changes.

## Scaling the DC Component with $H(0)$

**Example:** A periodic input has DC coefficient $X_0=4$ and the system has $H(0)=\frac12$. Find the output DC coefficient $Y_0$.

**Explanation**

The cue is the $k=0$ harmonic, or DC term. For periodic inputs, the DC term follows the same harmonic-scaling rule as every other coefficient.

Here the input has $X_0=4$ and the system gain at zero frequency is $H(0)=\frac12$. Write the output coefficient as $Y_0=H(0)X_0$.

$$
Y_0=H(0)X_0=\tfrac12 \cdot 4 = 2
$$

So the output DC coefficient is $Y_0=2$. The harmonic index stays $k=0$; only the coefficient is scaled.

This is the same move you will reuse whenever a periodic input has a nonzero DC term: match $k=0$, multiply by $H(0)$, and simplify.

## Scaling Positive and Negative Harmonic Pairs

**Example:** A real periodic input has $X_1=2-j$ and $X_{-1}=2+j$, while the system response is $H(j\omega_0)=1-j$ and $H(-j\omega_0)=1+j$. Find $Y_1$ and $Y_{-1}$.

**Explanation**

The cue is a positive/negative harmonic pair at $k=1$ and $k=-1$. Treat each sign separately and match each coefficient to its own response value.

Here $X_1=2-j$ matches $H(j\omega_0)=1-j$, and $X_{-1}=2+j$ matches $H(-j\omega_0)=1+j$. Write the two coefficient relations directly.

$$
\begin{aligned}Y_1 &= H(j\omega_0)X_1 = (1-j)(2-j) = 1-3j \\Y_{-1} &= H(-j\omega_0)X_{-1} = (1+j)(2+j) = 1+3j\end{aligned}
$$

So the output pair is $Y_1=1-3j$ and $Y_{-1}=1+3j$. Each sign of $k$ uses its own response value; the index does not get swapped.

For a real input, the positive and negative harmonics stay conjugate after scaling. The reusable move is to match $k$ with $H(jk\omega_0)$ before multiplying.

<a id="reconstructing-the-periodic-output-from-scaled-coefficients"></a>
## Reconstructing the Periodic Output from Scaled Coefficients

**Example:** Given scaled coefficients $Y_{-1}=1+j$, $Y_0=2$, and $Y_1=1-j$, write the output $y(t)$ as a Fourier series and, if helpful, convert the conjugate pair into a real sinusoidal form.

**Explanation**

The cue is a short list of output coefficients. Reconstruct the periodic output by placing each coefficient back on its harmonic, then group the conjugate pair if you want a real-signal form.

Here the scaled coefficients are $Y_{-1}=1+j$, $Y_0=2$, and $Y_1=1-j$. Substitute them into the Fourier-series synthesis formula for $y(t)$.

$$
\begin{aligned}y(t) &= \sum_{k=-1}^{1} Y_k e^{jk\omega_0 t} \\ &= Y_{-1}e^{-j\omega_0 t}+Y_0+Y_1e^{j\omega_0 t} \\ &= (1+j)e^{-j\omega_0 t}+2+(1-j)e^{j\omega_0 t} \\ &= 2+2\cos(\omega_0 t)+2\sin(\omega_0 t)\end{aligned}
$$

So the reconstructed output can be written as $y(t)=(1+j)e^{-j\omega_0 t}+2+(1-j)e^{j\omega_0 t}$, or equivalently as $y(t)=2+2\cos(\omega_0 t)+2\sin(\omega_0 t)$. The coefficients are back in the signal, and the harmonic indices are unchanged.

This closes the workflow: scale each Fourier coefficient, then rebuild $y(t)$ from the scaled coefficients using the same harmonic basis.
