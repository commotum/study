## Introduction to $Y(s)=X(s)H(s)$

When an LTI output is written as $y(t)=x(t)*h(t)$, the cue is the convolution symbol $*$. That cue tells you to move from the time-domain relation to the Laplace-domain product $Y(s)=X(s)H(s)$.

$$
Y(s)=X(s)H(s)
$$

Use $X(s)=\mathcal{L}\{x(t)\}$ for the input transform, $H(s)=\mathcal{L}\{h(t)\}$ for the system transform, and $Y(s)=\mathcal{L}\{y(t)\}$ for the output transform. Keep those roles fixed whenever you read or write the relation.

$$
\mathcal{L}\{x(t)*h(t)\}=\mathcal{L}\{x(t)\}\,\mathcal{L}\{h(t)\}
$$

Substituting those symbols into the transform rule gives $Y(s)=X(s)H(s)$. In this form, the output transform is the product of the input transform and the system transform.

That is the direct mapping you will reuse in the next steps: start from $y(t)=x(t)*h(t)$, identify $X(s)$, $H(s)$, and $Y(s)$, and read the output as the product relation in the $s$-domain.

## Translating an LTI Convolution Output into a Product Equation

**Example:** Show that from $y(t)=x(t)*h(t)$, with $X(s)=\frac{1}{s+1}$ and $H(s)=\frac{2}{s+2}$, the output transform is $Y(s)=X(s)H(s)=\frac{2}{(s+1)(s+2)}$.

**Explanation**

The cue is the convolution symbol in $y(t)=x(t)*h(t)$. For an LTI system, that cue tells you to use the Laplace convolution theorem and move from the time-domain relation to the product relation in the $s$-domain.

$$
Y(s)=\mathcal{L}\{y(t)\}=\mathcal{L}\{x(t)*h(t)\}=\mathcal{L}\{x(t)\}\,\mathcal{L}\{h(t)\}
$$

Now keep the symbol roles fixed: $X(s)$ is the input transform, $H(s)$ is the system transform, and $Y(s)$ is the output transform. With that mapping in place, the identity becomes $Y(s)=X(s)H(s)$.

$$
Y(s)=X(s)H(s)=\frac{1}{s+1}\cdot\frac{2}{s+2}=\frac{2}{(s+1)(s+2)}
$$

This is the worked substitution: the time-domain convolution becomes multiplication, the input and system transforms stay on the right side, and the result is the output transform $Y(s)$.

## Identifying $X(s)$, $H(s)$, and $Y(s)$ in the Product Relation

**Example:** Given $Y(s)=\frac{4}{(s+1)(s+2)}$ from an LTI relation, identify which symbolic factor is $X(s)$, which is $H(s)$, and which is $Y(s)$, then state the interpretation in one sentence.

**Explanation**

Start with the left side: by definition, the quantity labeled $Y(s)$ is the output transform. The factorization on the right side must therefore be read as the product of the input transform and the system transform.

$$
Y(s)=\frac{4}{(s+1)(s+2)}
$$

Use the LTI interpretation to assign the fixed system factor to $H(s)$ and the remaining factor to $X(s)$. In a product relation, the two right-hand factors are not interchangeable: their roles come from the system statement, not from algebra alone.

$$
Y(s)=X(s)H(s),\qquad X(s)=\frac{4}{s+1},\qquad H(s)=\frac{1}{s+2}
$$

So the interpretation is: $Y(s)$ is the output transform, $X(s)$ is the input transform, and $H(s)$ is the system transform. This is the role check you will reuse whenever a product in the $s$-domain appears.

<a id="writing-ys-from-given-input-and-system-transforms"></a>
## Writing $Y(s)$ from Given Input and System Transforms

**Example:** Compute $Y(s)$ from $X(s)=\frac{3}{s+1}$ and $H(s)=\frac{s}{s+4}$ by applying the topic core move.

**Explanation**

The cue is the product relation $Y(s)=X(s)H(s)$. That tells you to keep the input transform and system transform separate and multiply them directly in the $s$-domain.

$$
Y(s)=X(s)H(s)
$$

Substitute the given transforms exactly as written: $X(s)=\frac{3}{s+1}$ and $H(s)=\frac{s}{s+4}$. Then multiply the numerators and denominators without changing the symbol roles.

$$
Y(s)=\frac{3}{s+1}\cdot\frac{s}{s+4}=\frac{3s}{(s+1)(s+4)}
$$

So the output transform is $Y(s)=\frac{3s}{(s+1)(s+4)}$. The computation stays inside the same interpretation: $X(s)$ is the input transform, $H(s)$ is the system transform, and $Y(s)$ is the output transform.

<a id="interpreting-ysxshs-as-the-laplace-domain-lti-system-relation"></a>
## Interpreting $Y(s)=X(s)H(s)$ as the Laplace-Domain LTI System Relation

**Example:** With fixed $H(s)=\frac{1}{s+2}$ and varying input transforms, compare outputs for $X_1(s)=\frac{1}{s+1}$ and $X_2(s)=\frac{2}{s+1}$ using the same $Y(s)=X(s)H(s)$ relation.

**Explanation**

The cue is that $H(s)$ is fixed. That means the system part stays the same while the input transform changes, so you compare outputs by applying the same product rule to each input.

$$
Y_1(s)=X_1(s)H(s), \qquad Y_2(s)=X_2(s)H(s)
$$

Substitute the given transforms exactly as written: $X_1(s)=\frac{1}{s+1}$, $X_2(s)=\frac{2}{s+1}$, and $H(s)=\frac{1}{s+2}$. The only change across the two cases is the input factor.

$$
Y_1(s)=\frac{1}{s+1}\cdot\frac{1}{s+2}=\frac{1}{(s+1)(s+2)}, \qquad Y_2(s)=\frac{2}{s+1}\cdot\frac{1}{s+2}=\frac{2}{(s+1)(s+2)}
$$

So the same Laplace-domain system relation produces outputs that differ only through the input transform. The fixed factor is $H(s)$, and each output is still an $s$-domain result of the form $Y(s)=X(s)H(s)$.
