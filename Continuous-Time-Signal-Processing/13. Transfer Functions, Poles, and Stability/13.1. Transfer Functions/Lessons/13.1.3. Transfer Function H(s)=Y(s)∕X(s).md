## Introduction to Transfer Function $H(s)=Y(s)/X(s)$

For an LTI system, the Laplace-domain input-output relation is $Y(s)=X(s)H(s)$. The object to recognize here is $H(s)$: it is the system-only factor, separate from the particular input and output transforms.

$$
Y(s)=X(s)H(s)
$$

If $X(s)\neq 0$, divide both sides by $X(s)$ to isolate the system factor. This is the allowed algebraic move that removes the input dependence and leaves only the transfer function.

$$
H(s)=\frac{Y(s)}{X(s)}
$$

So the transfer function is not a new signal; it is the ratio that describes the LTI system itself. In later work, the same $H(s)$ stays with the system while different inputs change $X(s)$ and $Y(s)$.

$$
X(s)\neq 0
$$

The base case is simple cancellation: if $X(s)$ and $Y(s)$ share the same factor, divide it out and read the remaining constant or rational factor as $H(s)$. That is the core move this section prepares.

<a id="isolating-hs-from-ysxshs"></a>
## Isolating $H(s)$ from $Y(s)=X(s)H(s)$

**Example:** Given $X(s)=\frac{4}{s+1}$ and $Y(s)=\frac{10}{s+1}$, find $H(s)$.

**Explanation**

The cue is the product relation $Y(s)=X(s)H(s)$. To isolate the system factor, divide both sides by $X(s)$, assuming $X(s)\neq 0$.

$$
Y(s)=X(s)H(s)
$$

Now substitute the given transforms. Because both $X(s)$ and $Y(s)$ share the factor $(s+1)$, the ratio should cancel that shared term cleanly.

$$
H(s)=\frac{Y(s)}{X(s)}=\frac{\frac{10}{s+1}}{\frac{4}{s+1}}
$$

After cancellation, $H(s)=\frac{10}{4}=\frac{5}{2}$. This is the transfer function for the system in this example: the input factor is removed, and only the system multiplier remains.

## Finding $H(s)$ from Given Input and Output Transforms

**Example:** Given $X(s)=\frac{2}{s-3}$ and $Y(s)=\frac{8}{s-3}$, find $H(s)$.

**Explanation**

The cue is the same product relation $Y(s)=X(s)H(s)$. To isolate the system factor, divide by $X(s)$ and keep the ratio order $H(s)=Y(s)/X(s)$.

$$
Y(s)=X(s)H(s)
$$

Now substitute the given transforms. The new wrinkle is the shifted factor $(s-3)$ in both terms, but the cancellation pattern is the same because the shared pole factor appears in numerator and denominator.

$$
H(s)=\frac{Y(s)}{X(s)}=\frac{\frac{8}{s-3}}{\frac{2}{s-3}}=\frac{8}{s-3}\cdot\frac{s-3}{2}
$$

After cancellation, $H(s)=4$. The transfer function is still the system-only multiplier, and the shifted denominator does not change the ratio when the shared factor matches.

<a id="interpreting-hs-as-the-system-only-multiplier"></a>
## Interpreting $H(s)$ as the System-Only Multiplier

**Example:** Given $X(s)=\frac{2}{s+1}$ and $Y(s)=\frac{8}{s+1}$, find $H(s)$ and explain why the ratio represents only the system, not the specific input.

**Explanation**

The cue is still the product relation $Y(s)=X(s)H(s)$. To isolate the system factor, divide by $X(s)$ and keep the ratio order $H(s)=Y(s)/X(s)$.

$$
Y(s)=X(s)H(s)
$$

Now substitute the given transforms. Both $X(s)$ and $Y(s)$ share the same factor $(s+1)$, so the algebra should cancel that input-dependent part and leave only the system ratio.

$$
H(s)=\frac{Y(s)}{X(s)}=\frac{\frac{8}{s+1}}{\frac{2}{s+1}}
$$

After cancellation, $H(s)=4$. That result is the system-only multiplier: it describes the LTI system itself, while the specific input only changes $X(s)$ and therefore $Y(s)$ through the same ratio.

## Recognizing the Same Transfer Function Across Different Inputs

**Example:** Experiment A: $X_1(s)=\frac{1}{s+2}$, $Y_1(s)=\frac{3}{s+2}$. Experiment B: $X_2(s)=\frac{5}{s+2}$, $Y_2(s)=\frac{15}{s+2}$. Compute the transfer function from each and verify whether they match.

**Explanation**

The cue is the same product relation in each experiment: $Y(s)=X(s)H(s)$. To identify the system-only factor, divide each output transform by its matching input transform and keep the ratio order $H(s)=Y(s)/X(s)$.

$$
H_1(s)=\frac{Y_1(s)}{X_1(s)},\qquad H_2(s)=\frac{Y_2(s)}{X_2(s)}
$$

Now substitute the two pairs. Each experiment has the same shared factor $(s+2)$, so the cancellation pattern is identical even though the amplitudes are different.

$$
H_1(s)=\frac{\frac{3}{s+2}}{\frac{1}{s+2}}=3,\qquad H_2(s)=\frac{\frac{15}{s+2}}{\frac{5}{s+2}}=3
$$

Both ratios give $H(s)=3$, so the transfer function is the same across the two input-output pairs. That matching ratio is the system characteristic, while the specific input only changes the numerical scale of $X(s)$ and $Y(s)$.
