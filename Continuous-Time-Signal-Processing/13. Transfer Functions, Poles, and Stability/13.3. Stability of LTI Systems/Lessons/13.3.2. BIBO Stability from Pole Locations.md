## Introduction to BIBO Stability from Pole Locations

From the prior lesson, the prerequisite for this topic is already established: the system must be causal before applying pole-based BIBO tests. The object to track in this step is a transfer function written in the rational form $H(s)=\frac{N(s)}{D(s)}$.

Next define the poles as the roots of the denominator polynomial: if $D(s)=\prod_i (s-p_i)$, then each $p_i$ is a pole location in the complex $s$-plane. The left half-plane is the set of points where $\Re\{s\}<0$.

$$
H(s)=\frac{N(s)}{D(s)},\; D(s)=\prod_i (s-p_i)
$$

For a causal LTI system, the direct rule is strict: BIBO stability is true exactly when every pole has negative real part. This means $\Re\{p_i\}<0$ for each pole $p_i$ and any pole with $\Re\{p_i\}\ge 0$ is not allowed in this check.

$$
\text{BIBO stable for causal LTI} \iff \Re\{p_i\}<0\;\text{for every pole }p_i.
$$

Use the base case $H(s)=\frac{1}{s+2}$. The denominator is $s+2$, so the only pole is $-2$. Since $\Re\{-2\}=-2<0$, this transfer function is BIBO stable.

Contrast examples by inspection: $H(s)=\frac{1}{s-1}$ has pole $p=1$, so $\Re\{p\}>0$ and it is unstable. $H(s)=\frac{1}{s}$ has pole on the imaginary axis, $\Re\{p\}=0$, so it is not accepted as BIBO stable under this strict criterion.

Use this same move in three representations: listed poles, factored transfer functions, and pole-zero style lists. In later sections, the action stays the same: check causality first, then apply the pole sign test to classify each system as BIBO stable or unstable.

## Classifying a Causal LTI System from Listed Pole Locations

**Example:** Classify $H(s)$ for poles $\{p_1=-1,p_2=-3,p_3=2\}$.

**Explanation**

The cue here is the explicit pole list $\{p_1,p_2,p_3\}$. For a causal LTI system, apply the strict BIBO rule: every pole must be in the left half-plane, so each pole must satisfy $\Re\{p_i\}<0$.

$$
\{p_1=-1,p_2=-3,p_3=2\}
$$

Execute the test pole-by-pole. The three real parts are $\Re\{p_1\}=-1$, $\Re\{p_2\}=-3$, and $\Re\{p_3\}=2$.

Check the strict inequality: $p_1$ and $p_2$ satisfy $\Re\{p_i\}<0$, but $p_3=2$ does not because its real part is positive. A single violating pole is sufficient to fail the criterion.

$$
\text{BIBO stable} \iff \forall i,\,\Re\{p_i\}<0
$$

So this example is not BIBO stable because of the pole at $2$, and the result is unstable for the causal LTI system.

## Classifying Stability from a Factored Transfer Function

**Example:** Classify $H(s)=\dfrac{(s+2)(s+4)}{(s+1)(s+3)(s+6)}$.

**Explanation**

The cue is a transfer function written with factored denominator factors. Use the BIBO stability cue: for a causal LTI system, all poles must be strictly in the left half-plane, so the rule is $\Re(p)<0$ for every pole.

$$
H(s)=\dfrac{(s+2)(s+4)}{(s+1)(s+3)(s+6)}
$$

Start by extracting poles from the denominator only. Set each denominator factor to zero: $(s+1)=0$, $(s+3)=0$, and $(s+6)=0$. This gives poles $p_1=-1$, $p_2=-3$, and $p_3=-6$.

$$
D(s)=(s+1)(s+3)(s+6),\quad p_1=-1,\;p_2=-3,\;p_3=-6
$$

Check each real part: $\Re(p_1)=-1$, $\Re(p_2)=-3$, and $\Re(p_3)=-6$. Every pole satisfies the strict left-half-plane condition.

Since all poles are strictly negative on the real axis, the system is BIBO stable.

## Classifying Stability from a Pole-Zero Plot

**Example:** Use the provided pole-zero plot to classify stability for poles at $-1$, $-4$, and $0.8$ with zeros at $\pm j2$.

**Explanation**

The cue is an s-plane pole-zero plot. Your action is to read the pole locations, then apply the same strict rule from earlier sections: a causal LTI system is BIBO stable only if every pole satisfies $\Re(p)<0$.

![](<../Source/13.3.2. BIBO Stability from Pole Locations/Images/l002-s004-te-section-004.png>)

First, extract the poles from the plot: $-1$, $-4$, and $0.8$. Ignore zero locations at this step, because zeros do not enter the BIBO pole test.

Next, compute the real parts of the poles: $\Re(-1)=-1$, $\Re(-4)=-4$, and $\Re(0.8)=0.8$. Check each one against the strict condition $\Re(p)<0$.

Because $0.8$ is in the right half-plane, the rule fails, so the system is not BIBO stable. The result is unstable.

## Detecting Instability from One Pole Outside the Strict Left Half-Plane

**Example:** Classify the stability of $H(s)=\dfrac{5}{(s+3)(s+0.5)(s-0.1)}$.

**Explanation**

This is the pole-sign diagnostic form: extract all poles from the transfer function denominator, then apply the same strict left-half-plane rule as before.

Set each denominator factor to zero: $(s+3)=0$, $(s+0.5)=0$, and $(s-0.1)=0$, so the poles are $p_1=-3$, $p_2=-0.5$, and $p_3=0.1$.

Apply $\Re(p)<0$ to each pole. For $p_1=-3$, $p_2=-0.5$, and $p_3=0.1$, we have $\Re(-3)=-3<0$, $\Re(-0.5)=-0.5<0$, and $\Re(0.1)=0.1>0$.

The outlier is $0.1$, which lies in the right half-plane. Because one pole violates the strict condition, the system is unstable.
