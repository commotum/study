## Introduction to Causal LTI Systems

A continuous-time LTI system is causal exactly when its impulse response has no active values for negative time, so causality is the rule $h(t)=0$ for every $t<0$. In short: if $h(t)$ is nonzero before $t=0$, the system would require future input values and is noncausal.

$$
h(t)=0,\; t<0
$$

The same rule is about support. A right-sided impulse response like $h(t)=0$ for $t<0$ and possibly nonzero for $t\ge 0$ is causal. A left-sided response has support only in $t<0$ and is noncausal. A bilateral response has nonzero values on both sides of the origin and is also noncausal because of the negative-time component.

In this module, we also use the same time-domain rule before pole-based arguments: pole-location checks assume the system passes the causality prerequisite. So first verify the support condition on $h(t)$, and only then move to pole placement for the stability step.

Use stable notation for quick checks from formulas: write the time-domain support statement, check the sign of $t$, and test a representative negative time sample. For the base case $h(t)=e^{-t}u(t)$, use the same rule: since $u(t)=0$ for $t<0$, the impulse response is causal and has no nonzero left-time contribution.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

## Checking $h(t)=0 for t<0 from an Impulse Response Formula$

**Example:** Check causality of $h(t)=3e^{-t}u(t)-5u(t+2)$ by testing the value of $h(t)$ for $t<0$.

**Explanation**

The cue is whether any part of the impulse response is nonzero for negative time. Use the same rule as the tutorial: a continuous-time LTI system is causal only if $h(t)=0$ for every $t<0$.

Use the step-function support conditions: $u(t)=0$ for $t<0$, and $u(t+2)=0$ for $t<-2$, so the first term is zero on negative time and the second term is only constrained to zero before $t=-2$.

$$
u(t)=\begin{cases}0,&t<0\\1,&t\ge 0\end{cases},\quad u(t+2)=\begin{cases}0,&t<-2\\1,&t\ge -2\end{cases}
$$

Now test the negative-time region with a representative value, for example $t=-1\in(-2,0)$: the first term has $u(-1)=0$, so $3e^{-(-1)}u(-1)=0$, while the second term has $u(1)=1$, so $-5u(-1+2)=-5$.

$$
h(-1)=3e^{-(-1)}u(-1)-5u(-1+2)=0-5=-5\neq 0
$$

Because there exists a negative-time value with nonzero output, $h(t)$ violates the support condition, so this LTI system is noncausal.

## Checking Causality from an Impulse Response Graph

**Example:** From the graph of $h(t)$ shown, identify whether the LTI system is causal and explain the negative-time support test used.

**Explanation**

Use the same causality rule from the tutorial: a continuous-time LTI system is causal only if its impulse response is zero for every negative-time value. So classify by reading support from the graph.

![](<../Source/13.3.1. Causal LTI Systems/Images/l001-s003-te-section-003-graph.png>)

Locate support intervals in the plotted response. Here the graph has nonzero values both around the small negative interval $( -0.5, -0.25 )$ and for $t\ge 0$, so the support is split across negative and nonnegative time.

$$
\text{Supp}(h)=(-0.5,-0.25)\cup[0,\infty)
$$

Now check the negative-time rule directly. Pick one point in the left-side pulse, for example $t=-0.4$, and read $h(-0.4)\neq 0$ from the graph.

Because at least one nonzero value exists for $t<0$, the system is noncausal. The graph-based support test gives the same conclusion as the symbolic support test: any nonzero negative-time component breaks causality.

## Identifying Noncausal Negative-Time Support

**Example:** Identify the negative-time support of $h(t)=4e^{-0.5t}u(t-2)-2u(-t+1)$ and classify causality.

**Explanation**

Treat this as a support-triage task. The cue is the unit-step terms, so use the causality rule: a continuous-time LTI system is causal only if every nonzero part of $h(t)$ vanishes on $t<0$.

Split the expression into its two support contributors. For the first term, $u(t-2)=0$ for $t<2$, so $4e^{-0.5t}u(t-2)$ has support only for $t\ge 2$. For the second term, $u(-t+1)=1$ when $-t+1\ge 0$, i.e. $t\le 1$, so $-2u(-t+1)$ is active on the nonpositive-to-negative side.

$$
\text{Supp}(4e^{-0.5t}u(t-2))=[2,\infty),\quad \text{Supp}(-2u(-t+1))=(-\infty,1]
$$

Apply the strict negative-time test: intersect each support set with $t<0$. The first support $[2,\infty)$ has no negative-time overlap, but $(-\infty,1]$ contributes all negative times, so the combined impulse response is nonzero on $t<0$.

$$
\{t<0:\, h(t)\neq 0\}=(-\infty,0)
$$

A quick sample verifies it. At $t=-1$, $h(-1)=4e^{0.5}u(-3)-2u(2)=0-2=-2\neq 0$. A nonzero negative-time value is enough to fail the causality prerequisite.

Conclusion: because $h(t)$ has nonzero negative-time support, the system is noncausal. If causality fails here, do not rely on pole-based stability conclusions until the support rule is satisfied.

## Verifying Causality Before Using Pole Locations

**Example:** For $H(s)=\frac{1}{s^2+1}$, state the time-domain causality check flow before applying pole-location stability rules and show the consequence if $h(t)$ were found noncausal.

**Explanation**

The cue is the sequence control requirement: this lesson always tests causality first, then only proceeds to pole-based BIBO rules. Start by finding a time-domain form of $h(t)$ and checking support before reading poles.

Invert $H(s)=\frac{1}{s^2+1}$ using the standard pair. With a causal ROC choice, $h(t)=\sin(t)u(t)$. This form is right-sided, so its support is $\{t: t\ge 0\}$.

$$
h(t)=\sin(t)u(t),\quad \operatorname{Supp}(h)= [0,\infty).
$$

Check the strict causality condition from this topic: $h(t)$ must satisfy $h(t)=0$ for all $t<0$. For $h(t)=\sin(t)u(t)$, the condition is satisfied, so the system is causal at this checkpoint.

Now the flow is explicit: causal result first, then pole-location interpretation. If this step had returned a noncausal form such as $h(t)=\sin(t)u(-t)$, we would stop here, report noncausal status, and defer any BIBO claim from pole locations because the prerequisite is violated.

Therefore, the example answer is: verify right-sided support from the inverse transform, accept the causality prerequisite, and only then run the next stability decision rule.
