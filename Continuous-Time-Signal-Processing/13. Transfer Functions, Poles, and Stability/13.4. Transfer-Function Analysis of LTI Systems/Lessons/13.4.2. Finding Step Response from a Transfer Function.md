## Introduction to Finding Step Response from a Transfer Function

The first-pass procedure for this section is the step-response move in Laplace form: start from the system rule $Y(s)=X(s)H(s)$, then convert it into the unit-step workflow by substituting $X(s)=1/s$. This means every worked step keeps the same notation and the same order of operations: form the product, simplify, then invert.

Use the unit-step transform rule directly. For a unit step input, $\mathcal{L}\{u(t)\}=1/s$, so the direct substitution is $X(s)=1/s$ and the step-response transform is formed as a single division by $s$: $Y(s)=H(s)/s$.

$$
Y(s)=X(s)H(s)=\frac{1}{s}H(s)
$$

Use this base case to anchor the section: if $H(s)=\frac{1}{s+2}$, then $Y(s)=\frac{1}{s(s+2)}$. We now have a target Laplace form to invert, but we still hold off on technique details until later steps.

$$
y(t)=\mathcal{L}^{-1}\{Y(s)\}
$$

## Forming the Step-Response Transform $Y(s)=H(s)/s$

**Example:** Find $Y(s)$ for a unit-step input when $H(s)=\frac{3}{s+4}$. Show the intermediate substitution and simplification.

**Explanation**

For a unit-step input, the cue is $X(s)=\frac{1}{s}$, so we substitute this directly into the transfer-function output rule and keep only the algebraic transform form needed for inversion.

$$
Y(s)=H(s)X(s)=\left(\frac{3}{s+4}\right)\left(\frac{1}{s}\right)
$$

$$
Y(s)=\frac{3}{s(s+4)}
$$

This form is now inverse-Laplace ready and uses the same denominator structure as the tutorial baseline. The next reusable setup is a partial-fraction form for later inversion:

$$
\frac{3}{s(s+4)}=\frac{A}{s}+\frac{B}{s+4}
$$

Clearing denominators gives $3=A(s+4)+Bs$, so the coefficients are solved by coefficient matching in the next section. This preserves the established workflow: identify $H(s)$, substitute $1/s$, simplify $Y(s)$, then invert.

## Finding a Step Response from a First-Order Transfer Function

**Example:** Find $y(t)$ for $H(s)=\frac{5}{s+2}$ with a unit-step input.

**Explanation**

This example adds one wrinkle to the prior substitution step: after forming $Y(s)$, we now carry the first-order expression through partial fractions so the inverse Laplace table can be applied directly.

The cue is a first-order transfer function under a unit-step input, so keep the same core move and start with the product form $Y(s)=X(s)H(s)$ with $X(s)=\frac{1}{s}$.

$$
Y(s)=\left(\frac{5}{s+2}\right)\left(\frac{1}{s}\right)=\frac{5}{s(s+2)}
$$

Decompose $\frac{5}{s(s+2)}$ into standard inverse-Laplace pieces: $\frac{5}{s(s+2)}=\frac{A}{s}+\frac{B}{s+2}$.

$$
5=A(s+2)+Bs
$$

Match constants and slopes: $2A=5\Rightarrow A=\frac{5}{2}$ and $A+B=0\Rightarrow B=-\frac{5}{2}$, so $Y(s)=\frac{5/2}{s}-\frac{5/2}{s+2}$.

$$
\mathcal{L}^{-1}\left\{\frac{5}{s(s+2)}\right\}=\frac{5}{2}\mathcal{L}^{-1}\left\{\frac{1}{s}\right\}-\frac{5}{2}\mathcal{L}^{-1}\left\{\frac{1}{s+2}\right\}=\frac{5}{2}(1-e^{-2t})u(t)
$$

So the first-order step response is $y(t)=\frac{5}{2}(1-e^{-2t})u(t)$, a stable DC value of $\frac{5}{2}$ with an exponential transient set by the pole at $-2$.

## Finding a Step Response with Distinct Real Poles

**Example:** Find $y(t)$ when $H(s)=\frac{12}{(s+1)(s+3)}$ and the input is $u(t)$.

**Explanation**

This example keeps the same unit-step substitution rule and adds one new wrinkle: the transfer function now has two distinct real poles, so we must carry $Y(s)$ through a three-term partial-fraction expansion.

Use the cue $X(s)=\frac{1}{s}$ for a unit step and form the step-response transform from the product rule.

$$
Y(s)=H(s)X(s)=\left(\frac{12}{(s+1)(s+3)}\right)\left(\frac{1}{s}\right)=\frac{12}{s(s+1)(s+3)}
$$

Set up the decomposition into standard inverse-Laplace pieces with distinct real poles:

$$
\frac{12}{s(s+1)(s+3)}=\frac{A}{s}+\frac{B}{s+1}+\frac{C}{s+3}
$$

$$
12=A(s+1)(s+3)+Bs(s+3)+Cs(s+1)
$$

Evaluate the identity at the poles: $s=0 \Rightarrow 12=3A \Rightarrow A=4$, $s=-1 \Rightarrow 12=-2B \Rightarrow B=-6$, and $s=-3 \Rightarrow 12=-6C \Rightarrow C=2$. So $Y(s)=\frac{4}{s}-\frac{6}{s+1}+\frac{2}{s+3}$.

$$
\mathcal{L}^{-1}\{Y(s)\}=4\mathcal{L}^{-1}\left\{\frac{1}{s}\right\}-6\mathcal{L}^{-1}\left\{\frac{1}{s+1}\right\}+2\mathcal{L}^{-1}\left\{\frac{1}{s+3}\right\}
$$

$$
y(t)=\left(4-6e^{-t}+2e^{-3t}\right)u(t)
$$

The result is causal and stable with a step DC term $4u(t)$ plus two decays from poles at $-1$ and $-3$, matching the practice pattern for distinct real poles.

## Finding a Step Response with Repeated Poles

**Example:** Find the unit-step response for $H(s)=\frac{4}{(s+1)^2}$.

**Explanation**

This final example keeps the same two-step pipeline but introduces one new wrinkle: a repeated pole, so decomposition must include a repeated-denominator term before inversion.

As before, use the unit-step cue $X(s)=\frac{1}{s}$ and write the step-response transform product.

$$
Y(s)=H(s)X(s)=\left(\frac{4}{(s+1)^2}\right)\left(\frac{1}{s}\right)=\frac{4}{s(s+1)^2}
$$

Use the repeated-pole form for partial fractions.

$$
\frac{4}{s(s+1)^2}=\frac{A}{s}+\frac{B}{s+1}+\frac{C}{(s+1)^2}
$$

$$
4=A(s+1)^2+Bs(s+1)+Cs
$$

Clear denominators and solve coefficients: $4=A(s+1)^2+Bs(s+1)+Cs$, so $s=0\Rightarrow A=4$, and $s=-1\Rightarrow C=-4$.

Match the remaining linear term: from $2A+B+C=0$, with $A=4$, $C=-4$, we get $B=-4$.

$$
Y(s)=\frac{4}{s}-\frac{4}{s+1}-\frac{4}{(s+1)^2}
$$

$$
\mathcal{L}^{-1}\{Y(s)\}=4\mathcal{L}^{-1}\left\{\frac{1}{s}\right\}-4\mathcal{L}^{-1}\left\{\frac{1}{s+1}\right\}-4\mathcal{L}^{-1}\left\{\frac{1}{(s+1)^2}\right\}
$$

$$
y(t)=\left(4-4e^{-t}-4te^{-t}\right)u(t)=4\left(1-(1+t)e^{-t}\right)u(t)
$$

The repeated pole introduces the $te^{-t}$ term, so repeated roots should be handled with the correct additional decomposition term $\frac{C}{(s+1)^2}$ and the corresponding $t e^{-t}$ inverse.

This result preserves the same unit-step workflow and only adds the repeated-pole pattern needed for the next practice questions.
