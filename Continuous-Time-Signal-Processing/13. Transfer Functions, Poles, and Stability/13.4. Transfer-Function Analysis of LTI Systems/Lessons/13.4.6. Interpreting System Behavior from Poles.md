## Introduction to Interpreting System Behavior from Poles

For a causal transfer function $H(s)=\dfrac{N(s)}{D(s)}$, the denominator roots are the pole locations, and the core move is to read each pole as one natural mode in the homogeneous part of the response.

To interpret behavior, write each pole as $s_k=\sigma_k+j\omega_k$ and apply this action: use the sign of $\sigma_k$ for growth or decay, and use $\omega_k$ to decide whether a mode oscillates.

$$
h(t)=\sum_k A_k e^{s_k t}u(t), \quad s_k=\sigma_k+j\omega_k
$$

Use the base case $s=-a$ first. If $a>0$, then $s=-a<0$ and the mode is decaying; if $a<0$, then $s=-a>0$ and the mode grows; if $a=0$, the mode is sustained with no exponential decay or growth.

$$
\text{if } \sigma_k<0 \Rightarrow \text{decaying mode}, \; \sigma_k=0 \Rightarrow \text{sustained mode}, \; \sigma_k>0 \Rightarrow \text{growing mode}
$$

For a complex pair $s=\sigma\pm j\omega$, this rule gives $e^{\sigma t}(A\cos(\omega t)+B\sin(\omega t))$, so $\omega\neq 0$ adds oscillation and $\sigma<0,\sigma=0,\sigma>0$ set whether the oscillation decays, persists, or grows in envelope.

Classify a full pole set by combining rules: if any pole is in the right half-plane, the system is unstable; if all poles are strictly in the left half-plane, the response is stable; if a nonzero-imaginary-axis pole exists with no right-half-plane poles, the system is marginally stable and oscillatory.

Use this as a fixed checklist in every later step: locate poles, read each real part and imaginary part, then write one behavior line for growth/decay, oscillation, and stability before moving to worked examples.

## Interpreting Decay from Left-Half-Plane Real Poles

**Example:** For $H(s)=\frac{1}{s+4}$, identify the pole location and classify stability, growth or decay, and whether the natural response oscillates.

**Explanation**

For this step, the cue is the denominator of $H(s)$, because its roots are the poles that determine natural-mode behavior.

The transfer function is already in first-order form, so solve $s+4=0$ to get the pole location.

$$
s=-4
$$

The pole has real part $\text{Re}(s)=-4<0$ and imaginary part $\text{Im}(s)=0$, so it is a left-half-plane real pole with no oscillatory component.

Apply the rule from the tutorial: negative real part gives decay and zero imaginary part gives no oscillation. Therefore this mode is stable and non-oscillatory.

$$
h(t) \propto e^{-4t}u(t), \; \text{stable} \; (\text{decaying}, \text{non-oscillatory})
$$

## Interpreting Growth from Right-Half-Plane Real Poles

**Example:** For $H(s)=\frac{1}{s-3}$, find the pole and classify the system response type.

**Explanation**

Use the same cue as before: the pole comes from the denominator of $H(s)$, which determines the natural mode behavior.

This is the mirror image of the previous real-pole case, so first set the denominator to zero: $s-3=0$.

$$
s=3
$$

The pole has real part $\text{Re}(s)=3>0$ and imaginary part $\text{Im}(s)=0$, so it is a right-half-plane real pole.

Apply the rule: positive real part gives growth, and zero imaginary part gives no oscillation. So this mode is unstable, growing, and non-oscillatory.

$$
h(t) \propto e^{3t}u(t), \; \text{unstable} \; (\text{growing}, \text{non-oscillatory}),
$$

A bounded input can therefore produce an unbounded natural response term because the exponential envelope grows with time.

## Interpreting Sustained Oscillation from Imaginary-Axis Poles

**Example:** For $H(s)=\frac{1}{s^2+9}$, find poles and classify stability and oscillatory behavior.

**Explanation**

Use the same cue: read the poles from the transfer-function denominator and classify their real and imaginary parts.

Factor the denominator and solve for the roots: set $s^2+9=0$.

$$
s = \pm 3j
$$

The poles are $\sigma\pm j\omega = 0\pm j3$, so $\text{Re}(s)=0$ and $\text{Im}(s)\neq 0$.

$$
h(t) \propto A\cos(3t)+B\sin(3t)
$$

Map this to sustained sinusoidal natural modes from $e^{\pm j3t}=\cos(3t)+j\sin(3t)$, with no exponential growth or decay envelope.

Classification is bounded, marginally stable, and oscillatory (sustained mode), which is the boundary case between stable and unstable real-axis pole cases.

## Interpreting Decaying Oscillation from Left-Half-Plane Complex-Conjugate Poles

**Example:** For $H(s)=\frac{10}{s^2+2s+5}$, find the pole pair and classify the response behavior.

**Explanation**

Use the same cue as before: the denominator of $H(s)$ gives pole locations that determine the natural-mode behavior.

Solve for roots by completing the square or using the quadratic formula: set $s^2+2s+5=0$.

$$
s = \frac{-2 \pm \sqrt{2^2-4(1)(5)}}{2} = -1 \pm 2j
$$

The poles are $s=-1\pm 2j$, so $\text{Re}(s)=-1<0$ and $\text{Im}(s)=\pm 2\neq 0$.

$$
h(t) \propto e^{-t}(A\cos 2t+B\sin 2t)
$$

Apply the rule from earlier: negative real part means decay and nonzero imaginary part means oscillation, so the natural mode is a damped sinusoid.

Full classification: stable, decaying oscillatory response (bounded and not sustained).

## Classifying Stability and Behavior from a Full Pole Set

**Example:** For $H(s)=\frac{20}{(s+5)(s+1+2j)(s+1-2j)(s-0.5)}$, classify stability, decay/growth, and oscillatory behavior.

**Explanation**

Use the same cue as all previous steps: read the pole set from the denominator factors and apply the stability and mode rules to the complete set, not just one pole.

From the denominator factorization, list every pole: $s=-5$, $s=-1+2j$, $s=-1-2j$, and $s=0.5$.

$$
s_1=-5,\; s_{2,3}=-1\pm 2j,\; s_4=0.5
$$

Compute real parts and choose the rightmost pole: $\max\{\text{Re}(s_k)\}=0.5>0$.

Because an RHP pole exists ($s=0.5$), the full transfer function is unstable and the response has growth tendency, regardless of the stable or oscillatory LHP poles.

The pair $s=-1\pm 2j$ contributes damped oscillatory modes, while $s=-5$ contributes fast-decaying non-oscillatory behavior; the final behavior class is dominated by the RHP pole.

Final classification: unstable, growing, and oscillatory (with a dominant growth component from $s=0.5$).
