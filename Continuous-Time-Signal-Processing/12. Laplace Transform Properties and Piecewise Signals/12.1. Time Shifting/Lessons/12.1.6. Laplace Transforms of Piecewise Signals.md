## Introduction to Laplace Transforms of Piecewise Signals

This lesson uses one fixed workflow for piecewise signals: convert interval definitions into shifted step terms first, then transform each delayed term with one-sided Laplace rules, then combine results with linearity.

For any interval definition, read each segment boundary as a change in the active expression, then represent that change with $u(t-a)$ or a step difference $u(t-a)-u(t-b)$. This notation keeps the signal causal and makes each segment directly transformable.

$$
X(s)=\int_0^{\infty} x(t)e^{-st}\,dt
$$

Once a segment is written as $f(t-a)u(t-a)$, apply the one-sided time-shift rule immediately: the same local-time shape contributes a factor $e^{-as}$ in the transform. The delay appears on every shifted term that starts at time $a$.

$$
\mathcal{L}\{f(t-a)u(t-a)\}=e^{-as}F(s),\;a\ge0
$$

Use linearity across all step terms before and after conversion so constants can be carried cleanly. For the base case

$x(t)=\{2,\;0\le t<3;\;5,\;t\ge3\}$ becomes $x(t)=2u(t)-2u(t-3)+5u(t-3)$, so $X(s)=\frac{2}{s}+\frac{3e^{-3s}}{s}$. This same sequence is the model you will reuse in every tutorial-ready example in this topic.

$$
\mathcal{L}\{f(t)u(t-a)\}=\sum_k e^{-as}F_k(s)\text{ terms by linearity}
$$

Use one breakpoint first, then add complexity with finite windows and ramps. Do not start with graphs, and do not change the order of terms before the transformed form is ready; preserve each boundary order so the jump locations and signs remain correct.

## Transforming a Two-Piece Signal with One Breakpoint

**Example:** Find $\mathcal{L}\{x(t)\}$ for $x(t)=\{2,\;0\le t<3;\;5,\;t\ge3\}$.

**Explanation**

The target is a piecewise constant signal with one breakpoint, so rewrite the interval definition as step-gated constants and then apply the one-sided shift rule with linearity.

Since the value changes from $2$ to $5$ at $t=3$, use a baseline term for the initial value and add a correction at the breakpoint.

$$
x(t)=2u(t)-2u(t-3)+5u(t-3)
$$

Now convert each shifted constant term using $\mathcal{L}\{u(t-a)\}=\frac{e^{-as}}{s}$, preserving causal support.

$$
\mathcal{L}\{2u(t)\}=\frac{2}{s},\quad \mathcal{L}\{2u(t-3)\}=\frac{2e^{-3s}}{s},\quad \mathcal{L}\{5u(t-3)\}=\frac{5e^{-3s}}{s}
$$

Apply linearity and combine delayed coefficients to get one compact shifted expression.

$$
X(s)=\frac{2}{s}-\frac{2e^{-3s}}{s}+\frac{5e^{-3s}}{s}=\frac{2}{s}+\frac{3e^{-3s}}{s}
$$

The jump at $t=3$ is $+3$, which matches the transform contribution $\frac{3e^{-3s}}{s}$, so this is the correct end result.

## Transforming a Piecewise Constant Signal with Multiple Breakpoints

**Example:** Find $\mathcal{L}\{x(t)\}$ for $x(t)=\{0,\;t<1;\;2,\;1\le t<3;\;-1,\;3\le t<5;\;0,\;t\ge5\}$.

**Explanation**

This piecewise signal has three breakpoints, so apply the same core move from the previous step: represent each bounded interval with step differences before transforming.

Read the active values directly from the definition: $x(t)=2$ on $1\le t<3$, then $x(t)=-1$ on $3\le t<5$, and zero elsewhere. This is a finite-window correction pattern.

$$
x(t)=2\bigl(u(t-1)-u(t-3)\bigr)-\bigl(u(t-3)-u(t-5)\bigr)
$$

Each term is now a delayed constant with one-sided support, so apply $\mathcal{L}\{u(t-a)\}=\frac{e^{-as}}{s}$ and keep the signs from the interval differences.

$$
\mathcal{L}\{2u(t-1)\}=\frac{2e^{-s}}{s},\quad \mathcal{L}\{2u(t-3)\}=\frac{2e^{-3s}}{s},\quad \mathcal{L}\{u(t-3)\}=\frac{e^{-3s}}{s},\quad \mathcal{L}\{u(t-5)\}=\frac{e^{-5s}}{s}
$$

Use linearity to combine the coefficients with the shared $1/s$ factor.

$$
X(s)=\frac{2e^{-s}-2e^{-3s}-e^{-3s}+e^{-5s}}{s}=\frac{2e^{-s}-3e^{-3s}+e^{-5s}}{s}
$$

A quick check at $t=1,3,5$ confirms jumps of $+2$, $-3$, and $+1$, matching the interval coefficients in the symbolic expression, so the transformed form is consistent.

## Transforming a Piecewise Linear Signal with Shifted Ramps

**Example:** Find $\mathcal{L}\{x(t)\}$ for the piecewise signal $x(t)=0$ on $0 \le t < 1$, $x(t)=t-1$ on $1 \le t < 4$, and $x(t)=0$ for $t \ge 4$.

**Explanation**

The signal is a delayed ramp that turns on at $t=1$ and turns back off at $t=4$. The useful cue is that the active piece is written in local time as $t-1$, so the first term should match the shifted-ramp pattern $(t-a)u(t-a)$.

$$
\mathcal{L}\{(t-a)u(t-a)\}=\frac{e^{-as}}{s^2}
$$

Use step functions to keep the ramp only on the interval $1 \le t < 4$. This first writes the window as one ramp that starts at $t=1$ minus the same expression after $t=4$.

$$
x(t)=(t-1)u(t-1)-(t-1)u(t-4)
$$

The first term is already a delayed local-time ramp. The second term must be re-anchored at its own turn-off time $t=4$, because the shifting rule needs powers of $t-4$ multiplying $u(t-4)$.

$$
(t-1)u(t-4)=\bigl((t-4)+3\bigr)u(t-4)
$$

Now transform each shifted piece by linearity. The $3u(t-4)$ part appears because the ramp has height $3$ at the moment it is shut off.

$$
X(s)=\frac{e^{-s}}{s^2}-e^{-4s}\left(\frac{1}{s^2}+\frac{3}{s}\right)
$$

The subtraction term closes the finite ramp window. Without it, the inverse signal would keep increasing after $t=4$ instead of returning to zero for $t \ge 4$.

## Transforming a Mixed Piecewise Signal with Shifted Steps and Ramps

**Example:** Find $\mathcal{L}\{x(t)\}$ for the signal $x(t)=0$ on $0 \le t<1$, $x(t)=t-1$ on $1 \le t<3$, and $x(t)=4$ for $t \ge 3$.

**Explanation**

The signal is zero until $t=1$, then follows a shifted ramp until $t=3$, and then becomes a constant. Write the finite ramp as a turned-on ramp minus the same ramp turned off at $t=3$, then add the delayed constant.

$$
x(t)=(t-1)u(t-1)-(t-1)u(t-3)+4u(t-3)
$$

The first ramp term is already written in local time from $t=1$. For the shutoff term at $t=3$, rewrite $t-1$ as $(t-3)+2$ so the one-sided time-shift property can be applied with the correct delay.

$$
(t-1)u(t-3)=\big((t-3)+2\big)u(t-3)
$$

$$
\mathcal{L}\{(t-1)u(t-1)\}=\frac{e^{-s}}{s^2},\quad \mathcal{L}\{(t-1)u(t-3)\}=e^{-3s}\left(\frac{1}{s^2}+\frac{2}{s}\right),\quad \mathcal{L}\{4u(t-3)\}=\frac{4e^{-3s}}{s}
$$

Now combine the transformed terms with the signs from the step representation. The delayed constant and the constant part of the shutoff term both contribute at $t=3$.

$$
\begin{aligned} X(s)&=\frac{e^{-s}}{s^2}-e^{-3s}\left(\frac{1}{s^2}+\frac{2}{s}\right)+\frac{4e^{-3s}}{s}\\ &=\frac{e^{-s}-e^{-3s}}{s^2}+\frac{2e^{-3s}}{s}. \end{aligned}
$$

So the Laplace transform is $X(s)=\frac{e^{-s}-e^{-3s}}{s^2}+\frac{2e^{-3s}}{s}$. The key alignment step is keeping every delayed term in its own local time before transforming it.
