## Introduction to Time-Shifting Property of the Laplace Transform

The one-sided Laplace transform works with causal signals, so it is written around $u(t)$ turning a signal on at and after zero. This means the signal form should explicitly include the one-sided gate, which is why we first identify the delay using $f(t-a)u(t-a)$.

The rule is: if $\mathcal{L}\{f(t)u(t)\}=F(s)$, then $\mathcal{L}\{f(t-a)u(t-a)\}=e^{-as}F(s)$ for $a\ge 0$. Here $a$ is the delay to the right and $F(s)$ is the transform of the undelayed base signal $f(t)u(t)$.

$$
\mathcal{L}\{f(t-a)u(t-a)\}=e^{-as}F(s),\quad a\ge 0
$$

Use the base case $f(t)=1$ with $\mathcal{L}\{u(t)\}=1/s$. With delay $a$, the delayed constant is $u(t-a)$, so the transform becomes $\mathcal{L}\{u(t-a)\}=e^{-as}\,\mathcal{L}\{u(t)\}=e^{-as}/s$.

$$
\mathcal{L}\{u(t-a)\}=\frac{e^{-as}}{s}
$$

Before applying the rule, check two things: first, the delayed signal is in exact form $f(t-a)u(t-a)$ with the same shift $a$ in both the base term and the step, and second, the delay satisfies $a\ge 0$ for the one-sided formula.

## Identifying the Base Signal and Delay

**Example:** Find $\mathcal{L}\{u(t-3)(t-3)^2\}$ by rewriting it in the delayed form.

**Explanation**

Treat this as a delay-identification move. The target form is $x(t)=f(t-a)u(t-a)$. Here $x(t)=u(t-3)(t-3)^2$, so the same delay $a=3$ appears in both the base argument and the step.

First rewrite the delayed base term as $f(t-3)$: set $f(t)=t^2$. Then we can express the signal as $x(t)=f(t-3)u(t-3)$, which is the exact template required by the theorem.

$$
x(t)=u(t-3)(t-3)^2=f(t-3)u(t-3),\quad f(t)=t^2.
$$

Use the known one-sided pair for the base signal: $\mathcal{L}\{t^2\}=\frac{2}{s^3}$. Because this is the delayed version with $a=3$, the delay factor is $e^{-3s}$.

$$
\mathcal{L}\{f(t-3)u(t-3)\}=e^{-3s}F(s),\quad F(s)=\mathcal{L}\{f(t)u(t)\}=\frac{2}{s^3}
$$

Substitute and report the result as $\mathcal{L}\{u(t-3)(t-3)^2\}=\dfrac{2e^{-3s}}{s^3}$.

## Applying the Property from a Known Base Transform

**Example:** Use the known pair $\mathcal{L}\{e^{-2t}u(t)\}=1/(s+2)$ to compute $\mathcal{L}\{e^{-2(t-1)}u(t-1)\}$.

**Explanation**

This is a cue-based reuse step: the base transform is already known, so we do not rederive $\mathcal{L}\{e^{-2t}u(t)\}$. We only need to identify the delay structure and apply the time-shifting factor.

Match the target to the one-sided delayed template $\mathcal{L}\{f(t-a)u(t-a)\}=e^{-as}F(s)$. The signal can be written as $f(t-1)u(t-1)$ with $f(t)=e^{-2t}$ and delay $a=1$.

$$
e^{-2(t-1)}u(t-1)=f(t-1)u(t-1),\quad f(t)=e^{-2t},\quad a=1.
$$

From the given cue, we have the base transform $F(s)=\mathcal{L}\{f(t)u(t)\}=\mathcal{L}\{e^{-2t}u(t)\}=\frac{1}{s+2}$.

Apply the delay multiplier once and only once: multiply by $e^{-as}$ with $a=1$ to account for the shift.

$$
\mathcal{L}\{e^{-2(t-1)}u(t-1)\}=e^{-s} \cdot F(s)=\frac{e^{-s}}{s+2}.
$$

Result: $\mathcal{L}\{e^{-2(t-1)}u(t-1)\}=\frac{e^{-s}}{s+2}$. This stays in one-sided causal form because the delay is cleanly separated from the same base transform.

<a id="computing-the-base-transform-before-adding-the-delay-factor"></a>
## Computing the Base Transform Before Adding the Delay Factor

**Example:** Find $L\{u(t-4)(t-4+2)\}$ by first finding the base transform of $t+2$.

**Explanation**

Treat this as the sequencing move: compute the non-delayed base transform first, then attach the shift factor at the end. The target signal is $x(t)=u(t-4)(t-4+2)$.

Match $x(t)$ to the delayed template $f(t-a)u(t-a)$. Rewrite the bracketed polynomial as a delayed base function: $x(t)=f(t-4)u(t-4)$ with $f(t)=t+2$ and $a=4$.

$$
x(t)=u(t-4)(t-4+2)=\bigl(t-4+2\bigr)u(t-4)=f(t-4)u(t-4),\quad f(t)=t+2,\quad a=4.
$$

Now find the base transform of the undelayed base signal: $F(s)=L\{f(t)u(t)\}=L\{t+2\}=\frac{1}{s^2}+\frac{2}{s}$.

Apply the one-sided shift only after the base is ready: the transform rule gives a multiplicative factor $e^{-as}$ with $a=4$.

$$
L\{u(t-4)f(t-4)\}=e^{-4s}F(s),\quad F(s)=\frac{1}{s^2}+\frac{2}{s},\quad\Rightarrow\quad L\{u(t-4)(t-4+2)\}=e^{-4s}\left(\frac{1}{s^2}+\frac{2}{s}\right).
$$

Final result: $L\{u(t-4)(t-4+2)\}=\frac{e^{-4s}}{s^2}+\frac{2e^{-4s}}{s}$. This keeps the delay $e^{-4s}$ as a separate final multiplier, which is the required sequencing pattern.

## Recognizing When the Delayed Form Is Ready for Direct Use

**Example:** Determine whether $x(t)=u(t-1)(t+1)^2$ is directly ready for the theorem, then compute $L\{x(t)\}$.

**Explanation**

Before applying the shift rule, run the readiness check: can the signal be written as $f(t-a)u(t-a)$? If not, perform one local-time rewrite and then apply the theorem.

Here $x(t)=u(t-1)(t+1)^2$. Use the local-time variable $\tau=t-1$. Then $x(t)=u(t-1)(\tau+2)^2$ and this is already in delayed form as $f(\tau)u(t-1)$ with $a=1$ and $f(\tau)=(\tau+2)^2$.

$$
x(t)=u(t-1)(t+1)^2=u(t-1)(t-1+2)^2=u(t-1)f(t-1),\quad f(t)= (t+2)^2.
$$

To keep one-sided notation stable, the base transform is $F(s)=L\{f(t)u(t)\}=L\{(t+2)^2\}=L\{t^2+4t+4\}=\frac{2}{s^3}+\frac{4}{s^2}+\frac{4}{s}$.

Now attach the delay factor from the one-sided time-shifting rule exactly once: multiply by $e^{-as}$ with $a=1$.

$$
L\{x(t)\}=L\{u(t-1)(t+1)^2\}=e^{-s}F(s)=e^{-s}\left(\frac{2}{s^3}+\frac{4}{s^2}+\frac{4}{s}\right).
$$

Final result: $L\{u(t-1)(t+1)^2\}=e^{-s}\left(\frac{2}{s^3}+\frac{4}{s^2}+\frac{4}{s}\right)=\frac{2e^{-s}}{s^3}+\frac{4e^{-s}}{s^2}+\frac{4e^{-s}}{s}$. The key decision is that the signal became valid after one local-time rewrite check.
