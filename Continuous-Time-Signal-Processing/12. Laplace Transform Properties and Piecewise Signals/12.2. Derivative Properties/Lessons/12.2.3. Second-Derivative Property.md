## Introduction to Second-Derivative Property

This is a one-sided Laplace tutorial. The transform is over the causal interval $[0^-,\infty)$, and every derivative rule must use the left-limit convention in the boundary terms.

$$
\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty} x(t)e^{-st}\,dt
$$

To build the second-derivative rule, begin with the known first-derivative identity for $x'(t)$: $\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)$, and apply the same one-sided rule again with $x'(t)$ as the input signal.

$$
\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)
$$

Substitute the first-derivative transform into the second-derivative rule and keep both boundary terms: $\mathcal{L}\{x''(t)\}=s\mathcal{L}\{x'(t)\}-x'(0^-)$.

$$
\mathcal{L}\{x''(t)\}=s\mathcal{L}\{x'(t)\}-x'(0^-)=s[sX(s)-x(0^-)]-x'(0^-)=s^2X(s)-sx(0^-)-x'(0^-)
$$

So the target move is $\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)$. In this tutorial, the base case is the zero-condition version: if $x(0^-)=0$ and $x'(0^-)=0$, then the rule collapses to $\mathcal{L}\{x''(t)\}=s^2X(s)$.

## Transforming a Second Derivative with Zero Initial Conditions

**Example:** Find $\mathcal{L}\{x''(t)\}$ when $x(0^-)=0$, $x'(0^-)=0$, and $\mathcal{L}\{x(t)\}=X(s)$.

**Explanation**

From the previous tutorial, the cue is the second-derivative one-sided rule with boundary terms: $\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)$.

$$
\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)
$$

Apply the given initial conditions by substituting $x(0^-)=0$ and $x'(0^-)=0$ into the same formula.

$$
\mathcal{L}\{x''(t)\}=s^2X(s)-s\cdot 0-0
$$

Now simplify to the benchmark form $\mathcal{L}\{x''(t)\}=s^2X(s)$, which is the clean zero-initial-condition baseline for later examples.

## Transforming a Second Derivative with a Nonzero Initial Value

**Example:** Compute $\mathcal{L}\{x''(t)\}$ if $x(0^-)=5$, $x'(0^-)=0$, and $\mathcal{L}\{x(t)\}=X(s)$.

**Explanation**

From the same second-derivative template, identify the cue as $\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)$ and use the given values directly.

$$
\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)
$$

Substitute $x(0^-)=5$ and $x'(0^-)=0$. This introduces only one nonzero correction term compared with the previous baseline example.

$$
\mathcal{L}\{x''(t)\}=s^2X(s)-s(5)-0
$$

So the answer is $\mathcal{L}\{x''(t)\}=s^2X(s)-5s$, where the position correction remains negative and multiplied by $s$.

## Transforming a Second Derivative with a Nonzero Initial Slope

**Example:** Compute $\mathcal{L}\{x''(t)\}$ when $x(0^-)=0$, $x'(0^-)=7$, and $\mathcal{L}\{x(t)\}=X(s)$.

**Explanation**

Use the same one-sided second-derivative template, now with a nonzero slope initial value: $\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)$.

$$
\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)
$$

Substitute $x(0^-)=0$ and $x'(0^-)=7$. This keeps the position correction zero and activates only the slope correction.

$$
\mathcal{L}\{x''(t)\}=s^2X(s)-s\cdot 0-7
$$

So the result is $\mathcal{L}\{x''(t)\}=s^2X(s)-7$, and the slope term is unmultiplied by $s$ with a negative sign.

## Using the Second-Derivative Property in an s-Domain Equation

**Example:** Transform $y''(t)+3y(t)=u(t)$ into $s$-domain form for $y(0^-)=0$, $y'(0^-)=2$, and $\mathcal{L}\{u(t)\}=U(s)$.

**Explanation**

The cue is a differential equation containing $y''(t)$, so apply the one-sided second-derivative template while keeping all other time-domain terms in the transform domain as the equation is assembled.

$$
\mathcal{L}\{y''(t)\}=s^2Y(s)-sy(0^-)-y'(0^-)\n\mathcal{L}\{3y(t)\}=3Y(s)
$$

Use these substitutions in $y''(t)+3y(t)=u(t)$ and include the given forcing transform $\mathcal{L}\{u(t)\}=U(s)$.

$$
s^2Y(s)-sy(0^-)-y'(0^-)+3Y(s)=U(s)
$$

Substitute $y(0^-)=0$ and $y'(0^-)=2$ next, then simplify the equation so $Y(s)$ terms are collected together.

$$
(s^2+3)Y(s)-2=U(s)
$$

So the transformed equation is $(s^2+3)Y(s)-2=U(s)$, which can optionally be rearranged to $Y(s)=\frac{U(s)+2}{s^2+3}$ if the next step is solving in the $s$-domain.
