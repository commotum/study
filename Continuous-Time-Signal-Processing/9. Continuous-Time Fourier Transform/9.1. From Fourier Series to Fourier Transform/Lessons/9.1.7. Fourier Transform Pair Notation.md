## Introduction to Fourier Transform Pair Notation

The notation $x(t) \leftrightarrow X(j\omega)$ names a Fourier transform pair. It is not asking you to calculate yet; it is saying that one time-domain signal and one frequency-domain spectrum are matched.

$$
x(t) \leftrightarrow X(j\omega)
$$

The left side, $x(t)$, is the time-domain signal. The variable $t$ tells you that this description is organized by time.

The right side, $X(j\omega)$, is the frequency-domain spectrum. The argument $j\omega$ tells you that this description is organized by continuous angular frequency.

Reading the pair from left to right gives the forward Fourier transform: start with $x(t)$ and obtain $X(j\omega)$.

$$
x(t) \xrightarrow{\mathcal{F}} X(j\omega)
$$

Reading the pair from right to left gives the inverse Fourier transform: start with $X(j\omega)$ and reconstruct $x(t)$.

$$
X(j\omega) \xrightarrow{\mathcal{F}^{-1}} x(t)
$$

For later problems, identify the domain first. If the expression uses $t$, you are looking at the time signal; if it uses $j\omega$, you are looking at the spectrum. Then read the arrow direction to decide whether the forward or inverse transform is being used.

## Matching $x(t)$ with $X(j \omega)$

**Example:** A reference sheet shows the pair $x(t) \leftrightarrow X(j\omega)$. Identify which symbol is the time-domain signal, which symbol is the spectrum, and state what transform relationship the pair names.

**Explanation**

The cue is the printed pair $x(t) \leftrightarrow X(j\omega)$. This is a recognition task, not a calculation task: match each symbol to its domain and then read the arrow direction.

$$
x(t) \leftrightarrow X(j\omega)
$$

The left symbol, $x(t)$, is the time-domain signal because the argument $t$ organizes the description by time. The right symbol, $X(j\omega)$, is the frequency-domain spectrum because the argument $j\omega$ organizes the description by continuous angular frequency.

Reading the pair left to right names the forward Fourier transform: start with $x(t)$ and obtain $X(j\omega)$. Reading the pair right to left names the inverse Fourier transform: start with $X(j\omega)$ and reconstruct $x(t)$.

$$
x(t) \xrightarrow{\mathcal{F}} X(j\omega)
$$

$$
X(j\omega) \xrightarrow{\mathcal{F}^{-1}} x(t)
$$

So when you see a Fourier pair, identify the domain first, then read the arrow direction. $x(t)$ is the time signal, $X(j\omega)$ is the spectrum, and the notation tells you which transform direction connects them.

## Reading the Forward Transform Direction

**Example:** The pair notation $x(t) \leftrightarrow X(j\omega)$ is shown. If you start from $x(t)$, which symbol is produced by the forward transform, and what domain is it in?

**Explanation**

The cue is the starting symbol $x(t)$. That tells you to read the notation in the signal-to-spectrum direction, not the reverse direction.

In the forward transform, $x(t)$ is the input signal and $X(j\omega)$ is the output.

$$
x(t) \xrightarrow{\mathcal{F}} X(j\omega)
$$

The symbol produced by the forward transform is $X(j\omega)$. Because the argument is $j\omega$, that output lives in the frequency domain and represents the spectrum.

So if a prompt asks for the forward-transform result from $x(t)$, name $X(j\omega)$ and identify it as the frequency-domain spectrum.

## Reading the Inverse Transform Direction

**Example:** The pair notation $x(t) \leftrightarrow X(j\omega)$ is shown. If you start from $X(j\omega)$, which function do you recover with the inverse transform, and what domain does it live in?

**Explanation**

The cue is the starting symbol $X(j\omega)$. That tells you to read the notation in the spectrum-to-signal direction, not the forward direction.

In the inverse transform, $X(j\omega)$ is the input spectrum and $x(t)$ is the output.

$$
X(j\omega) \xrightarrow{\mathcal{F}^{-1}} x(t)
$$

The function recovered by the inverse transform is $x(t)$. Because the argument is $t$, that output lives in the time domain and represents the original signal.

So if a prompt asks for the inverse-transform result from $X(j\omega)$, name $x(t)$ and identify it as the time-domain signal.

## Interpreting a Fourier Transform Pair Table Entry

**Example:** A transform table entry lists $x(t)$ and $X(j\omega)$ as a paired row. Explain what the row says about the signal, the spectrum, and the transform relationship.

**Explanation**

The cue is the paired row $x(t)$ and $X(j\omega)$. Read it as a Fourier pair entry, not as two unrelated symbols.

$$
x(t) \leftrightarrow X(j\omega)
$$

The left symbol, $x(t)$, is the time-domain signal. The right symbol, $X(j\omega)$, is the frequency-domain spectrum.

So the table row summarizes the same transform relationship from the earlier examples: the forward transform sends $x(t)$ to $X(j\omega)$, and the inverse transform sends $X(j\omega)$ back to $x(t)$.

When you see this compact table entry, identify the signal, identify the spectrum, and read the row as one paired time-and-frequency description.
