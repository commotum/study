## Introduction to Aperiodic Signals as Infinite-Period Limits

The bridge idea in this section is simple: start from an aperiodic signal, make a periodic extension by repeating one unchanged copy every $T$ units, and then let $T$ grow. That gives you a periodic signal you can think about first, while still keeping the original aperiodic waveform in view.

To build the extension, copy the same waveform again and again without changing its shape or values. The repeated signal is periodic because shifting it by one period gives the same signal back.

$$
x_T(t+T)=x_T(t)
$$

As $T$ gets larger, the repeated copies move farther apart. On any fixed finite time window, that means the local part of the periodic extension stays the same while the extra copies are pushed away from the window.

So the aperiodic signal is recovered locally from the periodic extension in the limit. This is the time-domain picture that makes the Fourier-transform viewpoint natural for aperiodic signals.

$$
\lim_{T\to\infty} x_T(t)=x(t)\quad \text{on any fixed finite time window}
$$

Use this limit idea as the starting point for the next sections: first think of the signal as a periodic extension with large $T$, and then let that period move toward infinity to reach the aperiodic case.

<a id="building-a-periodic-extension-from-one-signal-copy"></a>
## Building a Periodic Extension from One Signal Copy

**Example:** Take a signal copy $x(t)$ that is nonzero on $0 \le t < 1$ and build a periodic extension with period $T=4$.

**Explanation**

The cue is to keep one signal copy unchanged and repeat it every $4$ units. The goal is not to reshape the waveform, but to place the same copy into each length-$4$ cycle.

$$
x_T(t)=x(t-4k), \quad 4k \le t < 4(k+1), \ k\in \mathbb{Z}
$$

This rule copies the original waveform into every period without changing its shape or values. Since the original copy is nonzero on $0 \le t < 1$, the same nonzero part appears in the same place inside each length-$4$ interval.

$$
x_T(t+4)=x_T(t)
$$

So the constructed signal is a periodic repetition of one unchanged copy, with period $4$. That is the concrete periodic extension the next steps will keep using.

## Increasing the Period While Preserving the Signal Copy

**Example:** Compare two periodic extensions of the same signal copy, one with period $T=4$ and one with period $T=12$, and explain what changes and what stays fixed.

**Explanation**

The cue is that both constructions use the same copy of $x(t)$. The only thing changing is the period, so the waveform itself must stay fixed while the spacing changes from $T_1=4$ to $T_2=12$.

$$
x_{T_1}(t+T_1)=x_{T_1}(t), \qquad x_{T_2}(t+T_2)=x_{T_2}(t)
$$

With $T_1=4$, the repeated copies are $4$ units apart. With $T_2=12$, the same copy is $12$ units apart from its neighbors, so the gaps are wider for the larger period.

Nothing about the waveform copy is stretched, compressed, or reshaped. Increasing the period changes only the spacing between repeated copies, not the signal copy itself.

<a id="taking-the-infinite-period-limit-of-the-extension"></a>
## Taking the Infinite-Period Limit of the Extension

**Example:** Let the period in the previous construction grow without bound. Describe what the periodic extension looks like on any fixed finite time window.

**Explanation**

The cue is the same periodic extension from the previous step: one unchanged copy of $x(t)$ repeated every $T$ units. Now let $T$ grow, but keep the copy itself fixed.

$$
x_T(t+T)=x_T(t)
$$

As $T$ gets larger, the repeated copies move farther apart. On a fixed finite window, that means the extra repeats eventually move out of view.

$$
\lim_{T\to\infty} x_T(t)=x(t)\quad \text{on any fixed finite time window}
$$

So the local behavior on that window matches the original aperiodic signal. Increasing $T$ changes only the spacing between copies; it does not change the copy itself.

<a id="connecting-the-infinite-period-limit-to-the-fourier-transform-viewpoint"></a>
## Connecting the Infinite-Period Limit to the Fourier Transform Viewpoint

**Example:** Use the infinite-period limit to explain why the Fourier-series harmonics of the periodic extension lead naturally to the Fourier-transform viewpoint for the original signal.

**Explanation**

The cue is the same periodic extension $x_T(t)$ from the previous step. For each finite $T$, it is still periodic, so its frequency description is a set of discrete Fourier-series harmonics rather than a continuous band.

$$
x_T(t)=\sum_{k=-\infty}^{\infty} c_k e^{j k \omega_0 t}
$$

As $T$ increases, the harmonic spacing shrinks, so those integer-indexed harmonics crowd closer together in frequency. The signal copy in time has not changed; only the frequency grid has become finer.

$$
\omega_0 \to 0 \quad \text{as} \quad T\to\infty
$$

So the infinite-period limit is read as a transition from a discrete harmonic picture to a continuous-frequency picture. That is why the original aperiodic signal is naturally analyzed with the Fourier transform viewpoint.
