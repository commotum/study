## Introduction to The System-Then-Shift Path

The system-then-shift path means you first apply the system rule to the original input $x(t)$ to get a finished output $y(t)$, and then you shift that completed output by replacing every $t$ with $t-T$.

$$
y(t)=A\,x(t-a)+B
$$

That shift acts on the completed expression, not on the input first. So the $t$ inside $x(t-a)$ shifts with the rest of the output, while the constant term $B$ stays the same.

$$
y(t-T)=A\,x(t-T-a)+B
$$

So if you already have $y(t)$, the system-then-shift path is just $y(t-T)$. This is the output that will later be compared with the result of shifting the input first in a time-invariance test.

<a id="applying-the-system-rule-before-any-input-shift"></a>
## Applying the System Rule Before Any Input Shift

**Example:** For the system $y(t)=2x(t)+x(t-1)$ and input $x(t)=t^2$, find $y(t)$ and then compute $y(t-T)$.

**Explanation**

The cue is that the system rule is already given, so the first job is to apply it to the original input $x(t)=t^2$ and form the finished output $y(t)$ before any shift is introduced.

$$
y(t)=2x(t)+x(t-1)=2t^2+(t-1)^2=3t^2-2t+1
$$

Now the system-then-shift path shifts the completed output, not the input rule. That means every explicit $t$ in $y(t)$ is replaced by $t-T$, while the constant term stays unchanged.

$$
y(t-T)=3(t-T)^2-2(t-T)+1
$$

This example shows the order clearly: first build $y(t)$ from $x(t)$, then shift that finished expression to get $y(t-T)$. That is the system-then-shift path used later in the time-invariance comparison.

## Forming $y(t - T)$ from a Direct Output Expression

**Example:** If $y(t)=5t^2-2t+1$, write $y(t-T)$.

**Explanation**

The cue is that the output is already finished, so the only job is to replace every explicit $t$ in $y(t)$ with $t-T$ and leave constants unchanged.

$$
y(t-T)=5(t-T)^2-2(t-T)+1
$$

Now simplify the substituted expression by expanding the square and collecting like terms. The constant $1$ stays fixed because it is not attached to $t$.

$$
y(t-T)=5t^2-10Tt+5T^2-2t+2T+1
$$

This is the system-then-shift form for a direct output expression: start with $y(t)$, replace $t$ by $t-T$ everywhere it appears, and then simplify the result.

## Forming $y(t - T)$ When $y(t)$ Contains $x(t - a)$

**Example:** If $y(t)=x(t-2)+3x(t)$, write $y(t-T)$.

**Explanation**

The cue is that the output already contains delayed input terms, so the only task is to shift the finished output expression by replacing $t$ with $t-T$ everywhere it appears.

$$
y(t-T)=x((t-T)-2)+3x(t-T)
$$

The embedded delay stays attached to the shifted time, so $x(t-2)$ becomes $x(t-T-2)$ and the undelayed term $x(t)$ becomes $x(t-T)$.

$$
y(t-T)=x(t-T-2)+3x(t-T)
$$

This shows the same system-then-shift rule in a delayed-output setting: shift the completed output, keep each delay attached to its argument, and write the result in simplified form.

## Forming $y(t - T)$ When $y(t)$ Combines Multiple Terms

**Example:** If $y(t)=2x(t-1)-x(t)+t+4$, write $y(t-T)$.

**Explanation**

The cue is that the output mixes delayed input terms, an undelayed input term, an explicit $t$ term, and a constant, so the shift must be applied to every $t$-dependent part exactly once.

$$
y(t-T)=2x((t-T)-1)-x(t-T)+(t-T)+4
$$

The delayed input term becomes $x(t-T-1)$, the undelayed input term becomes $x(t-T)$, the explicit time term becomes $t-T$, and the constant $4$ stays unchanged.

$$
y(t-T)=2x(t-T-1)-x(t-T)+t-T+4
$$

This is the same system-then-shift rule in a mixed-expression setting: shift the finished output once, carry every $t$-bearing term with the shift, and leave constants alone.
