## Introduction to Testing Time Invariance

To test time invariance, compare two paths for the same input shift $T$: shift the input first and then apply the system, or apply the system first and then shift the output by the same $T$. The object to recognize is the pair of expressions that should match if the system preserves shifts without changing its rule.

$$
y_1(t)=T\{x(t-T)\}
$$

The first path is the shift-then-system path: start with the shifted input $x(t-T)$, feed it into the system, and name the result $y_1(t)$. For the simplest base case, this is the path that shows what the system does after the delay has already been built into the input.

$$
y_2(t)=y(t-T)
$$

The second path is the system-then-shift path: first compute the output $y(t)=T\{x(t)\}$, then replace $t$ with $t-T$ to form the shifted output $y_2(t)$. Written directly, this is the same as taking the output rule and evaluating it at the delayed time.

$$
y_2(t)=T\{x(t)\}\big|_{t\to t-T}
$$

The decision rule is simple: if the simplified expressions for $y_1(t)$ and $y_2(t)$ are exactly the same for every valid $T$, the system is time invariant. In the base identity case $y(t)=x(t)$, both paths reduce to $x(t-T)$, so the matching rule is easy to see before any harder examples appear.

$$
y_1(t)=y_2(t)\;\forall T\;\Rightarrow\;\text{time invariant}
$$

This section sets up the comparison strategy only; later sections will reuse the same notation to test specific system rules and decide whether the paths match or fail to match after simplification.

## Matching Shift-Then-System and System-Then-Shift Expressions

**Example:** For $y(t)=2x(t)$, compute the shift-then-system and system-then-shift expressions and decide if they are equal.

**Explanation**

The cue here is a constant-gain system: multiplying by $2$ should not change the shape of the signal when the input is delayed. To test that, start by shifting the input by $T$ and then pass that shifted input through the system.

$$
y_1(t)=2x(t-T)
$$

That first path is the shift-then-system path. The input becomes $x(t-T)$ first, and the system rule $y(t)=2x(t)$ turns it into $y_1(t)=2x(t-T)$ with the delay preserved inside the argument.

$$
y(t)=2x(t)
$$

Now take the system-then-shift path. Apply the system to the original input first, which gives $y(t)=2x(t)$, and then shift that output by the same $T$.

$$
y_2(t)=2x(t-T)
$$

The delayed output has the same simplified form as the shift-then-system path, so the two expressions match exactly: $y_1(t)=y_2(t)=2x(t-T)$. Since the two paths are identical for arbitrary $T$, this system is time invariant.

## Nonmatching Shift-Then-System and System-Then-Shift Expressions

**Example:** For $y(t)=x(t)+t$, compute the shift-then-system and system-then-shift expressions for an arbitrary shift $T$ and identify the term that prevents them from matching.

**Explanation**

The cue is the explicit $t$ term in the output rule. Start with the shifted input $x(t-T)$, then apply the system rule at time $t$.

$$
y_1(t)=T\{x(t-T)\}=x(t-T)+t
$$

Now apply the system first, then shift the entire output by $T$. The input part shifts the same way, but the added time term must also be evaluated at the shifted time.

$$
y_2(t)=\bigl(T\{x(t)\}\bigr)\big|_{t\to t-T}=x(t-T)+(t-T)
$$

Compare the two expressions term by term. The input-dependent parts match, but the explicit-time terms differ: $t$ in $y_1(t)$ and $t-T$ in $y_2(t)$.

$$
y_1(t)-y_2(t)=T
$$

Because the two paths do not match for arbitrary $T$, the system is time varying.

## Testing Equality for an Arbitrary Input Shift

**Example:** For $y(t)=t\,x(t-2)$, simplify both paths $y_1(t)=T\{x(t-T)\}$ and $y_2(t)=T\{x(t)\}|_{t\to t-T}$ to test equality.

**Explanation**

The cue is the time prefactor $t$ multiplying the shifted input $x(t-2)$. Start by shifting the input first, then apply the system rule at time $t$.

$$
y_1(t)=t\,x((t-T)-2)=t\,x(t-T-2)
$$

Now apply the system first, then shift the whole output by $T$. The shifted output inherits the same input argument change, but the prefactor also shifts from $t$ to $t-T$.

$$
y_2(t)=\bigl(t\,x(t-2)\bigr)\big|_{t\to t-T}=(t-T)x(t-T-2)
$$

Compare the two expressions term by term. The shifted input argument matches, but the coefficients do not: $t$ in $y_1(t)$ versus $t-T$ in $y_2(t)$.

$$
y_1(t)-y_2(t)=T\,x(t-T-2)
$$

Because the two paths disagree for arbitrary $T$, this system is time varying.

## Classifying Time Invariance from Simplified Path Expressions

**Example:** Use the following path expressions and classify the system: $y_1(t)=x(t-T+1)$, $y_2(t)=x(t-T+1)$.

**Explanation**

The cue is that both paths are already simplified. At this point, the job is to compare the final symbolic forms for exact equality for arbitrary $T$.

$$
y_1(t)=x(t-T+1),\qquad y_2(t)=x(t-T+1)
$$

Read the two expressions term by term. The shifted argument is identical, and there are no extra coefficients or time offsets that change one path relative to the other.

$$
y_1(t)=y_2(t)
$$

Because the simplified path expressions match exactly for arbitrary $T$, the system is time invariant.

$$
y_1(t)=y_2(t)\ \text{for all }T\ \Longrightarrow\ \text{time invariant}
$$

This is the decision rule for the lesson: if the two simplified paths are identical for every input shift, classify the system as time invariant.
