## Introduction to Time-Invariant Memoryless Systems

A continuous-time system is time invariant when shifting the input by $T$ shifts the output by the same $T$ without changing the rule itself. For a memoryless system, the output at each time depends only on the input at that same time, so the pointwise mapping can be written as $y(t)=f(x(t))$.

$$
x_T(t)=x(t-T)
$$

Start from the shifted input $x_T(t)=x(t-T)$ and apply the same pointwise rule to it. The shifted-input output is $y_T(t)=f(x(t-T))$, so the test is whether this matches the original output shifted by $T$.

$$
y_T(t)=f(x(t-T))=y(t-T)
$$

The comparison path is system then shift: first form $y(t)=f(x(t))$, then replace $t$ with $t-T$ to get $y(t-T)=f(x(t-T))$. When the two paths agree, the memoryless rule is time invariant, and the simplest base case to remember is a constant-gain rule such as $y(t)=a x(t)$, which clearly gives the same shifted output on both paths.

## Testing a Constant-Gain Memoryless Rule

**Example:** Decide whether $y(t)=3x(t)$ is time invariant by comparing the output from $x_T(t)=x(t-T)$ with $y(t-T)$ from the original output.

**Explanation**

Use the shift test on the constant-gain memoryless rule $y(t)=3x(t)$. The shifted input is $x_T(t)=x(t-T)$, so the goal is to compare the shifted-input path with the same rule applied before the shift.

$$
x_T(t)=x(t-T)
$$

Apply the rule directly to the shifted input. Because the gain is fixed at $3$, the shifted-input path gives $y_T(t)=3x(t-T)$.

$$
y_T(t)=3x(t-T)
$$

Now apply the rule first and shift the output afterward. From $y(t)=3x(t)$, replacing $t$ with $t-T$ gives $y(t-T)=3x(t-T)$, which matches the shifted-input path exactly.

$$
y(t-T)=3x(t-T)
$$

Since both paths produce the same expression, the rule is time invariant. This constant-gain case is the clean base case to reuse before testing nonlinear or explicitly time-dependent memoryless rules.

## Testing a Squaring Memoryless Rule

**Example:** Decide whether $y(t)=x^2(t)$ is time invariant by comparing the output from $x_T(t)=x(t-T)$ with $y(t-T)$ from the original output.

**Explanation**

The cue is the pointwise square rule $y(t)=x^2(t)$, so test it with the same input shift $x_T(t)=x(t-T)$ and compare the shifted-input path to the shifted original output.

$$
x_T(t)=x(t-T)
$$

Apply the square rule directly to the shifted input. Because the rule is fixed and pointwise, the shifted-input path gives $y_T(t)=(x(t-T))^2$.

$$
y_T(t)=(x(t-T))^2
$$

Now apply the rule first and shift the output afterward. From $y(t)=x^2(t)$, replacing $t$ with $t-T$ gives $y(t-T)=(x(t-T))^2$.

$$
y(t-T)=(x(t-T))^2
$$

Both paths match exactly, so the square rule is time invariant. The key distinction is that the rule is nonlinear, but it still commutes with the shift because it has no explicit $t$ dependence.

## Testing a Constant-Offset Memoryless Rule

**Example:** Decide whether $y(t)=x(t)+5$ is time invariant by comparing the output from $x_T(t)=x(t-T)$ with $y(t-T)$ from the original output.

**Explanation**

Use the shift test on the additive memoryless rule $y(t)=x(t)+5$. The cue is the fixed output offset $+5$, so the comparison is between the shifted-input path and the output obtained by shifting the original result.

$$
x_T(t)=x(t-T)
$$

Apply the rule directly to the shifted input. Because the offset is constant, the shifted-input path gives $y_T(t)=x(t-T)+5$.

$$
y_T(t)=x(t-T)+5
$$

Now apply the rule first and shift the output afterward. From $y(t)=x(t)+5$, replacing $t$ with $t-T$ gives $y(t-T)=x(t-T)+5$.

$$
y(t-T)=x(t-T)+5
$$

Both paths produce the same expression, so the constant-offset rule is time invariant. The important point is that the $5$ is fixed and does not introduce any explicit $t$ dependence when the input is shifted.

## Spotting Explicit Time Dependence in a Memoryless Rule

**Example:** Decide whether $y(t)=t x(t)$ is time invariant by comparing the output from $x_T(t)=x(t-T)$ with $y(t-T)$ from the original output.

**Explanation**

The cue is the explicit time factor $t$ in the memoryless rule $y(t)=t x(t)$. Use the shift test by comparing the shifted-input path with the output obtained after shifting the original result.

$$
x_T(t)=x(t-T)
$$

Apply the rule to the shifted input first. The shifted-input path is $y_T(t)=t x(t-T)$, because the factor $t$ stays attached to the current time variable.

$$
y_T(t)=t x(t-T)
$$

Now apply the rule first and shift the output afterward. From $y(t)=t x(t)$, replacing $t$ with $t-T$ gives $y(t-T)=(t-T)x(t-T)$.

$$
y(t-T)=(t-T)x(t-T)
$$

The two paths do not match, so the rule is not time invariant. The important distinction is that the system is still memoryless, but the explicit $t$ dependence changes under a shift and breaks the commutation test.
