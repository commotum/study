## Introduction to Meaning of Time Invariance

A continuous-time system is time invariant when shifting the input by $T$ before the system produces the same shift by $T$ at the output after the system. In other words, the system commutes with input shifts: the shape and rule of the output stay the same, and only the time origin moves.

$$
x_1(t)=x(t-T), \; y_{tts}(t)=S\{x_1(t)\}=S\{x(t-T)\}
$$

To test the other path, start with the system output $y(t)=S\{x(t)\}$ and then shift that output by the same amount. The result is the system-then-shift path, abbreviated $y_{sts}(t)$.

$$
y_{sts}(t)=y(t-T), \; \text{compare } y_{tts}(t) \stackrel{?}{=} y_{sts}(t) \text{ for all } t,T
$$

The test is simple: a system is time invariant if the two paths are identical for every input $x(t)$ and every shift $T$. If the shift direction, the shift size, or the output rule changes, the system is not time invariant.

The cleanest base case is the memoryless system $y(t)=x(t)$. For a delay of $T$, both paths give $x(t-T)$, so this is the simplest template for the later matching-delay, matching-advance, and mismatch examples.

## Recognizing a Matching Output Delay

**Example:** Test time invariance for $y(t)=2x(t-1)$ under input delay $x_1(t)=x(t-T)$.

**Explanation**

The cue here is an input delay $x_1(t)=x(t-T)$. To test time invariance, keep the system rule fixed as $y(t)=2x(t-1)$ and compare the time-shift-then-system path with the system-then-time-shift path.

$$
y_{tts}(t)=2x((t)-1-T)=2x(t-T-1)
$$

Now compute the system-then-shift path from the unshifted output. The internal delay of $1$ stays inside the rule, and the output is shifted by the same amount $T$.

$$
y_{sts}(t)=2x((t-T)-1)=2x(t-T-1)
$$

The two expressions are identical term by term: both paths give $2x(t-T-1)$. That means the input delay propagates through the system unchanged.

So this system is time invariant for this delay test. The fixed offset inside $x(t-1)$ does not break shift commutation because both paths still produce the same delayed output.

## Recognizing a Matching Output Advance

**Example:** Test time invariance for $y(t)=\frac{1}{2}x(t)$ using an advance input $x_1(t)=x(t+T)$.

**Explanation**

The cue here is an advance input $x_1(t)=x(t+T)$. Keep the system rule fixed as $y(t)=\frac{1}{2}x(t)$ and compare the time-shift-then-system path with the system-then-time-shift path.

$$
y_{tts}(t)=\frac{1}{2}x(t+T)
$$

Now compute the system-then-shift path from the unshifted output. The output is first $y(t)=\frac{1}{2}x(t)$, and then it is advanced by the same amount $T$.

$$
y_{sts}(t)=\frac{1}{2}x(t+T)
$$

$$
y_{tts}(t)=y_{sts}(t)=\frac{1}{2}x(t+T)
$$

The two paths match exactly, so this is a matched output advance. That means the system is time invariant here as well, and the sign change from delay to advance does not change the compare-step method.

## Recognizing When a Shift Changes the Output Pattern

**Example:** Check whether $y(t)=t\,x(t)$ is time invariant under input shift $x_1(t)=x(t-T)$.

**Explanation**

The cue here is an input shift $x_1(t)=x(t-T)$. Keep the system rule fixed as $y(t)=t\,x(t)$ and compare the time-shift-then-system path with the system-then-time-shift path.

$$
y_{tts}(t)=t\,x(t-T)
$$

Now compute the system-then-shift path from the unshifted output. First the system gives $y(t)=t\,x(t)$, and then the output is delayed by the same amount $T$.

$$
y_{sts}(t)=(t-T)x(t-T)
$$

$$
y_{tts}(t)=t\,x(t-T), \; y_{sts}(t)=(t-T)x(t-T)
$$

The two paths do not match because the factor of $t$ becomes $t-T$ after the output shift. That means the output pattern changes with the shift, so this system is not time invariant.
