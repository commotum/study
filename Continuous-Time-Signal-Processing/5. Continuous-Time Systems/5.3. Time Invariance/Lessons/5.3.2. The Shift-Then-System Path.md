## Introduction to The Shift-Then-System Path

The shift-then-system path is the first leg of a time-invariance test. Start by shifting the input signal first, then apply the same system rule that would act on the original input. For this section, the shifted input is written as $x_1(t)=x(t-T)$.

$$
x_1(t)=x(t-T)
$$

If the system is written as $\mathcal{S}\{x(t)\}=y(t)$, then the shift-then-system path applies that same rule to the shifted input. Nothing about the system rule changes; only the input argument changes first.

$$
y_{ST}(t)=\mathcal{S}\{x_1(t)\}=\mathcal{S}\{x(t-T)\}
$$

In the simplest base case, if the system rule is just $y(t)=x(t)$, then the shift-then-system path gives $y_{ST}(t)=x(t-T)$. This is the output you will compare against the system-then-shift path in the next step.

<a id="writing-the-shifted-input-as-the-system-input"></a>
## Writing the Shifted Input as the System Input

**Example:** For $y(t)=2x(t)$, find the shift-then-system output when $x(t)$ is first shifted by $T$.

**Explanation**

The cue is that the system rule is already known: $y(t)=2x(t)$. For the shift-then-system path, first rename the shifted input as $x_1(t)=x(t-T)$ so the system sees the shifted signal as its input.

$$
x_1(t)=x(t-T)
$$

Now apply the same system rule to $x_1(t)$ instead of to $x(t)$. Nothing about the rule changes; only the input has been shifted before the gain is applied.

$$
y_{STS}(t)=2x_1(t)=2x(t-T)
$$

So the shift-then-system output is $2x(t-T)$. This is the direct substitution result that will be compared against the system-then-shift path in the next step.

## Applying a Memoryless System Rule After the Input Shift

**Example:** For $y(t)=x(t-3)$, find the shift-then-system output when $x(t)$ is first shifted by $T$.

**Explanation**

The cue is the internal delay in the system rule: $y(t)=x(t-3)$. Start by writing the shifted input as $x_1(t)=x(t-T)$ so the system receives the shifted signal as its input.

$$
x_1(t)=x(t-T)
$$

Now apply the same rule to the shifted input. Because the system delays whatever input it sees by $3$, substitute $x_1$ into the rule to get the shift-then-system output.

$$
y_{STS}(t)=x_1(t-3)=x((t-T)-3)
$$

So the shift-then-system output is $x((t-T)-3)$. The only new move is the substitution of the shifted input into the system's internal delay.

## Applying a System Rule with Internal Input Shifts After the Input Shift

**Example:** For $y(t)=x(t-3)$, find the shift-then-system output when $x(t)$ is first shifted by $T$.

**Explanation**

The cue is the internal delay in the system rule: $y(t)=x(t-3)$. Start by writing the shifted input as $x_1(t)=x(t-T)$ so the system receives the shifted signal as its input.

$$
x_1(t)=x(t-T)
$$

Now apply the same rule to the shifted input. Because the system delays whatever input it sees by $3$, substitute the shifted input into the rule and keep the parentheses in order.

$$

$$

So the shift-then-system output is $x((t-T)-3)$. The only new move is the substitution of the shifted input into the system's internal delay.

## Applying a Multi-Term System Rule After the Input Shift

**Example:** For $y(t)=3x(t-1)+2x(t+1)-5x(t)$, compute $y_{STS}(t)$ after $x(t)$ is first shifted by $T$.

**Explanation**

The cue is a multi-term linear rule: each term uses $x(t)$ with a different internal time shift, but the coefficients stay fixed. Start by writing the shifted input as $x_1(t)=x(t-T)$ so the system sees the shifted signal as its input.

$$
x_1(t)=x(t-T)
$$

Now substitute $x_1$ into every occurrence of $x(\cdot)$ in the system rule. Keep the constants $3$, $2$, and $-5$ unchanged while shifting only the time arguments inside each term.

$$
y_{STS}(t)=3x_1(t-1)+2x_1(t+1)-5x_1(t)=3x((t-T)-1)+2x((t-T)+1)-5x(t-T)
$$

So the shift-then-system output is $3x((t-T)-1)+2x((t-T)+1)-5x(t-T)$. The pattern is the same in every term: shift the input first, then replace each $x(\cdot)$ with the shifted input without changing the coefficients.
