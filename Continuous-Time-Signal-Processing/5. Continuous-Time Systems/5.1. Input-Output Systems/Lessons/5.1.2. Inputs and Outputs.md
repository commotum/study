## Introduction to Inputs and Outputs

A continuous-time system is a rule that takes one signal in and produces another signal out. In this lesson, call the signal that goes in the input, call the signal that comes out the output, and read the direction from input to output before you try to name any physical meaning.

$$
y(t)=T\{x(t)\}
$$

Read $y(t)=T\{x(t)\}$ as: the signal $x(t)$ is fed into the system rule $T$, and the result is $y(t)$. If $x(t)$ appears inside the system operator and $y(t)$ appears on the outside, then the mapping runs from input to output.

$$
y(t)=2x(t)
$$

The base case $y(t)=x(t)$ follows the same frame: $x(t)$ is still the input signal, $y(t)$ is still the output signal, and the transformation direction is still input to output even when the two signals match exactly. Keep the mapping clear first; only after that should you attach a physical meaning such as voltage, position, or temperature.

## Identifying Inputs and Outputs from System Descriptions

**Example:** Given $y(t)=4x(t)-5$, label which quantity is the input signal, which quantity is the output signal, and state the transformation direction.

**Explanation**

A written system description usually shows one signal on the left and one signal inside the rule on the right. Use that placement as your cue: the left-side signal is the output candidate, and the signal inside the rule is the input candidate.

$$
y(t)=4x(t)-5
$$

For $y(t)=4x(t)-5$, the signal being transformed is $x(t)$, and the result is $y(t)$. The constant $-5$ changes the output value, but it does not change which signal is being fed into the system, so the direction is still input to output.

$$
y(t)=F(x(t))
$$

That gives the repeatable method: read the equation, label the left side as output, label the signal inside the rule as input, and state the direction as input to output. The same reading works for other one-way system descriptions with gains or offsets, as long as the mapping is still one-sided.

<a id="determining-the-direction-of-a-signal-transformation"></a>
## Determining the Direction of a Signal Transformation

**Example:** For the rule $v(t)=\frac{d}{dt}u(t)$, identify the input, the output, and the direction, and confirm why differentiation indicates a one-way input→output transform.

**Explanation**

The cue here is the operator form. The signal on the left is the output candidate, and the signal inside the operator is the input candidate, so the direction runs from the inner signal to the left-side signal.

$$
v(t)=\frac{d}{dt}u(t)
$$

For $v(t)=\frac{d}{dt}u(t)$, the signal being transformed is $u(t)$, and the result is $v(t)$. Differentiation changes the signal, but it does not reverse the mapping: $u(t)$ still feeds the rule and $v(t)$ still comes out.

$$
v(t)=F(u(t))
$$

So the repeatable reading is: label the left side as output, label the signal inside the operator as input, and state the direction as input to output. The operator type can change from derivative to integral or another rule, but the direction still comes from the one-sided dependence.

## Assigning Physical Quantities as Input and Output Signals

**Example:** A sensor outputs voltage $v_s(t)$ based on position $x(t)$ through a transfer block. Choose the input and output and phrase the input-output mapping sentence.

**Explanation**

Use the physical cue first: decide which quantity is being applied to the block and which quantity is being produced by it. The externally supplied or controlled quantity is the input candidate, and the measured or resulting quantity is the output candidate.

$$
v_s(t)=F(x(t))
$$

Here, $x(t)$ is the signal entering the sensor model, so it is the input. The sensor produces $v_s(t)$ in response, so $v_s(t)$ is the output, and the direction is still input to output.

$$
x(t)\rightarrow v_s(t)
$$

So the reusable mapping sentence is: $x(t)$ is input, $v_s(t)$ is output, and the model runs from $x(t)$ to $v_s(t)$. The physical label changes, but the reading rule does not: identify the injected quantity first, then name the produced quantity second.

## Checking an Input-Output Assignment Against a System Description

**Example:** Given a proposed statement 'y is input and x is output' for $y(t)=\int_0^t x(\tau)d\tau$, check and correct the assignment.

**Explanation**

Treat the proposed labels as a claim to test against the rule structure. The signal inside the operator is the one feeding the system, and the left-side signal is the one coming out, so the check is whether the proposed labels match that direction.

$$
y(t)=\int_0^t x(\tau)d\tau
$$

Here, $x(t)$ is inside the rule, so it is the input. $y(t)$ is on the left, so it is the output. The proposed swap '$y$ is input and $x$ is output' conflicts with the equation, so it must be rejected.

$$
x(t)\rightarrow y(t)
$$

The corrected assignment is: $x(t)$ is input, $y(t)$ is output, and the mapping runs from $x(t)$ to $y(t)$. The verification rule is simple: match the symbols to the equation, then keep only the labeling that preserves the operator’s direction.
