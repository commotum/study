## Introduction to Continuous-Time System Notation

A continuous-time system is a rule that transforms one signal into another signal at each time $t$. Read these expressions as mappings: the input signal is written on the inside, and the output signal is written as the result of that mapping.

In arrow form, write $x(t) \to y(t)$ to mean: start from $x(t)$, apply the system rule, and produce $y(t)$ as output.

$$
x(t) \to y(t)
$$

Operator notation is the same idea in function-style language: $y(t) = T\{x(t)\}$. The symbol $T$ is the system operator, and the braces show that $T$ takes $x(t)$ as its input signal and returns $y(t)$ as the output signal.

$$
y(t) = T\{x(t)\}
$$

For the base case $y(t)=2x(t)$, identify $x(t)$ as input and $y(t)$ as output, then read the same transformation as arrow notation. The rule is scaling by $2$, so this is the same system written two ways.

$$
y(t) = 2x(t) = T\{x(t)\}
$$

In the next sections, first label what is input, output, and operator in each equation; then you will apply the same reading pattern to shifted and scaled system rules while keeping this notation structure stable.

## Identifying Input and Output in Arrow Notation

**Example:** Read this arrow form and identify the input/output: $x(t) \to y(t)=2x(t-1)$.

**Explanation**

The cue in this example is the arrow form $x(t) \to y(t)=2x(t-1)$. In this notation, the symbol on the left is the source signal, and the symbol on the right is the destination signal after the system acts.

$$
x(t) \to y(t)=2x(t-1)
$$

Apply step one: locate the left endpoint of the arrow. That endpoint is the input signal. Therefore, the input is $x(t)$.

Apply step two: the right endpoint is the output signal, so the output is $y(t)$. The right side also shows the same output as an explicit expression, $y(t)=2x(t-1)$, which reinforces output-side notation.

Apply step three: report the pair with explicit direction. Input is $x(t)$, output is $y(t)$, and the direction is input to output, written as $x(t) \to y(t)$.

$$
x(t) \to y(t), \quad y(t)=2x(t-1)
$$

## Identifying the System Operator in Operator Notation

**Example:** Given $y(t)=T\{x(t)\}$ and $T\{x(t)\}=x(t-1)$, identify the operator and restate the system map in operator form.

**Explanation**

Start by reading the braces in the map $y(t)=T\{x(t)\}$: the expression inside $\{\cdot\}$ is the operator input, so $x(t)$ is the argument passed through the system rule.

Next, identify the rule itself from $T\{x(t)\}=x(t-1)$. This is a one-step delay operator, because it replaces every instance of $t$ with $t-1$ inside the input signal.

$$
y(t)=T\{x(t)\}=x(t-1)
$$

Finally, keep the input/output roles explicit: input is $x(t)$, output is $y(t)$, and $T$ is the operator that maps that input to the output by delaying it one unit.

<a id="translating-between-arrow-notation-and-operator-notation"></a>
## Translating Between Arrow Notation and Operator Notation

**Example:** Translate this pair exactly and check equivalence: $x(t) \to y(t)=\int_0^t x(\tau)d\tau$.

**Explanation**

Start from the given notation form $x(t) \to y(t)=\int_0^t x(\tau)d\tau$. The arrow form gives the rule in the same order: input is $x(t)$, output is $y(t)$, and the transformation is the integral expression.

Identify the two conversion targets: the output is written as an operator-evaluated input in $y(t)=T\{x(t)\}$, so the operator body must be exactly the same expression attached to $x(t)$.

$$
T\{x(t)\}=\int_0^t x(\tau)d\tau,\quad y(t)=T\{x(t)\}
$$

Write the equivalent operator representation as $y(t)=T\{x(t)\}=\int_0^t x(\tau)d\tau$, and this can be translated back to arrow notation the same way: $x(t) \to y(t)=\int_0^t x(\tau)d\tau$. The meaning is unchanged in both forms.

- id: d
  content: |-
    $x(t) \to y(t)=\int_0^t x(t-\tau)\,d\tau$

  content: |-
    $x(t) \to \int_0^t x(\tau)\,d\tau$

## Interpreting System Notation with Named Signals

**Example:** For the operator form $y_u(t)=\mathcal{H}\{u(t)\}$ where $\mathcal{H}\{u(t)\}=u(t)^2+1$, identify input/output/operator and rewrite in arrow notation.

**Explanation**

Start from the operator form and parse the named endpoints. The output label is $y_u(t)$, the input signal is the argument $u(t)$ inside $\mathcal{H}\{\cdot\}$, and the operator body is $u(t)^2+1$.

Match the operator symbol to the same role used earlier: $\mathcal{H}$ is the system operator, so keep its mapping exactly as $\mathcal{H}\{u(t)\}=u(t)^2+1$ and do not change the underlying transformation when moving notation styles.

$$
y_u(t)=\mathcal{H}\{u(t)\}=u(t)^2+1,\quad u(t)\to y_u(t)=u(t)^2+1
$$

The equivalent arrow statement is $u(t)\to y_u(t)=u(t)^2+1$. This confirms the symbolic roles are unchanged by relabeling: input is still the non-braced signal, output is still the mapped signal, and $\mathcal{H}$ is the same operator.
