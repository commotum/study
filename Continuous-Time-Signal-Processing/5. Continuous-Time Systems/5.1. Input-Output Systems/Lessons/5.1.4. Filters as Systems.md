## Introduction to Filters as Systems

Filters are systems, so every filter description should be read as an input-output mapping: the filter takes one signal as input and produces another signal as output.

Always identify the three parts first: the input signal $x(t)$, the output signal $y(t)$, and the feature behavior of the filter.

$$
y(t)=T\{x(t)\}
$$

For the base case, use the statement "low-pass filter reduces high-frequency content": write input as $x(t)$ and output as $y(t)$, then mark that this filter attenuates one feature band.

Use the same pattern when you compare filters: first lock $x(t)\to y(t)$, then decide whether the filter passes, attenuates, or modifies the target feature.

$$
\text{Filter behavior} \in \{\text{pass},\;\text{attenuate},\;\text{modify}\}
$$

In the next section, keep this structure fixed and practice the same translation repeatedly so the mapping becomes automatic.

## Identifying the Input and Output of a Filter

**Example:** For the filter described as "This filter takes acceleration input $a(t)$ and produces velocity output $v(t)$ by suppressing rapid oscillations", identify $x(t)$ and $y(t)$ in system form.

**Explanation**

Cue: a filter statement usually names the source signal and the response signal. The source signal is the input candidate, and the response signal is the output candidate.

Choose the rule: use consistent system notation with $x(t)$ for the input and $y(t)$ for the output.

$$
y(t)=T\{x(t)\}
$$

From the description, the input signal is the acceleration signal, so set $x(t)=a(t)$. The output signal is velocity, so set $y(t)=v(t)$.

Therefore, the filter maps $a(t)$ to $v(t)$, which in standard system form is $y(t)=T\{x(t)\}$ with $x(t)=a(t)$ and $y(t)=v(t)$.

## Identifying the Signal Feature a Filter Passes

**Example:** A filter states: "This filter keeps DC and low-frequency components and reduces rapid oscillations." Identify the feature it passes in system terms.

**Explanation**

The cue is the phrase that says what the filter keeps. Here, "keeps DC and low-frequency components" tells you the passed feature is the low-frequency, near-DC part of the signal.

$$
\text{passed feature} = \text{low-frequency / near-DC content}
$$

The extra phrase "reduces rapid oscillations" supports the same reading: the filter is not passing the fast-varying part, so the preserved feature is the slow-varying, near-DC content.

$$
T\{x(t)\}\ \text{passes low-frequency / near-DC content}
$$

So the concise system-language classification is: this filter passes low-frequency, near-DC content. That is the feature label later questions should reuse when they ask what the filter passes.

## Identifying the Signal Feature a Filter Attenuates

**Example:** A filter says: "This filter reduces the energy of high-frequency components and suppresses fast fluctuations." Identify the feature it attenuates.

**Explanation**

The cue is the phrase that says what the filter weakens. Here, "reduces the energy of high-frequency components" tells you the attenuated feature is the high-frequency, rapid-fluctuation part of the signal.

$$
\text{attenuated feature} = \text{high-frequency / rapid fluctuation content}
$$

The phrase "suppresses fast fluctuations" confirms that the filter is reducing that feature, not removing it entirely. In system terms, the behavior is attenuation of the high-frequency part of $x(t)$.

$$
T\{x(t)\}\ \text{attenuates high-frequency / rapid fluctuation content}
$$

So the concise classification is: this filter attenuates high-frequency, rapid-fluctuation content. That is the label later questions should reuse when they ask what the filter attenuates.

## Identifying the Signal Feature a Filter Modifies

**Example:** A filter claims: "This filter amplifies selected frequencies by a factor and delays them by fixed $t_0$." Identify the modified signal feature.

**Explanation**

The cue is the phrase that describes how the filter changes the signal. Here, "amplifies selected frequencies by a factor" tells you the gain is modified, and "delays them by fixed $t_0$" tells you the timing is modified.

$$
\text{modified feature} = \text{gain and delay / phase-delay characteristics}
$$

This is not a pass-only or attenuate-only description. In system terms, the filter changes the way $x(t)$ is scaled and shifted, so the correct feature label is gain together with delay, or phase-delay behavior.

$$
T\{x(t)\}\ \text{modifies gain and delay}
$$

So the concise classification is: this filter modifies gain and delay characteristics. That label is what later questions should reuse when the description includes explicit transformation language.

<a id="mapping-a-filter-description-into-system-notation"></a>
## Mapping a Filter Description Into System Notation

**Example:** Filter description: "Input $x(t)$ is a continuous-time signal. The system outputs $y(t)$ where high-frequency content is reduced and phase is advanced by $t_0$." Convert this to one system-notation sentence and identify its feature behavior.

**Explanation**

The cue is the full description: it gives the input signal, the output signal, and the feature behavior. Here, $x(t)$ is the input, $y(t)$ is the output, high-frequency content is reduced, and phase is advanced by $t_0$.

$$
y(t)=T\{x(t)\}
$$

The behavior clause attaches to that system form: the filter attenuates high-frequency content and modifies phase by a delay advance of $t_0$. That keeps the notation compact while preserving both feature labels.

$$
y(t)=T\{x(t)\}, \qquad \text{high-frequency content is attenuated and phase is advanced by } t_0
$$

So the full system-notation statement is $y(t)=T\{x(t)\}$ with high-frequency attenuation and phase advance. That is the complete mapping later questions should imitate.
