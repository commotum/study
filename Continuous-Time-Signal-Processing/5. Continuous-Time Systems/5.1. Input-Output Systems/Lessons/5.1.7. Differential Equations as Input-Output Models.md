## Introduction to Differential Equations as Input-Output Models

Many differential equations in this course are also continuous-time system descriptions. Read the equation as a rule that takes one signal as the input and produces another signal as the output, instead of treating it only as something to solve for.

In the system view, the signal being driven by the equation is the input, and the signal whose derivatives appear on the left is the output. That lets us write the same idea as $y(t)=\mathcal{T}\{x(t)\}$, where $\mathcal{T}$ is the rule that maps $x(t)$ to $y(t)$.

$$
y'(t) + a\,y(t) = x(t)
$$

The simplest base case is the first-order equation $y'(t)+y(t)=x(t)$. Here $x(t)$ is the input, $y(t)$ is the output, and the equation tells you that the output is determined by its own current value and derivative together with the driving input.

$$
y''(t)+b\,y'(t)+c\,y(t)=x(t)
$$

The same reading works for higher-order equations such as $y''(t)+b\,y'(t)+c\,y(t)=x(t)$. The highest derivative of $y(t)$ tells you the system order, and the whole equation is the input-output rule you will translate in the next step.

## Identifying the Input and Output in a Differential Equation

**Example:** For $2y'(t)+3y(t)=x(t)+\sin t$, identify the valid input-output assignment and write it as a system rule.

**Explanation**

The cue is that the derivatives are attached to $y(t)$ on the left side of $2y'(t)+3y(t)=x(t)+\sin t$. That means $y(t)$ is the output signal, because it is the quantity being determined by the differential rule, and $x(t)$ is the input signal, because it is part of the driving side of the model.

The extra $\sin t$ term is a fixed forcing term on the driving side, so it does not change the role labels. The valid assignment is still input $x(t)$ and output $y(t)$; what would be wrong is to swap them and make the output signal drive itself.

So the system reading is: input $x(t)$ goes into a rule that produces output $y(t)$, with the differential equation providing the mapping. In later steps, that same role check will let you read more complicated equations quickly.

## Reading Output Derivative Orders in a Differential Equation

**Example:** Read $y'''(t)+y''(t)+5y'(t)=x(t)-1$ and report the output derivative orders, highest order, and corresponding system order.

**Explanation**

The cue is the output signal $y(t)$ on the left side: every derivative term attached to $y(t)$ belongs to the output side of the model. In this equation, the output derivative orders are $3$, $2$, and $1$, so the highest output derivative order is $3$.

The term $x(t)-1$ is on the forcing side, so it does not change the output order count. To read the system order, ignore the input expression and look only at the highest derivative of $y(t)$; here that makes the model a third-order system.

So the correct result is: output derivative orders $3$, $2$, and $1$, highest order $3$, and system order $3$. The input-output reading stays the same as in the previous step; this step adds only the rule for counting derivatives on the output side.

<a id="interpreting-the-equation-rule-that-relates-input-to-output"></a>
## Interpreting the Equation Rule that Relates Input to Output

**Example:** Interpret $y''(t)+y'(t)+y(t)=x(t)$ as a rule that maps input trajectory $x(t)$ to output trajectory $y(t)$, including derivative dependence.

**Explanation**

The cue is that the output signal is still $y(t)$, because all of the derivative terms on the left side are attached to $y(t)$. So this equation is not just a statement to solve; it is the rule that tells how the input $x(t)$ drives the output $y(t)$.

In operator form, we can write the same idea as $\mathcal{D}^2y(t)+\mathcal{D}y(t)+y(t)=x(t)$, where $\mathcal{D}$ represents differentiation with respect to $t$. That makes the rule explicit: the output is determined by a second derivative term, a first derivative term, and the output itself, all balanced against the input.

So the input-output description is: the signal $x(t)$ is the input, the signal $y(t)$ is the output, and the system rule maps $x(t)$ to $y(t)$ through the differential equation $y''(t)+y'(t)+y(t)=x(t)$. This is the form you want to recognize before moving on to more complicated equations.

```quiz
feedback: |-
  The driving signal is $x(t)$ because it appears as the right-side forcing term, while $y(t)$ and its derivatives are determined by the rule. So the system is a map from input $x(t)$ to output $y(t)$ through $y''(t)-y'(t)+4y(t)=x(t)$, or in operator form $\mathcal{D}^2 y(t)-\mathcal{D} y(t)+4y(t)=x(t)$.
```

## Converting Higher-Order Differential Equations into Input-Output Models

**Example:** Convert $y^{(4)}(t)+y'''(t)+5y''(t)+2y'(t)+y(t)=u(t)$ into a high-level input-output description and state the system order.

**Explanation**

The cue is that every derivative term belongs to the output signal $y(t)$, while the forcing term on the right side is the input $u(t)$. The highest derivative on the output is $y^{(4)}(t)$, so the system order is $4$.

Without solving for $y(t)$, we keep the equation as the rule that links the input to the output: a fourth-order output model driven by $u(t)$, with derivative terms $y^{(4)}(t)$, $y'''(t)$, $5y''(t)$, $2y'(t)$, and $y(t)$ combining to match the input.

In operator form, the model is $\mathcal{D}^4y(t)+\mathcal{D}^3y(t)+5\mathcal{D}^2y(t)+2\mathcal{D}y(t)+y(t)=u(t)$. So the input is $u(t)$, the output is $y(t)$, and the system is a fourth-order input-output model with no ambiguity about direction or order.

**Question 7:**

```quiz

  Then write the equivalent high-level input-output model in operator form.

  $$
  y^{(4)}(t)-2y''(t)+y(t)=3x(t)
  $$

correct: |-
  The input is $x(t)$ and the output is $y(t)$. This is a fourth-order system, and the operator form is $\mathcal{D}^4 y(t)-2\mathcal{D}^2 y(t)+y(t)=3x(t)$.

feedback: |-
  All derivative terms involving $y(t)$ are on the left, so they define the output dynamics and set the order to 4 via the highest derivative $y^{(4)}(t)$. The forcing term $3x(t)$ is outside those output derivatives, so it is the input signal and the system-order reading stays fourth-order.
```
