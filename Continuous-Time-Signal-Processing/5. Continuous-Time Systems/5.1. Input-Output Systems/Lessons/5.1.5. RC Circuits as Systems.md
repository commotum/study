## Introduction to RC Circuits as Systems

A series RC circuit can be read as a continuous-time input-output system: one signal drives the circuit, and another signal is the output we watch. In this first view, the important job is not solving the circuit yet but recognizing the roles that the source and circuit variables play.

![](<../Source/5.1.5. RC Circuits as Systems/Images/l005-s001-te-section-001.png>)

For the base case, name the source voltage as $v_s(t)$ and take the capacitor voltage $v_C(t)$ as the output. That gives the circuit a clear input-output pairing: the source is the input signal, and the capacitor voltage is the response signal.

$$
v_s(t)=v_R(t)+v_C(t)
$$

The resistor voltage is related to the current by Ohm's law, so the middle branch variable is not independent. Once the current is named as $i(t)$, the resistor voltage becomes $v_R(t)=Ri(t)$.

$$
v_R(t)=Ri(t)
$$

For the capacitor, the current and the capacitor voltage are linked by $i(t)=C \frac{d}{dt}v_C(t)$. That means the output signal is determined by the circuit relation rather than chosen arbitrarily.

$$
i(t)=C \frac{d}{dt}v_C(t)
$$

Substituting the resistor and capacitor relations into KVL gives the system rule for this base model. In other words, the RC circuit is now written as a mapping from $v_s(t)$ to $v_C(t)$.

$$
v_s(t)=RC \frac{d}{dt}v_C(t)+v_C(t)
$$

This section sets up the system view: the source voltage is the input, the capacitor voltage is the output, and the circuit equation is the rule that connects them. Later sections will keep the same circuit and change only the output choice or the way the same relation is read.

## Assigning the Source Voltage as the Input

**Example:** In the RC circuit, identify which signal should be treated as the input and explain why the source voltage, not $v_R(t)$ or $v_C(t)$, plays that role.

**Explanation**

In this RC circuit, the source voltage is the signal that drives the rest of the system. The task here is to recognize which signal plays the input role before worrying about how the circuit responds.

![](<../Source/5.1.5. RC Circuits as Systems/Images/l005-s002-te-section-002.png>)

Name the independent source as $v_s(t)$. Because it supplies the signal that enters the circuit, $v_s(t)$ is the input signal in this model.

The voltages across the resistor and capacitor, $v_R(t)$ and $v_C(t)$, are internal circuit variables. They are determined by the source and the circuit relation, so they are not the input.

So the input-output pairing starts with $v_s(t)$ feeding the circuit, while $v_R(t)$ and $v_C(t)$ remain response variables inside the system. That is the role assignment this example establishes for the RC model.

## Choosing the Capacitor Voltage as the Output

**Example:** In the same RC circuit, choose the capacitor voltage as the output and state the input-output pair.

**Explanation**

Keep the same RC circuit and the same source input $v_s(t)$. The new job here is to choose the capacitor voltage $v_C(t)$ as the output signal and read it off the circuit correctly.

![](<../Source/5.1.5. RC Circuits as Systems/Images/l005-s003-te-section-003.png>)

Locate the capacitor branch and name the voltage across it $v_C(t)$. That branch voltage is the output signal in this model.

Write the input-output pairing as $v_s(t) \mapsto v_C(t)$. The source still drives the circuit, and the capacitor voltage is the response we are tracking.

This choice does not change the physical circuit, but it does change the system description. The governing circuit relation will tell us how $v_C(t)$ depends on $v_s(t)$, and that is the perspective this example sets up.

<a id="interpreting-the-rc-circuit-relation-as-the-system-rule"></a>
## Interpreting the RC Circuit Relation as the System Rule

**Example:** Using the RC circuit with source voltage $v_s(t)$ as input and capacitor voltage $v_C(t)$ as output, write the equation that defines the system rule.

**Explanation**

This step uses the same RC circuit and input choice from the prior section, but now we translate the circuit into the system rule for output $v_C(t)$ directly.

![](<../Source/5.1.5. RC Circuits as Systems/Images/l005-s005-te-section-005.png>)

Write the loop rule with output and internal variables: $v_s(t)=v_R(t)+v_C(t)$.

Use Ohm and capacitor relations: $v_R(t)=R i(t)$ and $i(t)=C\frac{d}{dt}v_C(t)$.

$$
v_s(t)=RC\frac{d}{dt}v_C(t)+v_C(t)
$$

That equation is the system rule: the source signal $v_s(t)$ drives the system, and the system returns the capacitor-voltage response $v_C(t)$.
