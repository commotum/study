## Introduction to Homogeneity

A continuous-time system is homogeneous when scaling the input by a real factor produces the same scale factor at the output. This is the linearity test you use after you can write the system as $T\{x(t)\}=y(t)$.

$$
T\{x(t)\}=y(t)
$$

The homogeneity check is $T\{a x(t)\}=a T\{x(t)\}=a y(t)$, with $a\in\mathbb{R}$. The system rule stays the same; only the input and output scale together by the same factor.

$$
T\{a x(t)\}=a T\{x(t)\}
$$

The simplest mental test is to start with one input-output pair $x(t)\mapsto y(t)$ and check what happens when the input is doubled or negated. If doubling gives $2y(t)$ and negating gives $-y(t)$, the system passes this test; if either one fails, the system is not homogeneous and therefore not linear.

## Comparing the Output for a Scaled Input

**Example:** A system maps $x(t)$ to $y(t)$. If the input is changed to $3x(t)$, what output should a homogeneous system produce?

**Explanation**

Start from the known input-output pair $x(t) \mapsto y(t)$. The homogeneity test asks whether multiplying the input by a real constant multiplies the output by the same constant.

$$
T\{x(t)\}=y(t)
$$

Now replace the input with $3x(t)$. For a homogeneous system, the output should keep the same scale factor, so the new output is $3y(t)$.

$$
T\{3x(t)\}=3T\{x(t)\}=3y(t)
$$

Because the input was scaled by $3$ and the output was also scaled by $3$, this example passes the homogeneity check. The same comparison works the same way for any real scale factor $a$.

<a id="verifying-homogeneity-when-scaling-passes-through-the-system"></a>
## Verifying Homogeneity When Scaling Passes Through the System

**Example:** A system is defined by $y(t)=4x(t)$. Verify homogeneity for the input $a x(t)$.

**Explanation**

The cue is a linear gain rule: the output is already written as a constant times the input, so the homogeneity test is to replace $x(t)$ with $a x(t)$ and see whether the same factor $a$ can be carried through the system.

$$
T\{x(t)\}=4x(t)
$$

Substitute the scaled input into the rule. The system output becomes $T\{a x(t)\}=4[a x(t)]$, and the scalar factor can be moved outside the system action without changing the output shape.

$$
T\{a x(t)\}=4a x(t)=a\bigl(4x(t)\bigr)
$$

Since $4x(t)=y(t)$, the result is $T\{a x(t)\}=a y(t)$. The input scale and the output scale match exactly, so this system is homogeneous.

<a id="identifying-a-homogeneity-failure-from-a-mismatched-scale-factor"></a>
## Identifying a Homogeneity Failure from a Mismatched Scale Factor

**Example:** A system is defined by $y(t)=x^2(t)$. Test homogeneity using the input $a x(t)$.

**Explanation**

The cue is a nonlinear square rule: the output is the square of the input, so test homogeneity by replacing $x(t)$ with $a x(t)$ and checking whether the output keeps the same scale factor $a$.

$$
y(t)=x^2(t)
$$

Now substitute the scaled input. Squaring $a x(t)$ gives $a^2 x^2(t)$, so the scale factor moves from $a$ to $a^2$ instead of staying the same.

$$
T\{a x(t)\}=(a x(t))^2=a^2x^2(t)=a^2y(t)
$$

Compare that result with $a y(t)$. Because the output scales as $a^2 y(t)$ rather than $a y(t)$, the system fails the homogeneity test.

## Testing Homogeneity with an Arbitrary Scale Constant

**Example:** A system is defined by $y(t)=7x(t)$. Show that for any scalar $a$, the input $a x(t)$ produces output $a y(t)$.

**Explanation**

The cue is the gain rule $y(t)=7x(t)$. To test homogeneity, replace $x(t)$ with $a x(t)$ and track the same scale factor through the system.

$$
y(t)=7x(t)
$$

Substitute the scaled input: $T\{a x(t)\}=7(a x(t))=7a x(t)$. Because scalar multiplication can be regrouped, rewrite this as $a(7x(t))$.

$$
T\{a x(t)\}=7(a x(t))=7a x(t)=a(7x(t))=a y(t)
$$

Since $7x(t)=y(t)$, the output is exactly $a y(t)$. The same scalar appears on the output, so this system satisfies homogeneity.
