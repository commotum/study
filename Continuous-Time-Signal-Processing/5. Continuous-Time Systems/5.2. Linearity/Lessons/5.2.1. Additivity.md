## Introduction to Additivity

Additivity is the test for a continuous-time input-output system that asks a simple question: if you combine two inputs first, does the system output match the sum of the two separate outputs? Start with two inputs $x_1(t)$ and $x_2(t)$, build the summed input $x_1(t)+x_2(t)$, and compare the result with the outputs produced by each input on its own.

Write the test in operator form so the same pair of inputs appears on both sides. The left side means, “pass the summed input through the system once,” and the right side means, “pass each input through the system separately, then add the outputs.”

$$
T[x_1(t)+x_2(t)] = T[x_1(t)] + T[x_2(t)]
$$

If the equality holds for every continuous-time input pair, the system is additive. If one counterexample breaks the equality, the system is not additive. The check always uses the same inputs on both sides; only the way they are combined changes.

$$
y_{12}(t) = T[x_1(t)+x_2(t)] \quad \text{and} \quad y_1(t)+y_2(t) = T[x_1(t)] + T[x_2(t)]
$$

So the direct question for this section is: does one summed input produce the same output as the sum of the two individual outputs? That is the additivity comparison every later example will reuse.

## Checking Additivity with Two Continuous-Time Inputs

**Example:** Use $x_1(t) = \\sin t$ and $x_2(t) = \\cos t$ to verify additivity for the system $T[x(t)] = 2x(t)$.

**Explanation**

To check additivity, start with the two inputs $x_1(t)=\sin t$ and $x_2(t)=\cos t$. The cue is to form the summed input first, apply the system once, and compare that output with the sum of the outputs produced by the two inputs separately.

$$
T[x_1(t)+x_2(t)] = T[\sin t + \cos t] = 2(\sin t + \cos t)
$$

Now expand the scalar across the sum to get $2\sin t + 2\cos t$. That is the output for the summed input.

$$
T[x_1(t)] + T[x_2(t)] = 2\sin t + 2\cos t
$$

The two expressions match exactly, so this system is additive for this input pair. The comparison is the same one used by the additivity test: one summed input on the left, the two separate outputs added on the right.

## Checking Additivity from a Simple System Rule

**Example:** Show that the system $T[x(t)] = x(t-1)$ is additive for arbitrary continuous-time inputs $x_1(t)$ and $x_2(t)$.

**Explanation**

The cue is the shift rule $T[x(t)] = x(t-1)$. To test additivity, keep the same two inputs $x_1(t)$ and $x_2(t)$ on both sides, form the sum first, and apply the system once.

$$
T[x_1(t)+x_2(t)] = x_1(t-1)+x_2(t-1)
$$

Now apply the same shift rule to each input separately. Because the system just delays whatever it receives by one unit, the individual outputs are $T[x_1(t)] = x_1(t-1)$ and $T[x_2(t)] = x_2(t-1)$.

$$
T[x_1(t)] + T[x_2(t)] = x_1(t-1)+x_2(t-1)
$$

The two results are identical, so this system is additive. The comparison is the same on both sides: shift the summed input once on the left, or shift each input separately and add the results on the right.

## Recognizing Failure of Additivity from a Counterexample

**Example:** Use $T[x(t)] = [x(t)]^2$ with $x_1(t) = 1$ and $x_2(t) = 2$ to show that the system is not additive.

**Explanation**

The cue is the same additivity comparison used in the earlier examples: evaluate the system on the summed input, then compare that result with the sum of the separate outputs. Here the system rule is $T[x(t)] = [x(t)]^2$, so the key question is whether squaring the sum matches the sum of the two squares.

$$
T[x_1(t)+x_2(t)] = T[1+2] = [1+2]^2 = 9
$$

Now evaluate the two inputs separately. Since $T[1] = 1^2 = 1$ and $T[2] = 2^2 = 4$, the sum of the separate outputs is $1+4=5$.

$$
T[x_1(t)] + T[x_2(t)] = 1 + 4 = 5
$$

The two results do not match: the summed input produces $9$, but the separate outputs add to $5$. The mismatch comes from the cross term in $(1+2)^2$, so this one counterexample is enough to conclude that the system is not additive.

options:
- id: a
  content: |-

  correct: true
  feedback: |-
    Evaluating the summed input gives $T[2+3]=5^2=25$, while separate outputs give $2^2+3^2=4+9=13$. Since these are different, the system is not additive.

- id: b
  content: |-
    $T[x_1(t)+x_2(t)] = 2+3=5$ and $T[x_1(t)] + T[x_2(t)] = 13$, so the two sides appear to match if you treat $5$ as the combined squared value.

- id: c
  content: |-
    $T[x_1(t)+x_2(t)] = [2+3]^2 = 2^2 + 3^2 = 13$ and $T[x_1(t)] + T[x_2(t)] = 13$, so the system is additive.

- id: d
  content: |-

- id: e
  content: |-
    Compute $[2+3]^2 = (2+3)(2+3)=25$, then conclude incorrectly that the sum of separate outputs is also $25$, so $T$ is additive.
