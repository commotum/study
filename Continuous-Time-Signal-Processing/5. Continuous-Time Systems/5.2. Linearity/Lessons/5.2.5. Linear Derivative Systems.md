## Introduction to Linear Derivative Systems

A first-derivative system takes an input signal $x(t)$ and produces the output $y(t)=[x(t)]'$. The linearity test for this kind of system is whether the derivative rule preserves both sums and scalar multiples.

$$
y(t)=[x(t)]'
$$

For additivity, the derivative must distribute across an input sum. If the system is linear, then the derivative of $x_1(t)+x_2(t)$ must equal the sum of the two separate derivatives.

$$
(x_1+x_2)'(t)=x_1'(t)+x_2'(t)
$$

For homogeneity, a constant factor must pass through the derivative unchanged. If the input is scaled by $a$, then the output must scale by the same factor.

$$
(a x(t))'=a x'(t)
$$

Those two identities are the superposition test for a derivative system. A derivative rule is linear only when the response to a scaled sum matches the scaled sum of the separate responses, so later examples will check both identities in symbolic form.

$$
\left(a_1 x_1 + a_2 x_2\right)' = a_1 x_1' + a_2 x_2'
$$

## Testing Additivity for a First-Derivative System

**Example:** For $x_1(t)=t^2$ and $x_2(t)=3\cos t$, test additivity for $y(t)=[x(t)]'$ by comparing the derivative of $x_1+x_2$ with $y[x_1](t)+y[x_2](t)$.

**Explanation**

The cue is a summed input, so we check whether the derivative of the sum matches the sum of the separate derivatives. For this system, the output rule is $y[x](t)=x'(t)$.

$$
x(t)=x_1(t)+x_2(t)=t^2+3\cos t
$$

Differentiate the combined input directly, then differentiate each input separately. If additivity holds, both paths should produce the same output.

$$
\begin{aligned}
y[x](t) &= x'(t) = (t^2+3\cos t)' = 2t-3\sin t \\
y[x_1](t) &= (t^2)' = 2t \\
y[x_2](t) &= (3\cos t)' = -3\sin t
\end{aligned}
$$

Now compare the two results: $y[x_1](t)+y[x_2](t)=2t-3\sin t$, which matches $y[x](t)$. So this first-derivative system passes the additivity test for these inputs.

## Testing Homogeneity for a First-Derivative System

**Example:** For $x(t)=t^3-2t$ and $a=4$, test homogeneity by comparing $y[a x](t)$ with $a y[x](t)$ for $y(t)=[x(t)]'$.

**Explanation**

The cue is a scaled input $a x(t)$, so we check whether the derivative keeps that same scale outside the output. For this system, $y[x](t)=x'(t)$.

$$
x(t)=t^3-2t,\qquad a=4,\qquad a x(t)=4(t^3-2t)
$$

Differentiate the scaled input directly, then differentiate first and scale the output. If homogeneity holds, both paths should give the same expression.

$$
\begin{aligned}
y[a x](t) &= \big(4(t^3-2t)\big)' = 12t^2-8 \\
y[x](t) &= (t^3-2t)' = 3t^2-2 \\
a y[x](t) &= 4(3t^2-2) = 12t^2-8
\end{aligned}
$$

Because $y[a x](t)=a y[x](t)$, this first-derivative system passes the homogeneity test for this input and scale. That is the scalar-multiplication half of linearity.

<a id="applying-superposition-to-a-scaled-derivative-system"></a>
## Applying Superposition to a Scaled Derivative System

**Example:** For $y(t)=[x(t)]'$, $a=2$, $x_1(t)=t^3$, and $x_2(t)=\sin t$, compute $y[a x_1+x_2]$ and compare with $a y[x_1]+y[x_2]$.

**Explanation**

The cue is a scaled sum of two inputs, so we check whether the derivative of the combined input matches the scaled sum of the separate outputs. For this system, $y[x](t)=x'(t)$.

$$
u(t)=a x_1(t)+x_2(t)=2t^3+\sin t
$$

Differentiate the combined input directly, then differentiate each input separately and scale only the $x_1$ output by $a$. If superposition holds, the two results will match term by term.

$$
\begin{aligned}
y[u](t) &= \big(2t^3+\sin t\big)' = 6t^2+\cos t \\
y[x_1](t) &= (t^3)' = 3t^2 \\
y[x_2](t) &= (\sin t)' = \cos t \\
a y[x_1](t)+y[x_2](t) &= 2(3t^2)+\cos t = 6t^2+\cos t
\end{aligned}
$$

Because $y[u](t)=a y[x_1](t)+y[x_2](t)$, the first-derivative system passes the superposition test for this scaled-sum input. This combines additivity and homogeneity in one linearity check.

## Testing a System with an Input Term and a Derivative Term

**Example:** Test system $y(t)=x(t)+x'(t)$ on $x_1(t)=e^t$ and $x_2(t)=t^2$ by evaluating $y[x_1+x_2]$ and $y[x_1]+y[x_2]$ and then with scale $a=-2$.

**Explanation**

The cue is the mixed rule $y[x]=x+x'$. It adds the input itself and its first derivative, so the linearity check is to compare the response to $x_1+x_2$ with the sum of the separate responses, then check one scalar scale factor.

$$
y[x_1+x_2] = (x_1+x_2) + (x_1+x_2)' = (e^t+t^2) + (e^t+2t) = 2e^t+t^2+2t
\[6pt]
y[x_1] + y[x_2] = (x_1+x_1') + (x_2+x_2') = (e^t+e^t) + (t^2+2t) = 2e^t+t^2+2t
$$

The two expressions match, so additivity holds for this mixed operator. The same structure should also preserve scaling, so we test one negative scalar next.

$$
y[-2(x_1+x_2)] = -2(x_1+x_2) + \frac{d}{dt}\bigl[-2(x_1+x_2)\bigr] = -2(e^t+t^2) - 2(e^t+2t) = -4e^t-2t^2-4t
\[6pt]
-2\,y[x_1+x_2] = -2\bigl((e^t+t^2) + (e^t+2t)\bigr) = -4e^t-2t^2-4t
$$

Since the scaled output matches the output scaled by $-2$, this system passes both parts of the superposition test. The mixed input-plus-derivative rule is linear because each branch is linear and they combine without any constant offset.
