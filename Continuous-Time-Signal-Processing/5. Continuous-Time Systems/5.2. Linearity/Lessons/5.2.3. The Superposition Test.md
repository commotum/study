## Introduction to The Superposition Test

The superposition test is the combined linearity check for a continuous-time system $T[\,\cdot\,]$. It uses the same idea behind additivity and homogeneity: if you scale two inputs, add them, and send the combined input through the system, the output must match the same scaled sum of the two separate outputs.

$$
T[a x_1(t) + b x_2(t)] = aT[x_1(t)] + bT[x_2(t)]
$$

Read the rule in words first: scale the inputs by $a$ and $b$, add the scaled inputs, pass that sum through the system once, and compare the result with $a$ times the response to $x_1(t)$ plus $b$ times the response to $x_2(t)$. If those two outputs agree for every pair of continuous-time inputs and every real $a$ and $b$, the system passes the test.

$$
T[x_1(t) + x_2(t)] = T[x_1(t)] + T[x_2(t)]
$$

Start with the unit-coefficient case $T[x_1(t) + x_2(t)]$ before extending to arbitrary scalars. That simpler form makes the structure of the test easy to see, and the same pattern extends to expressions such as $T[2x_1(t) - x_2(t)] = 2T[x_1(t)] - T[x_2(t)]$.

$$
T[2x_1(t) - x_2(t)] = 2T[x_1(t)] - T[x_2(t)]
$$

One mismatch is enough to reject the test, so the task is always the same: compare the output from the combined input with the scaled sum of the separate outputs and check whether they are identical.

## Predicting the Output for a Scaled Sum of Two Inputs

**Example:** If $T[x_1(t)] = y_1(t)$ and $T[x_2(t)] = y_2(t)$, what is $T[3x_1(t) - 2x_2(t)]$?

**Explanation**

The cue is a scaled sum of two inputs, so use superposition: first separate the combined input into two scaled pieces, then apply homogeneity to each piece, and finally recombine the outputs.

$$
\begin{aligned}T[3x_1(t) - 2x_2(t)] &= T[3x_1(t)] + T[-2x_2(t)] \\ &= 3T[x_1(t)] - 2T[x_2(t)]\end{aligned}
$$

Now substitute the known outputs $T[x_1(t)] = y_1(t)$ and $T[x_2(t)] = y_2(t)$. That gives the predicted response $3y_1(t) - 2y_2(t)$.

$$
T[3x_1(t) - 2x_2(t)] = 3y_1(t) - 2y_2(t)
$$

This is the same superposition pattern from the definition, now used to predict an actual output from two known input-output pairs. The coefficients stay attached to their matching outputs, and the final expression is just the scaled sum of those responses.

## Verifying a Claimed Combined-Input Output

**Example:** If $T[x_1(t)] = y_1(t)$ and $T[x_2(t)] = y_2(t)$, verify whether the claim $T[2x_1(t) - x_2(t)] = 2y_1(t) - y_2(t)$ is consistent with the superposition test.

**Explanation**

The cue is a claimed combined-input output, so do not recompute the system from scratch. Use the superposition prediction from the two known input-output pairs and compare it directly with the claim.

$$
\begin{aligned}T[2x_1(t) - x_2(t)] &= 2T[x_1(t)] - T[x_2(t)] \\ &= 2y_1(t) - y_2(t)\end{aligned}
$$

The predicted output matches the claimed output term by term: the coefficient $2$ stays with $y_1(t)$ and the minus sign stays with $y_2(t)$. Because the expressions are identical, the claim is consistent with the superposition test.

$$
T[2x_1(t) - x_2(t)] = 2y_1(t) - y_2(t)
$$

This is the same check-and-compare move from the previous step, now used to verify a stated result instead of producing one from a scaled sum. The only job is to see whether the claimed expression matches the superposition prediction exactly.

<a id="recognizing-when-superposition-fails"></a>
## Recognizing When Superposition Fails

**Example:** Let $T[x(t)] = [x(t)]^2$. For $x_1(t) = 1$ and $x_2(t) = 2$, compare $T[x_1(t) + x_2(t)]$ with $T[x_1(t)] + T[x_2(t)]$ and decide whether superposition holds.

**Explanation**

The cue is a nonlinear squared-output rule, so use the same comparison as before: compute the output for the combined input, compute the outputs for the two inputs separately, and then compare the two results.

$$
\begin{aligned}T[x_1(t)+x_2(t)] &= [1+2]^2 = 9 \\ T[x_1(t)] + T[x_2(t)] &= [1]^2 + [2]^2 = 5\end{aligned}
$$

The two sides are not equal: the combined input gives $9$, while the separate outputs add to $5$. Because the expressions do not match, the system fails the superposition test.

$$
T[x_1(t)+x_2(t)] \ne T[x_1(t)] + T[x_2(t)]
$$

This is the same compare-and-decide move from the previous step, but now the mismatch itself is the result. One counterexample is enough to reject superposition.
