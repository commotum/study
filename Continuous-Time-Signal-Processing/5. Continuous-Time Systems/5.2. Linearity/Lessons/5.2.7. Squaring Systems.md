## Introduction to Squaring Systems

A squaring system has the form $T[x(t)] = [x(t)]^2$. Before you test any specific example, you need the two linearity checks that every later step will reuse: additivity and homogeneity. Additivity asks whether the output for a summed input matches the sum of the separate outputs, and homogeneity asks whether scaling the input produces the same scaled output.

$$
T[x(t)] = [x(t)]^2
$$

For additivity, compare the output of the sum $x_1(t)+x_2(t)$ with the sum of the separate outputs from $x_1(t)$ and $x_2(t)$. The simplest checkpoint for this lesson uses $x_1(t)=t$ and $x_2(t)=1$, so the squared sum can be expanded cleanly and the mismatch is easy to see.

$$
T[x_1(t)+x_2(t)] = [x_1(t)+x_2(t)]^2
$$

$$
T[x_1(t)] + T[x_2(t)] = x_1(t)^2 + x_2(t)^2
$$

When you expand the squared sum, the extra mixed term appears: $[x_1(t)+x_2(t)]^2 = x_1(t)^2 + 2x_1(t)x_2(t) + x_2(t)^2$. That cross-term is the signature that additivity fails for a squaring system.

For homogeneity, scale one input by a constant $a$ and compare $T[a x(t)]$ with $aT[x(t)]$. The base scalar checkpoint here uses $a=2$, because it makes the difference between $a^2$ and $a$ visible immediately.

$$
T[a x](t) = [a x(t)]^2 = a^2 x(t)^2
$$

$$
a\,T[x](t) = a\,x(t)^2
$$

Because squaring turns the scale factor into $a^2$ on one side but leaves only $a$ on the other, the two expressions do not match in general. That squared-scale mismatch is the homogeneity failure, and together with the cross-term it shows why the squaring system is not linear.

## Computing Outputs of a Squaring System

**Example:** Compute $T[t+1]$ for the system $T[x(t)] = [x(t)]^2$ and simplify the expression.

**Explanation**

Use the concrete input $x(t)=t+1$ with the squaring system $T[x(t)] = [x(t)]^2$. The action is to substitute the input into the rule, square the entire expression, and simplify the result.

$$
T[t+1] = [t+1]^2
$$

Now expand the squared binomial. The whole sum stays inside the brackets until the square is distributed, so the middle term appears when the product is multiplied out.

$$
(t+1)^2 = t^2 + 2t + 1
$$

So the output is $T[t+1] = t^2 + 2t + 1$. This is the baseline format for squaring-system outputs: substitute the input, square the entire expression, and simplify the result.

## Testing Additivity for a Squaring System

**Example:** Test additivity for $T[x(t)] = [x(t)]^2$ using $x_1(t)=t$ and $x_2(t)=1$.

**Explanation**

Use the additivity cue: compare the output of a summed input with the sum of the separate outputs. With $x_1(t)=t$ and $x_2(t)=1$, the first step is to apply the squaring rule to the combined input.

$$
T[x_1+x_2](t) = T[t+1] = (t+1)^2
$$

Now evaluate each input separately with the same system rule. The separate outputs are $T[x_1](t)=t^2$ and $T[x_2](t)=1$, so their sum is the reference side of the additivity test.

$$
T[x_1](t) + T[x_2](t) = t^2 + 1
$$

Expanding the combined input gives $T[t+1]=(t+1)^2=t^2+2t+1$, which does not match $t^2+1$. The extra $2t$ term is the mismatch that shows additivity fails for the squaring system.

## Identifying the Cross-Term in a Squared Sum

**Example:** Find the cross-term in $[x_1(t)+x_2(t)]^2$ for $x_1(t)=t$ and $x_2(t)=t^2$, and explain why this term breaks additivity.

**Explanation**

Start with the expansion rule. For a sum inside a square, compare $[x_1(t)+x_2(t)]^2 = x_1(t)^2 + 2x_1(t)x_2(t) + x_2(t)^2$ and use the mixed term $2x_1(t)x_2(t)$ as the cue for additivity failure.

$$
(x_1(t)+x_2(t))^2 = x_1(t)^2 + 2x_1(t)x_2(t) + x_2(t)^2
$$

Use $x_1(t)=t$ and $x_2(t)=t^2$ in the additivity test for $T[x(t)] = [x(t)]^2$. Compute each side of the check separately.

$$
T[x_1(t)+x_2(t)] = [t + t^2]^2 = t^2 + 2t^3 + t^4
$$

$$
T[x_1(t)] + T[x_2(t)] = t^2 + (t^2)^2 = t^2 + t^4
$$

The left side has the mixed term $2t^3$, while the right side does not. This extra term is exactly the $2x_1x_2$ cross-term, so the two sides are unequal. That mismatch is the additivity failure for a squaring system.

## Testing Homogeneity for a Squaring System

**Example:** Test homogeneity for $T[x(t)] = [x(t)]^2$ with $a=3$ and $x(t)=t+1$.

**Explanation**

Use the homogeneity cue and write the two quantities to compare: $T[a x(t)]$ and $a T[x(t)]$, with $a=3$ and $x(t)=t+1$.

Apply the system rule to the scaled input. First compute the scaled input signal and substitute into the map.

$$
T[3x(t)] = [3x(t)]^2
$$

$$
= [3(t+1)]^2 = 9(t+1)^2
$$

Compute the other side of the homogeneity check by scaling the original output using the same output map.

$$
T[x(t)] = [x(t)]^2 = (t+1)^2 \Rightarrow 3T[x(t)] = 3(t+1)^2
$$

Compare the results: $9(t+1)^2 \neq 3(t+1)^2$. The factor is $a^2$ on the left and only $a$ on the right, so the outputs do not scale the same way. Therefore, this squaring system is not homogeneous.

## Classifying a Squaring System from the Squared-Scale Mismatch

**Example:** For $T[x(t)] = [x(t)]^2$, state the linearity classification and justify it from the prior additivity and homogeneity mismatch signatures.

**Explanation**

Use the cue for final linearity classification: a system must pass both $T[x_1(t)+x_2(t)] = T[x_1(t)] + T[x_2(t)]$ and $T[a x(t)] = a T[x(t)]$ for all suitable inputs.

Start with the additivity mismatch already computed for the same squaring system using $T[x(t)] = [x(t)]^2$, $x_1(t)=t$, and $x_2(t)=1$.

$$
T[x_1(t)+x_2(t)] = [t+1]^2 = t^2+2t+1, \qquad T[x_1(t)] + T[x_2(t)] = t^2 + 1
$$

The additivity check fails because of the extra middle term $2t$, so this already violates a required linearity condition.

Now check the homogeneity mismatch used in the same system with $a=3$ and $x(t)=t+1$.

$$
T[3x(t)] = [3x(t)]^2 = 9(t+1)^2, \qquad 3T[x(t)] = 3(t+1)^2
$$

Homogeneity fails because one side scales with $a^2$ while the other side scales with $a$. Since both the additivity and homogeneity checks fail, conclude that $T[x(t)] = [x(t)]^2$ is nonlinear.
