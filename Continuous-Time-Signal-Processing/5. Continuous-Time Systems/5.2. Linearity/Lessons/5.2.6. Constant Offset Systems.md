## Introduction to Constant Offset Systems

A constant offset system is a rule of the form $T\{x(t)\}=S\{x(t)\}+c$, where $c$ is a constant added to the output. The important cue is that the offset does not depend on the input, so it stays present even when the input changes.

For linearity, you want the superposition checks to work, and you also want the zero-input, zero-output condition to hold. A constant offset is a good place to see the failure quickly because a constant term does not disappear when the input is zero.

$$
T\{0\}=S\{0\}+c
$$

$$
T\{0\}=0
$$

In the smallest nontrivial base case, $T\{x(t)\}=x(t)+3$, so setting the input to zero gives $T\{0\}=0+3=3$. The output is not zero, so the system fails the linearity test immediately.

That is the pattern to remember: an added constant output term breaks linearity right away, before you even move on to homogeneity or additivity checks.

## Checking the Zero-Input Output of a Constant Offset System

**Example:** Evaluate the zero-input output for $y(t)=x(t)+7$. Is the rule linear?

**Explanation**

The cue here is the zero-input test: set the input to $0$ and see whether the output is also $0$. For a constant-offset system, the added constant stays in the output even when the input disappears.

$$
x(t)=0
$$

$$
\begin{aligned}
T\{0\} &= 0 + 7 \\
&= 7
\end{aligned}
$$

The linearity condition requires $T\{0\}=0$, but here $T\{0\}=7$. That mismatch is enough to classify the rule as nonlinear immediately.

This is the minimum evidence you need: a nonzero output at zero input already breaks the zero-input, zero-output condition, so the system fails linearity before any further test is necessary.

## Testing Homogeneity for an Added Output Offset

**Example:** For $y(t)=2x(t)+1$, test homogeneity using input $x(t)$ scaled by $a=3$.

**Explanation**

The cue is the homogeneity test: scale the input by $a$ and compare $T\{ax(t)\}$ with $aT\{x(t)\}$. Here the constant offset should stay visible, because that is the part that does not scale with the input.

$$
T\{3x\}=2(3x(t))+1=6x(t)+1
$$

$$
3T\{x\}=3(2x(t)+1)=6x(t)+3
$$

The two expressions do not match: the scaled input gives $6x(t)+1$, but scaling the output gives $6x(t)+3$. The constant term does not scale the same way as the input, so the homogeneity condition fails.

Because $T\{3x\}\neq 3T\{x\}$, the rule is nonlinear. This is the same offset-driven failure you saw in the zero-input test, now shown through scaling.

## Testing Additivity for an Added Output Offset

**Example:** Check additivity for $y(t)=x(t)+9$ with generic inputs $x_1(t)$ and $x_2(t)$.

**Explanation**

The cue is the additivity test: compare the output from the summed input with the sum of the two separate outputs. With a constant offset, the same constant appears on each separate output, so this is where the mismatch shows up.

$$
T\{x_1+x_2\}=x_1+x_2+9
$$

$$
T\{x_1\}+T\{x_2\}=(x_1+9)+(x_2+9)=x_1+x_2+18
$$

The two sides do not match: the summed input gives $x_1+x_2+9$, but the separate outputs give $x_1+x_2+18$. The constant offset gets counted twice on the right side, so the additivity condition fails.

Because $T\{x_1+x_2\}\neq T\{x_1\}+T\{x_2\}$, the rule is nonlinear. This is the same offset-driven failure pattern you saw in the zero-input and homogeneity checks, now shown with two inputs.

## Classifying Otherwise Linear Rules with Constant Offsets

**Example:** Classify $y(t)=2x(t-1)+5$ using the superposition test framework.

**Explanation**

The cue is that this rule looks linear except for the added constant. So the right move is to test the rule as a whole and check whether the offset breaks the linearity conditions.

$$
T\{0\}=2(0)+5=5
$$

The zero-input test already fails, because a linear system must satisfy $T\{0\}=0$. Here the output is $5$, so the rule is not linear even before we look at the other superposition checks.

$$
T\{a x(t)\}=2a\,x(t-1)+5,\qquad aT\{x(t)\}=a\bigl(2x(t-1)+5\bigr)=2a\,x(t-1)+5a
$$

The homogeneity comparison shows the same problem: the constant term stays $5$ in $T\{a x(t)\}$, but it becomes $5a$ in $aT\{x(t)\}$. Since those expressions are different, homogeneity fails too.

$$
\begin{aligned}
T\{x_1(t)+x_2(t)\} &= 2\bigl(x_1(t-1)+x_2(t-1)\bigr)+5 \\
T\{x_1(t)\}+T\{x_2(t)\} &= \bigl(2x_1(t-1)+5\bigr)+\bigl(2x_2(t-1)+5\bigr) = 2x_1(t-1)+2x_2(t-1)+10
\end{aligned}
$$

The additivity check gives the same verdict: the constant appears once on the summed-input side but twice on the separate-output side. The offset is the only reason the rule fails, so the classification is nonlinear due to the added constant term.
