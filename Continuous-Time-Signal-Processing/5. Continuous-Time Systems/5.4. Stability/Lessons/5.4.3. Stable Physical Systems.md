## Introduction to Stable Physical Systems

A stable physical continuous-time system is one whose response stays finite over time when the input is bounded. The cue is not the size of the input alone; it is whether the system's own dynamics let the effect settle instead of pile up.

$$
|x(t)| \le M_x \text{ for all } t \implies |y(t)| \le M_y \text{ for all } t.
$$

In physical terms, stability comes from internal dynamics that dissipate or leak energy, so bounded input does not keep accumulating into a larger and larger response. Decay, leakage, and dissipation are the mechanisms that keep the long-run output under control.

$$
y(t)=y_{\mathrm{steady}}(t)+y_{\mathrm{transient}}(t), \qquad y_{\mathrm{transient}}(t)\to 0 \text{ as } t\to\infty
$$

When the transient decays, the response remains inside a finite envelope instead of accumulating without bound. That is the basic stability idea the next examples will use in more detailed cases.

<a id="recognizing-finite-responses-in-physical-systems"></a>
## Recognizing Finite Responses in Physical Systems

**Example:** Classify the response $y(t)=3 + 2e^{-4t}+0.1\cos(2t)$ as stable or not under bounded physical input assumptions.

**Explanation**

The cue here is a response law made from a constant offset, a decaying exponential, and a bounded oscillation. To classify the system, check whether any part can grow without bound as time advances.

$$
y(t)=3+2e^{-4t}+0.1\cos(2t)
$$

Each term stays finite: $3$ is a constant, $2e^{-4t}$ decays because the exponent is negative, and $0.1\cos(2t)$ always remains between $-0.1$ and $0.1$. None of these pieces can accumulate into unbounded growth.

$$
|y(t)| \le |3| + |2e^{-4t}| + |0.1\cos(2t)| \le 3 + 2 + 0.1 = 5.1
$$

So the response remains inside a finite envelope for all time, with the transient term decaying and the oscillation staying bounded. That is the stable physical behavior: bounded input does not turn into unbounded accumulation.

<a id="interpreting-bounded-responses-to-sustained-inputs"></a>
## Interpreting Bounded Responses to Sustained Inputs

**Example:** For $\dot y+5y=x(t)$, $y(0)=0$, and $|x(t)|\le 1$, classify whether $y(t)$ remains finite for all $t$.

**Explanation**

The cue is a first-order system with a damping term $+5y$ and a bounded input $|x(t)|\le 1$. To decide stability, write the response so the decaying natural part is separated from the forced part.

$$
y(t)=e^{-5t}y(0)+\int_0^t e^{-5(t-\tau)}x(\tau)\,d\tau
$$

Here $y(0)=0$, so the homogeneous term drops out and the response is the input filtered by a decaying kernel. Because $e^{-5(t-\tau)}$ shrinks older input instead of letting it accumulate, a bounded input cannot build into an unbounded output.

$$
|y(t)| \le \int_0^t e^{-5(t-\tau)}|x(\tau)|\,d\tau \le \int_0^t e^{-5(t-\tau)}\,d\tau = \frac{1-e^{-5t}}5 \le \frac15
$$

So $y(t)$ remains finite for all $t$ and stays inside a fixed envelope. The system is stable because its dynamics keep each bounded contribution from piling up without bound.

## Interpreting Settling Behavior After a Bounded Input Change

**Example:** For a bounded input shift producing $y(t)=2+Ce^{-3t}$, determine finite settling behavior after the change and justify with dynamics.

**Explanation**

The cue is a bounded input change whose response splits into a steady term and a transient term. To decide settling behavior, identify the long-time value and check whether the transient decays.

$$
y(t)=2+Ce^{-3t}
$$

The constant term $2$ is the finite settled level, and the transient $Ce^{-3t}$ decays because the exponent is negative. Since there is no polynomial growth term, nothing in the response can build up without bound after the input change.

$$
\lim_{t\to\infty} y(t)=2, \qquad y(t)-2=Ce^{-3t}\to 0
$$

So the response settles to a finite value after the bounded input change, and the settling comes from the decaying dynamics rather than from the initial condition alone. This is stable physical behavior: a bounded change produces a bounded transient that fades into a finite steady state.

## Identifying Dynamics That Prevent Accumulation

**Example:** Compare $y_1(t)=\int_0^t x(\tau)\,d\tau$ and $y_2(t)=\int_0^t e^{-2(t-\tau)}x(\tau)\,d\tau$ for bounded $x(t)$ and decide which prevents accumulation.

**Explanation**

The cue is two responses built from past input, but only one has a decaying memory of the past. To test accumulation, check whether older input keeps the same weight or gets suppressed with time.

$$
y_1(t)=\int_0^t x(\tau)\,d\tau, \qquad y_2(t)=\int_0^t e^{-2(t-\tau)}x(\tau)\,d\tau
$$

In $y_1$, every past input contributes equally, so bounded input can keep stacking up. In $y_2$, the factor $e^{-2(t-\tau)}$ makes older input count less, so the response does not keep full memory of the entire history.

$$
x(t)=1 \;\Rightarrow\; y_1(t)=\int_0^t 1\,d\tau=t, \qquad y_2(t)=\int_0^t e^{-2(t-\tau)}\,d\tau=\frac{1-e^{-2t}}{2}
$$

This shows the decision directly: $y_1$ is accumulation-prone because a bounded sustained input can grow without bound, while $y_2$ stays finite because the decaying kernel prevents old input from piling up. The dynamics in $y_2$ are the anti-accumulation mechanism.
