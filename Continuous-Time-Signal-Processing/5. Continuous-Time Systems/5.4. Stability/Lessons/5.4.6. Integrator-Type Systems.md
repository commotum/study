## Introduction to Integrator-Type Systems

An integrator-type system is a system whose output depends on accumulated input history rather than only on the input value at the current time. That cumulative dependence is the cue to watch for: if the output is built by adding up input over time, the system can behave very differently from a memoryless algebraic rule.

$$
y(t)=\int_0^t x(\tau)\,d\tau
$$

For the simplest base case, take a bounded constant input $x(t)=c$. This is the cleanest test because the input never grows in magnitude, so any growth in the output must come from the system rule itself rather than from the input.

$$
y(t)=\int_0^t c\,d\tau = ct
$$

Since $y(t)=ct$ grows without bound as $t$ increases whenever $c\neq 0$, this simple cumulative rule is a key BIBO stability test case. The lesson progression will keep using the same idea: identify cumulative input-output behavior, test it against a bounded input, and decide whether the output stays bounded for all time.

<a id="recognizing-a-cumulative-input-output-rule"></a>
## Recognizing a Cumulative Input-Output Rule

**Example:** For $y(t)=\int_0^t x(\tau)\,d\tau$, identify the cumulative input-output structure and state whether this is an integrator-type system.

**Explanation**

The cue is the integral from $0$ to $t$. That means the output $y(t)$ is built from the accumulated past input $x(\tau)$, not from the input value at a single instant.

$$
y(t)=\int_0^t x(\tau)\,d\tau
$$

Read this rule in words as: add up the input history from the starting time to the current time $t$. That cumulative dependence is exactly the pattern that defines the integrator-type family.

So this operator is an integrator-type system. It is the lesson's target pattern, and it sets up the later BIBO test by showing that a bounded input can still produce output growth through accumulation.

## Testing a Pure Integrator with a Bounded Constant Input

**Example:** Evaluate $y(t)=\int_0^t 1\,d\tau$ and use the result to decide BIBO stability for this system.

**Explanation**

The cue is a bounded constant input. For a pure integrator, the output adds up that constant over the interval from $0$ to $t$, so the direct test is to substitute the constant input into the cumulative rule.

$$
y(t)=\int_0^t 1\,d\tau = t
$$

The result is $y(t)=t$, which grows without bound as $t$ increases. The input stays bounded, but the accumulated output does not, so the system fails the bounded-output requirement.

So this pure integrator is not BIBO stable. This is the lesson's key growth test: a single bounded constant input can produce unbounded output when the system keeps accumulating input over time.

<a id="testing-a-scaled-integrator-type-system"></a>
## Testing a Scaled Integrator-Type System

**Example:** For $y(t)=3\int_0^t x(\tau)\,d\tau$ and bounded $x(t)=1$, compute $y(t)$ and classify BIBO stability.

**Explanation**

The cue is still cumulative input-output behavior, but now the integrator has a scalar gain of $3$. That gain changes the rate of accumulation, not the fact that the output is built from all input values from $0$ to $t$.

$$
y(t)=3\int_0^t 1\,d\tau = 3t
$$

The result is $y(t)=3t$, which still grows without bound as $t$ increases. The input is bounded, but the accumulated output is not, so the bounded-output requirement fails again.

So this scaled integrator-type system is not BIBO stable. The key point is that a nonzero gain does not repair accumulation: it only changes how fast the unbounded growth appears.

<a id="recognizing-that-one-bounded-output-does-not-prove-stability"></a>
## Recognizing That One Bounded Output Does Not Prove Stability

**Example:** Compare two inputs to $y(t)=\int_0^t x(\tau)\,d\tau$: $x_1(t)=\sin t$ and $x_2(t)=1$, then classify the system.

**Explanation**

The cue is the BIBO quantifier. To prove stability, it is not enough to find one bounded input with bounded output; every bounded input must produce a bounded output. So the right move is to test the same cumulative rule on two bounded inputs with different long-run behavior.

$$
y_1(t)=\int_0^t \sin \tau\,d\tau = 1-\cos t
$$

$$
y_2(t)=\int_0^t 1\,d\tau = t
$$

The first output is bounded, but the second grows without bound. That single counterexample is enough to reject BIBO stability, because the definition requires all bounded inputs to produce bounded outputs.

So one bounded output does not prove stability. It only shows that one test input behaved well; the system still fails if any bounded input, such as the constant input, makes the accumulated output unbounded.
