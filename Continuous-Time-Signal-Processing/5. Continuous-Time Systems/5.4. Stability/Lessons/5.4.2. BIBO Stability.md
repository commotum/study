## Introduction to BIBO Stability

A continuous-time signal is bounded when it stays within some finite magnitude limit. In this lesson, the cue to look for is a bound of the form $|x(t)| \le M$ for all $t$.

$$
|x(t)| \le M
$$

BIBO stability means that every bounded input must produce a bounded output under the system rule. The rule has to work for all bounded inputs, not just for a convenient one.

$$
\forall\, x(t)\text{ bounded},\; y(t)\text{ bounded}
$$

For the base case, start with a scalar gain rule such as $y(t)=a x(t)$. If $|x(t)| \le M$, then the output magnitude is controlled by the same finite input bound multiplied by the gain size.

$$
|y(t)| \le |a|M
$$

That is the core pattern used throughout this topic: identify a finite input bound, apply the system rule, and check that the resulting output bound is still finite. Later examples keep the same logic while adding more structure to the rule being tested.

## Finding an Output Bound from an Input Bound

**Example:** Given $|x(t)| \le 4$ and $y(t)=3x(t)$, find a valid bound for $|y(t)|$ and state whether the output is bounded.

**Explanation**

The cue is a bounded input with $|x(t)| \le 4$ and a simple scalar-gain rule $y(t)=3x(t)$. This is the base BIBO check: carry the input bound through the system rule and see whether the output stays finite.

$$
|x(t)| \le 4
$$

Apply the system rule inside an absolute value. Since $y(t)=3x(t)$, the output magnitude is $|y(t)|=|3x(t)|=3|x(t)|$.

$$
|y(t)| = |3x(t)| = 3|x(t)|
$$

Now substitute the input bound $|x(t)| \le 4$ to get $|y(t)| \le 3\cdot 4 = 12$. Because $12$ is finite, the output is bounded.

$$
|y(t)| \le 12
$$

So this simple gain rule passes the BIBO test for the given bounded input: the input bound becomes a finite output bound by multiplying by the gain size.

## Verifying BIBO Stability for Scaled and Offset System Rules

**Example:** Decide whether the system rule $y(t)=2x(t)-5$ is BIBO stable for any bounded input $x(t)$, and justify the verdict by building a bound from $|x(t)| \le M$.

**Explanation**

The cue is a bounded input with $|x(t)| \le M$ and a rule that scales the input and adds a constant offset. This is the next BIBO check: keep the same input bound and see whether the output can still be trapped by one finite constant.

$$
|x(t)| \le M
$$

Write the output magnitude directly from the system rule. Since $y(t)=2x(t)-5$, take absolute values and bound each contribution separately.

$$
|y(t)| = |2x(t)-5| \le |2x(t)| + |5| = 2|x(t)| + 5
$$

Now substitute the input bound $|x(t)| \le M$ to get $|y(t)| \le 2M+5$. Because $2M+5$ is finite whenever $M$ is finite, the output is bounded for every bounded input.

$$
|y(t)| \le 2M+5
$$

So this scaled-plus-offset rule is BIBO stable: the output bound comes from the same input bound plus a fixed finite offset, not from any special choice of input.

## Verifying BIBO Stability for Shifted-Input System Rules

**Example:** Decide whether $y(t)=x(t-3)+4x(t+1)$ is BIBO stable for any bounded input $x(t)$, and derive a bound that uses the same input bound for both shifted copies.

**Explanation**

The cue is a bounded input with $|x(t)| \le M$ and a rule that uses shifted copies of the same input. Time shifts do not change the magnitude bound, so each shifted copy is still controlled by the same finite $M$.

$$
|x(t)| \le M
$$

Write the output magnitude from the system rule and bound the shifted terms separately. Since $|x(t-3)| \le M$ and $|x(t+1)| \le M$, the output magnitude is controlled by the same input bound in both places.

$$
|y(t)| = |x(t-3)+4x(t+1)| \le |x(t-3)| + 4|x(t+1)|
$$

Substitute the common bound into each shifted copy to get $|y(t)| \le M+4M=5M$. Because $5M$ is finite whenever $M$ is finite, the output is bounded for every bounded input.

$$
|y(t)| \le 5M
$$

So this shifted-input rule is BIBO stable: the time shift changes where the signal is sampled, but it does not change the size of the bound that controls the output.

## Checking the Every Bounded Input Requirement

**Example:** Show that $y(t)=t\,x(t)$ is not BIBO stable by choosing one bounded input that makes the output unbounded.

**Explanation**

The cue is the universal requirement in the BIBO test: the system must produce a bounded output for every bounded input. To reject the rule, it is enough to find one bounded input that makes the output unbounded.

$$
|x(t)| \le 1
$$

Choose the bounded input $x(t)=1$. Substituting it into the system rule gives $y(t)=t\,x(t)=t$.

$$
y(t)=t\,x(t) \Rightarrow y(t)=t
$$

Now the output magnitude is $|y(t)|=|t|$, and that grows without bound as $|t|$ increases. So the output is not bounded for this bounded input.

$$
\lim_{|t|\to\infty}|y(t)|=\infty
$$

Therefore, the system is not BIBO stable: one bounded counterexample is enough to break the 'every bounded input' requirement.
