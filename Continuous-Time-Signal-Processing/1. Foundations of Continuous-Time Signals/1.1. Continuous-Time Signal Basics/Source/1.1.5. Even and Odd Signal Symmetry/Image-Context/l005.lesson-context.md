Generated step/example content:
Tutorial blocks:
- paragraph:
  text: Signal symmetry is tested by pairing time values. For any positive time $t$, compare the signal value at $t$ with the value at the matching negative time $-t$. The classification is about the whole signal, so the same relationship must hold for every matched pair.
- image:
  image_slot_id: section-001
- paragraph:
  text: A signal is even when each matched pair has the same value. On a graph, this looks like a mirror image across the vertical axis $t=0$. For example, if $x(1)=2$ and $x(-1)=2$, that pair supports even symmetry; the same equality must hold for all other matched pairs.
- display-math:
  latex: x(-t)=x(t)
- paragraph:
  text: A signal is odd when each matched pair has equal magnitude and opposite sign. On a graph, the left and right sides are related through the origin, not by vertical-axis mirroring. For example, if $x(1)=2$ and $x(-1)=-2$, that pair supports odd symmetry.
- display-math:
  latex: x(-t)=-x(t)
- paragraph:
  text: If a signal fails both whole-signal tests, it is neither even nor odd. One matched pair can rule out even symmetry if the two values are not equal, and one matched pair can rule out odd symmetry if the two values are not negatives of each other. Sometimes the same pair rules out both.
- display-math:
  latex: \text{neither: the signal satisfies neither } x(-t)=x(t) \text{ nor } x(-t)=-x(t) \text{ for all } t
- paragraph:
  text: Use the same routine each time: choose matching $t$ and $-t$ values, compare their signal values, then classify the signal as even, odd, or neither. The next examples apply this routine to graphs first and then to a piecewise definition.
