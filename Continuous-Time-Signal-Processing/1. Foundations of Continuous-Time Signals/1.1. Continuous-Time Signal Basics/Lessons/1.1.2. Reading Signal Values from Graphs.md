## Introduction to Reading Signal Values from Graphs

A graph of a continuous-time signal $x(t)$ shows how each time input is paired with a signal value. The horizontal coordinate is the time $t$, and the vertical coordinate is the value $x(t)$.

$$
x(t_0)=\text{the vertical value of the graph at time }t_0
$$

To read $x(t_0)$ from a graph, first find $t_0$ on the horizontal axis. Then move vertically to the signal graph. The height of the graph at that point is the value of $x(t_0)$.

![](<../Source/1.1.2. Reading Signal Values from Graphs/Images/l002-s001-te-section-001.png>)

In the image, the requested time is $t_0=2$. Moving up from $t=2$ reaches the signal at height $3$, so the signal value at that time is $3$.

$$
x(2)=3
$$

The answer to $x(t_0)$ is the vertical value, not the time label. The time tells where to look on the graph; the height tells the signal value to report.

## Reading a Signal Value at a Marked Time

**Example:** Use the graph of $x(t)$ to find $x(2)$.

**Explanation**

![](<../Source/1.1.2. Reading Signal Values from Graphs/Images/l002-s002-te-section-002.png>)

The notation $x(2)$ tells us to look at the signal when the time input is $t=2$. On the graph, start by locating $2$ on the horizontal axis.

From $t=2$, move vertically until you reach the plotted signal. The signal point at that time is on the grid line with vertical value $4$.

$$
x(2)=4
$$

So the value of the signal at time $2$ is $4$. The answer is the vertical value of the graph, not the horizontal time coordinate.

## Reading a Signal Value Between Marked Times

**Example:** Use the graph of $x(t)$ to find $x(1.5)$.

**Explanation**

![](<../Source/1.1.2. Reading Signal Values from Graphs/Images/l002-s003-te-section-003.png>)

The requested time is $t=1.5$. This time is not one of the labeled integer ticks, so first find it halfway between $t=1$ and $t=2$ on the horizontal axis.

Now use the same read-off procedure as before: move vertically from $t=1.5$ to the plotted signal. The point on the graph at that time has vertical coordinate $3$.

$$
x(1.5)=3
$$

Even when the time lies between marked ticks, the signal value is still the graph's height at that exact time.

## Reading a Signal Value at an Endpoint or Breakpoint

**Example:** Use the graph of $x(t)$ to find $x(1)$ at the breakpoint.

**Explanation**

![](<../Source/1.1.2. Reading Signal Values from Graphs/Images/l002-s004-te-section-004.png>)

The requested time is $t=1$, where the graph has a breakpoint. At a breakpoint, use the plotted point that is included in the signal value.

At $t=1$, the open circle is at height $3$, but an open circle is not included. The closed dot is at height $-1$, so that closed dot gives the actual signal value at $t=1$.

$$
x(1)=-1
$$

So the signal value at the breakpoint is the vertical coordinate of the closed dot, not the nearby open circle or neighboring segment.

## Reading a Zero Signal Value from the Time Axis

**Example:** Use the graph of $x(t)$ to find $x(3)$ when the graph is on the time axis at $t=3$.

**Explanation**

![](<../Source/1.1.2. Reading Signal Values from Graphs/Images/l002-s005-te-section-005.png>)

The requested time is $t=3$. Locate $3$ on the horizontal axis, then look at the plotted signal at that same time.

At $t=3$, the graph lies on the horizontal time axis. Points on the horizontal time axis have vertical coordinate $0$.

$$
x(3)=0
$$

So the signal value at time $3$ is $0$. The nearby nonzero parts of the graph do not change the value at the requested time.
