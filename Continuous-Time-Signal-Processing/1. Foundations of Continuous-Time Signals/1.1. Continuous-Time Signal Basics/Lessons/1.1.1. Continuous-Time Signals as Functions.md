## Introduction to Continuous-Time Signals as Functions

A continuous-time signal is a function of time. The input is a time instant $t$, and the output is the signal value at that time, written $x(t)$.

The phrase continuous-time means that $t$ can be any real-valued time, not just a whole-number time step. Times such as $0$, $3$, $-1.5$, and $\frac{1}{2}$ are all possible inputs.

The function viewpoint is the basic rule to recognize: a time input gets mapped to a signal value.

$$
t \mapsto x(t)
$$

To use a signal rule, choose a time, substitute that time for $t$, and interpret the result as the value of the signal at that instant. For example, if $x(t)=2t+1$, then choosing $t=3$ gives one specific signal value.

$$
\begin{aligned}
x(t) &= 2t+1 \\
x(3) &= 2(3)+1 \\
&= 7
\end{aligned}
$$

So $x(3)=7$ means that the signal assigns the value $7$ to the time $3$. This same input-output viewpoint is the foundation for reading signal graphs, piecewise rules, support, symmetry, and basic signal parameters later.

## Interpreting $x(t)$ as a Time-to-Value Rule

**Example:** For the statement $x(2)=5$, identify the time input and the signal value.

**Explanation**

The cue is the function notation $x(2)$. In signal notation, the number inside the parentheses is the time input.

$$
x(\text{time input}) = \text{signal value at that time}
$$

So in $x(2)=5$, the input time is $2$. The number after the equals sign is the output of the signal at that time, so the signal value is $5$.

$$
x(2)=5 \quad \Longrightarrow \quad 2 \mapsto 5
$$

The statement means that time $2$ maps to signal value $5$. No computation is needed here; the task is to read the input and output from the notation.

## Finding $x(t_0)$ at a Specific Time

**Example:** Let $x(t)=3t-2$. Find $x(4)$.

**Explanation**

The cue is the requested value $x(4)$. This means the time input is $4$, so we use the rule $x(t)=3t-2$ with $t=4$.

Substitute $4$ for every $t$ in the signal rule, then simplify.

$$
\begin{aligned}
x(4) &= 3(4)-2 \\
&= 12-2 \\
&= 10
\end{aligned}
$$

So the signal value at time $4$ is $10$. In time-to-value language, the rule maps $4$ to $10$.

$$
4 \mapsto 10
$$

## Evaluating a Signal at Non-Integer Times

**Example:** Let $x(t)=4t+1$. Find $x\left(\frac{1}{2}\right)$.

**Explanation**

The cue is the requested value $x\left(\frac{1}{2}\right)$. The time input is $\frac{1}{2}$, which is still a valid continuous-time input.

Use the same substitution move as before: replace every $t$ in the rule with the entire fractional input $\frac{1}{2}$.

$$
\begin{aligned}
x\left(\frac{1}{2}\right) &= 4\left(\frac{1}{2}\right)+1 \\
&= 2+1 \\
&= 3
\end{aligned}
$$

So the signal value at time $\frac{1}{2}$ is $3$. The non-integer input changes the arithmetic, but it does not change the function viewpoint.

$$
\frac{1}{2} \mapsto 3
$$

## Reading a Signal Rule Over All Real Time

**Example:** For $x(t)=t^2-1$, describe what the rule assigns to an arbitrary time $t$, then find $x(-1)$, $x(0)$, and $x(2)$.

**Explanation**

The cue is the formula $x(t)=t^2-1$. This is not just one value; it is a rule that takes any real time $t$ and returns the signal value $t^2-1$.

$$
t \mapsto t^2-1
$$

To find the requested signal values, use the same substitution move for each time input.

$$
\begin{aligned}
x(-1) &= (-1)^2-1 = 0 \\
x(0) &= 0^2-1 = -1 \\
x(2) &= 2^2-1 = 3
\end{aligned}
$$

So the rule assigns $0$ to time $-1$, $-1$ to time $0$, and $3$ to time $2$.

$$
-1 \mapsto 0, \quad 0 \mapsto -1, \quad 2 \mapsto 3
$$

These are individual values from one complete signal rule. The formula $x(t)=t^2-1$ defines the signal over real time, and each substitution reads one time-to-value pair from that rule.
