## Introduction to Sums of Periodic Signals

For a sum $x(t)=x_1(t)+x_2(t)$, the key question is whether one positive shift $T$ repeats the whole sum, not whether each component is periodic in isolation.

In the base case, start with two components that already share the same positive period $T$. That is the simplest situation because the same shift can be tested against both components at once.

$$
x_1(t+T)=x_1(t)
$$

$$
x_2(t+T)=x_2(t)
$$

If both components satisfy those equalities for the same $T$, then the sum satisfies $x(t+T)=x(t)$ as well, because each term returns to itself under the same shift.

When the component periods differ, do not reuse one component period automatically. Later examples will search for a common repeating time by comparing periods directly, then angular frequencies and harmonic relationships, and they will also show cases where no shared repeat exists.

That shared-shift idea is the only tool this introduction needs: if a single positive shift repeats every component, it repeats the sum, and the rest of the lesson asks how to find or rule out that shared shift.

## Sums of Signals with the Same Period

**Example:** Determine whether $x(t)=\cos(2\pi t)+\sin(2\pi t+\pi/3)$ is periodic and, if so, identify a repeating period.

**Explanation**

The cue here is that both terms already repeat after the same positive shift. Because the coefficient of $t$ is $2\pi$ in each component, each signal has period $T=1$.

$$
x_1(t+1)=\cos\bigl(2\pi(t+1)\bigr)=\cos(2\pi t+2\pi)=\cos(2\pi t)=x_1(t)
$$

$$
x_2(t+1)=\sin\bigl(2\pi(t+1)+\pi/3\bigr)=\sin(2\pi t+2\pi+\pi/3)=\sin(2\pi t+\pi/3)=x_2(t)
$$

Since both components return to themselves after the same shift, the sum does too: $x(t+1)=x_1(t+1)+x_2(t+1)=x_1(t)+x_2(t)=x(t)$.

So $x(t)$ is periodic, and one repeating period is $T=1$. The key point is that the shared period belongs to the whole sum because it belongs to every component.

## Finding a Common Period from Component Periods

**Example:** Determine whether $x(t)=\cos(\pi t)+\sin(2\pi t/3)$ is periodic and, if so, find a repeating period.

**Explanation**

The cue here is that the component periods are different, so the goal is to find a common positive shift that repeats both terms at once. From the coefficients of $t$, $x_1(t)=\cos(\pi t)$ has period $2$ and $x_2(t)=\sin(2\pi t/3)$ has period $3$.

$$
T_1=\frac{2\pi}{\pi}=2,\qquad T_2=\frac{2\pi}{2\pi/3}=3
$$

The first shared repeat time is the least common multiple of $2$ and $3$, so $T=6$. That is the smallest positive shift that can repeat both components together.

$$
x_1(t+6)=\cos\bigl(\pi(t+6)\bigr)=\cos(\pi t+6\pi)=\cos(\pi t)=x_1(t)
$$

$$
x_2(t+6)=\sin\bigl(\tfrac{2\pi}{3}(t+6)\bigr)=\sin\bigl(\tfrac{2\pi}{3}t+4\pi\bigr)=\sin\bigl(\tfrac{2\pi}{3}t\bigr)=x_2(t)
$$

Since both components return to their original values after $6$, the sum does too: $x(t+6)=x_1(t+6)+x_2(t+6)=x_1(t)+x_2(t)=x(t)$. So $x(t)$ is periodic, and one repeating period is $T=6$; any larger common multiple also works, but $6$ is the least shared repeat.

## Finding a Common Period from Component Angular Frequencies

**Example:** Determine whether $x(t)=\cos(4t)+\sin(6t-\pi/4)$ is periodic and, if so, find a repeating period.

**Explanation**

The cue is that both coefficients of $t$ are multiples of a smaller angular frequency. Here $4=2\cdot 2$ and $6=3\cdot 2$, so both components are harmonics of $2$ rad/s.

$$
4=2\cdot 2,\qquad 6=3\cdot 2
$$

A shared base angular frequency of $2$ rad/s corresponds to period $T=\frac{2\pi}{2}=\pi$. So $\pi$ is the candidate repeat for the sum.

$$
\begin{aligned}
\cos\bigl(4(t+\pi)\bigr) &= \cos(4t+4\pi) = \cos(4t),\\
\sin\bigl(6(t+\pi)-\pi/4\bigr) &= \sin(6t-\pi/4+6\pi) = \sin(6t-\pi/4)
\end{aligned}
$$

Because both terms return to themselves after the same shift, the sum does too: $x(t+\pi)=x_1(t+\pi)+x_2(t+\pi)=x_1(t)+x_2(t)=x(t)$. So $x(t)$ is periodic, and one repeating period is $T=\pi$.

## Recognizing Sums with No Shared Repeating Time

**Example:** Determine whether $x(t)=\cos(t)+\cos(\sqrt{2}t)$ is periodic.

**Explanation**

The cue is that each term is periodic on its own, so the test is whether they share a positive repeat time. From the angular frequencies, $x_1(t)=\cos(t)$ has period $T_1=2\pi$ and $x_2(t)=\cos(\sqrt{2}t)$ has period $T_2=\frac{2\pi}{\sqrt{2}}=\sqrt{2}\pi$.

$$
T_1=2\pi,\qquad T_2=\sqrt{2}\pi
$$

The ratio $T_1/T_2=\sqrt{2}$ is irrational. An exact common repeat would have to be a common positive multiple of both periods, so it would require integers $m$ and $n$ with $2\pi m=\sqrt{2}\pi n$.

$$
2\pi m=\sqrt{2}\pi n \quad \Rightarrow \quad 2m=\sqrt{2}\,n
$$

That would force $\sqrt{2}=2m/n$, a rational number, which is impossible. So no positive common shift exists, and $x(t)$ is not periodic.
