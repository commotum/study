## Introduction to Determining the Overlap Interval

In the previous lessons, you found the support of $x(\tau)$ and the support of $h(t-\tau)$ separately. The next move is to combine those two support intervals in the convolution variable $\tau$.

The product $x(\tau)h(t-\tau)$ can be nonzero only at values of $\tau$ where both factors are nonzero at the same time. That common set of $\tau$ values is called the overlap interval.

$$
x(\tau)h(t-\tau) \ne 0 \quad \text{only where} \quad \tau \in \operatorname{supp} x(\tau) \cap \operatorname{supp} h(t-\tau).
$$

For example, suppose $x(\tau)$ is nonzero on $0\le \tau\le 2$, and $h(t-\tau)$ is nonzero on $t-3\le \tau\le t-1$. While finding overlap, treat $t$ as fixed and decide which $\tau$ values satisfy both interval conditions.

In general, the left endpoint of the overlap comes from the larger lower endpoint, and the right endpoint comes from the smaller upper endpoint.

$$
\text{If the supports are } [a,b] \text{ and } [c(t),d(t)], \text{ then overlap is } [\max(a,c(t)),\min(b,d(t))].
$$

Later sections will compare these endpoints to find the actual overlap interval in each time region. For now, the key rule is: overlap means the intersection of the fixed support of $x(\tau)$ and the moving support of $h(t-\tau)$, with $t$ held fixed.

<a id="intersecting-supports-for-one-fixed-t"></a>
## Intersecting Supports for One Fixed $t$

**Example:** Suppose $x(\tau)$ is nonzero on $0 \le \tau \le 4$ and $h(t-\tau)$ is nonzero on $t-3 \le \tau \le t-1$. Determine the overlap interval when $t=5$.

**Explanation**

The cue is the fixed value $t=5$. First substitute that value into the moving support interval for $h(t-\tau)$.

$$
t-3 \le \tau \le t-1 \quad\Rightarrow\quad 5-3 \le \tau \le 5-1
$$

$$
2 \le \tau \le 4
$$

Now compare this moving support with the fixed support of $x(\tau)$.

$$
\operatorname{supp} x(\tau): 0 \le \tau \le 4, \qquad \operatorname{supp} h(5-\tau): 2 \le \tau \le 4
$$

The overlap interval must satisfy both support conditions. Use the larger lower endpoint and the smaller upper endpoint.

$$
\max(0,2) \le \tau \le \min(4,4)
$$

$$
2 \le \tau \le 4
$$

Since the lower endpoint $2$ is not greater than the upper endpoint $4$, the interval is nonempty. The overlap interval when $t=5$ is $2 \le \tau \le 4$.

<a id="writing-overlap-with-lower-and-upper-endpoint-rules"></a>
## Writing Overlap with Lower and Upper Endpoint Rules

**Example:** Suppose $x(\tau)$ is nonzero on $0 \le \tau \le 4$ and $h(t-\tau)$ is nonzero on $t-3 \le \tau \le t-1$. Write the overlap interval using lower- and upper-endpoint rules.

**Explanation**

The cue is that no numerical value of $t$ is given. Instead of substituting for $t$, keep the endpoints symbolic and use the endpoint rule for intersecting intervals.

$$
\operatorname{supp} x(\tau): 0 \le \tau \le 4, \qquad \operatorname{supp} h(t-\tau): t-3 \le \tau \le t-1
$$

The lower endpoint of the overlap must be at least as large as both lower endpoints. The two lower endpoints are $0$ and $t-3$, so the overlap starts at their maximum.

$$
L(t)=\max(0,t-3)
$$

The upper endpoint of the overlap must be no larger than both upper endpoints. The two upper endpoints are $4$ and $t-1$, so the overlap ends at their minimum.

$$
U(t)=\min(4,t-1)
$$

Therefore, the symbolic overlap interval is written by placing the maximum lower endpoint on the left and the minimum upper endpoint on the right.

$$
\max(0,t-3) \le \tau \le \min(4,t-1)
$$

This endpoint-rule interval applies on values of $t$ where the lower endpoint is not greater than the upper endpoint. Do not split it into cases yet; the goal here is only to record the overlap in max/min form.

<a id="finding-the-t-values-where-endpoint-order-changes"></a>
## Finding the $t$ Values Where Endpoint Order Changes

**Example:** For the endpoint-rule overlap $\max(0,t-3) \le \tau \le \min(4,t-1)$, find the $t$ values where the lower endpoint choice or upper endpoint choice can change.

**Explanation**

The cue is the endpoint-rule form. A chosen endpoint can change only when the two expressions competing inside the same $\max$ or $\min$ become equal.

$$
\max(0,t-3) \le \tau \le \min(4,t-1)
$$

For the lower endpoint, the competing expressions inside the maximum are $0$ and $t-3$. Set them equal to find where the lower endpoint choice can switch.

$$
0=t-3 \quad\Rightarrow\quad t=3
$$

For the upper endpoint, the competing expressions inside the minimum are $4$ and $t-1$. Set them equal to find where the upper endpoint choice can switch.

$$
4=t-1 \quad\Rightarrow\quad t=5
$$

List the switch values in increasing order. These are only the possible endpoint-change values; they are not yet a full piecewise overlap description.

$$
\text{critical } t\text{-values: } 3,\ 5
$$

## Determining Overlap Intervals Across Time Regions

**Example:** For the active overlap range $1 \le t \le 7$, suppose the endpoint-rule overlap is $\max(0,t-3) \le \tau \le \min(4,t-1)$. Determine the overlap interval in each time region where the endpoint formulas differ.

**Explanation**

The cue is the active overlap range together with the endpoint-rule expression. The endpoint choices can change at $t=3$ and $t=5$, so use those values to split the active range.

$$
1 \le t \le 3, \qquad 3 \le t \le 5, \qquad 5 \le t \le 7
$$

On the first region, $1\le t\le 3$. The larger lower endpoint is $0$ because $t-3\le 0$, and the smaller upper endpoint is $t-1$ because $t-1\le 4$.

$$
1\le t\le 3: \qquad 0 \le \tau \le t-1
$$

On the middle region, $3\le t\le 5$. Now $t-3$ is the larger lower endpoint, while $t-1$ is still the smaller upper endpoint.

$$
3\le t\le 5: \qquad t-3 \le \tau \le t-1
$$

On the final region, $5\le t\le 7$. The lower endpoint remains $t-3$, but the smaller upper endpoint is now $4$ because $4\le t-1$.

$$
5\le t\le 7: \qquad t-3 \le \tau \le 4
$$

These intervals describe where $x(\tau)h(t-\tau)$ can be nonzero in each time region. They are overlap intervals only; setting integral bounds and evaluating the convolution come later.

```quiz

content: |-
  For the active overlap range $-2 \le t \le 7$, suppose the endpoint-rule overlap is $\max(-1,t-4) \le \tau \le \min(3,t+1)$. Determine the overlap interval in each time region where the endpoint formulas differ.

correct: |-
  For $-2 \le t \le 2$: $-1 \le \tau \le t+1$; for $2 \le t \le 3$: $-1 \le \tau \le 3$; for $3 \le t \le 7$: $t-4 \le \tau \le 3$.

feedback: |-
  The endpoint choices can change when $-1=t-4$, giving $t=3$, and when $3=t+1$, giving $t=2$. These values split the active range into three regions.

  $$
  -2 \le t \le 2, \qquad 2 \le t \le 3, \qquad 3 \le t \le 7
  $$

  $$
  \begin{aligned}
  -2 \le t \le 2 &: \quad -1 \le \tau \le t+1 \\
  2 \le t \le 3 &: \quad -1 \le \tau \le 3 \\
  3 \le t \le 7 &: \quad t-4 \le \tau \le 3
  \end{aligned}
  $$
```
