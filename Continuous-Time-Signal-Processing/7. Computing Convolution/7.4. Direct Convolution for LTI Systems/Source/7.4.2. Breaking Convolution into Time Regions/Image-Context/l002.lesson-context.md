Generated step/example content:
Tutorial blocks:
- paragraph:
  text: A direct convolution is split into time regions because the tau-values that contribute to the integral change as t changes. For a fixed output time t, only tau-values where both factors are nonzero can affect y(t).
- display-math:
  latex: y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
- paragraph:
  text: In the simplest finite-support case, x(\tau) gives a fixed support constraint on the tau-axis. If x(\tau) is nonzero on [a,b], then those endpoints do not move as t changes.
- display-math:
  latex: x(\tau)\neq 0 \text{ on } [a,b]
- paragraph:
  text: The other factor, h(t - \tau), creates the moving support constraint. If h is nonzero on [c,d] in its own input variable, then h(t - \tau) is nonzero on the tau-interval [t - d, t - c].
- display-math:
  latex: h(t-\tau)\neq 0 \text{ on } [t-d,t-c]
- image:
  image_slot_id: section-001
- paragraph:
  text: So the useful tau-values are exactly the overlap of the fixed support interval and the moving support interval. When that overlap changes, the integration bounds must change too.
- display-math:
  latex: \text{overlap in }\tau=[a,b]\cap[t-d,t-c]
- paragraph:
  text: A contact time is a t-value where an endpoint of the moving interval [t - d, t - c] lines up with an endpoint of the fixed interval [a,b]. These contact times are the breakpoints for the convolution calculation.
- paragraph:
  text: The open intervals between consecutive contact times are the time regions. Inside one such region, the overlap pattern stays the same, so the same kind of tau-bounds applies throughout that region.
- paragraph:
  text: The routine for this lesson is to find the contact times, order them on the t-axis, decide which regions have overlap, and then write the tau integration bounds for each overlap region.
