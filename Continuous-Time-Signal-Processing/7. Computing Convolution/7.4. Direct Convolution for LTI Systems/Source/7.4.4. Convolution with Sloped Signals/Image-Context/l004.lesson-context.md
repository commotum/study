Generated step/example content:
Tutorial blocks:
- paragraph:
  text: For an LTI system, direct convolution still starts with the same integral. The output time t is held fixed, and tau is the variable that moves through the overlap between x(tau) and h(t - tau).
- display-math:
  latex: y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
- image:
  image_slot_id: section-001
- paragraph:
  text: With rectangular pulses, the product is often constant on the overlap, so the main work is finding the overlap length. With a sloped segment, the signal value changes as tau changes. That means the integrand must use the actual formula for the overlapping signal piece.
- paragraph:
  text: In the simplest case, let the input piece be a ramp and let the shifted impulse-response piece be constant on the overlap.
- display-math:
  latex: x(\tau)=\tau \text{ on } 0\le \tau\le 1,\qquad h(t-\tau)=1 \text{ on } t-1\le \tau\le t
- paragraph:
  text: Only tau-values inside both active intervals contribute to the integral. If a(t) is the lower overlap bound and b(t) is the upper overlap bound, the one-region setup uses the ramp value tau throughout that overlap.
- display-math:
  latex: y(t)=\int_{a(t)}^{b(t)} \tau\cdot 1\,d\tau=\int_{a(t)}^{b(t)}\tau\,d\tau
- paragraph:
  text: So the recurring workflow for sloped convolution is: write each overlapping piece as a function of tau, find the time-dependent overlap bounds, integrate the product over that interval, and then place the result in the correct piece of y(t).
