## Introduction to Interpreting Causal Convolution

In causal convolution, the object to watch is the shifted impulse response $h(t - \tau)$. The output time t is fixed, and $\tau$ is the variable that scans through input time values.

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
$$

A causal impulse response is zero before its input time. For the base case, you can think of a causal exponential such as $h(s)=e$^{-as}$u(s)$ with $a>0$. The important point is the support rule: $h(s)$ is zero when $s<0$.

$$
h(s)=0\text{ for }s<0,\quad \text{so }h(t-\tau)=0\text{ when }t-\tau<0
$$

Now apply that rule to the shifted argument $s=t-\tau$. The shifted response $h(t - \tau)$ can be nonzero only when t - $\tau$ is not negative.

$$
t-\tau\ge 0\Longleftrightarrow \tau\le t
$$

![](<../Source/7.3.6. Interpreting Causal Convolution/Images/l006-s001-te-section-001.png>)

The inequality $\tau \le t$ is the causal cutoff. Values $x(\tau)$ with $\tau \le t$ are present or past input values relative to the output time t. Values with $\tau > t$ are future input values, so a causal LTI system cannot use them to form $y(t)$.

$$
y(t)=\int_{-\infty}^{t}x(\tau)h(t-\tau)\,d\tau
$$

This causal form is only the first support restriction. If $x(\tau)$ is zero on part of the past region, those values still do not contribute. The actual contribution comes from the overlap where $x(\tau)$ and $h(t - \tau)$ are both nonzero.

The interpretation to carry forward is this: causal convolution accumulates weighted past input. At time $t$, each allowed input value $x(\tau)$ is multiplied by the shifted impulse-response weight $h(t - \tau)$, and the integral adds those weighted contributions.

## Identifying Past Input Values at a Fixed Output Time

**Example:** For a causal LTI system, identify which input values $x(\tau)$ can contribute to $y(3)$.

**Explanation**

The cue is that the system is causal. For a causal impulse response, $h(t - \tau)$ can be nonzero only when the input time $\tau$ is not after the output time $t$.

$$
h(t-\tau)\text{ can be nonzero only when }\tau\le t
$$

Here the output time is $t=3$, so substitute $3$ for $t$ in the causal condition.

$$
\tau\le t\quad\Longrightarrow\quad \tau\le 3
$$

So the possible contributing input values are $x(\tau)$ with $\tau \le 3$. This includes the present input value at $\tau=3$ and all earlier input times.

$$
\text{Possible contributors to }y(3):\quad x(\tau)\text{ with }\tau\le 3
$$

Input values with $\tau > 3$ are future values relative to $y(3)$, so they cannot contribute in a causal LTI system.

## Reading Causal Overlap Bounds from One-Sided Supports

**Example:** For $x(\tau)$ nonzero on $0 \le \tau \le 4$ and causal $h(t - \tau)$, determine the overlap bounds when $0 \le t \le 4$.

**Explanation**

The cue is that there are now two support restrictions. The active overlap is the set of $\tau$-values where both $x(\tau)$ and $h(t - \tau)$ can be nonzero.

The input support gives the first restriction.

$$
0\le \tau\le 4
$$

Because $h(t - \tau)$ is causal, the shifted impulse response can be nonzero only for present and past input times.

$$
\tau\le t
$$

Now use the given time region, $0 \le t \le 4$. In this region, t lies inside the input support, so the upper overlap limit comes from the causal cutoff $\tau \le t$, not from the endpoint $\tau=4$.

$$
\{0\le \tau\le 4\}\cap\{\tau\le t\}=\{0\le \tau\le t\},\quad 0\le t\le 4
$$

Therefore, the overlap bounds are $0 \le \tau \le t$. These are the input values inside the one-sided input support that are also visible to the causal impulse response at time t.

$$
\text{Overlap bounds:}\quad 0\le \tau\le t
$$

## Interpreting the Shifted Impulse Response as a Weighting Function

**Example:** For $h(t) = e^{-2t}u(t)$, interpret $h(5 - \tau)$ as a weighting function on $x(\tau)$.

**Explanation**

The cue is the shifted impulse-response factor in the product $x(\tau)h(5 - \tau)$. This factor is the weight applied to each input value $x(\tau)$ when the output time is $t=5$.

Substitute $5 - \tau$ into the impulse response expression.

$$
h(5-\tau)=e^{-2(5-\tau)}u(5-\tau)
$$

The unit step decides where this weight can be nonzero. Since $u(5 - \tau)$ is on when $5 - \tau \ge 0$, only $\tau$-values with $\tau \le 5$ can receive a nonzero weight.

$$
5-\tau\ge 0\quad\Longleftrightarrow\quad \tau\le 5
$$

So the shifted impulse response acts like this weighting function over input time.

$$
h(5-\tau)=\begin{cases}e^{-2(5-\tau)}, & \tau\le 5\\0, & \tau>5\end{cases}
$$

For each allowed past input value, $x(\tau)$ is multiplied by $e^{-2(5 - \tau)}$. Inputs closer to $\tau=5$ receive a larger weight, while farther-past inputs receive a smaller exponential weight.

$$
x(\tau)h(5-\tau)=x(\tau)e^{-2(5-\tau)}\quad\text{for }\tau\le 5
$$

Values with $\tau > 5$ are future values relative to $y(5)$, so $h(5 - \tau)=0$ there and those input values receive weight zero.

<a id="recognizing-zero-output-from-no-past-overlap"></a>
## Recognizing Zero Output from No Past Overlap

**Example:** If $x(\tau)$ is nonzero only for $2 \le \tau \le 5$ and $h$ is causal, determine whether $y(t)$ is zero for $t < 2$.

**Explanation**

The cue is the time region $t < 2$, which is before the input support begins. Use the same support-intersection test, but look for whether any overlap exists at all.

The input is nonzero only on this $\tau$-interval.

$$
2\le \tau\le 5
$$

Because $h$ is causal, $h(t - \tau)$ can be nonzero only for input times in the causal past of $t$.

$$
\tau\le t
$$

Now apply the region $t < 2$. If $\tau \le t$ and $t < 2$, then $\tau$ is less than $2$, so those past input times are entirely before the nonzero input support starts.

$$
\{2\le \tau\le 5\}\cap\{\tau\le t\}=\varnothing,\quad t<2
$$

There is no $\tau$-value where both $x(\tau)$ and $h(t - \tau)$ can be nonzero. The product inside the convolution integral is therefore zero for every $\tau$ in this time region.

$$
x(\tau)h(t-\tau)=0\quad\text{for every }\tau,\quad t<2
$$

So the convolution output is zero for $t < 2$. A causal system cannot respond before any nonzero input value has entered its past.

$$
y(t)=0,\quad t<2
$$

<a id="explaining-output-as-accumulated-weighted-past-input"></a>
## Explaining Output as Accumulated Weighted Past Input

**Example:** Explain what $y(4) = \int_0^4 x(\tau)e^{-2(4 - \tau)}\,d\tau$ means for a causal convolution with input support starting at $\tau = 0$.

**Explanation**

The cue is that the expression is already written as a causal convolution value at one fixed output time. The fixed output time is $t=4$.

$$
y(4)=\int_0^4 x(\tau)e^{-2(4-\tau)}\,d\tau
$$

The integration interval gives the contributing input times. Since the input support starts at $\tau=0$ and the system is causal, $y(4)$ uses input values from $\tau=0$ through the present time $\tau=4$.

$$
0\le \tau\le 4
$$

The factor multiplying $x(\tau)$ is the shifted impulse-response weight. For each contributing $\tau$-value, $x(\tau)$ is multiplied by $e^{-2(4 - \tau)}$.

$$
\text{weight on }x(\tau):\quad e^{-2(4-\tau)}
$$

The integral then adds all of those weighted input contributions over the overlap interval. It is not just one input value and it is not unweighted area under $x(\tau)$.

$$
y(4)=\int_0^4 \bigl[\text{input value at }\tau\bigr]\bigl[\text{weight from }h(4-\tau)\bigr]\,d\tau
$$

So $y(4)$ means the accumulated weighted past input from $\tau=0$ to $\tau=4$. No $\tau > 4$ input values appear, because those values are future values relative to the output time $t=4$.
