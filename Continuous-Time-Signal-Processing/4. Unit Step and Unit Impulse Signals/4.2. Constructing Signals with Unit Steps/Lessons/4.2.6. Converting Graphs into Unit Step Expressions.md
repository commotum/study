## Introduction to Converting Graphs into Unit Step Expressions

A graph is ready to convert when you can read its breakpoints first. The breakpoints tell you where the signal turns on, stays active, and turns off, so those times become the shifted step arguments in the expression.

![](<../Source/4.2.6. Converting Graphs into Unit Step Expressions/Images/l006-s001-te-section-001.png>)

For one finite interval, write a unit-step window as the difference of two shifted steps. The window is 1 on the active interval and 0 everywhere else, so it gates the signal to that segment only.

$$
x(t)=A\big(u(t-a)-u(t-b)\big)
$$

In the simplest pulse case, the active interval is $0 \le t < T$, so the same rule becomes $x(t)=A\big(u(t)-u(t-T)\big)$. This is the base pattern you will reuse whenever a graph has one nonzero interval.

$$
x(t)=\sum_k f_k\big[u(t-a_k)-u(t-b_k)\big]
$$

For more complicated graphs, attach each interval formula to its own window, then combine the terms and simplify. The next steps will follow that same sequence: read the intervals, write each gated segment, and merge the result into one compact step expression.

## Identifying Breakpoints and Interval Formulas from a Graph

**Example:** Read the displayed graph and write the ordered breakpoint list together with the interval formula table $\{(t_0,t_1]: f_1, (t_1,t_2]: f_2, \dots\}$.

**Explanation**

Start by reading the breakpoints in the graph. In this example, the signal changes at $t=-2$, $t=0$, $t=3$, and $t=5$, so those four times determine the ordered interval map.

![](<../Source/4.2.6. Converting Graphs into Unit Step Expressions/Images/l006-s002-te-section-002.png>)

Now assign one formula to each region between neighboring breakpoints. Here the graph is piecewise constant, so each interval keeps the height shown on the plot, and the breakpoint convention places each change point on the interval to its right.

$$
t_0=-2,\quad t_1=0,\quad t_2=3,\quad t_3=5
$$

$$
x(t)=0 \text{ for } t<-2,\; 2 \text{ for } -2\le t<0,\; -1 \text{ for } 0\le t<3,\; 3 \text{ for } 3\le t<5,\; 0 \text{ for } t\ge 5
$$

That ordered breakpoint list and interval table are the complete input for the next conversion step. Keep the boundaries and interval values aligned exactly as shown, because the step-term rewrite will reuse this map directly.

## Converting a Single Nonzero Graph Segment into a Step Window Term

**Example:** Convert the graph with $x(t)=A$ for $a\le t<b$ and $x(t)=0$ elsewhere into a step form.

**Explanation**

The cue is a single nonzero interval with constant height $A$: the graph is zero before $a$, stays at $A$ on $a\le t<b$, and returns to zero after $b$. That means one window term is enough; the job is to gate the amplitude with the two breakpoints.

![](<../Source/4.2.6. Converting Graphs into Unit Step Expressions/Images/l006-s003-te-section-003.png>)

Use the standard window difference. $u(t-a)$ turns the signal on at $a$, and $u(t-b)$ turns it back off at $b$, so $u(t-a)-u(t-b)$ is 1 exactly on the active interval and 0 elsewhere.

$$
x(t)=A\big(u(t-a)-u(t-b)\big)
$$

Check the three regions in order. For $t<a$, both steps are 0. For $a\le t<b$, the first step is 1 and the second is 0. For $t\ge b$, both steps are 1, so the difference returns to 0. That verifies the exact single-window template for one isolated segment.

## Converting a Piecewise Constant Graph into Shifted Unit Steps

**Example:** Convert the graph $0\to A\to B\to 0$ over two intervals to a unit-step sum.

**Explanation**

The cue is a piecewise constant graph with two nonzero plateaus. Read the levels and breakpoints first: the signal is $A$ on $a\le t<b$, then $B$ on $b\le t<c$, and zero outside those intervals.

![](<../Source/4.2.6. Converting Graphs into Unit Step Expressions/Images/l006-s004-te-section-004.png>)

Write one shifted window for each plateau. The interval $a\le t<b$ is isolated by $u(t-a)-u(t-b)$, and the interval $b\le t<c$ is isolated by $u(t-b)-u(t-c)$; scaling each window by its plateau height gives the full signal.

$$
x(t)=A\big(u(t-a)-u(t-b)\big)+B\big(u(t-b)-u(t-c)\big)
$$

Check the result interval by interval. Before $a$ both windows are off; on $a\le t<b$ only the first term contributes; on $b\le t<c$ only the second term contributes; after $c$ both terms are off again. The signs stay attached to the plateau heights, so the step sum matches the graph exactly.

## Converting a Piecewise Linear Graph into Windowed Segment Formulas

**Example:** Convert the graph with $x(t)=t$ for $0\le t<2$, $x(t)=4-t$ for $2\le t<4$, and $x(t)=0$ elsewhere into a sum of windowed segment formulas.

**Explanation**

The cue is two linear pieces, not one constant plateau. Read each segment formula first: the signal rises like $t$ on $0\le t<2$ and falls like $4-t$ on $2\le t<4$. Then attach a gate that keeps each formula active only on its own interval.

![](<../Source/4.2.6. Converting Graphs into Unit Step Expressions/Images/l006-s005-te-section-005.png>)

Use one window per segment. The rising piece is kept on by $u(t)-u(t-2)$, and the falling piece is kept on by $u(t-2)-u(t-4)$. Multiplying each interval formula by its own window prevents the linear trend from extending past its breakpoints.

$$
x(t)=t\big(u(t)-u(t-2)\big)+(4-t)\big(u(t-2)-u(t-4)\big)
$$

Check the intervals in order. Before $0$ both windows are off. On $0\le t<2$, only the rising segment remains. On $2\le t<4$, only the falling segment remains. After $4$, both windows are off again, so the windowed sum matches the graph on every interval.

## Writing a Simplified Unit Step Expression from a Multi-Segment Graph

**Example:** Given the graph with $x(t)=2$ for $0\le t<2$, $x(t)=4-t$ for $2\le t<4$, $x(t)=-1$ for $4\le t<6$, and $x(t)=0$ elsewhere, derive and simplify one compact unit-step expression that matches all intervals.

**Explanation**

The cue is a mixed graph with constant and linear pieces. Read the interval formulas first: the signal is $2$ on $0\le t<2$, then $4-t$ on $2\le t<4$, then $-1$ on $4\le t<6$, and $0$ elsewhere. The simplification comes from combining shared windows at the breakpoints.

![](<../Source/4.2.6. Converting Graphs into Unit Step Expressions/Images/l006-s006-te-section-006.png>)

Convert each segment independently. Use $u(t)-u(t-2)$ for the constant plateau, $u(t-2)-u(t-4)$ for the linear fall, and $u(t-4)-u(t-6)$ for the negative plateau. Then add the terms before simplifying the repeated breakpoint windows.

$$
x(t)=2\big(u(t)-u(t-2)\big)+(4-t)\big(u(t-2)-u(t-4)\big)-\big(u(t-4)-u(t-6)\big)
$$

Now combine the shared breakpoint terms at $t=2$ and $t=4$. Collecting like step functions gives one compact expression with one coefficient per breakpoint, which is easier to read and check.

$$
x(t)=2u(t)+(2-t)u(t-2)+(t-5)u(t-4)+u(t-6)
$$

Check the intervals in order. Before $0$ every step is off. On $0\le t<2$ the value is $2$; on $2\le t<4$ it becomes $4-t$; on $4\le t<6$ it is $-1$; and after $6$ it returns to $0$. That confirms the simplified form matches the full graph exactly.
