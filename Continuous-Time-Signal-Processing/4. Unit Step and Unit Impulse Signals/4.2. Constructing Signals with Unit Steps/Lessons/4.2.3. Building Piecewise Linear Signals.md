## Introduction to Building Piecewise Linear Signals

Your job in this step is to represent piecewise linear signals with reusable building blocks, not by writing many separate case lines. A slope change at time $a$ becomes one shifted ramp term, so many breakpoints can be combined into a single expression.

Start from the shifted unit-ramp definition. The block $r(t-a)$ is a ramp that starts at $a$, and multiplying by $u(t-a)$ gates it on after that time.

$$
r(t-a)= (t-a)u(t-a)
$$

Use the base case: $x(t)=m r(t-a)=m(t-a)u(t-a)$. It is zero before $a$, then grows linearly with slope $m$ after $a$, which gives the exact same behavior as the simplest slope segment.

The core move is to add slope increments. If $\Delta m_1$ appears at $a_1$, it contributes only for $t \ge a_1$; if $\Delta m_2$ appears at $a_2$, it contributes only for $t \ge a_2$, etc. At any $t$, active slope is the sum of these contributions.

$$
x(t)=m_0 r(t-a_0)+\Delta m_1\big[r(t-a_1)-r(t-a_2)\big]+\Delta m_2\big[r(t-a_2)-r(t-a_3)\big]
$$

A difference of shifted ramps creates a finite-interval slope block. The term $\Delta m [r(t-a)-r(t-b)]$ adds slope $\Delta m$ from $a$ until $b$, and then stops changing afterward. This is the key pattern for segmenting piecewise linear segments cleanly.

Next, you can generalize this recipe from one ramp to one breakpoint increment, then to a finite interval, and then to several increments chained together in the full signal form.

## Starting a Signal with One Shifted Ramp

**Example:** Express $x(t)$ where $x(t)=0$ for $t<-1$ and $x(t)=2(t+1)$ for $t\ge-1$.

**Explanation**

Use the cue from the prompt: the signal is flat at $0$ before the start time and becomes linear with slope $2$ at $t=-1$, which means this is one shifted ramp segment.

The target is to express the turn-on time with a ramp shifted to $-1$. For a ramp shifted by $a$, the rule is $\Delta m r(t-a)=\Delta m(t-a)u(t-a)$.

$$
r(t-a)=(t-a)u(t-a)
$$

Apply the rule with $a=-1$ and slope $\Delta m=2$: first form the shifted ramp, then scale it by $2$.

$$
x(t)=2r(t+1)
$$

$$
x(t)=2(t+1)u(t+1)
$$

Check the two regions: for $t<-1$, $u(t+1)=0$, so $x(t)=0$; for $t\ge-1$, $u(t+1)=1$, so $x(t)=2(t+1)$. This matches the prompt exactly and is the compact one-ramp model for this step.

## Adding a Slope Change at a Breakpoint

**Example:** Express a signal that has slope $0$ for $t<0$, slope $1$ on $[0,3)$, and slope $4$ for $t\ge3$.

**Explanation**

The cue is that the signal does not just turn on once; its slope changes at the breakpoint $t=3$. Start with the slope-$1$ ramp that begins at $t=0$, then add only the extra slope needed after $t=3$.

$$
r(t-a)=(t-a)u(t-a)
$$

The first active segment has slope $1$, so the baseline term is $r(t)$. At the breakpoint, the slope must increase from $1$ to $4$, so the slope increment is $\Delta m=4-1=3$.

$$
\Delta m=4-1=3
$$

A slope increment at $t=3$ is represented by a shifted ramp increment, so add $3r(t-3)$ to the original ramp.

$$
x(t)=r(t)+3r(t-3)
$$

$$
x(t)=t u(t)+3(t-3)u(t-3)
$$

Check the intervals by reading active ramps. For $t<0$, neither ramp is active, so the slope is $0$. For $0\le t<3$, only $r(t)$ is active, so the slope is $1$. For $t\ge3$, both terms are active, so the slope is $1+3=4$.

## Returning the Slope to Zero After an Interval

**Example:** Construct $x(t)$ where $x(t)=2t$ for $0 \le t < 2$ and constant for $t \ge 2$.

**Explanation**

The cue is that the slope should stay at $2$ only on $[0,2)$ and then stop changing. That makes this a finite-interval slope block, so the right move is to start with the active ramp and then cancel it with a delayed copy.

$$
r(t)=t u(t)
$$

Start with the slope-$2$ ramp $2r(t)$, which turns on at $t=0$. To return the slope to zero at $t=2$, subtract the same ramp shifted right by $2$, $2r(t-2)$, so the added slope disappears after the interval.

$$
x(t)=2r(t)-2r(t-2)
$$

$$
x(t)=2t u(t)-2(t-2)u(t-2)
$$

Check the regions: for $t<0$, both ramps are off, so $x(t)=0$; for $0 \le t < 2$, only the first ramp is active, so $x(t)=2t$; for $t \ge 2$, both ramps are active, so the slope terms cancel and the signal stays constant at $4$.

## Combining Multiple Slope Changes in One Expression

**Example:** Represent a signal with slope profile: $0$ for $t<0$, $1$ for $0 \le t<2$, $4$ for $2 \le t<5$, and $2$ for $t\ge5$.

**Explanation**

The cue is a slope profile with three changes: the slope turns on at $t=0$, jumps again at $t=2$, and then drops at $t=5$. Read each change as one shifted-ramp term, and add the terms in time order.

Start from the baseline slope-$1$ ramp $r(t)$. The change at $t=2$ is $+3$, because the slope goes from $1$ to $4$, and the change at $t=5$ is $-2$, because the slope goes from $4$ to $2$.

$$
x(t)=r(t)+3r(t-2)-2r(t-5)
$$

$$
x(t)=t u(t)+3(t-2)u(t-2)-2(t-5)u(t-5)
$$

Check the intervals: for $t<0$, all ramps are off, so the slope is $0$; for $0 \le t<2$, only $r(t)$ is active, so the slope is $1$; for $2 \le t<5$, the first two ramps are active, so the slope is $1+3=4$; for $t\ge5$, all three ramps are active, so the slope is $1+3-2=2$.
