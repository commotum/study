## Introduction to Windowing a Signal Over a Time Interval

The object to recognize is a **window gate** built from unit steps: $u(t-a)-u(t-b)$. Read this as an on-off factor that is multiplied into another signal.

First define the pieces you are switching on. The gate turns on at $t=a$ through $u(t-a)$ and turns off at $t=b$ through $u(t-b)$, so the two shifted steps create a retention interval between those times.

Now apply the action directly: keep the original signal in the window and kill it elsewhere by writing $y(t)=x(t)(u(t-a)-u(t-b))$. This is the minimum direct-instruction move in this section.

Use the simplest base case to verify the pattern. Let $x(t)=1$ and form $y(t)=1\cdot(u(t)-u(t-b))$. For $t<0$, $u(t)=0$ so the output is zero. For $0\le t<b$, both switches keep the gate at one and the output is one. For $t\ge b$, $u(t-b)=1$ and the difference is zero.

$$
y(t)=x(t)(u(t-a)-u(t-b))
$$

$$
u(t-a)-u(t-b)=1\text{ for }a\le t<b,\;0\text{ otherwise}
$$

Sanity check the generic result from the same rule: the expression says $y(t)=x(t)$ only on the closed-open interval $a\le t<b$, and $y(t)=0$ outside it, so the gate enforces both retention bounds and clipping in one multiplication.

## Windowing a Signal from $t=0 to t=b$

**Example:** Build $y(t)=t\,(u(t)-u(t-b))$ and describe the retained interval and equivalent piecewise form.

**Explanation**

Cue: the interval should turn on at $t=0$ and turn off at $t=b$, so the window factor is $u(t)-u(t-b)$. This is the one new wrinkle in this step compared with the prior tutorial.

Use the base factor directly and identify where it is active. Since $u(t)-u(t-b)=1$ for $0\le t<b$ and $0$ otherwise, this window preserves any signal only on that interval.

$$
u(t)-u(t-b)=\begin{cases}1,&0\le t<b\\0,&\text{otherwise}\end{cases}
$$

Apply the multiplication rule with $x(t)=t$: $y(t)=x(t)(u(t)-u(t-b))=t\,(u(t)-u(t-b))$. The next step is to split by interval.

$$
y(t)=t\,(u(t)-u(t-b))
$$

For $0\le t<b$, the window is $1$, so $y(t)=t\cdot 1=t$. For $t<0$ or $t\ge b$, the window is $0$, so $y(t)=0$.

$$
y(t)=\begin{cases}t,&0\le t<b\\0,&\text{otherwise}\end{cases}
$$

So the worked result confirms the future question pattern: write the output as $y(t)=t(u(t)-u(t-b))$, then read the retained interval as $0\le t<b$ and the clipped form as zero elsewhere.

## Windowing a Signal from $t=a to t=b$

**Example:** For $x(t)=\cos t$, multiply by $u(t-a)-u(t-b)$ and write the exact interval where the cosine component remains.

**Explanation**

The cue is the shifted retention window. In this step the signal stays active from $t=a$ up to $t=b$, so use the same form as before with both shifts: $u(t-a)-u(t-b)$. This adds exactly one wrinkle from the prior step: a nonzero left shift.

$$
u(t-a)-u(t-b)=\begin{cases}1,&a\le t<b\\0,&\text{otherwise}\end{cases}
$$

Use the core rule from the previous steps: $y(t)=x(t)(u(t-a)-u(t-b))$. Substitute $x(t)=\cos t$ to get $y(t)=\cos t\,(u(t-a)-u(t-b))$.

$$
y(t)=\cos t\,(u(t-a)-u(t-b))
$$

Now isolate interval conditions. Multiply by the window value on each region: on $a\le t<b$, the window equals $1$, and outside this interval it equals $0$.

$$
y(t)=\begin{cases}\cos t,&a\le t<b\\0,&\text{otherwise}\end{cases}
$$

Therefore, the retained component is the cosine term on $a\le t<b$, and all other times are zeroed out. This directly mirrors the planned question form: identify the same interval and express the answer in multiplied or piecewise form.

## Windowing a Signal Across $t=0$

**Example:** Write the windowed signal $y(t)=e^{-t}(u(t+2)-u(t-3))$ and identify where $y(t)$ is nonzero.

**Explanation**

The cue is that the interval now crosses the origin. Build the window directly as $u(t+2)-u(t-3)$, which uses a switch-on time at $t=-2$ and a switch-off time at $t=3$.

Use the two-step rule separately: $u(t+2)=1$ when $t\ge -2$, and $u(t-3)=1$ when $t\ge 3$, otherwise each is $0$.

$$
u(t+2)-u(t-3)=\begin{cases}1,&-2\le t<3\\0,&\text{otherwise}\end{cases}
$$

Apply the product rule from the lesson's core move: $y(t)=x(t)(u(t+2)-u(t-3))$. With $x(t)=e^{-t}$, this is $y(t)=e^{-t}(u(t+2)-u(t-3))$.

$$
y(t)=e^{-t}(u(t+2)-u(t-3))
$$

Then isolate the active region. On $-2\le t<3$, the window is $1$, so $y(t)=e^{-t}$. Outside that interval, the window is $0$, so $y(t)=0$.

$$
y(t)=\begin{cases}e^{-t},&-2\le t<3\\0,&\text{otherwise}\end{cases}
$$

This verifies the desired target form: nonzero content is retained on a time interval that crosses $0$, specifically $-2\le t<3$, while all other regions are clipped to zero.

## Identifying the Retained Interval from a Windowed Signal

**Example:** From $y(t)=x(t)(u(t-2)-u(t-5))$, identify the window interval and rewrite a clean retained-domain sentence.

**Explanation**

The cue is to read a finished window expression instead of constructing one. Here the retention window is $u(t-2)-u(t-5)$, so read the switch times as $t=2$ and $t=5$.

Apply the inverse version of the core rule: the first step $u(t-2)$ turns on at $t=2$, and the second step $u(t-5)$ turns off the window at $t=5$. Sort the events and test the intervals $t<2$, $2\le t<5$, and $t\ge 5$.

$$
u(t-2)-u(t-5)=\begin{cases}0,&t<2\\1,&2\le t<5\\0,&t\ge 5\end{cases}
$$

Attach that support to $x(t)$ only where the window equals one. So $y(t)=x(t)$ for $2\le t<5$, and $y(t)=0$ otherwise.

$$
y(t)=\begin{cases}x(t),&2\le t<5\\0,&\text{otherwise}\end{cases}
$$

The clean retained-domain statement is: the original signal is kept on the interval $2\le t<5$, then fully removed elsewhere.
