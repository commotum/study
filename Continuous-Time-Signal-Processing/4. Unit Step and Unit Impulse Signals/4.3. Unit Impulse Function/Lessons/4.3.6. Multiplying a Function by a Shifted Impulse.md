## Introduction to Multiplying a Function by a Shifted Impulse

If you already know the ordinary impulse rule $f(t)\delta(t)=f(0)\delta(t)$, the shifted case uses the same idea. The cue is the factor $\delta(t-t_0)$, which tells you to sample the surrounding function at the time where the impulse argument is zero.

So the action is simple: replace every remaining $t$ in $f(t)$ with $t_0$ and leave the shifted impulse in place. In symbolic work, the impulse localizes the product at $t=t_0$ instead of letting the full function of time survive.

$$
f(t)\delta(t-t_0)=f(t_0)\delta(t-t_0)
$$

For the base case, a shift of $2$ means the impulse is located at $t=2$, so $f(t)\delta(t-2)=f(2)\delta(t-2)$. That is the same substitution rule, just applied at a specific impulse location.

$$
f(t-a)\delta(t-a)=f(a)\delta(t-a)
$$

Any shifted impulse works this way, including negative shifts written as $\delta(t+a)$. Later sections will use this substitution rule directly to simplify concrete products quickly.

## Evaluating a Function at the Impulse Location

**Example:** Evaluate and simplify $f(t)\delta(t-5)$ for $f(t)=2t+3$.

**Explanation**

The cue is the shifted impulse $\delta(t-5)$, so the multiplier is sampled at $t=5$ while the impulse stays centered at $5$.

$$
\begin{aligned}
f(t)\delta(t-5) &= f(5)\delta(t-5) \\
&= (2(5)+3)\delta(t-5) \\
&= 13\delta(t-5)
\end{aligned}
$$

So the simplified result is $13\delta(t-5)$. The function has been evaluated at the impulse location, and the shifted impulse argument is unchanged.

## Multiplying by a Shifted Impulse at a Negative Time

**Example:** Evaluate $f(t)\delta(t+3)$ for $f(t)=t^2-1$.

**Explanation**

Read $\delta(t+3)$ as $\delta(t-(-3))$, so the sample point is $t=-3$, not $t=+3$. The shifted impulse tells you to evaluate the multiplier there and keep the same impulse argument.

$$
\begin{aligned}
f(t)\delta(t+3) &= f(-3)\delta(t+3) \\
&= \big((-3)^2-1\big)\delta(t+3) \\
&= 8\delta(t+3)
\end{aligned}
$$

So the simplified product is $8\delta(t+3)$. The negative shift changes only the location where the function is sampled.

## Combining Function Values with Scaled Shifted Impulses

**Example:** Simplify $2(4t+2)\delta(t-4)-3\delta(t-4)$.

**Explanation**

Both terms use the same shifted impulse $\delta(t-4)$, so first evaluate the multiplier $2(4t+2)$ at the impulse location $t=4$. Then keep the common impulse factor and combine the coefficients.

$$
\begin{aligned}
2(4t+2)\delta(t-4)-3\delta(t-4) &= 2\big(4(4)+2\big)\delta(t-4)-3\delta(t-4) \\
&= 36\delta(t-4)-3\delta(t-4) \\
&= 33\delta(t-4)
\end{aligned}
$$

So the simplified result is $33\delta(t-4)$. The two terms can be merged because they share the same shift, and the function value is taken at that same impulse location before the coefficients are added.

## Multiplying a Piecewise Function by a Shifted Impulse

**Example:** Simplify $f(t)\delta(t-2)$ for $f(t)=\{t,\, t<1;\, 3-t,\, t\ge 1\}$.

**Explanation**

The cue is $\delta(t-2)$, so sample the piecewise function at $t=2$. Since $2\ge 1$, use the branch $3-t$ and evaluate it at that impulse location.

$$
\begin{aligned}
f(t)\delta(t-2) &= f(2)\delta(t-2) \\
&= (3-2)\delta(t-2) \\
&= 1\delta(t-2)
\end{aligned}
$$

So the simplified product is $1\delta(t-2)$. The only extra step is choosing the correct branch before applying the shifted-impulse rule.
