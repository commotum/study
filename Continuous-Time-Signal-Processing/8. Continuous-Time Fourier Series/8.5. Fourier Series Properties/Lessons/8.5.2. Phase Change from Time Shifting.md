## Introduction to Phase Change from Time Shifting

For a delay $x(t-t_0)$ with $t_0>0$, the complex Fourier series coefficient magnitudes stay fixed and only the phases change. The time shift is a harmonic-by-harmonic phase update, not a recomputation of the coefficient integral.

$$
c_k' = c_k e^{-jk\omega_0 t_0}
$$

Write each original coefficient in polar form as $c_k = |c_k|e^{j\phi_k}$ so the phase change is visible directly. The shift leaves $|c_k|$ unchanged and changes only the angle attached to each harmonic index $k$.

$$
c_k' = |c_k|e^{j(\phi_k-k\omega_0 t_0)}
$$

The new phase is $\phi_k' = \phi_k-k\omega_0 t_0$, so higher harmonics rotate more because the phase subtraction is scaled by $k$. This is why the rule is harmonic-dependent even though the magnitude does not move.

For $k=0$, the multiplier is $e^0=1$, so the DC coefficient does not rotate at all. Use this coefficient-level rule whenever you want the shifted spectrum without recomputing Fourier integrals: keep the magnitudes, subtract $k\omega_0 t_0$ from each phase, and reuse the same notation for every harmonic.

<a id="phase-update-for-one-shifted-fourier-coefficient"></a>
## Phase Update for One Shifted Fourier Coefficient

**Example:** Given $c_2 = 4e^{j\pi/6}$ for a periodic signal with fundamental angular frequency $\omega_0$, find the new $k=2$ coefficient of $x(t-T_0/4)$ in polar form.

**Explanation**

The cue is one nonzero harmonic coefficient, $c_2 = 4e^{j\pi/6}$, so use the time-shift rule from the previous step: keep the magnitude and subtract the shift angle from the phase.

$$
c_2' = c_2 e^{-j2\omega_0(T_0/4)}
$$

Here $t_0 = T_0/4$, so the phase change is $2\omega_0(T_0/4) = \omega_0T_0/2 = \pi/2$ because $\omega_0T_0 = 2\pi$. Subtract that angle from the original phase $\pi/6$.

$$
c_2' = 4e^{j(\pi/6-\pi/2)} = 4e^{-j\pi/3}
$$

So the shifted coefficient is $c_2' = 4e^{-j\pi/3}$. The magnitude stays $4$, and the only update is the phase subtraction by $k\omega_0t_0$.

## Phase Updates Across Multiple Harmonic Indices

**Example:** A periodic signal has $c_0 = 3$, $c_1 = 2e^{j\pi/3}$, and $c_3 = e^{-j\pi/2}$. Find the shifted phases for $x(t-T_0/6)$ and write the new coefficient phases for $k=0,1,3$.

**Explanation**

The cue is a short coefficient list, so update each harmonic with the same rule $c_k' = c_k e^{-jk\omega_0 t_0}$. Here $t_0 = T_0/6$, and the $k=0$ term stays fixed because no phase is subtracted when $k=0$.

$$
\omega_0 t_0 = \frac{2\pi}{T_0}\cdot\frac{T_0}{6} = \frac{\pi}{3}
$$

That means the phase change is $k(\pi/3)$ for harmonic $k$, so the update is different at each index.

$$
\phi_0' = 0
$$

$$
\phi_1' = \frac{\pi}{3} - 1\cdot\frac{\pi}{3} = 0
$$

$$
\phi_3' = -\frac{\pi}{2} - 3\cdot\frac{\pi}{3} = -\frac{3\pi}{2}
$$

The $k=3$ result is the same as $\pi/2$ after wrapping by $2\pi$, so the shifted coefficients are $c_0' = 3$, $c_1' = 2$, and $c_3' = e^{j\pi/2}$. The magnitudes stay unchanged; only the phases move by the harmonic-dependent offset.

## Phase Sign for Delays and Advances

**Example:** For the coefficient $c_1 = 5e^{-j\pi/4}$, compare the new phase for $x(t-T_0/8)$ with the new phase for $x(t+T_0/8)$.

**Explanation**

The cue is one coefficient with two opposite shifts. Use the same rule $c_k' = c_k e^{-jk\omega_0 t_0}$, but note that a delay has $t_0>0$ and an advance has $t_0<0$. That sign change is what flips the phase direction.

$$
\omega_0 t_0 = \frac{2\pi}{T_0}\cdot\frac{T_0}{8} = \frac{\pi}{4}
$$

Starting from $c_1 = 5e^{-j\pi/4}$, the delay uses $t_0 = T_0/8$, so the phase is reduced by $\pi/4$. The advance uses $t_0 = -T_0/8$, so the same subtraction rule turns into adding $\pi/4$.

$$
\phi_1'(\text{delay}) = -\frac{\pi}{4} - 1\cdot\frac{\pi}{4} = -\frac{\pi}{2}
$$

$$
\phi_1'(\text{advance}) = -\frac{\pi}{4} - 1\cdot\left(-\frac{\pi}{4}\right) = 0
$$

So the delay gives $c_1' = 5e^{-j\pi/2}$ and the advance gives $c_1' = 5$. The magnitudes stay at $5$ in both cases; the sign of $t_0$ determines whether the phase moves down or up.

<a id="reading-the-shifted-phase-spectrum"></a>
## Reading the Shifted Phase Spectrum

**Example:** An original phase spectrum has all zero phases, and the shifted spectrum has $\phi'_0 = 0$, $\phi'_1 = -\pi/6$, $\phi'_2 = -\pi/3$, and $\phi'_3 = -\pi/2$. Identify the phase ramp and the time shift that produced it.

**Explanation**

The cue is a completed phase spectrum, so read the phases by harmonic and check the change from one index to the next. Since the original phases are all zero, the shift shows up only as a linear phase ramp, and the magnitudes stay unchanged.

$$
\phi'_0 = 0,\quad \phi'_1 = -\pi/6,\quad \phi'_2 = -\pi/3,\quad \phi'_3 = -\pi/2
$$

Each step between adjacent harmonics is the same, so compare the differences instead of treating the phases as separate numbers.

$$
\phi'_1-\phi'_0 = \phi'_2-\phi'_1 = \phi'_3-\phi'_2 = -\pi/6
$$

That constant step is $-\omega_0 t_0$, so $\omega_0 t_0 = \pi/6$ and $t_0 = T_0/12$. Because the phases get more negative as $k$ increases, the shift is a delay, and the ramp is $\phi'_k = -k\pi/6$.
