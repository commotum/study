## Introduction to Time-Reversal Property

For the complex Fourier series, time reversal is a harmonic-index reversal. The coefficient at harmonic $k$ in $x(-t)$ comes from the coefficient at harmonic $-k$ in $x(t)$, so the coefficient sequence is read backward around $k=0$.

$$
x(t)=\sum_{k=-\infty}^{\infty} C_k e^{jk\omega_0 t}
$$

Start by substituting $-t$ into the series. This changes the sign in each exponential, but it does not change the coefficient values themselves.

$$
x(-t)=\sum_{k=-\infty}^{\infty} C_k e^{-jk\omega_0 t}
$$

Now reindex the sum so the exponent returns to the standard positive-$k$ form. That reindexing gives $C_k^{x(-t)} = C_{-k}^{x(t)}$.

$$
x(-t)=\sum_{k=-\infty}^{\infty} C_{-k} e^{jk\omega_0 t}
$$

The $k=0$ coefficient stays fixed, and each matched pair of harmonics $k$ and $-k$ swaps sides. So the magnitude and phase spectra of $x(-t)$ are mirror images of those of $x(t)$ across harmonic index $0$.

## Mapping One Fourier Series Coefficient Under Time Reversal

**Example:** Given a coefficient table for $x(t)$ with entries around $k=0$, such as $C_{-2}=1+j$, $C_{-1}=2$, $C_0=3$, $C_1=2-j$, and $C_2=1-j$, determine $C_2$ for $x(-t)$.

**Explanation**

The cue is a coefficient table centered at $k=0$. For time reversal, the coefficient at harmonic $k$ in $x(-t)$ comes from the coefficient at harmonic $-k$ in $x(t)$.

$$
C_2^{x(-t)} = C_{-2}^{x(t)}
$$

From the given table, the opposite-index coefficient is $C_{-2}=1+j$. Keep that value unchanged and assign it to the target index.

$$
C_2^{x(-t)} = 1+j
$$

So the reversed signal uses the same coefficient value at the mirrored harmonic index: the lookup changes from $-2$ to $2$, but the coefficient itself does not change.

## Reversing a Full Fourier Coefficient Sequence

**Example:** Given the coefficient list for $x(t)$ with the five harmonics $k=-2,-1,0,1,2$, write the full coefficient list for $x(-t)$ in the same index convention.

**Explanation**

The cue is a finite coefficient list centered at $k=0$. Time reversal does not change the coefficient values; it reverses the harmonic order around $0$.

$$
C_{-2}^{x(t)}, C_{-1}^{x(t)}, C_0^{x(t)}, C_1^{x(t)}, C_2^{x(t)}
$$

Read the original list from most negative to most positive. Then move each coefficient to the opposite harmonic index: $-2$ swaps with $2$, $-1$ swaps with $1$, and $0$ stays fixed.

$$
C_{-2}^{x(-t)} = C_2^{x(t)}, C_{-1}^{x(-t)} = C_1^{x(t)}, C_0^{x(-t)} = C_0^{x(t)}, C_1^{x(-t)} = C_{-1}^{x(t)}, C_2^{x(-t)} = C_{-2}^{x(t)}
$$

So the full coefficient list for $x(-t)$ is the same list read backward around $0$. The center term stays in place, and the left and right sides swap positions.

$$
C_{-2}^{x(-t)}, C_{-1}^{x(-t)}, C_0^{x(-t)}, C_1^{x(-t)}, C_2^{x(-t)} = C_2^{x(t)}, C_1^{x(t)}, C_0^{x(t)}, C_{-1}^{x(t)}, C_{-2}^{x(t)}
$$

## Interpreting the Magnitude Spectrum After Time Reversal

**Example:** Given the magnitude table $|C_{-2}|=5$, $|C_{-1}|=3$, $|C_0|=2$, $|C_1|=1$, and $|C_2|=4$ for $x(t)$, identify the magnitude table for $x(-t)$.

**Explanation**

The cue is a magnitude table indexed by harmonic number $k$. For time reversal, the magnitude values do not change; only the index order mirrors about $0$.

$$
|C_{-2}^{x(t)}|=5,\quad |C_{-1}^{x(t)}|=3,\quad |C_0^{x(t)}|=2,\quad |C_1^{x(t)}|=1,\quad |C_2^{x(t)}|=4
$$

Mirror the index order about $0$: $-2$ pairs with $2$, $-1$ pairs with $1$, and $0$ stays fixed. Keep each magnitude value attached to the opposite index instead of recomputing it.

$$
|C_{-2}^{x(-t)}|=|C_2^{x(t)}|=4,\quad |C_{-1}^{x(-t)}|=|C_1^{x(t)}|=1,\quad |C_0^{x(-t)}|=|C_0^{x(t)}|=2,\quad |C_1^{x(-t)}|=|C_{-1}^{x(t)}|=3,\quad |C_2^{x(-t)}|=|C_{-2}^{x(t)}|=5
$$

So the magnitude spectrum of $x(-t)$ is the left-right mirror of the magnitude spectrum of $x(t)$: the values read $4, 1, 2, 3, 5$ from $k=-2$ to $k=2$.

## Interpreting the Phase Spectrum After Time Reversal

**Example:** Given the phase table $\angle C_{-2}=-\pi/2$, $\angle C_{-1}=0$, $\angle C_0=\pi/6$, $\angle C_1=\pi/3$, and $\angle C_2=-\pi/4$ for $x(t)$, identify the phase table for $x(-t)$.

**Explanation**

The cue is a phase table indexed by harmonic number $k$. For time reversal, the phase values stay the same while the index order mirrors about $0$.

$$
\angle C_{-2}^{x(t)}=-\pi/2,\quad \angle C_{-1}^{x(t)}=0,\quad \angle C_0^{x(t)}=\pi/6,\quad \angle C_1^{x(t)}=\pi/3,\quad \angle C_2^{x(t)}=-\pi/4
$$

Mirror the index order about $0$: $-2$ pairs with $2$, $-1$ pairs with $1$, and $0$ stays fixed. Move each phase value to the opposite index instead of changing the phase value itself.

$$
\angle C_{-2}^{x(-t)}=\angle C_2^{x(t)}=-\pi/4,\quad \angle C_{-1}^{x(-t)}=\angle C_1^{x(t)}=\pi/3,\quad \angle C_0^{x(-t)}=\angle C_0^{x(t)}=\pi/6,\quad \angle C_1^{x(-t)}=\angle C_{-1}^{x(t)}=0,\quad \angle C_2^{x(-t)}=\angle C_{-2}^{x(t)}=-\pi/2
$$

So the phase spectrum of $x(-t)$ is the left-right mirror of the phase spectrum of $x(t)$: read from $k=-2$ to $k=2$, the phases are $-\pi/4$, $\pi/3$, $\pi/6$, $0$, and $-\pi/2$.
