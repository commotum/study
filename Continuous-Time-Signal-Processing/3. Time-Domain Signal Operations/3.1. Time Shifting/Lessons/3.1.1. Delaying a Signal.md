## Introduction to Delaying a Signal

A delay moves a continuous-time signal to the right by $T$ units. In the graph below, $x(t)$ and $y(t)$ have the same shape; only the time locations change.

![](<../Source/3.1.1. Delaying a Signal/Images/l001-s001-te-section-001.png>)

The delay operator is $y(t)=x(t-T)$. Read the minus sign inside the input as "look back $T$ units on the original signal," so the visible signal appears $T$ units later.

$$
y(t)=x(t-T)
$$

Any tagged feature follows the same rule: a peak, breakpoint, or marker at $t_0$ in $x(t)$ appears at $t_0+T$ in $y(t)$, and its value does not change.

$$
t_0 \mapsto t_0+T
$$

The same rule applies to support: if $x(t)$ is nonzero on $[a,b]$, then $y(t)$ is nonzero on $[a+T,b+T]$, and each piece of a piecewise signal keeps its formula after the shift.

$$
[a,b] \mapsto [a+T,b+T]
$$

This is the base case for the lesson. The examples that follow keep the same right-shift rule and add one controlled wrinkle at a time: a single point, multiple points, support boundaries, and finite-duration breakpoints.

## Delaying a Single Feature Time

**Example:** The signal $x(t)$ has one peak of height 4 at time $t = 1$. After the delay $y(t)=x(t-3)$, find the time at which that same peak occurs in $y(t)$ and its peak value.

**Explanation**

The cue gives both a time coordinate and a signal value: the peak occurs at time $t=1$ and has height 4. For a delay, change only the peak's time coordinate; the peak height stays the same.

![](<../Source/3.1.1. Delaying a Signal/Images/l001-s002-te-section-002.png>)

Write the delayed signal as $y(t)=x(t-T)$. Here $T=3$, so the peak's time coordinate moves right by 3 units.

$$
y(t)=x(t-T)
$$

The original peak time is $t_0=1$, so the delayed peak time is $t_0+T=1+3=4$.

$$
t_0+T=1+3=4
$$

The peak value stays $4$, so in $y(t)$ the peak occurs at time $t=4$ and still has height $4$.

## Delaying Key Points on a Signal Graph

**Example:** Take a signal with key points $(-2,3)$, $(0,-1)$, and $(3,2)$. Delay by $T = 2$. List all delayed key-point times with values.

**Explanation**

The cue is a graph with several labeled key points. For a delay, move every time coordinate right by the same $T$ and keep each value unchanged.

![](<../Source/3.1.1. Delaying a Signal/Images/l001-s003-te-section-003.png>)

Use the delayed-signal rule $y(t)=x(t-T)$. Then apply that same shift to each marked point, one by one.

$$
y(t)=x(t-T)
$$

Here $T=2$, so add 2 to each key-point time and leave the values alone: $-2 \mapsto 0$, $0 \mapsto 2$, and $3 \mapsto 5$.

$$
(-2,3) \to (0,3),\qquad (0,-1) \to (2,-1),\qquad (3,2) \to (5,2)
$$

The delayed graph keeps the same shape and the same relative order of the points. Only the horizontal positions change.

## Delaying the Support Interval

**Example:** Given that $x(t)$ is nonzero on $2 \le t \le 6$, delay by $T = 1.5$ and specify the support of $y(t)$.

**Explanation**

The cue is a finite support interval. For a delay, move both endpoints right by the same $T$ and keep the signal zero outside the shifted interval.

![](<../Source/3.1.1. Delaying a Signal/Images/l001-s004-te-section-004.png>)

Use the delayed-signal rule $y(t)=x(t-T)$. Since the original support is $[2,6]$, shift the whole interval by $T=1.5$.

$$
y(t)=x(t-T)
$$

$$
2+1.5=3.5,\quad 6+1.5=7.5
$$

So the support interval shifts to the right by $1.5$ with no change in the signal shape.

$$
\text{support of } y(t) = [3.5,7.5]
$$

That means $y(t)$ is nonzero on $[3.5,7.5]$ and zero for $t<3.5$ or $t>7.5$.

## Delaying Breakpoints of a Finite-Duration Signal

**Example:** A signal has breakpoints at $t = -1$, $t = 2$, and $t = 4$ and piecewise formulas on those intervals. Delay by $T = 2$. Translate each breakpoint and interval.

**Explanation**

The cue is a finite-duration piecewise signal with breakpoints at $-1$, $2$, and $4$. For a delay, move every breakpoint and support boundary right by the same $T$ and keep each segment formula attached to its shifted interval.

![](<../Source/3.1.1. Delaying a Signal/Images/l001-s005-te-section-005.png>)

Use the delayed-signal rule $y(t)=x(t-T)$. Here $T=2$, so the breakpoint times and the support edges all shift right by 2.

$$
y(t)=x(t-T)
$$

Shift each breakpoint and boundary by adding 2: $-1 \mapsto 1$, $2 \mapsto 4$, and $4 \mapsto 6$.

$$
-1+2=1,\quad 2+2=4,\quad 4+2=6
$$

That rewrites the piecewise time regions as $t<1$, $1 \le t < 4$, $4 \le t < 6$, and $t \ge 6$. The segment shapes and values stay the same on the shifted intervals.

$$
\text{support of } y(t) = [1,6]
$$

So $y(t)$ is zero outside $[1,6]$, and only the horizontal placement of the breakpoints changes.
