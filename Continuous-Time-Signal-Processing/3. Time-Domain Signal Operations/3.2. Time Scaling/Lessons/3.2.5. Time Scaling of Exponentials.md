## Introduction to Time Scaling of Exponentials

When the exponent contains a time-scaled input, rewrite the expression so the scale factor multiplies the exponent coefficient. The core identity is $e^{s(at)} = e^{(as)t}$, which keeps the exponential family the same while changing its rate.

$$
e^{s(at)} = e^{(as)t}
$$

Start with the real exponential $e^{-t}$. If you replace $t$ by $2t$, the result is $e^{-2t}$, so the same decay shape happens twice as fast and is compressed toward $t=0$.

$$
e^{-t} \rightarrow e^{-2t}
$$

That same rate change rule gives the general interpretation: if $a>1$, the exponential evolves faster, and if $0<a<1$, it evolves more slowly. The multiplier changes how quickly the curve moves in time, not the exponential family itself.

The same idea also applies when the exponent is imaginary. For a complex exponential, $e^{j\omega(at)} = e^{j(a\omega)t}$, so the factor $a$ changes the oscillation rate in exactly the same way that it changes the growth or decay rate in a real exponential.

$$
e^{j\omega(at)} = e^{j(a\omega)t}
$$

## Rewriting a Time-Scaled Real Exponential

**Example:** Rewrite $x(t)=e^{-3(2t)}$ in standard form and state how its decay compares with $e^{-3t}$.

**Explanation**

The cue is the factor $2$ inside the exponent. For a time-scaled real exponential, rewrite the signal by multiplying the exponent coefficient by the scale factor.

$$
x(t)=e^{-3(2t)}=e^{(-3\cdot 2)t}=e^{-6t}
$$

Compared with $e^{-3t}$, the exponent coefficient changes from $-3$ to $-6$. The rewritten signal is still the same exponential family, but its decay happens twice as fast because the coefficient is larger in magnitude.

So the time-scaled signal is compressed toward $t=0$ and has unchanged amplitude. The only change is the decay rate, which is faster in the rewritten form $e^{-6t}$.

<a id="interpreting-faster-and-slower-exponential-decay"></a>
## Interpreting Faster and Slower Exponential Decay

**Example:** Compare $x_1(t)=e^{-2(3t)}$ and $x_2(t)=e^{-2(0.5t)}$ with the unscaled signal $e^{-2t}$; rewrite each and decide which decays fastest, which is unchanged, and which decays slowest.

**Explanation**

The cue is the scale factor inside the exponent. Rewrite each signal by multiplying the base decay coefficient by that factor, then compare the resulting coefficients.

$$
\begin{aligned}x_1(t)&=e^{-2(3t)}=e^{-6t}\\e^{-2t}&=e^{-2t}\\x_2(t)&=e^{-2(0.5t)}=e^{-t}\end{aligned}
$$

The effective decay coefficients are $-6$, $-2$, and $-1$. Since the more negative coefficient decays faster, $x_1(t)$ decays fastest, $e^{-2t}$ is unchanged, and $x_2(t)$ decays slowest.

That ordering matches the scaling rule: $a>1$ compresses the waveform toward $t=0$, while $0<a<1$ stretches it away from $t=0$. The same coefficient-multiplication rule explains both the rewrite and the decay-speed comparison.

## Scaling the Oscillation Rate of a Complex Exponential

**Example:** Rewrite $x(t)=e^{j4(2t)}$ in standard form and state how the oscillation rate compares with $e^{j4t}$.

**Explanation**

The cue is the factor $2$ inside the complex exponential. Use the same coefficient-multiplication rule as before: multiply the frequency coefficient by the time-scaling factor.

$$
x(t)=e^{j4(2t)}=e^{j(4\cdot 2)t}=e^{j8t}
$$

Compared with $e^{j4t}$, the angular frequency changes from $4$ to $8$. The rewritten signal is still the same complex exponential family, but it oscillates twice as fast because the coefficient was multiplied by $2$.

So the time-scaled complex exponential keeps the same amplitude while its oscillation rate increases. The general rule is still $e^{s(at)}=e^{(as)t}$; here the imaginary part of $s$ makes that rate change show up as faster oscillation.

## Scaling Both the Envelope and Oscillation of a Damped Sinusoid

**Example:** Rewrite $x(t)=e^{(-1+j4)(2t)}$ in standard form and identify how both the envelope and oscillation compare with $e^{(-1+j4)t}$.

**Explanation**

The cue is the scale factor $2$ multiplying $t$. Apply the same rule to every part of the complex exponent: multiply both the real part that controls decay and the imaginary part that controls oscillation.

$$
x(t)=e^{(-1+j4)(2t)}=e^{(-2+j8)t}
$$

The real part changes from $-1$ to $-2$, so the envelope is $e^{-2t}$ instead of $e^{-t}$ and decays twice as fast.

The imaginary part changes from $j4$ to $j8$, so the oscillation rate doubles. The initial amplitude is still $1$; time scaling changes the rate, not the starting height.

So the standard form is $e^{(-2+j8)t}$, and the combined interpretation is faster decay together with faster oscillation, exactly as the rule $e^{s(at)}=e^{(as)t}$ predicts.
