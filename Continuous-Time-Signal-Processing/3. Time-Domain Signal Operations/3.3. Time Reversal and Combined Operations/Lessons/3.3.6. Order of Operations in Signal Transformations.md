## Introduction to Order of Operations in Signal Transformations

The object to watch is the transformed argument inside $x(\cdot)$. When the signal is written in factored form, as $y(t)=x(a(t-b))$, read the factor $a$ first and the shift $b$ second.

$$
y(t)=x(a(t-b))
$$

To locate where an original feature at time $t_0$ appears in the transformed signal, solve the inside relation $a(t-b)=t_0$. That gives the inverse map $t=t_0/a+b$, which is the rule you will reuse for every labeled time point.

$$
t=t_0/a+b
$$

Use the base case $y(t)=x(2(t-1))$ to see the order clearly. The factor $2$ compresses time by $2$, and the $-1$ inside the parentheses shifts the compressed signal right by $1$, so a feature at $t_0$ lands at $t=t_0/2+1$.

$$
y(t)=x(2(t-1))
$$

If $a<0$, the same inverse map still works, but the order of the landmarks reverses because the signal has been flipped in time before the shift is read. Before you compare a formula to a graph, factor the argument first, then read the factor, then read the shift.

## Sequencing a Shift and Positive Time Scale

**Example:** Suppose $x(t)$ has a peak at $t_0=8$ and let $y(t)=x(2(t-1))$. Find where the peak appears in $y(t)$ and state the order of operations that produced it.

**Explanation**

The cue is the factored inside argument of $x$ in $y(t)=x(2(t-1))$. Read the factor $2$ first: it compresses time by a factor of $2$ before the shift is applied.

$$
t_0=2(t-1)
$$

Set the original time equal to the inside argument, then solve for $t$. This gives the inverse map $t=t_0/2+1$, which tells you where any labeled time point appears in the transformed signal.

$$
t=t_0/2+1
$$

Now apply the rule to the peak at $t_0=8$. Substituting gives $t=5$, and the peak height stays the same because only the time location changes.

$$
t_0=8 \Rightarrow t=5
$$

So the peak appears at $t=5$. The order is scale first, then shift: compress by $2$, then move right by $1$. The factor $2$ acts before the $-1$ inside the parentheses is read as the shift.

## Sequencing a Shift and Time Reversal

**Example:** Suppose $x(t)$ has a peak at $t_0=6$ and let $y(t)=x(-2(t-1))$. Find where the peak appears and explain how the reversal changes the order of landmarks.

**Explanation**

The cue is the factored inside argument of $x$ in $y(t)=x(-2(t-1))$. Read the minus sign first: it flips time, not amplitude, so the factor acts as a reversal before the shift is applied.

$$
t_0=-2(t-1)
$$

Set the original time equal to the inside argument, then solve for $t$. This gives the inverse map $t=1-t_0/2$, which is the rule you reuse for every labeled time point.

$$
t=1-t_0/2
$$

Now apply the rule to the peak at $t_0=6$. Substituting gives $t=-2$, and the peak lands on the opposite side of $t=0$ because the negative scale factor reverses the time order before the shift is read. The peak height stays the same.

$$
t_0=6 \Rightarrow t=-2
$$

So the peak appears at $t=-2$. The order is reversal first, then shift right by $1$: flip by the negative scale factor, then apply the shift inside the parentheses.

## Factoring an Unfactored Time Argument Before Transforming

**Example:** Suppose $x(t)$ is nonzero on $[0,8]$ and let $y(t)=x(4t-12)$. Factor the argument and find the support of $y(t)$.

**Explanation**

The cue is the unfactored argument inside $x$ in $y(t)=x(4t-12)$. Rewrite it first so the scale-and-shift order is visible before you map the support.

$$
4t-12=4(t-3)
$$

Now set the original time $t_0$ equal to the inside argument and solve for $t$. This gives the inverse map $t=(t_0+12)/4$, which is the rule you reuse for every endpoint of the support.

$$
t=(t_0+12)/4
$$

Apply the map to the original support endpoints $t_0=0$ and $t_0=8$. They go to $t=3$ and $t=5$, so the transformed signal is nonzero on the interval between those times.

$$
t_0=0 \Rightarrow t=3, \quad t_0=8 \Rightarrow t=5
$$

So the support of $y(t)$ is $[3,5]$. Factoring first reveals the order: scale by $4$, then shift right by $3$.

## Recovering Transformation Order from a Graph

**Example:** Given a plotted source signal $x(t)$ with a peak at $t=6$ and support $[0,8]$, and a transformed graph with the peak at $t=5$ and support $[2,6]$, recover the operation order that produced the graph.

**Explanation**

The cue is the pair of graphs. Compare the support width and the landmark positions to recover the operation order from the picture.

![](<../Source/3.3.6. Order of Operations in Signal Transformations/Images/l006-s005-te-section-001.png>)

On $x(t)$, the support runs from $0$ to $8$, so the width is $8$. On $y(t)$, the support runs from $2$ to $6$, so the width is $4$. That means the time axis was compressed by a factor of $2$ before the shift.

$$
8/2=4
$$

With that scale factor, the inverse map is $t=t_0/2+2$. It sends the peak at $t_0=6$ to $t=5$.

$$
t=t_0/2+2
$$

$$
t_0=0 \Rightarrow t=2, \quad t_0=8 \Rightarrow t=6
$$

So the graph comes from scale by $2$ first, then shift right by $2$. The transformed peak at $5$ and support $[2,6]$ match that order.

## Comparing Graphs from Different Operation Orders

**Example:** Compare the graphs produced by $y_1(t)=x(2(t-2))$ and $y_2(t)=x(2t-2)$ for the same source signal, and explain how the different order changes the peak location and support.

**Explanation**

The cue is that both graphs come from the same source signal, so the only thing that changes is the order of the same shift and scale operations. Compare the peak and support placements to see which order produced each graph.

![](<../Source/3.3.6. Order of Operations in Signal Transformations/Images/l006-s006-te-section-001.png>)

For $y_1(t)=x(2(t-2))$, read the factor $2$ first. Scaling by $2$ compresses the original support width from $8$ to $4$ and moves the peak from $t_0=6$ to $t=3$; shifting right by $2$ then gives support $[2,6]$ and peak $5$.

$$
t_0=6 \Rightarrow t=5, \quad [0,8] \Rightarrow [2,6]
$$

For $y_2(t)=x(2t-2)$, start with the shift. Shifting right by $2$ moves the support to $[2,10]$ and the peak to $8$; scaling by $2$ then compresses that graph to support $[1,5]$ and peak $4$.

$$
t_0=6 \Rightarrow t=4, \quad [0,8] \Rightarrow [1,5]
$$

So the two orders are not interchangeable: scale-then-shift gives peak $5$ and support $[2,6]$, while shift-then-scale gives peak $4$ and support $[1,5]$.
