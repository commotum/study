## Introduction to The $0^-$ Convention

A one-sided Laplace transform step is a setup move for causal signals, so the target here is to define the integral format before any solving starts. The core move is to carry the origin convention explicitly so later examples treat discontinuities and impulses at $0$ consistently.

Use the interval choice $0^- \\le t < \\infty$ as the integration domain: for section work in this module, this is the signal-notation object that declares a causal transform setup.

With the base case $x(t)=u(t)$, the setup starts at $0^-$ so all causal support is included, including any jump or impulse behavior at the origin, while support for $t<0$ is excluded by definition.

$$
X(s)=\\int_{0^-}^{\\infty}x(t)e^{-st}\\,dt
$$

Section rule: write $X(s)=\\int_{0^-}^{\\infty}x(t)e^{-st}\\,dt$ first, then substitute $x(t)$; this is the format to reuse in every later example before applying the rest of the Laplace machinery.

## Setting a One-Sided Laplace Integral from $0^-$

**Example:** Write the one-sided setup for $x(t)=u(t)+2u(t-1)$ and keep the transform expression in the form of a causal integral.

**Explanation**

The cue is a causal signal written as a step sum: $x(t)=u(t)+2u(t-1)$. The action is to encode this signal in the one-sided template directly, so the setup stays symbolic and preserves the lower limit convention before any integration is done.

Use the one-sided rule for this module: for any causal setup, write $X(s)=\int_{0^-}^{\infty}x(t)e^{-st}\,dt$ first, then place $x(t)$ and keep the same bound for every causal branch.

$$
X(s)=\\int_{0^-}^{\\infty} x(t)e^{-st}\\,dt
$$

Decompose the cue into its pieces and substitute it into the template: $u(t)$ contributes over $[0^-,\infty)$ and $2u(t-1)$ is a delayed causal branch that is still inserted into the same $0^-$ setup without changing the lower limit.

$$
X(s)=\\int_{0^-}^{\\infty}[u(t)+2u(t-1)]e^{-st}\\,dt
$$

$$
X(s)=\\int_{0^-}^{\\infty}u(t)e^{-st}\\,dt+\int_{0^-}^{\\infty}2u(t-1)e^{-st}\\,dt
$$

Result: the final setup is notation-complete when it is expressed as a causal one-sided integral with $0^-$ explicitly present and the delayed step left as the same causal form; evaluation and simplification come later.

## Recognizing Signals That Change at $t=0$

**Example:** For $x(t)=\begin{cases}5,&t<0\\0,&0\le t<1\\2,&t\ge 1\end{cases}$, write the one-sided setup and identify which branch is included.

**Explanation**

The cue is the piecewise signal $x(t)$, so the first move is to mark which branches are active for each interval and then keep only the causal interval from the one-sided rule.

$$
x(t)=\begin{cases}5,&t<0\\0,&0\le t<1\\2,&t\ge 1\end{cases}
$$

Apply the same causal template used in previous sections: $X(s)=\int_{0^-}^{\infty}x(t)e^{-st}\,dt$. The lower bound remains $0^-$ and the integration only uses causal support.

$$
X(s)=\\int_{0^-}^{\\infty}x(t)e^{-st}\\,dt
$$

Since $x(t)=5$ for $t<0$, that branch is excluded by causality. On $[0,1)$ the branch is $0$, and for $t\ge 1$ the branch is $2$, so the causal setup can be written as the retained post-origin branch only.

$$
X(s)=\\int_{0^-}^{\\infty}x(t)e^{-st}\\,dt=\int_{1}^{\\infty}2e^{-st}\\,dt
$$

Result rule to carry forward: bounded jumps at $t=0$ do not add a finite-area term in the integral setup; only the interval starting at $0^-$ is kept and only causal branches contribute, with impulses handled separately by a distribution rule.

## Including an Impulse at $t=0$

**Example:** Find the one-sided Laplace setup and final transform expression for $x(t)=2\delta(t)+u(t)$.

**Explanation**

The cue is a mixed signal with an origin impulse and a causal step: $x(t)=2\delta(t)+u(t)$. The first action is to set the one-sided template exactly once, then separate the impulse and step parts.

Use the same causal rule from earlier sections: $X(s)=\int_{0^-}^{\infty}x(t)e^{-st}\,dt$. Keep this form first, then substitute the mixed signal into it.

$$
X(s)=\\int_{0^-}^{\\infty}[2\delta(t)+u(t)]e^{-st}\\,dt
$$

Split the setup into two terms and apply the origin rule for the $\delta$ contribution. The distribution term is supported at the lower endpoint, so $\int_{0^-}^{\infty}2\delta(t)e^{-st}\,dt=2$ under this convention.

$$
X(s)=\\int_{0^-}^{\\infty}2\delta(t)e^{-st}\\,dt+\\int_{0^-}^{\\infty}u(t)e^{-st}\\,dt
$$

The finite-jump rule from the previous section still applies separately: bounded jumps do not produce finite-area terms, but the impulse term does produce a constant contribution from the endpoint.

$$
X(s)=2+\\int_{0^-}^{\\infty}u(t)e^{-st}\\,dt
$$

Result: keep this as the final setup-expression form with one-sided lower limit and explicit impulse constant, then let later steps simplify the remaining one-sided step integral if needed.

## Excluding Signal Behavior Before $t=0$

**Example:** Write the one-sided setup for $x(t)=\begin{cases}3,&t<0\\t^2,&t\ge 0\end{cases}$ and state the excluded pre-origin branch.

**Explanation**

The cue is a piecewise signal with one noncausal branch and one causal branch. First separate support regions so that only post-origin content can survive the one-sided setup.

$$
x(t)=\begin{cases}3,&t<0\\t^2,&t\ge 0\end{cases}
$$

Apply the template from this topic: $X(s)=\int_{0^-}^{\infty}x(t)e^{-st}\,dt$. Keep $0^-$ fixed as the lower endpoint and enforce causality before writing any value changes.

$$
X(s)=\\int_{0^-}^{\\infty}x(t)e^{-st}\\,dt=\\int_{0^-}^{\\infty}t^2e^{-st}\\,dt
$$

Result: the excluded pre-origin branch is $x(t)=3$ for $t<0$, and the retained branch is $x(t)=t^2$ on $t\ge0$. This gives the compact direct-expression form used by the next question model: $X(s)=\int_{0^-}^{\infty}t^2e^{-st}\,dt$.
