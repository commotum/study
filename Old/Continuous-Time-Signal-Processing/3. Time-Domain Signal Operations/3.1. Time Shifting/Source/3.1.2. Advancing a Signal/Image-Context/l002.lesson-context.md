  image_slot_id: section-001
- paragraph:
  text: In the simplest base case, a single labeled feature at $t_0$ moves to $t_0-T$. That is the whole idea of an advance: the feature stays the same, and only its time location changes.
- display-math:
  latex: t_0\mapsto t_0-T
- paragraph:
  text: The same left shift applies to every key time point, breakpoint, and endpoint in the graph. If a signal is described by a landmark time, the advanced signal uses the same landmark moved left by $T$.
- display-math:
  latex: t_{\text{new}}=t_{\text{old}}-T
- paragraph:
  text: So an interval $[a,b]$ becomes $[a-T,b-T]$. The important check is that only the time locations change; the amplitudes, widths, and ordering stay the same.
- display-math:
