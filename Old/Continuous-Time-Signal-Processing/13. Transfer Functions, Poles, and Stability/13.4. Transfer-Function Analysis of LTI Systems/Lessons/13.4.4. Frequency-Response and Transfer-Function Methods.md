## Introduction to Frequency-Response and Transfer-Function Methods

Your method choice is controlled by two cues: the input representation and the required output behavior. If the input is given as a Laplace-domain expression or the goal is a full time-domain output, use the transfer-function branch. If the input is a sinusoid and the goal is sinusoidal steady-state response (gain and phase), use the frequency-response branch.

Use the transfer-function branch when the input is naturally in the $s$-domain. Form $Y(s)$ in one line and carry it through inverse transformation only after the domain math is complete.

$$
Y(s)=X(s)H(s)
$$

Use the frequency-response branch for sinusoidal steady-state work. With $x(t)=\cos(\omega t)$, the input is most direct through $X(j\omega)$, so output behavior is tracked by multiplication in the frequency domain.

$$
Y(j\omega)=X(j\omega)H(j\omega)
$$

If either the input form or the output target conflicts with the current branch, switch methods before algebra begins. This avoids forcing formulas into an incompatible representation.

Base case: for a single sinusoid input $x(t)=\cos(\omega t)$, use $H(j\omega)$ to get amplitude scaling and phase shift directly through $|Y(j\omega)|=|X(j\omega)||H(j\omega)|$, while the branch with $H(s)$ is reserved for full transfer-function-domain input/output workflows.

$$
|Y(j\omega)|=|X(j\omega)||H(j\omega)|
$$

Keep this rule as the section's reusable move: identify input/output form, pick exactly one branch, then execute that branch end-to-end.

## Using $H(s)$ for a Laplace-Domain Input

**Example:** Given $X(s)=\frac{1}{s+2}$ and $H(s)=\frac{3}{s+5}$, form $Y(s)$ and find $y(t)$ from $Y(s)=X(s)H(s)$.

**Explanation**

Because the input is already a Laplace-domain signal, use the $H(s)$ branch directly. The required flow is: choose branch, form $Y(s)$, simplify, then invert.

$$
Y(s)=X(s)H(s)
$$

Multiply the two first-order factors to form the product:

$$
Y(s)=\frac{1}{s+2}\cdot \frac{3}{s+5}=\frac{3}{(s+2)(s+5)}
$$

This is not a single-table lookup, so decompose into partial fractions so each term can invert cleanly.

$$
\frac{3}{(s+2)(s+5)}=\frac{A}{s+2}+\frac{B}{s+5}
$$

Solve coefficients by matching numerators: $3=A(s+5)+B(s+2)$. Substituting $s=-5$ gives $B=-1$, and substituting $s=-2$ gives $A=1$, so

$$
Y(s)=\frac{1}{s+2}-\frac{1}{s+5}
$$

Apply inverse Laplace to each term and keep the causal result:

$$
y(t)=e^{-2t}u(t)-e^{-5t}u(t)
$$

## Using $H(j\omega)$ for a Sinusoidal Input

**Example:** Given $x(t)=3\cos(4t+30^\circ)$ and $H(j\omega)=\frac{4}{1+j\omega}$, find the sinusoidal steady-state output $y_{ss}(t)$.

**Explanation**

The input is a single sinusoid and the goal is steady-state behavior, so this is a frequency-response case. The cue is to keep the input frequency $\omega=4$ and use $H(j\omega)$, not $H(s)$.

Evaluate the transfer function at the signal frequency:

$$
H(j\omega)=\frac{4}{1+j\omega},\quad H(j4)=\frac{4}{1+j4}
$$

Find the frequency-response gain and phase shift from $H(j4)$ so the sinusoid keeps the same frequency and receives only amplitude scaling and phase adjustment.

$$
|H(j4)|=\frac{4}{\sqrt{1^2+4^2}}=\frac{4}{\sqrt{17}},\quad \angle H(j4)=\tan^{-1}\!\left(\frac{-4}{1}\right)=-\tan^{-1}(4)
$$

Apply the sinusoidal frequency-response rule: for $x(t)=A\cos(\omega t+\phi)$, $y_{ss}(t)=A|H(j\omega)|\cos(\omega t+\phi+\angle H(j\omega))$.

$$
y_{ss}(t)=3\cdot\frac{4}{\sqrt{17}}\cos\left(4t+30^\circ-\tan^{-1}(4)\right)
$$

So the output remains a $4\,\mathrm{rad/s}$ sinusoid: the amplitude is scaled to $\frac{12}{\sqrt{17}}$ and the phase is shifted by $-\tan^{-1}(4)$ (about $-75.96^\circ$) from the input phase.

Numerically, this is $y_{ss}(t)\approx2.91\cos(4t-45.96^\circ)$, which is the expected same-frequency response from the frequency-response branch.

## Choosing the Method from the Input Description

**Example:** For each item below, choose the correct method branch and write the first equation form: (i) $x(t)=e^{-t}u(t)$, (ii) $x(t)=\cos(3t)$, given $H(s)$ is available. If only steady-state is requested in (ii), show the $H(j\omega)$ setup; otherwise use $H(s)$.

**Explanation**

Read each item and its requested output behavior before writing transforms. The rule is: use the $H(s)$ branch when the target is full response from a time-domain or Laplace-domain input, and use the $H(j\omega)$ branch when the target is sinusoidal steady-state.

Item (i) is $x(t)=e^{-t}u(t)$, an exponential-decay input with transient behavior implied by the form and no steady-state-only cue, so choose the transfer-function branch.

Write the first equation for item (i) in the transfer-function domain:

$$
Y(s)=X(s)H(s),\quad X(s)=\mathcal{L}\{e^{-t}u(t)\}=\frac{1}{s+1}
$$

This keeps the algebra in $s$ because the input is not a pure steady-state sinusoid and the expected workflow is full causal output.

Item (ii) is $x(t)=\cos(3t)$, and the prompt requires the steady-state setup, so this is the controlled branch change: use frequency-response form at the input frequency.

$$
Y_{ss}(j\omega)=X(j\omega)H(j\omega),\quad Y_{ss}(j3)=X(j3)H(j3)
$$

This step is complete once each branch is chosen and the first setup equation is written; the next step for practice is to evaluate output magnitude/phase for (ii) and perform full inverse transforms for (i).

## Matching the Method to the Desired Output Behavior

**Example:** A system has $H(s)=\frac{1}{s+1}$. For input $x(t)=2\cos(4t)$, compare method selection when the goal is (i) the complete output response and (ii) only the sinusoidal steady-state component.

**Explanation**

This is the same input with two output goals, so the branch decision is controlled by requested behavior rather than only the waveform class.

For (i), full response is required, so use transfer-function setup and plan for inversion in the $s$-domain.

First set the Laplace-domain equation for case (i):

$$
X(s)=\frac{2s}{s^2+16},\quad Y(s)=X(s)H(s)=\frac{2s}{(s^2+16)(s+1)}
$$

A complete $y(t)$ requires partial-fraction decomposition of $Y(s)$ and inverse Laplace, but the step here is to keep this case anchored to the $H(s)$ branch.

For (ii), the request is sinusoidal steady-state only, so switch to frequency-response form even though the input is sinusoidal and still match the stated objective.

$$
Y_{ss}(j\omega)=X(j\omega)H(j\omega),\quad Y_{ss}(j4)=X(j4)H(j4)
$$

Use the cosine steady-state rule with amplitude $A=2$ and frequency $\omega=4$. For the same input, $H(j4)=\frac{1}{1+j4}$, so $|H(j4)|=\frac{1}{\sqrt{17}}$, $\angle H(j4)=-\tan^{-1}(4)$.

$$
y_{ss}(t)=\frac{2}{\sqrt{17}}\cos\left(4t-\tan^{-1}(4)\right)
$$

Tie-break rule: same input can use both branches, and the requested output behavior decides which branch is correct—full causal response uses $H(s)$ first, sinusoidal steady-state uses $H(j\omega)$ first.
