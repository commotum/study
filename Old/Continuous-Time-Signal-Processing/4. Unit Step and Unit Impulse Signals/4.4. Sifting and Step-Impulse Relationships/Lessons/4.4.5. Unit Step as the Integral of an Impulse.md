## Introduction to Unit Step as the Integral of an Impulse

Let $y(t)=\int_{-\infty}^{t}\delta(\tau)\,d\tau$. This is an accumulation problem: it counts how much of the unit impulse's area has been included as the upper limit moves past $\tau=0$.

$$
y(t)=\int_{-\infty}^{t}\delta(\tau)\,d\tau
$$

Before the limit reaches the impulse, nothing has been accumulated, so $y(t)=0$ for $t<0$. Once the limit reaches or passes the impulse, the full unit area is included, so $y(t)=1$ for $t\ge 0$.

$$
y(t)=u(t)
$$

That $0$-to-$1$ switch is exactly the unit step $u(t)$, so the accumulated impulse is written as $y(t)=u(t)$. Read this as the basic switch rule: off before $0$, on at and after $0$, with the matching reverse relation $\frac{d}{dt}u(t)=\delta(t)$.

Use this as the base case for shifted impulses later: the only thing that changes is the time at which the accumulation window first includes the impulse area.

## Accumulating an Unshifted Unit Impulse

**Example:** Evaluate $\int_{-\infty}^{t} \delta(\tau)\,d\tau$ and write the result as a unit-step expression.

**Explanation**

The cue is the unit impulse at the origin. Let $y(t)=\int_{-\infty}^{t}\delta(\tau)\,d\tau$, so the task is to decide when the moving upper limit has included the unit area of $\delta(\tau)$.

$$
y(t)=\int_{-\infty}^{t}\delta(\tau)\,d\tau
$$

For $t<0$, the interval $(-\infty,t]$ stops before $\tau=0$, so no impulse area has been included and $y(t)=0$. For $t\ge 0$, the interval includes the impulse, so the full unit area has been included and $y(t)=1$.

$$
y(t)=\begin{cases}0, & t<0 \\ 1, & t\ge 0\end{cases}
$$

So the accumulated impulse is exactly the unit step: $y(t)=u(t)$. This is the baseline unshifted case that later examples will shift to other impulse locations.

## Accumulating a Shifted Unit Impulse

**Example:** Find $\int_{-\infty}^{t}\delta(\tau-3)\,d\tau$ and express the result as a unit step.

**Explanation**

The cue is the shifted unit impulse at $\tau=3$. Let $y(t)=\int_{-\infty}^{t}\delta(\tau-3)\,d\tau$, so the task is to decide when the moving upper limit has included the impulse area at that shift point.

$$
y(t)=\int_{-\infty}^{t}\delta(\tau-3)\,d\tau
$$

For $t<3$, the interval $(-\infty,t]$ stops before $\tau=3$, so no impulse area has been included and $y(t)=0$. For $t\ge 3$, the interval includes the impulse, so the full unit area has been included and $y(t)=1$.

$$
y(t)=\begin{cases}0, & t<3 \\ 1, & t\ge 3\end{cases}
$$

So the accumulated shifted impulse is exactly the shifted unit step: $y(t)=u(t-3)$. The only thing that changed from the unshifted case is the time at which the accumulation window first includes the unit area.

<a id="deciding-whether-the-impulse-has-been-included"></a>
## Deciding Whether the Impulse Has Been Included

**Example:** Decide if the impulse at $\tau=2$ has been accumulated in $\int_{-\infty}^{t}\delta(\tau-2)\,d\tau$ for $t=-1,2,5$ and state the matching step form.

**Explanation**

The cue is the shifted unit impulse centered at $\tau=2$. Let $y(t)=\int_{-\infty}^{t}\delta(\tau-2)\,d\tau$, so the task is to test whether the moving upper limit has reached the shift point before labeling the output.

$$
y(t)=\int_{-\infty}^{t}\delta(\tau-2)\,d\tau
$$

For $t=-1$, the interval $(-\infty,t]$ stops before $\tau=2$, so the impulse has not been included and the value is $0$. For $t=2$, the interval reaches the impulse location, so the unit area is included and the value is $1$. For $t=5$, the interval is already past the impulse, so the value is still $1$.

$$
y(t)=\begin{cases}0, & t<2 \\ 1, & t\ge 2\end{cases}
$$

So the inclusion test switches exactly at $t=2$, which means the accumulated impulse is the shifted unit step $u(t-2)$. The rule to carry forward is to compare the moving upper limit to the impulse location, then write $0$ before inclusion and $1$ at or after inclusion.

## Converting Scaled Impulse Accumulations into Scaled Steps

**Example:** Convert $\int_{-\infty}^{t} 5\delta(\tau+1)\,d\tau$ into its unit-step form.

**Explanation**

The cue is a scaled impulse centered at $\tau=-1$. Use linearity first: the factor $5$ stays attached while the accumulation test still checks whether the moving upper limit has reached the impulse location.

$$
y(t)=\int_{-\infty}^{t} 5\delta(\tau+1)\,d\tau
$$

For $t<-1$, the interval $(-\infty,t]$ stops before $\tau=-1$, so the impulse has not been included and the value is $0$. For $t\ge -1$, the interval includes the full unit area, so the scale factor carries through and the value is $5$.

$$
y(t)=\begin{cases}0, & t<-1 \\ 5, & t\ge -1\end{cases}
$$

So the accumulated scaled impulse is $y(t)=5u(t+1)$. The rule to carry forward is simple: keep the coefficient, check the shifted include point, and then write the corresponding scaled step.
