## Introduction to System Output from Input and Impulse Response

In this lesson, the input signal is written as $x(t)$, the impulse response is written as $h(t)$, and the output signal is written as $y(t)$. The impulse response $h(t)$ describes the LTI system, so once $x(t)$ and $h(t)$ are known, the output is determined by convolution.

$$
y(t)=(x*h)(t)
$$

This equation says that the output value at time t is the convolution of the input with the impulse response. The variable t is the output time, so the final answer is still a function of t.

To compute that convolution directly, use a dummy integration variable $\tau$. The input $x(t)$ becomes $x(\tau)$, and the impulse response $h(t)$ becomes $h(t-\tau)$.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

The basic workflow is: identify $x(t)$, $h(t)$, and $y(t)$; write the convolution integral; substitute the formulas as $x(\tau)$ and $h(t-\tau)$; then evaluate the resulting integral for the output. Later sections will practice those moves one at a time.

## Identifying the Input, Impulse Response, and Output

**Example:** A causal LTI system is driven by input $x(t)=u(t)-u(t-2)$ and has impulse response $h(t)=e$^{-t}$u(t)$. Identify the input signal, impulse response, and output symbol.

**Explanation**

Start by matching each phrase in the statement to its role. The phrase "driven by input" names the input signal, so the input is $x(t)$.

$$
x(t)=u(t)-u(t-2)
$$

The phrase "has impulse response" names the system's impulse response, so the impulse response is $h(t)$.

$$
h(t)=e^{-t}u(t)
$$

The output signal is the unknown response of the LTI system. We name it $y(t)$, and it is the convolution of the input with the impulse response.

$$
y(t)=(x*h)(t)
$$

So the labels are: input $x(t)=u(t)-u(t-2)$, impulse response $h(t)=e$^{-t}$u(t)$, and output $y(t)$. This step only identifies the roles; the convolution integral is set up later.

## Writing the Output as a Convolution Integral

**Example:** An LTI system has input $x(t)=u(t)-u(t-1)$ and impulse response $h(t)=e$^{-2t}$u(t)$. Write the output $y(t)$ as a convolution integral before substituting the formulas.

**Explanation**

The cue is that the system is LTI and the statement gives both the input $x(t)$ and the impulse response $h(t)$. For an LTI system, the output is the convolution of those two signals.

$$
y(t)=(x*h)(t)
$$

To write this as an integral, use $\tau$ as the integration variable. The input is read at $\tau$, and the impulse response is read at t-$\tau$.

$$
x(t)\to x(\tau),\qquad h(t)\to h(t-\tau)
$$

Now place those two factors inside the convolution integral, integrate with respect to $\tau$, and use infinite bounds for the general continuous-time convolution form.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

This is the requested setup. The given formulas for $x(t)$ and $h(t)$ have not been substituted yet; that is the next move after the convolution template is written.

<a id="substituting-xtau-and-ht-tau-into-the-integral"></a>
## Substituting $x(\tau)$ and $h(t - \tau)$ into the Integral

**Example:** For $x(t)=u(t)-u(t-1)$ and $h(t)=e$^{-2t}$u(t)$, substitute $x(\tau)$ and $h(t-\tau)$ into the convolution integral for $y(t)$.

**Explanation**

Start from the convolution integral formed in the previous step. The new move is to replace the symbolic factors $x(\tau)$ and $h(t-\tau)$ with the matching formulas from the problem.

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
$$

For the input, replace every t in $x(t)=u(t)-u(t-1)$ with $\tau$. This gives the factor $x(\tau)$.

$$
x(\tau)=u(\tau)-u(\tau-1)
$$

For the impulse response, replace every t in $h(t)=e$^{-2t}$u(t)$ with t-$\tau$. This gives the shifted factor $h(t-\tau)$.

$$
h(t-\tau)=e^{-2(t-\tau)}u(t-\tau)
$$

Now multiply those two substituted factors inside the same integral. Keep the infinite bounds and do not evaluate or simplify the overlap regions yet.

$$
y(t)=\int_{-\infty}^{\infty}[u(\tau)-u(\tau-1)]e^{-2(t-\tau)}u(t-\tau)\,d\tau
$$

This is the substituted convolution integral. The setup is complete for this section; evaluating the integral is a separate step.

<a id="evaluating-the-integral-for-the-output-signal"></a>
## Evaluating the Integral for the Output Signal

**Example:** For an LTI system with input $x(t)=e$^{-t}$u(t)$ and impulse response $h(t)=u(t)$, the convolution setup on $0<t<1$ is $y(t)$=$\int$_0^t $e^{-\tau}$\,d$\tau$. Evaluate $y(t)$ on this interval.

**Explanation**

The convolution setup and the time region are already given. The task is only to evaluate the definite integral for $0<t<1$.

$$
y(t)=\int_0^t e^{-\tau}\,d\tau
$$

Integrate with respect to $\tau$. An antiderivative of $e^{-\tau}$ is -$e^{-\tau}$.

$$
\int e^{-\tau}\,d\tau=-e^{-\tau}
$$

Apply the upper bound $\tau$=t and the lower bound $\tau$=0, then simplify.

$$
y(t)=\left[-e^{-\tau}\right]_0^t=-e^{-t}-(-e^0)=1-e^{-t}
$$

Attach the stated interval to the result: on $0<t<1$, the output is $y(t)=1-e$^{-t}.

  $$
