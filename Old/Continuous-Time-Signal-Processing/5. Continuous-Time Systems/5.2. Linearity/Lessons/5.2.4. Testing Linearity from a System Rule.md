## Introduction to Testing Linearity from a System Rule

To test linearity for a system rule $T\{\cdot\}$, check whether the operator gives matching results from two equivalent constructions.

Use two generic inputs $x_1(t)$ and $x_2(t)$ and a scalar $a$ to write the superposition comparison without plugging numbers yet.

$$
T\{a[x_1(t)+x_2(t)]\}=aT\{x_1(t)+x_2(t)\}?
$$

$$
T\{a x_1(t)\}+T\{a x_2(t)\}=aT\{x_1(t)\}+aT\{x_2(t)\}?
$$

Use the base rule $T\{x(t)\}=3x(t)$ with $x_1(t)=u(t)$, $x_2(t)=2u(t)$, and $a=2$ to keep the first check concrete.

$$
T\{2[u(t)+2u(t)]\}=T\{6u(t)\}=18u(t),\\ T\{2u(t)\}=6u(t),\\ T\{2\cdot 2u(t)\}=12u(t),\\ 2T\{u(t)\}+2T\{2u(t)\}=18u(t)
$$

Pass/fail rule: if the two expressions are identical for the checked inputs and scale, the rule passes this linearity check for that test case; later steps will reuse the same template with more direct verification steps before practice.

## Setting Up the Superposition Test from a Rule

**Example:** For $T\{x(t)\}=3x(t)$, write the two expressions in the superposition test using the input symbols $x_1(t)$, $x_2(t)$, and scale $a$.

**Explanation**

The cue is the same as the previous tutorial: choose the two expressions the superposition test compares, but now instantiate them for a concrete rule.

For a symbolic check, the first expression applies the system to a scaled sum, $T\{a[x_1(t)+x_2(t)]\}$, and the second is the scaled sum of separate outputs, $aT\{x_1(t)\}+aT\{x_2(t)\}$.

$$
T\{a[x_1(t)+x_2(t)]\} \stackrel{\text{LHS}}{=} ?,\\ aT\{x_1(t)\}+aT\{x_2(t)\} \stackrel{\text{RHS}}{=} ?
$$

Now substitute the rule $T\{x(t)\}=3x(t)$ into each side without evaluating $x_1$ and $x_2$ numerically.

$$
T\{a[x_1(t)+x_2(t)]\}=3a[x_1(t)+x_2(t)],\\ aT\{x_1(t)\}+aT\{x_2(t)\}=a(3x_1(t))+a(3x_2(t))=3a[x_1(t)+x_2(t)]
$$

Result: the symbolic setup is complete and both sides now share the same target expression, so this is the correct form to pass to the next step for verification or mismatch checking.

## Computing the Output for a Scaled Sum of Inputs

**Example:** Evaluate the left-hand side $T\{2[x_1(t)+x_2(t)]\}$ for $x_1(t)=2t$, $x_2(t)=t-1$ using $T\{x(t)\}=3x(t)$.

**Explanation**

Start with the cue: this step asks for the left-hand side of the superposition test, so keep the input in the form $2[x_1(t)+x_2(t)]$ and apply the rule directly.

$$
x_1(t)+x_2(t)=2t+(t-1)=3t-1
$$

Now scale the combined input before the system acts: $2[x_1(t)+x_2(t)] = 2(3t-1) = 6t-2$.

$$
T\{2[x_1(t)+x_2(t)]\}=3\bigl(2[x_1(t)+x_2(t)]\bigr)=3(6t-2)=18t-6
$$

The computed left-hand expression is $18t-6$. That is the output for the scaled sum, and it is the quantity to compare with the right-hand side in the test.

## Computing the Scaled Sum of Separate Outputs

**Example:** Evaluate the right-hand side $2[T\{x_1(t)\}+T\{x_2(t)\}]$ for $x_1(t)=2t$, $x_2(t)=t-1$ using $T\{x(t)\}=3x(t)$.

**Explanation**

Start with the right-hand side of the test: compute each transformed input separately, then scale and combine the results.

$$
T\{x_1(t)\}=3(2t)=6t,\qquad T\{x_2(t)\}=3(t-1)=3t-3
$$

Now add the separate outputs before applying the scalar $2$: $T\{x_1(t)\}+T\{x_2(t)\}=6t+(3t-3)=9t-3$.

$$
2[T\{x_1(t)\}+T\{x_2(t)\}]=2(9t-3)=18t-6
$$

The scaled sum of separate outputs is $18t-6$, which matches the left-hand result from section 3.

## Verifying Linearity When the Two Expressions Match

**Example:** Compare section-3 and section-4 results for $T\{x(t)\}=3x(t)$, $x_1(t)=2t$, $x_2(t)=t-1$, $a=2$ and state whether the rule is linear in this test.

**Explanation**

Write both computed expressions next to each other so the comparison is direct.

$$
T\{2[x_1(t)+x_2(t)]\}=18t-6,\qquad 2[T\{x_1(t)\}+T\{x_2(t)\}]=18t-6
$$

Both sides simplify to the same expression, $18t-6$, so the superposition test passes for this input pair and scale.

Because the two expressions match exactly, the rule $T\{x(t)\}=3x(t)$ is linear for this test case.

## Rejecting Linearity When the Two Expressions Do Not Match

**Example:** Apply superposition to $T\{x(t)\}=x(t)^2$ with $x_1(t)=t$, $x_2(t)=1$, and $a=2$; compare $T\{2[x_1(t)+x_2(t)]\}$ and $2[T\{x_1(t)\}+T\{x_2(t)\}]$.

**Explanation**

Start with the same comparison workflow, but now the rule squares its input, so a mismatch can appear from the expansion.

$$
T\{2[x_1(t)+x_2(t)]\}=[2(t+1)]^2=4t^2+8t+4
$$

Now compute the transformed inputs separately: $T\{x_1(t)\}=t^2$ and $T\{x_2(t)\}=1$, so their scaled sum is $2[t^2+1]$.

$$
2[T\{x_1(t)\}+T\{x_2(t)\}]=2(t^2+1)=2t^2+2
$$

The two expressions do not match: the left-hand side has the extra cross-term and the wrong scaling pattern, so the rule is nonlinear.
