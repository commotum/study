- paragraph:
  text: Treat automobile motion as a continuous-time system: one motion signal goes in, another motion signal comes out, and the system rule tells you how they are connected. In the simplest version of this topic, take acceleration $a(t)$ as the input and velocity $v(t)$ or position $x(t)$ as the output.
- image:
  image_slot_id: section-001-image-001
- paragraph:
  text: The key modeling move is to express that connection with a kinematic rule. If acceleration is the input, then velocity is obtained by integrating acceleration, and position is obtained by integrating velocity. The same physical motion can therefore be written as more than one valid input-output pair, as long as the direction of the rule is consistent.
- display-math:
  latex: v(t) = \int a(\tau)\,d\tau + C
- paragraph:
  text: For the base case, imagine a car with constant acceleration $a(t)=a_0$ and zero initial velocity and position. Then the system produces a velocity that grows linearly in time, and that same output can be integrated again to get position. This is the cleanest starting point for recognizing automobile motion as a system.
- display-math:
  latex: x(t) = \int v(\tau)\,d\tau + D
- paragraph:
  text: So the core idea is simple: choose a physical input and output, then write the rule that maps one to the other with the correct integration direction and initial-condition convention. Later sections will use this same setup to test which signal plays each role and how the rule changes when the chosen pair changes.
