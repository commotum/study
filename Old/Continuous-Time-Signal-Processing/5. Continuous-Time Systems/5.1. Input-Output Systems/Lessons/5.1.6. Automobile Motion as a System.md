## Introduction to Automobile Motion as a System

Treat automobile motion as a continuous-time system: one motion signal goes in, another motion signal comes out, and the system rule tells you how they are connected. In the simplest version of this topic, take acceleration $a(t)$ as the input and velocity $v(t)$ or position $x(t)$ as the output.

![](<../Source/5.1.6. Automobile Motion as a System/Images/l006-s001-te-section-001-image-001.png>)

The key modeling move is to express that connection with a kinematic rule. If acceleration is the input, then velocity is obtained by integrating acceleration, and position is obtained by integrating velocity. The same physical motion can therefore be written as more than one valid input-output pair, as long as the direction of the rule is consistent.

$$
v(t) = \int a(\tau)\,d\tau + C
$$

For the base case, imagine a car with constant acceleration $a(t)=a_0$ and zero initial velocity and position. Then the system produces a velocity that grows linearly in time, and that same output can be integrated again to get position. This is the cleanest starting point for recognizing automobile motion as a system.

$$
x(t) = \int v(\tau)\,d\tau + D
$$

So the core idea is simple: choose a physical input and output, then write the rule that maps one to the other with the correct integration direction and initial-condition convention. Later sections will use this same setup to test which signal plays each role and how the rule changes when the chosen pair changes.

## Choosing Automobile Motion Input and Output Signals

**Example:** A car's acceleration is known as a function of time. Velocity is monitored as output. Write the valid input-output statement for the motion system.

**Explanation**

The cue is that acceleration is the given motion signal and velocity is the monitored quantity. That makes $a(t)$ the natural input and $v(t)$ the output.

With that choice, the motion rule is a one-step kinematic map from acceleration to velocity. In operator form, write $v(t)=\mathcal{T}\{a(t)\}$; in integration form, the same rule is

$$
v(t)=\int_{0}^{t} a(\tau)\,d\tau+v(0)
$$

This pairing is valid because one integration changes the signal from acceleration units to velocity units, and the signal direction stays consistent with the system description. The result is a clean input-output statement for automobile motion.

## Modeling Acceleration as the Input and Velocity as the Output

**Example:** Model a system with input $a(t)$ and output $v(t)$ where $a(t)=3$ and $v(0)=2$. Compute the explicit output rule.

**Explanation**

The cue is that acceleration is the input signal and velocity is the output signal, so this is a one-step kinematic system from $a(t)$ to $v(t)$. The goal is to write the system rule in a form that keeps the integration direction and initial condition visible.

$$
v(t)=\int_{0}^{t} a(\tau)\,d\tau+v(0)
$$

Substitute the constant acceleration input $a(t)=3$ and use the given initial value $v(0)=2$. The integral of a constant over $[0,t]$ is linear in $t$, so the output stays in the same signal family as the input-rule description predicts.

$$
v(t)=\int_{0}^{t} 3\,d\tau+2=3t+2
$$

So the explicit system rule is $v(t)=3t+2$. That is the correct input-output model: acceleration drives velocity, the constant of integration is fixed by $v(0)$, and the notation stays consistent with the motion-system setup.

## Modeling Velocity as the Input and Position as the Output

**Example:** Represent the system with input $v(t)$ and output $x(t)$, then compute $x(t)$ for $v(t)=2t+1$ and $x(0)=0$.

**Explanation**

The cue is that velocity is the given motion signal and position is the accumulated quantity, so this is the next kinematic stage from $v(t)$ to $x(t)$. The goal is to write the system rule in a form that keeps the integration direction and initial condition visible.

$$
x(t)=\int_{0}^{t} v(\tau)\,d\tau+x(0)
$$

Substitute the given velocity input $v(t)=2t+1$ and use the initial value $x(0)=0$. Integrate term by term so the output rule stays aligned with the same input-output convention used in the previous section.

$$
x(t)=\int_{0}^{t} (2\tau+1)\,d\tau+0=t^2+t
$$

So the explicit system rule is $x(t)=t^2+t$. That is the correct input-output model: velocity drives position, the constant of integration is fixed by $x(0)$, and the notation remains consistent with the motion-system setup.

<a id="representing-acceleration-to-position-motion-as-an-input-output-system"></a>
## Representing Acceleration-to-Position Motion as an Input-Output System

**Example:** Model the system from $a(t)$ directly to $x(t)$ and compute $x(t)$ for $a(t)=t$, $v(0)=1$, $x(0)=2$.

**Explanation**

The cue is that acceleration is the input and position is the final output, but this system has two integration stages. The rule is to chain the acceleration-to-velocity map with the velocity-to-position map, keeping both initial conditions visible.

$$
v(t)=\int_0^t a(\tau)\,d\tau+v(0),\qquad x(t)=\int_0^t v(\sigma)\,d\sigma+x(0)
$$

First compute the intermediate velocity from $a(t)=t$ and $v(0)=1$. That gives the signal that feeds the second stage of the system.

$$
v(t)=\int_0^t \tau\,d\tau+1=\frac{t^2}{2}+1
$$

Now insert that velocity into the position rule and apply $x(0)=2$. This turns the two-step kinematic relation into one direct input-output model from acceleration to position.

$$
x(t)=\int_0^t \left(\frac{\sigma^2}{2}+1\right)\,d\sigma+2=\frac{t^3}{6}+t+2
$$

So the composed system rule is a two-integral chain from $a(t)$ to $x(t)$, with $v(0)$ and $x(0)$ fixing the constants. For this input, the output is $x(t)=\frac{t^3}{6}+t+2$.

```quiz

id: EE01-M05-01-L06-q007
content: |-
  For $a(t)=3t$, with $v(0)=2$ and $x(0)=-1$, derive $x(t)$ directly from the acceleration-to-position chain $a(t) \to v(t) \to x(t)$.

correct: |-
  $x(t)=\frac{t^3}{2}+2t-1$

feedback: |-
  First integrate acceleration to get velocity with the given initial condition.

  $$
  v(t)=\int_{0}^{t} a(\tau)\,d\tau+v(0)=\int_{0}^{t}3\tau\,d\tau+2=\frac{3}{2}t^2+2
  $$

  Now integrate velocity to get position and apply $x(0)=-1$.

  $$
  x(t)=\int_{0}^{t} v(\sigma)\,d\sigma+x(0)=\int_{0}^{t}\left(\frac{3}{2}\sigma^2+2\right)d\sigma-1=\frac{t^3}{2}+2t-1
  $$
```

```quiz
  $$
```
