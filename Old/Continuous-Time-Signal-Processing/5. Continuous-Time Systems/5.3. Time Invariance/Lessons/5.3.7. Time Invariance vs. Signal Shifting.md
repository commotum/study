## Introduction to Time Invariance vs. Signal Shifting

Signal shifting means moving one waveform in time. Delay the input by $\tau$ with $x(t-\tau)$, and advance it by $\tau$ with $x(t+\tau)$; this is a shift in the argument, not a change in signal shape.

Time invariance is the property that a continuous-time system preserves that same shift at the output. Compare two paths: first shift the input and then apply the system, versus applying the system first and shifting the output afterward.

Use this test rule: let $y(t)=T\{x(t)\}$, then form $T\{x(t-\tau)\}$ and compare it to $y(t-\tau)$. If the expressions are identical for all $\tau$ and for the same $x(t)$, the system is time invariant.

The goal is identical delay propagation: the output must be delayed (or advanced) by the same amount and in the same direction, with no additional algebraic change beyond that shift.

$$
y(t)=T\{x(t)\}
$$

$$
T\{x(t-\tau)\}
$$

$$
y(t-\tau)
$$

$$
T\{x(t-\tau)\}=y(t-\tau)
$$

## Identifying Signal Shifting as an Operation on One Signal

**Example:** Given the signal $x(t)$, interpret the shifted inputs $x(t-3)$ and $x(t+2)$ as delayed or advanced versions of the same waveform before any system is applied.

**Explanation**

Use the cue from the prompt: the core input is $x(t)$, and the only change shown is a substituted time argument. First, identify the unshifted reference signal as $x(t)$.

Read $x(t-3)$ as $x(t)$ delayed by $3$ in time, so its feature at time $t$ now appears at $t-3$. Read $x(t+2)$ as $x(t)$ advanced by $2$, so its feature at time $t$ now appears at $t+2$.

This operation only changes the argument value where the same waveform is sampled. The signal rule and shape are preserved; the rule is still the same $x(\cdot)$ relation to time, with horizontal placement shifted.

Keep this distinction separate from system-level claims: at this step, we are only classifying the input expression. A time-invariance test comes next, after a system rule is introduced.

## Comparing the Shift-Then-System and System-Then-Shift Paths

**Example:** For the system $T\{x(t)\}=x^2(t)$, compare the output for the shifted input $x(t-\tau)$ with the shifted original output $y(t-\tau)$ when $y(t)=T\{x(t)\}$.

**Explanation**

Start with the original output $y(t)=x^2(t)$. The time-invariance test asks whether shifting the input first gives the same result as shifting this output by the same amount.

$$
y(t)=x^2(t)
$$

For the shift-then-system path, replace $x(t)$ by $x(t-\tau)$ inside the rule. That gives $T\{x(t-\tau)\}=x^2(t-\tau)$.

$$
T\{x(t-\tau)\}=x^2(t-\tau)
$$

For the system-then-shift path, shift the finished output $y(t)$ by the same amount. Replacing $t$ with $t-\tau$ in $y(t)=x^2(t)$ gives $y(t-\tau)=x^2(t-\tau)$.

$$
y(t-\tau)=x^2(t-\tau)
$$

The two paths produce the same expression, so the input delay is preserved at the output. That is exactly what it means for the system to be time invariant.

<a id="recognizing-preserved-delays-as-time-invariant-behavior"></a>
## Recognizing Preserved Delays as Time-Invariant Behavior

**Example:** For the system $T\{x(t)\}=x(t)+x(t-1)$ and input $x(t-\tau)$, show that the output is exactly the delayed version of the original output.

**Explanation**

Start by writing the original output. The rule adds the current input and a one-unit delayed copy, so the output is $y(t)=x(t)+x(t-1)$.

$$
y(t)=x(t)+x(t-1)
$$

Now apply the system to the shifted input $x(t-\tau)$. Replace $x(t)$ everywhere in the rule by $x(t-\tau)$, which gives the shift-then-system output.

$$
T\{x(t-\tau)\}=x(t-\tau)+x(t-1-\tau)
$$

Next shift the original output by the same amount. Replacing $t$ with $t-\tau$ in $y(t)=x(t)+x(t-1)$ gives the system-then-shift output.

$$
y(t-\tau)=x(t-\tau)+x(t-1-\tau)
$$

The two expressions are identical term by term, so the delay is preserved by the system. That preserved-delay match is the signature of time-invariant behavior.

## Rejecting Time Invariance from a Single Shifted Output

**Example:** For the system $T\{x(t)\}=t\,x(t)$, compare the output for $x(t-\tau)$ with $y(t-\tau)$ and show the paths do not match.

**Explanation**

Start with the original output $y(t)=t\,x(t)$. The time-invariance test asks whether shifting the input produces exactly the same delay on the output and nothing else changes.

$$
y(t)=t\,x(t)
$$

For the shift-then-system path, replace $x(t)$ by $x(t-\tau)$ inside the rule. The factor $t$ stays tied to the current time, so the shifted-input output is $T\{x(t-\tau)\}=t\,x(t-\tau)$.

$$
T\{x(t-\tau)\}=t\,x(t-\tau)
$$

For the system-then-shift path, shift the finished output by the same amount. Replacing $t$ with $t-\tau$ in $y(t)=t\,x(t)$ gives $y(t-\tau)=(t-\tau)\,x(t-\tau)$.

$$
y(t-\tau)=(t-\tau)\,x(t-\tau)
$$

The two expressions are not equal because one path keeps the factor $t$ while the other changes it to $t-\tau$. Since the delay is not preserved exactly, the system is not time invariant.
