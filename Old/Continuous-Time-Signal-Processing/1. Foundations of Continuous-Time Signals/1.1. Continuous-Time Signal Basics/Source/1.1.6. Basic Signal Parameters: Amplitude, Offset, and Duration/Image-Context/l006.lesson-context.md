Tutorial blocks:
- paragraph:
  text: When you read a continuous-time signal, three basic parameters describe the active part of the signal: how tall it is, where it is centered vertically, and how long it lasts. These are called amplitude, vertical offset, and duration.
- image:
  image_slot_id: section-001
- paragraph:
  text: Amplitude is a vertical distance. If the active part of the signal has maximum value $M$ and minimum value $m$, then the peak-to-peak range is $M-m$, so the amplitude is half of that range. The vertical offset is the center level halfway between the same maximum and minimum.
- display-math:
  latex: \begin{aligned}
A &= \frac{M-m}{2} \\
C &= \frac{M+m}{2}
\end{aligned}
- paragraph:
  text: Duration is a horizontal length. First identify the nonzero support interval: the time interval where the signal is not zero. If that interval starts at $t_{\text{start}}$ and ends at $t_{\text{end}}$, then the duration is the end time minus the start time.
- display-math:
  latex: D=t_{\text{end}}-t_{\text{start}}
- paragraph:
  text: Use the same order each time: identify the active extrema, identify the baseline or center level, locate the nonzero support endpoints, and then report amplitude, vertical offset, and duration.
