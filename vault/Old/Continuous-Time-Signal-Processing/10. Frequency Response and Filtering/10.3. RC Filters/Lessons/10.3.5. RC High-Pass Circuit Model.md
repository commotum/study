## Introduction to RC High-Pass Circuit Model

The RC high-pass circuit is the physical LTI filter to recognize here. In the standard schematic, the input source feeds a capacitor in series, and the resistor drops from the output node to ground.

![](<../Source/10.3.5. RC High-Pass Circuit Model/Images/l005-s001-te-section-001.png>)

Read the capacitor as the series element and the resistor as the shunt-to-ground path. That wiring is the base case you will keep using in this lesson.

The output is the resistor voltage, $v_{out}(t)$, not the capacitor voltage. That output choice is what makes this the high-pass model.

Keep this input-output picture in mind. Later sections will use the same circuit to write the differential equation and the frequency response without redrawing the full model.

<a id="identifying-the-series-capacitor-and-resistor-to-ground"></a>
## Identifying the Series Capacitor and Resistor-to-Ground

**Example:** In the RC high-pass circuit shown, identify which element is the series capacitor and which element is connected from the output node to ground.

**Explanation**

The cue here is the high-pass topology: the input source at $v_{in}(t)$ reaches the output node through a series capacitor, and the resistor returns that node to ground.

![](<../Source/10.3.5. RC High-Pass Circuit Model/Images/l005-s002-te-section-002.png>)

Trace the input source to the first passive element on the path. That first element is the series capacitor, because it sits directly between the input and the output node.

Now follow the branch from the output node to ground. That branch is the resistor-to-ground path, which is the second defining element of the model.

So the correct circuit description is: series capacitor, then resistor to ground. Keep this arrangement fixed; later sections will use the same schematic to locate the signals and then treat the circuit as an LTI model.

## Locating the Input Voltage and Resistor-Voltage Output

**Example:** In the same RC high-pass circuit, locate the input voltage and the resistor-voltage output.

**Explanation**

Use the circuit layout as the cue: the source-side node is where the input enters, and the resistor branch is where the output is taken. In an RC high-pass circuit, the signal port is the same physical network you identified before, but now you read it as an input-output system.

![](<../Source/10.3.5. RC High-Pass Circuit Model/Images/l005-s003-te-section-003.png>)

Mark the source-side node as $v_{in}(t)$. That is the input voltage, because it is the driving signal applied to the circuit before the series capacitor.

Mark the voltage across the resistor as $v_{out}(t)$. The output is measured from the output node down to ground across the resistor, not across the capacitor.

So the model is an input at the source and an output across the resistor. That port choice is the one you carry forward into the differential-equation and frequency-response sections.

<a id="interpreting-the-high-pass-circuit-as-an-lti-system"></a>
## Interpreting the High-Pass Circuit as an LTI System

**Example:** Treat the RC high-pass circuit as an LTI system by naming its input, output, and fixed passive elements.

**Explanation**

Use the port labels as the cue: the source-side signal is $v_{in}(t)$ and the resistor voltage is $v_{out}(t)$. That turns the same circuit diagram into an input-output model instead of just a parts diagram.

![](<../Source/10.3.5. RC High-Pass Circuit Model/Images/l005-s004-te-section-004.png>)

Treat the capacitor and resistor as fixed passive elements. They do not change with time, so they define a fixed network for the signal to pass through.

With one input, one output, and fixed passive elements, the circuit is a linear time-invariant system. In other words, it is a stable RC filter model with a consistent input-output relationship.

That is the interpretation you carry forward into the differential-equation and frequency-response sections: the circuit is not just a schematic, it is the filter model you will analyze.

## Distinguishing the High-Pass Model from the Low-Pass Model

**Example:** Compare the high-pass schematic with the low-pass schematic and identify the placement difference that makes this model high-pass.

**Explanation**

Use the low-pass model as the contrast cue. The two circuits use the same capacitor and resistor, but the order of those elements and the output node are what change the filter type.

![](<../Source/10.3.5. RC High-Pass Circuit Model/Images/l005-s005-te-section-005.png>)

In the high-pass model, the capacitor is in series with the input path and the resistor goes to ground. In the low-pass model, the resistor is in series and the capacitor goes to ground.

Check the output node next. The high-pass output is across the resistor, while the low-pass output is across the capacitor.

That is the distinguishing feature: high-pass means capacitor first, resistor to ground, and output across the resistor. The same parts arranged the other way give the low-pass model instead.
