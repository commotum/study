## Introduction to Phase Response

Phase response is the phase part of the frequency response. For a sinusoidal component at frequency $\omega_0$, $\angle H(j\omega_0)$ is the phase shift the system adds. It changes timing, not amplitude.

$$
x(t)=A\cos(\omega_0 t+\phi)
$$

Use a single cosine input $x(t)=A\cos(\omega_0 t+\phi)$ so only one frequency and one phase adjustment are in play. The system keeps the same sinusoid frequency, scales the amplitude by $|H(j\omega_0)|$, and adds the system phase to the input phase.

$$
y(t)=A|H(j\omega_0)|\cos\big(\omega_0 t+\phi+\angle H(j\omega_0)\big)
$$

With this sign convention, positive $\angle H(j\omega_0)$ advances the sinusoid and negative $\angle H(j\omega_0)$ delays it. Later examples will use that timing language directly when they read phase response.

$$
\text{phase shift at }\omega_0=\angle H(j\omega_0)
$$

## Reading $\angle$ $H(j\omega)$ at a Single Frequency

**Example:** Given $H(j4)=3e^{j\pi/4}$, identify the phase shift experienced by a sinusoidal input at $\omega=4$.

**Explanation**

The cue is the single frequency $\omega=4$, and the response is already written in polar form as $H(j4)=3e^{j\pi/4}$. For phase response, read the angle, not the magnitude, because the angle is the phase shift at that frequency.

$$
H(j4)=3e^{j\pi/4}
$$

The argument of $H(j4)$ is $\pi/4$, so the phase shift at $\omega=4$ is $\pi/4$. In lead-or-lag language, this is a phase lead of $\pi/4$.

$$
\angle H(j4)=\pi/4
$$

## Applying Phase Response to a Sinusoidal Component

**Example:** If $x(t)=\cos(2t+\pi/4)$ and $\angle H(j2)=-\pi/6$, write the steady-state output phase for the sinusoidal component.

**Explanation**

The cue is a single sinusoid at $\omega_0=2$: $x(t)=\cos(2t+\pi/4)$. Read the phase response at the same frequency, $\angle H(j2)=-\pi/6$, and keep the frequency fixed while you add the system phase to the input phase.

$$
x(t)=\cos(2t+\pi/4)
$$

Add the phases: $\pi/4+(-\pi/6)=\pi/12$. So the steady-state output keeps the same frequency and uses the new phase $\pi/12$.

$$
y(t)=\cos(2t+\pi/12)
$$

## Interpreting Positive and Negative Phase Shifts

**Example:** If $\angle H(j3)=\pi/5$ and $\angle H(j8)=-\pi/5$, describe the phase change at each frequency in terms of lead or lag.

**Explanation**

The cue is the sign of $\angle H(j\omega)$ at each frequency. A positive phase value means the output leads, or advances, the input. A negative phase value means the output lags, or delays, the input.

$$
\angle H(j3)=\pi/5, \qquad \angle H(j8)=-\pi/5
$$

So at $\omega=3$, the output leads the input by $\pi/5$. At $\omega=8$, the output lags the input by $\pi/5$.

$$
\omega=3:\ \text{lead by }\pi/5 \qquad \omega=8:\ \text{lag by }\pi/5
$$

## Comparing Phase Shifts Across Frequencies

**Example:** If $\angle H(j1)=\pi/6$ and $\angle H(j5)=-\pi/3$, determine which frequency component is more delayed and which is more advanced.

**Explanation**

Read each phase shift first. At $\omega=1$, the phase is positive, so that component is advanced. At $\omega=5$, the phase is negative, so that component is delayed.

$$
\angle H(j1)=\pi/6, \qquad \angle H(j5)=-\pi/3
$$

Now compare the sizes: $|\pi/6| < |\pi/3|$, so the delay at $\omega=5$ is larger in magnitude than the advance at $\omega=1$. The $\omega=5$ component is more delayed, and the $\omega=1$ component is more advanced.

$$
\omega=1:\ \text{advanced by }\pi/6 \qquad \omega=5:\ \text{delayed by }\pi/3
$$
