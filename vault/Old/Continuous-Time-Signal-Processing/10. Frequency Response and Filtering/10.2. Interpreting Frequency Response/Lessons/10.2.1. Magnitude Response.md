## Introduction to Magnitude Response

For a continuous-time LTI system, the magnitude response $|H(j\omega)|$ is the amplitude gain at frequency $\omega$. Read it as the factor that tells you how strongly the system scales a sinusoidal input at that frequency.

In the base case, start with one sinusoid $x(t)=A\cos(\omega_0 t)$ and read the gain at that same frequency. The output keeps the same frequency, and only the amplitude changes according to the magnitude response.

$$
A_{\text{out}} = |H(j\omega_0)|A_{\text{in}}
$$

This gives the three basic interpretations of the curve: if $|H(j\omega)|<1$, that frequency is attenuated; if $|H(j\omega)|=1$, it is passed with the same amplitude; and if $|H(j\omega)|>1$, it is amplified.

$$
|H(j\omega)|<1 \Rightarrow \text{attenuated},\quad |H(j\omega)|=1 \Rightarrow \text{passed},\quad |H(j\omega)|>1 \Rightarrow \text{amplified}
$$

So the first job in this topic is to read $|H(j\omega)|$ as a frequency-by-frequency amplitude scale. The next sections will use the same rule at one frequency, then two frequencies, and then across an entire magnitude-response curve.

## Scaling One Sinusoidal Input by |$H(j\omega_0)$|

**Example:** An input $x(t)=6\cos(\omega_0 t)$ enters a system with $|H(j\omega_0)|=0.5$. Find the output amplitude.

**Explanation**

The cue is a single sinusoid at frequency $\omega_0$ and a gain value given at that same frequency. For magnitude response, the output amplitude is the input amplitude multiplied by $|H(j\omega_0)|$.

$$
A_{\text{out}} = |H(j\omega_0)|A_{\text{in}} = 0.5 \cdot 6 = 3
$$

So the output amplitude is $3$. The frequency stays $\omega_0$; only the amplitude changes when the system scales this sinusoidal input.

$$
y(t)=3\cos(\omega_0 t)
$$

## Classifying One Frequency as Attenuated, Passed, or Amplified

**Example:** At $\omega_0$, a system has $|H(j\omega_0)|=0.75$. Classify the component at that frequency as attenuated, passed, or amplified.

**Explanation**

The cue is a single frequency $\omega_0$ with its gain value $|H(j\omega_0)|$ already given. To classify the component, compare that gain to 1 instead of computing a new output amplitude.

$$
|H(j\omega_0)|<1 \Rightarrow \text{attenuated},\quad |H(j\omega_0)|=1 \Rightarrow \text{passed},\quad |H(j\omega_0)|>1 \Rightarrow \text{amplified}
$$

Here $|H(j\omega_0)|=0.75$, and $0.75<1$. That means the component at $\omega_0$ is attenuated.

$$
0.75<1 \Rightarrow \text{attenuated}
$$

<a id="comparing-magnitude-response-at-two-frequencies"></a>
## Comparing Magnitude Response at Two Frequencies

**Example:** Given $|H(j\omega_1)|=0.4$ and $|H(j\omega_2)|=1.6$, compare the output amplitudes for the same sinusoidal input at $\omega_1$ and $\omega_2$.

**Explanation**

The cue is two gain values for the same sinusoidal input. Compare the gains directly, and keep the input amplitude the same at both frequencies so the output amplitudes differ only because of $|H(j\omega)|$.

$$
A_{\text{out},1}=0.4A_{\text{in}},\qquad A_{\text{out},2}=1.6A_{\text{in}}
$$

Because $0.4<1$, the component at $\omega_1$ is attenuated. Because $1.6>1$, the component at $\omega_2$ is amplified. Since $1.6>0.4$, the output amplitude at $\omega_2$ is larger than the output amplitude at $\omega_1$ for the same input.

$$
A_{\text{out},2}>A_{\text{out},1}
$$

## Interpreting a Magnitude-Response Curve Across Frequency

**Example:** Using the magnitude-response plot, identify which frequency regions are attenuated, passed, and amplified by comparing the curve to the unity line.

**Explanation**

The cue is a full magnitude-response curve, so read it by comparing each part of the curve to the unity line $|H(j\omega)|=1$. Do not classify the response from the slope or peak alone; the key test is whether the curve is above, on, or below 1.

![](<../Source/10.2.1. Magnitude Response/Images/l001-s005-te-section-005.png>)

Scan the curve region by region. Where the curve is above the unity line, the system amplifies those frequencies. Where it lies on the line, the system passes them. Where it falls below the line, the system attenuates them. Apply that same rule separately to the low-, middle-, and high-frequency bands.

$$
|H(j\omega)|>1 \Rightarrow \text{amplified},\qquad |H(j\omega)|=1 \Rightarrow \text{passed},\qquad |H(j\omega)|<1 \Rightarrow \text{attenuated}
$$

For this plot, the low-frequency band is amplified, the middle band is passed, and the high-frequency band is attenuated. In plain language, the system boosts low frequencies, leaves a middle band roughly unchanged, and reduces high frequencies.
