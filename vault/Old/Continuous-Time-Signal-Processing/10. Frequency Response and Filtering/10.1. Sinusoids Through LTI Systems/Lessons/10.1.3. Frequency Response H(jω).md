## Introduction to Frequency Response $H(j\omega)$

Frequency response is the system's response profile indexed by angular frequency. For each $\omega$, $H(j\omega)$ names the complex gain an LTI system applies at that frequency.

$$
x(t)=e^{j\omega_0 t}
$$

Use $x(t)=e^{j\omega_0 t}$ as the probe input. Here $\omega_0$ is the frequency being tested, so the notation asks only how the system responds at that one angular frequency.

$$
y(t)=H(j\omega_0)e^{j\omega_0 t}
$$

Read $H(j\omega_0)$ as the complex gain at angular frequency $\omega_0$. The output keeps the same exponential $e^{j\omega_0 t}$; only the multiplier changes with $\omega$.

$$
H(j\omega_0)=\text{the complex gain at angular frequency }\omega_0
$$

That is the meaning of frequency response: same frequency in, same frequency out, with the LTI system contributing a frequency-dependent complex multiplier.

## Matching a Complex Exponential Input to $H(j\omega_0)$

**Example:** An LTI system is driven by $x(t)=e^{j6t}$. Identify the frequency-response sample used for this input and write the output in indexed-gain form.

**Explanation**

The exponent tells us the probe frequency is $\omega_0=6$. So the matching frequency-response sample is $H(j6)$, not a generic $H(j\omega)$.

$$
x(t)=e^{j6t}
$$

For this probe input, the output stays at the same angular frequency and picks up the complex gain at that frequency.

$$
y(t)=H(j6)e^{j6t}
$$

So the output is the same exponential scaled by $H(j6)$. The only index we had to read from the input was the $6$ inside the exponent.

## Interpreting $H(j\omega_0)$ as a Complex Gain

**Example:** Suppose an LTI system has $H(j2)=3e^{-j\pi/6}$. Interpret what this value means for the response to $e^{j2t}$.

**Explanation**

The cue is the index $2$: use the sample $H(j2)$, not a different frequency. Read that sample as the complex multiplier at angular frequency $2$.

$$
H(j2)=3e^{-j\pi/6}
$$

So the response to the matching input $e^{j2t}$ is the same input scaled by that gain.

$$
y(t)=H(j2)e^{j2t}=3e^{-j\pi/6}e^{j2t}
$$

The output stays at frequency $2$. The only change is the complex gain factor.

<a id="writing-the-same-frequency-output-using-hjomega0"></a>
## Writing the Same-Frequency Output Using $H(j\omega_0)$

**Example:** For $x(t)=e^{j3t}$ and $H(j3)=1-j$, write the output expression using the same input frequency.

**Explanation**

Match the input frequency to the response sample: the probe is $e^{j3t}$, so the indexed gain is $H(j3)$. Use that gain as a multiplier, not as a new signal.

$$
x(t)=e^{j3t}, \quad H(j3)=1-j
$$

Write the output by multiplying the input by the indexed gain and keep the exponent unchanged.

$$
y(t)=H(j3)e^{j3t}=(1-j)e^{j3t}
$$

The frequency stays at $3$; only the complex factor changes, so the gain belongs in front of the same exponential.

<a id="comparing-complex-gains-at-different-frequencies"></a>
## Comparing Complex Gains at Different Frequencies

**Example:** An LTI system has $H(j1)=2$ and $H(j4)=1-j$. Compare the response gains applied to $e^{jt}$ and $e^{j4t}$.

**Explanation**

Read the two frequencies separately: $e^{jt}$ uses $H(j1)$, and $e^{j4t}$ uses $H(j4)$. Do not reuse one gain for both inputs.

$$
H(j1)=2, \quad H(j4)=1-j
$$

Now pair each input with its own indexed gain and keep the output frequency unchanged.

$$
y_1(t)=H(j1)e^{jt}=2e^{jt}, \quad y_4(t)=H(j4)e^{j4t}=(1-j)e^{j4t}
$$

The comparison is the gain values themselves: the multiplier is $2$ at frequency $1$ and $1-j$ at frequency $4$. The response changes with frequency.
