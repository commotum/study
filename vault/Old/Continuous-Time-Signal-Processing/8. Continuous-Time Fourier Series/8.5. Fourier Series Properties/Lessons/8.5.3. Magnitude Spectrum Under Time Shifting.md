## Introduction to Magnitude Spectrum Under Time Shifting

For one harmonic coefficient $c_k$ of a periodic signal, a time shift keeps the harmonic index fixed and changes only the coefficient phase. For $x(t-t_0)$, the shifted coefficient is $c_k' = c_k e^{-jk\omega_0 t_0}$, so the first thing to recognize is the phase-rotation factor attached to the original coefficient.

$$
c_k' = c_k e^{-jk\omega_0 t_0}
$$

The multiplier $e^{-jk\omega_0 t_0}$ has unit magnitude, so it rotates $c_k$ in the complex plane without changing its length. That is the key cue: a time shift can move phase, but it cannot change the size of the coefficient.

$$
|c_k'| = |c_k|\,|e^{-jk\omega_0 t_0}| = |c_k|
$$

So the magnitude spectrum stays the same for every harmonic index $k$, even though the phase spectrum changes. The shift changes where each coefficient points, not how tall each magnitude bar is.

Use this rule whenever a periodic signal is time shifted: multiply each coefficient by the phase factor, then read the magnitudes as unchanged.

## Identifying the Unit-Magnitude Time-Shift Multiplier

**Example:** A periodic signal has Fourier coefficient $c_3 = 2 - 2j$. After the shift $x(t-t_0)$, the coefficient becomes $c_3' = c_3 e^{-j3\omega_0 t_0}$. Identify the multiplier's magnitude and the magnitude of $c_3'$.

**Explanation**

The cue is the factor multiplying $c_3$ in the shifted coefficient. For $x(t-t_0)$, the shift does not change the harmonic index; it appends the multiplier $e^{-j3\omega_0 t_0}$ to the original coefficient.

$$
c_3' = c_3 e^{-j3\omega_0 t_0}
$$

Because $e^{-j3\omega_0 t_0}$ is a complex exponential, its magnitude is $1$. So the shift changes phase only, not coefficient size.

$$
|e^{-j3\omega_0 t_0}| = 1
$$

Now compute the original magnitude: $|c_3| = |2-2j| = \sqrt{2^2+(-2)^2} = 2\sqrt{2}$. Since the multiplier has unit magnitude, the shifted coefficient keeps that same magnitude.

$$
|c_3'| = |c_3| = 2\sqrt{2}
$$

So the multiplier is unit-magnitude, and the shifted coefficient has magnitude $2\sqrt{2}$. The phase changes, but the magnitude spectrum height does not.

<a id="finding-magnitudes-after-a-time-shift"></a>
## Finding Magnitudes After a Time Shift

**Example:** A signal has coefficients $c_0 = 2$, $c_1 = 1 - j$, and $c_2 = -3j$. After the shift $x(t-t_0)$, determine the shifted magnitudes $|c_0'|$, $|c_1'|$, and $|c_2'|$.

**Explanation**

The cue is the time-shift factor on each coefficient. A shift leaves the coefficient list in place and multiplies each harmonic by a complex exponential with magnitude $1$, so the magnitudes should match the original list.

$$
c_0' = c_0,\qquad c_1' = c_1 e^{-j\omega_0 t_0},\qquad c_2' = c_2 e^{-j2\omega_0 t_0}
$$

Start with the original magnitudes: $|c_0| = |2| = 2$, $|c_1| = |1-j| = \sqrt{1^2+(-1)^2} = \sqrt{2}$, and $|c_2| = |-3j| = 3$.

$$
|c_0'| = |c_0| = 2,\qquad |c_1'| = |c_1| = \sqrt{2},\qquad |c_2'| = |c_2| = 3
$$

So the shifted magnitude list is identical to the original one: the Fourier-series spectrum heights do not change under time shifting. Only the phases rotate.

## Comparing Original and Shifted Magnitude Spectra

**Example:** The original magnitude spectrum is $\{|c_0|, |c_1|, |c_2|\} = \{4, 1, 2\}$. After shifting the signal to $x(t-t_0)$, which magnitude spectrum is correct?

**Explanation**

The cue is the full magnitude list, not the complex coefficients. A time shift changes each coefficient by a unit-magnitude factor, so each entry in the spectrum keeps its height.

$$
\{|c_0|, |c_1|, |c_2|\} = \{4, 1, 2\}
$$

Apply the shift rule term by term: $|c_0'| = |c_0| = 4$, $|c_1'| = |c_1| = 1$, and $|c_2'| = |c_2| = 2$.

$$
\{|c_0'|, |c_1'|, |c_2'|\} = \{4, 1, 2\}
$$

So the correct shifted magnitude spectrum is the same ordered list as the original one. The coefficients rotate in phase, but the spectrum heights do not move or scale.

<a id="distinguishing-magnitude-invariance-from-phase-rotation"></a>
## Distinguishing Magnitude Invariance from Phase Rotation

**Example:** A student says the magnitude spectrum must change because $c_k' = c_k e^{-jk\omega_0 t_0}$. Decide what changes and what stays the same for $x(t-t_0)$.

**Explanation**

The cue is the update rule itself. A time shift does not rewrite the coefficient list; it multiplies each $c_k$ by a complex exponential that depends on $k$, so the only question is whether that multiplier changes magnitude or only phase.

$$
c_k' = c_k e^{-jk\omega_0 t_0}
$$

The exponential factor has magnitude $1$, so it cannot change $|c_k|$. It only rotates the phase by an amount that depends on $k$ and the shift $t_0$.

$$
|c_k'| = |c_k|,\qquad \angle c_k' = \angle c_k - k\omega_0 t_0
$$

So the student's claim is false. A time shift changes phase, not magnitude: the magnitude spectrum stays fixed while the phase spectrum rotates.
