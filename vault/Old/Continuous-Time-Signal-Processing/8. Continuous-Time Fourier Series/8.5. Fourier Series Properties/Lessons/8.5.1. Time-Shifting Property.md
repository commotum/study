## Introduction to Time-Shifting Property

When a periodic signal is shifted in time, its continuous-time Fourier series coefficients keep the same magnitudes and change only in phase. The phase change depends on the harmonic index, so the shift affects each coefficient in a controlled way instead of changing the whole spectrum.

Start with a periodic signal $x(t)$ whose CTFS coefficients are $c_k$. If the shifted signal is $y(t)=x(t-t_0)$, with $t_0>0$ meaning a delay, then the new coefficients are $d_k$.

$$
d_k=c_k e^{-jk\omega_0 t_0}
$$

The multiplier uses $k$, so each harmonic gets its own complex phase factor. The DC term is the special case $k=0$, where the multiplier becomes $1$ and $d_0=c_0$.

So a time shift changes coefficient phase, not coefficient magnitude. Once you know the original $c_k$, you can update the coefficients for a delay or an advance directly, without recomputing the Fourier integrals.

<a id="updating-one-fourier-coefficient-for-a-delay"></a>
## Updating One Fourier Coefficient for a Delay

**Example:** For a signal with coefficient $c_2=3e^{j\pi/4}$, find the corresponding coefficient $d_2$ for $y(t)=x(t-T_0/8)$.

**Explanation**

This is a delay, so use the CTFS time-shifting property instead of recomputing the coefficient integral. The magnitude stays the same; only the phase changes.

Here the relevant harmonic is $k=2$, and the shift is $t_0=T_0/8$. Since a periodic signal satisfies $\omega_0T_0=2\pi$, the phase multiplier for this harmonic is $e^{-j\pi/2}$.

$$
\begin{aligned} d_2 &= c_2 e^{-j2\omega_0(T_0/8)} \\ &= 3e^{j\pi/4}e^{-j\pi/2} \\ &= 3e^{-j\pi/4} \end{aligned}
$$

So the updated coefficient is $d_2=3e^{-j\pi/4}$. The coefficient magnitude is still $3$; only the phase has rotated.

## Updating a Coefficient List for $x(t - t0)$

**Example:** Given $c_0=2$, $c_1=1-j$, and $c_2=4$ for $x(t)$, find $d_0$, $d_1$, and $d_2$ for $y(t)=x(t-T_0/4)$.

**Explanation**

The cue is a delay, so update the whole coefficient list with the time-shifting property. Since $y(t)=x(t-T_0/4)$ and $\omega_0T_0=2\pi$, the common shift angle is $\omega_0t_0=\pi/2$.

$$
\begin{aligned} d_0 &= c_0 e^{-j0\omega_0t_0} = 2, \\ d_1 &= c_1 e^{-j1\omega_0t_0} = (1-j)e^{-j\pi/2} = -1-j, \\ d_2 &= c_2 e^{-j2\omega_0t_0} = 4e^{-j\pi} = -4 \end{aligned}
$$

The DC term stays unchanged because its multiplier is $1$. The nonzero harmonics each pick up their own phase rotation from the same shift angle.

So the shifted coefficient list is $d_0=2$, $d_1=-1-j$, and $d_2=-4$. The result comes directly from the multiplier rule, without recomputing any Fourier integrals.

## Handling an Advance as a Negative Time Shift

**Example:** For $c_3=2e^{-j\pi/3}$, find the $k=3$ coefficient of $y(t)=x(t+T_0/6)$.

**Explanation**

The cue is the plus sign in $x(t+T_0/6)$. Rewrite it as $x(t-t_0)$ with $t_0=-T_0/6$, then apply the same CTFS time-shifting rule that you used for delays.

Now substitute the signed shift into $d_k=c_k e^{-jk\omega_0 t_0}$. Since $\omega_0T_0=2\pi$, the phase for $k=3$ becomes $e^{-j3\omega_0(-T_0/6)}=e^{j\pi}$, which is a positive phase rotation because the shift is an advance.

$$
\begin{aligned} d_3 &= c_3 e^{-j3\omega_0 t_0} \\ &= 2e^{-j\pi/3}e^{-j3\omega_0(-T_0/6)} \\ &= 2e^{-j\pi/3}e^{j\pi} \\ &= 2e^{j2\pi/3} \end{aligned}
$$

So the coefficient is $d_3=2e^{j2\pi/3}$. The advance is handled by the negative value of $t_0$; the multiplier still does all the work, and the magnitude stays the same.
