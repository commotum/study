## Introduction to Phase Spectrum

If the magnitude spectrum tells you how large each harmonic coefficient is, the phase spectrum tells you its angle. It extends the magnitude spectrum by recording one phase value at each harmonic index $k$.

$$
C_k = |C_k|e^{j\phi_k}
$$

For every nonzero coefficient, read the phase as $\phi_k = \arg(C_k)$ and keep that value attached to the same harmonic index $k$. That phase is part of the spectrum, not a separate object.

$$
\phi_k = \arg(C_k)
$$

In the base case, if $C_1 = 3e^{-j\pi/4}$, then the phase-spectrum entry at harmonic $k=1$ is $\phi_1 = -\pi/4$. The coefficient still belongs to harmonic 1; only the angle is what you record.

$$
C_{-k} = C_k^* \;\Rightarrow\; \phi_{-k} = -\phi_k \text{ for real } x(t)
$$

For real-valued signals, positive and negative harmonics come in conjugate pairs, so their phases are opposite. Zero coefficients have no phase entry, so they are left out of the phase spectrum.

## Extracting Phase from a Nonzero Complex Coefficient

**Example:** Given $C_2 = -1 - \sqrt{3}j$, compute the phase at harmonic $k=2$ and rewrite the coefficient in phase-angle form.

**Explanation**

The cue here is a single complex coefficient written in rectangular form: $C_2 = -1 - \sqrt{3}j$. The rule from the tutorial is to read phase as $\phi_k = \arg(C_k)$, so the first job is to place the point on the complex plane and identify its quadrant.

$$
|C_2| = \sqrt{(-1)^2 + (-\sqrt{3})^2} = 2
$$

Because both parts are negative, $C_2$ lies in quadrant III. The reference angle is $\pi/3$, so the principal argument is $\phi_2 = -2\pi/3$.

$$
\phi_2 = \arg(C_2) = -2\pi/3
$$

That phase is the phase-spectrum entry at harmonic $k=2$. To confirm it, rewrite the coefficient in phase-angle form using the same magnitude and angle.

$$
C_2 = 2e^{-j2\pi/3}
$$

So the final reading is: harmonic $k=2$ has phase $-2\pi/3$, and the coefficient is $2e^{-j2\pi/3}$. The phase stays attached to the harmonic index; the magnitude only sets the coefficient's size.

## Assigning Phases to Positive and Negative Harmonics

**Example:** Given $C_0 = 2$, $C_1 = 3e^{j\pi/4}$, $C_{-1} = 3e^{-j\pi/4}$, $C_2 = 0$, $C_{-2} = 0$, $C_3 = 4e^{-j\pi/2}$, and $C_{-3} = 4e^{j\pi/2}$, build the phase spectrum across $k=-3,-2,-1,0,1,2,3$.

**Explanation**

The cue is a full coefficient table. Read each nonzero coefficient and attach its phase to the same harmonic index $k$. Here the DC term is $C_0 = 2$, so it contributes the phase entry $\phi_0 = 0$.

$$
\phi_0 = 0
$$

For the first harmonic pair, $C_1 = 3e^{j\pi/4}$ and $C_{-1} = 3e^{-j\pi/4}$ give opposite phases at $k=1$ and $k=-1$. That means $\phi_1 = \pi/4$ and $\phi_{-1} = -\pi/4$.

$$
\phi_1 = \pi/4,\quad \phi_{-1} = -\pi/4
$$

For the third harmonic pair, $C_3 = 4e^{-j\pi/2}$ and $C_{-3} = 4e^{j\pi/2}$ give $\phi_3 = -\pi/2$ and $\phi_{-3} = \pi/2$. The harmonic index stays attached to each phase entry.

$$
\phi_3 = -\pi/2,\quad \phi_{-3} = \pi/2
$$

The zero coefficients at $k=\pm2$ do not add phase entries, so the phase spectrum is organized by the nonzero indices only. Across $k=-3,-2,-1,0,1,2,3$, the phase assignment is the one above, with no phase shown at $k=\pm2$.

## Leaving Zero Coefficients Out of the Phase Spectrum

**Example:** Given $C_0 = 1$, $C_1 = 0$, $C_{-1} = 0$, $C_2 = 2e^{j\pi/5}$, and $C_{-2} = 2e^{-j\pi/5}$, state which harmonics appear in the phase spectrum and which harmonics are omitted.

**Explanation**

The cue is the zero entries at $k=1$ and $k=-1$. A zero Fourier coefficient has no argument, so it does not get a phase label. Keep the phase spectrum sparse: include only harmonics with nonzero coefficients.

$$
\phi_0 = 0,\quad \phi_2 = \pi/5,\quad \phi_{-2} = -\pi/5
$$

So the phase spectrum contains only $k=0,2,-2$. The harmonics $k=1$ and $k=-1$ are omitted entirely, not shown with placeholder phases, and the remaining nonzero pair still has opposite phases.

## Interpreting a Phase Spectrum from Fourier Coefficients

**Example:** Given $C_0 = -3$, $C_1 = 2e^{-j\pi/6}$, $C_{-1} = 2e^{j\pi/6}$, $C_2 = 0$, $C_{-2} = 0$, $C_3 = 5e^{j\pi/2}$, and $C_{-3} = 5e^{-j\pi/2}$, compute the phase spectrum and interpret the resulting harmonic phases.

**Explanation**

Start from the coefficient table and extract phase only from the nonzero entries. The negative DC term $C_0 = -3$ has phase $\pi$, the pair at $k=\pm 1$ has phases $\mp\pi/6$, and the pair at $k=\pm 3$ has phases $\pm\pi/2$. The zeros at $k=\pm 2$ do not produce phase entries.

$$
\begin{aligned}
\phi_0 &= \pi, \qquad \phi_1 = -\pi/6, \qquad \phi_{-1} = \pi/6,\\
\phi_3 &= \pi/2, \qquad \phi_{-3} = -\pi/2, \qquad C_2 = C_{-2} = 0 \;\text{omitted}
\end{aligned}
$$

So the phase spectrum is sparse: it keeps $k=0, \pm 1, \pm 3$ and leaves out $k=\pm 2$ entirely. The interpretation is direct: every nonzero harmonic carries a phase shift, the conjugate pair has opposite signs, and zero coefficients disappear from the phase spectrum instead of being given a placeholder value.
