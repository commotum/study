## Introduction to Fundamental Frequency in Fourier Series

A Fourier series is read on a frequency grid. The key quantity on that grid is the fundamental angular frequency $\omega_0$, because every harmonic component sits at an integer multiple of that spacing.

If a periodic signal repeats every $T_0$ seconds, then one full cycle corresponds to the same $2\pi$ radians of phase each time. That is why the period tells you the spacing of the Fourier-series frequency grid.

$$
\omega_0 = \frac{2\pi}{T_0}
$$

Use the simplest base case first: if $T_0 = 1$ s, then $\omega_0 = 2\pi$ rad/s. The harmonic locations then appear at $0,\omega_0,2\omega_0,3\omega_0,\dots$, so the spacing between adjacent components is always the same fundamental step.

$$
\omega_k = k\omega_0,\quad k \in \mathbb{Z}
$$

So the reusable procedure is simple: find $T_0$ first, convert it to $\omega_0$, and then use $\omega_0$ to read the spacing between the harmonic components in the Fourier-series description.

<a id="computing-omega0-from-a-given-fundamental-period"></a>
## Computing $\omega$_0 from a Given Fundamental Period

**Example:** A periodic signal has $T_0 = 2$ s. Compute its fundamental angular frequency $\omega_0$.

**Explanation**

The cue is the fundamental period $T_0$. Once $T_0$ is known, the fundamental angular frequency comes from direct substitution into $\omega_0 = 2\pi/T_0$.

$$
\omega_0 = \frac{2\pi}{T_0} = \frac{2\pi}{2\text{ s}}
$$

Now simplify the result. With $T_0 = 2$ s, the spacing is $\pi$ rad/s, so the Fourier-series frequency grid advances in steps of $\pi$.

$$
\omega_0 = \pi\ \text{rad/s}
$$

## Computing $\omega$_0 After Identifying the Fundamental Period

**Example:** A periodic waveform repeats on intervals of length $3$ s. Identify $T_0$ and compute $\omega_0$.

**Explanation**

The cue is the repeat description. A waveform that repeats every $3$ s has fundamental period $T_0 = 3$ s.

$$
T_0 = 3\text{ s}
$$

Now apply the rule $\omega_0 = 2\pi/T_0$ and substitute the identified period.

$$
\omega_0 = \frac{2\pi}{T_0} = \frac{2\pi}{3\text{ s}}
$$

So the fundamental angular frequency is $\omega_0 = \frac{2\pi}{3}$ rad/s. That is the spacing used by the Fourier-series harmonic grid.

$$
\omega_0 = \frac{2\pi}{3}\ \text{rad/s}
$$

<a id="using-omega0-as-the-spacing-between-fourier-series-frequencies"></a>
## Using $\omega$_0 as the Spacing Between Fourier Series Frequencies

**Example:** If $\omega_0 = \pi/3$ rad/s, list the first four nonnegative Fourier-series frequencies and show how the spacing works.

**Explanation**

The cue is the given spacing $\omega_0$. For Fourier series, the frequencies form an equally spaced grid at integer multiples of $\omega_0$.

$$
\omega_k = k\omega_0
$$

Substitute $\omega_0 = \pi/3$ rad/s. For the first four nonnegative grid points, use $k = 0, 1, 2, 3$.

$$
\{0,\ \omega_0,\ 2\omega_0,\ 3\omega_0\} = \left\{0,\ \frac{\pi}{3},\ \frac{2\pi}{3},\ \pi\right\}\ \text{rad/s}
$$

So each adjacent harmonic is separated by $\pi/3$ rad/s, which is the same spacing as $\omega_0$.

$$
\omega_{k+1} - \omega_k = \omega_0 = \frac{\pi}{3}\ \text{rad/s}
$$

<a id="comparing-frequency-spacing-for-different-fundamental-periods"></a>
## Comparing Frequency Spacing for Different Fundamental Periods

**Example:** Signal A has $T_0 = 2$ s and signal B has $T_0 = 4$ s. Compute each $\omega_0$ and state which harmonic grid is more widely spaced.

**Explanation**

The cue is the period. Fundamental frequency changes inversely with $T_0$, so the shorter period gives the wider spacing.

$$
\omega_0 = \frac{2\pi}{T_0}
$$

For Signal A, substitute $T_0 = 2$ s into the rule.

$$
\omega_0^{(A)} = \frac{2\pi}{2\text{ s}} = \pi\ \text{rad/s}
$$

For Signal B, substitute $T_0 = 4$ s into the same rule.

$$
\omega_0^{(B)} = \frac{2\pi}{4\text{ s}} = \frac{\pi}{2}\ \text{rad/s}
$$

Signal A has the larger spacing, and it is twice Signal B's spacing. That is the inverse period-spacing relationship.

$$
\omega_0^{(A)} = 2\omega_0^{(B)}
$$
