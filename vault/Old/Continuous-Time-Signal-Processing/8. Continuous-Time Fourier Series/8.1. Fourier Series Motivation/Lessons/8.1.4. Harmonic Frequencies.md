## Introduction to Harmonic Frequencies

Once the fundamental frequency $\omega_0$ is known, harmonic frequencies are the positive integer multiples of that same spacing. In the Fourier-series frequency-domain view, those multiples are the discrete frequencies you read off as separate sinusoidal components.

$$
\omega_k = k\omega_0, \quad k = 1,2,3,\dots
$$

Here $k$ is the harmonic index, and it is a positive integer. Start with $k=1$ so the first harmonic is just $\omega_0$, then use the same rule for $k=2$, $k=3$, and beyond.

$$
\omega_1 = \omega_0, \quad \omega_2 = 2\omega_0, \quad \omega_3 = 3\omega_0
$$

This gives a simple ladder of equally spaced harmonic frequencies: each new harmonic is one more copy of the fundamental spacing. The pattern is always the same rule, multiply $\omega_0$ by the integer index.

So when you look at a Fourier-series spectrum, treat each nonzero harmonic line as one sinusoidal component at $\omega_k = k\omega_0$. The $0$-frequency DC term is separate from the harmonic frequencies.

## Computing Harmonic Frequencies from a Fundamental Frequency

**Example:** Given $\omega_0 = 3\pi$ rad/s and $k = 4$, compute the fourth harmonic frequency.

**Explanation**

The cue is the integer harmonic index $k$. Use the rule from the introduction, $\omega_k = k\omega_0$, and substitute the given values for $k$ and $\omega_0$.

$$
\omega_4 = 4\omega_0 = 4(3\pi) = 12\pi\,\text{rad/s}
$$

So the fourth harmonic frequency is $12\pi$ rad/s. The only operation is multiplying the fundamental frequency by the harmonic index.

## Listing the First Several Harmonic Frequencies

**Example:** List the first five harmonic frequencies when $\omega_0 = 2\pi$ rad/s.

**Explanation**

The cue is the request to list several harmonics. Use the same rule from the previous example, $\omega_k = k\omega_0$, and start with $k=1$ so the list begins at the first harmonic.

$$
\begin{aligned}\omega_1 &= 1(2\pi) = 2\pi\,\text{rad/s}\\\omega_2 &= 2(2\pi) = 4\pi\,\text{rad/s}\\\omega_3 &= 3(2\pi) = 6\pi\,\text{rad/s}\\\omega_4 &= 4(2\pi) = 8\pi\,\text{rad/s}\\\omega_5 &= 5(2\pi) = 10\pi\,\text{rad/s}\end{aligned}
$$

So the first five harmonic frequencies are $2\pi$, $4\pi$, $6\pi$, $8\pi$, and $10\pi$ rad/s in ascending order. Each entry is an integer multiple of the same fundamental frequency.

## Matching Frequencies to Harmonic Indices

**Example:** If $\omega_0 = 5\pi$ rad/s, which harmonic index corresponds to $20\pi$ rad/s?

**Explanation**

The cue is the target frequency $20\pi$ rad/s. To match a frequency to a harmonic index, compare it to the spacing frequency $\omega_0$ and form the ratio $\omega / \omega_0$.

$$
\frac{\omega}{\omega_0} = \frac{20\pi}{5\pi} = 4
$$

The ratio is the integer $4$, so the frequency is exactly $4\omega_0$. The matching harmonic index is $k=4$.

## Interpreting Harmonics as Frequency-Domain Components

**Example:** A Fourier-series spectrum has lines at $\omega_0$, $3\omega_0$, and $5\omega_0$. Which harmonic components are present, and what do they mean?

**Explanation**

The cue is a set of spectral lines at integer multiples of $\omega_0$. In the Fourier-series frequency-domain view, each line is one sinusoidal component at a harmonic frequency.

$$
\begin{aligned}
\omega_0 &\rightarrow k=1 \\
3\omega_0 &\rightarrow k=3 \\
5\omega_0 &\rightarrow k=5
\end{aligned}
$$

So the spectrum contains the 1st, 3rd, and 5th harmonic components. Each allowed line marks one sinusoidal component in the harmonic decomposition.
