## Introduction to Periodic vs. Aperiodic Signals

A continuous-time signal is periodic when there is some finite $T>0$ such that the signal repeats exactly after a shift of $T$, meaning the same waveform returns at every time.

$$
x(t+T)=x(t)
$$

The base case is a single sinusoid. For $x(t)=\cos(\omega_0 t)$, you can read off the smallest repeat period directly, so this is the cleanest place to see the periodicity test in action.

$$
x(t)=\cos(\omega_0 t), \quad T_0=\frac{2\pi}{\omega_0}
$$

If no finite $T>0$ makes $x(t+T)=x(t)$ true for all $t$, then the signal is aperiodic. That is the correct classification whenever the waveform never repeats exactly after any finite shift.

This classification determines the analysis tool: periodic signals are handled with Fourier series, and aperiodic signals move to Fourier-transform analysis.

The next sections will test more complicated signals and then use this periodic-versus-aperiodic decision to choose the right analysis method.

## Testing a Signal for a Finite Repeating Period

**Example:** Determine whether $x(t)=\cos(2t)+\cos(3t)$ is periodic, and if it is, identify a valid repeat period.

**Explanation**

To test periodicity, check whether the signal can repeat after one finite shift $T$ that works for every term at once. Here the cue is a sum of two sinusoids, so start by finding the repeat period of each sinusoidal term.

$$
\begin{aligned}T_1 &= \frac{2\pi}{2} = \pi,\\T_2 &= \frac{2\pi}{3}\end{aligned}
$$

A common repeat period must work for both terms together, so look for a finite shift that is a multiple of both $\pi$ and $\frac{2\pi}{3}$. The shift $2\pi$ does that, so it is a valid candidate to test.

$$
\begin{aligned}x(t+2\pi) &= \cos(2(t+2\pi)) + \cos(3(t+2\pi))\\&= \cos(2t+4\pi) + \cos(3t+6\pi)\\&= \cos(2t) + \cos(3t)\\&= x(t)\end{aligned}
$$

Since $x(t+2\pi)=x(t)$, the signal is periodic. One valid repeat period is $2\pi$.

<a id="identifying-aperiodic-signals-from-failed-period-tests"></a>
## Identifying Aperiodic Signals from Failed Period Tests

**Example:** Determine whether $x(t)=\cos(t)+\cos(\sqrt{2}t)$ is periodic.

**Explanation**

The cue is a sum of two sinusoidal terms, and each term is periodic on its own. The test is whether one finite shift $T>0$ can make both terms repeat at the same time.

$$
\begin{aligned}T_1 &= 2\pi,\\T_2 &= \frac{2\pi}{\sqrt{2}} = \sqrt{2}\pi\end{aligned}
$$

A finite repeat period for the whole signal would have to be a common repeat time for both terms. That means the same $T$ would have to line up as a common multiple of $2\pi$ and $\sqrt{2}\pi$, but those periods are not commensurate.

$$
\begin{aligned}2\pi k &= \frac{2\pi m}{\sqrt{2}}, \qquad k,m\in\mathbb{Z}\end{aligned}
$$

This would force $k=m/\sqrt{2}$, which is impossible for integers unless the period is zero. So no finite $T>0$ works, and the signal is aperiodic.

## Choosing Fourier Series or Fourier Transform Analysis from Periodicity

**Example:** For $x(t)=\cos(t)+\cos(\sqrt{2}t)$, decide whether Fourier series or Fourier transform is the appropriate analysis tool and state why.

**Explanation**

From the previous section, $x(t)=\cos(t)+\cos(\sqrt{2}t)$ is aperiodic, so there is no finite $T>0$ with $x(t+T)=x(t)$ for all $t$. That classification determines the analysis tool.

$$
\text{periodic signal} \rightarrow \text{Fourier series} \qquad \text{aperiodic signal} \rightarrow \text{Fourier transform}
$$

Use Fourier series only when the signal repeats with a finite period, because the series describes one period and extends it by repetition. Use the Fourier transform when no finite repeat period exists, because the signal must be analyzed without assuming periodic repetition.

Therefore the correct choice here is the Fourier transform, not Fourier series. The signal is aperiodic, so Fourier-transform analysis is the right tool.
