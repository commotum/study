Tutorial blocks:
- paragraph:
  text: In causal convolution, the object to watch is the shifted impulse response h(t - tau). The output time t is fixed, and tau is the variable that scans through input time values.
- display-math:
  latex: y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
- paragraph:
  text: A causal impulse response is zero before its input time. For the base case, you can think of a causal exponential such as h(s)=e^{-as}u(s) with a>0. The important point is the support rule: h(s) is zero when s<0.
- display-math:
  latex: h(s)=0\text{ for }s<0,\quad \text{so }h(t-\tau)=0\text{ when }t-\tau<0
- paragraph:
  text: Now apply that rule to the shifted argument s=t-tau. The shifted response h(t - tau) can be nonzero only when t - tau is not negative.
- display-math:
  latex: t-\tau\ge 0\Longleftrightarrow \tau\le t
- image:
  image_slot_id: section-001
- paragraph:
  text: The inequality tau <= t is the causal cutoff. Values x(tau) with tau <= t are present or past input values relative to the output time t. Values with tau > t are future input values, so a causal LTI system cannot use them to form y(t).
- display-math:
  latex: y(t)=\int_{-\infty}^{t}x(\tau)h(t-\tau)\,d\tau
- paragraph:
  text: This causal form is only the first support restriction. If x(tau) is zero on part of the past region, those values still do not contribute. The actual contribution comes from the overlap where x(tau) and h(t - tau) are both nonzero.
- paragraph:
  text: The interpretation to carry forward is this: causal convolution accumulates weighted past input. At time t, each allowed input value x(tau) is multiplied by the shifted impulse-response weight h(t - tau), and the integral adds those weighted contributions.
