Generated step/example content:
Tutorial blocks:
- paragraph:
  text: For rectangular-pulse convolution, the key object to watch is the overlap between the fixed pulse x(tau) and the shifted pulse h(t - tau). At each value of t, the convolution value is the area of the product x(tau)h(t - tau).
- display-math:
  latex: y(t)=(x*h)(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
- paragraph:
  text: Use the simplest unequal-width case first: let both pulses have height 1, with x(t) nonzero on [0,5] and h(t) nonzero on [0,2]. Then h(t - tau) is a width-2 rectangle sliding across the width-5 rectangle x(tau). Because the heights are both 1, the area is just the overlap length.
- display-math:
  latex: y(t)=\text{overlap length of }[0,5]\text{ and }[t-2,t]
- image:
  image_slot_id: section-001
- paragraph:
  text: Unequal widths create one extra middle behavior. With equal widths, the overlap grows and then immediately shrinks. Here, the shorter width-2 pulse can fit completely inside the longer width-5 pulse, so the overlap grows, stays constant for a while, and then shrinks.
- paragraph:
  text: That gives the trapezoid pattern. Before first contact, the output is zero. During entry, the overlap length increases, so the output is an increasing ramp. During full overlap, the overlap length is constant, so the output has a flat plateau. During exit, the overlap length decreases, so the output is a decreasing ramp. After last contact, the output returns to zero.
- display-math:
  latex: 0,\quad \text{growing ramp},\quad \text{plateau},\quad \text{shrinking ramp},\quad 0
- paragraph:
  text: The rest of the lesson uses this region pattern as the control structure: order the breakpoints, identify the no-overlap regions, write the growing overlap length, write the full-overlap length, write the shrinking overlap length, and then assemble the complete trapezoidal output.
