Tutorial blocks:
- paragraph:
  text: The object to watch is the overlap interval between the fixed pulse x(tau) and the shifted pulse h(t - tau). For equal-width rectangular pulses, the convolution output is built by tracking how long that overlap interval is as t changes.
- display-math:
  latex: y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
- paragraph:
  text: This integral only receives contribution from tau-values where both factors are nonzero. For rectangular pulses, the product x(tau)h(t - tau) is constant on the overlap interval, so the integral becomes a rectangle area: height product times overlap length.
- display-math:
  latex: y(t)=(\text{height product})(\text{overlap length at time }t)
- image:
  image_slot_id: section-001
- paragraph:
  text: Use the simplest base case: two unit-height rectangular pulses supported on [0, 2]. In the convolution variable, x(tau) stays fixed on [0, 2]. The shifted factor h(t - tau) is nonzero when 0 <= t - tau <= 2, so its support in tau is [t - 2, t].
- paragraph:
  text: As t increases, the shifted interval [t - 2, t] first has no overlap with [0, 2]. Then it enters the fixed interval, so the overlap length grows linearly. After maximum overlap, it leaves the fixed interval, so the overlap length shrinks linearly. That grow-then-shrink pattern is what creates the triangular output.
- paragraph:
  text: The next sections use this same structure in four active steps: locate the time regions, compute the rising overlap area, compute the falling overlap area, and assemble the piecewise triangle.
