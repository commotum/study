## Introduction to Time Reversal

Time reversal is the operation that mirrors a continuous-time signal across $t=0$. In this first pass, the only thing that changes is the time argument, so the signal values stay attached to their original heights.

Write the reversed signal as $y(t)=x(-t)$. The minus sign acts on time, not on amplitude, so this means "read the original signal backward in time" rather than "flip the signal values."

$$
y(t)=x(-t)
$$

For the base case, a point at $t_0=3$ moves to $-3$, and a point at $t_0=-2$ moves to $2$. The value attached to each point stays the same, so the reversal is a left-right swap in time, not a change in height.

You can also think of time reversal as time scaling by $-1$. That viewpoint will matter later, but for now the key idea is simple: every time location $t_0$ maps to $-t_0$ while the signal value itself is preserved.

## Evaluating Values of $x(-t)$ from $x(t)$

**Example:** A signal is given by the table $x(-3)=4$, $x(-1)=1$, $x(0)=0$, and $x(2)=5$. For $y(t)=x(-t)$, find $y(3)$, $y(1)$, and $y(-2)$.

**Explanation**

The cue is a lookup in $y(t)=x(-t)$. To answer it, flip the query time first and then read the matching value from the original $x(t)$ table.

$$
y(3)=x(-3),\; y(1)=x(-1),\; y(-2)=x(2)
$$

Now read those values from the table: $x(-3)=4$, $x(-1)=1$, and $x(2)=5$.

So $y(3)=4$, $y(1)=1$, and $y(-2)=5$. The time argument changes sign, but the signal value itself does not.

## Mapping Time Locations Under Time Reversal

**Example:** Given labeled time locations at $t=-4$, $t=-1$, $t=0$, and $t=5$ on $x(t)$, trace the locations of the same features in $x(-t)$ and list the mirrored times in order.

**Explanation**

The cue is a set of labeled times on $x(t)$. Under time reversal, each time coordinate flips sign, so the feature values stay attached while the locations move to the opposite side of $t=0$.

$$
-4 \mapsto 4,\; -1 \mapsto 1,\; 0 \mapsto 0,\; 5 \mapsto -5
$$

So the mirrored locations are $4$, $1$, $0$, and $-5$. The value attached to each feature does not change; only the time label changes sign.

Ordered from left to right, the reversed signal has features at $-5$, $0$, $1$, and $4$. The point at $0$ stays fixed because $-0=0$.

<a id="recognizing-time-reversal-as-scaling-by-1"></a>
## Recognizing Time Reversal as Scaling by $-1$

**Example:** A student sees $y(t)=x(-t)$ and thinks it is a shift. Use a labeled point such as $t_0=6$ to show the point moves to $-6$ and explain why the operation is time scaling by $-1$.

**Explanation**

The cue is the minus sign inside the time argument. That means the transformation is of the form $y(t)=x(at)$ with $a=-1$, so time is being scaled, not shifted.

$$
y(t)=x(at),\; a=-1
$$

Use the tracked point $t_0=6$. Under the scaling rule, $6$ maps to $-6$, so the same feature appears at the mirrored time.

$$
6 \mapsto -6
$$

A shift would add the same offset to every time label, but here the sign of each time label changes instead. That is why the whole signal mirrors about $t=0$ and $0$ stays fixed.

So $y(t)=x(-t)$ is time scaling by $-1$, not a shift. The signal values stay attached to the same features while the time locations reverse.
