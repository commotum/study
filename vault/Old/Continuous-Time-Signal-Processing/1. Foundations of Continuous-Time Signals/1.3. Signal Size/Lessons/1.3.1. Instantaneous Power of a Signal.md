## Introduction to Instantaneous Power of a Signal

Instantaneous power is the pointwise signal-size quantity attached to a continuous-time signal $x(t)$. It tells you how large the signal is at a single time, so the rule is local in time rather than over an interval.

$$
p(t)=|x(t)|^2
$$

To compute it, take the magnitude of $x(t)$ at that same time and square it. The squaring removes sign, so a real sample like $x(t_0)=3$ gives the same power as any other value with magnitude $3$.

$$
p(t_0)=|x(t_0)|^2=|3|^2=9
$$

So if $x(t_0)=3$, the instantaneous power at that time is $9$. The same step works at every time: substitute the current signal value, square its magnitude, and keep the result as a new pointwise quantity.

That pointwise quantity is the one that will later be accumulated into energy and averaged into average power. For now, keep the rule fixed: $p(t)$ is the squared magnitude of $x(t)$ at the same time.

## Computing Instantaneous Power at a Single Time

**Example:** If $x(2)=-4$, what is $p(2)$?

**Explanation**

The cue is a single known signal value at one time: $x(2)=-4$. Use the definition from the tutorial, $p(t)=|x(t)|^2$, and substitute the given time into the signal before doing anything else.

$$
p(2)=|x(2)|^2
$$

Now replace $x(2)$ with the given value and take its magnitude. The minus sign disappears inside the absolute value, so the quantity inside the square is $4$.

$$
p(2)=|-4|^2=4^2
$$

Square that magnitude to get $16$. Instantaneous power is pointwise signal size, so the final answer is positive even though the original signal value was negative.

So for $x(2)=-4$, the instantaneous power is $p(2)=16$. The same substitution pattern will work whenever a question gives one time and one signal value.

## Computing an Instantaneous Power Signal from a Formula

**Example:** For $x(t)=2t-1$, find the instantaneous power signal $p(t)$.

**Explanation**

The cue is a formula for $x(t)$, so the goal is to turn that whole signal into a power signal using the same rule from the previous steps: $p(t)=|x(t)|^2$.

$$
p(t)=|x(t)|^2
$$

Substitute $x(t)=2t-1$ into the definition. Because $2t-1$ is real-valued, the magnitude is just the absolute value of the expression, so the power signal becomes $|2t-1|^2$.

$$
p(t)=|2t-1|^2=(2t-1)^2
$$

The absolute value disappears after squaring, so the simplified power signal is $p(t)=(2t-1)^2$. The result is a full function of $t$, not just one number, because the input was a formula for the whole signal.

So the instantaneous power signal is $p(t)=(2t-1)^2$. The same substitution pattern will work for any formula you are given, as long as you keep the magnitude square around the signal first.

## Computing Instantaneous Power from Piecewise Signal Values

**Example:** For $x(t)=4$ for $0 \le t < 1$, $x(t)=-1$ for $1 \le t < 2$, and $x(t)=0$ otherwise, find the instantaneous power signal $p(t)$.

**Explanation**

The cue is a piecewise signal, so apply the same rule on each interval: $p(t)=|x(t)|^2$. Keep the interval boundaries unchanged and only square the signal values.

$$
p(t)=|x(t)|^2
$$

On $0 \le t < 1$, the value is $4$, so $p(t)=|4|^2=16$. On $1 \le t < 2$, the value is $-1$, so $p(t)=|-1|^2=1$.

$$
p(t)=\begin{cases}16, & 0 \le t < 1\\1, & 1 \le t < 2\\0, & \text{otherwise}\end{cases}
$$

Outside the listed intervals, $x(t)=0$, so $p(t)=0$. The negative middle piece still gives positive power because the magnitude is squared.

So the instantaneous power signal is $p(t)=16$ on $0 \le t < 1$, $p(t)=1$ on $1 \le t < 2$, and $p(t)=0$ otherwise.

<a id="interpreting-zero-and-larger-instantaneous-power-values"></a>
## Interpreting Zero and Larger Instantaneous Power Values

**Example:** If $p(t_1)=0$ and $p(t_2)=9$, what can you conclude about $x(t_1)$ and the magnitude of $x(t_2)$?

**Explanation**

The cue is a pair of power values, so read each one through the rule $p(t)=|x(t)|^2$ rather than treating power as a signed signal.

$$
p(t)=|x(t)|^2
$$

If $p(t_1)=0$, then $|x(t_1)|^2=0$, so $x(t_1)=0$. If $p(t_2)=9$, then $|x(t_2)|^2=9$, so $|x(t_2)|=3$.

$$
x(t_1)=0,\qquad |x(t_2)|=3
$$

The sign of $x(t_2)$ is not determined by power alone, but its magnitude is larger than at $t_1$ because $3>0$. Zero power means zero signal value, and larger power means larger magnitude.
