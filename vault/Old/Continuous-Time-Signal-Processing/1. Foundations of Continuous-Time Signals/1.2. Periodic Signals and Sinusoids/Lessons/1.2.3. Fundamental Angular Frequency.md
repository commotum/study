## Introduction to Fundamental Angular Frequency

For a periodic continuous-time signal, start by recognizing the fundamental cycle. The angular frequency attached to that one repeating cycle is $\omega_0$.

Use the simplest base case: one full cycle takes $T_0$ seconds, and over that cycle the phase advances by one full turn, or $2\pi$ radians. That is why $\omega_0$ is measured in rad/s: it is the angular rate of the repeating pattern.

$$
\omega_0 = \frac{2\pi}{T_0}
$$

This formula gives the phase-advance rate for one cycle. If the signal repeats faster, $\omega_0$ is larger; if it repeats more slowly, $\omega_0$ is smaller.

$$
\omega_k = k\omega_0
$$

Once $\omega_0$ is set, the harmonic angular frequencies fall on a uniform ladder at integer multiples of the same spacing. So $\omega_0$ is not just one frequency value; it is the base step size for the whole harmonic set.

Keep this lesson focused on interpreting $\omega_0$ as the angular rate of one fundamental cycle and as the spacing between harmonics. Later lessons will connect $\omega_0$ and $T_0$ in conversion problems, but here the job is to recognize the base rate cleanly.

## Interpreting $\omega$_0 as Angular Rate

**Example:** A periodic signal completes one fundamental cycle every $4$ s. Interpret $\omega_0$ as the angular rate of that cycle and identify its value.

**Explanation**

The cue is the phrase 'one fundamental cycle every $4$ s.' That tells you to read the cycle time as $T_0 = 4$ s and to interpret $\omega_0$ as the phase-advance rate of that single repeat.

One fundamental cycle always means one full $2\pi$ radians of phase advance. So the angular rate is the phase advance per cycle divided by the cycle time.

$$
\omega_0 = \frac{2\pi}{T_0}
$$

Substitute $T_0 = 4$ s and simplify.

$$
\omega_0 = \frac{2\pi}{4} = \frac{\pi}{2}
$$

So the signal's fundamental angular frequency is $\pi/2$ rad/s. In words, the signal advances by $\pi/2$ radians each second across one repeating cycle.

That is the interpretation to carry forward: $\omega_0$ is the angular rate attached to one fundamental cycle, not a harmonic multiple or a separate period value.

## Identifying $\omega$_0 from One Fundamental Cycle

**Example:** A periodic signal repeats once every $\frac{2}{5}$ s. Find its fundamental angular frequency $\omega_0$ exactly.

**Explanation**

The cue is the phrase 'repeats once every $\frac{2}{5}$ s.' That tells you the fundamental period is $T_0 = \frac{2}{5}$ s, so the job is to turn one cycle into an angular rate.

One fundamental cycle always corresponds to a full $2\pi$ radians of phase advance. So the base angular frequency is the phase advance per cycle divided by the cycle time.

$$
\omega_0 = \frac{2\pi}{T_0}
$$

Substitute $T_0 = \frac{2}{5}$ s and simplify exactly.

$$
\omega_0 = \frac{2\pi}{\frac{2}{5}} = 5\pi
$$

So the fundamental angular frequency is $5\pi$ rad/s. The unit check matches the interpretation: radians per second is the angular rate of one repeating cycle.

## Distinguishing $\omega$_0 from Harmonic Angular Frequencies

**Example:** A periodic signal has angular frequencies $4$ rad/s, $8$ rad/s, and $12$ rad/s. Which value is $\omega_0$, and which values are harmonics?

**Explanation**

The cue is the list of angular frequencies $4$ rad/s, $8$ rad/s, and $12$ rad/s. The job is not to compute a period; it is to identify the base spacing that the other values sit on.

Start with the smallest positive value. Here that is $4$ rad/s, so take $\omega_0 = 4$ rad/s.

$$
8 = 2\omega_0, \qquad 12 = 3\omega_0
$$

Because each larger frequency is an integer multiple of $\omega_0$, both are harmonics. The multiple on $8$ rad/s is $2$, so it is the second harmonic; the multiple on $12$ rad/s is $3$, so it is the third harmonic.

So the classification is $\omega_0 = 4$ rad/s, while $8$ rad/s and $12$ rad/s are harmonic frequencies.

The key rule to carry forward is: choose the smallest positive spacing as $\omega_0$, then label only the integer multiples as harmonics. Do not pick the largest value just because it appears later in the list.

<a id="using-omega0-as-harmonic-frequency-spacing"></a>
## Using $\omega$_0 as Harmonic Frequency Spacing

**Example:** If a periodic signal has $\omega_0 = 3$ rad/s, what are the first four positive harmonic frequencies?

**Explanation**

The cue is the given base spacing $\omega_0 = 3$ rad/s. The job is to build the harmonic ladder by multiplying that spacing by consecutive positive integers.

Use the harmonic rule $\omega_k = k\omega_0$ for $k = 1, 2, 3, 4$.

$$
\omega_k = k\omega_0
$$

Substitute $\omega_0 = 3$ rad/s and evaluate the first four terms.

$$
\omega_1 = 1(3) = 3, \qquad \omega_2 = 2(3) = 6, \qquad \omega_3 = 3(3) = 9, \qquad \omega_4 = 4(3) = 12
$$

So the first four positive harmonic frequencies are $3$ rad/s, $6$ rad/s, $9$ rad/s, and $12$ rad/s. Each one is spaced by $3$ rad/s, which is exactly $\omega_0$.

The carry-forward rule is to start at $\omega_0$ and keep multiplying by consecutive positive integers. Do not divide by the harmonic number or skip the base spacing.
