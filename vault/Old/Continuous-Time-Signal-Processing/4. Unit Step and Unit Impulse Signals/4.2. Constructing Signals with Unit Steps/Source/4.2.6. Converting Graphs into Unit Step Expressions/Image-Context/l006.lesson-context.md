- paragraph:
  text: A graph is ready to convert when you can read its breakpoints first. The breakpoints tell you where the signal turns on, stays active, and turns off, so those times become the shifted step arguments in the expression.
- image:
  image_slot_id: section-001
- paragraph:
  text: For one finite interval, write a unit-step window as the difference of two shifted steps. The window is 1 on the active interval and 0 everywhere else, so it gates the signal to that segment only.
- display-math:
  latex: x(t)=A\big(u(t-a)-u(t-b)\big)
- paragraph:
  text: In the simplest pulse case, the active interval is $0 \le t < T$, so the same rule becomes $x(t)=A\big(u(t)-u(t-T)\big)$. This is the base pattern you will reuse whenever a graph has one nonzero interval.
- display-math:
  latex: x(t)=\sum_k f_k\big[u(t-a_k)-u(t-b_k)\big]
- paragraph:
  text: For more complicated graphs, attach each interval formula to its own window, then combine the terms and simplify. The next steps will follow that same sequence: read the intervals, write each gated segment, and merge the result into one compact step expression.
