## Introduction to Building Piecewise Constant Signals

In this section, the move is to encode a piecewise constant signal as one baseline value plus a sequence of level jumps that each turn on at specific times. Your target is to represent interval-by-interval constants with shifted unit-step terms so each breakpoint maps directly to one term.

Use the unit step as the building cue: $u(t)$ is $0$ for $t<0$ and $1$ for $t\ge 0$. A shifted version $u(t-a)$ moves that switch to time $a$, so it is $0$ for $t<a$ and $1$ for $t\ge a$. Treat this as the fundamental left-right region rule you will reuse throughout.

For the base case, use one transition from level $0$ to level $A$ at time $a$ with $y(t)=A u(t-a)$. Verify directly: when $t<a$, $u(t-a)=0$ so $y(t)=0$; when $t\ge a$, $u(t-a)=1$ so $y(t)=A$. This one-term form is the smallest nontrivial pattern to imitate.

To create a finite window, keep the first switch-on term and add a second switch-off term at the ending time $b$ as $y(t)=A u(t-a)-A u(t-b)$. In $a\le t<b$, only the first term stays on and $y(t)=A$; for $t\ge b$, both terms are on and cancel, giving $y(t)=0$. This is the same representation idea with one extra breakpoint.

$$
y(t)=y_0+\sum_k \Delta A_k u(t-a_k)
$$

In the next sections, keep the exact same action rule and only change the jump list: for each breakpoint at $a_k$, add $\Delta A_k u(t-a_k)$ where $\Delta A_k$ is the signed change from the prior level to the next level. Multiple transitions become a reusable sum, not separate special cases.

## Turning On a Constant Level with a Shifted Unit Step

**Example:** Write a unit-step form for $y(t)=0$ for $t<2$, and $y(t)=5$ for $t\ge 2$.

**Explanation**

The cue is a two-region piecewise constant signal with zero baseline before a single switch time. In this form, the move is to represent the right-hand jump at $t=2$ as a shifted unit-step term added to the baseline.

Use the one-term template from the core move: $y(t)=A u(t-a)$ for a transition from $0$ to a level $A$ at time $a$. Here the start is at $a=2$ and the level after the switch is $A=5$, so the candidate form is $y(t)=5u(t-2)$.

$$
y(t)=5u(t-2)
$$

Verify region-by-region to confirm the representation: for $t<2$, $u(t-2)=0$, so $y(t)=5\cdot 0=0$. For $t\ge 2$, $u(t-2)=1$, so $y(t)=5\cdot 1=5$.

The result is complete: the step form is $y(t)=5u(t-2)$, and it is the direct one-step extension of the previous tutorial pattern from section 1.

## Turning Off a Constant Level with a Second Shifted Unit Step

**Example:** Construct a unit-step equation for $x(t)=4$ when $1\le t<5$, and $x(t)=0$ elsewhere.

**Explanation**

This signal has one nonzero pulse, so the cue is a finite interval with a clear start and end time. Use a turn-on term at $t=1$ and a turn-off term at $t=5$.

From the finite support pattern, place $4u(t-1)$ for the onset at the left edge. Then add a negative offset at the right edge: $-4u(t-5)$ to remove the level after $t\ge 5$.

$$
x(t)=4u(t-1)-4u(t-5)
$$

Check all regions. For $t<1$, both shifted steps are $0$, so $x(t)=0-0=0$. For $1\le t<5$, $u(t-1)=1$ and $u(t-5)=0$, so $x(t)=4\cdot 1-4\cdot 0=4$. For $t\ge 5$, both are $1$, so $x(t)=4\cdot 1-4\cdot 1=0$.

The finite support form is therefore $x(t)=4u(t-1)-4u(t-5)$, which is the same rule as before plus one extra breakpoint that turns the level off.

## Changing Directly Between Two Nonzero Constant Levels

**Example:** Convert the piecewise signal $x(t)=2$ for $t<1$, $x(t)=5$ for $1\le t<3$, and $x(t)=2$ for $t\ge3$ to unit-step form.

**Explanation**

The cue is a nonzero-to-nonzero level change: the baseline is $2$, then the signal rises at $t=1$ and falls back at $t=3$. Because the baseline is already $2$, this is a cumulative-jump form problem, not a zero-reset problem.

Set the baseline term first: $y_0=2$. Then compute each signed jump from the previous level. At $t=1$, the jump is $\Delta A_1=5-2=3$, so add $3u(t-1)$. At $t=3$, the jump is $\Delta A_2=2-5=-3$, so add $-3u(t-3)$.

$$
x(t)=2+3u(t-1)-3u(t-3)
$$

Validate each interval. For $t<1$, both $u(t-1)$ and $u(t-3)$ are $0$, so $x(t)=2+0-0=2$. For $1\le t<3$, only $u(t-1)=1$ and $u(t-3)=0$, so $x(t)=2+3-0=5$. For $t\ge3$, both are $1$, so $x(t)=2+3-3=2$.

The final step form is $x(t)=2+3u(t-1)-3u(t-3)$, which shows the exact signed-jump mechanism for direct transitions between two nonzero levels.

## Combining Multiple Level Changes into One Step Expression

**Example:** Write one unit-step expression for $x(t)=1$ if $t<0$, $x(t)=4$ if $0\le t<2$, $x(t)=-2$ if $2\le t<4$, and $x(t)=3$ if $t\ge4$.

**Explanation**

This signal has multiple breakpoints, so the cue is to use one baseline and one signed jump at each breakpoint. List the levels in order: start at $1$, then jump to $4$ at $t=0$, then to $-2$ at $t=2$, then to $3$ at $t=4$.

Set the baseline to the first value: $y_0=1$. The first jump is $\Delta A_1=4-1=3$ at $t=0$, so add $3u(t)$. The second jump is $\Delta A_2=-2-4=-6$ at $t=2$, so add $-6u(t-2)$. The third jump is $\Delta A_3=3-(-2)=5$ at $t=4$, so add $5u(t-4)$.

$$
x(t)=1+3u(t)-6u(t-2)+5u(t-4)
$$

Check the intervals. For $t<0$, all shifted steps are $0$, giving $x(t)=1$. For $0\le t<2$, only $u(t)=1$, so $x(t)=1+3=4$. For $2\le t<4$, $u(t)=1$ and $u(t-2)=1$ while $u(t-4)=0$, so $x(t)=1+3-6=-2$. For $t\ge4$, all terms are $1$, so $x(t)=1+3-6+5=3$.

The compact representation is $x(t)=1+3u(t)-6u(t-2)+5u(t-4)$, and it is the general reusable form for multiple level changes in this topic.
