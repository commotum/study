## Introduction to Definition of the Unit Impulse

Ordinary signals are described by finite widths and finite heights, but the impulse is introduced as a limiting point-concentrated signal. You should recognize the core object first: $\delta(t)$ is defined by a zero-width support idea, not by a usual shape you can inspect point by point.

Your first action is to treat support as the object criterion: the unit impulse is concentrated at $t=0$, so it is identified by where it acts in the continuum, not by an ordinary pointwise value. Keep in mind that practical use is tied to what happens under integration.

Use this pair of properties together as the operating definition: for $t\neq 0$, $\delta(t)=0$, and $\int_{-\infty}^{\infty}\delta(t)\,dt=1$. The second part fixes the impulse's meaning as a unit-area building block.

Use the base case model to check intuition. As $\epsilon \to 0^+$, write $\delta_\epsilon(t)=\frac{1}{\epsilon}[u(t+\epsilon/2)-u(t-\epsilon/2)]$. The pulse gets narrower and taller while preserving unit area, which is exactly the limiting behavior you will reuse in later sections.

$$
\int_{-\infty}^{\infty}\delta(t)\,dt=1
$$

$$
\delta(t)=\lim_{\epsilon\to 0^+}\frac{1}{\epsilon}\,[u(t+\epsilon/2)-u(t-\epsilon/2)]
$$

## Recognizing $\delta$(t) as a Point Signal

**Example:** Identify the point-support interpretation of $f(t)=\delta(t)$: choose the correct statement about where the signal acts and what quantity it contributes under integration.

**Explanation**

Cue: the expression is written as $\delta(t)$, so you should treat it as a point-support object, not a finite-width pulse. The support is therefore $\{0\}$, meaning the signal is concentrated at the single instant $t=0$.

Apply the rule from the prior definition: $\delta(t)=0$ for all $t\neq 0$, and its identifying quantity is area, not pointwise value. So for a unit impulse at the origin the unit-area condition is $\int_{-\infty}^{\infty}\delta(t)\,dt=1$.

Execute the matching step. Since no offset appears, $\delta(t)$ is exactly the same as $\delta(t-0)$, so the support point and the unit-area interpretation are unchanged. That is the key recognition move you will reuse when you evaluate options like $\delta(t-a)$ or combinations.

$$
\delta(t)=\delta(t-0)
$$

Result: the correct statement is that $f(t)=\delta(t)$ contributes one unit of area at $t=0$, so it should be interpreted by support and integral action, not as an ordinary pointwise value at zero.

<a id="identifying-the-zero-width-behavior-of-deltat"></a>
## Identifying the Zero-Width Behavior of $\delta$(t)

**Example:** Evaluate the limit model $x_\epsilon(t)=\frac{1}{\epsilon}\,\mathbf{1}_{|t|<\epsilon/2}$ and state the zero-width implication for $t\ne 0$ and the preserved area property.

**Explanation**

Cue: this step adds one controlled wrinkle beyond pure support recognition by introducing a width-to-zero family. Start from the interval form, identify that for each fixed $\epsilon>0$, the pulse is nonzero only on $-\epsilon/2 < t < \epsilon/2$ and has height $1/\epsilon$.

Compute the defining invariant first. For generic $\epsilon$, integrate directly over the active interval: $\int_{-\epsilon/2}^{\epsilon/2} \frac{1}{\epsilon}\,dt = 1$, so the area is fixed at one before taking any limit.

$$
\int_{-\epsilon/2}^{\epsilon/2}\frac{1}{\epsilon}\,dt = 1
$$

Now track value and area separately as $\epsilon\to 0^+$. For $t\ne 0$, the interval eventually excludes $t$, so $\lim_{\epsilon\to 0^+}x_\epsilon(t)=0$. At the same time, the unit-area identity remains intact, which is the signature of zero-width concentration.

$$
\lim_{\epsilon\to 0^+}x_\epsilon(t)=0 \text{ for } t\neq 0
$$

Result: this model shrinks toward a point-support signal with support at $t=0$ while preserving unit area, so it behaves like the impulse abstraction used in this lesson's core move.

## Interpreting the Unit Area of $\delta$(t)

**Example:** Compute the area of $\delta(t)$ and $3\delta(t)$ under the same integral convention, and interpret what the scalar does.

**Explanation**

Cue: this step keeps the zero-width support fixed at $t=0$ and adds one controlled wrinkle: coefficient scaling. The task is to interpret the scalar in front of the impulse as a signal area weight.

Execute step one. Use the base rule for the unit impulse: for the unscaled atom, the area is $\int_{-\infty}^{\infty}\delta(t)\,dt=1$. This is the same baseline used in earlier steps.

$$
\int_{-\infty}^{\infty}\delta(t)\,dt=1
$$

Execute step two with linearity. Since $x(t)=3\delta(t)$, $\int_{-\infty}^{\infty}x(t)\,dt=3\int_{-\infty}^{\infty}\delta(t)\,dt=3\cdot 1=3$, so the area scales by the same coefficient.

$$
\int_{-\infty}^{\infty}3\delta(t)\,dt=3
$$

Result: $3\delta(t)$ has unit-support at $t=0$ but area $3$, so it is not interpreted as a pointwise peak value; it is interpreted as a weighted impulse event.

## Using $\delta$(t) as a Continuous-Time Signal Building Block

**Example:** Write a signal description for two impulse events at the origin: one unit impulse and one weighted by $2$, then simplify it into a single weighted impulse expression.

**Explanation**

Cue: both events are at the same support point $t=0$, so this step keeps the same location rule from prior sections and adds only one wrinkle: combining coefficients at matching support.

Translate the verbal events into symbols using the same rule: one unit event is $\delta(t)$, and the weighted event is $2\delta(t)$. So the signal is $x(t)=\delta(t)+2\delta(t)$.

Apply additivity on matching support points. Since both terms share support $t=0$, combine their scalar coefficients: $\delta(t)+2\delta(t)=3\delta(t)$. This is the core composition move for impulse-based representations.

$$
x(t)=\delta(t)+2\delta(t)=3\delta(t)
$$

Result: the simplified representation is a single weighted impulse at $t=0$ with coefficient $3$, which means area $3$ at the same instant and no change in support.
