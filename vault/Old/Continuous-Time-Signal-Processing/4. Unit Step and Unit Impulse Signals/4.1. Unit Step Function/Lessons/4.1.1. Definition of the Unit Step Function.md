## Introduction

The unit step function is a simple way to model a switch in continuous time. In its basic form, the switch turns on at $t=0$.

Before the switching time, the signal is off:

$$
u(t)=0\quad (t<0)
$$

After the switching time, the signal is on:

$$
u(t)=1\quad (t>0)
$$

For example, $u(-1)=0$ because $-1$ is before the switch, while $u(2)=1$ because $2$ is after the switch.

At the exact switching time, different sources use different conventions. In this course, we will use

$$
u(0)=1
$$

With that convention, the basic unit step can be summarized as

$$
u(t)=
\begin{cases}
0, & t<0,\\
1, & t\ge 0.
\end{cases}
$$

This function is a core building block for signals that start, stop, or change at specific times. Later, we will shift unit steps to create delayed switches and combine them to build rectangular pulses and other on-off signal forms.

## Evaluating the Unit Step Before and After the Switch

**Example:** Evaluate $u(-4)$ and $u(3)$ with the definition from the tutorial.

**Explanation**

Use the unit-step rule as the guide: for $t<0$, the signal is off and $u(t)=0$, and for $t>0$, the signal is on and $u(t)=1$.

Classify the first query: $-4<0$, so it is on the left side of the switch.

Apply the left-side rule to the query and report the result: $u(-4)=0$.

Classify the second query: $3>0$, so it is on the right side of the switch.

Apply the right-side rule and report the result: $u(3)=1$.

Final answer: $u(-4)=0$, $u(3)=1$. In this lesson format, any non-boundary point is solved by that same two-step pointwise classification and substitution pattern.

## Evaluating the Unit Step at the Switching Time

**Example:** Evaluate $u(0)$ and decide whether it differs from both one-sided limits.

**Explanation**

Use the same switch rule as the earlier sections: for $t<0$, $u(t)=0$, and for $t>0$, $u(t)=1$. The new cue here is to handle the boundary-time case.

Recognize $t=0$ is not a strict interior point, so it is not covered by either the left-hand or right-hand branch alone.

Apply the lesson convention directly at the boundary: $u(0)=1$ for this topic line.

For contrast, the neighbor values are $u(0^-)=0$ and $u(0^+)=1$ under the previously learned rules.

Result: the boundary point is $u(0)=1$, which does differ from the left-limit value at zero and matches the chosen on-value convention used in this lesson.

## Reading the Unit Step Function from a Time-Axis Graph

**Example:** Read the graph and compute $u(t)$ for three selected times, including the switch instant.

**Explanation**

![](<../Source/4.1.1. Definition of the Unit Step Function/Images/l001-s004-te-section-004.png>)

Use the graph as the cue: identify the switching instant first, then read which side of the jump each query time is on.

If the switch is at $t=0$, then the left-side region is $t<0$ and the right-side region is $t>0$.

Classify the selected times: $t=-2$ lies left of the switch, so $u(-2)=0$.

For the switch instant $t=0$, apply the lesson convention, so $u(0)=1$. In this lesson that is the same boundary convention used in symbolic work.

For $t=2$, the time is right of the jump, so $u(2)=1$. Therefore the on interval is $t\ge 0$ and the off interval is $t<0$ under this convention.

<a id="recognizing-the-unit-step-as-the-basic-continuous-time-switching-signal"></a>
## Recognizing the Unit Step as the Basic Continuous-Time Switching Signal

**Example:** Rewrite and interpret the piecewise signal defined by $x(t)u(t)$ with $x(t)=t^2$.

**Explanation**

Use the cue that multiplication by $u(t)$ gates the signal by time region, so $x(t)u(t)$ must be split by the same $u(t)$ regions.

From the learned rule, if $t<0$, then $u(t)=0$, so $x(t)u(t)=t^2\cdot 0=0$ on the off region.

For $t>0$, the on region has $u(t)=1$, so $x(t)u(t)=t^2\cdot 1=t^2$ there.

$$
x(t)u(t)=\begin{cases}0, & t<0\\ t^2, & t\ge0\end{cases}
$$

Using the lesson convention at the boundary, $u(0)=1$, so $x(0)u(0)=0^2\cdot 1=0$ and the boundary aligns with the right-side expression.
