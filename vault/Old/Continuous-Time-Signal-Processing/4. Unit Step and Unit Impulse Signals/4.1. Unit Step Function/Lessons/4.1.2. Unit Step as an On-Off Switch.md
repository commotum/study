## Introduction to Unit Step as an On-Off Switch

The object to recognize is the continuous-time unit step $u(t)$. In this topic, treat it as a switch: for $t<0$, it turns off; for $t\ge 0$, it turns on. Therefore a product $y(t)=x(t)u(t)$ is a regionwise product that depends on the sign of $t$.

$$
y(t)=x(t)u(t)
$$

Use the base case $x(t)=1$ so the switch action is transparent: then $y(t)=u(t)$. For any $x(t)$, apply the same rule and write the decomposition explicitly as a switched expression.

$$
y(t)=\begin{cases}0,\; t<0\\x(t),\; t\ge 0\end{cases}
$$

The meaning is direct: $u(t)$ suppresses the signal before the switch time, so $y(t)=0$ for $t<0$, and it lets the original form pass unchanged afterward, so $y(t)=x(t)$ for $t\ge 0$. This same template will be reused as the core move whenever step multiplication defines a region of activation.

## Evaluating $x(t)$$u(t)$ Before $t = 0$

**Example:** Evaluate $y(t)=x(t)u(t)$ for $y(t)=(2-t)u(t)$ at $t=-1$.

**Explanation**

Cue: this is an on-off switch evaluation in the pre-switch region. Use $y(t)=x(t)u(t)$ with $x(t)=2-t$ and evaluate both factors at $t=-1$.

$$
y(-1)=(2-(-1))u(-1)
$$

Because the switch is off in the region $t<0$, the value rule gives $u(-1)=0$.

$$
u(-1)=0
$$

Substitute that factor into the product: $y(-1)=(2-(-1))\cdot 0=0$. The result is $y(-1)=0$, which is exactly the explicit zero output in the blocked region.

## Evaluating $x(t)$$u(t)$ After $t = 0$

**Example:** Evaluate $y(t)=(3t+1)u(t)$ at $t=2$.

**Explanation**

Cue: this is an on-region evaluation where the gate is open. Identify the target expression as $y(t)=x(t)u(t)$ and substitute $t=2$ into both factors.

$$
y(2)=(3\cdot2+1)u(2)
$$

From the switch rule, for $t>0$, $u(t)=1$, so here $u(2)=1$.

$$
u(2)=1
$$

Now compute the switched value directly: $y(2)=(3\cdot2+1)\cdot 1=7$. This matches the active formula $x(2)=7$, so in the on region $y(t)=x(t)$.

## Writing the On-Off Output of $x(t)$$u(t)$ in Piecewise Form

**Example:** Express $y(t)=(4t+1)u(t)$ as an explicit piecewise function of $t$.

**Explanation**

Cue: this is the same switch rule from earlier, now written for all times. Start from the generic product form $y(t)=x(t)u(t)$ with $x(t)=4t+1$.

$$
y(t)=x(t)u(t),\quad x(t)=4t+1
$$

Set the off branch using $t<0\Rightarrow u(t)=0$, and the on branch using $t\ge 0\Rightarrow u(t)=1$.

$$
y(t)=\begin{cases}0,\; t<0 \\ 4t+1,\; t\ge 0\end{cases}
$$

This form is explicit for every time region: $y(t)$ is blocked to zero before the switch and equals $x(t)$ after and at the switch point, which is the core on-off behavior of $x(t)u(t)$.
