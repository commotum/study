## Introduction to Definition of Continuous-Time Convolution

Continuous-time convolution describes the output of an LTI system from its input and impulse response. The key idea is to view the input $x(t)$ as an accumulation of tiny weighted impulse contributions, one contribution near each input time $\tau$.

![](<../Source/6.3.1. Definition of Continuous-Time Convolution/Images/l001-s001-te-section-001.png>)

The contribution near time $\tau$ has weight $x(\tau)$ d $\tau$. Since the system is LTI, an impulse located at $\tau$ produces a shifted impulse response $h(t-\tau)$, so the weighted contribution to the output at time t is $x(\tau)$$h(t-\tau)$ d $\tau$.

To form the total output at time t, add the contributions from all input times $\tau$. This accumulated output is called the convolution of x and h.

$$
y(t)=(x*h)(t)
$$

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

Read this formula as an accumulation of weighted, shifted impulse responses: $x(\tau)$ gives the input weight at time $\tau$, $h(t-\tau)$ gives the corresponding shifted impulse response observed at time t, and d $\tau$ tells us to integrate over all input times. For now, the goal is to formulate and interpret the definition, not to compute overlap intervals or evaluate the integral.

## Reading the Signals in the Convolution Definition

**Example:** In $y(t)$=$\int$_{-$\infty$}^{$\infty$} $x(\tau)$$h(t-\tau)$\,d$\tau$, identify the input term, the shifted impulse-response term, the integration variable, and the output.

**Explanation**

The cue is the convolution definition itself. We are not evaluating the integral yet; we are reading the parts of the formula and naming what each part represents.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

The output is $y(t)$. It names the value produced by the LTI system at the fixed observation time t.

The integration variable is $\tau$. The differential d $\tau$ tells us that $\tau$ is the variable being swept through all input times inside the integral.

The input term is $x(\tau)$. For each input time $\tau$, this factor gives the input weight attached to the contribution from that time.

The shifted impulse-response term is $h(t-\tau)$. It is the response observed at time t from an impulse placed at the input time $\tau$.

$$
y(t):\text{ output},\quad \tau:\text{ integration variable},\quad x(\tau):\text{ input term},\quad h(t-\tau):\text{ shifted impulse-response term}
$$

So the formula says to accumulate input-weighted shifted impulse responses. This example only labels the roles of the symbols; it does not choose limits from signal support or compute the integral.

## Writing the Continuous-Time Convolution Integral

**Example:** Given an LTI system with input $x(t)$ and impulse response $h(t)$, write the convolution integral for the output $y(t)$.

**Explanation**

The cue is that the system is LTI and the input and impulse response are named. For an LTI system, the output is the convolution of the input with the impulse response.

$$
y(t)=(x*h)(t)
$$

To write the integral form, use $\tau$ as the integration variable. The input term becomes $x(\tau)$, because $\tau$ scans the input time.

The impulse-response term becomes $h(t-\tau)$, because an impulse located at time $\tau$ contributes a shifted response observed at the output time t.

Finally, include the full accumulation over all input times. That means the limits run from negative infinity to infinity and the differential is d $\tau$.

$$
y(t)=(x*h)(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

This is the complete convolution setup for the named input and impulse response. The result writes the output formula; it does not yet evaluate the integral.

## Connecting the Integral to an LTI System Output

**Example:** An LTI system has input $x(t)$ and impulse response $h(t)$. Express its output $y(t)$ using the continuous-time convolution definition.

**Explanation**

The cue is that the system is LTI and its impulse response is $h(t)$. For an LTI system, the impulse response tells how the system responds to each shifted impulse in the input.

Use the input $x(t)$ as the source of weights. A contribution from input time $\tau$ has weight $x(\tau)$, and the corresponding shifted impulse response is $h(t-\tau)$.

So the output is the convolution of the input with the impulse response.

$$
y(t)=(x*h)(t)
$$

Writing out the convolution definition gives the accumulated contribution from all input times $\tau$.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

This expression is the LTI system output. It is an accumulation of weighted, shifted impulse responses, not pointwise multiplication of $x(t)$ and $h(t)$ and not the impulse response alone.

<a id="interpreting-convolution-as-accumulated-shifted-responses"></a>
## Interpreting Convolution as Accumulated Shifted Responses

**Example:** Explain what $x(\tau)$$h(t-\tau)$\,d$\tau$ contributes to $y(t)$ in the convolution integral.

**Explanation**

The cue is the differential contribution inside the convolution integral. The expression $x(\tau)$$h(t-\tau)$ d $\tau$ is not the entire output; it describes one small contribution to the output from input times near $\tau$.

$$
x(\tau)h(t-\tau)\,d\tau
$$

First read $x(\tau)$ d $\tau$ as the small weighted input contribution near the input time $\tau$. The value $x(\tau)$ gives the weight, and d $\tau$ represents the tiny interval of input time being included.

Because the system is LTI, an impulse located at time $\tau$ produces the shifted impulse response $h(t-\tau)$. At the output time t, the value of that shifted response is $h(t-\tau)$.

Multiplying these pieces gives the contribution to $y(t)$ from that one small slice of input time: the input weight times the shifted response value.

$$
x(\tau)\,d\tau \quad \text{scaled by} \quad h(t-\tau)
$$

The full convolution integral accumulates all of these small shifted-response contributions over every input time $\tau$.

$$
y(t)=\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau
$$

So $x(\tau)$$h(t-\tau)$ d $\tau$ is one infinitesimal shifted-response contribution, and the integral is the accumulated output $y(t)$.
