## Introduction to Continuous-Time Sifting Representation

A shifted impulse such as $\delta(t-\tau)$ is located at the time selected by $\tau$. The sifting property says that, inside an integral, this impulse keeps only the value of the weighting function at the matching time.

$$
\int_{-\infty}^{\infty} f(\tau)\delta(t-\tau)\,d\tau=f(t)
$$

In this formula, $\tau$ is the integration variable and $t$ is the time where the result is being evaluated. The impulse $\delta(t-\tau)$ selects $\tau=t$, so the integral returns the weighting function evaluated at $t$.

For a signal $x(t)$, use the same rule with the weighting function $x(\tau)$. This gives the continuous-time sifting representation:

$$
x(t)=\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau
$$

Read the integral as a continuous superposition of shifted impulses. Each value of $\tau$ supplies one shifted impulse $\delta(t-\tau)$, and the signal value $x(\tau)$ supplies that impulse's weight.

This is not ordinary area accumulation over wide pulses. It is a way to rebuild the signal from impulse components indexed by $\tau$. That decomposition prepares the input signal for later system-output construction.

## Evaluating a Sifting Integral at a Fixed Time

**Example:** Evaluate $\int_{-\infty}^{\infty}(\tau^2+1)\delta(3-\tau)\,d\tau$.

**Explanation**

The cue is the shifted impulse $\delta(3-\tau)$. This is the sifting pattern with the fixed time value $3$, so the impulse selects the value $\tau=3$.

The weighting expression is the factor multiplying the impulse:

$$
f(\tau)=\tau^2+1
$$

By the sifting property, replace $\tau$ in the weighting expression with the selected value $3$.

$$
\begin{aligned}
\int_{-\infty}^{\infty}(\tau^2+1)\delta(3-\tau)\,d\tau &= f(3) \\
&=3^2+1 \\
&=10
\end{aligned}
$$

Therefore, the value of the sifting integral is $10$. The integration variable $\tau$ has been selected and removed, so the result is a scalar.

## Reconstructing $x(t)$ with $\delta$(t-$\tau$)

**Example:** Simplify $\int_{-\infty}^{\infty}e^{-2\tau}u(\tau)\delta(t-\tau)\,d\tau$.

**Explanation**

The cue is the impulse $\delta(t-\tau)$. Instead of selecting a fixed number such as $\tau=3$, this impulse selects the symbolic value $\tau=t$.

The expression multiplying the impulse is the signal expression in $\tau$:

$$
f(\tau)=e^{-2\tau}u(\tau)
$$

Use the sifting property by replacing every occurrence of $\tau$ in that expression with $t$. The integration variable $\tau$ is removed, while $t$ remains as the output time variable.

$$
\begin{aligned}
\int_{-\infty}^{\infty}e^{-2\tau}u(\tau)\delta(t-\tau)\,d\tau &= f(t) \\
&= e^{-2t}u(t)
\end{aligned}
$$

So the sifting integral reconstructs the signal expression $e^{-2t}u(t)$.

## Writing a Signal as a Sifting Integral

**Example:** Write $x(t)=\cos(2t)u(t)$ as a continuous-time sifting integral.

**Explanation**

The cue is the phrase "as a continuous-time sifting integral." This means use the reconstruction identity, but build the integral instead of simplifying one.

$$
x(t)=\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau
$$

Start with the given signal expression and rewrite it as a function of the integration variable $\tau$. Replace every $t$ in the signal expression with $\tau$.

$$
x(\tau)=\cos(2\tau)u(\tau)
$$

Now place $x(\tau)$ as the weight multiplying $\delta(t-\tau)$. Use infinite limits because no support restriction has been requested.

$$
x(t)=\int_{-\infty}^{\infty}\cos(2\tau)u(\tau)\delta(t-\tau)\,d\tau
$$

This integral is the sifting representation of the original signal $x(t)=\cos(2t)u(t)$.

<a id="restricting-the-sifting-integral-to-the-signal-support"></a>
## Restricting the Sifting Integral to the Signal Support

**Example:** Write the signal $x(t)=2t$ for $0\le t\le 3$, and $x(t)=0$ otherwise, as a sifting integral with limits restricted to its support.

**Explanation**

The cue is that the limits should be restricted to the signal support. The signal is nonzero only on $0\le t\le 3$, so the integration variable should range over the same interval.

$$
0\le \tau \le 3
$$

On that interval, the signal formula is $x(t)=2t$. Rewrite the nonzero formula with $\tau$ replacing $t$ to form the weight in the sifting integral.

$$
x(\tau)=2\tau
$$

Place this weight in front of $\delta(t-\tau)$, and use the support interval as the lower and upper limits. Values of $\tau$ outside this interval contribute zero.

$$
x(t)=\int_{0}^{3}2\tau\delta(t-\tau)\,d\tau
$$

This is the support-restricted sifting representation of the signal.
