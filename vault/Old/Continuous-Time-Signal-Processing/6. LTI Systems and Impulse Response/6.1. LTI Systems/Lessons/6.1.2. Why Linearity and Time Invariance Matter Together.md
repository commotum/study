## Introduction to Why Linearity and Time Invariance Matter Together

The useful object in this lesson is a known input-output pair for a system. If the input $x(t)$ produces the output $y(t)$, then we want to know when related inputs can reuse that same response pattern instead of requiring a new analysis from scratch.

$$
T\{x(t)\}=y(t)
$$

Linearity controls scaling and addition. For one component, the scaling part says that if the input is multiplied by a constant a, the corresponding output is multiplied by the same constant. The system does not invent a new shape for that scaled copy.

$$
T\{a x(t)\}=a y(t)
$$

Time invariance controls shifting. If the input copy is delayed or advanced, the output copy is delayed or advanced by the same amount. The time shift moves the response; it does not change which response pattern is being used.

$$
T\{x(t-t_0)\}=y(t-t_0)
$$

An LTI system has both properties at once. That means a scaled and shifted copy of a known input produces the same scaled and shifted copy of the known output. This is the reusable-response rule that the next examples will practice.

$$
T\{a x(t-t_0)\}=a y(t-t_0)
$$

This pairing is why linearity and time invariance matter together. Linearity lets scaled components keep the same response with scaled amplitude, while time invariance lets shifted components keep the same response with shifted time. Later, that is what allows one response pattern to serve as a reusable reference for many shifted and scaled input components.

## Tracing a Scaled Input Component Through a Linear System

**Example:** Suppose a linear system satisfies $T{x(t)}$ = $y(t)$. What output must correspond to the input $3x(t)$?

**Explanation**

Start with the known input-output pair. The system sends the input component $x(t)$ to the output $y(t)$.

$$
T\{x(t)\}=y(t)
$$

The cue is that the new input $3x(t)$ is the same input component multiplied by the scalar 3. Since this section is only about scaling, use the homogeneity part of linearity, not time invariance.

$$
T\{3x(t)\}=3T\{x(t)\}
$$

Now substitute the known output $y(t)$ for $T{x(t)}$. The scalar that multiplies the input becomes the same scalar multiplying the output.

$$
T\{3x(t)\}=3y(t)
$$

Therefore, the input $3x(t)$ must produce the output $3y(t)$. The response pattern is still $y(t)$; only its scale changes.

## Tracing a Shifted Input Component Through a Time-Invariant System

**Example:** Suppose a time-invariant system satisfies $T{x(t)}$ = $y(t)$. What output must correspond to the input $x(t - 4)$?

**Explanation**

Start with the known input-output pair. The system sends the input component $x(t)$ to the output $y(t)$.

$$
T\{x(t)\}=y(t)
$$

The cue is that the new input $x(t - 4)$ is a delayed copy of the known input component. Since there is no scalar multiplier in this example, use time invariance, not linearity.

$$
T\{x(t-t_0)\}=y(t-t_0)
$$

Here the delay is 4, so the output receives the same delay. Keep the sign inside the argument the same: an input written with t - 4 produces an output written with t - 4.

$$
T\{x(t-4)\}=y(t-4)
$$

Therefore, the input $x(t - 4)$ must produce the output $y(t - 4)$. The response pattern is still $y(t)$; only its time location changes.

## Tracing a Scaled and Shifted Component Through an LTI System

**Example:** Suppose an LTI system satisfies $T{x(t)}$ = $y(t)$. What output must correspond to the input $-2x(t - 3)$?

**Explanation**

Start with the known input-output pair. The system sends the input component $x(t)$ to the output $y(t)$.

$$
T\{x(t)\}=y(t)
$$

The cue is that $-2x(t - 3)$ is both scaled and delayed. Because the system is LTI, time invariance handles the delay and linearity handles the scalar multiplier.

$$
T\{a x(t-t_0)\}=a y(t-t_0)
$$

Apply the time shift first. The input copy $x(t - 3)$ is delayed by 3, so the associated output copy is delayed by the same amount.

$$
T\{x(t-3)\}=y(t-3)
$$

Now apply the scalar. The multiplier -2 on the input copy becomes the same multiplier on the shifted output copy. The negative sign changes the scale, not the shift direction.

$$
T\{-2x(t-3)\}=-2y(t-3)
$$

Therefore, the input $-2x(t - 3)$ must produce the output $-2y(t - 3)$. Both the scalar and the delay are copied onto the known response pattern $y(t)$.

## Justifying a Reusable Response Pattern for LTI Systems

**Example:** A system is LTI and a basic component $x(t)$ produces $y(t)$. Explain why knowing $y(t)$ is enough to predict the outputs for $2x(t)$, $x(t - 5)$, and $2x(t - 5)$.

**Explanation**

The known response pair is the reusable object. The input component $x(t)$ produces the output pattern $y(t)$.

$$
T\{x(t)\}=y(t)
$$

Linearity explains the scaled input. If the input component is multiplied by 2, the corresponding output is multiplied by the same 2.

$$
T\{2x(t)\}=2y(t)
$$

Time invariance explains the shifted input. If the input component is delayed by 5, the corresponding output pattern is delayed by the same amount.

$$
T\{x(t-5)\}=y(t-5)
$$

Because the system has both properties, the scaled and shifted input reuses the same output pattern with both changes applied.

$$
T\{2x(t-5)\}=2y(t-5)
$$

So knowing $y(t)$ is enough because an LTI system preserves the two changes that appear in these related inputs: linearity preserves scaling, and time invariance preserves shifting. That is the reusable-response idea that will make the later impulse-response framework useful.
