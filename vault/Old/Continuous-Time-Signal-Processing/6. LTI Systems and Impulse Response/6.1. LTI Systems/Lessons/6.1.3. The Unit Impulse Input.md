## Introduction to The Unit Impulse Input

An LTI system is useful because linearity and time invariance let one response pattern be reused. The first input used to expose that pattern is the unit impulse, written $\delta(t)$.

$$
x(t)=\delta(t)
$$

Here $\delta(t)$ is an idealized unit impulse located at $t=0$. In this section, treat it as the input signal being applied to the system, not as a normal finite-height pulse and not as the output.

![](<../Source/6.1.3. The Unit Impulse Input/Images/l003-s001-te-section-001.png>)

Applying $\delta(t)$ to an LTI system is the standard probe case. The system takes that impulse input and produces an output response to the unit impulse at the origin.

$$
\delta(t)\ \longrightarrow\ \text{LTI system}\ \longrightarrow\ \text{response to }\delta(t)
$$

That output is the reference response for this system. Later sections will use the same reference response when the impulse input is shifted or scaled, but this section only identifies the unshifted unit impulse input and the response it produces.

<a id="identifying-deltat-as-the-probe-input"></a>
## Identifying $\delta$(t) as the Probe Input

**Example:** Identify the probe input in a set of candidate signals sent into the same LTI system: $\delta(t)$, $u(t)$, $\delta(t - 2)$, 2$\delta$(t), and a rectangular pulse.

**Explanation**

The cue is the phrase probe input. In this lesson, the probe input must be the unshifted unit impulse: it has to be an impulse, it has to be located at $t=0$, and it has to be the unit impulse rather than a scaled impulse.

![](<../Source/6.1.3. The Unit Impulse Input/Images/l003-s002-te-section-002.png>)

Read the candidate labels first. The unit step $u(t)$ is not an impulse, and the rectangular pulse is a finite-width pulse, so neither one is the unit impulse probe. The shifted impulse $\delta(t - 2)$ is an impulse, but it is located at $t=2$ instead of $t=0$. The scaled impulse 2$\delta$(t) is at $t=0$, but it is not the unit impulse because it has a factor of 2.

$$
\begin{aligned}\nu(t)&:\ \text{step, not an impulse}\\
\delta(t-2)&:\ \text{shifted impulse, not at }t=0\\
2\delta(t)&:\ \text{scaled impulse, not unit}\\
\text{rectangular pulse}&:\ \text{finite-width pulse, not an ideal impulse}
\end{aligned}
$$

The only candidate that passes all three checks is $\delta(t)$: it is an impulse, it is located at $t=0$, and it is the unit impulse. Therefore $\delta(t)$ is the canonical probe input for this LTI system.

$$
\text{unshifted unit impulse probe input}=\delta(t)
$$

<a id="distinguishing-the-impulse-input-from-its-system-output"></a>
## Distinguishing the Impulse Input from Its System Output

**Example:** A block diagram shows $\delta(t)$ entering an LTI system and a waveform $y(t)$ leaving it. Identify which signal is the impulse input and which signal is the system output.

**Explanation**

The cue is the direction of the arrows through the system block. The signal on the arrow entering the LTI system is the input applied to the system, and the signal on the arrow leaving the system is the output produced by the system.

![](<../Source/6.1.3. The Unit Impulse Input/Images/l003-s003-te-section-003.png>)

Start with the entering arrow. Its label is $\delta(t)$, so $\delta(t)$ is the impulse input probe. This is the signal being applied to the system, not the response generated by the system.

$$
\delta(t)\ \longrightarrow\ \text{LTI system}\ \longrightarrow\ y(t)
$$

Now read the leaving arrow. The waveform labeled $y(t)$ is the system output produced after the input $\delta(t)$ passes through the LTI system. The output waveform may have a different shape from the impulse, but its role is still output, not input.

$$
\text{impulse input}=\delta(t),\qquad \text{system output}=y(t)
$$

<a id="using-the-unit-impulse-output-as-the-reference-response"></a>
## Using the Unit Impulse Output as the Reference Response

**Example:** An LTI system produces the output $r(t)$ when the input is $\delta(t)$. Interpret what role $r(t)$ will play for later shifted and scaled impulse inputs.

**Explanation**

The cue is the input-output pair: the input is $\delta(t)$, and the corresponding output is $r(t)$. Since $\delta(t)$ is the unshifted unit impulse probe, the output produced by that probe is the response pattern tied to this LTI system.

![](<../Source/6.1.3. The Unit Impulse Input/Images/l003-s004-te-section-004.png>)

First confirm the applied input. The diagram says the system is driven by $\delta(t)$, so this is the standard unit impulse probe case rather than a step input, shifted impulse, or scaled impulse.

$$
\delta(t)\ \longrightarrow\ \text{LTI system}\ \longrightarrow\ r(t)
$$

Now read the output produced by that probe. The signal $r(t)$ is not the input and it is not arbitrary; it is the output generated by this system when the input is the unit impulse. In this lesson, that makes $r(t)$ the reference response for later impulse-input reasoning.

$$
\delta(t)\ \text{produces}\ r(t)\quad\Rightarrow\quad r(t)\ \text{is the reference response}
$$

Later shifted and scaled impulse inputs will reuse this reference response pattern. For now, the required interpretation is only that the output caused by the unit impulse input is the system's reference response.
