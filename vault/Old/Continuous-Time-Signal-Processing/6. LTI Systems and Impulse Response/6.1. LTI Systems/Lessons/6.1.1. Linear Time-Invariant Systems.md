## Introduction to Linear Time-Invariant Systems

A continuous-time input-output system is linear time-invariant, or LTI, only when it passes two separate tests. The system must be linear, meaning it preserves scaling and addition of inputs, and it must be time-invariant, meaning a time shift at the input produces the same time shift at the output.

Use the linearity test first. If the system sends input $x_1(t)$ to output $y_1(t)$, and input $x_2(t)$ to output $y_2(t)$, then any scaled sum of those inputs must produce the same scaled sum of the outputs.

$$
T[a x_1(t)+b x_2(t)] = a y_1(t)+b y_2(t)
$$

Use the time-invariance test next. If the system sends $x(t)$ to $y(t)$, then delaying or advancing the input must only delay or advance the output by the same amount.

$$
T[x(t-t_0)] = y(t-t_0)
$$

The constant-gain system $y(t)$=$3x(t)$ is the cleanest base case. Multiplying an input by 3 does not disturb scaling or addition, and shifting $x(t)$ before the system simply gives 3x(t-$t_0$), which is the original output shifted by $t_0$.

$$
\text{linear} + \text{time-invariant} \Rightarrow \text{LTI}
$$

Both tests must pass. If either superposition or time-shift consistency fails, the system is not LTI. This classification matters because impulse-response and convolution methods are only available after the system has been established as LTI.

<a id="testing-a-constant-gain-system-for-lti-classification"></a>
## Testing a Constant-Gain System for LTI Classification

**Example:** Classify the system $y(t)$=$4x(t)$ as linear time-invariant or not by applying both the superposition test and the time-shift test.

**Explanation**

The rule is a constant-gain system: it multiplies every input value by the same constant 4. Write the system operator as T[$x(t)$]=$4x(t)$. To classify it as LTI, check linearity first and time invariance second.

$$
T[x(t)]=4x(t)
$$

For the superposition test, feed the system a scaled sum a $x_1(t)$+b $x_2(t)$. The output is 4 times that whole input.

$$
\begin{aligned}
T[a x_1(t)+b x_2(t)] &= 4[a x_1(t)+b x_2(t)] \\
&= a[4x_1(t)] + b[4x_2(t)] \\
&= aT[x_1(t)]+bT[x_2(t)]
\end{aligned}
$$

This matches the required superposition form, so the constant-gain system is linear.

Now test a time shift. If the input is shifted to $x(t-t_0)$, the system still multiplies the shifted input by 4.

$$
T[x(t-t_0)] = 4x(t-t_0)
$$

The original output is $y(t)$=$4x(t)$. Shifting that output by $t_0$ gives $y(t-t_0)$=4x(t-$t_0$), the same expression as the shifted-input output.

$$
y(t-t_0)=4x(t-t_0)
$$

Both tests pass, so the system $y(t)$=$4x(t)$ is LTI. The fixed multiplier 4 preserves both superposition and time shifts.

<a id="testing-a-derivative-system-for-lti-classification"></a>
## Testing a Derivative System for LTI Classification

**Example:** Classify the system $y(t)$=dx(t)/dt as linear time-invariant or not by applying both LTI tests.

**Explanation**

The cue is that this system differentiates the input instead of just multiplying it by a constant. Write the system operator as T[$x(t)$]=d $x(t)$/dt. To classify it, use the same two-test routine: check linearity first, then check time invariance.

$$
T[x(t)]=\frac{d}{dt}x(t)
$$

For the superposition test, feed the system a scaled sum a $x_1(t)$+b $x_2(t)$. Differentiation preserves both scaling and addition.

$$
\begin{aligned}
T[a x_1(t)+b x_2(t)] &= \frac{d}{dt}[a x_1(t)+b x_2(t)] \\
&= a\frac{d}{dt}x_1(t)+b\frac{d}{dt}x_2(t) \\
&= aT[x_1(t)]+bT[x_2(t)]
\end{aligned}
$$

This matches the required superposition form, so the derivative system is linear.

Now test a time shift. If the input is shifted to $x(t-t_0)$, differentiating with respect to t gives the derivative of the shifted signal.

$$
\begin{aligned}
T[x(t-t_0)] &= \frac{d}{dt}x(t-t_0) \\
&= x'(t-t_0)
\end{aligned}
$$

The original output is $y(t)=x$'(t). Shifting that output by $t_0$ gives the same expression as the shifted-input output.

$$
y(t-t_0)=x'(t-t_0)
$$

Both tests pass, so the system $y(t)$=dx(t)/dt is LTI. Differentiation changes the waveform, but it still preserves superposition and commutes with time shifts.

<a id="rejecting-lti-classification-when-linearity-fails"></a>
## Rejecting LTI Classification When Linearity Fails

**Example:** Classify the system $y(t)$=[$x(t)$]^2 as linear time-invariant or not by applying both LTI tests.

**Explanation**

The cue is the square on the input value. Write the system operator as T[$x(t)$]=[$x(t)$]^2. Since LTI classification requires both tests to pass, start by checking linearity.

$$
T[x(t)]=[x(t)]^2
$$

A quick way to test linearity is to check whether scaling the input by 2 scales the output by 2. For this system, the square changes the scale factor.

$$
\begin{aligned}
T[2x(t)] &= [2x(t)]^2 \\
&= 4[x(t)]^2 \\
2T[x(t)] &= 2[x(t)]^2
\end{aligned}
$$

These are not the same for a general nonzero input, so the homogeneity part of superposition fails. The system is not linear, which already means it cannot be LTI.

Still check time invariance so the classification is specific. If the input is shifted to $x(t-t_0)$, the system squares that shifted input.

$$
T[x(t-t_0)] = [x(t-t_0)]^2
$$

The original output is $y(t)$=[$x(t)$]^2. Shifting that output by $t_0$ gives the same expression.

$$
y(t-t_0)=[x(t-t_0)]^2
$$

The time-shift test passes, but the linearity test fails. Therefore $y(t)$=[$x(t)$]^2 is not LTI; it is nonlinear but time-invariant.

<a id="rejecting-lti-classification-when-time-invariance-fails"></a>
## Rejecting LTI Classification When Time Invariance Fails

**Example:** Classify the system $y(t)=t$ $x(t)$ as linear time-invariant or not by applying both LTI tests.

**Explanation**

The cue is the explicit time multiplier t. Write the system operator as T[$x(t)$]=t $x(t)$. This rule is still linear in the input $x(t)$, but the explicit t may affect the time-shift test.

$$
T[x(t)]=t x(t)
$$

Start with the superposition test. Feeding in a scaled sum gives the same scaled sum of the separate outputs because the multiplier t distributes over the input combination.

$$
\begin{aligned}
T[a x_1(t)+b x_2(t)] &= t[a x_1(t)+b x_2(t)] \\
&= a[t x_1(t)]+b[t x_2(t)] \\
&= aT[x_1(t)]+bT[x_2(t)]
\end{aligned}
$$

This matches the required superposition form, so the system is linear.

Now test time invariance by comparing two paths. First shift the input to $x(t-t_0)$, then run it through the system.

$$
T[x(t-t_0)] = t x(t-t_0)
$$

For the other path, start from the original output $y(t)=t$ $x(t)$, then shift that output by $t_0$.

$$
y(t-t_0)=(t-t_0)x(t-t_0)
$$

The two expressions are different because one has the multiplier t and the other has t-$t_0$. The system is linear but time-varying, so $y(t)=t$ $x(t)$ is not LTI.

## Deciding Whether the Impulse-Response Framework Applies

**Example:** Decide whether the impulse-response framework applies to the system $y(t)$=$2x(t)$-$x(t-1)$ by classifying the system as LTI or not LTI.

**Explanation**

The system forms the output from a scaled copy of the current input and a scaled delayed copy of the input. Write the operator as T[$x(t)$]=$2x(t)$-$x(t-1)$. To decide whether the impulse-response framework applies, first decide whether the system is LTI.

$$
T[x(t)]=2x(t)-x(t-1)
$$

Check linearity by feeding in a scaled sum a $x_1(t)$+b $x_2(t)$. The system rule distributes through both the current-input term and the delayed-input term.

$$
\begin{aligned}
T[a x_1(t)+b x_2(t)] &= 2[a x_1(t)+b x_2(t)] - [a x_1(t-1)+b x_2(t-1)] \\
&= a[2x_1(t)-x_1(t-1)] + b[2x_2(t)-x_2(t-1)] \\
&= aT[x_1(t)]+bT[x_2(t)]
\end{aligned}
$$

The superposition form holds, so the system is linear. Next check whether a time shift at the input produces the same time shift at the output.

$$
T[x(t-t_0)] = 2x(t-t_0)-x(t-t_0-1)
$$

Now shift the original output $y(t)$=$2x(t)$-$x(t-1)$ by $t_0$. This gives the same expression as the shifted-input path.

$$
y(t-t_0)=2x(t-t_0)-x(t-t_0-1)
$$

Both tests pass, so the system is LTI. Therefore the impulse-response framework applies to this system; the fixed delay term does not block that framework because it preserves both superposition and time shifts.
