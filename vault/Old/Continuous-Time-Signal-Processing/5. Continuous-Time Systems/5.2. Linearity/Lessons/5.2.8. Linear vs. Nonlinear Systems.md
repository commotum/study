## Introduction to Linear vs. Nonlinear Systems

A continuous-time system is an input-output rule, written as $y(t)=T[x(t)]$. For this lesson, classification is an identity-check task: we will test whether the system keeps the right algebra when inputs are added or scaled, rather than trying to guess the answer from the name of the system.

$$
T[x_1+x_2](t) \stackrel{?}{=} T[x_1](t)+T[x_2](t)
$$

The first check is additivity. If a system is linear, then the output for a summed input must match the sum of the separate outputs. We will reuse this check whenever we combine two continuous-time inputs.

$$
T[a x](t) \stackrel{?}{=} a\,T[x](t)
$$

The second check is homogeneity. If we scale the input by a constant $a$, then a linear system must scale the output by the same constant. The simplest symbols to keep in mind are a generic input $x(t)$, a second input $x_2(t)=1$, and a scale factor $a=2$.

$$
T[a_1 x_1 + a_2 x_2](t) = a_1 T[x_1](t)+a_2 T[x_2](t)
$$

These two checks combine into the superposition test, which is the compact rule we will use throughout the lesson. In the next sections, derivative, constant-offset, and squaring systems will each be classified by applying this same symbolic test to their system rules.

## Classifying a Derivative System

**Example:** For $T[x(t)] = \frac{d}{dt}x(t)$, let $x_1(t)=t^2$ and $x_2(t)=\sin t$. Compute $T[x_1+x_2](t)$ and $T[x_1](t)+T[x_2](t)$, then test homogeneity with $a=3$.

**Explanation**

The cue is a derivative rule, so we apply the linearity checks from the introduction to the same operator $T$. Start by forming the summed input $x_1(t)+x_2(t)$, then compare the output of the sum with the sum of the separate outputs.

$$
x_1(t)+x_2(t)=t^2+\sin t
$$

$$
T[x_1+x_2](t)=\frac{d}{dt}\bigl(t^2+\sin t\bigr)=2t+\cos t
$$

$$
T[x_1](t)=\frac{d}{dt}(t^2)=2t,\qquad T[x_2](t)=\frac{d}{dt}(\sin t)=\cos t
$$

$$
T[x_1](t)+T[x_2](t)=2t+\cos t
$$

The two expressions match, so the derivative rule passes additivity for this input pair. Now test homogeneity by scaling the same input by $a=3$ and comparing the result to three times the original output.

$$
T[3x](t)=\frac{d}{dt}\bigl(3x(t)\bigr)=3\frac{d}{dt}x(t)=3x'(t)
$$

$$
3T[x](t)=3x'(t)
$$

The scaled input gives the same scaled output, so homogeneity also holds. Since both additivity and homogeneity pass, the derivative system is linear.

## Classifying a Constant Offset System

**Example:** Classify $T[x(t)] = x(t)+4$ by evaluating $T[0]$ and comparing $T[2x](t)$ with $2T[x](t)$.

**Explanation**

The cue is a constant offset in the system rule, so we check whether the added $4$ survives the linearity tests. Start with the zero-input test, since a linear system must send $0$ to $0$.

$$
T[0](t)=0+4=4
$$

Because $T[0](t)\neq 0$, the rule already fails the linear zero-input requirement. We can confirm the same mismatch with homogeneity by scaling the input by $2$.

$$
T[2x](t)=2x(t)+4
$$

$$
2T[x](t)=2\bigl(x(t)+4\bigr)=2x(t)+8
$$

The two outputs do not match, so homogeneity also fails. The constant offset breaks linearity, and the system is nonlinear.

## Classifying a Squaring System

**Example:** For $T[x(t)] = [x(t)]^2$, test linearity with $x_1(t)=t$ and $x_2(t)=1$, then check scaling with $a=3$ and $x(t)=t+1$.

**Explanation**

The cue is a squaring rule, so we expect the output to be the square of the input. To test linearity, first compare the output of a summed input with the sum of the separate outputs.

$$
x_1(t)+x_2(t)=t+1
$$

$$
T[x_1+x_2](t)=[t+1]^2=t^2+2t+1
$$

$$
T[x_1](t)+T[x_2](t)=[t]^2+[1]^2=t^2+1
$$

These expressions do not match because the square of a sum creates the cross-term $2t$. So additivity fails. Now check homogeneity with a scaled input.

$$
T[3x](t)=[3x(t)]^2=9x^2(t)=9(t+1)^2
$$

$$
3T[x](t)=3[x(t)]^2=3(t+1)^2
$$

The scale factor is squared on the left, so homogeneity fails too. Since the squaring rule breaks both linearity checks, the system is nonlinear.

## Classifying Mixed System Rules

**Example:** For $T[x(t)] = \frac{d}{dt}x(t) + [x(t)]^2$, use $x_1(t)=t$, $x_2(t)=1$, and $a=2$ to test superposition and classify the system.

**Explanation**

The cue is a mixed rule: one derivative term and one squaring term. The derivative part is linear, so the classification will be decided by whether the square term preserves the superposition test.

$$
x_1(t)+x_2(t)=t+1
$$

$$
T[x_1+x_2](t)=\frac{d}{dt}(t+1)+[t+1]^2=1+t^2+2t+1=t^2+2t+2
$$

$$
T[x_1](t)=\frac{d}{dt}(t)+[t]^2=1+t^2,\qquad T[x_2](t)=\frac{d}{dt}(1)+[1]^2=1
$$

$$
T[x_1](t)+T[x_2](t)=t^2+2
$$

The two sides do not match because the squared sum creates the cross-term $2t$. So additivity fails, even though the derivative part itself behaves linearly.

$$
T[2x](t)=\frac{d}{dt}\bigl(2x(t)\bigr)+\bigl[2x(t)\bigr]^2=2+4x^2(t)
$$

$$
2T[x](t)=2\left(\frac{d}{dt}x(t)+[x(t)]^2\right)=2+2x^2(t)
$$

The scale factor is squared in the nonlinear term, so homogeneity fails too. Since one mismatch is enough to reject linearity, the mixed rule is nonlinear.
