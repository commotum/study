## Introduction to Time-Varying Systems with Explicit $t$

To test time invariance, compare the output of the shifted input, $T(x(t-t_0))$, with the shifted version of the original output, $y(t-t_0)$, where $T(x(t))=y(t)$. If those two paths agree for every shift $t_0$, the system is time invariant.

$$
T(x(t)) = y(t) \qquad \text{compare } T(x(t-t_0)) \text{ with } y(t-t_0)
$$

An explicit $t$ in the system rule means the rule depends on absolute time, not just on the input value. In the simplest case, if $T(x(t)) = t \, x(t)$, then shifting the input gives $T(x(t-t_0)) = t \, x(t-t_0)$, while shifting the original output gives $y(t-t_0) = (t-t_0) \, x(t-t_0)$.

$$
T(x(t)) = t\,x(t), \qquad T(x(t-t_0)) = t\,x(t-t_0), \qquad y(t-t_0) = (t-t_0)\,x(t-t_0)
$$

Because $t$ stays tied to the absolute observation time, the two outputs are different in general. That is the key cue: when the system rule contains explicit $t$, the shift test can fail because the output does not move exactly with the input.

## Comparing Paths for a Time-Dependent Multiplier

**Example:** For $T(x(t))=t x(t)$ and input $x(t)$, compare the outputs for the shifted input $x(t-t_0)$ and for the shifted original output $y(t-t_0)$.

**Explanation**

Start from the original rule $T(x(t))=t x(t)$, so the unshifted output is $y(t)=t x(t)$. The shift test compares two paths: first shift the input and then apply the system, or first apply the system and then shift the output.

$$
y(t)=t\,x(t)
$$

If we shift the input first, the rule uses the current time variable $t$ exactly as written, so the output is $T(x(t-t_0))=t x(t-t_0)$. If we shift the original output instead, we replace $t$ by $t-t_0$ everywhere in $y(t)$, which gives $y(t-t_0)=(t-t_0)x(t-t_0)$.

$$
T(x(t-t_0))=t\,x(t-t_0), \qquad y(t-t_0)=(t-t_0)\,x(t-t_0)
$$

The mismatch is in the multiplier: one path keeps $t$, while the other changes it to $t-t_0$. That difference means the output does not shift along with the input, so this explicit-$t$ rule is time varying.

## Comparing Paths for a Time-Dependent Offset

**Example:** For $T(x(t))=x(t)+t$ and input $x(t)$, compare $T(x(t-t_0))$ with $y(t-t_0)$.

**Explanation**

Start from the original rule $T(x(t))=x(t)+t$, so the unshifted output is $y(t)=x(t)+t$. For the shift test, compare the output of the shifted input with the shifted version of the original output.

$$
y(t)=x(t)+t
$$

If we shift the input first, the system rule becomes $T(x(t-t_0))=x(t-t_0)+t$. If we shift the original output instead, we replace $t$ by $t-t_0$ everywhere in $y(t)$, which gives $y(t-t_0)=x(t-t_0)+(t-t_0)$.

$$
T(x(t-t_0))=x(t-t_0)+t, \qquad y(t-t_0)=x(t-t_0)+(t-t_0)
$$

The input term matches on both paths, but the added time term does not. That mismatch is the cue: when the rule contains an explicit $t$ in an offset, the output depends on absolute time, so the system is time varying.

## Tracking Explicit $t$ Through an Input Shift

**Example:** For $T(x(t))=t x(t)+x(t)$ and input $x(t)$, compare $T(x(t-t_0))$ with $y(t-t_0)$.

**Explanation**

Start from the original rule $T(x(t))=t x(t)+x(t)$, so the unshifted output is $y(t)=t x(t)+x(t)$. For the shift test, compare the output of the shifted input with the shifted version of the original output, term by term.

$$
y(t)=t\,x(t)+x(t)
$$

If we shift the input first, the rule still uses absolute time $t$ in the multiplier, so $T(x(t-t_0))=t x(t-t_0)+x(t-t_0)$. If we shift the original output instead, we replace every $x(t)$ by $x(t-t_0)$ and every free $t$ by $t-t_0$, which gives $y(t-t_0)=(t-t_0)x(t-t_0)+x(t-t_0)$.

$$
T(x(t-t_0))=t\,x(t-t_0)+x(t-t_0), \qquad y(t-t_0)=(t-t_0)\,x(t-t_0)+x(t-t_0)
$$

The input term $x(t-t_0)$ matches on both paths, but the multiplier changes from $t$ to $t-t_0$. That mismatch is the cue that the rule depends on absolute time, so the system is time varying.

## Classifying Explicit-$t$ System Rules as Time Varying

**Example:** For $T(x(t))=t x(t)+2x(t)$ and input $x(t)$, compare the two shift paths and decide whether the system is time varying.

**Explanation**

Start from the original rule $T(x(t))=t x(t)+2x(t)$, so the unshifted output is $y(t)=t x(t)+2x(t)$. To classify the rule, compare the shifted-input path with the shifted-output path and check whether the expressions match.

$$
y(t)=t\,x(t)+2x(t)
$$

If we shift the input first, the system rule gives $T(x(t-t_0))=t x(t-t_0)+2x(t-t_0)$. If we shift the original output instead, we replace every $x(t)$ by $x(t-t_0)$ and every free $t$ by $t-t_0$, so $y(t-t_0)=(t-t_0)x(t-t_0)+2x(t-t_0)$.

$$
T(x(t-t_0))=t\,x(t-t_0)+2x(t-t_0), \qquad y(t-t_0)=(t-t_0)\,x(t-t_0)+2x(t-t_0)
$$

The $2x(t)$ term shifts cleanly, but the multiplier changes from $t$ to $t-t_0$. Because the two paths are not the same, the rule is time varying.
