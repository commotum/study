## Introduction to Systems as Signal Transformations

In this course, $x(t)$ names an input signal and $y(t)$ names the corresponding output signal. A continuous-time system is the rule that takes one signal in and produces the other signal out.

$$
y(t)=T\{x(t)\}
$$

Read $T\{\cdot\}$ as the system itself. The input signal enters the rule, the rule acts on it, and the output signal comes out. The system is the transformation, not the signal.

$$
y(t)=x(t)
$$

In the identity transformation, the output is exactly the input. This is the simplest case: the system still has an input-to-output structure, but it leaves the signal unchanged.

$$
y(t)=2x(t)
$$

In a scaled transformation, the same input-output structure remains, but the rule changes the input by a fixed factor. Later sections will keep this same view and use it to interpret filters, circuits, differential-equation models, and system-property tests.

## Distinguishing a Signal from a System

**Example:** Given $y(t)=\dfrac{d}{dt}x(t)+2x(t)$, identify the input signal, output signal, and system mapping.

**Explanation**

The cue is the equation $y(t)=\dfrac{d}{dt}x(t)+2x(t)$. The left-hand side tells us the output signal, and the expression on the right tells us the system rule that transforms the input.

$$
y(t)=\dfrac{d}{dt}x(t)+2x(t)
$$

Here $x(t)$ is the input signal, because it is the signal being acted on. The output signal is $y(t)$, because it is the signal produced after the rule acts.

$$
y(t)=T\{x(t)\}
$$

So the system is the operator $T\{\cdot\}$ defined by $T\{x(t)\}=\dfrac{d}{dt}x(t)+2x(t)$. The transformation is the whole rule, not either signal by itself.

## Applying a Simple System Rule to a Signal

**Example:** Apply $y(t)=x(t-1)$ to $x(t)=u(t)-u(t-2)$ and simplify the output expression.

**Explanation**

The cue is the system rule $y(t)=x(t-1)$. That rule says to keep the same input signal form and replace every $t$ inside $x(t)$ with $t-1$.

$$
y(t)=x(t-1)
$$

Here the input signal is $x(t)=u(t)-u(t-2)$. Apply the same shift to each term: $u(t)$ becomes $u(t-1)$ and $u(t-2)$ becomes $u(t-3)$.

$$
x(t)=u(t)-u(t-2)
$$

So the output is $y(t)=u(t-1)-u(t-3)$. The system rule stayed fixed; only the input was transformed by the same shift everywhere it appeared.

$$
y(t)=u(t-1)-u(t-3)
$$

<a id="recognizing-the-same-system-rule-across-different-inputs"></a>
## Recognizing the Same System Rule Across Different Inputs

**Example:** Given $x_1(t)=t$, $x_2(t)=e^{-t}$, and $x_3(t)=\sin t$, show how all three follow the same rule $y(t)=x(t-1)+x(t+1)$ and compute one output form.

**Explanation**

The cue is the same fixed system rule $y(t)=x(t-1)+x(t+1)$. The input changes from one signal to the next, but the rule stays exactly the same.

$$
y(t)=x(t-1)+x(t+1)
$$

For $x_1(t)=t$, substitute $t-1$ and $t+1$ into the same rule. That gives $y_1(t)=x_1(t-1)+x_1(t+1)=(t-1)+(t+1)=2t$.

$$
\begin{aligned}
y_1(t) &= x_1(t-1)+x_1(t+1) \\
&= (t-1)+(t+1) \\
&= 2t
\end{aligned}
$$

For $x_2(t)=e^{-t}$, the same substitution pattern gives $y_2(t)=x_2(t-1)+x_2(t+1)=e^{-(t-1)}+e^{-(t+1)}$. For $x_3(t)=\sin t$, the output follows the same rule: $y_3(t)=\sin(t-1)+\sin(t+1)$.

$$
\begin{aligned}
y_2(t) &= e^{-(t-1)}+e^{-(t+1)} \\
y_3(t) &= \sin(t-1)+\sin(t+1)
\end{aligned}
$$

The important point is that the system rule does not change when the input changes. Each new signal is processed by the same transformation, so the system is recognized by its rule, not by one particular input.
