## Introduction to Bounded Signals

A continuous-time signal is **bounded** when its magnitude stays below one finite ceiling for all time. In this topic, boundedness is the first check you use before BIBO stability reasoning: if a signal never grows beyond a finite limit, then its size is controlled in the way later system arguments need.

$$
\exists M \in \mathbb{R}_{>0}: |x(t)| \le M,\; \forall t \in \mathbb{R}
$$

That is the exact condition to recognize: there must exist some finite $M > 0$ that works for every time $t$. The bound does not have to be the smallest possible number; it only has to be finite and valid everywhere the signal is defined.

$$
|x(t)| \le M \Rightarrow x(t) \text{ is bounded.}
$$

For the constant signal $x(t)=3$, one valid bound is $M=3$, because $|x(t)|=3$ for every $t$. By contrast, $x(t)=t$ is not bounded, because no single finite ceiling can contain $|t|$ as time grows without limit.

So the base rule is simple: look for one finite magnitude limit that works at all times. Later examples will add wrinkles, but they still use this same criterion.

## Finding a Magnitude Bound from a Simple Formula

**Example:** Determine whether $x(t)=3+4\sin(t)$ is bounded and give a bound $M$.

**Explanation**

The cue is that $x(t)$ is a constant term plus a sinusoid, so the cleanest move is to bound each piece separately. The constant $3$ is already finite, and $\sin(t)$ has a known magnitude envelope over all time.

$$
|\sin(t)| \le 1
$$

That envelope gives $|4\sin(t)| \le 4$. Now combine the constant and variable parts with the triangle inequality: $|x(t)| = |3+4\sin(t)| \le |3| + |4\sin(t)| \le 3+4$.

$$
|x(t)| \le 7
$$

So one valid magnitude bound is $M=7$, which means $x(t)$ is bounded. The key pattern is to separate the formula into bounded pieces, then combine their envelopes into one finite global bound.

## Finding a Magnitude Bound for Sinusoidal Signals

**Example:** Find a finite bound for $x(t)=2\sin(4t)+3\cos(2t+\pi/6)$.

**Explanation**

The cue is a sum of sinusoidal terms, so the right move is to bound each term with its own global envelope. A phase shift such as $2t+\pi/6$ changes where the wave sits in time, but it does not change the fact that a sine or cosine always stays between $-1$ and $1$.

$$
|a\sin(\omega t+\phi)| \le |a|
$$

So $|2\sin(4t)| \le 2$ and $|3\cos(2t+\pi/6)| \le 3$. Now combine the two envelopes with the triangle inequality:

$$
|x(t)| = |2\sin(4t)+3\cos(2t+\pi/6)| \le |2\sin(4t)|+|3\cos(2t+\pi/6)| \le 2+3=5
$$

Therefore one valid magnitude bound is $M=5$, so $x(t)$ is bounded. The pattern is the same as before: identify the envelope of each bounded piece, then add those envelopes to get one finite global bound.

## Checking Boundedness from a Signal Graph

**Example:** Use the displayed graph to decide whether $x(t)$ is bounded. Explain by referencing long-run growth behavior and envelope candidates.

**Explanation**

The cue is a signal graph, so the first job is to look for a finite vertical envelope that contains the whole curve for every time. If the peaks and troughs stay within fixed levels and the graph does not drift upward or downward without limit, the signal is bounded.

![](<../Source/5.4.1. Bounded Signals/Images/l001-s004-te-section-004.png>)

Here the curve stays between $-2$ and $2$ for all shown time, so one finite magnitude limit is immediately visible. There is no long-run growth, so the same envelope works everywhere on the graph.

$$
|x(t)| \le 2
$$

So the graph represents a bounded signal, and a valid bound is $M=2$. The decision rule is the same one used in the symbolic examples: find one finite magnitude ceiling that holds for all $t$.

## Recognizing Unbounded Growth Over All Time

**Example:** Assess boundedness of $x(t)=t^2 + 3e^{-t}$.

**Explanation**

The cue is a mixed signal: one term is a polynomial growth term and the other is an exponential term. To decide boundedness, check whether either term forces the magnitude to grow without a finite ceiling over all $t$.

$$
\text{For } t\ge 0,\; 3e^{-t}>0 \text{ so } x(t)=t^2+3e^{-t}\ge t^2.
$$

Because $t^2$ grows without bound, no finite $M$ can satisfy $|x(t)|\le M$ for all $t$. The positive exponential term does not change that conclusion, so $x(t)$ is unbounded.

## Classifying Candidate Inputs as Bounded or Unbounded

**Example:** Classify each of the following candidates: $x_1(t)=\cos(5t)$, $x_2(t)=\frac{t+1}{t}$, $x_3(t)=2e^{-t}$.

**Explanation**

Use the same checkpoint for each signal: first look for an obvious global envelope, then look for singular behavior or one-sided growth that breaks any finite bound.

$$
|x_1(t)|=|\cos(5t)|\le 1
$$

$x_1(t)$ is bounded because its magnitude never exceeds $1$.

$$
x_2(t)=\frac{t+1}{t}=1+\frac{1}{t}
$$

$x_2(t)$ is unbounded because it blows up near $t=0$, so no finite magnitude limit exists over all time.

$$
|x_3(t)|=2e^{-t}\to\infty \quad \text{as } t\to-\infty
$$

$x_3(t)$ is unbounded because it grows without limit in the negative-time direction. Final classification: $x_1$ bounded, $x_2$ unbounded, $x_3$ unbounded.
