## Introduction to Bounded Inputs with Unbounded Outputs

A continuous-time system is BIBO stable only if every bounded input produces a bounded output. For this lesson, the key test is simple: one bounded input and one output with no finite bound are enough to reject BIBO stability.

$$
|x(t)| \le M_x
$$

Here, a bounded input means that some finite constant $M_x$ exists with $|x(t)| \le M_x$ for all $t$. A bounded output would require the same kind of finite constant $M_y$ with $|y(t)| \le M_y$ for all $t$.

$$
|y(t)| \le M_y
$$

So the counterexample pattern is enough on its own: show one bounded input, trace it through the system rule, and then show that the resulting output has no finite bound. A simplest base case is a bounded input like $x(t)=1$ paired with an output like $y(t)=t$, which grows without bound.

$$
x(t)=1 \qquad \text{and} \qquad y(t)=t
$$

In the next step, the lesson will keep this same logic but apply it to a specific system rule: first check that the chosen input is bounded, then trace it through the rule, and finally prove that the output cannot be bounded by any finite constant.

## Checking That the Test Input Is Bounded

**Example:** Verify that the test input $x(t)=1$ is bounded for all real $t$.

**Explanation**

The cue is the constant test input $x(t)=1$. To show that it is bounded, use the definition from the introduction: find one finite constant $M$ such that $|x(t)| \le M$ for every $t$.

$$
x(t)=1
$$

Taking the absolute value gives $|x(t)|=|1|=1$ for every $t$. So the same finite bound works everywhere, and the simplest choice is $M=1$.

$$
|x(t)|=1 \le 1
$$

Therefore the test input is bounded. That lets the lesson keep the same input in the next step and focus on the system rule and the output bound instead of rechecking the input.

<a id="tracing-a-bounded-input-through-the-system-rule"></a>
## Tracing a Bounded Input Through the System Rule

**Example:** For the system $y(t)=t x(t)$ and the bounded input $x(t)=1$, compute the output $y(t)$.

**Explanation**

The cue is the same bounded input from the previous step, $x(t)=1$. Now apply the system rule directly: substitute that input into $y(t)=t x(t)$ and simplify the result.

$$
\begin{aligned}
y(t) &= t x(t) \\
&= t(1) \\
&= t
\end{aligned}
$$

So the bounded input produces the output $y(t)=t$. This is the simplified expression the next step will use to show that the output has no finite bound.

```quiz
correct: |-
  $y(t)=2t$

feedback: |-
  Substitute the input into the system rule: $y(t)=2t\,x(t)=2t(1)$. Then simplify, which gives $y(t)=2t$.
```

<a id="showing-that-the-output-has-no-finite-bound"></a>
## Showing That the Output Has No Finite Bound

**Example:** Show that the output $y(t)=t$ has no finite bound.

**Explanation**

The cue is the simplified output $y(t)=t$ from the previous step. To show that it has no finite bound, test an arbitrary finite constant $M$ and check whether it can satisfy $|y(t)| \le M$ for all $t$.

$$
\begin{aligned}
|y(M+1)| &= |M+1| \\
&= M+1
\end{aligned}
$$

Because $M+1 > M$, this candidate bound fails. Since $M$ was arbitrary, no finite constant can dominate $|y(t)|$ for every $t$, so the output is unbounded.

**Question 5:**

```quiz
type: free
id: EE01-M05-04-L07-q005
content: |-
  Show that $y(t)=2t+3$ has no finite bound. Assume a finite constant $M>0$ and test whether $|y(t)|\le M$ can hold for every $t$.

  Evaluate the output at $t=M+1$.

  $$
  |y(M+1)|=|2(M+1)+3|=|2M+5|=2M+5
  $$

  Since $2M+5>M$ for every $M>0$, this output value already exceeds any assumed finite bound. Conclude that no global finite bound exists.

correct: |-
  $y(t)=2t+3$ is unbounded because for any finite $M>0$, choosing $t=M+1$ gives $|y(M+1)|=2M+5>M$.

feedback: |-
  The unboundedness test is unchanged from the worked example: assume one finite $M$, then find one time $t$ that breaks $|y(t)|\le M$. Since this can be done for arbitrary $M$, no finite $M$ works for all time.
```

**Question 6:**

```quiz
type: free
id: EE01-M05-04-L07-q006
content: |-
  Show that $y(t)=1-t$ has no finite bound. Use a fixed finite $M>0$ and construct one time where the bound $|y(t)|\le M$ fails.

  Choose a time that makes the magnitude grow past $M$.

  $$
  t = -M-2 \\ \Rightarrow y(-M-2)=1-(-M-2)=M+3 \\ |y(-M-2)|=M+3
  $$

  Because $M+3>M$, the candidate bound is violated. Therefore no universal finite bound exists for $y(t)$.

correct: |-
  $y(t)=1-t$ is unbounded. For arbitrary $M>0$, take $t=-M-2$ so $|y(-M-2)|=|M+3|=M+3>M$, contradicting any supposed global bound.

feedback: |-
  This is the same proof structure as the anchor example: substitute a specific time into the output and show the absolute value can exceed $M$. Any output with unbounded linear growth fails boundedness in this way.
```

<a id="disproving-bibo-stability-from-one-counterexample"></a>
## Disproving BIBO Stability from One Counterexample

**Example:** Use the bounded input $x(t)=1$ and the unbounded output $y(t)=t$ to decide whether the system is BIBO stable.

**Explanation**

The cue is the counterexample pair from the previous steps: the input $x(t)=1$ is bounded, and the output $y(t)=t$ has no finite bound. The BIBO rule says that a stable system must send every bounded input to a bounded output.

$$
\begin{aligned}
x(t)=1 &\quad \text{is bounded} \\
y(t)=t &\quad \text{is unbounded}
\end{aligned}
$$

Because one bounded input produced one unbounded output, the system fails the BIBO test. So the correct conclusion is that the system is not BIBO stable.

```quiz
    The BIBO rule requires every bounded input to map to a bounded output. Here $x(t)=2$ is bounded and $|2t|$ has no finite global bound, so one counterexample is enough to fail BIBO stability.
```
