## Introduction to Stability Classification from Examples

The cue for this lesson is a continuous-time system example where you can inspect what happens to the output without solving the whole system. Start from the control case: a bounded input that produces a clearly bounded output. That is the behavior you want to recognize as BIBO stable before you look for failures.

$$
\forall x(t): |x(t)| \le M_x \implies \forall t: |y(t)| \le M_y \text{ (stable)}
$$

If you can point to a bounded input that forces the output to grow without bound, classify the system as unstable. The lesson will use one fixed decision path for every example: first check whether the output stays bounded, then look for growth, then inspect whether the response is too weakly damped, and finally check whether accumulation is building up over time.

$$
\forall M > 0,\ \exists t_0 \text{ such that } |y(t_0)| > M \text{ indicates unbounded output}
$$

The recurring instability signatures in this topic are persistent growth, inadequate damping, and integrator accumulation. A bounded input can still produce an unbounded output through accumulation, so keep that mechanism in view even when the input itself looks harmless.

$$
y_{\text{integrator}}(t)=\int_0^t x(\tau)\,d\tau
$$

Use the same scan order every time: bounded-output evidence first, then growth, then damping, then accumulation. That keeps the classification decision consistent and gives later examples a stable vocabulary to reuse.

## Classifying Systems with Directly Bounded Outputs

**Example:** Classify stability for $y(t)=0.5\,\arctan(x(t))$ with bounded input $x(t)=\cos(2t)$.

**Explanation**

The cue is a bounded input passed through a static nonlinearity. Here, $x(t)=\cos(2t)$ is bounded for all $t$, so this is the control style of example where the output can be checked directly from the formula.

$$
|x(t)|=|\cos(2t)|\le 1
$$

Now use the output rule itself. Because $|\arctan(u)| \le \pi/2$ for every real $u$, the output is globally bounded no matter which bounded value $x(t)$ takes.

$$
|y(t)|=\left|0.5\,\arctan(x(t))\right|\le 0.5\cdot \frac{\pi}{2}=\frac{\pi}{4}
$$

That explicit finite bound means the system is BIBO stable. The reason is directly bounded output: the output stays under a fixed limit for every time $t$, so this example belongs in the stable class.

## Classifying Systems with Growing Outputs

**Example:** Classify whether $y(t)=e^{t}x(t)$ is stable for bounded input $x(t)=\sin t$.

**Explanation**

The cue is a bounded input multiplied by an explicit growth factor. Here, $x(t)=\sin t$ is bounded, so the only new issue is whether the factor $e^t$ forces the output to leave every finite bound.

$$
|x(t)|=|\sin t|\le 1
$$

Now write the output magnitude directly. The bounded input stays bounded, but the exponential multiplier keeps increasing, so the output magnitude grows without bound as $t$ increases.

$$
|y(t)|=|e^t x(t)|=e^t|x(t)|=e^t|\sin t|
$$

At times where $|\sin t|=1$, the magnitude matches the exponential factor, so it can become arbitrarily large. That is enough to classify the system as unstable.

$$
\forall M>0,\ \exists n \text{ such that } |y(\pi/2+2\pi n)|=e^{\pi/2+2\pi n}>M
$$

The reason label is output growth: the input is bounded, but the exponential factor makes the output unbounded. Keep that distinction explicit, because later examples will separate growth from damping and accumulation.

## Classifying Integrator-Type Accumulation

**Example:** Classify the system $y(t)=\int_0^t x(\tau)\,d\tau$ under bounded input $x(t)=1$ for all $t$.

**Explanation**

The cue is an accumulator: the output at time $t$ is the running integral of the input. The input $x(t)=1$ is bounded, so this is a valid BIBO test case.

$$
|x(t)| = |1| = 1
$$

Now evaluate the accumulated response directly. Integrating a constant input makes the output grow linearly with time, so the output does not stay within one fixed bound.

$$
y(t)=\int_0^t 1\,d\tau = t
$$

Because $|y(t)|=t$ grows without limit as $t$ increases, there is no finite uniform bound on the output. One bounded-input counterexample is enough to classify the system as unstable.

$$
\forall M>0,\ \exists t>M \text{ such that } |y(t)|=t>M
$$

The classification is unstable, and the mechanism label is integrator accumulation.

## Classifying Damped Physical Responses

**Example:** Determine stability of $y(t)=e^{-3t}x(t)$ for bounded $x(t)$.

**Explanation**

The cue is exponential decay, so this is a damping-dominated response rather than growth or accumulation. Start from the bounded-input condition $|x(t)|\le M_x$.

$$
|x(t)|\le M_x
$$

For the causal response with $t\ge 0$, the factor $e^{-3t}$ never exceeds $1$ and only shrinks with time. That gives an explicit global bound on the output.

$$
0\le e^{-3t}\le 1\quad (t\ge 0),\qquad |y(t)|=|e^{-3t}x(t)|\le |x(t)|\le M_x
$$

Because the output stays bounded for every bounded input, the system is stable. The reason label is damping-dominated physical response.

<a id="choosing-the-stability-reason-in-mixed-examples"></a>
## Choosing the Stability Reason in Mixed Examples

**Example:** Classify $y(t)=e^{-2t}x(t)+\int_0^t e^{-\tau}x(t-\tau)\,d\tau$ for bounded input $x(t)=\sin t$.

**Explanation**

The cue is mixed: one term is directly damped, and the other is an accumulation term with a decaying kernel. Start with the bounded input, $x(t)=\sin t$, so $|x(t)|\le 1$.

$$
|x(t)|\le 1
$$

Bound each contribution separately. The direct term cannot grow because of the factor $e^{-2t}$, and the integral term is controlled by the same exponential decay inside the kernel.

$$
\begin{aligned}
|y(t)| &\le e^{-2t}|x(t)| + \int_0^t e^{-\tau}|x(t-\tau)|\,d\tau \\
&\le 1 + \int_0^t e^{-\tau}\,d\tau \\
&\le 2
\end{aligned}
$$

The output stays bounded, so the system is stable. The single strongest reason is damping, because the decay terms prevent both growth and unbounded accumulation.
