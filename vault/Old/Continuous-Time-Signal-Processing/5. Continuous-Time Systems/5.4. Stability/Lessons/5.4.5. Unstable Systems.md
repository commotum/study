## Introduction to Unstable Systems

A continuous-time system is unstable when it fails the bounded-input bounded-output criterion: there exists a bounded input that produces an output with no finite bound. The cue is simple - if the input stays bounded but the output can still grow without limit, the system is unstable.

$$
|x(t)| \le M \text{ for all } t
$$

A bounded input stays inside some finite ceiling $M$, and a bounded output would stay inside some finite ceiling $N$. Instability appears when you can name a bounded input but cannot find any finite bound on the corresponding output.

$$
\exists\,x(t) \text{ bounded such that } \sup_t |y(t)| = \infty
$$

Start with the simplest failure case: $x(t)=\sin t$ is bounded, but $y(t)=t\sin t$ is not, because its envelope grows like $|t|$. The input remains under control while the output grows without bound, so the system is unstable.

The growth can come from insufficient damping or from reinforcing dynamics, but the first test is always the same: decide whether the output stays bounded for bounded input. Later examples will separate true divergence from merely large but finite behavior.

Keep the classification rule fixed: bounded input plus unbounded output means instability. That is the definition the next examples will keep reusing.

## Recognizing Unbounded Output Growth

**Example:** A bounded input $x(t)=\sin t$ produces output $y(t)=t\sin t$. Decide whether the output is bounded or unbounded and state what that means for the system.

**Explanation**

The cue is the bounded input: $x(t)=\sin t$ stays between $-1$ and $1$, so it is bounded.

$$
x(t)=\sin t
$$

Now inspect the output $y(t)=t\sin t$. The sinusoid still oscillates, but the factor $t$ makes the envelope grow without bound as $t$ increases.

$$
y(t)=t\sin t
$$

Because no finite $N$ can bound $|y(t)|$ for all $t$, the output is unbounded. A bounded input has produced an unbounded output, so the system fails BIBO stability and is unstable.

$$
\sup_t |y(t)| = \infty
$$

## Distinguishing Large Bounded Outputs from Unbounded Outputs

**Example:** A bounded input $x(t)=\cos t$ produces output $y(t)=10\sin t$. Decide whether the output is merely large or actually unbounded.

**Explanation**

The cue is still a bounded input: $x(t)=\cos t$ stays between $-1$ and $1$, so the input is bounded.

$$
x(t)=\cos t
$$

Now inspect the output $y(t)=10\sin t$. The amplitude is large, but the factor $10$ is fixed, so the envelope does not grow with $t$.

$$
y(t)=10\sin t
$$

Because the output stays within a finite bound, it is bounded rather than unbounded. This behavior does not make the system unstable, because size alone is not the BIBO test; the envelope must grow without bound to fail stability.

$$
\sup_t |y(t)| < \infty
$$

## Identifying Instability from Insufficient Damping

**Example:** A bounded input $x(t)=\sin t$ produces output $y(t)=e^{0.2t}\sin t$. Decide whether the system is unstable and explain why the damping interpretation matters.

**Explanation**

The cue is the bounded input: $x(t)=\sin t$ stays between $-1$ and $1$, so the input is bounded.

$$
x(t)=\sin t
$$

Now inspect the output $y(t)=e^{0.2t}\sin t$. The sine term still oscillates, but the envelope is $e^{0.2t}$, and that factor grows with $t$ instead of decaying. That is the sign of insufficient damping.

$$
y(t)=e^{0.2t}\sin t
$$

Because the envelope keeps increasing, no finite $N$ can bound $|y(t)|$ for all $t$. The response is unbounded, so a bounded input has produced an unbounded output and the system fails BIBO stability.

$$
\sup_t |y(t)| = \infty
$$

## Identifying Instability from Reinforcing Dynamics

**Example:** A bounded input $x(t)=u(t)$ passes through a system with output $y(t)=\int_0^t x(\tau)\,d\tau$. Decide whether the output stays bounded or grows without bound.

**Explanation**

The cue is the bounded input $x(t)=u(t)$. It stays at $0$ or $1$, so the input is bounded.

$$
x(t)=u(t)
$$

The output is an accumulated response, $y(t)=\int_0^t x(\tau)\,d\tau$. For this input, the system keeps adding positive area, so the response grows instead of settling.

$$
y(t)=\int_0^t x(\tau)\,d\tau
$$

Substituting the bounded input gives $y(t)=\int_0^t 1\,d\tau=t$ for $t\ge 0$, or equivalently $y(t)=t\,u(t)$. That is a ramp with no finite upper bound, so the output is unbounded because of reinforcing dynamics.

$$
y(t)=t\,u(t)
$$

Since a bounded input produced an unbounded output, the system fails BIBO stability and is unstable. The cause here is reinforcing accumulation: each new bit of input adds more output instead of being damped away.

<a id="classifying-an-unstable-system-from-input-output-behavior"></a>
## Classifying an Unstable System from Input-Output Behavior

**Example:** A bounded input produces $y(t)=t\cos t + 3\sin t$. Classify the system and name the term that makes the output unbounded.

**Explanation**

The cue is the mixed response $y(t)=t\cos t + 3\sin t$ coming from a bounded input. The question is not whether part of the output is bounded; it is whether the full output has a finite bound.

$$
y(t)=t\cos t + 3\sin t
$$

Split the response into two terms. The $3\sin t$ term is bounded, but the $t\cos t$ term has an envelope that grows like $|t|$, so it has no finite upper bound.

$$
\sup_t |t\cos t| = \infty
$$

Because the unbounded term dominates the bounded add-on, the whole output is unbounded. A bounded input has produced an unbounded output, so the system is unstable by the BIBO criterion.

$$
\sup_t |y(t)| = \infty
$$
