## Introduction to Initial Conditions in Laplace Transforms

Use the one-sided (causal) Laplace setup from this module: $\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty}x(t)e^{-st}\,dt$. The key object is the one-sided first-derivative move, which is the only rule that carries initial value data into the $s$-domain.

Define the boundary term directly as the left-hand limit, $x(0^-)=\lim_{t\to0^-}x(t)$. This value captures pre-origin behavior, which is what the one-sided derivative integral is sensitive to at the lower limit.

$$
\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)
$$

Use the base case with a known pre-initial value: if $x(0^-)=c$, then substitute directly into $\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)$ to get $\mathcal{L}\{x'(t)\}=sX(s)-c$. Keep the subtraction order exactly as written so the sign is correct.

Do not use $x(0^+)$ here. $x(0^+)$ is the first post-origin value and is not the boundary term in the one-sided derivative theorem; substituting it can shift the entire transformed equation by the wrong side-state information.

$$
x(0^-)=\lim_{t\to 0^-}x(t)
$$

Next examples will apply this same template in one step: first direct substitution, then zero initial-value checks, then explicit pre- vs post-origin comparison, and finally carrying the corrected term through an $s$-domain equation.

## Substituting a Given Initial Value into the First-Derivative Property

**Example:** Given $\mathcal{L}\{x(t)\}=\frac{3}{s+1}$ and $x(0^-)=2$, find $\mathcal{L}\{x'(t)\}$.

**Explanation**

The cue is that both $X(s)$ and the pre-initial value are already provided, so this is a direct substitution step using the one-sided first-derivative identity from the prior tutorial.

$$
\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)
$$

Write the identity in symbolic form first, then replace $X(s)$ and $x(0^-)$ with the given values.

$$
\mathcal{L}\{x'(t)\}=s\left(\frac{3}{s+1}\right)-2
$$

So the transformed result is $\mathcal{L}\{x'(t)\}=\frac{3s}{s+1}-2$. The same subtraction term structure is now visible and reusable for later steps.

## Handling Zero Initial Conditions in the First-Derivative Property

**Example:** Given $\mathcal{L}\{x(t)\}=\frac{5}{s^2+9}$ and $x(0^-)=0$, compute $\mathcal{L}\{x'(t)\}$.

**Explanation**

The cue is that the first-derivative rule is known and the pre-initial value is explicitly zero, so this is the boundary-term simplification branch.

$$
\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)
$$

Substitute the given initial condition into the formula: $x(0^-)=0$.

$$
\mathcal{L}\{x'(t)\}=sX(s)-0 = sX(s)
$$

Now insert the provided transform $X(s)=\frac{5}{s^2+9}$.

$$
\mathcal{L}\{x'(t)\}=s\left(\frac{5}{s^2+9}\right)
$$

So the transformed derivative is $\mathcal{L}\{x'(t)\}=\frac{5s}{s^2+9}$, which confirms the zero-initial-condition branch collapses to the core multiplication-by-$s$ form.

## Distinguishing Pre-Initial Values from Values After the Origin

**Example:** Suppose $x(0^-)= -1$ and $x(0^+)=3$ with $\mathcal{L}\{x(t)\}=\frac{2s+1}{s^2+4}$. Find $\mathcal{L}\{x'(t)\}$.

**Explanation**

This example is the notation-discrimination case: both a pre-origin and post-origin value are shown, but only the first one belongs in the derivative boundary term.

$$
\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)
$$

Use the one-sided derivative identity with $x(0^-)$ explicitly; the value $x(0^+)=3$ is a separate post-origin point and is not substituted here.

$$
\mathcal{L}\{x'(t)\}=s\left(\frac{2s+1}{s^2+4}\right)-(-1)
$$

Replace the negative pre-initial value carefully: subtracting $x(0^-)= -1$ adds one.

$$
\mathcal{L}\{x'(t)\}=\frac{2s^2+s}{s^2+4}+1
$$

So the result is $\mathcal{L}\{x'(t)\}=s\left(\frac{2s+1}{s^2+4}\right)+1$, showing only the pre-initial value drives the additive boundary term.

<a id="carrying-initial-conditions-into-an-s-domain-equation"></a>
## Carrying Initial Conditions into an s-Domain Equation

**Example:** Transform $x'(t)+3x(t)=e^{-2t}$ with $x(0^-)=1$ and write the resulting algebraic equation in $s$.

**Explanation**

This is the full-equation transfer step: we now carry the initial condition through each transformed term of a differential equation, not just a single transform lookup.

$$
\mathcal{L}\{x'(t)\}+3\mathcal{L}\{x(t)\}=\mathcal{L}\{e^{-2t}\}
$$

Use the one-sided derivative rule and the known transform $\mathcal{L}\{x(t)\}=X(s)$ with $\mathcal{L}\{e^{-2t}\}=\frac{1}{s+2}$.

$$
sX(s)-x(0^-)+3X(s)=\frac{1}{s+2}
$$

Insert the pre-initial value explicitly from the cue: $x(0^-)=1$.

$$
sX(s)-1+3X(s)=\frac{1}{s+2}
$$

Collect $X(s)$ terms to get the transfer-ready form: $\left(s+3\right)X(s)-1=\frac{1}{s+2}$, or equivalently $X(s)=\frac{\frac{1}{s+2}+1}{s+3}$.
