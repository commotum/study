## Introduction to Delayed Signals with Unit Steps

The object to recognize is a delayed activation signal. A delayed waveform is turned on through a shifted unit-step gate, so $u(t-a)$ means the same base behavior is present only for $t \ge a$ and is delayed by $a$ units from the origin.

To keep the move stable, define local time as $\tau = t-a$. This is a time-origin shift for that expression: you do not replace the symbol $t$ by a constant, you rewrite delayed content in the shifted local coordinate so the base term and the gate share the same offset.

Use the canonical target form only when it is exact: $x(t)=f(t-a)u(t-a)$. Before applying time-shifting, verify that the same delay $a$ appears in both the local argument and the unit-step gate. If this synchronization is missing, rewrite before transforming.

$$
x(t)=f(t-a)u(t-a)\Rightarrow X(s)=e^{-as}F(s),\quad a \ge 0
$$

Use the base case $x(t)=u(t-a)$ to lock the pattern: the delayed base term is $f(t)=1$ and the only shifted part is the gate, so extract the shared delay $a$ and keep the representation in one form only, ready to map to $e^{-as}$ in the Laplace domain.

$$
\tau=t-a
$$

## Identifying the Delay and Local Time

**Example:** Find the delay and local-time variable for $x(t)=(t-3)^2u(t-3)$.

**Explanation**

Read the unit-step gate first: in $x(t)=(t-3)^2u(t-3)$, the gate is $u(t-3)$, so the activation delay is $a=3$. The same delay value must be the one used to anchor the local-time rewrite.

Set local time to $\tau=t-3$, so $t=\tau+3$. This is the local variable the base term should be written in.

$$
\tau=t-3 \Rightarrow t=\tau+3
$$

Now rewrite the base factor using this local coordinate: $(t-3)^2=(\tau)^2$, so the delayed canonical form is $x(t)=g(t-3)u(t-3)$ with $g(\tau)=\tau^2$.

$$
x(t)=g(t-3)u(t-3),\quad g(\tau)=\tau^2
$$

Result to check: the same delay appears in both parts, $a=3$ and $\tau=t-3$, so this is a valid synchronized delayed form ready for one-sided Laplace time-shifting.

## Writing a Delayed Base Signal as $f(t-a)u(t-a)$

**Example:** Rewrite $x(t)=(t+4)u(t-4)$ as $f(t-4)u(t-4)$ and state $f(\cdot)$ explicitly.

**Explanation**

The cue is the unit-step gate: in $x(t)=(t+4)u(t-4)$, the delayed activation is exactly $u(t-4)$, so the delay is $a=4$. The canonical delayed form must keep that same $a$ in the local anchor.

Define local time once: $\tau=t-4$, so $t=\tau+4$. The base expression is rewritten in terms of $\tau$, because the delayed form is expressed around the local variable that tracks the switched-on segment.

$$
\tau=t-4 \Rightarrow t=\tau+4
$$

Substitute into the base term: $(t+4)=(\tau+4)+4=\tau+8$. Because the signal is delayed by $4$, this is written as $g(\tau)=\tau+8$ inside $x(t)=g(t-4)u(t-4)$.

$$
x(t)=g(t-4)u(t-4),\quad g(\tau)=\tau+8
$$

Consistency check: $g(t-4)= (t-4)+8=t+4$, so $x(t)=g(t-4)u(t-4)$ is algebraically identical to the original signal and now has the canonical delayed pattern ready for the time-shifting step.

## Converting Delayed Exponentials to Local-Time Form

**Example:** Find the local form for $x(t)=e^{-2(t-5)}u(t-5)$ for use with one-sided time shifting.

**Explanation**

The cue is again the unit-step gate. In $x(t)=e^{-2(t-5)}u(t-5)$, the delayed activation is $u(t-5)$, so the delay is $a=5$ and the same $a$ must appear in the local representation.

Set the local variable as $\tau=t-5$, so that $t=\tau+5$. This is the standard delayed coordinate used throughout the delayed-base steps.

$$
\tau=t-5 \Rightarrow t=\tau+5
$$

Rewrite the exponent using this local variable: $e^{-2(t-5)}=e^{-2\tau}$. Then the signal can be written as $x(t)=e^{-2\tau}u(\tau)$, which is the synchronized local-time form before mapping back.

Now map back to delayed notation with a shared delay anchor: $x(t)=g(t-5)u(t-5)$ where $g(\tau)=e^{-2\tau}$. This keeps the exponential in local time and preserves the same delay as the gate.

$$
x(t)=g(t-5)u(t-5),\quad g(\tau)=e^{-2\tau}
$$

Consistency check: substituting $\tau=t-5$ gives $g(t-5)=e^{-2(t-5)}$, so the rewritten form is identical to the original delayed exponential and is ready for one-sided Laplace shifting.

## Rewriting Turned-On Signals from Global Time to Shifted Time

**Example:** Rewrite $x(t)=(t-2)\big[u(t-2)-u(t-6)\big]$ as a local-time delayed form.

**Explanation**

The cue now has two gates, so start with the first shifted gate: $u(t-2)$. This sets the primary delay anchor at $a=2$, which defines the local-time frame for the whole segment.

Choose the local variable $\tau=t-2$, so $t=\tau+2$. This is the same anchor used in earlier delayed-base steps.

$$
\tau=t-2 \Rightarrow t=\tau+2
$$

Rewrite each factor in this local frame. The base polynomial becomes $t-2=\tau$. The gates become $u(t-2)=u(\tau)$ and $u(t-6)=u(\tau-4)$.

$$
u(t-6)=u((t-2)-4)=u(\tau-4)
$$

Assemble the synchronized form: $x(t)=\tau\big[u(\tau)-u(\tau-4)\big]$. Both gate boundaries and the local base now use the same local coordinate.

$$
x(t)=\tau\big[u(\tau)-u(\tau-4)\big],\quad \tau=t-2
$$

If you prefer delayed notation, this is equivalent to a windowed delayed form with synchronized support. Substituting back gives the exact original behavior: the signal is active on $2\le t<6$ with local ramp $\tau=t-2$, and zero elsewhere.

## Checking Whether a Delayed Signal Is Ready for Time Shifting

**Example:** Check if $x(t)=e^{-t}u(t-2)$ is already in canonical time-shifting form; if not, provide the correction.

**Explanation**

Start by checking the gate anchor. $x(t)=e^{-t}u(t-2)$ has the delayed switch $u(t-2)$, so the form should use delay $a=2$ with a single local coordinate $\tau=t-2$.

Now test synchronization. The base term is $e^{-t}$, not yet written as a function of $\tau=t-2$, so this is not in canonical form yet.

$$
\tau=t-2 \Rightarrow t=\tau+2
$$

Rewrite the base expression in the same local variable: $e^{-t}=e^{-(\tau+2)}=e^{-2}e^{-\tau}$. Then the signal becomes $x(t)=e^{-2}e^{-\tau}u(\tau)$.

Map back to delayed notation: $x(t)=e^{-2}e^{-(t-2)}u(t-2)=\big(e^{-2}e^{-\tau}\big)u(\tau)$ with $\tau=t-2$. This is the canonical form needed for one-sided time shifting.

$$
x(t)=g(t-2)u(t-2),\quad g(t-2)=e^{-2}e^{-(t-2)}
$$

Verdict: not ready in its original form, but ready after synchronization. Minimal correction is to rewrite the base as a function of $t-2$ so the delay in the gate and base are the same.
