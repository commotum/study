## Introduction to Rewriting Piecewise Signals with Unit Steps

A piecewise signal is controlled by breakpoints $a_k$, each one turning a new local formula on. Read the pattern as: baseline piece $x_0$ is always present, and every breakpoint adds a correction term.

Use one local variable per breakpoint, $τ=t-a_k$, so the gate and the local expression share the same shift. In that form, the activation term is $u(t-a_k)$ and the correction is written to this gate.

$$
\Delta f_k=f_k(\tau)-f_{k-1}(\tau),\quad x(t)=x_0+\sum_{k=1}^{K}\Delta f_k\,u(t-a_k)
$$

For the baseline one-breakpoint case from the outline, $x(t)=x_0$ for $t<a_1$ and $x(t)=x_1(t-a_1)$ for $t\ge a_1$, the compressed form is $x(t)=x_0+\bigl[x_1(t-a_1)-x_0\bigr]u(t-a_1)$.

Region check: if $t<a_1$, then $u(t-a_1)=0$ and $x(t)=x_0$; if $t\ge a_1$, then $u(t-a_1)=1$ and $x(t)=x_1(t-a_1)$, so the rewritten expression matches both regions exactly.

$$
x(t)=x_0+\sum_{k=1}^{K}\left[f_k(t-a_k)-f_{k-1}(t-a_k)\right]u(t-a_k)
$$

The next operational goal is that every added branch is written in local-time form; that is the format needed when the piecewise signal is transformed next in the Laplace time-shifting workflow.

## Rewriting a Two-Segment Piecewise Signal with One Unit-Step Correction

**Example:** Rewrite $x(t)=2$ for $t<1$ and $x(t)=t+1$ for $t\ge1$ as a base-plus-correction unit-step expression.

**Explanation**

The cue is a single breakpoint at $t=1$, so use one correction term and keep the baseline segment as $x_0$ for the left-hand region.

From the piecewise rule, set the baseline to $x_0=2$. The new branch is active for $t\ge1$, so $a=1$ and the local variable is $\tau=t-1$.

$$
x_0=2,\quad x_1(\tau)=\tau+2,\quad \tau=t-1.
$$

Next build the correction term from the branch jump: $\Delta f_1=x_1(\tau)-x_0=\tau$. The canonical one-breakpoint form is a baseline plus one delayed correction.

$$
x(t)=x_0+\Delta f_1\,u(t-1)=2+(t-1)u(t-1).
$$

Verify by regions: if $t<1$, then $u(t-1)=0$, so $x(t)=2$. If $t\ge1$, then $u(t-1)=1$, so $x(t)=2+(t-1)=t+1$. This matches the original two-piece definition exactly.

## Rewriting a Finite-Duration Segment with Turn-On and Turn-Off Steps

**Example:** Rewrite $x(t)=0$ for $t<1$, $x(t)=5$ for $1\le t<3$, and $x(t)=0$ for $t\ge3$ as a unit-step sum.

**Explanation**

The cue is a finite interval: the signal turns on at $t=1$, stays on for a limited span, and turns off at $t=3$. That means start from a baseline and add two corrections, one for activation and one for cancellation.

Set the left-side baseline for the first region as $x_0=0$. At the first breakpoint $a_1=1$, add the turn-on correction $+5u(t-1)$ because the new segment is $5$.

At the second breakpoint $a_2=3$, the signal returns to zero, so add a turn-off correction $-5u(t-3)$. Use the local-time form with the same shift for each gate.

$$
x(t)=5u(t-1)-5u(t-3)=5\left[u(t-1)-u(t-3)\right].
$$

Check regions to verify the result. For $t<1$, both steps are zero and $x(t)=0$. For $1\le t<3$, only $u(t-1)=1$, so $x(t)=5-0=5$. For $t\ge3$, both are one and $x(t)=5-5=0$.

So the unit-step form is a compact one-window representation: $x(t)=5u(t-1)-5u(t-3)$, exactly matching the finite-duration pulse on $[1,3)$.

## Rewriting a Multi-Segment Piecewise Signal with Breakpoint Corrections

**Example:** Rewrite $x(t)=2$ for $t<1$, $x(t)=4$ for $1\le t<2$, $x(t)=1$ for $2\le t<5$, and $x(t)=3$ for $t\ge5$ as cumulative unit-step corrections.

**Explanation**

This is a multi-breakpoint signal, so treat each boundary as one correction and keep the same baseline-plus-update structure from earlier sections.

Start with the baseline value for the leftmost region: $x_0=2$.

At $a_1=1$, the value jumps from $2$ to $4$, so add $+2u(t-1)$.

At $a_2=2$, the value drops from $4$ to $1$, so add $-3u(t-2)$. At $a_3=5$, it rises from $1$ to $3$, so add $+2u(t-5)$.

$$
x(t)=2+2u(t-1)-3u(t-2)+2u(t-5).
$$

Check region-by-region: for $t<1$, all steps are zero, so $x(t)=2$. For $1\le t<2$, only $u(t-1)=1$, so $x(t)=2+2=4$. For $2\le t<5$, $u(t-1)=u(t-2)=1$ and $u(t-5)=0$, so $x(t)=2+2-3=1$. For $t\ge5$, all steps are one, so $x(t)=2+2-3+2=3$.

This final expression is the verified three-breakpoint representation, built by cumulative corrections in breakpoint order.

## Rewriting Piecewise Linear Signals with Shifted Ramp Corrections

**Example:** Rewrite $x(t)=1$ for $t<1$, $x(t)=t+1$ for $1\le t<3$, and $x(t)=2t-2$ for $t\ge3$ as a delayed-unit-step decomposition.

**Explanation**

The cue is a piece that changes with ramps, so keep the same breakpoint-correction structure and convert each active branch into local-time form.

Set the left-region baseline to $x_0=1$.

At $a_1=1$, rewrite the second branch as a function of local time $\tau=t-1$, so $x_1(\tau)=\tau+2$. The correction from baseline is $\Delta f_1= x_1(\tau)-x_0=(\tau+2)-1=\tau+1$, which gives $+(\tau+1)u(t-1)$.

At $a_2=3$, rewrite the third branch in local time $\tau=t-3$ as $x_2(\tau)=2\tau+4$. The previous local branch at this breakpoint is $x_1(\tau)=\tau+4$, so the correction is $\Delta f_2=x_2(\tau)-x_1(\tau)=\tau$, giving $+\tau u(t-3)$.

$$
x(t)=1+[(t-1)+1]u(t-1)+(t-3)u(t-3).
$$

Check intervals: if $t<1$, both step terms are inactive and $x(t)=1$. If $1\le t<3$, only $u(t-1)=1$, so $x(t)=1+(t-1+1)=t+1$. If $t\ge3$, both are active and $x(t)=1+(t-1+1)+(t-3)=2t-2$.

This is the same cumulative method as before, now with shifted ramp corrections replacing constant jumps.

## Rewriting All Corrections in Local Time for Laplace Time Shifting

**Example:** Normalize the same pattern as $x(t)=0$ for $t<1$, $x(t)=3-t$ for $1\le t<3$, $x(t)=1$ for $3\le t<4$, and $x(t)=0$ for $t\ge4$ into local-time unit-step corrections.

**Explanation**

The signal has three breakpoints, so the method stays the same as before, but every correction must be written in local time at its own breakpoint for immediate Laplace readiness.

Set the baseline as $x_0=0$ and list breakpoints $a_1=1$, $a_2=3$, and $a_3=4$.

At $a_1=1$, use $\tau=t-1$. The new branch is $x_1(\tau)=3-(\tau+1)=2-\tau$, so the first correction is $\Delta f_1=x_1-x_0=2-\tau$. This gives $(2-(t-1))u(t-1)$.

At $a_2=3$, use the local variable $\tau=t-3$. Before this breakpoint the active branch is still $3-t$, so in local time it is $x_1(\tau)=3-(\tau+3)=-\tau$. The next branch is $x_2(\tau)=1$, so the second correction is $\Delta f_2=1-(-\tau)=1+\tau$, giving $(1+(t-3))u(t-3)$.

At $a_3=4$, use $\tau=t-4$. The active previous branch is constant $1$, so the final correction is $\Delta f_3=0-1=-1$, giving $-u(t-4)$.

$$
x(t)=\left[2-(t-1)\right]u(t-1)+(1+(t-3))u(t-3)-u(t-4)
$$

Check intervals: for $t<1$, all step terms are zero, so $x(t)=0$. For $1\le t<3$, only $u(t-1)=1$, so $x(t)=2-(t-1)=3-t$. For $3\le t<4$, both first two terms are active, so $x(t)=3-t+1+t-3=1$. For $t\ge4$, all terms are active, so $x(t)=3-t+1+t-3-1=0$.

This is the normalized local-time form: every nonzero correction uses delayed local substitution, so the expression is directly compatible with delayed one-sided Laplace operations.
