## Introduction to Zeros of a Transfer Function

A transfer function is written in rational form as $H(s)=\frac{N(s)}{D(s)}$. In this notation, $N(s)$ is the numerator polynomial and $D(s)$ is the denominator polynomial, so the move is about reading the numerator structure in the right ratio form.

$$
H(s)=\frac{N(s)}{D(s)}
$$

To locate zeros, set the function value to zero. If $H(s)=0$, then the numerator must be zero: $H(s)=0 \Rightarrow N(s)=0$, with the transfer function remaining defined.

$$
H(s)=0 \Rightarrow N(s)=0
$$

This condition is valid only when the denominator is not zero, so $D(s)\neq 0$ at the candidate point. Otherwise the expression is not a finite value of $H(s)$ and is not a zero.

$$
D(s)\neq0
$$

Use the base example $H(s)=\frac{s+3}{s+1}$. For this step, set the numerator equation to zero: $s+3=0$, then solve to get $s=-3$. Since $-3$ does not make $s+1$ equal zero, it is an allowed zero value.

Each root of $N(s)$ that also satisfies $D(s)\neq 0$ is a zero location in the $s$-plane. In this lesson, we will keep working this rule through additional numerator forms.

## Finding a Zero from a Linear Numerator

**Example:** Find the zero of $H(s)=\frac{s-4}{s+3}$.

**Explanation**

For this transfer function, the zero lies where the numerator is zero, so begin by writing $H(s)=0$ for $H(s)=\frac{s-4}{s+3}$.

$$
H(s)=0
$$

Because $H(s)=\frac{N(s)}{D(s)}$ is a ratio, setting $H(s)=0$ requires $N(s)=0$ while keeping $D(s)\neq 0$ at the same location. Here, the numerator is $s-4$, so reduce to $s-4=0$.

$$
s-4=0
$$

Solve the linear equation to get $s=4$. Then check the denominator: $s+3\neq0$ at $s=4$, so the candidate is valid and not canceled by a pole condition.

The $s$-plane zero location is $s=4$.

## Finding Multiple Zeros from a Factored Numerator

**Example:** Find all zeros of $H(s)=\frac{(s+3)(s-4)}{s+5}$.

**Explanation**

To find all zero locations in this step, use the definition that zeros make the transfer function equal to zero.

$$
H(s)=0
$$

Set $H(s)=0$ for the given fraction, so the numerator must vanish while the denominator stays nonzero. This gives $(s+3)(s-4)/(s+5)=0$, and thus $(s+3)(s-4)=0$ with $s+5\neq0$.

$$
(s+3)(s-4)=0
$$

Apply the zero-product rule: a product is zero only when one factor is zero.

$$
s+3=0
$$

$$
s-4=0
$$

Solve both equations to obtain $s=-3$ and $s=4$. Check $s=-5$ does not appear as either root, so both values are valid zero locations.

## Finding Zeros by Factoring a Quadratic Numerator

**Example:** Find all zeros of $H(s)=\frac{s^2-4s-5}{s^2+2s+1}$.

**Explanation**

Find zeros where $H(s)=0$, so start from the cue equation $\frac{s^2-4s-5}{s^2+2s+1}=0$.

$$
H(s)=0
$$

Since this is a ratio, set the numerator to zero and keep the denominator nonzero at the zero locations. The first task is to factor the numerator.

$$
s^2-4s-5=(s-5)(s+1)
$$

Apply the zero-product rule by setting each factor in the factored numerator equal to zero.

$$
s-5=0\quad \text{or}\quad s+1=0
$$

Solve both equations to get $s=5$ and $s=-1$. The zero set is $\{5,-1\}$, and both are valid because the denominator is finite at these values.

## Interpreting Zeros as Locations Where $H(s)$ Vanishes

**Example:** Identify the zeros of $H(s)=\frac{(s+2)(s-4)}{(s+1)(s+3)}$ and interpret their meaning.

**Explanation**

The zero condition is $H(s)=0$, so use this cue to focus on the numerator root condition first.

$$
H(s)=0
$$

For this transfer function, set the numerator to zero: $H(s)=\frac{(s+2)(s-4)}{(s+1)(s+3)}\Rightarrow (s+2)(s-4)=0$, because the denominator is checked separately.

$$
(s+2)(s-4)=0
$$

Apply the factor rule: each factor can be zero.

$$
s+2=0\quad\text{or}\quad s-4=0
$$

Solving gives zeros at $s=-2$ and $s=4$. The denominator zeros $s=-1,-3$ are poles and are not zero locations.

So in the $s$-plane, $s=-2$ and $s=4$ are where $H(s)=0$, while denominator roots indicate non-finite locations not in the zero set.
