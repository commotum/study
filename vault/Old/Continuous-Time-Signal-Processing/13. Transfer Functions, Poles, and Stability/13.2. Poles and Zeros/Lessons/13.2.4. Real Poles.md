## Introduction to Real Poles

A transfer function written as a ratio of polynomials links pole values to natural response modes: each denominator root produces an exponential term in the system response. For this lesson, your target move is to read a pole value $p$ from denominator form and map it to the mode shape it creates.

Use the simplest form first: $H(s)=\frac{A}{s-p}$. The denominator is zero when $s=p$, so the pole is at $s=p$, and the corresponding time-domain mode is the canonical term $A e^{pt}u(t)$.

$$
H(s)=\frac{K}{s-p} \Rightarrow h(t)=Ke^{pt}u(t)
$$

Now apply the same direct rule to the base example. For $H(s)=\frac{A}{s+2}$, the pole is $p=-2$. Because $p=-2<0$, the mode is $e^{-2t}u(t)$, which decreases as $t$ increases.

$$
p<0 \Rightarrow e^{pt}\text{ decays}
$$

Use the same comparison for other signs: if $p>0$, then $e^{pt}$ grows, and if $p=0$, then the mode is constant over time.

$$
p>0 \Rightarrow e^{pt}\text{ grows}
$$

For real poles, this gives a direct stability read: negative real poles produce decaying nonoscillatory modes, positive real poles produce growing nonoscillatory modes, and $p=0$ gives a sustained constant mode.

## Interpreting Negative Real Poles as Decaying Modes

**Example:** Interpret the real-pole mode in $H(s)=\frac{3}{s+5}$.

**Explanation**

Read the denominator of the transfer function first: $H(s)=\frac{3}{s+5}$ has $D(s)=s+5$. Write it in root form as $s-(-5)$, so the real pole is $p=-5$.

$$
s+5=s-(-5)
$$

Map the pole to the homogeneous-mode rule from the tutorial: for a real pole at $p$, the time-domain mode is $h_h(t)=Ce^{pt}u(t)$. Substituting $p=-5$ gives the mode from this factor.

$$
h_h(t)=3e^{-5t}u(t)
$$

Because the pole value is negative ($p=-5<0$), the factor is decaying and nonoscillatory: it contributes $e^{-5t}$, which shrinks in magnitude as $t$ increases.

$$
p<0\Rightarrow e^{pt}\text{ is decaying and nonoscillatory}
$$

## Interpreting Positive Real Poles as Growing Modes

**Example:** Interpret the real-pole mode in $H(s)=\\frac{1}{s-1.5}$.

**Explanation**

Read the transfer function denominator: for $H(s)=\frac{1}{s-1.5}$, the denominator is $D(s)=s-1.5$, so the real pole is at $p=1.5$. The pole is positive because $1.5>0$.

$$
D(s)=s-1.5 = s-(1.5) \Rightarrow p=1.5
$$

Apply the same mapping used before for real poles: a real pole at $p$ produces a nonoscillatory mode $h_h(t)=Ce^{pt}u(t)$. Here, use $p=1.5$.

$$
h_h(t)=Ce^{1.5t}u(t)
$$

Now compare the time trend: because $p>0$, the factor $e^{1.5t}$ grows without bound as $t$ increases. So this is a growing, nonoscillatory mode, and it is unstable if it is the dominant real mode.

$$
p>0 \Rightarrow e^{pt}=e^{1.5t}\ \text{grows}\ \text{as}\ t\to\infty
$$

## Comparing Real-Pole Locations and Exponential Rates

**Example:** Example: Compare the nonoscillatory rates for transfer functions with poles $s=-1$, $s=-3$, and $s=2$.

**Explanation**

Use a concrete transfer function with those poles, for example $H(s)=\frac{1}{(s+1)(s+3)(s-2)}$. The real poles are the roots of the denominator: $p_1=-1$, $p_2=-3$, and $p_3=2$.

$$
D(s)=(s+1)(s+3)(s-2)=0 \Rightarrow p\in\{-1,-3,2\}
$$

Convert each real pole to its natural-mode exponent using the same real-pole rule: for pole $p$, the nonoscillatory mode is $e^{pt}u(t)$.

$$
p=-3 \Rightarrow h_1(t)=Ce^{-3t}u(t),\quad p=-1 \Rightarrow h_2(t)=Ce^{-t}u(t),\quad p=2 \Rightarrow h_3(t)=Ce^{2t}u(t)
$$

Now rank the exponents. The negative poles both decay: $e^{-3t}$ is faster-decaying than $e^{-t}$, so $e^{-3t}u(t)$ is the fastest decay and $e^{-t}u(t)$ is the slowest decay. The positive pole $p=2$ gives $e^{2t}u(t)$, which grows and dominates at large $t$.

$$
-3<-1<0<2 \Rightarrow e^{-3t}\text{ decays fastest},\ e^{-t}\text{ decays slowest among decays},\ e^{2t}\text{ dominates}
$$
