## Introduction to Left-Half-Plane Poles

In the causal LTI setting from the prior lesson, pole placement is now the core signal for stability: the $s$-plane location of each pole drives time-domain behavior, and this step establishes that rule as a direct-instruction checkpoint.

Start with transfer-function poles. For $H(s)=\frac{N(s)}{D(s)}$, poles are the roots of $D(s)=0$. The left half-plane is defined by $\Re\{s\}<0$.

$$
H(s)=\frac{N(s)}{D(s)}
$$

![](<../Source/13.3.3. Left-Half-Plane Poles/Images/l003-s001-te-section-001.png>)

Use the base case $H(s)=\frac{1}{s+2}$ first: the denominator is zero at $s=-2$. Because $\Re\{-2\}=-2<0$, the associated mode is decaying. This is the canonical stable-decay anchor for this topic.

To connect pole location to mode shape, write a pole as $s=\sigma+j\omega$ so the time-domain factor is $e^{st}=e^{(\sigma+j\omega)t}=e^{\sigma t}e^{j\omega t}$. The factor $e^{\sigma t}$ is the envelope, and strict negative $\sigma$ is what creates decay.

$$
e^{st}=e^{(\sigma+j\omega)t}=e^{\sigma t}e^{j\omega t}
$$

Boundary rule for this lesson: any pole with $\Re\{s\}\ge 0$ is outside the left-half-plane rule and breaks the causal-LTI BIBO-stability criterion used here. So the target action is explicit: all poles must satisfy $\Re\{s\}<0$.

The next sections reuse this same cue: identify poles from formulas, plot them on the $s$-plane, interpret the sign of each real part, then state the stability result from the same strict all-$\text{LHP}$ rule.

## Identifying Poles with Negative Real Parts

**Example:** Classify the pole set $\{-1, -4, 2, -j3\}$ for the causal transfer function.

**Explanation**

Use the rule that stability depends on the real part of each pole, so first convert every pole in the set to a $\sigma + j\omega$ form and keep the real part explicitly visible.

$$
\{ -1, -4, 2, -j3 \} = \{ -1+ j\,0,\ -4 + j\,0,\ 2+ j\,0,\ 0- j3 \}
$$

Compute real parts: $\Re\{-1\}=-1$, $\Re\{-4\}=-4$, $\Re\{2\}=2$, and $\Re\{-j3\}=0$.

Apply the strict left-half-plane test from earlier: keep poles with $\Re\{s\}<0$. This gives $\{ -1, -4 \}$ as LHP poles and excludes $2$ and $0$.

Because the set contains the right-half-plane pole $2$, the strict all-$\Re\{s\}<0$ condition fails for this transfer function, so the result is not stable in this causal LTI-BIBO check.

## Locating Left-Half-Plane Poles on the s-Plane

**Example:** Use the provided $s$-plane diagram to identify all left-half-plane poles and classify stability for the causal system.

**Explanation**

The core cue is geometric: identify all pole locations on the given $s$-plane map and apply the same strict rule from earlier, $\Re\{s\}<0$, to each point.

![](<../Source/13.3.3. Left-Half-Plane Poles/Images/l003-s003-te-section-003.png>)

Read the plotted poles: $\{-2,\,-0.5,\,0.2,\,-1+2j\}$, and ignore zero markers because this criterion depends on poles only.

$$
\Re(-2)=-2,\quad \Re(-0.5)=-0.5,\quad \Re(0.2)=0.2,\quad \Re(-1+2j)=-1
$$

Apply $\Re\{s\}<0$ to each pole. The poles in the LHP are $-2$, $-0.5$, and $-1+2j$; the pole at $0.2$ violates the strict inequality.

List of LHP poles: $\{-2,\,-0.5,\,-1+2j\}$. Because one pole is in the right half-plane, the all-poles rule fails, so this causal LTI example is classified as not BIBO stable.

## Interpreting Negative Real Parts as Decaying Modes

**Example:** For poles $s=-2$ and $s=-1.5+2j$, write the associated mode terms in time-domain form and state whether each mode decays.

**Explanation**

The cue is that each pole in Laplace form maps to a mode term $e^{st}$. For each pole, first write $s=\sigma+j\omega$ so the mode has the factored time-domain shape $e^{(\sigma+j\omega)t}=e^{\sigma t}e^{j\omega t}$, then test the sign of $\sigma$.

For $s=-2$, decomposition gives $\sigma=-2$, $\omega=0$, so the mode term is $e^{-2t}e^{j0t}=e^{-2t}$.

$$
e^{-2t} = e^{(-2+0j)t}=e^{-2t}e^{j0t}
$$

For $s=-1.5+2j$, decomposition gives $\sigma=-1.5$, $\omega=2$, so $e^{st}=e^{(-1.5+2j)t}=e^{-1.5t}e^{j2t}$.

$$
e^{(-1.5+2j)t}=e^{-1.5t}e^{j2t}
$$

Both modes have strict negative real parts: $\sigma=-2<0$ and $\sigma=-1.5<0$, so both are decaying. The first decays faster because $|-2|>|-1.5|$, and $e^{-1.5t}e^{j2t}$ adds oscillation via frequency $\omega=2$ without changing decay.

The stability intuition is immediate: when all pole-derived modes have negative real parts, each response mode is bounded and decaying for causal LTI systems.

## Connecting All Left-Half-Plane Poles to BIBO Stability

**Example:** Given $H(s)=\frac{10}{(s+1)(s+2)(s+4)}$, determine BIBO stability for a causal LTI system.

**Explanation**

The target rule is the all-poles check: extract every pole from the denominator and test each one with $\Re\{s\}<0$. For $H(s)=\frac{10}{(s+1)(s+2)(s+4)}$, the poles come from $(s+1)(s+2)(s+4)=0$.

$$
(s+1)(s+2)(s+4)=0 \Rightarrow s\in\{-1,-2,-4\}
$$

Now check each pole real part: $\Re(-1)=-1$, $\Re(-2)=-2$, and $\Re(-4)=-4$. Every pole is strictly negative.

Apply the strict all-pole rule from earlier: the system is BIBO stable only if every pole satisfies $\Re\{s\}<0$. Here all three satisfy it, so the transfer function is BIBO stable.

In one statement: all poles are in the left half-plane, so all modal terms are decaying for causal LTI and the whole transfer-function result is stable.
