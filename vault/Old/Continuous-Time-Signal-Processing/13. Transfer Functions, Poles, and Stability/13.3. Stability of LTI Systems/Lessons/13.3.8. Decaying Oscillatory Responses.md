## Introduction to Decaying Oscillatory Responses

Recognize the target cue first: a complex-conjugate pole pair with negative real part is the signature of a decaying oscillatory mode in a causal LTI response.

Use the rule directly: for poles $s=\sigma\pm j\omega$, convert to a causal term template $h_c(t)=e^{\sigma t}(A\cos(\omega t)+B\sin(\omega t))u(t)$ and treat $\sigma$ as the growth/decay exponent and $\omega$ as the oscillation frequency.

$$
\mathcal{L}^{-1}\left\{\frac{\omega}{(s+\alpha)^2+\omega^2}\right\}=e^{-\alpha t}\sin(\omega t)u(t)
$$

$$
h_c(t)=e^{-\alpha t}(A\cos(\omega t)+B\sin(\omega t))u(t)
$$

Apply the base case now: for $s=-2\pm j3$, the converted causal mode is $e^{-2t}(A\cos(3t)+B\sin(3t))u(t)$, which decays because the exponent is negative. In contrast, $s=-2$ maps to a non-oscillatory decay $e^{-2t}u(t)$, while $s=\pm j3$ gives sustained oscillation with no exponential decay.

Close with this stability check: in a causal LTI mode decomposition, all such conjugate pair terms must satisfy $\Re\{s\}<0$ for BIBO stability; any mode with zero or positive real part is the point where the response fails to decay.

## Identifying Decaying Oscillations from Left-Half-Plane Pole Pairs

**Example:** Given pole pairs $s=-2\pm j3$ and $s=+2\pm j3$, classify each as decaying oscillatory or not.

**Explanation**

Use this as a mode-identification pass. A pair is a decaying oscillatory contribution when it satisfies three conditions at once: it is complex (nonzero imaginary part), the two values are conjugates of each other, and the common real part is negative.

Start with $s=-2\pm j3$. This pair is complex because it has $\omega=\pm 3\neq 0$, the values are conjugates, and the real part is $\sigma=-2$, which is negative.

$$
s=-2\pm j3 \;\Rightarrow\; \sigma=-2<0,\;\omega=3\neq 0 \;\Rightarrow\; \text{decaying oscillatory}
$$

$$
s=+2\pm j3 \;\Rightarrow\; \sigma=+2>0,\;\omega=3\neq 0 \;\Rightarrow\; \text{unstable (growing) oscillatory contribution}
$$

So the correct classification is: the pair $s=-2\pm j3$ is a decaying oscillatory mode, while $s=+2\pm j3$ is an unstable oscillatory mode for a causal LTI decomposition.

## Reading Decay Rate and Oscillation Frequency from Complex Poles

**Example:** For poles $s=-3\pm j2$, compute the decay rate and frequency used in the time-domain prototype.

**Explanation**

Use the same cue as in the prior sections: a complex-conjugate pair is written as $s=\sigma\pm j\omega$ and maps directly to a causal mode template. First identify the two parameters before applying any simplification.

For the given poles, read the real and imaginary parts directly: $s=-3\pm j2$ already matches $\sigma\pm j\omega$ with $\sigma=-3$ and $\omega=2$.

$$
s=-3\pm j2 \;\Rightarrow\; \sigma=-3,\; \omega=2
$$

The decay rate is the magnitude of the negative real part, so the exponential envelope is $e^{-3t}$. The angular frequency is the magnitude of the imaginary coefficient, so the oscillation frequency is $\omega=2$ radians per second.

$$
h_c(t)=e^{-3t}\left(A\cos(2t)+B\sin(2t)\right)u(t)
$$

Result: decay constant $3$, frequency $2$, and the corresponding prototype mode is $h_c(t)=e^{-3t}(A\cos(2t)+B\sin(2t))u(t)$, which is a decaying oscillatory contribution in a causal decomposition.

## Writing the Response Term from a Complex-Conjugate Pole Pair

**Example:** Poles at $s=-2\pm j5$ appear in the factor $(s+2)^2+25$. Write the corresponding response mode.

**Explanation**

Use the response-construction cue: once the pole pair is identified, write the denominator in standard causal-decay form and substitute directly into the real-time template.

Start by matching the provided factor to $(s+\alpha)^2+\omega^2$ so that the pair is in template-ready form.

$$
(s+2)^2+25 = (s+\alpha)^2+\omega^2
$$

Read off the parameters from this match: $\alpha=2$ and $\omega=5$. The conjugate poles are therefore $s=-2\pm j5$, so the mode is in the decaying oscillatory causal family.

$$
h_c(t)=e^{-2t}\left(A\cos(5t)+B\sin(5t)\right)u(t)
$$

Final result: the response mode is $h_c(t)=e^{-2t}(A\cos(5t)+B\sin(5t))u(t)$, and because $\alpha=2>0$ in this course's convention, the exponential envelope decays in time.

## Interpreting BIBO Stability from Decaying Oscillatory Modes

**Example:** Determine stability from poles corresponding to decaying terms $e^{-2t}(A\cos 4t)u(t)$, $e^{-t}(B\sin 3t)u(t)$, and one growing oscillatory mode $e^{t}(C\cos 2t)u(t)$.

**Explanation**

Apply the same per-mode cue used in this topic: a causal mode is stable only if each exponential envelope decays for $t \to +\infty$. Start by listing the real exponents in the three mode terms.

$$
h_1(t)=e^{-2t}(A\cos 4t)u(t),\; h_2(t)=e^{-t}(B\sin 3t)u(t),\; h_3(t)=e^{t}(C\cos 2t)u(t)
$$

Use the BIBO rule from the lesson core move: list the real parts of each exponent. For $h_1(t)$ the real part is $-2$, for $h_2(t)$ it is $-1$, and for $h_3(t)$ it is $+1$.

$$
\Re\{s\}_{h_1}=-2,\; \Re\{s\}_{h_2}=-1,\; \Re\{s\}_{h_3}=+1
$$

Aggregate the sign check across all modes: BIBO stability in this causal LTI setting requires every real part to be negative. One positive real part ($+1$) violates the all-negative rule and dominates the combined response behavior.

$$
\text{BIBO stable} \iff \forall \text{ modes },\; \Re\{s\}<0
$$

Conclusion: the system is unstable, because the $e^{t}(C\cos 2t)u(t)$ mode grows over time and breaks bounded-output stability regardless of the other two decaying oscillatory modes.
