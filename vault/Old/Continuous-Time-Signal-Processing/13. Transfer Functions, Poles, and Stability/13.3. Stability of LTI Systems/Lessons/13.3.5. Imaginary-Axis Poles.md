## Introduction to Imaginary-Axis Poles

Start from the prior lesson: pole location determines causal LTI behavior, and causality remains the prerequisite condition for every stability check in this chain.

A single mode from a pole $s=\sigma+j\omega$ is represented as $e^{st}=e^{(\sigma+j\omega)t}=e^{\sigma t}e^{j\omega t}$; the factor $e^{\sigma t}$ is the growth/decay envelope and $e^{j\omega t}$ is the oscillatory part.

Use the $s$-plane categories exactly: left-half-plane is $\Re\{s\}<0$, right-half-plane is $\Re\{s\}>0$, and imaginary-axis is $\Re\{s\}=0$. The tutorial rule is: this boundary case must be marked separately from stable and unstable half-planes.

![](<../Source/13.3.5. Imaginary-Axis Poles/Images/l005-s001-te-section-001.png>)

When the real part is zero, $\Re\{s\}=0$, the envelope is $e^{0\cdot t}=1$, so the term does not decay. For a causal LTI mode, this means the response neither grows nor shrinks in amplitude and is therefore not BIBO stable on its own.

Now apply the strict rule: in $H(s)=\frac{N(s)}{D(s)}$, factor $D(s)$ as $\prod_i (s-p_i)$ and inspect each $p_i$. For this lesson, if any pole has $\Re\{p_i\}=0$, classify the causal system as BIBO-unstable.

$$
e^{st}=e^{(\sigma+j\omega)t}=e^{\sigma t}e^{j\omega t}
$$

$$
\Re\{s\}=0 \Rightarrow e^{\sigma t}=1 \text{ (nondecaying envelope)}
$$

$$
H(s)=\frac{N(s)}{D(s)},\; D(s)=\prod_i (s-p_i)
$$

## Recognizing Poles with Zero Real Part

**Example:** Classify the poles $\{-2,\,-5,\,3j,\,-3j\}$ for a causal LTI transfer function.

**Explanation**

Use the cue from this section: the pole list is the full set of system poles, and each pole is checked directly by its real part to test BIBO stability for causal LTI systems.

Apply the rule from the previous tutorial step and use $\Re\{p\}=0$ as the imag-axis test. Compute the real parts of each pole: $\Re\{-2\}=-2$, $\Re\{-5\}=-5$, $\Re\{3j\}=0$, and $\Re\{-3j\}=0$.

$$
\Re\{-2\}=-2,\; \Re\{-5\}=-5,\; \Re\{3j\}=0,\; \Re\{-3j\}=0
$$

Select the poles with zero real part, $p=\pm 3j$, as imaginary-axis poles. These produce nondecaying modes because their envelope factor is constant in time.

Therefore the transfer function is not BIBO stable: a causal LTI system with any pole on the imaginary axis is classified as unstable in this lesson chain.

## Classifying a Pole at the Origin

**Example:** Classify BIBO stability for poles at $\{0,-1,-4\}$.

**Explanation**

Cue: this section gives the pole list, so the action is to inspect each listed pole directly by real part. For this causal-LTI example, classify each pole from the set $\{0,-1,-4\}$.

Use the boundary rule from the tutorial and verify the poles, then compute real parts: $\Re\{0\}=0$, $\Re\{-1\}=-1$, and $\Re\{-4\}=-4$.

$$
p\in\{0,-1,-4\},\; \Re\{0\}=0,\; \Re\{-1\}=-1,\; \Re\{-4\}=-4
$$

Apply the lesson rule: if any pole has $\Re\{p\}=0$, the system has a nondecaying constant-like mode and is not BIBO stable. Here, $p=0$ is on the imaginary axis by real-part test.

Conclude: the pole at the origin alone is enough to mark this causal LTI transfer function as not BIBO stable.

## Classifying Simple Nonzero Imaginary-Axis Poles

**Example:** Classify poles $\{4,\,-1,\,-2j,\,2j\}$ for a causal LTI transfer function.

**Explanation**

Cue: the section gives a pole set, so the action is to classify each pole by real part and then decide BIBO stability for the causal LTI system.

Use the same rule as prior sections: inspect all poles in $\{4,-1,-2j,2j\}$, then evaluate their real parts.

$$
\Re\{4\}=4,\; \Re\{-1\}=-1,\; \Re\{-2j\}=0,\; \Re\{2j\}=0
$$

Apply strict checks: any pole with $\Re\{p\}>0$ is unstable, poles with $\Re\{p\}<0$ are acceptable for this lesson, and poles with $\Re\{p\}=0$ are nondecaying and therefore violate BIBO stability.

Here, $p=\pm2j$ are on the imaginary axis ($\Re\{\pm2j\}=0$), so they contribute nondecaying oscillatory modes.

Result: because an imaginary-axis pair is present, classify the causal LTI transfer function as not BIBO stable.

## Classifying Repeated Imaginary-Axis Poles

**Example:** Classify the stability of $H(s)=\dfrac{5}{(s+j2)^2(s+1)}$ for a causal LTI system.

**Explanation**

Cue: this section is the multiplicity extension, so first factor the denominator and list every pole, including repetition: $H(s)=\dfrac{5}{(s+j2)^2(s+1)}$.

$$
D(s)=(s+j2)^2(s+1),\; p_1=p_2=-j2,\; p_3=-1
$$

Apply the existing real-part rule and record: $\Re\{-j2\}=0$ (with multiplicity 2), and $\Re\{-1\}=-1$.

Because the repeated poles are on the imaginary axis, they are still nondecaying modes; multiplicity does not change the instability class in this lesson, it only reinforces that the system violates the strict stability condition.

Therefore, the causal LTI transfer function is not BIBO stable.
