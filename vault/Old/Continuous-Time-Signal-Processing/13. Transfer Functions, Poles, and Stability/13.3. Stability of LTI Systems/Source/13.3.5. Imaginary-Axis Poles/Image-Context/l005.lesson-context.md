  text: Use the $s$-plane categories exactly: left-half-plane is $\Re\{s\}<0$, right-half-plane is $\Re\{s\}>0$, and imaginary-axis is $\Re\{s\}=0$. The tutorial rule is: this boundary case must be marked separately from stable and unstable half-planes.
- image:

- paragraph:
  text: When the real part is zero, $\Re\{s\}=0$, the envelope is $e^{0\cdot t}=1$, so the term does not decay. For a causal LTI mode, this means the response neither grows nor shrinks in amplitude and is therefore not BIBO stable on its own.
- paragraph:
  text: Now apply the strict rule: in $H(s)=\frac{N(s)}{D(s)}$, factor $D(s)$ as $\prod_i (s-p_i)$ and inspect each $p_i$. For this lesson, if any pole has $\Re\{p_i\}=0$, classify the causal system as BIBO-unstable.
