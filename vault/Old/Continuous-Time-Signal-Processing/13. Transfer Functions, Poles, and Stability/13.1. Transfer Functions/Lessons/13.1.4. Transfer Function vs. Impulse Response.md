## Introduction to Transfer Function vs. Impulse Response

An LTI system is described in the time domain by its impulse response $h(t)$. The corresponding $s$-domain description is the transfer function $H(s)=\mathcal{L}\{h(t)\}$. In the simplest base case, $h(t)=\delta(t)$, so the system has $H(s)=1$ and does not change the input.

$$
h(t)=\delta(t) \Rightarrow H(s)=1
$$

For any input $x(t)$, the output of an LTI system is $y(t)=x(t)*h(t)$. Taking the one-sided Laplace transform gives $Y(s)=\mathcal{L}\{y(t)\}=X(s)H(s)$. This is the rule that connects the time-domain convolution kernel to the $s$-domain multiplier.

$$
Y(s)=\mathcal{L}\{x(t)*h(t)\}=X(s)H(s)
$$

Use $h(t)$ when you want the intuitive time-domain description of the system, and use $H(s)$ when you want the algebraic multiplier that acts on $X(s)$. The two forms describe the same LTI system, so later sections can move between them without changing the system itself.

The practical takeaway is simple: recognize the impulse response, transform it to get the transfer function, and then use $Y(s)=X(s)H(s)$ to analyze the output in the Laplace domain.

## Identifying $h(t)$ as the Time-Domain System Description

**Example:** From $y(t)=\int_{0^-}^{\infty} x(\tau)e^{-2(t-\tau)}u(t-\tau)\,d\tau$, identify the corresponding $h(t)$.

**Explanation**

Match the given output formula to the convolution pattern $y(t)=\int x(\tau)h(t-\tau)\,d\tau$. The cue is the factor multiplying $x(\tau)$ inside the integral, so the kernel is the part that depends on $t-\tau$.

$$
y(t)=\int x(\tau)h(t-\tau)\,d\tau
$$

Here, $e^{-2(t-\tau)}u(t-\tau)$ plays the role of $h(t-\tau)$. To read off the time-domain system description, replace the shifted argument $t-\tau$ by the free variable $t$.

$$
h(t)=e^{-2t}u(t)
$$

So the impulse response is $h(t)=e^{-2t}u(t)$. That is the time-domain description of the LTI system, and it is the quantity whose Laplace transform later gives the transfer function $H(s)$.

## Finding $H(s)$ from a Simple Impulse Response

**Example:** Find $H(s)$ for $h(t)=2e^{-2t}u(t)$.

**Explanation**

The cue is a causal exponential impulse response. Use the standard one-sided Laplace pair for $e^{-at}u(t)$, then keep the constant multiplier outside the transform.

$$
\mathcal{L}\{e^{-at}u(t)\}=\frac{1}{s+a}, \qquad \Re(s)>-a
$$

With $a=2$, we get $\mathcal{L}\{e^{-2t}u(t)\}=\frac{1}{s+2}$. Multiplying by the outside factor 2 gives $H(s)=\frac{2}{s+2}$, with ROC $\Re(s)>-2$.

## Finding $h(t)$ from a Simple Transfer Function

**Example:** Find $h(t)$ when $H(s)=\frac{1}{s+2}$.

**Explanation**

The cue is a simple first-order transfer function with one pole at $s=-2$. Match it to the standard unilateral Laplace pair, then read the time-domain kernel by reversing the transform.

$$
\mathcal{L}^{-1}\left\{\frac{1}{s+a}\right\}=e^{-at}u(t), \qquad \Re(s)>-a
$$

Here the denominator is $s+2$, so set $a=2$. The inverse transform is $h(t)=e^{-2t}u(t)$, with causal ROC $\Re(s)>-2$.

## Comparing $y(t)=x(t)*h(t) with Y(s)=X(s)H(s)$

**Example:** For $x(t)=e^{-t}u(t)$ and $h(t)=e^{-2t}u(t)$, show $y(t)=x(t)*h(t)$ and verify $Y(s)=X(s)H(s)$.

**Explanation**

The cue is that both signals are causal exponentials, so each one has a standard one-sided Laplace transform. First compute the input transform and the impulse-response transform, then multiply them in the $s$-domain.

$$
X(s)=\frac{1}{s+1}, \qquad H(s)=\frac{1}{s+2}
$$

Now apply the system rule $Y(s)=X(s)H(s)$. The product is $Y(s)=\frac{1}{(s+1)(s+2)}$, which is the $s$-domain form that matches the convolution output.

$$
Y(s)=X(s)H(s)=\frac{1}{(s+1)(s+2)}
$$

To check consistency in time, convolve the signals directly: $y(t)=\int_0^t e^{-\tau}e^{-2(t-\tau)}\,d\tau=(e^{-t}-e^{-2t})u(t)$. That time-domain result transforms back to the same product, so the convolution rule and the multiplication rule agree.
