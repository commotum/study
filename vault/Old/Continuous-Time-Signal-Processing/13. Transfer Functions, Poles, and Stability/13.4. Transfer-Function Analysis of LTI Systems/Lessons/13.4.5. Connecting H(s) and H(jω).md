## Introduction to Connecting $H(s)$ and $H(j\omega)$

The core object to recognize in this step is the frequency-response function itself. For this lesson, evaluate the Laplace transfer function on the imaginary axis by replacing $s$ with $j\omega$, so $H(j\omega)$ is the value of $H(s)$ that controls steady-state sinusoidal behavior.

$$
H(j\omega)=H(s)\Big|_{s=j\omega}
$$

Use the simplest base case exactly as your model: start from $H(s)=\frac{1}{s+a}$ with $a>0$, then write $H(j\omega)=\frac{1}{j\omega+a}=\frac{1}{a+j\omega}$. This gives a concrete pattern for substitution and simplification that appears in every later example.

Then read the result as a complex gain: $H(j\omega)=|H(j\omega)|\,e^{j\angle H(j\omega)}$. If the input is $A\cos(\omega t+\phi_\text{in})$, the steady-state output scales by $|H(j\omega)|$ and shifts by phase $\angle H(j\omega)$.

$$
y_\text{ss}(t)=|H(j\omega)|A\cos(\omega t+\angle H(j\omega)+\phi_\text{in})
$$

Before moving on, enforce one validity check: $H(j\omega)$ is only defined at frequencies where this substitution does not land on a pole. If $s=j\omega$ is a pole, the frequency is singular and must be excluded from this direct evaluation step.

## Substituting $s=j\omega$ into $H(s)$

**Example:** Evaluate $H(j\omega)$ for $H(s)=\frac{20}{s+5}$.

**Explanation**

Use the substitution rule from the previous step: replace every occurrence of $s$ with $j\omega$ in the transfer function to build the frequency-response expression.

Start from the given transfer function and apply the rule directly:

$$
H(s)=\frac{20}{s+5} \quad \Longrightarrow \quad H(j\omega)=\frac{20}{j\omega+5}
$$

Keep the expression in this clean complex-ratio form, with the real constant term and the imaginary part separated in the denominator. This is the target symbolic form for this step:

$$
H(j\omega)=\frac{20}{5+j\omega}
$$

Since the denominator is $5+j\omega$, it is never zero for real $\omega$, so this is a valid first frequency-response expression and ready to pass to the simplification/checklist step next.

## Simplifying a Rational $H(j\omega)$

**Example:** Simplify $H(j\omega)$ for $H(s)=\frac{s+2}{s^2+6s+13}$ and express it as $\frac{A(\omega)+jB(\omega)}{C(\omega)}$.

**Explanation**

This section is cued by the substitution move from the previous step, so the rule is: evaluate $H(s)$ at $s=j\omega$, then rewrite the result as a real-denominator algebraic form suitable for magnitude and phase.

Start with the given transfer function and apply the cue substitution directly.

$$
H(s)=\frac{s+2}{s^2+6s+13} \quad \Longrightarrow \quad H(j\omega)=\frac{j\omega+2}{(j\omega)^2+6j\omega+13}
$$

Use $(j\omega)^2=-\omega^2$ and collect real/imaginary terms. Then the intermediate target form is

$$
H(j\omega)=\frac{2+j\omega}{13-\omega^2+6j\omega}
$$

Because the denominator is still complex, multiply by its conjugate to create one real denominator.

$$
H(j\omega)=\frac{(2+j\omega)(13-\omega^2-6j\omega)}{(13-\omega^2+6j\omega)(13-\omega^2-6j\omega)}
$$

Expanding and collecting powers gives a clean ratio with real $C(\omega)$ in the denominator and separate real and imaginary numerators.

$$
H(j\omega)=\frac{26+4\omega^2+j(\omega-\omega^3)}{\omega^4+10\omega^2+169} = \frac{A(\omega)+jB(\omega)}{C(\omega)}
$$

Read off the standard pieces: $A(\omega)=26+4\omega^2$, $B(\omega)=\omega-\omega^3$, and $C(\omega)=\omega^4+10\omega^2+169$. This is the form to feed into the next magnitude-phase step.

## Finding Magnitude and Phase of $H(j\omega)$

**Example:** Find $|H(j\omega)|$ and $\angle H(j\omega)$ for $H(s)=\frac{s+1}{s+2}$.

**Explanation**

From the simplification flow in earlier sections, the cue is to first convert $H(s)$ to a ratio with explicit real and imaginary parts by setting $s=j\omega$.

Apply the substitution directly and identify real-imag pieces in numerator and denominator:

$$
H(j\omega)=\frac{j\omega+1}{j\omega+2} = \frac{1+j\omega}{2+j\omega}
$$

For magnitude, apply the quotient-of-norms rule: the magnitude of a ratio is the numerator magnitude divided by denominator magnitude.

$$
|H(j\omega)| = \frac{|1+j\omega|}{|2+j\omega|} = \frac{\sqrt{1^2+\omega^2}}{\sqrt{2^2+\omega^2}} = \frac{\sqrt{1+\omega^2}}{\sqrt{4+\omega^2}}
$$

For phase, subtract denominator phase from numerator phase using argument rules, with each piece in arctangent form.

$$
\angle H(j\omega)=\angle(1+j\omega)-\angle(2+j\omega)=\arctan\left(\frac{\omega}{1}\right)-\arctan\left(\frac{\omega}{2}\right)
$$

Result:

$$
|H(j\omega)|=\frac{\sqrt{1+\omega^2}}{\sqrt{4+\omega^2}}, \quad \angle H(j\omega)=\arctan(\omega)-\arctan\left(\frac{\omega}{2}\right)
$$

This final pair is the reusable output format for downstream interpretation and for multiple-choice distractors about sign and ratio order.

## Interpreting Sinusoidal Steady-State Output from $H(j\omega)$

**Example:** Given $x(t)=3\cos(\omega_0 t-\pi/6)$ and $H(s)=\frac{5}{s+2}$, write the steady-state output $y_\text{ss}(t)$ using $H(j\omega_0)$.

**Explanation**

The cue is interpretation: use the frequency-response evaluation rule from earlier sections and convert the resulting $|H(j\omega_0)|$ and $\angle H(j\omega_0)$ into a cosine output model.

First evaluate at $s=j\omega_0$: 

$$
H(j\omega_0)=\frac{5}{2+j\omega_0}=\frac{5(2-j\omega_0)}{(2+j\omega_0)(2-j\omega_0)}=\frac{10-5j\omega_0}{4+\omega_0^2}
$$

Read off magnitude and phase of this ratio:

$$
|H(j\omega_0)|=\frac{5}{\sqrt{4+\omega_0^2}}, \quad \angle H(j\omega_0)=\angle\left(\frac{1}{2+j\omega_0}\right)= -\arctan\left(\frac{\omega_0}{2}\right)
$$

Multiply the input amplitude by the gain and add the phase shift inside the cosine argument.

$$
A_\text{out}=3|H(j\omega_0)|=\frac{15}{\sqrt{4+\omega_0^2}}, \quad \phi_\text{out}=(-\pi/6)+\angle H(j\omega_0)= -\pi/6-\arctan\left(\frac{\omega_0}{2}\right)
$$

Resulting steady-state output:

$$
y_\text{ss}(t)=\frac{15}{\sqrt{4+\omega_0^2}}\cos\left(\omega_0 t-\frac{\pi}{6}-\arctan\left(\frac{\omega_0}{2}\right)\right)
$$

This preserves the core move: same input frequency and phase reference, with amplitude and phase modified by $H(j\omega_0)$.

## Recognizing When $H(j\omega)$ Is Not Defined

**Example:** Determine where $H(j\omega)$ is undefined for $H(s)=\frac{1}{s^2+1}$ and interpret the result for frequency response.

**Explanation**

This step uses the same substitution rule as before but adds a validity check: after substituting, make sure the resulting denominator is not zero for the frequency you test.

Start by substituting $s=j\omega$ into the denominator expression:

$$
H(j\omega)=\frac{1}{(j\omega)^2+1}=\frac{1}{1-\omega^2}
$$

Find where this ratio is undefined by setting the denominator to zero and solving for real frequencies.

$$
1-\omega^2=0 \quad \Rightarrow \quad \omega=\pm 1
$$

So $H(j\omega)$ is undefined at $\omega=1$ and $\omega=-1$. At these frequencies, the denominator in $s^2+1$ vanishes on the imaginary axis, so the linear frequency-response formula is not valid there.

Result: for this example, the valid frequency-domain rule is usable for all real $\omega$ except at the excluded points $\omega=\pm 1$, where magnitude/phase interpretation must be handled as a singular response case.
