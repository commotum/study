## Introduction to The $s$-Plane

You have already seen $s=\sigma+j\omega$. The new geometric move is to anchor each complex value on a shared coordinate map so the same point tells you exponential weighting and oscillation at a glance.

$$
s=\sigma+j\omega
$$

Define the horizontal axis as the real part $\sigma$ and the vertical axis as $j\omega$ (where $\omega$ is the frequency coordinate). In this view, each point is the ordered pair $(\sigma,\omega)$, so the two labels are read separately and directly.

$$
\sigma=\Re\{s\},\quad \omega=\Im\{s\}
$$

Use the simplest examples first: $s=0$ is the origin, $s=3$ is on the real axis at $(\sigma,\omega)=(3,0)$, and $s=j\omega$ is on the imaginary axis where $\sigma=0$. This is the base pattern students reuse.

![](<../Source/11.1.6. The Complex Frequency Plane/Images/l006-s001-te-section-001.png>)

From this point forward, movement left or right changes $\sigma$, and movement up or down changes $\omega$. A final anchor: the Fourier-frequency slice is the $j\omega$ axis, so $\sigma=0$ corresponds exactly to no exponential weighting.

## Plotting a Complex Value $s=\sigma+j\omega$

**Example:** Plot $s=2+j3$ on the $s$-plane and label the axis-crossings of the plotted point.

**Explanation**

Treat the prompt as a coordinate decode: in $s=\sigma+j\omega$, the real part is the horizontal coordinate and the coefficient of $j\omega$ is the vertical coordinate.

For $s=2+j3$, identify the cue values by matching terms: $\sigma=2$ and $\omega=3$.

$$
(\sigma,\omega)=(2,3),\quad s=2+j3
$$

Place the point at two-rights, three-ups from the origin. Mark its axis crossings by drawing right-angle projections to the axes, so the same point corresponds to $\sigma$-axis intercept $(2,0)$ and imaginary-axis intercept $(0,3)$.

$$
\sigma=0 \text{ and } \omega=0\text{-axis crossings for this example are } (0,3) \text{ and } (2,0),
$$

![](<../Source/11.1.6. The Complex Frequency Plane/Images/l006-s002-te-section-002.png>)

The plotted point is therefore $s=2+j3$, which is in the first quadrant and has nonzero real part, so it is not on the pure Fourier-frequency $j\omega$ axis.

## Reading $\sigma$ and $\omega$ from an $s$-Plane Point

**Example:** Read the point at $\sigma=-4$, $\omega=1$ from the $s$-plane diagram and write the corresponding value of $s$.

**Explanation**

Use this as a coordinate-read prompt: the point is already marked on the $s$-plane, so the task is to decode its horizontal and vertical coordinates into the canonical form $s=\sigma+j\omega$.

First, read the real-axis coordinate. The marked point lies at $\sigma=-4$, so the real part is $\sigma=-4$.

Next, read the imaginary-axis coordinate. The height is $\omega=1$, so the imaginary coefficient is positive one.

$$
\sigma=-4,\quad \omega=1
$$

Write the point in the form $s=\sigma+j\omega$, then substitute: $s=-4+j(1)= -4+j$.

![](<../Source/11.1.6. The Complex Frequency Plane/Images/l006-s003-te-section-003.png>)

So the plotted point corresponds to $s=-4+j$, which is left of the $\sigma=0$ axis and above the real axis.

## Interpreting Horizontal Position as Exponential Weighting

**Example:** Use the point $s=-2+j3$ and state whether it corresponds to exponential decay or growth in $e^{-st}$.

**Explanation**

Use this as an interpretation prompt: the point is already given as $s$, so read its coordinates, then apply the split $e^{-st}=e^{-\sigma t}e^{-j\omega t}$ to infer exponential behavior.

From the point representation, identify $\sigma=-2$ so the real part is negative.

![](<../Source/11.1.6. The Complex Frequency Plane/Images/l006-s004-te-section-004.png>)

$$
e^{-st}=e^{-\sigma t}e^{-j\omega t},\quad \sigma=-2 \Rightarrow e^{-(-2)t}=e^{2t}
$$

Because $e^{-\sigma t}=e^{2t}$ grows with $t$, the weighting is exponential growth.

For comparison, if $\sigma>0$ then $e^{-\sigma t}$ decays, and $\sigma=0$ removes exponential weighting altogether (pure-frequency slice).

So the point $s=-2+j3$ corresponds to exponential growth in the $e^{-st}$ weighting term.

## Identifying the $j\omega$ Axis as the Fourier-Frequency Line

**Example:** From the $s$-plane, identify whether $s=j2$ is on the $j\omega$ axis and state the value of $\sigma$.

**Explanation**

Use the axis-check cue in the prompt: the point is given as $s=j2$, so we read its coordinates and decide whether the real coordinate is zero.

First, decompose $s=j2$ into the form $s=\sigma+j\omega$ so the real part is $\sigma=0$ and the imaginary part is $\omega=2$.

$$
\sigma=0,\; \omega=2,\; s=0+j2=j2
$$

![](<../Source/11.1.6. The Complex Frequency Plane/Images/l006-s005-te-section-005.png>)

Because the real coordinate is zero, the point lies exactly on the $\sigma=0$ (or $j\omega$) axis.

That means this is the Fourier-frequency slice, so the corresponding specialization is $X(j\omega)$ with no exponential weighting shift.
