## Introduction to Limitations of the Fourier Transform

Before using a frequency-response model, test whether the Fourier transform is mathematically valid. The move for this lesson is simple: decide if the Fourier integral is well defined before using it to interpret $x(t)$ or a system impulse response as frequency-domain data.

Write the candidate transform as $X(j\omega)=\int_{-\infty}^{\infty} x(t)e^{-j\omega t}\,dt$ and check absolute integrability first. The gate condition is $\int_{-\infty}^{\infty}|x(t)|\,dt<\infty$. If this fails, the ordinary Fourier representation on the $j\omega$ axis is not justified.

$$
X(j\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}\,dt
$$

Use the lightest possible case as the anchor: let $x(t)=e^{-t}u(t)$. It is nonzero for $t\ge 0$, its magnitude decays, and this concrete base case makes the convergence check easy to reuse in later steps.

$$
\int_{-\infty}^{\infty}|x(t)|\,dt<\infty \Rightarrow X(j\omega)\text{ exists}
$$

In this lesson sequence, you will first confirm a convergent case, then contrast it with nondecaying and growing cases that fail, and finally apply the same test to impulse responses. When convergence fails, you will be ready to move to weighted transforms in the Laplace framework.

## Testing Convergence for a Decaying Time Signal

**Example:** Test whether the Fourier transform converges for $x(t)=e^{-2|t|}$.

**Explanation**

Apply the lesson cue from the prior step: test convergence of the Fourier transform before concluding a $j\omega$-axis frequency response exists. For this signal, you evaluate absolute convergence of the transform kernel with $x(t)=e^{-2|t|}$.

First remove the oscillatory factor by taking magnitude, which gives $|x(t)e^{-j\omega t}|=\left|e^{-2|t|}e^{-j\omega t}\right|=e^{-2|t|}$. Absolute integrability is the decision criterion.

Split the absolute integral at the sign change of $|t|$ into two one-sided pieces.

$$
\int_{-\infty}^{\infty}|e^{-2|t|}|\,dt=\int_{-\infty}^{0}e^{2t}dt+\int_{0}^{\infty}e^{-2t}dt=1
$$

Both one-sided integrals are finite, so the absolute integral is finite. Therefore $\int_{-\infty}^{\infty}e^{-2|t|}e^{-j\omega t}\,dt$ is absolutely convergent, and the Fourier transform $X(j\omega)$ is valid for this step's signal.

## Recognizing Divergence for a Nondecaying Time Signal

**Example:** Test convergence for $x(t)=1$ and decide if a Fourier transform exists.

**Explanation**

Keep the same core move from the previous step, but change to a nondecaying signal to isolate failure. The cue is the same absolute-convergence test, now applied to $x(t)=1$.

Form the magnitude of the transform kernel: $\left|1\cdot e^{-j\omega t}\right|=1$. If this absolute value cannot be integrated to a finite number over the time axis, the Fourier transform does not exist.

Compute the absolute integral directly to test convergence.

$$
\int_{-\infty}^{\infty}|1|\,dt=\int_{-\infty}^{\infty}1\,dt=\infty
$$

The improper integral diverges, so this example fails the core lesson move: $X(j\omega)$ is not defined in the ordinary Fourier sense. Frequency-response language for this signal is therefore not justified without extension.

## Recognizing Divergence for a Growing Exponential Signal

**Example:** Test whether the Fourier transform converges for $x(t)=e^{2t}u(t)$.

**Explanation**

Keep the same absolute-convergence rule from earlier steps, but apply the one new wrinkle: the signal now grows. The cue is to test convergence for $x(t)=e^{2t}u(t)$ on the $j\omega$ Fourier kernel.

Use one-sided support and magnitude first: $\left|e^{2t}u(t)e^{-j\omega t}\right|=e^{2t}u(t)$. If this magnitude integral is infinite, then $X(j\omega)$ is not defined in the standard Fourier sense.

Compute the absolute integral over the nonzero support interval $[0,\infty)$.

$$
\int_{-\infty}^{\infty}|e^{2t}u(t)e^{-j\omega t}|\,dt=\int_{0}^{\infty}|e^{2t}|\,dt=\lim_{T\to\infty}\int_{0}^{T}e^{2t}dt=\lim_{T\to\infty}\left(\frac{e^{2T}-1}{2}\right)=\infty
$$

The improper integral diverges because the antiderivative grows without bound. This is a clear failure of the lesson core move: the same absolute-integral test now shows the Fourier transform does not exist for this growing exponential, so the learner should move to weighted alternatives.

## Testing Whether an Impulse Response Has a Frequency Response

**Example:** Test whether $h(t)=\frac{1}{1+t}u(t)$ has a Fourier-domain frequency response.

**Explanation**

Now shift the test to the system object. Use the same absolute-convergence rule, but apply it to the impulse response $h(t)$: a frequency response $H(j\omega)$ is valid only if the absolute integral of $h(t)$ is finite.

Start from the transform-derivation bound. By triangle inequality, $\left|\int h(t)e^{-j\omega t}dt\right|\le \int |h(t)|\,dt$, so we test absolute integrability of $h(t)=\frac{1}{1+t}u(t)$.

Reduce to the improper one-sided integral and evaluate its growth.

$$
\int_{0}^{\infty}\left|\frac{1}{1+t}u(t)\right|\,dt=\int_{0}^{\infty}\frac{1}{1+t}\,dt=\lim_{T\to\infty}\ln(1+T)=\infty
$$

The absolute integral diverges, so $H(j\omega)$ does not exist in the ordinary Fourier sense. This is the impulse-response analogue of the earlier scalar-signal failures and marks the exact point where weighted-form (Laplace-domain) treatment is needed.

<a id="deciding-when-laplace-domain-weighting-is-needed"></a>
## Deciding When Laplace-Domain Weighting Is Needed

**Example:** For $x(t)=e^{2t}u(t)$, decide whether Fourier or weighted Laplace-domain analysis applies and find the condition on $\sigma$ that would permit convergence.

**Explanation**

Use the same cue from earlier steps: first test the unweighted Fourier integral, then add only the minimal remedy. The growth term is $e^{2t}u(t)$, which already showed unweighted divergence, so we introduce a real exponential weight $e^{-\sigma t}$.

Write the weighted complex integral form, then reduce to a magnitude condition: $X(s)=\int_{-\infty}^{\infty}x(t)e^{-st}\,dt$ with $s=\sigma+j\omega$. For this example, $x(t)=e^{2t}u(t)$ gives the absolute term $e^{-(\sigma)t}e^{2t}u(t)=e^{(2-\sigma)t}u(t)$.

The convergence test is now a one-sided exponential integral on $[0,\infty)$.

$$
\int_{0}^{\infty}e^{(2-\sigma)t}\,dt<\infty \iff \sigma>2
$$

Therefore Fourier fails at $\sigma=0$ because the unweighted exponent is nondecaying, but any choice with $\sigma>2$ makes the weighted integral finite. Branch rule: use Fourier only when the unweighted $j\omega$-axis integral converges; otherwise move to weighted Laplace-domain representation.
