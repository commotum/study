## Introduction to Partial-Fraction Setup for Inverse Transforms

In this section, the setup move is the core target. Before inverse-transform calculation begins, rewrite a proper rational function $X(s)$ into a sum of simpler terms that each match a known one-sided inverse Laplace template.

Start by reading the denominator structure. For a proper rational expression, the first action is to factor the denominator into linear factors, because that defines the denominator shapes that the template must match.

$$
X(s)=\frac{3}{s(s+2)}=\frac{A}{s}+\frac{B}{s+2}
$$

This is the setup form for the base case. You do not solve for $A$ and $B$ yet; you first anchor the decomposition template so each term is already in a known inverse-able shape.

$$
N(s)=A(s+2)+B(s)
$$

For repeated factors, the same setup logic applies, but the template expands: use two separate numerators tied to $\frac{A}{s+\alpha}$ and $\frac{B}{(s+\alpha)^2}$. Coefficient solving comes after this structural form is fixed.

$$
X(s)=\frac{N(s)}{(s+\alpha)^2}=\frac{A}{s+\alpha}+\frac{B}{(s+\alpha)^2}
$$

## Setting Up Terms for Distinct Linear Factors

**Example:** Set up the partial-fraction form for $\frac{3s+5}{s(s+2)}$.

**Explanation**

The cue is the denominator factorization: $s(s+2)$ gives two distinct linear factors, so the action is to attach one constant numerator to each factor.

Write the decomposition template directly before solving, using unknown constants $A$ and $B$. This creates a form that is already aligned with inverse-transform pair templates.

$$
\frac{3s+5}{s(s+2)}=\frac{A}{s}+\frac{B}{s+2}
$$

To get the coefficient identity, multiply both sides by the common denominator $s(s+2)$ so the equation is written only in numerators.

$$
3s+5 = A(s+2)+Bs
$$

Grouping by powers gives $3s+5 = (A+B)s+2A$, so the next step will solve $A$ and $B$ when coefficients are matched. For this section, stop at this symbolic identity.

## Factoring the Denominator Before Setting Up Terms

**Example:** Set up the partial-fraction form for $\frac{2s^2+8s+3}{s^2+3s-4}$.

**Explanation**

The target is still a partial-fraction setup, but now the cue is an unfactored denominator in the target rational function. The first action is always to factor before assigning any numerator symbols.

Factor the quadratic denominator into distinct linear factors: $s^2+3s-4=(s+4)(s-1)$. This step defines the allowed templates.

$$
s^2+3s-4=(s+4)(s-1)
$$

With factors in hand, attach one constant to each denominator factor and write the setup template.

$$
\frac{2s^2+8s+3}{s^2+3s-4}=\frac{2s^2+8s+3}{(s+4)(s-1)}=\frac{A}{s+4}+\frac{B}{s-1}
$$

Multiply by the common denominator to produce the numerator identity and keep the setup symbolic.

$$
2s^2+8s+3=A(s-1)+B(s+4)
$$

This section ends with that identity. Solving for $A$ and $B$ is the next stage; here we keep the result as a reusable template generated from a factored denominator.

## Setting Up Terms for Repeated Linear Factors

**Example:** Set up the partial-fraction form for $\frac{2s+1}{(s+1)^2(s+3)}$.

**Explanation**

The cue is now repeated roots in the denominator. First identify multiplicity: one repeated factor $(s+1)^2$ and one distinct factor $(s+3)$.

Use the repeated-factor rule: give one constant numerator for each multiplicity level, so this denominator requires $\frac{A}{s+1}+\frac{B}{(s+1)^2}$, plus one term for $(s+3)$.

$$
\frac{2s+1}{(s+1)^2(s+3)}=\frac{A}{s+1}+\frac{B}{(s+1)^2}+\frac{C}{s+3}
$$

Multiply through by $(s+1)^2(s+3)$ to obtain the numerator identity from which coefficients will be solved later.

$$
2s+1 = A(s+1)(s+3)+B(s+3)+C(s+1)^2
$$

Keep this symbolic setup; coefficient matching is deferred to the next step, but this hierarchy $A$, $B$, and $C$ is now complete and aligned with inverse-transform templates.

## Setting Up a Mixed Partial-Fraction Expansion

**Example:** Set up the partial-fraction form for $\frac{7s^2+2s+1}{(s-1)(s+2)^2(s+5)}$.

**Explanation**

The denominator has one distinct factor and one repeated factor: $(s-1)$, $(s+2)^2$, and $(s+5)$. The cue is to build one layer of terms for each distinct root and one layer per repeated power.

Choose constants for each slot in the full structure: one for $(s-1)$, one for $(s+2)$ and one for $(s+2)^2$, then one for $(s+5)$.

$$
\frac{7s^2+2s+1}{(s-1)(s+2)^2(s+5)} = \frac{A}{s-1}+\frac{B}{s+2}+\frac{C}{(s+2)^2}+\frac{D}{s+5}
$$

Clear the denominator by multiplying through with $(s-1)(s+2)^2(s+5)$ to move to a numerator identity in $s$. 

$$
7s^2+2s+1=A(s+2)^2(s+5)+B(s-1)(s+2)(s+5)+C(s-1)(s+5)+D(s-1)(s+2)^2
$$

This is the complete mixed template for this topic branch. Hold this symbolic form and solve $A,B,C,D$ in the next step.
