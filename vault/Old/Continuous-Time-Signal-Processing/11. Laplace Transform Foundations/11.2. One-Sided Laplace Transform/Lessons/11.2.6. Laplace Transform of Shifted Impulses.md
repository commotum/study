## Introduction to Laplace Transform of Shifted Impulses

The shifted-impulse lesson starts from a fixed rule: for one-sided Laplace work, first test whether the signal event lies in the interval $0^- \le t < \infty$, then apply the sifting rule with that support check.

Every one-sided transform begins with the definition

$$
\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty} x(t)e^{-st}\,dt
$$

Now use the same definition with $x(t)=A\delta(t-T)$. The impulse contributes only at the single time $t=T$, so evaluate the integrand there. This gives $\mathcal{L}\{A\delta(t-T)\}=A e^{-sT}$ when $T$ is inside the one-sided interval.

$$
\mathcal{L}\{A\delta(t-T)\}=\int_{0^-}^{\infty} A\delta(t-T)e^{-st}\,dt=\begin{cases}Ae^{-sT}, & T\ge 0, \\ 0, & T<0.\end{cases}
$$

Use this as a two-step execution check in every example: identify $T$, verify whether it satisfies $T\ge 0$, then write $Ae^{-sT}$ with the same amplitude and exponential term from the impulse location.

## Transforming a Shifted Impulse Inside the One-Sided Interval

**Example:** Compute $\mathcal{L}\{3\delta(t-2)\}$.

**Explanation**

Use the cue that this is a shifted impulse in the form $A\delta(t-T)$, then identify the parameters directly: $A=3$ and $T=2$.

Start from the one-sided definition for the input signal

$$
\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty} x(t)e^{-st}\,dt
$$

Substitute $x(t)=3\delta(t-2)$ and keep the same lower limit.

$$
\mathcal{L}\{3\delta(t-2)\}=\int_{0^-}^{\infty}3\delta(t-2)e^{-st}\,dt
$$

Apply sifting at $t=2$: the impulse picks the integrand at $t=2$, giving $3e^{-2s}$. Since $2\ge 0$, the impulse is inside the one-sided interval and the result is kept.

$$
\mathcal{L}\{3\delta(t-2)\}=3e^{-2s},\quad (T=2\ge0)
$$

So the final transform is $3e^{-2s}$, with the amplitude and shift preserved from the original impulse.

## Including Amplitude in a Shifted Impulse Transform

**Example:** Compute $\mathcal{L}\{-\frac{5}{2}\delta(t-3)\}$.

**Explanation**

This is the same shifted-impulse cue as before, but now the new wrinkle is a signed fractional amplitude: $x(t)=-\frac{5}{2}\delta(t-3)$. The rule is still $A\delta(t-T)\to Ae^{-sT}$ with $T\ge 0$.

Write the one-sided definition for this signal first.

$$
\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty} x(t)e^{-st}\,dt
$$

Substitute $x(t)=-\frac{5}{2}\delta(t-3)$ into the definition.

$$
\mathcal{L}\{-\tfrac{5}{2}\delta(t-3)\}=\int_{0^-}^{\infty}-\tfrac{5}{2}\delta(t-3)e^{-st}\,dt
$$

Apply sifting at $t=3$. The scalar amplitude is preserved and multiplies the kernel value, so $e^{-s(3)}$ is attached to $-\frac{5}{2}$. Check the support rule: $T=3\ge 0$, so this term is included.

$$
\mathcal{L}\{-\frac{5}{2}\delta(t-3)\}=-\frac{5}{2}e^{-3s}
$$

The final transform is $-\frac{5}{2}e^{-3s}$, with the coefficient and sign carried unchanged from the time-domain impulse.

## Handling an Impulse at the Origin with the $0^-$ Convention

**Example:** Compute $\mathcal{L}\{2\delta(t)\}$ and explain why the $0^-$ limit includes it.

**Explanation**

This is the boundary version of the shifted-impulse rule: identify the form $A\delta(t-T)$ with $A=2$ and $T=0$, then check inclusion using the one-sided limit.

Start from the one-sided Laplace definition.

$$
\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty}x(t)e^{-st}\,dt
$$

Substitute $x(t)=2\delta(t)$ into that definition.

$$
\mathcal{L}\{2\delta(t)\}=\int_{0^-}^{\infty}2\delta(t)e^{-st}\,dt
$$

Apply sifting at $t=0$, so the value becomes $2e^{-s\cdot 0}=2$. The $0^-$ notation explicitly includes the impulse at the origin; this is not excluded by a strict open boundary at $0$.

$$
\mathcal{L}\{2\delta(t)\}=2
$$

So the final result is $2$, and the transform is nonzero because the $0^-$ convention keeps origin impulses in the integration interval.

<a id="recognizing-shifted-impulses-outside-the-one-sided-interval"></a>
## Recognizing Shifted Impulses Outside the One-Sided Interval

**Example:** Compute $\mathcal{L}\{3\delta(t+1)\}$.

**Explanation**

The signal still matches the shifted-impulse cue, now with a negative shift: $x(t)=3\delta(t+1)=3\delta(t-(-1))$. The coefficient is $A=3$ and the support point is $T=-1$.

Start from the one-sided definition used in all prior examples.

$$
\mathcal{L}\{x(t)\}=\int_{0^-}^{\infty} x(t)e^{-st}\,dt
$$

Substitute the signal into that definition.

$$
\mathcal{L}\{3\delta(t+1)\}=\int_{0^-}^{\infty}3\delta(t+1)e^{-st}\,dt=\int_{0^-}^{\infty}3\delta(t-(-1))e^{-st}\,dt
$$

Apply sifting at $t=-1$, which gives a candidate $3e^{-s(-1)}=3e^{s}$, but then apply the interval rule first: $T=-1\ge 0$ is false.

Because the impulse support is outside the one-sided interval $[0^-,\infty)$, the weighted integral contributes nothing.

$$
\mathcal{L}\{3\delta(t+1)\}=0
$$

So the final answer is $0$, which distinguishes this edge case from the positive-shift examples where the same rule gives a nonzero exponential result.
