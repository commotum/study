## 1. Interference Foundations

1. [ ] [Reading Path Difference from a Double-Slit Pattern](<../../M6/2026-08-05-M6-1/Lessons/Problem-3.md>) — **Core M6 form:** classify a marked fringe, count its order from the central maximum, and translate that order into a whole- or half-integer path difference.
2. [ ] [Predicting Changes in Double-Slit Fringe Spacing](<../../M6/2026-08-09-HW-9/Lessons/Problem-4.md>) — **High-yield conceptual form:** use $\Delta y\approx\lambda L/d$ and $v=f\lambda$ to predict how wavelength, frequency, screen distance, and slit separation change the pattern.

## 2. Double-Slit Measurement

3. [ ] [Finding Wavelength From a Double-Slit Intensity Graph](<../../M6/2026-08-05-M6-1/Lessons/Problem-4.md>) — **Written-problem candidate:** read peak-to-peak spacing from a graph, convert all lengths consistently, and solve $\lambda=\Delta y\,d/L$.

## 3. Diffraction Gratings

4. [ ] [Finding Wavelength from a Diffraction-Grating Pattern](<../../M6/2026-08-05-M6-1/Lessons/Problem-5.md>) — **Written-problem candidate:** turn screen position into an exact angle and use $d\sin\theta=m\lambda$ without forcing a small-angle shortcut.
5. [ ] [Finding Diffraction-Grating Line Density from Symmetric Fringes](<../../M6/2026-08-06-M6-2/Lessons/Problem-2.md>) — **Distinct grating form:** halve an opposite-order fringe separation, find the angle, and convert reciprocal slit spacing into lines per millimeter.
6. [ ] [Counting Visible Diffraction-Grating Maxima on a Finite Screen](<../../M6/2026-08-06-M6-2/Lessons/Problem-3.md>) — **Constraint-and-counting form:** combine the physical order bound with the screen-edge bound, round down, and count symmetric orders including $m=0$.

## 4. Single-Slit Diffraction

7. [ ] [Finding Slit Width from Adjacent Single-Slit Minima](<../../M6/2026-08-06-M6-2/Lessons/Problem-1.md>) — **Core single-slit form:** turn adjacent dark-minimum spacing into $a\approx\lambda L/\Delta y$ while keeping the full central width separate.
8. [ ] [Finding Slit Width from the Central Diffraction Maximum](<../../M6/2026-08-09-HW-9/Lessons/Problem-2.md>) — **Factor-of-two safeguard:** use $W_{\mathrm{central}}\approx2\lambda L/a$ and distinguish the full central width from the one-sided first-minimum distance.
