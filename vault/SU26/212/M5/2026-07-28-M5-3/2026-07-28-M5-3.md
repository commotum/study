## Problem 1

```quiz
type: blank
id: m5-3pre-q1
require_exact: true
content: |-
  **Question 1**

  You are $2.5\ \mathrm{m}$ from a speaker and measure a sound intensity of $280\ \mathrm{W/m^2}$. At a new location, you measure an intensity of $160\ \mathrm{W/m^2}$. How far are you from the speaker at the new location?

  Enter the distance in meters as a number only: ==3.3==
feedback: |-
  Sound intensity follows the inverse-square law:

  $$
  I_1r_1^2=I_2r_2^2.
  $$

  Therefore,

  $$
  r_2=r_1\sqrt{\frac{I_1}{I_2}}
  =(2.5\ \mathrm{m})\sqrt{\frac{280}{160}}
  =3.307\ldots\ \mathrm{m}.
  $$

  The givens support two significant figures, so $r_2=3.3\ \mathrm{m}$.
```

  Enter the intensity in watts per square meter as a number only: ==60==

  $$
  I_2=I_1\left(\frac{r_1}{r_2}\right)^2
  =(240\ \mathrm{W/m^2})\left(\frac{12}{24}\right)^2
  =60\ \mathrm{W/m^2}.
  $$

## Problem 4

```quiz
type: blank
id: m5-3lec-q3
require_exact: true
content: |-
  **Question 3**

  The sound intensity level of a normal conversation is about $60\ \mathrm{dB}$. What is the sound intensity level if two people are talking independently at that level?

  Enter the intensity level in decibels as a number only: ==63==
feedback: |-
  Two equally loud independent sources double the intensity, so

  $$
  \beta_2=\beta_1+10\log_{10}(2)
  =60\ \mathrm{dB}+3.010\ldots\ \mathrm{dB}
  \approx63\ \mathrm{dB}.
  $$

  Decibel levels do not add directly, so the result is not $120\ \mathrm{dB}$.
```

## Problem 5

```quiz
type: blank
id: m5-3lec-q4
require_exact: true
content: |-
  **Question 4**

  A singer produces an $880\ \mathrm{Hz}$ note. A bat flies toward the singer at $35\ \mathrm{m/s}$. What frequency does the bat hear? Use $343\ \mathrm{m/s}$ for the speed of sound.

  Enter the frequency in hertz as a number only: ==970==
feedback: |-
  The bat is a moving observer approaching a stationary source:

  $$
  f'=f\left(\frac{v+v_o}{v}\right)
  =(880\ \mathrm{Hz})\left(\frac{343+35}{343}\right)
  =969.8\ldots\ \mathrm{Hz}.
  $$

  The limiting measured speed has two significant figures, so the result is $9.7\times10^2\ \mathrm{Hz}$, entered as `970`.
```

## Problem 7

```quiz
type: blank
id: m5-3lec-q6
require_exact: false
content: |-
  **Question 6**

  A bat chirps at $25\ \mathrm{kHz}$ while flying away from you. How fast must it fly for you to hear $20\ \mathrm{kHz}$? The source does not specify a value for the speed of sound.

  Using $343\ \mathrm{m/s}$ for the speed of sound, the bat's speed in meters per second is ==86==.
feedback: |-
  For a source moving away from a stationary observer,

  $$
  f'=f_s\frac{v}{v+v_s}.
  $$

  Solving with $v=343\ \mathrm{m/s}$ gives

  $$
  v_s=v\left(\frac{f_s}{f'}-1\right)
  =(343\ \mathrm{m/s})\left(\frac{25}{20}-1\right)
  =85.75\ \mathrm{m/s}.
  $$

  The frequencies have two significant figures, so the result is $86\ \mathrm{m/s}$. Using $340\ \mathrm{m/s}$ instead gives $85\ \mathrm{m/s}$, so exact string grading is disabled because the original prompt does not specify the sound speed.
```
