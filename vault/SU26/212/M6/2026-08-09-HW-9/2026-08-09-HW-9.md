## Problem 1

```quiz
type: radio
id: q-1
shuffle: true
content: |-
  **Question 1**

  For incident light of wavelength $\lambda$, which slit width would produce a clear single-slit diffraction pattern?
options:
- id: a
  content: |-
    $10\lambda$
  correct: true
  feedback: |-
    Single-slit minima satisfy $a\sin\theta=m\lambda$. With $a=10\lambda$, the first minimum has $\sin\theta=0.1$, so it occurs at about $5.7^\circ$. The pattern spreads enough for its central maximum and neighboring structure to be clearly resolved.
- id: b
  content: |-
    $\lambda$
  feedback: |-
    With $a=\lambda$, the first-minimum condition requires $\sin\theta=1$, placing that minimum at $90^\circ$. A forward screen therefore does not show the ordinary resolved minimum-bounded diffraction pattern requested here.
- id: c
  content: |-
    $\dfrac{\lambda}{10}$
  feedback: |-
    With $a=\lambda/10$, the first-minimum condition would require $\sin\theta=10$, which is impossible. Without a physical first minimum, the usual clear single-slit fringe pattern is not produced.
```

## Problem 2

```quiz
type: radio
id: q-2
shuffle: true
content: |-
  **Question 2**

  In a single-slit diffraction experiment, the width $W$ of the central bright maximum is $5\%$ of the distance $L$ between the slit and the screen:

  $$
  W=0.05L.
  $$

  Approximately how wide is the slit $a$, expressed in terms of the wavelength $\lambda$?
options:
- id: a
  content: |-
    $10\lambda$
  feedback: |-
    The central width is $W\approx2L\lambda/a$. Substituting $a=10\lambda$ gives $W\approx0.20L$, four times the stated width, so the slit must be wider.
- id: b
  content: |-
    $20\lambda$
  feedback: |-
    With $W\approx2L\lambda/a$, a width of $a=20\lambda$ would give $W\approx0.10L$, not the stated $0.05L$.
- id: c
  content: |-
    $25\lambda$
  feedback: |-
    Substituting $a=25\lambda$ into $W\approx2L\lambda/a$ gives $W\approx0.08L$. This central maximum is still wider than the specified $0.05L$.
- id: d
  content: |-
    $40\lambda$
  correct: true
  feedback: |-
    The first minima lie at $y_1\approx L\lambda/a$, so the full central width is $W\approx2L\lambda/a$. Setting $0.05L=2L\lambda/a$ and canceling $L$ gives $a=40\lambda$.
```

## Problem 3

```quiz
type: radio
id: q-3
shuffle: true
content: |-
  **Question 3**

  A single slit of width

  $$
  a=20\ \mu\mathrm{m}
  $$

  is illuminated separately with violet and green light:

  $$
  \lambda_v=400\ \mathrm{nm},
  \qquad
  \lambda_g=500\ \mathrm{nm}.
  $$

  A screen is located $2.0\ \mathrm{m}$ from the slit. What is the distance between the first-minimum positions for the two wavelengths, measured on the same side of the central maximum?
options:
- id: a
  content: |-
    $1\ \mathrm{cm}$
  correct: true
  feedback: |-
    The first-minimum position is $y_1\approx L\lambda/a$. Therefore $\Delta y=L(\lambda_g-\lambda_v)/a=(2.0)(100\times10^{-9})/(20\times10^{-6})=0.010\ \mathrm{m}=1.0\ \mathrm{cm}$, corresponding to the listed $1\ \mathrm{cm}$ choice.
- id: b
  content: |-
    $2\ \mathrm{cm}$
  feedback: |-
    The separation uses the wavelength difference, not twice that difference: $\Delta y=L(\lambda_g-\lambda_v)/a$. Direct substitution gives $1.0\ \mathrm{cm}$, so $2\ \mathrm{cm}$ is too large by a factor of two.
- id: c
  content: |-
    $5\ \mathrm{cm}$
  feedback: |-
    The value $5\ \mathrm{cm}$ is the approximate first-minimum position for the green light alone, $L\lambda_g/a$. The question asks for the distance between the green and violet minima, so their positions must be subtracted.
- id: d
  content: |-
    $10\ \mathrm{cm}$
  feedback: |-
    Twice the green first-minimum position would describe the approximate full central-maximum width for green light. It does not give the separation between the first minima produced by the two wavelengths.
```

## Problem 4

```quiz
type: checkbox
id: q-4
shuffle: true
content: |-
  **Question 4**

  Which changes would increase the distance between neighboring bright fringes in a double-slit interference pattern? Select all that apply.
options:
- id: a
  content: |-
    Lowering the frequency of the light
  correct: true
  feedback: |-
    In a fixed medium, lowering $f$ increases $\lambda=c/f$. Since neighboring-fringe spacing is $\Delta y\approx\lambda L/d$, the spacing increases.
- id: b
  content: |-
    Increasing the frequency of the light
  feedback: |-
    Increasing $f$ decreases $\lambda=c/f$. Because $\Delta y\approx\lambda L/d$, the bright fringes move closer together rather than farther apart.
- id: c
  content: |-
    Increasing the distance from the slits to the screen
  correct: true
  feedback: |-
    Fringe spacing is directly proportional to the screen distance: $\Delta y\approx\lambda L/d$. Increasing $L$ therefore increases the distance between neighboring bright fringes.
- id: d
  content: |-
    Increasing the separation between the slits
  feedback: |-
    Slit separation is in the denominator of $\Delta y\approx\lambda L/d$. Increasing $d$ decreases the fringe spacing, so more closely spaced fringes result.
```

## Problem 5

```quiz
type: checkbox
id: q-5
shuffle: true
content: |-
  **Question 5**

  A double-slit interference pattern is displayed on a screen of fixed width. Which changes would increase the number of bright fringes that fit on the screen? Select all that apply.
options:
- id: a
  content: |-
    Increasing the frequency of the light
  correct: true
  feedback: |-
    Increasing $f$ decreases $\lambda=c/f$ and therefore decreases $\Delta y\approx\lambda L/d$. Smaller spacing allows more bright fringes to fit across the fixed screen width.
- id: b
  content: |-
    Decreasing the frequency of the light
  feedback: |-
    Decreasing $f$ increases the wavelength and fringe spacing. Wider spacing means fewer, not more, bright fringes fit on a screen of fixed width.
- id: c
  content: |-
    Increasing the slit separation
  correct: true
  feedback: |-
    Increasing $d$ decreases $\Delta y\approx\lambda L/d$. Because the fringes are closer together, more of them fit across the fixed screen width.
- id: d
  content: |-
    Increasing the distance from the slits to the screen
  feedback: |-
    Increasing $L$ increases the fringe spacing. A fixed-width screen therefore contains fewer bright fringes, not more.
```

## Problem 6

```quiz
type: radio
id: q-6
shuffle: true
content: |-
  **Question 6**

  A double slit initially has separation $d$. Its second-order bright maximum occurs at angle $\theta$.

  The slit separation is then changed to $d'$. What must $d'$ be so that the **third dark fringe** occurs at the same angle $\theta$?
options:
- id: a
  content: |-
    $\dfrac{4d}{5}$
  feedback: |-
    This reverses the required ratio. At the shared angle, the original second bright maximum corresponds to $2\lambda$, while the third dark fringe corresponds to $5\lambda/2$. The new separation must therefore be larger, not smaller, than $d$.
- id: b
  content: |-
    $d$
  feedback: |-
    If the separation remains $d$, then the same angle still satisfies $d\sin\theta=2\lambda$, so it remains the second bright maximum rather than becoming the third dark fringe.
- id: c
  content: |-
    $\dfrac{5d}{4}$
  correct: true
  feedback: |-
    The original maximum gives $d\sin\theta=2\lambda$. The third dark fringe gives $d'\sin\theta=5\lambda/2$. Dividing the equations at the same angle yields $d'/d=(5/2)/2=5/4$, so $d'=5d/4$.
- id: d
  content: |-
    $\dfrac{3d}{2}$
  feedback: |-
    With $d'=3d/2$, the shared-angle path difference would be $d'\sin\theta=(3/2)(2\lambda)=3\lambda$. That is a third-order bright maximum, not the third dark fringe.
```

## Problem 7

```quiz
type: radio
id: q-7
shuffle: true
content: |-
  **Question 7**

  A diffraction grating has slit spacing

  $$
  d=5\lambda.
  $$

  A screen is located a distance $L$ from the grating. What is the distance $y$ from the central maximum to the third-order maximum?
options:
- id: a
  content: |-
    $\dfrac{3L}{5}$
  feedback: |-
    The grating equation gives $\sin\theta=3/5$, but the screen coordinate is $y=L\tan\theta$, not $L\sin\theta$. Thus $3L/5$ uses the wrong trigonometric projection.
- id: b
  content: |-
    $\dfrac{4L}{5}$
  feedback: |-
    From $\sin\theta=3/5$, a $3$-$4$-$5$ triangle gives $\cos\theta=4/5$. The screen displacement is not $L\cos\theta$; it is $y=L\tan\theta$.
- id: c
  content: |-
    $\dfrac{5L}{4}$
  feedback: |-
    The ratio $5/4$ is $1/\cos\theta$ for the resulting $3$-$4$-$5$ triangle. The transverse screen coordinate instead uses $\tan\theta=3/4$.
- id: d
  content: |-
    $\dfrac{3L}{4}$
  correct: true
  feedback: |-
    The third-order grating maximum satisfies $d\sin\theta=3\lambda$. With $d=5\lambda$, $\sin\theta=3/5$, so a $3$-$4$-$5$ triangle gives $\tan\theta=3/4$. Therefore $y=L\tan\theta=3L/4$.
```
