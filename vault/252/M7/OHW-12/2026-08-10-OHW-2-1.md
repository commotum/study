## Problem 1

Intersections: (y=x) and (y=4x) meet at (x=0).

[  
A=\int_0^7(4x-x),dx  
=\int_0^7 3x,dx  
=\frac{147}{2}  
]

[  
\boxed{A=\frac{147}{2}}  
]

## Problem 2

(f) and (g) intersect at (x=0), since

[  
16e^0=16=-0+16.  
]

For (0\le x\le16), (f(x)) is above (g(x)):

[  
A=\int_0^{16}\left(16e^x-(-x+16)\right),dx  
]

[  
=\left[16e^x+\frac{x^2}{2}-16x\right]_0^{16}  
=16e^{16}-144  
]

[  
\boxed{A=16e^{16}-144}  
]

## Problem 3

Solve the intersections:

[  
x=x^9  
]

[  
x(x^8-1)=0  
]

so (x=-1,0,1). There are two symmetric enclosed regions:

[  
A=2\int_0^1(x-x^9),dx  
]

[  
=2\left[\frac{x^2}{2}-\frac{x^{10}}{10}\right]_0^1  
=2\left(\frac12-\frac1{10}\right)  
=\frac45  
]

[  
\boxed{A=\frac45}  
]

## Problem 4

Find the (y)-coordinates of intersection:

[  
y^2=6+5y  
]

[  
y^2-5y-6=0  
]

[  
(y-6)(y+1)=0  
]

so (y=-1,6).

Right minus left:

[  
A=\int_{-1}^{6}\left[(6+5y)-y^2\right],dy  
]

[  
=\left[6y+\frac52y^2-\frac13y^3\right]_{-1}^{6}  
=\frac{343}{6}  
]

[  
\boxed{A=\frac{343}{6}}  
]

## Problem 5

Find intersections:

[  
y^2+3=27-2y  
]

[  
y^2+2y-24=0  
]

[  
(y+6)(y-4)=0  
]

so (y=-6,4).

Right minus left:

[  
A=\int_{-6}^{4}\left[(27-2y)-(y^2+3)\right],dy  
]

[  
=\int_{-6}^{4}(24-2y-y^2),dy  
]

[  
=\left[24y-y^2-\frac{y^3}{3}\right]_{-6}^{4}  
=\frac{500}{3}  
]

[  
\boxed{A=\frac{500}{3}}  
]

## Problem 6

The relevant intersections are:

[  
F\cap H:\quad 6-x=6\Rightarrow x=0  
]

[  
F\cap G:\quad 6-x=\ln(x-5)  
]

which occurs at (x=6), since both sides equal (0).

And

[  
G\cap H:\quad \ln(x-5)=6  
]

[  
x=5+e^6.  
]

Thus,

[  
A=\int_0^6\left[6-(6-x)\right]dx  
+\int_6^{5+e^6}\left[6-\ln(x-5)\right]dx.  
]

The first part is

[  
\int_0^6x,dx=18.  
]

For the second part, let (u=x-5):

[  
\int_1^{e^6}(6-\ln u),du  
=e^6-7.  
]

Therefore,

[  
\boxed{\text{area}=e^6+11}  
]

## Problem 7

The exponential intersects (y=1) when

[  
e^{3x}=1\Rightarrow x=0.  
]

Therefore,

[  
A=\int_0^4(e^{3x}-1),dx  
]

[  
=\left[\frac13e^{3x}-x\right]_0^4  
]

[  
=\frac{e^{12}-1}{3}-4  
=\frac{e^{12}-13}{3}.  
]

[  
\boxed{\text{area}=\frac{e^{12}-13}{3}}  
]
