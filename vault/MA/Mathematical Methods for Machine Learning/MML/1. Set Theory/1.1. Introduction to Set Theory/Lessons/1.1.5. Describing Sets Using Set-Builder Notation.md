## Introduction

As previously seen, we can define sets using so-called *constructive definitions* of the form

$$
\big\{{\color{blue}\textrm{rule}} \:: \: {\color{blue}\textrm{base set}} \big\}
$$

where the ${\color{blue}\textrm{rule}}$ is an expression (or formula) that depends on a variable that *constructs* elements of our set when the variable runs over some ${\color{blue}\textrm{base set}}$.

For example, the set $A$, given by

$$
A = \big\{2n+1\,: \, n\in\mathbb N_0 \big \}
$$

is defined constructively and contains all positive odd numbers:

$$
\begin{aligned}
A &= {2n + 1: n ∈ N_{0}} \\
&= {2(0) + 1, 2(1) + 1, 2(2) + 1, 2(3) + 1, …} \\
&= {1, 3, 5, 7, …}
\end{aligned}
$$

Sometimes, it's helpful to write a set using a constructive definition. For example, how might we express the following set constructively?

$$
B = \big\{4, 7, 10, 13, \ldots \big\}
$$

First, notice that the elements of our set
$4,\quad 7,\quad 10,\quad 13,\quad \ldots$
form an arithmetic sequence with common difference $d=3{:}$

$$
\begin{aligned}
d &= 3 \\
&= 7 - 4 \\
&= 10 - 7 \\
&= 13 - 10 \\
&=⋮
\end{aligned}
$$

So, the $n$th term $a_n$ of our sequence for $n\in\mathbb N$ is given by

$$
\begin{aligned}
a_{n} &= a_{1} + (n - 1) \cdot d \\
&= 4 + (n - 1) \cdot 3 \\
&= 4 + 3n - 3 \\
&= 3n + 1
\end{aligned}
$$

Therefore, we can define our set constructively as follows:

$$
B = \big\{3n+1 \:: \: n \in \mathbb{N} \big\}
$$

The expression $3n+1$ generates the elements of our set when $n$ runs over $\mathbb{N}$.

Note the following:

- A bar "$\mid$" is just as acceptable as a colon to separate the rule from the base set. So, we could also express our set as follows:
$B=\big\{3n+1 \: \mid \: n \in \mathbb{N} \big\}$
- The constructive definition of a given set is typically not unique. For example, we could also define $B$ as follows:
$B=\big\{3n+4 \::\: n \in \mathbb{N}_0 \big\}$
Notice that we used $\mathbb N_0$ as the base set.This definition does indeed generate all elements of $B{:}$
${3n + 4: n ∈ N_{0}}|= {3(0) + 4, 3(1) + 4, 3(2) + 4, 3(3) + 4, …}; = {4, 7, 10, 13, …}; = B$.

## Expressing a Given Set Using an Arithmetic Sequence

**Example:** Describe the set $S=\{..., -5, -3, -1, 1, 3,...\}$ using a constructive definition.

*Hint: Take $a_1 = 1$ in the sequence that generates the elements of $S$.*

**Explanation**

Notice that the elements of our set
$\ldots, \quad -5, \quad -3, \quad -1, \quad 1, \quad 3, \quad \ldots$
form a two-way infinite arithmetic sequence with common difference $d=2{:}$

$$
\begin{aligned}
d &= 2 \\
&=-3 - (-5) \\
&=-1 - (-3) \\
&= 1 - (-1) \\
&= ⋯
\end{aligned}
$$

Therefore, setting $a_1=1$, the $n$th term $a_n$ of our sequence for $n\in\mathbb{Z}$ is given by

$$
\begin{aligned}
a_{n} &= a_{1} + (n - 1) \cdot d \\
&= 1 + (n - 1) \cdot 2 \\
&= 1 + 2n - 2 \\
&= 2n - 1
\end{aligned}
$$

Therefore, we can define our set using a constructive definition as follows:

$$
S = \big\{2n-1 \:: \: n \in \mathbb{Z}\big\}
$$

**Watch Out!**

The constructive definition of a set is typically not unique.

Since the elements of $A$ are generated by a *two-way* infinite arithmetic sequence, we could have picked *any* term in our sequence as $a_1$ when determining $a_n$. We selected $a_1 = 1$ because this led to a nice, simple expression in our constructive definition.

## Expressing a Given Set Using a Geometric Sequence

**Example:** Describe the set $S=\left\{\ldots, -36, -6, -1, -\dfrac1{6}, -\dfrac1{36},...\right\}$ using a constructive definition.

*Hint: Take $a_1 = -\dfrac16$ in the sequence that generates the elements of $S$.*

**Explanation**

Notice that the elements of our set

$$
\ldots,\quad -36, \quad -6, \quad -1, \quad -\dfrac1{6}, \quad -\dfrac1{36}, \quad \ldots
$$

form a two-way infinite geometric sequence with a common ratio

$$
r=\dfrac16{:}
$$

$$
\begin{aligned}
r &= \frac{1}{6} \\
&= (\frac{-6}{-36}) \\
&= (\frac{-1}{-6}) \\
&= ((-\frac{1}{6}))/((-1)) \\
&= ⋯
\end{aligned}
$$

Therefore, setting

$$
a_1=-\dfrac16
$$

the $n$th term $a_n$ of our sequence for $n\in\mathbb{Z}$ is given by

$$
\begin{aligned}
a_{n} &= a_{1} \cdot r^{n - 1} \\
&= (-\frac{1}{6}) \cdot (\frac{1}{6})^{n - 1} \\
&= - (\frac{1}{6}) \cdot (\frac{1}{6})^{-1} \cdot (\frac{1}{6})^{n} \\
&= - (\frac{1}{6})^{n}
\end{aligned}
$$

Therefore, we can define our set using a constructive definition as follows:

$$
S = \left\{-\left(\dfrac16\right)^{n} \:: \: n\in \mathbb{Z}\right\}
$$

## Conditional Definitions of Sets

We can also define sets using so-called *conditional definitions* of the form

$$
\{{\color{blue}\textrm{base set}} \:: \: {\color{blue}\textrm{conditions}} \}
$$

where our set contains only those elements of the ${\color{blue}\textrm{base set}}$ that satisfy the given ${\color{blue}\textrm{conditions}}$ (or restrictions).

For example, the set $A$, given by

$$
A = \{n\in \mathbb Z \::\: -2\leq n\leq 2\}
$$

is defined conditionally and contains all integers between $-2$ and $2$ inclusive:

$$
A = \{-2,-1,0,1,2\}
$$

It's often helpful to describe sets using conditional definitions. For example, let's rewrite the following set using a conditional definition.

$$
S = \big\{50,51,52,53,\ldots\big\}
$$

The set $S$ contains all natural numbers greater than or equal to $50$, which we can write as follows:

$$
S = \{n\in \mathbb N \::\: n\geq 50\}
$$

The conditional definition of a set is not unique. We can write down an equivalent definition of $S$ as follows:

$$
S = \{n\in \mathbb N \::\: n\gt 49\}
$$

Under this definition, $S$ contains all natural numbers greater than $49$, *excluding* $49$.

Although $\mathbb N$ is the most natural base set in this instance, we can also define $S$ using the set of integers $\mathbb Z$ as the base set. For example,

$$
S = \{n\in \mathbb Z \::\: n\geq 50\}
$$

## Expressing a Set Using a Conditional Definition

**Example:** Describe the set $S = \{-9,-8,-7,..., 5\}$ using a conditional definition.

**Explanation**

The set $S$ contains all integer numbers between $-9$ and $5$ (including $-9$ and $5$).

Therefore, the set can be written as

$$
S = \{x \in \bbox[2pt,Gainsboro]{\color{blue}\mathbb Z} \:: \: \bbox[2pt,Gainsboro]{\color{blue}-9} \leq x \leq \bbox[2pt,Gainsboro]{\color{blue}5} \}
$$

**Note**: This definition is not unique. For example, we can write $S$ equivalently as follows:

$$
S = \big\{x \in \mathbb Z \:: \: -10 \lt x \lt 6 \big\}
$$

## Defining a Set Conditionally Using the Roots of a Polynomial

**Example:** Find the missing coefficients $p$ and $q$ in the constructive definition of the set given below.

$\{\pm 3\textrm{i}\} = \Big\{z \in \mathbb{C} \:: \: 4z^2+pz+q = 0 \Big\}$

**Explanation**

The given set contains the roots $z\in\mathbb C$ of some quadratic polynomial $f(z)$.

Since the quadratic polynomial has roots

$$
z_1=-3\textrm{i}
$$

and

$$
z_2=3\textrm{i}
$$

and the coefficient of the quadratic term is $a=4$, we can write the polynomial as follows:

$$
\begin{aligned}
f(z) &= a(z - z_{1})(z - z_{2}) \\
&= 4 \cdot (z - (-3\textrm{i}))(z - (3\textrm{i})) \\
&= 4 \cdot (z + 3\textrm{i})(z - 3\textrm{i}) \\
&= 4 \cdot (z^{2} - (3\textrm{i})^{2}) \\
&= 4 \cdot (z^{2} - 9\textrm{i}^{2}) \\
&= 4 \cdot (z^{2} + 9) \\
&= 4z^{2} + 36
\end{aligned}
$$

Therefore, we can express the given set as follows:

$$
\{\pm 3\textrm{i}\} = \Big\{z \in \mathbb{C} \:: \: 4z^2+\bbox[2pt,Gainsboro]{\color{blue}0}z+\bbox[2pt,Gainsboro]{\color{blue}36} = 0 \Big\}
$$

Finally, $p=0$ and $q=36$.
