## Introduction

Let's plot the graph of

$$
y= \mid x \mid
$$

. According to the algebraic definition of absolute value, we have

$$
{x\begin{vmatrix}forx \ge 0 \\ -x\end{vmatrix}forx < 0
$$

So, the left-hand branch of the graph is the function $y=-x$, and the right-hand branch is $y=x$:

![](<../Source/9.1.7. Absolute Value Graphs/Images/074038cf6c69b003e74094c238b75e3a.png>)

Notice that the graph has a sharp corner at $(0,0)$. We call this point the **vertex** or the **minimum point.**

We can apply **horizontal** and **vertical translations** to the graph of

$$
y= \mid x \mid
$$

.

- The graph of $y= \mid x \mid +a$ is a **vertical translation** of the absolute value graph $y= \mid x \mid$. It moves the graph $a$ units up.![](<../Source/9.1.7. Absolute Value Graphs/Images/7e51a5a636c9c5796b272c68e44d0cfe.png>)
- The graph of $y= \mid x-a \mid$ is a **horizontal translation** of the absolute value graph $y= \mid x \mid$. It moves the graph $a$ units to the *right*.![](<../Source/9.1.7. Absolute Value Graphs/Images/dbf86889e09cdfe984128942db0894c5.png>)

Note the following:

- When drawing horizontal and vertical translations, it is easiest to transform the graph's vertex first. Then, the two branches can be drawn coming out of the vertex.
- When we translate the graph $y= \mid x \mid$, the resulting curve is called the **image** of $y = \mid x \mid$ under the translation.

<a id="graphing-a-vertical-translation"></a>
## Graphing a Vertical Translation

**Example:** Sketch the graph of $y= \mid x \mid -3$.

**Explanation**

Remember that

$$
y= \mid x \mid +a
$$

is a vertical translation of the absolute value graph

$$
y= \mid x \mid
$$

by $a$ units up.

The function

$$
y= \mid x \mid -3
$$

has $a=-3$. Therefore, it is a vertical translation of the absolute value graph

$$
y= \mid x \mid
$$

by $3$ units *down*.

![](<../Source/9.1.7. Absolute Value Graphs/Images/81b16fb84beae30727ed2e8aa3f44bc7.png>)

<a id="graphing-a-horizontal-translation"></a>
## Graphing a Horizontal Translation

**Example:** Sketch the graph of $y= \mid x-3 \mid$.

**Explanation**

Remember that

$$
y= \mid x-a \mid
$$

is a horizontal translation of the absolute value graph

$$
y= \mid x \mid
$$

by $a$ units right.

The function

$$
y= \mid x-3 \mid
$$

has $a=3$. Therefore, it is a horizontal translation of the absolute value graph

$$
y= \mid x \mid
$$

by $3$ units right.

![](<../Source/9.1.7. Absolute Value Graphs/Images/9ded8561b4dba967f3137388e96e674f.png>)

**Watch Out!** It's easy to confuse the translations

$$
y= \mid x-3 \mid
$$

and

$$
y= \mid x+3 \mid
$$

. The graph of

$$
y= \mid x-3 \mid
$$

is shifted to the right and the graph of

$$
y= \mid x+3 \mid
$$

is shifted to the left, even though it seems like it should be the other way around.

<a id="combining-translations"></a>
## Combining Translations

Horizontal and vertical translations can be combined. It does not matter which we do first.

In general, the graph of

$$
y= \mid x-h \mid +k
$$

is a translation of the graph

$$
y= \mid x \mid
$$

by

- $h$ units right, and
- $k$ units up.

---

<a id="combining-horizontal-and-vertical-translations"></a>
## Combining Horizontal and Vertical Translations

**Example:** Sketch the graph of $y= \mid x+1 \mid +2$.

**Explanation**

Remember that

$$
y= \mid x-h \mid +k
$$

is a translation of the absolute value graph

$$
y= \mid x \mid
$$

by $h$ units right and $k$ units up.

The function

$$
y= \mid x+1 \mid +2
$$

has $h=-1$ and $k=2$. Therefore, it is a translation of the absolute value graph

$$
y= \mid x \mid
$$

by $1$ unit *left* and $2$ units up.

![](<../Source/9.1.7. Absolute Value Graphs/Images/24e2e66e933afb2307f905556bc9c109.png>)
