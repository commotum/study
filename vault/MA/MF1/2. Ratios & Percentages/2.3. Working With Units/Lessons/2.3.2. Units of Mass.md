## Introduction

**Measuring** means finding a number that describes the size of something.

The **mass** of an object measures how much "stuff" (or **matter**) an object contains. The mass of an object is connected to its weight. We use **mass units** to specify an object's mass.

The most popular measurement system within the scientific community is the **metric system**. Within the metric system, the most common units of measurement are called **base units**.

The base unit of mass is the **gram,** which we denote using the symbol "$\textrm{g}$." The object below has a mass of exactly $1\,\textrm g$.

![](<../Source/2.3.2. Units of Mass/Images/7a8f788f163c2a237482b2aca5882152.png>)

We can measure the mass of an object using **weighing scales.** To measure an object's mass, we first place it on one side of the weighing scales. Then, we put $1\,\textrm g$ masses on the other side until the scales balance perfectly.

![](<../Source/2.3.2. Units of Mass/Images/1d0f5f5217486c460ed856471f9d9ffc.png>)

In this example, we have an object on the left scale and sixteen $1\,\textrm g$ masses on the right scale. Since the scales are perfectly balanced, the object's mass is $16\,\textrm g$.

It's convenient to define new units of measurement from the base unit. The most common variations for mass units are shown below:

| Name | Symbol | Conversion |
| --- | ---: | ---: |
| Kilogram | $\textrm{kg}$ | $1\,\textrm{kg} = 1\,000\,\textrm{g}$ |
| Gram | $\textrm{g}$ | Base Unit |
| Milligram | $\textrm{mg}$ | $1\,000\,\textrm{mg} = 1\,\textrm{g}$ |

Let's give some examples of each unit, going from the largest (or "heaviest") unit $(\textrm{kg})$ to the smallest (or "lightest") unit $(\textrm{mg})$:

- A regular bag of sugar has a mass of around $1\,\textrm{kg}$.
- A single postage stamp has a mass of around $1\,\textrm g$.
- A single grain of sand has a mass of around $50\,\textrm{mg}$.

**Important**: Each metric symbol for mass ends in "$\textrm{g}$", the base unit.

<a id="the-prefix-system-for-metric-units"></a>
## The Prefix System for Metric Units

Let's recall the table that relates metric units of mass.

| Name | Symbol | Conversion |
| --- | ---: | ---: |
| Kilogram | $\textrm{kg}$ | $1\,\textrm{kg} = 1\,000\,\textrm{g}$ |
| Gram | $\textrm{g}$ | Base Unit |
| Milligram | $\textrm{mg}$ | $1\,000\,\textrm{mg} = 1\,\textrm{g}$ |

**Important**: Symbols in the metric system follow a consistent set of **prefix rules**, which we explain below. If you find these difficult, *do not worry*! For now, you just need to remember the conversions shown in the table above.

The prefix rules are as follows:

- The prefix "$\textrm k$" stands for **kilo**, which means $1\,000$. Therefore, $1\,\textrm{kg} = 1\,000\,\textrm{g}$.
- The prefix "$\textrm m$" stands for **milli**, which means $\dfrac{1}{1,000}$. Therefore, $1\,\textrm{mg}=\dfrac{1}{1\,000}\,\textrm{g}$. Notice that if we add $1\,\textrm{mg}$ to itself $1\,000$ times, we get exactly $1\,\textrm{g}{:}$
$1mg + 1mg + ⋯ + 1mg^(⏞)^(1000times)|=; \frac{1}{1000}g + \frac{1}{1000}g + ⋯ + \frac{1}{1000}g|=; 1000 \cdot \frac{1}{1000}g|=; \frac{1000 \cdot 1}{1000}g|=; \frac{1000}{1000}g|=; 1g$
Therefore, $1\,000\,\textrm{mg}$ equals $1\,\textrm{g}$, as stated in the table.

<a id="stating-mass-conversions-in-metric-units"></a>
## Stating Mass Conversions in Metric Units

**Example:** A melon has a mass of $1\,\textrm{kg}$. What is this mass in grams?

**Explanation**

A table showing the metric units of mass is given below.

| Name | Symbol | Conversion |
| --- | ---: | ---: |
| Kilogram | $\textrm{kg}$ | $1\,\textrm{kg} = 1\,000\,\textrm{g}$ |
| Gram | $\textrm{g}$ | Base Unit |
| Milligram | $\textrm{mg}$ | $1\,000\,\textrm{mg} = 1\,\textrm{g}$ |

So, $1\,\textrm{kg}$ is equivalent to $1\,000\,\textrm{g}$.

## Customary Units of Mass

Another way to measure mass is to use **customary units**. The most common customary units of mass are **ounce**, **pound**, and **ton**.

A table showing some of the most common customary mass units is shown below.

| Name | Symbol | Conversion |
| --- | ---: | ---: |
| Ton | $\textrm{ton}$ | $1\,\textrm{ton} = 2,000\,\textrm{lb}$ |
| Pound | $\textrm{lb}$ | $1\,\textrm{lb} = 16\,\textrm{oz}$ |
| Ounce | $\textrm{oz}$ | $-$ |

Let's give some examples of each unit, going from the largest unit $(\textrm{ton})$ to the smallest $(\textrm{oz})$:

- A small car could have a mass of around $1\,\textrm{ton}$.
- A small bag of rice has a mass of around $1\,\textrm{lb}$.
- A single slice of bread could have a mass of around $1\,\textrm{oz}$.

Customary units are not standard in the scientific community. However, they are commonly used in the United States and other countries.
