## Introduction

In a previous lesson, we studied some rules for determining if an integer is divisible by $2,5,10,4$, and $8$. In this lesson, we'll extend our understanding of divisibility rules to include $3,9,6$, and $7$.

We have the following rule for determining if a number is divisible by $3{:}$

> *A number is divisible by $3$ if the sum of its digits is divisible by $3$.*

For example, let's determine if the following number is divisible by $3{:}$

$312\,561$
If we sum the digits, we get

$$
3+1+2+5+6+1 = 18
$$

Now, since $18$ is divisible by $3$, we conclude that $312\,561$ is divisible by $3$.

The rule for determining if a number is divisible by $9$ is similar:

> *A number is divisible by $9$ if the sum of its digits is divisible by $9$.*

Let's see another example.

---

<a id="determining-if-a-number-is-divisible-by-3-or-9"></a>
## Determining if a Number Is Divisible by 3 or 9

**Example:** Which of the following numbers are divisible by $3$ and $9$?

1. $176\,850$
2. $1\,362\,448$
3. $68\,543\,031$

**Explanation**

A number is divisible by $3$ if the sum of its digits is divisible by $3$. Likewise, a number is divisible by $9$ if the sum of its digits is divisible by $9$.

- The sum of the digits of $176\,850$ is
$1+7+6+8+5+0 = 27$,
which is divisible by both $3$ and $9$. So, $176\,850$ is divisible by both $3$ and $9$.
- The sum of the digits of $1\,362\,448$ is
$1+3+6+2+4+4+8 = 28$,
which is *not* divisible by $3$. So, $1\,362\,448$ is *not* divisible by $3$. Also, since it is not divisible by $3$, it cannot be divisible by $9$ either.
- The sum of the digits of $68\,543\,031$ is
$6+8+5+4+3+0+3+1 = 30$,
which is divisible by $3$, but not divisible $9$. So, $68\,543\,032$ is divisible by $3$, but it is not divisible by $9$.

Therefore, only I is divisible by $3$ and $9$.

## Divisibility by 6

We have the following rule for determining if a number is divisible by $6{:}$

> *A number is divisible by $6$ if it is divisible by both $2$ and $3$.*

For example, let's determine if the following number is divisible by $6{:}$

$$
353,856
$$

To check whether this number is divisible by $6$, we need to check that it's divisible by *both* $2$ *and* $3{:}$

- Notice that the last digit of $353,85{\color{blue}{6}}$ is ${\color{blue}{6}}$. Since ${\color{blue}{6}}$ is even, $353,856$ is divisible by $2.\quad{\color{green}{\checkmark}}$
- We now check for divisibility by $3$. The sum of the digits is
$3+5+3+8+5+6 = 30$.
Since $30$ is divisible by $3$, we have that $353,856$ is divisible by $3.\quad{\color{green}{\checkmark}}$

So, since $353,856$ is divisible by *both* $2$ *and* $3$, we conclude that it is divisible by $6$.

Let's see another example.

## Determining if a Number Is Divisible by 6

**Example:** Which digits, when inserted into the blank, make the number $93\,455\,13\square$ divisible by $6$?

1. $3$
2. $6$
3. $8$

**Explanation**

A number is divisible by $6$ if it is divisible by both $2$ and $3$. Remember that to determine whether a number is divisible by $3$, we check whether the sum of the digits is divisible by $3$.

For the given number, the sum of the digits is

$$
9+3+4+5+5+1+3+\square = 30+\square
$$

Now, let's consider each of the given digits we can substitute into the blank.

- If we substitute ${\color{blue}{3}}$ into the blank, we get $93\,455\,13{\color{blue}{3}}$, which is not divisible by $2$. Therefore, it is not divisible by $6$ either.
- If we substitute ${\color{blue}{6}}$ into the blank, we get $93\,455\,13{\color{blue}{6}}$, which is divisible by $2$. The sum of the digits is $30 + {\color{blue}{6}} = 36$, which is divisible by $3$, so the number is also divisible by $3$. Therefore, the number is divisible by $6$.
- If we substitute ${\color{blue}{8}}$ into the blank, we get $93\,455\,13{\color{blue}{8}}$, which is divisible by $2$. However, it is not divisible by $3$ because the sum of the digits is $30+{\color{blue}{8}}=38$, which is not divisible by $3$. So, the number is *not* divisible by $6$ either.

Therefore, the correct answer is "II only."

## Divisibility by 7

The rule for dividing by $7$ is the trickiest rule of the ones we've studied.

> *To check if a number is divisible by $7$, we double the last digit, subtract the result from the remaining digits, and then check if the difference is divisible by $7$.*

For example, let's check if the following number is divisible by $7{:}$

$$
46{\color{red}{2}}
$$

The last digit is ${\color{red}{2}}$. If we double this digit, we get

$$
2\cdot {\color{red}{2}} = {\color{blue}{4}}
$$

Then, if we subtract ${\color{blue}{4}}$ from the remaining digits, we get

$$
46 - {\color{blue}{4}} = 42
$$

Now, since $42$ is divisible by $7$, we conclude that $462$ is divisible by $7$.

Let's see some more examples.

---

<a id="determining-if-a-number-is-divisible-by-7"></a>
## Determining if a Number Is Divisible by 7

**Example:** Which of the following numbers are divisible by $7$?

1. $637$
2. $368$
3. $112$

**Explanation**

To check if a number is divisible by $7$, double the last digit, subtract the result from the remaining digits, and then check if the difference is divisible by $7$.

- For the number ${\color{blue}{63}}{\color{red}{7}}$, we have that
${\color{blue}{63}}-2({\color{red}{7}})=63-14=49$
which is divisible by $7$. Therefore, $637$ is divisible by $7$.
- For the number ${\color{blue}{36}}{\color{red}{8}}$, we have that
${\color{blue}{36}}-2({\color{red}{8}})=36-16=20$
which is not divisible by $7$. Therefore, $368$ is not divisible by $7$.
- For the number ${\color{blue}{11}}{\color{red}{2}}$, we have that
${\color{blue}{11}}-2({\color{red}{2}})=11-4=7$
which is divisible by $7$. Therefore, $112$ is divisible by $7$.

Therefore, the correct answer is "I and III only."
