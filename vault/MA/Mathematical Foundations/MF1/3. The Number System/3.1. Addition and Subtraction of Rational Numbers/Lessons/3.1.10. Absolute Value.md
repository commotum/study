## Introduction

The **absolute value** of a number is its *distance from zero* when viewed on a number line.

Distances are never negative. Therefore, the absolute value of a number is always positive or zero.

Let's consider the number $-5$ and its position on a number line, shown below.

![](<../Source/3.1.10. Absolute Value/Images/cf920d91f72b1615210264e172d01bc3.png>)

The **distance** between $-5$ and zero equals $5$ because $-5$ is five steps away from zero.

![](<../Source/3.1.10. Absolute Value/Images/18e8471cb3232c92db80fd4281fcc721.png>)

Therefore, *the absolute value of* $-5$ *equals* $5$. We write this as follows:

$$
\mid \, {-5} \, \mid = 5
$$

---

<a id="a-fast-way-of-finding-the-absolute-value"></a>
## A Fast Way of Finding the Absolute Value

There is a fast way to find the absolute value of a number:

- The absolute value of a positive number is equal to itself. For example,
$\mid 8 \mid = 8$.
- To find the absolute value of a negative number, we drop the negative sign. For instance,
$\mid {-8} \mid = 8$.

<a id="finding-the-absolute-value-of-a-positive-number"></a>
## Finding the Absolute Value of a Positive Number

**Example:** What is the value of $\mid 4\!\mid \,$?

**Explanation**

The absolute value of a positive number equals the number:

$$
\begin{aligned} \mid 4\!\mid \, =4 \end{aligned}
$$

The absolute value of a number gives the distance between the number and zero on a number line.

![](<../Source/3.1.10. Absolute Value/Images/ecf82ab57681530dc61be205de984f04.png>)

## Finding the Absolute Value of a Negative Number

**Example:** Find $\mid {-2} \mid$.

**Explanation**

To find the absolute value of $-2$, we simply drop the negative sign:

$$
\mid-2\!\mid=2
$$

The absolute value of a number gives the distance between the number and zero on a number line.

![](<../Source/3.1.10. Absolute Value/Images/dff1a8683a8801088a3ab41a97e525ef.png>)

## Finding a Number Given Its Absolute Value and Position on a Number Line

**Example:** The point shown below represents a number on a number line. The absolute value of this number is $4$. What is the number?

![](<../Source/3.1.10. Absolute Value/Images/5d582147fd8d78c85f93d1c0d92da868.png>)

**Explanation**

The number is *negative* because it is to the *left* of zero.

The absolute value of the number is $4$, so the distance between that number and zero on a number line is $4$.

The negative number at a distance of $4$ from zero is $-4$, so the number is $-4$.

![](<../Source/3.1.10. Absolute Value/Images/eb80c5a808a4166ec5dcdabb8d6a63d0.png>)
