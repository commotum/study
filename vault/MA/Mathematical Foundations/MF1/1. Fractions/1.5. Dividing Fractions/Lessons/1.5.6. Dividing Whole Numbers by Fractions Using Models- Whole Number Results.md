## Introduction

Remember that a *unit fraction* contains $\color{blue}1$ in the numerator.

For example, the following fractions are unit fractions since they each contain ${\color{blue}{1}}$ in the numerator:

$$
\dfrac{\color{blue}{1}}{2}, \qquad \dfrac{\color{blue}{1}}{5}, \qquad \dfrac{\color{blue}{1}}{8}
$$

However, the following fractions are *not-unit* fractions since they do *not* contain ${\color{blue}{1}}$ in the numerator:

$$
\dfrac{\color{red}{2}}{3}, \qquad \dfrac{\color{red}{5}}{8}, \qquad \dfrac{\color{red}{7}}{12}
$$

In this lesson, we will use models to divide whole numbers by *non-unit* fractions.

**Note**: Throughout this lesson, we'll be drawing numerous fraction models. It is highly recommended that you draw these models on a piece of paper to better understand their workings.

<a id="a-worked-example"></a>
## A Worked Example

Let's use a model to find the result of the following division problem:

$$
{\color{blue}{1}} \div \dfrac26
$$

We start with a model that represents ${\color{blue}{1}}$ whole:

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/d42ff288557f6c5f87939d38f9a8b932.png>)

We need to determine how many times

$$
\dfrac26
$$

fits into ${\color{blue}{1}}$ whole. So, we proceed as follows:

- First, we split our whole into *sixths* (the denominator of our fraction):

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/6a09788964e50e518b33a513748d4511.png>)

- Next, we create groups, where each group contains $\dfrac26{:}$

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/763caff15494b05b0e1b6d81018b34ba.png>)

- Finally, we count the groups. We see that there are $\color{purple} 3$ groups in total.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/2388f9a9c65dbf043e0467a24167b159.png>)

So, if we divide $\color{blue}1$ whole into groups of

$$
{\color{black}{\dfrac26}}
$$

we get ${\color{purple}{3}}$ groups in total.

Therefore, we conclude that

$$
{\color{blue}{1}} \div {\color{black}\dfrac26} = {\color{purple}3}
$$

<a id="finding-a-missing-number"></a>
## Finding a Missing Number

**Example:** Use the model above to determine the missing number in the following division problem.
$\frac{0}{0}$

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/168e45b1d12eb907c91ba0ca28141cb9.png>)

**Explanation**

Let's start by interpreting our model:

- The model shows $\color{blue}4$ wholes. Each whole is split into *fifths*.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/87f6a28b4cef379c7dbbab8555b0aabe.png>)

- The fifths are grouped, and each group contains ${\color{red}{\dfrac{2}{5}}}$.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/38b636ffcb7516ab0cb330781955a40a.png>)

- There are $\color{purple} 10$ groups in total.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/9f2529a4287c038b41ff233d75767bb5.png>)

So, if we divide $\color{blue}4$ wholes into groups of

$$
{\color{red}{\dfrac{2}{5}}}
$$

we get ${\color{purple}{10}}$ groups in total.

Therefore, the model represents the following division problem:

$$
\frac{2}{5}
$$

So, the missing number is

$$
\bbox[3pt, Gainsboro]{\color{red}\dfrac{2}{5}}
$$

## Dividing a Whole Number by a Non-Unit Fraction

**Example:** The model above represents $3$ wholes. Use the model to determine the missing number in the following division problem.
$0$

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/434571f93259bf26f87c79fb2b2df51e.png>)

**Explanation**

We proceed as follows:

- First, we split each whole into fifths.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/5c836697c0429df32bed7edf97f87b38.png>)

- Next, we create groups of ${\color{red}{\dfrac3{5}}}$.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/6d466f9b0bc38d59bfc8f54727d3c3a6.png>)

- Then, we count the groups.

![](<../Source/1.5.6. Dividing Whole Numbers by Fractions Using Models- Whole Number Results/Images/260fe65166810e04d8fc6305cc8cee2c.png>)

So, if we divide $\color{blue}3$ wholes into groups of

$$
{\color{red}{\dfrac3{5}}}
$$

we get ${\color{purple}{5}}$ groups in total.

Therefore, we conclude that

$$
3 \div \dfrac{3}{{5}} = \fbox{5}
$$

So, the missing number is $\bbox[3pt, Gainsboro]{\color{purple}5}$.
