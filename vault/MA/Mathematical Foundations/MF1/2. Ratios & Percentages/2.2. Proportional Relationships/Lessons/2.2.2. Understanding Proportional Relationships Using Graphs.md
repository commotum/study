## Introduction

How does a proportional relationship look when we plot it in the $(x,y)$ plane?

To answer this, let's consider the following proportional relationship:

$$
y = 2x
$$

To plot a graph, we first need a table of values.

| $x$ | $y$ |
| --- | ---: |
| $0$ |  |
| $1$ |  |
| $2$ |  |
| $3$ |  |

Filling in the $y$-values using the equation $y = 2x$, we get the following:

| $x$ | $y$ |
| --- | ---: |
| $0$ | $0$ |
| $1$ | $2$ |
| $2$ | $4$ |
| $3$ | $6$ |

So, we have the following $(x,y)$ coordinates:

$$
(0,0), \quad (1,2), \quad (2,4), \quad (3,6)
$$

If we plot these points in the coordinate plane, we get the following:

![](<../Source/2.2.2. Understanding Proportional Relationships Using Graphs/Images/243f67da73b4cdbe50e50c219994bcf5.png>)

This leads us to the following important fact:

> *The graph of any proportional relationship is a straight line that passes through the origin $(0,0)$.*

<a id="computing-a-constant-of-proportionality-or-unit-rate"></a>
## Computing a Constant of Proportionality or Unit Rate

**Example:** The graph below shows a proportional relationship. What is the constant of proportionality?

![](<../Source/2.2.2. Understanding Proportional Relationships Using Graphs/Images/da44fcc445ef360b7d827dc6ce54487c.png>)

**Explanation**

To find the constant of proportionality, we first need to choose a point $(x,y)$ on the graph. Here, let's choose the point $(4,3)$.

![](<../Source/2.2.2. Understanding Proportional Relationships Using Graphs/Images/f28a05e4e4eda07b2d757ec950ad394c.png>)

Now, we can find the constant of proportionality by computing the ratio of the $y$-coordinate to the $x$-coordinate, as follows:

$$
k = \dfrac{y}{x} = \dfrac{3}{4}
$$

Therefore, the constant of proportionality is

$$
k=\dfrac{3}{4}
$$

<a id="alternative-notations-and-terminology"></a>
## Alternative Notations and Terminology

When there is a proportional relationship between $x$ and $y$, we can express this using the **proportionality symbol** $\propto$, as follows:
$y \propto x$

Note that the following statements are all equivalent:

- $y = kx$
- $y$ **varies directly** with $x$
- $y$ is **directly proportional** to $x$
- $y \propto x$

<a id="finding-a-direct-variation-equation-from-a-graph"></a>
## Finding a Direct Variation Equation from a Graph

**Example:** The graph above shows the relationship between the displacement $d$, in centimeters, of a particular spring when a mass $m$, in kilograms, is attached to it. Find a direct variation equation that describes the relationship between $d$ and $m$.

![](<../Source/2.2.2. Understanding Proportional Relationships Using Graphs/Images/d28776658963243950ddafe9d7e0f982.png>)

**Explanation**

Since $d$ varies directly with $m$, we use the equation

$$
d = km
$$

Next, we notice that there is a point on the graph with $m=5$ and $d=20$. So, we substitute this data into the above equation to find $k$:

$$
\begin{aligned}
20 &= k \cdot 5 \\
\frac{20}{5} &= k \\
4 &= k
\end{aligned}
$$

Therefore, the direct variation equation is given by
$d=4m$.
