## Introduction

Suppose that $S$ is a subset of $\mathbb R^2$.
A **vector field** on $\mathbb R^2$ is a function $\mathbf F$ that maps every point $(x,y)$ in $S$ to a *vector* $\mathbf F(x,y)$ in $\mathbb{R}^2$.

![](<../Source/1.3.1. Vector Fields/Images/bb766e8e1f3fb308ce96bfdd27bcdf92.png>)

For example, consider the vector field $\mathbf F$, given by

$$
\mathbf F(x,y) = (x+y)\,\mathbf{i} + (x-y)\,\mathbf{j}
$$

This vector field maps the point $(2,1)$ to the vector $3\,\mathbf{i}+\mathbf{j}$, because

$$
\begin{aligned}
F(2, 1) &= (2 + 1)i + (2 - 1)j = 3i + j
\end{aligned}
$$

In general, any vector field $\mathbf F(x,y)$ on $\mathbb R^2$ can be expressed in terms of its component functions $P$ and $Q$ as follows:

$$
\mathbf F(x,y) = P(x,y)\,\mathbf{i} + Q(x,y)\,\mathbf{j}
$$

In the example above, we had

$$
P(x,y) = x+y, \qquad Q(x,y) = x-y
$$

**Note:** We can easily extend our definition of a vector field to three-dimensional or even $n$-dimensional space. For example, if $S$ is a subset of $\mathbb R^3$, then a vector field on $\mathbb R^3$ is a function $\mathbf F$ that maps every point $(x,y,z)$ in $S$ to a vector $\mathbf F(x,y,z)$ in $\mathbb{R}^3$.

## Identifying Vector Fields on Two-Dimensions

**Example:** Which of the following are vector fields on $\mathbb R^2$?

1. $\mathbf A(x,y) = \sqrt{x}\,\mathbf i + y^3\,\mathbf j$
2. $\mathbf B(x,y,z) = \ln y\,\mathbf i - (x+y)\,\mathbf j + z\,\mathbf k$
3. $\mathbf C(t) = \sin{t}\,\mathbf i + (2-t^3)\,\mathbf j$

**Explanation**

Suppose that $S$ is a subset of $\mathbb R^2$. A vector field on $\mathbb R^2$ is a function $\mathbf F$ that maps every point $(x,y)$ in $S$ to a vector $\mathbf F(x,y)\in \mathbb R^2$.

With that in mind, let's examine each function.

- The function $\mathbf A(x,y)$ is a vector field on $\mathbb R^2$. It maps every point in the set $S$, given by
$S = \big\{(x,y)\in\mathbb R^2 \: \mid \: x \geq 0\big\}$
to a vector in $\mathbb R^2$.
- The function $\mathbf B(x,y,z)$ is *not* a vector field on $\mathbb R^2$. It is a vector field on $\mathbb R^3$.
- The function $\mathbf C(t)$ is *not* a vector field on $\mathbb R^2$. It assigns points in $\mathbb{R}$ (not $\mathbb{R^2}$) to vectors in $\mathbb{R^2}$.

Therefore, the correct answer is "I only."

## Identifying Vector Fields on Three-Dimensions

**Example:** Which of the following are vector fields on $\mathbb R^3$?

1. $\mathbf R(x,y,z) = 2\,\mathbf i - x\,\mathbf j + y\,\mathbf k$
2. $\mathbf S(x,y) = 2x\,\mathbf i - y^3\,\mathbf j$
3. $\mathbf T(x,y,z) = \dfrac{x}{z}\,\mathbf i - \dfrac{y}{z}\,\mathbf j + \dfrac{z}{2}\,\mathbf k$

**Explanation**

Suppose that $S$ is a subset of $\mathbb R^3$. A vector field on $\mathbb R^3$ is a function $\mathbf F$ that maps every point $(x,y,z)\in S$ to a vector $\mathbf F(x,y,z)\in\mathbb R^3$.

With that in mind, let's examine each function.

- The function $\mathbf R(x,y,z)$ is a vector field on $\mathbb R^3$. It assigns every point $(x,y,z) \in \mathbb{R^3}$ to a vector in $\mathbb{R^3}$.
- The function $\mathbf S(x,y)$ is *not* a vector field on $\mathbb R^3$. It assigns points in $\mathbb R^2$ (not $\mathbb R^3$) to vectors in $\mathbb R^2$ (not $\mathbb R^3$).
- The function $\mathbf T(x,y,z)$ is a vector field on $\mathbb R^3$. It assigns every point in the set $S$, given by
$S = \big\{(x,y,z)\in\mathbb R^3\: \mid \: z \neq 0\big\}$
to a vector in $\mathbb R^3$.

Therefore, the correct answer is "I and III only."

## The Domain of a Vector Field

We can find the domain of a vector field by calculating the intersection of the domains of its component functions.

To demonstrate, let's find the domain of the vector field $\mathbf F$ on $\mathbb{R}^2$, given by

$$
\mathbf F(x,y) = \ln\left(4-x^2-y^2\right)\,\mathbf{i} + \sqrt{x-1}\,\mathbf{j}
$$

whose component functions are

$$
P(x,y) = \ln\left(4-x^2-y^2\right), \qquad Q(x,y) = \sqrt{x-1}
$$

To find the domain of $\mathbf F$, we find the domain of each component function and then compute their intersection.

- The function $P(x,y)$ is defined when the expression under the logarithm is positive. To find the domain, we solve the following inequality:
$4-x^2-y^2 \gt 0 \quad\Longrightarrow\quad x^2+y^2 \lt 4$
Therefore, the domain of $P$ is given by
$D_1 = \big\{(x,y)\in\mathbb R^2\: \mid \: x^2+y^2 \lt 4 \big\}$,
which is the interior of a circle of radius $2$, as shown below:

![](<../Source/1.3.1. Vector Fields/Images/0c10c4eac7af0285ff86af0658bb8283.png>)

- The function $Q(x,y)$ is defined when the expression under the radical is positive or zero. To find the domain, we solve the following inequality:
$x-1 \geq 0 \quad\Longrightarrow \quad x \geq 1$
Therefore, the domain of $Q$ is given by
$D_2 = \big\{(x,y)\in\mathbb R^2\: \mid \: x \geq 1 \big\}$,
which is the half-plane shown below:

![](<../Source/1.3.1. Vector Fields/Images/690ab47176f0eecf38c595825d5446d1.png>)

Finally, the domain $D$ of $\mathbf F$ is given by

$$
D = D_1 \cap D_2 = \big\{(x,y)\in\mathbb R^2\: \mid \: x^2 + y^2 \lt 4, \, x\geq 1 \big\}
$$

The domain of $\mathbf F$ is shown below.

![](<../Source/1.3.1. Vector Fields/Images/3d2817f9db455e782287e3d9683d3dee.png>)

## Finding the Domain of a Vector Field

**Example:** Find the domain of the vector field $\mathbf F$ on $\mathbb R^2$, given by

$\mathbf F(x,y) =\dfrac{1}{x^2+y^2}\, \mathbf{i} + \sqrt{1+x-y} \, \mathbf{j}\,$.

**Explanation**

The function $\mathbf F$ can be expressed in terms of its components $P(x,y)$ and $Q(x,y)$ as

$$
\mathbf F(x,y) = P(x,y)\,\mathbf i + Q(x,y)\,\mathbf j
$$

where

$$
P(x,y) =\dfrac{1}{x^2+y^2}, \qquad Q(x,y) = \sqrt{1+x-y}
$$

We first find the domain of each component function. Then, we compute their intersection to find the domain of $\mathbf F$:

- The function $P(x,y)$ is defined everywhere other than when the denominator vanishes. To find where the denominator vanishes, we set it equal to zero and solve:
$x^2 + y^2 = 0 \quad\Longrightarrow \quad x=y = 0$
Therefore, the domain of $P$ is given by
$D_1 = \big\{(x,y)\in\mathbb R^2\: \mid \: (x,y)\neq (0,0)\big\}$.
The region $D_1$ is the entire plane $\mathbb R^2$ with the origin removed, as shown below.![](<../Source/1.3.1. Vector Fields/Images/2d11f66345e024eed7bf280882ed66a0.png>)
- The function $Q(x,y)$ is defined when the expression under the radical is positive or zero. To find the domain, we solve the following inequality:
$1+x - y \geq 0 \qquad \Longrightarrow \qquad y\leq 1 + x$
Therefore, the domain of $Q$ is given by
$D_2 = \big\{(x,y)\in\mathbb R^2\: \mid \: y \leq 1 + x\big\}$.

The region $D_2$, shown below:

![](<../Source/1.3.1. Vector Fields/Images/4792228f471aa7edfa5498ff57e5d63b.png>)

Finally, the domain $D$ of $\mathbf F$ is given by

$$
D = D_1\cap D_2 = \big\{(x,y)\in\mathbb R^2\: \mid \: (x,y)\neq 0,\, y \leq 1 + x\big\}
$$

The region $D$ is shown below.

![](<../Source/1.3.1. Vector Fields/Images/fd17dd94e4234f271b92358cae0a9b6d.png>)
