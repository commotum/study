## Introduction

We can use functions to represent rotations of points and objects in the coordinate plane.

The simplest is a rotation of $180^\circ$ about the origin, which can be represented using the following function:

$$
(x,y) \mapsto (-x,-y)
$$

For example, by rotating the point $A(3,1)$ by $180^\circ$ using our function, we obtain

$$
(3,1) \mapsto (-3,-1)
$$

which gives us the image $A'(-3,-1)$:

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/5312d21d85fbcc88b4042d741672deef.png>)

**Note:** A rotation of $180^\circ$ gives the same result clockwise and counterclockwise. Therefore, we can use the same function to rotate a point by $180^\circ$ clockwise.

---

<a id="rotating-a-point-180-degrees-using-a-function"></a>
## Rotating a Point 180 Degrees Using a Function

**Example:** The point $(3,0)$ is rotated by $180^\circ$ about the origin. What is the image of this point under the transformation?

**Explanation**

Rotation of a point by $180^\circ$ (clockwise or counterclockwise) about the origin can be represented by the function

$$
(x,y) \mapsto (-x,-y)
$$

As a result, we have
$(3,0) \mapsto (-3,0)$.

Therefore, the resulting point is $(-3,0)$.

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/6e5ce9418ba26814b174959328442d0f.png>)

<a id="rotations-90-degrees-counterclockwise"></a>
## Rotations 90 Degrees Counterclockwise

A rotation of $90^\circ$ **counterclockwise** about the origin can be represented by the function

$$
({\color{red}{x}},{\color{blue}{y}}) \mapsto (-{\color{blue}{y}},{\color{red}{x}})
$$

For example, by rotating the point $A(3,1)$ by $90^\circ$ counterclockwise using our function, we obtain

$$
({\color{red}{3}},{\color{blue}{1}}) \mapsto (-{\color{blue}{1}},{\color{red}{3}})
$$

which gives us the image $A'(-{\color{blue}{1}},{\color{red}{3}})$:

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/e68acac34fc082279c085736b385053a.png>)

Note the following:

- The function $(x,y) \mapsto (-y,x)$ can be difficult to remember. One way is to picture the example above and reconstruct the function from there.
- A rotation of $270^\circ$ *clockwise* is the same as a rotation of $90^\circ$ *counterclockwise*.

---

<a id="rotating-a-point-90-degrees-counterclockwise-using-a-function"></a>
## Rotating a Point 90 Degrees Counterclockwise Using a Function

**Example:** The point $(2,1)$ is rotated by $90^\circ$ **counterclockwise** about the origin. What is the image of this point under the transformation?

**Explanation**

Rotation of a point by $90^\circ$ *counterclockwise* about the origin can be represented by the function

$$
(x,y) \mapsto (-y,x)
$$

As a result, we have

$$
(2,1) \mapsto (-1,2)
$$

Therefore, the resulting point is $(-1,2)$.

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/60eafafd6b119052de742c37c3f622b3.png>)

<a id="rotations-270-degrees-counterclockwise"></a>
## Rotations 270 Degrees Counterclockwise

A rotation of $270^\circ$ counterclockwise about the origin can be represented by the function

$$
({\color{blue}{x}},{\color{red}{y}}) \mapsto ({\color{red}{y}},-{\color{blue}{x}})
$$

For example, by rotating the point $A(3,1)$ by $270^\circ$ counterclockwise using our function, we obtain

$$
({\color{blue}{3}},{\color{red}{1}}) \mapsto ({\color{red}{1}},-{\color{blue}{3}})
$$

which gives us the image $A'({\color{red}{1}},-{\color{blue}{3}})$:

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/50f6e1b9933093950a0f33db23566c11.png>)

Note the following:

- The function $(x,y) \mapsto (y,-x)$ can be difficult to remember. One way is to picture the example above and reconstruct the function from there.
- A rotation of $270^\circ$ *counterclockwise* is the same as a rotation of $90^\circ$ *clockwise*. Therefore, we can use the same function to rotate a point by $90^\circ$ clockwise.

---

<a id="rotating-a-point-270-degrees-counterclockwise-using-a-function"></a>
## Rotating a Point 270 Degrees Counterclockwise Using a Function

**Example:** The point $(-4,-3)$ is rotated by $90^\circ$ **clockwise** about the origin. What is the image of this point under the transformation?

**Explanation**

First, recall that rotation by $90^\circ$ *clockwise* is the same as rotation by $270^\circ$ *counterclockwise*.

Rotation of a point by $270^\circ$ *counterclockwise* about the origin can be represented by the function

$$
(x,y) \mapsto (y,-x)
$$

As a result, we have
$(-4,-3) \mapsto (-3,4)$.

Therefore, the resulting point is $(-3,4)$.

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/3c2e4fc95e31a69a12cadb43add4eca8.png>)

## Rotating a Polygon in the Coordinate Plane Using a Function

**Example:** The function $R_O(x,y)\mapsto (-x, ky)$ rotates the polygon $\mathcal P$ about the origin $O$ by an angle of $\theta$ degrees counterclockwise. The image of $\mathcal P$ under the rotation $R_O$ is $\mathcal P'$, as shown below. Find the values of $k$ and $\theta$.

![](<../Source/8.2.3. Rotating Objects in the Coordinate Plane Using Functions/Images/f5175984a1c6971b4c1a7732e3b8c676.png>)

**Explanation**

From the picture, we can see that if we rotate the polygon $\mathcal P$ about the origin by $180^\circ$ counterclockwise, we get the polygon $\mathcal P'$. Therefore,

$$
\theta = 180^\circ
$$

Recall that the transformation $(x,y) \mapsto (-x,-y)$ defines a rotation by the angle of $180^\circ$ counterclockwise about the origin, so $k=-1$.

Indeed, this transformation maps vertices of $\mathcal P$ to vertices of $\mathcal P'$:
$\begin{bmatrix}(-1.5, 0.5) & ↦ (1.5,-0.5) \\ (-1.5, 2.5) & ↦ (1.5,-2.5) \\ (-0.5, 1.5) & ↦ (0.5,-1.5)\end{bmatrix}$
