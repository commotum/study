## Introduction

A **set** is a collection of objects known as **elements** or **members**.

Usually, the elements of a set have some property in common. For example, a set could be a class at school where the students are the members of the set. The common property is that all the students are members of the class.

To write a set, we list the elements between two braces (curly brackets). Commas are used to separate the elements.

So, for example, the set of the primary colors would be written as

$$
S =\{\text{yellow}, \: \text{red}, \: \text{blue} \}
$$

The elements of this set are $\text{yellow}$, $\text{red}$, and $\text{blue}$.

A set that does not contain any elements is known as the **null set** or **empty set** and is written as either
$\emptyset \quad \text{or} \quad \{\}$.

Note the following:

- *A set may contain other sets as elements.* For instance, the set
$T = \{1, \: 2, \: 3, \: 4, \: \{5, 6\}\}$
contains the set $\{5, 6\}$ as an element. However, it does *not* contain the elements $5$ and $6$.
- *Order doesn't matter.* The order in which the elements are listed is irrelevant. For instance, the following sets represent the same thing:
$A = \{1, \: 2, \: 3 \} = \{2, \: 3, \: 1\}$
It's usually easier to understand a set if the elements are listed in some order.
- *Duplicates don't matter.* Having multiple copies of an element does not affect the structure of a set. For example, the following sets represent the same thing:
$B = \{m, \: n, \: p, \: q\} = \{m, \: m, \: m, \: n, \: n, \: p, \: p, \: p, \: q\}$
When writing a set, we should try to organize it so that each element is listed once only.

<a id="identifying-the-elements-of-a-set"></a>
## Identifying the Elements of a Set

**Example:** List the elements of the following set:
$A = \big\{a, c,3, \{c,3 \}, \emptyset, \{\emptyset\}\big\}$

**Explanation**

The elements of the set $A$ are as follows:

$$
a, \quad c, \quad 3, \quad \{c,3\}, \quad \emptyset, \quad \{\emptyset\}
$$

**Watch Out!**

- The elements $c,3$, and $\{c,3\}$ are three separate entities. The first two are the elements $c$ and $3$, and the third is a set *containing* these two elements.
- The elements $\emptyset$ and $\{\emptyset \}$ are also separate entities. The first one is the empty set (i.e., the set containing no elements), while the second is a set that contains the empty set.

<a id="identifying-non-sets"></a>
## Identifying Non-Sets

**Example:** Which of the following is **not** a set?

1. $\{2, 4, 6 \}$
2. $\{\{2 \}, \{4, 6 \} \}$
3. $2, 4, 6$
4. $\emptyset$

**Explanation**

A set is a collection of elements listed between two braces (curly brackets). However, note that the null set (the set that does not contain any elements) can be written as either $\{\}$ or $\emptyset$.

- $\{2, 4, 6 \}$ is a set. The elements are $2$, $4$, and $6$, and they are listed between two braces.
- $\{\{2 \}, \{4, 6 \} \}$ is a set. The elements are $\{2 \}$ and $\{4, 6 \}$, and are listed between the two outermost braces.
- $2, 4, 6$ is *not* a set. The numbers $2$, $4$, and $6$ are *not* listed between two braces.
- $\emptyset$ is the empty set. Therefore, it is a set.

In conclusion, only III is not a set.

<a id="element-notation"></a>
## Element Notation

By convention, sets are denoted by uppercase letters, while lowercase letters refer to elements of the set.

There is a special notation, $\in$, for expressing elements of sets. For example, if $a$ is an element of a set $A$, we write

$$
a \in A
$$

For example, for the set $S$, given by

$$
S = \{\text{yellow}, \text{red}, \text{blue} \}
$$

we can write

$$
\text{yellow}\in S
$$

Similarly, if $a$ is *not* an element of $A$, then we write

$$
a \notin A
$$

For example,

$$
\text{green} \notin S
$$

---

<a id="using-element-notation"></a>
## Using Element Notation

**Example:** Write the following statement using element notation:

$\qquad$ $1$ and $2$ are elements of a set $S$, but $3$, $4$, and $5$ are not.

**Explanation**

If $a$ is an element of $S$, we write $a \in S$. Otherwise, if $a$ is *not* an element of $S$, we write $a \notin S$.

- Since $1$ and $2$ are elements of $S$, we write $1,2 \in S$.
- Since $3$, $4$, and $5$ are *not* elements of $S$, we write $3,4,5 \notin S$.

All together, we have the following statement:

$$
1,2 \in S\quad \textrm{and}\quad 3,4,5 \notin S
$$

<a id="ellipsis-notation"></a>
## Ellipsis Notation

When a set contains only a few elements, we can write them all explicitly.

For example, the set $A$ containing all positive even integers less than $20$ could be written as follows:

$$
A = \{2, \: 4, \: 6, \: 8, \: 10, \: 12, \: 14, \: 16, \: 18\}
$$

However, when a set contains many elements, we can save ourselves the pain of writing out all its elements using an ellipsis, "$\ldots$".

For example:

- The set $B$ containing all positive even integers less than $200$ can be written as
$B = \{2, \: 4, \: 6, \: \ldots, \: 198\}$.
- The set $C$ containing *all* positive even integers can be written as
$C = \{2, \: 4, \: 6, \: \ldots \}$.

Generally, an ellipsis means "and so on up to" if it's followed by a specific element or "and so on" if not.

Finally, note that $A$ and $B$ contain a finite number of elements ($A$ and $B$ contain $9$ and $99$ elements, respectively), while $C$ contains infinitely many elements:

- A set containing a finite number of elements is called a **finite set**.
- A set containing an infinite number of elements is called an **infinite set**.

So, $A$ and $B$ are finite sets, while $C$ is an infinite set.

<a id="identifying-the-set-corresponding-to-a-description"></a>
## Identifying the Set Corresponding to a Description

**Example:** Express the following sets using an ellipsis:

- The set $X$ of all positive integers greater than or equal to $10$
- The set $Y$ of integers less than zero
- The set $A$ of all natural numbers greater than $5$ and less than $5\, 005$

**Explanation**

Remember that an ellipsis means "and so on up to" if it's followed by a specific element, or "and so on" if not.

- To express the set $X$, we start with the first positive integer greater than or equal to $10$, which is $10$. The next integer is $11$, the one after that is $12$, and so on, which we denote with an ellipsis:
$X = \{10, 11, 12, \ldots \}$
- To express the set $Y$, we start with the first integer less than zero, which is $-1$. The next integer less than zero is $-2$, the one after that is $-3$, and so on, which we denote with an ellipsis:
$Y = \{-1, -2, -3, \ldots \}$
However, note that it is conventional to write a set of numbers from least to greatest, just like is shown on the number line. Writing the elements of $Y$ from least to greatest, we have
$Y = \{\ldots, -3, -2, -1\}$.
- To express the set $A$, we start with the first positive integer greater than $5$, which is $6$. The next integer is $7$, the one after that is $8$, and so on up to $5\, 004$ (the largest integer less than $5\, 005$). So, we have
$A = \{6, 7, 8, \ldots, 5004\}$.
