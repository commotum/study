## Introduction

Recall the graph of the function $y=\sin{x}$, shown below.

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/50293eb4b9ee09c5b5c67cd05db936a1.png>)

We can move the graph of $y=\sin x$ up (or down) by adding (or subtracting) a number to the right-hand-side of the function. These are known as **vertical translations**.

For example, the graph of

$$
y=\sin x +{\color{blue}1}
$$

moves the original sine curve up by $\color{blue}1$ unit:

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/d933f50bbbaa73e992b5222ef76241e8.png>)

Similarly, the graph of

$$
y=\sin x {\color{red}\,-\,2}
$$

moves the original sine curve down by $\color{red}2$ units:

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/79aacb79dfc9af762398c8e6003010bb.png>)

We can apply a vertical translation to any trigonometric function in the same way.

<a id="determining-the-equation-of-a-vertically-translated-sine-function"></a>
## Determining the Equation of a Vertically Translated Sine Function

**Example:** What is the equation of the graph shown above?

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/6162b7f292964d67f441e9d6172ad06d.png>)

**Explanation**

Let's add $y=\sin x$ to the plot.

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/5f0c528385396ddf71ce35f6f060b4fe.png>)

To plot the given curve, we follow these steps:

- Start with the graph of $y = \sin x$.
- Then, shift it by $1$ unit **down**.

Therefore, the given curve is the graph of

$$
y = \sin{x} - 1
$$

## Vertical Translations of the Cosine Function

Now, recall the graph of the function $y=\cos x$:

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/0d926e2b3f05407b6cbbdfd932518635.png>)

We can apply vertical translations to the cosine function. For instance, the graphs of

$$
y=\cos x{\color{blue}\,+\,2}
$$

and

$$
y=\cos x {\color{red}\,-\,1}
$$

are as follows:

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/00d59bd1136939b4abf07f493f9ce754.png>)

The $\color{blue}+\,2$ moves the curve up by two units, and the $\color{red}-\,1$ moves it down by one unit.

<a id="finding-the-maximum-and-minimum-values-of-a-vertically-translated-sine-or-cosine-function"></a>
## Finding the Maximum and Minimum Values of a Vertically Translated Sine or Cosine Function

**Example:** What is the minimum value of $y=\sin x + 2$?

**Explanation**

**Method 1**

To plot the given curve, we follow these steps:

- Start with the graph of $y = \sin x$.
- Then, shift it by $2$ units **up.**

The resulting graph is shown below.

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/f57e7a3379a181f41b4a63ed41ea529d.png>)

From the graph, we see that the minimum value is $y = 1$.

**Method 2**

We know that $y = \sin{x}$ has a minimum value of $-1$. So, we have

$$
-1 \leq \sin x
$$

Adding $2$ to both sides of the above inequality gives

$$
\begin{bmatrix}-1 + 2 & \le \sin x + 2 \\ 1 & \le \sin x + 2\end{bmatrix}
$$

Therefore, the minimum value of $\sin{x} + 2$ is $1$.

<a id="the-equation-of-a-vertically-translated-tangent-function"></a>
## The Equation of a Vertically Translated Tangent Function

**Example:** The graph above shows $y=\tan{x}+D$. What is the value of $D$?

![](<../Source/9.7.1. Vertical Translations of Trigonometric Functions/Images/37ab2474c44daf72f0e6afd48b8ffb71.png>)

**Explanation**

To plot the given curve, we follow these steps:

- Start with the graph of $y = \tan x$.
- Then, shift it by $3$ units **down.**

Therefore, the given curve is the graph of

$$
y = \tan x - 3
$$

So, we conclude that $D = -3$.
