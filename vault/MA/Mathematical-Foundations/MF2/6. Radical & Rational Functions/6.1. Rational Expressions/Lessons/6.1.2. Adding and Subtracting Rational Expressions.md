## Introduction

When two fractions have the same denominator, we add the numerators. For example,

$$
\dfrac 1 7 + \dfrac 5 7 = \dfrac{1+5}{7} = \dfrac 6 7
$$

In this case, both fractions were over a common denominator of $7$.

It works the same with rational expressions! So suppose that we want to add

$$
\dfrac{1}{x} + \dfrac{5}{x}
$$

Because both fractions have the same denominator of $x$, we can add the numerators as before:

$$
\dfrac{1}{x} + \dfrac{5}{x} = \dfrac{1+5}{x} = \dfrac{6}{x}
$$

Let's see some more examples!

---

<a id="adding-rational-expressions-with-a-common-denominator"></a>
## Adding Rational Expressions With a Common Denominator

**Example:** Simplify $\dfrac{2+a}{2a} + \dfrac{3+2a}{2a}$.

**Explanation**

We have a common denominator of $2a$, so we add the numerators and simplify:

$$
\begin{aligned}
\frac{2 + a}{2a} + \frac{3 + 2a}{2a} &=  \\
\frac{2 + a + 3 + 2a}{2a} &=  \\
\frac{2 + 3 + a + 2a}{2a} &=  \\
&= \frac{5 + 3a}{2a}
\end{aligned}
$$

<a id="adding-rational-expressions-without-common-denominators"></a>
## Adding Rational Expressions Without Common Denominators

Remember that in order to add fractions with different denominators, like

$$
\dfrac 1 4 + \dfrac 1 8
$$

we need to put the fractions over a **common denominator**, as follows:

$$
\begin{aligned}
\frac{1}{4} + \frac{1}{8} &=  \\
\frac{2}{8} + \frac{1}{8} &=  \\
&= \frac{3}{8}
\end{aligned}
$$

It works the same in algebraic rational expressions! To add two fractions, we need to put each fraction over a common denominator. Then, we add the numerators.

<a id="adding-rational-expressions-in-one-variable-with-common-factors-in-the-denominators"></a>
## Adding Rational Expressions in One Variable With Common Factors in the Denominators

**Example:** Given that $\dfrac 3 {2x}=a$ and $\dfrac y x=b$, what is $a+b$?

**Explanation**

We wish to add the following fractions:

$$
a+b = \dfrac 3 {2x} + \dfrac y x
$$

In order to add the two fractions, we need them to have a common denominator. Here, we can put both fractions over a common denominator of $2x$ if we multiply the top and bottom of the second fraction by $2$:

$$
\begin{aligned} \dfrac 3 {2x} + \dfrac y x \\[5pt] &= \dfrac 3 {2x} + \dfrac 2 2 \cdot \dfrac y x \\[5pt] &= \dfrac 3 {2x} + \dfrac {2y} {2x} \\[5pt] &= \dfrac {3 + 2y} {2x} \end{aligned}
$$

<a id="adding-rational-expressions-in-multiple-variables-with-common-factors-in-the-denominators"></a>
## Adding Rational Expressions in Multiple Variables With Common Factors in the Denominators

**Example:** Simplify $\dfrac{y}{x(1+y)} + \dfrac{y}{1+y}$.

**Explanation**

In order to add the two fractions, we need them to have a common denominator. Here, we can put both fractions over a common denominator of $x(y+1)$ if we multiply the top and bottom of the second fraction by $x$:

$$
\begin{aligned}
(y)/(x(1 + y)) + \frac{y}{1 + y} &=  \\
(y)/(x(1 + y)) + \frac{x}{x} \cdot \frac{y}{1 + y} &=  \\
(y)/(x(1 + y)) + (xy)/(x(1 + y)) &=  \\
(y + xy)/(x(1 + y)) &=  \\
&= (y(1 + x))/(x(1 + y))
\end{aligned}
$$
