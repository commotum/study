## Introduction

We can draw a curve by defining a relationship between $x$ and $y$ using a third parameter $t$. For example, suppose we have

$$
x=2t, \,\,\, y=t^2, \quad -3\leq t\leq 3
$$

These are the **parametric equations** of the curve.

First, let's create a table for some values of $t$:

| **$t$** | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $x= 2t$ | $-6$ | $-4$ | $-2$ | $0$ | $2$ | $4$ | $6$ |
| $y=t^2$ | $9$ | $4$ | $1$ | $0$ | $1$ | $4$ | $9$ |

Plotting these points, we get the following curve:

![](<../Source/3.1.1. Graphing Curves Defined Parametrically/Images/13a7b7e8ef810bb0af302b19de45175d.png>)

The curve is actually a parabola.
A curve defined by parametric equations is called a **parametric curve** and is said to be "defined parametrically".

## Filling a Table of Values for a Parametric Curve

**Example:** For the parametric curve
$x=3t, \,\,\, y=t^3, \quad -3\leq t \leq 3$,

fill in the following table of values.

| **$t$** | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $x$ |  |  |  |  |  |  |  |
| $y$ |  |  |  |  |  |  |  |

**Explanation**

First, we work out the $x$-values using the formula $x=3t$. This gives

| $x$ | $-9$ | $-6$ | $-3$ | $0$ | $3$ | $6$ | $9$ |
| $y$ |  |  |  |  |  |  |  |

Now, we work out the $y$-values using $y=t^3$. This gives

| **$t$** | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $x$ | $-9$ | $-6$ | $-3$ | $0$ | $3$ | $6$ | $9$ |

## Graphing a Curve Defined Parametrically

**Example:** Plot the graph of the parametrically defined curve
$x=t(t-6), \,\,\, y=t^3, \quad -2\leq t \leq 2$.

**Explanation**

We need to create a table of values and then sketch the curve. First, we work out the $x$-values using the formula $x=t(t-6)$. This gives

| **$t$** | $-2$ | $-1$ | $0$ | $1$ | $2$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $x$ | $16$ | $7$ | $0$ | $-5$ | $-8$ |
| $y$ |  |  |  |  |  |

Now, we work out the $y$ values using $y=t^3$. This gives

| **$t$** | $-2$ | $-1$ | $0$ | $1$ | $2$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $x$ | $16$ | $7$ | $0$ | $-5$ | $-8$ |

<a id="determining-the-range-of-a-parametric-equation"></a>
## Determining the Range of a Parametric Equation

**Example:** Given that a curve is defined parametrically as
$x=t^2-6t, \,\,\, y=t^4+4, \quad t \in (-\infty, \infty)$,

what are the ranges of $x$ and $y$?

**Explanation**

Let's consider each variable in turn.

- To find the range of $x$, we can start by completing the square, as follows:
$x|= t^{2} - 6t; = (t - 3)^{2} - (3)^{2}; = (t - 3)^{2} - 9$
Since $\left(t-3\right)^2 \geq 0$, we can conclude that $x \geq -9$.
- To find the range of $y=t^4+4$, notice that $t^4 \geq 0$, and consequently $y \geq 4$.

Therefore, the ranges are

$$
x \geq -9
$$

and

$$
y \geq 4
$$

<a id="defining-parametric-curves-using-other-parameters"></a>
## Defining Parametric Curves Using Other Parameters

We often see parametric curves defined in terms of the parameter $t$, such as the parametric curve given below:

$$
x=2 \cos t, \,\,\, y=3 \sin t, \quad 0 \leq t < 2 \pi
$$

However, we can also define parametric curves in terms of other variables. Another commonly used variable is $\theta$. So, in terms of $\theta$, the above parametric equation is expressed as

$$
x=2 \cos \theta, \,\,\, y=3 \sin \theta, \quad 0 \leq \theta < 2 \pi
$$

We often use $\theta$ when the bounds are

$$
0 \leq \theta < 2\pi
$$

because this implies that the parameter $\theta$ might be interpreted as an angle.

<a id="determining-the-range-of-a-parametric-equation-defined-in-terms-of-trigonometric-functions"></a>
## Determining the Range of a Parametric Equation Defined in Terms of Trigonometric Functions

**Example:** Given that a curve is defined parametrically as
$x = 4\cos\theta, \,\,\, y = 2\sin\theta, \quad 0\leq \theta < 2\pi$,
what are the ranges of $x$ and $y$?

**Explanation**

Let's consider each variable in turn.

- To find the range of $x$, notice that for $0\leq\theta < 2\pi$, we have $-1 \leq \cos{\theta} \leq 1$. Consequently,
$\begin{bmatrix}-1 & \le \cos θ \le 1 \\ -4 & \le 4\cos θ \le 4 \\ -4 & \le x \le 4\end{bmatrix}$.
So, we can conclude that $-4 \leq x \leq 4$.
- To find the range of $y$, notice that for $0\leq\theta < 2\pi$, we have $-1 \leq \sin{\theta} \leq 1$. Consequently,
$\begin{bmatrix}-1 & \le \sin θ \le 1 \\ -2 & \le 2\sin θ \le 2 \\ -2 & \le y \le 2\end{bmatrix}$.
So, we can conclude that $-2 \leq y \leq 2$.

Therefore, the ranges are

$$
-4 \leq x \leq 4
$$

and

$$
-2 \leq y \leq 2
$$
