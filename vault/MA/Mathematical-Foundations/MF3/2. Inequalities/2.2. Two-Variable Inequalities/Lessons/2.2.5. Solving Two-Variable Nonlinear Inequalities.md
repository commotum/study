## Introduction

Consider the function $f(x,y)$, defined as

$$
f(x,y) = 2x^2y
$$

This is a function of two variables, $x$ and $y$. The function is positive for some values of $(x,y)$ and negative for others. How can we determine those values of $x$ and $y$ for which the function is positive, and those for which the function is negative?

To answer this question, we first solve

$$
f(x,y) = 0
$$

This gives

$$
2x^{2} \cdot y = 0 \mid ⟹2x^{2} = 0ory = 0
$$

Solving the equations $2x^2 = 0$ and $y = 0$ gives the solutions $x=0$ and $y=0$. These solutions divide the $xy$-plane into four regions, as shown below.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/8d48d00366b7f0e23d7c2b47f8ac515d.png>)

Our task now is to determine the sign of $f(x,y)$ in each region. To do this, we pick four test points, one for each region.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/efcf2dda11bd4e7071868b020a230149.png>)

We compute the sign of $f(x,y)$ in each region by calculating the sign at each test point. We record our results in a sign table.

|  | Test point | $2x^2$ | $y$ | $f(x,y) = 2x^2\cdot y$ |
| --- | ---: | ---: | ---: | ---: |
| Top-Left | $(-1,1)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Top-Right | $(1,1)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Bottom-Left | $(-1,-1)$ | $\color{blue}+$ | $\color{red}-$ | $\color{red}-$ |
| Bottom-Right | $(1,-1)$ | $\color{blue}+$ | $\color{red}-$ | $\color{red}-$ |

Using the *last* column of the table above, we get the following picture:

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/cbca36e90e408d550f5b5f94ab871a09.png>)

We can also record our findings using a simplified sign table, like the one below.

| $y > 0$ | $\color{blue}+$ | $\color{blue}+$ |
| --- | ---: | ---: |
| $y < 0$ | $\color{red}-$ | $\color{red}-$ |
|  | $x< 0$ | $x> 0$ |

## Identifying Quadrants Where a Function Is Positive or Negative Using a Sign Table

**Example:** Consider the expression $f(x,y) = -3xy^2$. What are the missing entries in the following sign table of $f(x,y)$?

| $y > 0$ |  |  |
| --- | ---: | ---: |
| $y < 0$ |  |  |
|  | $x< 0$ | $x> 0$ |

**Explanation**

Notice that $f(x,y)$ equals zero when $x=0$ and $y=0$. These lines divide the $xy$-plane into four regions, as shown below.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/fa0cdfbb8ecb9b5d13af631848b5da0c.png>)

To determine the sign of $f(x,y)$ in each region, we pick four test points, one for each region.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/f6e83f9a06ec3ffc2e748ac277b18d98.png>)

Next, we calculate the sign of $f(x,y)$ in each region using a sign table:

|  | Test point | $-3x$ | $y^2$ | $f(x,y)$ |
| --- | ---: | ---: | ---: | ---: |
| Top-Left | $(-1,1)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Top-Right | $(1,1)$ | $\color{red}-$ | $\color{blue}+$ | $\color{red}-$ |
| Bottom-Left | $(-1,-1)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Bottom-Right | $(1,-1)$ | $\color{red}-$ | $\color{blue}+$ | $\color{red}-$ |

Using the *last* column of the table above, we get the following picture:

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/924be9539b8d5080971b034ecf97ac9f.png>)

Finally, we fill in the required sign table.

| $y > 0$ | $\color{blue}+$ | $\color{red}-$ |
| --- | ---: | ---: |
| $y < 0$ | $\color{blue}+$ | $\color{red}-$ |
|  | $x< 0$ | $x> 0$ |

## Identifying Quadrants Where a Function Is Positive or Negative

**Example:** Suppose that $f(x,y) = -6x^2y$. Determine the region that gives the solution to the inequality $f(x,y) \geq 0$?

**Explanation**

Notice that $f(x,y)$ equals zero when $x=0$ and $y=0$. These lines divide the $xy$-plane into four regions, as shown below. Since we have an "or equal to" inequality, we use solid lines to divide the plane.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/bd25ddaae705f22bf898f72975a3bad8.png>)

To determine the sign of $f(x,y)$ in each region, we pick four test points, one for each region.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/be2358a1616b4922da71ba80f0abb9b3.png>)

Next, we calculate the sign of $f(x,y)$ in each region using a sign table:

|  | Test point | $-6x^2$ | $y$ | $f(x,y)$ |
| --- | ---: | ---: | ---: | ---: |
| Top-Left | $(-1,1)$ | $\color{red}-$ | $\color{blue}+$ | $\color{red}-$ |
| Top-Right | $(1,1)$ | $\color{red}-$ | $\color{blue}+$ | $\color{red}-$ |
| Bottom-Left | $(-1,-1)$ | $\color{red}-$ | $\color{red}-$ | $\color{blue}+$ |
| Bottom-Right | $(1,-1)$ | $\color{red}-$ | $\color{red}-$ | $\color{blue}+$ |

Finally, on our diagram, we shade in the solutions to

$$
f(x,y) \geq 0
$$

using the *last* column of the table above.

![](<../Source/2.2.5. Solving Two-Variable Nonlinear Inequalities/Images/b56ef32af055eb1c45a9ebeeee43aa12.png>)
