## Introduction

Just as we can have a system of linear equations, we can also have systems of linear inequalities. For example, the system

$$
y \le x + 2; y > - x
$$

is solved by the points that satisfy the inequalities

$$
y \leq x+2
$$

*and* $y>-x$ simultaneously.

To find the points that satisfy both inequalities, we first draw the graph of the inequality

$$
y \leq x + 2{:}
$$

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/0118424e31e628629f7e60b87611205d.png>)

Now, on top of the diagram above, we draw the graph of the second inequality, $y > -x{:}$

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/d5c85a9c4ff25953ac92b95b406874bd.png>)

The solution to the system is the *intersection* of the two regions (i.e., the part that is shaded twice).

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/b59080e9a4cf84e74344a6251f7c0e99.png>)

The important thing to realize is that *any* point in the shaded region above satisfies *both* inequalities.

## Working With Systems Containing "Or Equal To" Inequalities

**Example:** Which system of inequalities defines the shaded region shown above?

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/3edbb889f6978133fc2ae041a3085a33.png>)

**Explanation**

Consider the line $y = 2x - 1$. Since the line is solid, the inequality is an "or equal to" inequality. Also, since the shaded region lies *below* the line, the inequality is a "less than" inequality. So the corresponding inequality is

$$
y \leq 2x - 1
$$

Now consider the line

$$
y = -x+2
$$

Since the line is solid, the inequality is an "or equal to" inequality. Also, since the shaded region lies *above* the line, the inequality is a "greater than" inequality. So the corresponding inequality is

$$
y \geq -x + 2
$$

Therefore, the system of inequalities that defines our shaded region is

$$
{y \le 2x - 1; y \ge - x + 2
$$

## Working With Systems Containing Strict Inequalities

**Example:** Which system of inequalities defines the shaded region shown above?

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/344928c0eea99cd3497661d8845d95b4.png>)

**Explanation**

Consider the line $y=2x-3$. Since the line is dashed, the inequality is strict. Also, since the shaded region lies *above* the line, the inequality is a "greater than" inequality. So the corresponding inequality is
$y \gt 2x - 3$.

Now consider the line

$$
y = x + 1
$$

Since the line is dashed, the inequality is strict. Also, since the shaded region lies *below* the line, the inequality is a "less than" inequality. So the corresponding inequality is
$y \lt x+1$.

Therefore, the system of inequalities that defines the shaded region is
${y > 2x - 3; y < x + 1$.

## Working With Systems Containing Mixed Inequalities

**Example:** Which of the following systems of inequalities represents the shaded region shown in the graph above?

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/457d1898a5945703bd6b2621ffa8f08a.png>)

**Explanation**

Consider the line

$$
y = \dfrac{1}{3}x+3
$$

Since the line is solid, the inequality is an "or equal to" inequality. Also, since the shaded region lies *below* the line, the inequality is a "less than" inequality. So the corresponding inequality is

$$
y \leq \dfrac{1}{3}x+3
$$

Now consider the line

$$
y = x+2
$$

Since the line is dashed, the inequality is strict. Also, since the shaded region lies *below* the line, the inequality is a "less than" inequality. So the corresponding inequality is
$y \lt x+2$.

Therefore, the system of inequalities that defines the shaded region is

$$
{y \le \frac{1}{3}x + 3; y < x + 2
$$

## Working With Systems Containing Inequalities Presented in Standard Form

**Example:** What system of inequalities defines the shaded region shown below?

![](<../Source/2.2.4. Systems of Linear Inequalities/Images/8d691714edd32c1331cb1041545ed34e.png>)

**Explanation**

Consider the line $y=1$. Since the line is dashed, the inequality is strict. Also, since the shaded region lies *below* the line, the inequality is a "less than" inequality. So the corresponding inequality is
$y < 1$.

Now consider the line $x - y = 2$. Since the line is solid, the inequality is an "or equal to" inequality. Writing the equation of this line in slope-intercept form, we have
$y =x- 2$.

Now, since the shaded region lies *above* the line, the inequality is a "greater than" inequality. So the corresponding inequality is

$$
y \geq x - 2
$$

which we can rewrite as

$$
x-y \leq 2
$$

Therefore, the system of inequalities that defines the shaded region is

$$
{y < 1; x - y \le 2
$$
