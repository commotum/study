## Introduction

Consider the function $f(x,y)$, defined as

$$
f(x,y) = 2(x-1)^2(y-2)
$$

Let's determine the values of $x$ and $y$ for which the function is positive and negative.

As always, we first solve

$$
f(x,y) = 0
$$

This gives

$$
2(x - 1)^{2} \cdot (y - 2) = 0 \mid ⟹2(x - 1)^{2} = 0or(y - 2) = 0
$$

Solving these equations gives the solutions $x=1$ and $y=2$. These solutions divide the $xy$-plane into four regions, as shown below.

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/b7a5ea37413569d0256fcd7b60e2707e.png>)

We now determine the sign of $f(x,y)$ in each region. To do this, we pick four test points, one for each region.

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/8a50041cd21a0f663940cbc9021ebffe.png>)

We compute the sign of $f(x,y)$ in each region by calculating the sign at each test point. We record our results in a sign table.

|  | Test point | $2(x-1)^2$ | $(y-2)$ | $f(x,y) = 2(x-1)^2\cdot (y-2)$ |
| --- | ---: | ---: | ---: | ---: |
| Top-Left | $(0,3)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Top-Right | $(2,3)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Bottom-Left | $(0,1)$ | $\color{blue}+$ | $\color{red}-$ | $\color{red}-$ |
| Bottom-Right | $(2,1)$ | $\color{blue}+$ | $\color{red}-$ | $\color{red}-$ |

Using the *last* column of the table above, we get the following picture:

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/fc090d930c1a09e260a5d4f9c759a8a9.png>)

We can also record our findings using a simplified sign table, like the one below.

| $y > 2$ | $\color{blue}+$ | $\color{blue}+$ |
| --- | ---: | ---: |
| $y < 2$ | $\color{red}-$ | $\color{red}-$ |
|  | $x< 1$ | $x> 1$ |

## Identifying Regions Where a Function Is Positive or Negative Using a Sign Table

**Example:** Consider the expression $f(x,y) = (3-x)(y+1)^2$. What are the missing entries in the sign table of $f(x,y)$ shown below?

| $y > -1$ |  |  |
| --- | ---: | ---: |
| $y < -1$ |  |  |
|  | $x< 3$ | $x> 3$ |

**Explanation**

Notice that $f(x,y)$ equals zero when $x = 3$ and $y = -1$. These lines divide the $xy$-plane into four regions, as shown below.

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/b7c9a28da4eb9d34bd96f0d44ec1e023.png>)

To determine the sign of $f(x,y)$ in each region, we pick four test points, one for each region.

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/59e7d4a360af087d0af49993c2fcb8b8.png>)

Next, we calculate the sign of $f(x,y)$ in each region using a sign table:

|  | Test point | $(3-x)$ | $(y+1)^2$ | $f(x,y)$ |
| --- | ---: | ---: | ---: | ---: |
| Top-left | $(2,0)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Top-Right | $(4,0)$ | $\color{red}-$ | $\color{blue}+$ | $\color{red}-$ |
| Bottom-Left | $(2,-2)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Bottom-Right | $(4,-2)$ | $\color{red}-$ | $\color{blue}+$ | $\color{red}-$ |

Using the *last* column of the table above, we get the following picture:

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/c0d3dfb30ea814e83cccbb4b403b88fa.png>)

Finally, we fill in the required sign table.

| $y > -1$ | $\color{blue}+$ | $\color{red}-$ |
| --- | ---: | ---: |
| $y < -1$ | $\color{blue}+$ | $\color{red}-$ |
|  | $x< 3$ | $x> 3$ |

## Identifying Regions in the Plane Where a Function Is Positive or Negative

**Example:** Suppose that $f(x,y) = (x-2)^2(y+1)$. Which of the following shaded areas gives the solution to the inequality $f(x,y) > 0$?

**Explanation**

Notice that $f(x,y)$ equals zero when $x=2$ and $y=-1$. These lines divide the $xy$-plane into four regions, as shown below. Since we have a strict inequality, we use dashed lines to divide the plane.

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/1d27c3483fe5a41e0d1d8b6a1156162a.png>)

To determine the sign of $f(x,y)$ in each region, we pick four test points, one for each region.

![](<../Source/2.2.6. Further Solving of Two-Variable Nonlinear Inequalities/Images/e1a79695a81263b0d3e9b0ff97ee32c2.png>)

Next, we calculate the sign of $f(x,y)$ in each region using a sign table:

|  | Test point | $(x-2)^2$ | $(y+1)$ | $f(x,y)$ |
| --- | ---: | ---: | ---: | ---: |
| Top-Left | $(1,0)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Top-Right | $(3,0)$ | $\color{blue}+$ | $\color{blue}+$ | $\color{blue}+$ |
| Bottom-Left | $(1,-2)$ | $\color{blue}+$ | $\color{red}-$ | $\color{red}-$ |
| Bottom-Right | $(3,-2)$ | $\color{blue}+$ | $\color{red}-$ | $\color{red}-$ |

Finally, on our diagram, we shade in the solutions to $f(x,y) > 0$ using the *last* column of the table above.
