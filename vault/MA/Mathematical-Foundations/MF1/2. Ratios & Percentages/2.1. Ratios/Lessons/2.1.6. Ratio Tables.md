## Introduction

Let's take a look at the following equivalent ratios:

$$
00
$$

We can place the equivalent ratios in a **ratio table**, such as the one below. In a ratio table, each row represents a ratio.

| ${\color{blue}5}$ | ${\color{red}10}$ |
| --- | ---: |
| ${\color{blue}10}$ | $\bbox[3pt,Gainsboro]{\color{red}\textrm{?}}$ |
| ${\color{blue}20}$ | ${\color{red}40}$ |

One number is missing. Let's figure out what it is.

We start with the ratio ${\color{blue}5}:{\color{red}10}$, which is the first ratio in the table. Writing this ratio as a fraction, we have

$$
\dfrac{{\color{blue}5}}{{\color{red}10}}
$$

The numerator represents the left-hand entry (${\color{blue}5}$), and the denominator represents the right-hand entry (${\color{red}10}$).

To find the missing number, we need to make a numerator of ${\color{blue}10}$. We can do this by multiplying the numerator and denominator by $2$:

$$
\begin{aligned}
\frac{5 \cdot 2}{10 \cdot 2} &= \frac{10}{20}
\end{aligned}
$$

We now add this to our ratio table:

| ${\color{blue}5}$ | ${\color{red}10}$ |
| --- | ---: |
| ${\color{blue}10}$ | $\bbox[3pt,Gainsboro]{\color{red}20}$ |
| ${\color{blue}20}$ | ${\color{red}40}$ |

So, the missing number is $\color{red}20$.

## Filling a Ratio Table by Multiplying: Missing Denominators

**Example:** What number is missing from the ratio table?

| $5$ | $4$ |
| --- | ---: |
| $20$ | $\bbox[3pt,Gainsboro]{\color{red}?}$ |
| $25$ | $20$ |

**Explanation**

We start with the ratio ${\color{blue}5}:{\color{red}4}$ and write it as a fraction:

$$
\dfrac{\color{blue}5}{\color{red}4}
$$

So the numerator represents the left-hand entry (${\color{blue}5}$), and the denominator represents the right-hand entry (${\color{red}4}$).

We can make a numerator of $20$ by multiplying the numerator and denominator by $4$:

$$
\begin{aligned}
\frac{5 \cdot 4}{4 \cdot 4} &= \frac{20}{16}
\end{aligned}
$$

We add this to our ratio table:

| ${\color{blue}5}$ | ${\color{red}4}$ |
| --- | ---: |
| ${\color{blue}20}$ | $\bbox[3pt,Gainsboro]{\color{red}16}$ |
| ${\color{blue}25}$ | ${\color{red}20}$ |

So, the missing number is $\color{red}16$.

## Filling a Ratio Table by Multiplying: Missing Numerators

**Example:** Complete the ratio table below.

| $3$ | $5$ |
| --- | ---: |
| $\bbox[3pt,Gainsboro]{\color{blue}?}$ | $10$ |
| $\bbox[3pt,Gainsboro]{\color{blue}?}$ | $35$ |
| $\bbox[3pt,Gainsboro]{\color{blue}?}$ | $50$ |

**Explanation**

We start with the ratio ${\color{blue}3}:{\color{red}5}$ and write it as a fraction:

$$
\dfrac{\color{blue}3}{\color{red}5}
$$

So the numerator represents the left-hand entry (${\color{blue}3}$), and the denominator represents the right-hand entry (${\color{red}5}$).

We can generate equivalent ratios by finding equivalent fractions:

- To create a denominator of $10$, we multiply the numerator and denominator of our fraction by $2{:}$
$\dfrac{{\color{blue}3}\times 2}{{\color{red}5}\times 2} = \dfrac{\bbox[3pt,Gainsboro]{\color{blue}6}}{\color{red}10}$
- To create a denominator of $35$, we multiply the numerator and denominator of our fraction by $7{:}$
$\dfrac{{\color{blue}3}\times 7}{{\color{red}5}\times 7} = \dfrac{\bbox[3pt,Gainsboro]{\color{blue}21}}{\color{red}35}$
- To create a denominator of $50$, we multiply the numerator and denominator of our fraction by $10{:}$
$\dfrac{{\color{blue}3}\times 10}{{\color{red}5}\times 10} = \dfrac{\bbox[3pt,Gainsboro]{\color{blue}30}}{\color{red}50}$

Finally, we fill in the ratio table:

| ${\color{blue}3}$ | ${\color{red}5}$ |
| --- | ---: |
| $\bbox[3pt,Gainsboro]{\color{blue}6}$ | ${\color{red}10}$ |
| $\bbox[3pt,Gainsboro]{\color{blue}21}$ | ${\color{red}35}$ |
| $\bbox[3pt,Gainsboro]{\color{blue}30}$ | ${\color{red}50}$ |

## Filling a Ratio Table by Multiplying and Dividing

**Example:** From top to bottom, what are the missing numbers in the ratio table below?

| $6$ | $18$ |
| --- | ---: |
| $\bbox[3pt,Gainsboro]{\color{blue}?}$ | $24$ |
| $20$ | $\bbox[3pt,Gainsboro]{\color{red}?}$ |

**Explanation**

We start with the ratio ${\color{blue}6}:{\color{red}18}$ and write it as a fraction:

$$
\dfrac{{\color{blue}6}}{{\color{red}18}}
$$

So the numerator represents the left-hand entry (${\color{blue}6}$), and the denominator represents the right-hand entry (${\color{red}18}$).

Now we divide the numerator and the denominator by $6$ to find an equivalent ratio:

$$
\dfrac{{\color{blue}{6}}\div 6}{{\color{red}{18}}\div 6} = \dfrac{{\color{blue}1}}{{\color{red}3}}
$$

We can generate equivalent ratios by finding equivalent fractions:

- To create a denominator of $24$, we multiply the numerator and denominator of the previous fraction by $8{:}$
$\dfrac{{\color{blue}{1}}\times 8}{{\color{red}{3}}\times 8} = \dfrac{\bbox[3pt,Gainsboro]{\color{blue}8}}{{\color{red}24}}$
- To create a numerator of $20$, we multiply the numerator and denominator of our fraction by $20{:}$
$\dfrac{{\color{blue}{1}}\times 20}{{\color{red}{3}}\times 20} = \dfrac{{\color{blue}20}}{\bbox[3pt,Gainsboro]{\color{red}60}}$

Finally, we fill in the ratio table:

| ${\color{blue}6}$ | ${\color{red}18}$ |
| --- | ---: |
| $\bbox[3pt,Gainsboro]{\color{blue}8}$ | ${\color{red}24}$ |
| ${\color{blue}20}$ | $\bbox[3pt,Gainsboro]{\color{red}60}$ |

So, from top to bottom, the missing numbers are $8$ and $60$.

## Word Problems

**Example:** Harvey's parents reward him for each hour he spends helping with the housework. The following ratio table shows the number of hours of work Harvey did over the last three weeks and the corresponding rewards.

| Reward (in dollars) | Hours of work |
| --- | ---: |
| $\bbox[3pt,Gainsboro]{\color{blue}?}$ | $3$ |
| $12$ | $4$ |
| $15$ | $\bbox[3pt,Gainsboro]{\color{red}?}$ |

From top to bottom, what are the missing numbers in the ratio table?

**Explanation**

We start with the ratio ${\color{blue}12}:{\color{red}4}$ and write it as a fraction:

$$
\dfrac{{\color{blue}12}}{{\color{red}4}}
$$

Now we divide the numerator and the denominator by $4$ to find an equivalent ratio:

$$
\dfrac{{\color{blue}{12}}\div 4}{{\color{red}{4}}\div 4} = \dfrac{{\color{blue}3}}{{\color{red}1}}
$$

We can generate ratios that are equivalent to $3:1$ by finding more equivalent fractions:

$$
\begin{aligned}
\frac{3 \cdot 3}{1 \cdot 3} &= \frac{9}{3} \\
\frac{3 \cdot 5}{1 \cdot 5} &= \frac{15}{5}
\end{aligned}
$$

Finally, we fill in the ratio table:

| Reward (in dollars) | Hours of work |
| --- | ---: |
| $\bbox[3pt,Gainsboro]{\color{blue}9}$ | $3$ |
| $12$ | $4$ |
| $15$ | $\bbox[3pt,Gainsboro]{\color{red}5}$ |

So, from top to bottom, the missing numbers are $9$ and $5$.
