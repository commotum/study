## Introduction

Remember that we can place equivalent ratios in a ratio table, like the one below.

| $\color{blue}x$ | $\color{red}y$ |
| --- | ---: |
| $\color{blue}1$ | $\color{red}2$ |
| $\color{blue}2$ | $\color{red}4$ |
| $\color{blue}4$ | $\color{red}8$ |

By setting the values in the left column as $\color{blue}x$-coordinates and the values in the right column as the corresponding $\color{red}y$-coordinates, we can graph the points to represent a relationship between the ratios.

In this case, we have the following ordered pairs: $({\color{blue}1},{\color{red}2})$, $({\color{blue}2},{\color{red}4})$, $({\color{blue}4},{\color{red}8})$.

Plotting these points on a coordinate plane, we get the following graph:

![](<../Source/2.1.7. Graphing Ratios/Images/d8dee400d56d83eff2607955df4071cf.png>)

Connecting the points gives us a straight line! Plotting equivalent ratios will *always* give a straight line. Furthermore, the straight line will *always* pass through the origin $(0,0)$.

## Graphing Ratios

**Example:** By finding the missing values in the ratio table below, determine the graph that represents the given relationship.

| $x$ | $y$ |
| --- | ---: |
| $4$ | $2$ |
| $8$ |  |
|  | $6$ |

**Explanation**

We start with the ratio ${\color{blue}4}:{\color{red}2}$ and write it as a fraction:

$$
\dfrac{{\color{blue}4}}{{\color{red}2}}
$$

We can generate equivalent ratios by finding equivalent fractions:

$$
\begin{aligned}
\frac{4 \cdot 2}{2 \cdot 2} &= \frac{8}{4} \\
\frac{4 \cdot 3}{2 \cdot 3} &= \frac{12}{6}
\end{aligned}
$$

We add these to our ratio table:

| $x$ | $y$ |
| --- | ---: |
| $4$ | $2$ |
| $8$ | $4$ |
| $12$ | $6$ |

So, we have the following ordered pairs: $(4,2)$, $(8,4)$, $(12,6)$.

Plotting these points on the coordinate plane and connecting them with a straight line, we get the following graph:

![](<../Source/2.1.7. Graphing Ratios/Images/fc8f023b719daa7d2bb040bb14662c0f.png>)

<a id="determining-a-ratio-from-a-graph"></a>
## Determining a Ratio From a Graph

**Example:** What $x:y$ ratio is shown in the graph above?

![](<../Source/2.1.7. Graphing Ratios/Images/4804153163537d6afbbad2aeff726ff5.png>)

**Explanation**

We see that the point $(32,20)$ lies on the graph. Let's write the ratio $32:20$ as a fraction:

$$
\dfrac{32}{20}
$$

We can simplify this fraction by dividing both the numerator and the denominator by $4$:

$$
\begin{aligned}
\frac{32 \div 4}{20 \div 4} &= \frac{8}{5}
\end{aligned}
$$

So the graph shows the ratio

$$
\dfrac{8}{5}
$$

## Determining a Ratio From a Graph: Word Problems

**Example:** Betty is making pizza. The amount of water she needs for a given amount of flour is shown in the graph above. In its simplest form, what is the ratio of flour to water?

![](<../Source/2.1.7. Graphing Ratios/Images/2701cd2d2d9d3991dbbdaf2f3044a3fa.png>)

**Explanation**

One of the points belonging to the graph is $(15,6)$.

Let's write the ratio $15:6$ as a fraction:

$$
\dfrac{15}{6}
$$

We can simplify this fraction by dividing both the numerator and the denominator by $3$:

$$
\begin{aligned}
\frac{15 \div 3}{6 \div 3} &= \frac{5}{2}
\end{aligned}
$$

So the ratio of flour to water is $5:2$.
