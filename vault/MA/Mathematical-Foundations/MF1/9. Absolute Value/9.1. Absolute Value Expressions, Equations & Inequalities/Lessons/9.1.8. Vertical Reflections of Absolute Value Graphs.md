## Introduction

If we want to plot the graph of

$$
y=-\mid x \mid
$$

, we reflect the curve

$$
y= \mid x \mid
$$

in the $x$-axis, as shown below:

![](<../Source/9.1.8. Vertical Reflections of Absolute Value Graphs/Images/a60f454a50ff411fe1e3a3217f47f4ab.png>)

This transformation is called a **reflection in the $x$-axis**, and it occurs because the output $y$-values of the function

$$
y= \mid x \mid
$$

are made negative by the transformation.

If we combine vertical and horizontal translations with reflection, we get a general form

$$
y=-\mid x-h \mid +k
$$

This is the equation of a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated

- $h$ units right and
- $k$ units up.

<a id="vertical-translation"></a>
## Vertical Translation

**Example:** Plot the graph of $y=-\mid x \mid +4$.

**Explanation**

Remember that

$$
y=-\mid x \mid +k
$$

is a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated $k$ units up.

The given function

$$
y=-\mid x \mid +4
$$

has $k=4$. Therefore, it is a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated $4$ units up.

![](<../Source/9.1.8. Vertical Reflections of Absolute Value Graphs/Images/72a641ceec46a11a783375c90b3cc23b.png>)

<a id="horizontal-translations"></a>
## Horizontal Translations

**Example:** Plot the graph of $y=-\mid x+2 \mid$.

**Explanation**

Remember that

$$
y=-\mid x-h \mid
$$

is a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated $h$ units right.

The given function

$$
y=-\mid x+2 \mid
$$

has $h=-2$. To see this clearly, we can write the curve as follows:

$$
\begin{aligned}
y &= -\mid x + 2 \mid \\
y &= -\mid x - (-2) \mid
\end{aligned}
$$

Therefore, the given curve is a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated $2$ units *left*.

![](<../Source/9.1.8. Vertical Reflections of Absolute Value Graphs/Images/b8a8211a24535cb9cf4e840577f38fed.png>)

<a id="combining-horizontal-and-vertical-translations"></a>
## Combining Horizontal and Vertical Translations

**Example:** Plot the graph of $y=-\mid x+5 \mid +6$.

**Explanation**

Remember that

$$
y=-\mid x-h \mid +k
$$

is a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated $h$ units right and $k$ units up.

The given function

$$
y=-\mid x+5 \mid +6
$$

has $h=-5$ and $k=6$. Therefore, it is a reflected absolute value graph

$$
y=-\mid x \mid
$$

that is translated $5$ units *left* and $6$ units up.

![](<../Source/9.1.8. Vertical Reflections of Absolute Value Graphs/Images/94c8c28f01bf850e70383e2e205b04c2.png>)
