## Introduction

We can add fractions with unlike denominators using fraction models. To illustrate, let's use the fraction model below to find the value of

$$
\dfrac{1}{6} + \dfrac{2}{3}
$$

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/011a374f25a6329f0e440f0ac73d830f.png>)

We *cannot* add the fractions at the moment because they are split into different numbers of parts. In other words, they have different denominators.

To get around this, we split the shape on the right into a total of $\color{blue}6$ equal parts by drawing a horizontal line. This turns the fraction

$$
\dfrac 2 3
$$

into the equivalent fraction

$$
\dfrac 4 6
$$

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/e98845fe5eda2dd4bc2d9fe5c991806f.png>)

Now that both fractions have the same number of parts, we can add them:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/6552e83504e976b833c83823e4150683.png>)

So now, we have:

$$
\dfrac{1}{6} + \dfrac{2}{3} = \dfrac{1}{\color{blue}6} + \dfrac{4}{\color{blue}6} = \dfrac{5}{\color{blue}6}
$$

To add fractions, they need a **common denominator**. Splitting up the second shape meant that the fractions had a common denominator of $\color{blue}6$, which allowed us to add them.

## Adding Fractions When One Split is Required

**Example:** Use the fraction model above to find the value of $\dfrac{1}{2}+\dfrac{1}{4}$.

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/97f1fe36e477d72f3ec4716537ec054c.png>)

**Explanation**

We split the shape on the left into $4$ equal parts by drawing a horizontal line:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/baad30327646d2f98974923f42c35602.png>)

Now that they have the same number of parts, we can add them:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/de03dc455b3d1cca2293a381ac538e22.png>)

Therefore,

$$
\dfrac{1}{2} + \dfrac{1}{\color{blue}4} = \dfrac{2}{\color{blue}4} + \dfrac{1}{\color{blue}4} = \dfrac{3}{\color{blue}4}
$$

In this case, we made a common denominator of ${\color{blue}{4}}$.

## Adding Fractions When Multiple Splits are Required

**Example:** Use the model below to find the value of $\dfrac{2}{9} + \dfrac{2}{3}$.

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/3d718500e1f2a883e450b2984d783529.png>)

**Explanation**

The denominators are $9$ and $3$. Since $9$ is a multiple of $3$, we can make a common denominator of $\color{blue}9$.

We split the shape on the right into $9$ parts by drawing two vertical lines:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/4aba4f38df67724e45e10cc5d154f50b.png>)

Now that both shapes have a common denominator of $\color{blue}9$, we can add them:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/615d74537a5bf25dc9564bba648f8424.png>)

Therefore, we have:

$$
\dfrac{2}{9} + \dfrac{2}{3} = \dfrac{2}{\color{blue}9} + \dfrac{6}{\color{blue}9} = \dfrac{8}{\color{blue}9}
$$

<a id="making-a-common-denominator"></a>
## Making a Common Denominator

Let's suppose that we want to work out

$$
\dfrac{1}{2} + \dfrac{2}{5}
$$

The fraction model for this is given below.

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/ea666cd14c4a941df3da9b276c38c5e8.png>)

We cannot alter the shape on the left so that it contains $5$ equal parts. So what do we do?

The denominators are $\color{blue}2$ and $\color{red}5$. So we can make a common denominator of

$$
{\color{blue}{2}} \times {\color{red}{5}} = 10
$$

as follows:

- We split the shape on the left into $\color{red}5$ parts vertically.
- We split the shape on the right into $\color{blue}2$ parts horizontally.

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/aa9908eb586dcedc2432903cb2227f65.png>)

We can now add the two numbers:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/19409a3cddd822a9a0a3857933c87bfb.png>)

Therefore, we have:

$$
\dfrac{1}{2} + \dfrac{2}{5} = \dfrac{5}{10} + \dfrac{4}{10} = \dfrac{9}{10}
$$

## Making a Common Denominator by Altering Both Fractions

**Example:** Use the model above to determine the number that is missing in the statement below.
$0$

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/38f7d88defab053b6b403fa4a2f3238d.png>)

**Explanation**

The denominators are $5$ and $6$. So we can make a common denominator of

$$
5\times 6 = \color{blue}30
$$

We split the shape on the left of the addition sign into $6$ parts vertically, and we split the shape on the right into $5$ parts horizontally:

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/f936393f116bbf0d24aecda1fea34f77.png>)

Now, the shape to the left shows

$$
\dfrac{6}{\color{blue}30}
$$

and the shape to the right shows

$$
\dfrac{5}{\color{blue}30}
$$

We add the number of shaded parts and get:

$$
6 + 5 = {\color{red}11}
$$

![](<../Source/1.2.5. Adding Fractions With Unlike Denominators Using Models/Images/947b2d49349b237a537091a1aa6afee0.png>)

Therefore, we have
$11$

So, the missing number is $\color{red}11$.
