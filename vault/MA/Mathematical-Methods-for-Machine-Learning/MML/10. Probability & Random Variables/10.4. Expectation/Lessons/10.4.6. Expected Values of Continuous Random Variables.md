## Introduction

The **expected value** (also known as the **expectation** or **mean**) of a continuous random variable is the average value we'd expect to get if we observed the random variable many times.

For a continuous random variable $X$ with probability density function $f(x)$ defined over a set $S$, we can calculate the expected value using the following formula:

$$
\textrm E[X] = \int_S x \cdot f(x) \, \textrm dx
$$

For example, consider the continuous random variable $X$ with the following probability density function:

$$
f(x) = \dfrac{x}{4}, \quad 1 < x < 3
$$

We compute the expected value as follows:

$$
\begin{aligned}
E[X] &= ∫_{1}^{3}x \cdot \frac{x}{4}dx \\
&= ∫_{1}^{3}\frac{x^{2}}{4}dx \\
&= \frac{x^{3}}{12} \mid _{1}^{3} \\
&= \frac{13}{6}
\end{aligned}
$$

## Computing the Mean of a Continuous Random Variable

**Example:** Given that $X$ is a continuous random variable with the following probability density function, compute $\textrm E[X]$.
$f(x) = \dfrac{x^2}{9}, \quad 0 \leq x \leq 3$

**Explanation**

For a continuous random variable $X$ with probability density function $f(x)$ defined over a set $S$, we can calculate the expected value using the following formula:

$$
\textrm E[X] = \int_S x \cdot f(x) \, \textrm dx
$$

We compute the expected value of $X$ as follows:

$$
\begin{aligned}
E[X] &= ∫_{0}^{3}x \cdot \frac{x^{2}}{9}dx \\
&= ∫_{0}^{3}\frac{x^{3}}{9}dx \\
&= \frac{x^{4}}{36} \mid _{0}^{3} \\
&= \frac{9}{4}
\end{aligned}
$$

<a id="computing-the-mean-of-a-continuous-random-variable-with-a-piecewise-pdf"></a>
## Computing the Mean of a Continuous Random Variable With a Piecewise PDF

**Example:** Given that $X$ is a continuous random variable with the following probability density function, compute $\textrm E[X]$.
${\frac{1}{4},\begin{vmatrix}0 < x < 2 \\ \frac{x}{2} - \frac{3}{4},\end{vmatrix}2 \le x \le 3$

**Explanation**

For a continuous random variable $X$ with probability density function $f(x)$ defined over a set $S$, we can calculate the expected value using the following formula:

$$
\textrm E[X] = \int_S x \cdot f(x) \, \textrm dx
$$

We compute the expected value of $X$ as follows:

$$
\begin{aligned}
E[X] &= ∫_{0}^{3}x \cdot f(x)dx \\
&= ∫_{0}^{2}x \cdot f(x)dx + ∫_{2}^{3}x \cdot f(x)dx \\
&= ∫_{0}^{2}x \cdot \frac{1}{4}dx + ∫_{2}^{3}x \cdot (\frac{x}{2} - \frac{3}{4})dx \\
&= ∫_{0}^{2}\frac{x}{4}dx + ∫_{2}^{3}(\frac{x^{2}}{2} - \frac{3x}{4})dx \\
&= \frac{x^{2}}{8} \mid _{0}^{2} + (\frac{x^{3}}{6} - \frac{3x^{2}}{8}) \mid _{2}^{3} \\
&= \frac{1}{2} + \frac{31}{24} \\
&= \frac{43}{24}
\end{aligned}
$$

## Computing the Mean of a Transformed Continuous Random Variable

**Example:** Given that $X$ is a continuous random variable with the following probability density function, compute $\textrm E[7X-4]$.

$f(x) = \dfrac{3x^2}{7}, \quad 1 < x < 2$

**Explanation**

First, we simplify using the properties of expected value:

$$
\textrm E[7X-4] = 7 \textrm E[X] - 4
$$

For a continuous random variable $X$ with probability density function $f(x)$ defined over a set $S$, we can calculate the expected value using the following formula:

$$
\textrm{E}[X] = \int_S x \cdot f(x) \,\textrm{d}x
$$

So, we calculate the expected value of $X$ as follows:

$$
\begin{aligned}
E[X] &= ∫_{S}x \cdot f(x)dx \\
&= ∫_{1}^{2}x \cdot \frac{3x^{2}}{7}dx \\
&= ∫_{1}^{2}\frac{3x^{3}}{7}dx \\
&= \frac{3x^{4}}{28} \mid _{1}^{2} \\
&= \frac{45}{28}
\end{aligned}
$$

Therefore,

$$
\begin{aligned}
E[7X - 4] &= 7E[X] - 4 \\
&= 7 \cdot \frac{45}{28} - 4 \\
&= \frac{29}{4}
\end{aligned}
$$
