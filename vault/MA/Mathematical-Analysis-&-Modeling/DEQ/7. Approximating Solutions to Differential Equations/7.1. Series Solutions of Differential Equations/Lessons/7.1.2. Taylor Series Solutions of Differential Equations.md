## Introduction

We can use Taylor series to approximate the solution to a differential equation. For example, let's find a series solution about $x=0$, in ascending powers of $x$ up to and including the term in $x^3$, of the initial value problem

$$
y''=x+y, \qquad y(0)=2, \quad y'(0)=3
$$

We start by writing the form of the Taylor series of $y(x)$ about $x=0$:

$$
y(x) = y(0) + xy'(0) + \dfrac{x^2}{2!}y''(0) + \dfrac{x^3}{3!}y^{(3)}(0)+\cdots
$$

We're given $y(0)$ and $y'(0)$, so we need to calculate $y''(0)$ and $y^{(3)}(0)$.

- We know that $y(0)=2$, so we substitute this into the given equation to find $y''(0)$:
$y^{″}(0)|= 0 + y(0); = 0 + 2; = 2$
- Next, to find an expression for $y^{(3)}(x)$, we differentiate both sides on the given equation with respect to $x$:
$y^{(3)}=1 + y'$
We can now find $y^{(3)}(0)$ by substituting in the known values:
$y^{(3)}(0)|= 1 + y^{′}(0); = 1 + 3; = 4$

Finally, we substitute the obtained values in the Taylor series:

$$
\begin{aligned}
y(x) &= y(0) + xy^{′}(0) + \frac{x^{2}}{2!}y^{″}(0) + \frac{x^{3}}{3!}y^{(3)}(0) + ⋯ \\
&= 2 + x \cdot 3 + \frac{x^{2}}{2!} \cdot 2 + \frac{x^{3}}{3!} \cdot 4 + ⋯ \\
&= 2 + 3x + x^{2} + \frac{2x^{3}}{3} + ⋯
\end{aligned}
$$

## Finding a Series Solution to a Second-Order Initial Value Problem About Zero

**Example:** Use the Taylor series method to find a series solution about $x=0$, in ascending powers of $x$ up to and including the term in $x^3$, of the initial value problem
$y''=y+e^{-4x}, \qquad y(0)=0, \quad y'(0)=2$.

**Explanation**

We wish to express $y(x)$ as a Taylor series about $x=0$:

$$
y(x) = y(0) + xy'(0) + \dfrac{x^2}{2!}y''(0) + \dfrac{x^3}{3!}y^{(3)}(0)+\cdots
$$

We're given $y(0)$ and $y'(0)$, so we need to calculate $y''(0)$ and $y^{(3)}(0)$.

- We know that $y(0)=0$, so we substitute this into the given equation to find $y''(0)$:
$y^{″}(0)|= y(0) + e^{-4(0)}; = 0 + 1; = 1$
- Next, to find an expression for $y^{(3)}(x)$, we differentiate both sides on the given equation with respect to $x$:
$y^{(3)}=y'-4e^{-4x}$
We can now find $y^{(3)}(0)$ by substituting in the known values:
$y^{(3)}(0)|= y^{′}(0) - 4e^{-4(0)}; = 2 - 4; =-2$

Finally, we substitute the obtained values in the Taylor series:

$$
\begin{aligned}
y(x) &= y(0) + xy^{′}(0) + \frac{x^{2}}{2!}y^{″}(0) + \frac{x^{3}}{3!}y^{(3)}(0) + ⋯ \\
&= 0 + x \cdot 2 + \frac{x^{2}}{2!} \cdot 1 + \frac{x^{3}}{3!} \cdot (-2) + ⋯ \\
&= 2x + \frac{x^{2}}{2} - \frac{x^{3}}{3} + ⋯
\end{aligned}
$$

## Finding a Series Solution to a Second-Order Initial Value Problem About a Non-Zero Point

**Example:** Use the Taylor series method to find a series solution about $x=2$, in ascending powers of $(x-2)$ up to and including the term in $(x-2)^3$, of the initial value problem
$y''=y-2xy', \qquad y(2)=0, \quad y'(2)=1$.

**Explanation**

We wish to express $y(x)$ as a Taylor series about $x=2$:

$$
y(x) = y(2) + (x-2)y'(2) + \dfrac{(x-2)^2}{2!}y''(2) + \dfrac{(x-2)^3}{3!}y^{(3)}(2)+\cdots
$$

We're given $y(2)$ and $y'(2)$, so we need to calculate $y''(2)$ and $y^{(3)}(2)$.

- We substitute $y(2)=0$ and $y'(2)=1$ into the given equation to find $y''(2)$:
$y^{″}(2)|= y(2) - 2(2)y^{′}(2); = 0 - 4; =-4$
- Next, to find an expression for $y^{(3)}(x)$, we differentiate both sides on the given equation with respect to $x$:
$y^{(3)}(x)=-y' -2y' - 2xy'' = -3y'- 2xy''$
We can now find $y^{(3)}(2)$ by substituting in the known values:
$y^{(3)}(2)|=-3y^{′}(2) - 2(2)y^{″}(2); =-3 + 16; = 13$

Finally, we substitute the obtained values in the Taylor series:

$$
\begin{aligned}
y(x) &= y(2) + (x - 2)y^{′}(2) + ((x - 2)^{2})/(2!)y^{″}(2) + ((x - 2)^{3})/(3!)y^{(3)}(2) + ⋯ \\
&= 0 + (x - 2) \cdot 1 + ((x - 2)^{2})/(2) \cdot (-4) + ((x - 2)^{3})/(6) \cdot 13 + … \\
&= (x - 2) - 2(x - 2)^{2} + (13(x - 2)^{3})/(6) + ⋯
\end{aligned}
$$

## Finding a Series Solution to a First-Order Initial Value Problem

**Example:** Use the Taylor series method to find a series solution about $x=0$, in ascending powers of $x$ up to and including the term in $x^3$, of the initial value problem
$y'=2x-y \cos x, \qquad y(0)=4$.

**Explanation**

We wish to express $y(x)$ as a Taylor series about $x=0$:

$$
y(x) = y(0) + xy'(0) + \dfrac{x^2}{2!}y''(0) + \dfrac{x^3}{3!}y^{(3)}(0)+\cdots
$$

We're given $y(0)$, so we need to calculate $y'(0)$, $y''(0)$, and $y^{(3)}(0)$.

- We know that $y(0)=4$, so we substitute this into the given equation to find $y'(0)$:
$y^{′}(0)|= 2(0) - y(0)\cos 0; = 0 - 4(1); =-4$
- Next, to find an expression for $y''(x)$, we differentiate both sides on the given equation with respect to $x$:
$y''(x)=2-y'\cos x + y \sin x$
We can now find $y''(0)$ by substituting in the known values:
$y^{″}(0)|= 2 - y^{′}(0)\cos 0 + y(0)\sin 0; = 2 - (-4)(1) + 0; = 6$
- To find an expression for $y^{(3)}(x)$, we differentiate $y''(x)$ with respect to $x$:
$y^{(3)}(x)=-y''\cos x + 2y'\sin x + y \cos x$
We can now find $y^{(3)}(0)$ by substituting in the known values:
$y^{(3)}(0)|=-y^{″}(0)\cos 0 + y^{′}(0)\sin 0 + y(0)\cos 0; = - (6)(1) + (-4)(0) + (4)(1); =-2$

Finally, we substitute the obtained values in the Taylor series:

$$
\begin{aligned}
y(x) &= y(0) + xy^{′}(0) + \frac{x^{2}}{2!}y^{″}(0) + \frac{x^{3}}{3!}y^{(3)}(0) + ⋯ \\
&= 4 + x \cdot (-4) + \frac{x^{2}}{2} \cdot 6 + \frac{x^{3}}{6} \cdot (-2) + ⋯ \\
&= 4 - 4x + 3x^{2} - \frac{x^{3}}{3} + ⋯
\end{aligned}
$$
