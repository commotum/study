<a id="simply-connected-regions"></a>
## Simply-Connected Regions

A connected region $D$ is **simply connected** if every simple closed curve in $D$ can be contracted to a point.

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/704ab166a81e006b18ba38f85c16fc5b.png>)

When we have a connected *plane* region (e.g. a region in the $xy$-plane), determining whether it's simply connected is a little simpler: we just need to check whether the region contains holes.

Plane regions containing holes are not simply connected, since some simple closed curves cannot be contracted to a point:

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/42421d933a5fae7991e550465be995cd.png>)

So, if a connected plane region does not contain any holes, then it is simply connected.

More precisely, a connected *plane* region $D$ is simply connected if every simple closed curve in $D$ encloses only points in $D$.

## Identifying Simply-Connected Regions

**Example:** Which of the regions shown below are simply connected?

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/1164dfedfd68fecee2af1031295ffb86.png>)

**Explanation**

A connected region $D$ is simply connected if every simple closed curve in $D$ can be contracted to a point.

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/06bab6e6cec4b75e4a1363b4dbc20310.png>)

A connected *plane* region $D$ is simply connected if every simple closed curve in $D$ encloses only points in $D$. In other words, the region does not contain any holes. Plane regions containing holes are not simply connected, since some simple closed curves cannot be contracted to a point:

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/42d126c7bd2ac311262b659d2596dc37.png>)

With that in mind, let's examine each of the regions:

- Region I is not simply connected. Instead, this is a connected region that contains a hole.
- Region II is simply connected. This is a connected region that does not contain holes.
- Region III is not simply connected. Instead, this is a region that consists of two pieces (it's not connected).
- Region IV is simply connected. This is a connected region that does not contain holes.

Therefore, the correct answer is "II and IV only."

## Identifying Simply-Connected Regions in Euclidian Space

**Example:** Which of the following regions are simply connected?

1. $\{(x,y) \in \mathbb R^2 \: \mid \: y-x\geq 0\}$
2. $\{(x,y) \in \mathbb R^2 \: \mid \: (x,y)\neq (0,0)\}$
3. $\{(x,y)\in \mathbb R^2 \: \mid \: x^2+y^2> 4\}$

**Explanation**

A connected region $D$ is simply connected if every simple closed curve in $D$ can be contracted to a point.

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/998c3fae4e98a4fcb65db22d9a3b178a.png>)

A connected *plane* region $D$ is simply connected if every simple closed curve in $D$ encloses only points in $D$. In other words, the region does not contain any holes. Plane regions containing holes are not simply connected, since some simple closed curves cannot be contracted to a point:

![](<../Source/1.3.6. Connected and Simply-Connected Regions/Images/06500334cbe214f995d2491dc71265a1.png>)

Let's now examine our regions in turn.

- Region I is simply connected. Indeed, it is the half-plane $y \geq x$. So, it's a plane region without holes.
- Region II is *not* simply connected since it's a plane region with a hole at $(0,0)$.
- Region III is *not* simply connected since it's a plane region with a hole. In this case, the hole contains all points on the disc $x^2+y^2 \leq 4$.

Therefore, the correct answer is "I only."
