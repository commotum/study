## Introduction

The cumulative distribution function (or CDF) of a continuous random variable is defined the same way as for a discrete random variable.

Given a continuous random variable $X$, the CDF is the function $F(x)$ such that

$$
F(x) = P(X \leq x)
$$

If our random variable has the probability density function (or PDF) $f(x)$, then we have

$$
F(x) = P(X \leq x) = \int_{-\infty}^x f(t) \, \textrm dt
$$

Note that we use $f(t)dt$ in the integrand because $x$ serves as the upper limit of integration.

For example, consider the random variable $X$ with the following PDF:

$[MATH: {(2)/(π(1 + x^{2})), \mid x ∈ [0, ∞); 0, \mid otherwise]$

Since

$$
f(x)= 0
$$

for all $x < 0$, we have

$$
F(x) = \int_{-\infty}^x 0 \, \textrm dt = 0
$$

if $x<0$.

To compute the CDF for

$$
x\geq 0
$$

we integrate $f(x)$ as follows:

$$
\begin{aligned}
F(x) &= ∫_{- ∞}^{x}f(t)dt \\
&= ∫_{- ∞}^{0}f(t)dt + ∫_{0}^{x}f(t)dt \\
&= 0 + ∫_{0}^{x}(2)/(π(1 + t^{2}))dt \\
&= \frac{2}{π}\arctan t \mid _{0}^{x} \\
&= \frac{2}{π}\arctan x - \frac{2}{π}(0) \\
&= \frac{2}{π}\arctan x
\end{aligned}
$$

Expressing our CDF as a function defined over the entire real line, we get

$$
{0,\begin{vmatrix}x < 0, \\ \frac{2}{π}\arctan x,\end{vmatrix}x \ge 0
$$

## Finding a CDF Given a PDF With a Lower Bound

**Example:** Given that the random variable $X$ has the probability density function
${e^{-x},\begin{vmatrix}x \ge 0, \\ 0,\end{vmatrix}x < 0$,

find the cumulative distribution function $F(x)$.

**Explanation**

Since our random variable $X$ has a probability distribution function $f(x)$ that is strictly positive only for

$$
x \geq 0
$$

the cumulative distribution function takes the following form:

$$
{0,\begin{vmatrix}x < 0, \\ ∫_{0}^{x}f(t)dt,\end{vmatrix}x \ge 0
$$

For the given probability density function, we have

$$
\begin{aligned}
∫_{0}^{x}f(t)dt &= ∫_{0}^{x}e^{-t}dt \\
&=-e^{-t} \mid _{0}^{x} \\
&=-e^{-x} + 1 \\
&= 1 - e^{-x}
\end{aligned}
$$

So, the cumulative distribution function is given by

$$
{0,\begin{vmatrix}x < 0, \\ 1 - e^{-x},\end{vmatrix}x \ge 0
$$

## Computing a CDF Given a PDF That’s Nonzero Over All Real Numbers

**Example:** Given that the random variable $X$ has the probability density function
$f(x) = e^{-\mid 2x \mid}, \quad x \in (-\infty, \infty)$,

find the cumulative distribution function $F(x)$.

**Explanation**

Since our random variable $X$ has a probability distribution function $f(x)$ that involves an absolute value, the cumulative distribution function takes the following form:

$$
{∫_{- ∞}^{x}e^{2t}dt,\begin{vmatrix}x < 0, \\ ∫_{- ∞}^{0}e^{2t}dt + ∫_{0}^{x}e^{-2t}dt,\end{vmatrix}x \ge 0
$$

Let's compute the integrals.

- If $x \leq 0$, we have
$∫_{- ∞}^{x}e^{2t}dt|= \frac{e^{2t}}{2} \mid _{- ∞}^{x}; = \frac{e^{2x}}{2}$,
Therefore,
$∫_{- ∞}^{0}e^{2t}dt|= \frac{e^{2x}}{2} \mid _{x = 0}; = \frac{1}{2}$.
- If $x > 0$, we have
$∫_{0}^{x}e^{-2t}dt|=-\frac{e^{-2t}}{2} \mid _{0}^{x}; =-\frac{e^{-2x}}{2} + \frac{1}{2}$.
As a result, we get
$∫_{- ∞}^{0}e^{2t}dt + ∫_{0}^{x}e^{-2t}dt|= \frac{1}{2} + (-\frac{e^{-2x}}{2} + \frac{1}{2}); = 1 - \frac{e^{-2x}}{2}$.

So, the cumulative distribution function is given by

$$
{\frac{e^{2x}}{2},\begin{vmatrix}x < 0, \\ 1 - \frac{e^{-2x}}{2},\end{vmatrix}x \ge 0
$$

## Finding a CDF Given a PDF With Lower and Upper Bounds

When a random variable $X$ has a probability distribution function $f(x)$ that is strictly positive on the interval

$$
a \leq x \leq b
$$

only, we have

- $P(X \leq x) = 0$ for $x < a$, and
- $P(X \leq x) = 1$ for $x > b$.

In these cases, the cumulative distribution function takes the following form:

$$
{0,\begin{vmatrix}x < a \\ ∫_{a}^{x}f(t)dt,\end{vmatrix}a \le x \le b; 1, \mid x > b
$$

---

<a id="finding-a-cdf-given-a-pdf-with-lower-and-upper-bounds"></a>
## Finding a CDF Given a PDF With Lower and Upper Bounds

**Example:** Given that the random variable $X$ has the probability density function
${\frac{1}{72}x,\begin{vmatrix}0 \le x \le 12, \\ 0,\end{vmatrix}otherwise$,

find the cumulative distribution function $F(x)$.

**Explanation**

Since our random variable $X$ has a probability distribution function $f(x)$ that is strictly positive only for

$$
0 \leq x \leq 12
$$

the cumulative distribution function takes the following form:

$$
{0,\begin{vmatrix}x < 0 \\ ∫_{0}^{x}f(t)dt,\end{vmatrix}0 \le x \le 12; 1, \mid x > 12
$$

For the given probability density function, we have

$$
\begin{aligned}
∫_{0}^{x}f(t)dt &= ∫_{0}^{x}\frac{1}{72}tdt \\
&= \frac{1}{144}t^{2} \mid _{0}^{x} \\
&= \frac{1}{144}x^{2}
\end{aligned}
$$

So, the cumulative distribution function is given by

$$
{0,\begin{vmatrix}x < 0 \\ \frac{x^{2}}{144},\end{vmatrix}0 \le x \le 12; 1, \mid x > 12
$$

## Using a CDF to Compute a Probability Over an Interval

As with discrete random variables, we can use the CDF of a continuous random variable to quickly compute a probability over an interval:

$$
P(a \leq X \leq b) = F(b) - F(a)
$$

For example, suppose that a random variable $X$ has the following CDF:

$$
F(x) = \dfrac{1}{1+e^{-x}}, \qquad -\infty < x < \infty
$$

We can use the above CDF to quickly compute

$$
P(0 \leq x \leq 1)
$$

as follows:

$$
\begin{aligned}
P(0 \le x \le 1) &= F(1) - F(0) \\
&= \frac{1}{1 + e^{-1}} - \frac{1}{1 + e^{0}} \\
&= \frac{1}{1 + e^{-1}} - \frac{1}{2} \\
&\approx 0.231
\end{aligned}
$$

Remember that for continuous random variables, it doesn't matter whether or not we include the endpoints of the interval, so we have

$$
P(0 \leq X \leq 1) = P(0 < X \leq 1) = P(0 \leq X < 1) = P(0 < X < 1) = 0.231
$$

In general, for a continuous random variable $X$, we have

$$
P(a \leq X \leq b) = P(a < X \leq b) = P(a \leq X < b) = P(a < X < b) = F(b) - F(a)
$$

<a id="computing-a-probability-over-an-interval-using-a-cdf"></a>
## Computing a Probability Over an Interval Using a CDF

**Example:** Given that the random variable $X$ has the cumulative distribution function
${0,\begin{vmatrix}x < 5 \\ \frac{x^{2} - 25}{75},\end{vmatrix}5 \le x \le 10; 1, \mid x > 10$,

find $P(2\leq X \leq 6)$.

**Explanation**

Remember that for continuous random variables, it doesn't matter whether or not we include the endpoints of the interval. So we can perform this computation as follows:

$$
\begin{aligned}
P(2 \le X \le 6) &= P(2 < X \le 6) \\
&= P(X \le 6) - P(X \le 2) \\
&= F(6) - F(2) \\
&= \frac{6^{2} - 25}{75} - 0 \\
&= \frac{11}{75}
\end{aligned}
$$
