## Introduction

The **intersection** of two intervals is their set of common values, and is denoted by the intersection symbol $\cap$.

For example, the intersection of the two intervals $[MATH: (-\infty, 2]]$ and $[MATH: [-1,\infty)]$ is denoted

$[MATH: (-\infty, 2] \cap [-1,\infty)]$

and corresponds to the set of values that are in both intervals $[MATH: (-\infty, 2]]$ and $[MATH: [-1,\infty).]$

To represent the intersection on a number line, we can start by sketching the two intervals separately:

![](<../Source/1.3.5. Intersections of Intervals/Images/fb5cefe4f7f7ee5e32772e3e0e5d4141.png>)

![](<../Source/1.3.5. Intersections of Intervals/Images/8f0cc1633dbb14ad0bc80d00986a2425.png>)

The intersection $[MATH: (-\infty, 2] \cap [-1,\infty)]$ represents the values that are in both intervals. So, it can be graphed by finding where the two intervals overlap:

![](<../Source/1.3.5. Intersections of Intervals/Images/4e829159c371d29ff10fb686ea65f3d5.png>)

Therefore, the intersection of the intervals is ${\color{blue}[-1,2]}$. Symbolically, we write

$[MATH: {\color{red}(-\infty,2]} \cap {\color{red}[-1,\infty)} = {\color{blue}[-1,2]}.]$

## Finding the Intersection of Two Intervals

**Example:** Find the intersection of intervals $[MATH: (-\infty, 3] \cap (0, \infty).]$ Express the result as an inequality.

**Explanation**

We can start by sketching the two intervals $[MATH: (-\infty, 3]]$ and $(0, \infty)$ separately:

![](<../Source/1.3.5. Intersections of Intervals/Images/21a09c95672de97f3ee5764c28cf4316.png>)

![](<../Source/1.3.5. Intersections of Intervals/Images/44ddfef2b5f9328a43ed4807113494bc.png>)

The intersection $[MATH: (-\infty, 3] \cap (0, \infty)]$ represents the values that are in both intervals. So, it can be graphed by finding where the two intervals overlap:

![](<../Source/1.3.5. Intersections of Intervals/Images/0d736537b7f1b1b6668597898e388738.png>)

Thus, $[MATH: (-\infty, 3]\cap(0, \infty)={\color{blue}(0,3]}.]$ This corresponds to the inequality

$$
0 < x \leq 3
$$

**Watch out!** The point $0$ is not included in the intersection since it does not lie in the second interval. On the other hand, the point $3$ is included in the intersection because it lies in both intervals.

## Finding the Intersection of Two Intervals Given as Inequalities

**Example:** Given the inequalities $x < 3$ and $x \leq -1$, express their common set of solutions as an interval.

**Explanation**

We start by sketching the solutions to the two inequalities separately:

![](<../Source/1.3.5. Intersections of Intervals/Images/2f7a2766509ca9a313d180ce1fe49ec0.png>)

![](<../Source/1.3.5. Intersections of Intervals/Images/8aba3d1eb86cee7077ce3e2752c2c3d7.png>)

The common set of values consists of the values that are in both intervals. So, it can be graphed by finding where the two intervals overlap:

![](<../Source/1.3.5. Intersections of Intervals/Images/0afb1fb95005f6a3220d45f0d2bc34f9.png>)

Therefore, the common set of values is
$[MATH: {\color{blue}(-\infty, -1]}.]$

## Finding the Intersection of Three Intervals

**Example:** Given the inequalities $x < 1$, $x \geq 0$, and $-2 < x < 4$, express their common set of solutions as an interval.

**Explanation**

To find the common set of values, we graph the inequalities on a number line and find where they overlap:

![](<../Source/1.3.5. Intersections of Intervals/Images/68a0a00a10d1d74a8dd5ab60c5b70555.png>)

Therefore, the common set of values is
$[MATH: {\color{blue}\left[0, 1\right)}.]$

**Watch out!** The point $0$ is included in the intersection since it lies in all three intervals. On the other hand, the point $1$ is not included in the intersection because it does not lie in the first interval.
