<a id="introduction"></a>
## Introduction

We've seen what it means for two segments or angles to be congruent. In this lesson, we'll explore the concept of congruence in more detail. As we'll see, this deeper understanding is needed to prove results from geometry.

Before we explore congruence, let's take a step back and examine what it means for two numbers to be *equal.*

Consider the following statements:

$$
1+1 = 2, \qquad\qquad 2 = 3-1
$$

All three expressions, namely

$$
1+1,\qquad 2,\qquad 3-1
$$

are **equivalent representations** of the same number. That is, they all represent the number $2$.

There are many ways to represent the number $2$. Let's list a few more:

$$
1+1, \qquad \dfrac{2}{1}, \qquad 3-1, \qquad 2, \qquad \dfrac{4}{2}, \qquad \ldots
$$

We can combine all these equivalent representations into a single collection (or **set**), like the one shown below.

![](<../Source/1.3.8. Properties of Congruence/Images/e4d05934ccc583e00ed56a8c556ddb2c.png>)

Imagine that this set contains *all possible representations* of the number $2{:}$

Now, let's state some important properties that relate the different representations to each other:

- The **reflexive** property of equality: Every representation *equals itself*.For example, the statement
$2 = 2$
is true. Also
$1+1 = 1+1, \qquad 3-1 = 3-1, \qquad$
are both true.
- The **symmetric** property of equality: We can *switch the order* of the numbers in an equality statement.For example,
$\textrm{if}\:\: {\color{blue}{1}} + {\color{blue}{1}} = {\color{red}{2}},\:\: \textrm{then} \:\: {\color{red}{2}} = {\color{blue}{1}} + {\color{blue}{1}}$.
Similarly,
$\textrm{if}\:\: {\color{blue}{1}} + {\color{blue}{1}} = {\color{red}{3}} - {\color{red}{1}},\:\: \textrm{then} \:\: {\color{red}{3}} - {\color{red}{1}} = {\color{blue}{1}} + {\color{blue}{1}}$.
- The **transitive** property of equality: If one representation equals a second, and the second equals a third, then the first equals the third:For example,
$\textrm{if}\:\: {\color{blue}{1}} + {\color{blue}{1}} = {\color{red}{2}}\:\: \textrm{and} \:\: {\color{red}{2}} = {\color{purple}{3}} - {\color{purple}{1}}, \:\: \textrm{then} \:\: {\color{blue}{1}} + {\color{blue}{1}} ={\color{purple}{3}} - {\color{purple}{1}}$.

Reflexivity, symmetricity, and transitivity capture what it means for numbers to be equal. Please take a moment to reread them and make sure you understand. You'll be using them a lot in the future.

<a id="reflexivity-symmetricity-and-transitivity-of-equality"></a>
## Reflexivity, Symmetricity, and Transitivity of Equality

Let's now state our three properties of equality more generally:

- The **reflexive** property of equality:
$a = a$
This states that every number equals itself.
- The **symmetric** property of equality:
$\textrm{If}\: a = b, \textrm{then}\: b=a$
This states that if the first number equals the second, the second must equal the first.
- The **transitive** property of equality:
$\textrm{If}\: a = b \:\textrm{and}\: b=c,\textrm{then}\:a=c$
This states that if the first number equals the second and the second equals the third, the first must equal the third.

<a id="equality-of-numbers"></a>
## Equality of Numbers

**Example:** Consider the following true statement.

$\qquad$ Since $2 \cdot 5 = 10$ and $10 = 4+6$, we have $2 \cdot 5 = 4+6$.

Which property of equality makes this statement true?

**Explanation**

The following properties are valid for all integers $a, b$, and $c{:}$

- The *reflexive* property of equality:
$a = a$
This states that every number equals itself.
- The *symmetric* property of equality:
$\textrm{If}\: a = b, \textrm{then}\: b=a$
This states that if the first number equals the second, the second must equal the first.
- The *transitive* property of equality:
$\textrm{If}\: a = b \:\textrm{and}\: b=c,\textrm{then}\:a=c$
This states that if the first number equals the second and the second equals the third, the first must equal the third.

We can rewrite the given sentence as follows:

> If $2 \cdot 5 = 10$ and $10 = 4+6$, then $2 \cdot 5 = 4+6$.

Therefore, this statement is true by the $\bbox[3pt,Gainsboro]{\color{blue}\textrm{transitive}}$ property of equality.

<a id="congruence-of-segments"></a>
## Congruence of Segments

Recall that two segments are *congruent* if they have the same length.

Suppose we have a segment $\overline{AB}$. Similar to earlier, we can create a collection (or **set**) containing *all* segments congruent to $\overline{AB}$.

![](<../Source/1.3.8. Properties of Congruence/Images/7281043783955c84ab6a7cc733d3664d.png>)

Imagine this set contains *every* segment congruent to $\overline{AB}$. In other words, it contains every segment with the *same length* as $\overline{AB}$.

Here's the key concept: segment congruence has the same equivalence properties as equality!

- The **reflexive** property of congruence: Every segment is congruent with itself:For example:
$\overline{AB}\cong \overline{AB}, \qquad \overline{CD}\cong \overline{CD}$
- The **symmetric** property of congruence: We can *switch the order* of the segments in a congruence statement:For example,
$\textrm{if}\:\: {\color{blue}{\overline{AB}}} \cong {\color{red}{\overline{CD}}},\:\: \textrm{then} \:\: {\color{red}{\overline{CD}}} \cong {\color{blue}{\overline{AB}}}$.
- The **transitive** property of congruence: If one segment is congruent to a second, and the second is congruent to a third, then the first is congruent to the third:For example,
$\textrm{if}\:\: {\color{blue}{\overline{AB}}} \cong {\color{red}{\overline{CD}}} \:\: \textrm{and} \:\: {\color{red}{\overline{CD}}} \cong {\color{purple}{\overline{EF}}}, \:\: \textrm{then} \:\: {\color{blue}{\overline{AB}}} \cong {\color{purple}{\overline{EF}}}$.

<a id="reflexivity-symmetricity-and-transitivity-of-congruence"></a>
## Reflexivity, Symmetricity, and Transitivity of Congruence

Suppose that $a, b$, and $c$ are all segments. Let's state our three properties of segment congruence more generally.

- The *reflexive* property of congruence:
$a \cong a$
This states that every segment is congruent to itself.
- The *symmetric* property of congruence:
$\textrm{If}\: a \cong b, \textrm{then}\: b \cong a$
This states that if the first segment is congruent to the second, the second must be congruent to the first.
- The *transitive* property of congruence:
$\textrm{If}\: a \cong b \:\textrm{and}\: b \cong c,\textrm{then}\:a \cong c$
This states that if the first segment is congruent to the second, and the second is congruent to the third, the first must be congruent to the third.

## Segment Congruence

**Example:** Consider the following true statement.

![](<../Source/1.3.8. Properties of Congruence/Images/a621cbc85ce0a9638f9a28a048158392.png>)

$\qquad$ Since $\overline{AB} \cong \overline{AC}$, we have $\overline{AC} \cong \overline{AB}$.

Which property of congruence makes this statement true?

**Explanation**

The following properties are valid for all segments $a, b$, and $c{:}$

- The *reflexive* property of congruence:
$a \cong a$
This states that every segment is congruent to itself.
- The *symmetric* property of congruence:
$\textrm{If}\: a \cong b, \textrm{then}\: b \cong a$
This states that if the first segment is congruent to the second, the second must be congruent to the first.
- The *transitive* property of congruence:
$\textrm{If}\: a \cong b \:\textrm{and}\: b \cong c,\textrm{then}\:a \cong c$
This states that if the first segment is congruent to the second, and the second is congruent to the third, the first must be congruent to the third.

We can rewrite the given sentence as follows:

> If $\overline{AB} \cong \overline{AC}$, then $\overline{AC} \cong \overline{AB}$.

Therefore, this statement is true by the $\bbox[3pt,Gainsboro]{\color{blue}\textrm{symmetric}}$ property of congruence.

## Congruence of Angles

![](<../Source/1.3.8. Properties of Congruence/Images/a036a18e97fb8ae6d781e795c6308b1b.png>)

Congruent *angles* also have the properties of reflexivity, symmetricity, and transitivity. Let's list them:

- The **reflexive** property of congruence:
$\angle a \cong \angle a$
This states that every angle is congruent to itself.
- The **symmetric** property of congruence:
$\textrm{If}\: \angle a \cong \angle b, \textrm{then}\: \angle b \cong \angle a$
This states that if the first angle is congruent to the second, the second must be congruent to the first.
- The **transitive** property of congruence:
$\textrm{If}\: \angle a \cong \angle b \:\textrm{and}\: \angle b \cong \angle c,\textrm{then}\:\angle a \cong \angle c$
This states that if the first angle is congruent to the second, and the second is congruent to the third, the first must be congruent to the third.

## Angle Congruence

**Example:** Consider the following true statement.

![](<../Source/1.3.8. Properties of Congruence/Images/7c4714b40926a93d48fcbacb8ac6b782.png>)

$\qquad$ Since $\angle ADC \cong\angle BDC$, we have $\angle BDC \cong \angle ADC$.

Which property of congruence makes this statement true?

**Explanation**

The following properties are valid for all angles $\angle a, \angle b$, and $\angle c\,{:}$

- The *reflexive* property of congruence:
$\angle a \cong \angle a$
This states that every angle is congruent to itself.
- The *symmetric* property of congruence:
$\textrm{If}\: \angle a \cong \angle b, \textrm{then}\: \angle b \cong \angle a$
This states that if the first angle is congruent to the second, the second must be congruent to the first.
- The *transitive* property of congruence:
$\textrm{If}\: \angle a \cong \angle b \:\textrm{and}\: \angle b \cong \angle c,\textrm{then}\:\angle a \cong \angle c$
This states that if the first angle is congruent to the second, and the second is congruent to the third, the first must be congruent to the third.

We can rewrite the given sentence as follows:

> If $\angle ADC \cong\angle BDC$, then $\angle BDC \cong \angle ADC$.

Therefore, this statement is true by the $\bbox[3pt,Gainsboro]{\color{blue}\textrm{symmetric}}$ property of congruence.

<a id="omitting-the-symmetric-property"></a>
## Omitting the Symmetric Property

We occasionally skip referencing the symmetric property when proving mathematical statements involving equality and congruence. This helps to make our proofs a bit shorter.

For example, suppose we have the following two equations:

$$
x = y^2, \qquad x = 2
$$

We can construct a formal proof that $y^2 = 2$ using a so-called two-column format as follows:

|  | Statement | Reason |
| --- | ---: | ---: |
| 1 | $x=y^2$ | Given |
| 2 | $y^2 = x$ | Symmetric property of equality |
| 3 | $x=2$ | Given |
| 4 | $y^2=2$ | Transitive property of equality |

The last line is true because, from rows 2 and 3 respectively, we have

$$
y^2 = {\color{red}{x}} \quad \textrm{and}\quad {\color{red}{x}}=2
$$

and so by the transitive property of equality,
$y^2 = 2$.

We can construct a shorter proof by omitting the second line:

|  | Statement | Reason |
| --- | ---: | ---: |
| 1 | $x=y^2$ | Given |
| 3 | $x=2$ | Given |
| 3 | $y^2=2$ | Transitive property of equality |

In this proof, the symmetric property is still applied "under the hood," but we don't explicitly refer to it.
