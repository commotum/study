## Introduction

Let's consider the function $f(x)$ whose mapping diagram is given below.

![](<../Source/3.1.2. One-To-One Functions/Images/a248e156af2a307602104a798d4aeee0.png>)

Notice that each element $y$ in the range is paired with one (*and only one*) element $x$ in the domain. Such functions are called **one-to-one** functions.

On the other hand, for the function $g(x)$ shown below, we no longer have that property.

![](<../Source/3.1.2. One-To-One Functions/Images/df4799d70c10f9dd837dfd42c06f1cf4.png>)

In the mapping diagram of $g(x)$, there are two arrows (originating from $3$ and $5$ in the domain) that are landing at the element $1$ in the range. So this element in the range is paired with *multiple* elements in the domain. Such functions are called **many-to-one** functions.

<a id="determining-whether-a-function-is-one-to-one-from-a-mapping-diagram"></a>
## Determining Whether a Function is One-To-One From a Mapping Diagram

**Example:** Which of the following statements are true regarding the function represented by the mapping diagram above?

![](<../Source/3.1.2. One-To-One Functions/Images/f489e3023135ef5f7408bed151c88e96.png>)

1. It is one-to-one
2. It is many-to-one
3. It is not a function

**Explanation**

Remember that

- a mapping diagram represents a *function* if every element in the domain maps to exactly one element in the range,
- a function is *one-to-one* if every element in the range is paired with one (and only one) element in the domain, and
- a function is *many-to-one* if some element in the range is paired with multiple elements in the domain.

In the given mapping diagram, every element in the domain maps to exactly one element in the range, so it represents a function.

The element $0$ in the range is paired with multiple elements ($0$ and $2$) in the domain, so the function is many-to-one but not one-to-one.

Therefore, the correct answer is "II only".

## Determining Whether a Function is One-To-One From a Table

**Example:** Which of the following statements are true regarding the function $g(x)$?

| **$x$** | $-9$ | $-3$ | $0$ | $3$ | $6$ | $9$ | $12$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $g(x)$ | $27$ | $3$ | $0$ | $4$ | $12$ | $27$ | $56$ |

1. It is one-to-one
2. It is many-to-one
3. It is not a function

**Explanation**

Remember that

- a mapping diagram represents a *function* if every element in the domain maps to exactly one element in the range,
- a function is *one-to-one* if every element in the range is paired with one (and only one) element in the domain, and
- a function is *many-to-one* if some element in the range is paired with multiple elements in the domain.

In the given table, every element in the domain maps to exactly one element in the range, so it represents a function.

The element $g(x)=27$ in the range is paired with multiple elements ($x=-9$ and $x=9$) in the domain, so the function is many-to-one but not one-to-one.

| **$x$** | $\color{red}-9$ | $-3$ | $0$ | $3$ | $6$ | $\color{red}9$ | $12$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $g(x)$ | $\color{blue}27$ | $3$ | $0$ | $4$ | $12$ | $\color{blue}27$ | $56$ |

Therefore, the correct answer is "II only".

<a id="the-horizontal-line-test"></a>
## The Horizontal Line Test

When a function is presented as a graph, there is a useful graphical method to determine whether a function is one-to-one or not. This method is called the **horizontal line test.**
Here is how it works:

**Step 1.** Plot the graph of the function.

**Step 2.** Draw a horizontal line on the plot.

**Step 3.** Imagine moving the horizontal line up and down across the entire range.

- If the horizontal line hits the graph only once no matter where we draw it, then the function is one-to-one.
- If the horizontal line *ever* hits the graph more than once, then the function is many-to-one.

To demonstrate, let's use the horizontal line test to determine whether the following is a one-to-one function.

![](<../Source/3.1.2. One-To-One Functions/Images/c7023a963323f701c50e74d743dc32a6.png>)

If we draw any horizontal line on the plot of the function above, it will hit the graph only once, no matter where we place the line.

![](<../Source/3.1.2. One-To-One Functions/Images/e56eae0a440c58439eabd65823057991.png>)

Therefore, this is a one-to-one function.

<a id="determining-whether-a-function-is-one-to-one-from-its-definition"></a>
## Determining Whether a Function Is One-To-One From Its Definition

**Example:** Which of the following statements are true regarding $f(x)= \mid x-3 \mid -2$?

1. It is one-to-one
2. It is many-to-one
3. It is a function

**Explanation**

The given $f(x)$ is a function because each input $x$ gives a unique output $y$.

To address the other statements, let's first make a graph of the function

$$
f(x)= \mid x-3 \mid -2
$$

as follows:

- Take the curve $y= \mid x \mid$.
- Translate it by $3$ units right to get $y= \mid x-3 \mid$.
- Shift it by $2$ units down to get $y= \mid x-3 \mid -2$.

If we apply the horizontal line test, we see that a horizontal line intersects the curve more than once for some horizontal lines. Therefore, it is many-to-one, not one-to-one.

![](<../Source/3.1.2. One-To-One Functions/Images/67ca80bd59ef5480863b1243fbe55933.png>)

So, the correct answer is "II and III only".
