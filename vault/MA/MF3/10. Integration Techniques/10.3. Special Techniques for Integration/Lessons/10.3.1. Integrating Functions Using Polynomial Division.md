## Introduction

How do we calculate

$$
\displaystyle \int\dfrac{3x+2}{x+2}\,\textrm d x\,
$$

We need to write the integrand so that it's something we can integrate. One way to do this is to divide $3x+2$ by $x+2$ using polynomial or synthetic division. We'll use synthetic division because it's faster.

To rewrite

$$
\dfrac{3x+2}{x+2}
$$

we complete a synthetic division table.

|  | $x^1$ | $x^0$ |
| --- | ---: | ---: |
| $\color{red}-2$ | $3$ | $2$ |
|  | $\color{gray}\downarrow$ | $-6$ |
|  | $3$ | $-4$ |

This tells us that

$$
\dfrac{3x+2}{x+2}
$$

can be decomposed into a quotient and remainder as

$$
\dfrac{3x+2}{x+2}= 3 - \dfrac{4}{x+2}
$$

Now, we can integrate the function, which gives

$$
\begin{aligned}
∫\frac{3x + 2}{x + 2}dx &= ∫(3 - \frac{4}{x + 2})dx \\
&= ∫3dx - 4∫\frac{1}{x + 2}dx \\
&= 3x - 4\ln \mid x + 2 \mid + C
\end{aligned}
$$

## Integrating a Quotient of Linear Polynomials

**Example:** Calculate $\displaystyle\int_0^1 \dfrac{4x-1}{x+1}\,\textrm d x$.

**Explanation**

The denominator of the integrand doesn't divide the numerator exactly, so we need to decompose it into its quotient and remainder. For this, we can use synthetic division.

We start by drawing up our synthetic division table:

|  | $x^1$ | $x^0$ |
| --- | ---: | ---: |
| $\color{red}-1$ | $4$ | $-1$ |
|  | $\color{gray}\downarrow$ | $-4$ |
|  | $4$ | $-5$ |

So, from the synthetic division, we get that

$$
\dfrac{4x-1}{x+1} = 4 -\dfrac{5}{x+1}
$$

Therefore,

$$
\begin{aligned}
∫_{0}^{1}\frac{4x - 1}{x + 1}dx &= ∫_{0}^{1}(4 - \frac{5}{x + 1})dx \\
&= ∫_{0}^{1}4dx - 5∫_{0}^{1}\frac{1}{x + 1}dx \\
&= 4x\begin{vmatrix}_{0}^{1} - 5\ln & x + 1\end{vmatrix} \mid _{0}^{1} \\
&= [4 - 0] - 5[\ln 2 - \ln 1] \\
&= 4 - 5\ln 2
\end{aligned}
$$

## Integrating a Rational Function Whose Denominator is Linear

**Example:** Calculate $\displaystyle\int \dfrac{2x^2-3x-4}{x-3}\,\textrm d x$.

**Explanation**

We first need to decompose the integrand into its quotient and remainder parts, which we can do using synthetic division.

We draw up a synthetic division table:

|  | $x^2$ | $x^1$ | $x^0$ |
| --- | ---: | ---: | ---: |
| $\color{red}3$ | $2$ | $-3$ | $-4$ |
|  | $\color{gray}\downarrow$ | $6$ | $9$ |
|  | $2$ | $3$ | $5$ |

So, from the synthetic division, we get that

$$
\begin{aligned} \dfrac{2x^2-3x-4}{x-3} = 2x + 3 + \dfrac {5}{x-3}. \end{aligned}
$$

Therefore,

$$
\begin{aligned}
∫\frac{2x^{2} - 3x - 4}{x - 3}dx &= ∫(2x + 3 + \frac{5}{x - 3})dx \\
&= x^{2} + 3x + 5\ln \mid x - 3 \mid + C
\end{aligned}
$$

## Integrating a Rational Function Whose Denominator Contains a Leading Coefficient

**Example:** Evaluate $\displaystyle\int \dfrac{x-1}{2x-1}\,\textrm d x$.

**Explanation**

First, we pull out the factor of $2$ from the denominator:

$$
\begin{aligned}
∫\frac{x - 1}{2x - 1}dx &= ∫(x - 1)/(2(x - \frac{1}{2}))dx \\
&= \frac{1}{2}∫(x - 1)/((x - \frac{1}{2}))dx
\end{aligned}
$$

Then, we draw up our synthetic division table to decompose the integrand into its quotient and remainder.

|  | $x^1$ | $x^0$ |
| --- | ---: | ---: |
| $\color{red}\dfrac12$ | $1$ | $-1$ |
|  | $\color{gray}\downarrow$ | $\dfrac12$ |
|  | $1$ | $-\dfrac12$ |

So, from the synthetic division, we get that

$$
\begin{aligned}
(x - 1)/((x - \frac{1}{2})) &= 1 - ((\frac{1}{2}))/((x - \frac{1}{2})) \\
&= 1 - (1)/(2(x - \frac{1}{2})) \\
&= 1 - \frac{1}{2x - 1}
\end{aligned}
$$

Therefore,

$$
\begin{aligned}
∫\frac{x - 1}{2x - 1}dx &= \frac{1}{2}∫(1 - \frac{1}{2x - 1})dx \\
&= \frac{1}{2}[x - \frac{1}{2}\ln\begin{vmatrix}2x - 1 & ] + C \\ = \frac{1}{2}x - \frac{1}{4}\ln & 2x - 1\end{vmatrix}+ C
\end{aligned}
$$
