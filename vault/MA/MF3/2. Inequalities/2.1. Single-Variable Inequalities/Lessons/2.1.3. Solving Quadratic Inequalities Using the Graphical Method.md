## Introduction

We can use the so-called **graphical method** to solve quadratic inequalities. For example, consider the inequality

$$
x^2 + x - 2 > 0
$$

To solve it, we need to find the values of $x$ for which the parabola

$$
y=x^2+x-2
$$

is *above* the $x$-axis.

First, let's find the roots of the parabola:

$$
\begin{aligned}
x^{2} + x - 2 &= 0 \\
(x + 2)(x - 1) &= 0
\end{aligned}
$$

So, the roots are $x=-2$ and $x=1$, and we can graph the parabola as follows:

![](<../Source/2.1.3. Solving Quadratic Inequalities Using the Graphical Method/Images/a67a0235539d64da1b5e9f2919f07364.png>)

The values marked in blue show all $x$-values where the parabola lies *above* the $x$-axis.

So, the solution to the inequality is $x \lt -2$ or $x \gt 1$.

## Solving Greater Than (Or Equal To) Inequalities

**Example:** Find the solution of $x^2-2x-8 \geq 0$.

**Explanation**

To solve the inequality

$$
x^2-2x-8 \geq 0
$$

we need to find the values of $x$ for which the parabola
$y=x^2-2x-8$
lies *above* the $x$-axis or touches this axis.

First, let's find the roots of the parabola:

$$
\begin{aligned}
x^{2} - 2x - 8 &= 0 \\
(x + 2)(x - 4) &= 0
\end{aligned}
$$

So, the roots are $x=-2$ and $x=4$, and we can graph the parabola as follows:

![](<../Source/2.1.3. Solving Quadratic Inequalities Using the Graphical Method/Images/d48ff6ef1caea411bdbfb5e32821a420.png>)

The values marked in blue show all $x$-values where the parabola lies *above* the axis or touches this axis.

So, the solution to the inequality is

$$
x \leq -2
$$

or

$$
x \geq 4
$$

## Solving Less Than (Or Equal To) Inequalities

**Example:** Find the solution of $-x^2 + 7 x - 10 \leq 0$.

**Explanation**

To solve the inequality

$$
-x^2 + 7 x - 10 \leq 0
$$

we need to find the values of $x$ for which the parabola

$$
y = -x^2 + 7 x - 10
$$

lies *below* the $x$-axis or touches this axis.

First, let's find the roots of the parabola:

$$
\begin{aligned}
-x^{2} + 7x - 10 &= 0 \\
- (x^{2} - 7x + 10) &= 0 \\
- (x - 2)(x - 5) &= 0
\end{aligned}
$$

So, the roots are $x=2$ and $x = 5$, and we can graph the parabola as follows:

![](<../Source/2.1.3. Solving Quadratic Inequalities Using the Graphical Method/Images/66589305706cca7f293953c16fb19690.png>)

The values marked in blue show all $x$-values where the parabola lies *below* the $x$-axis or touches this axis.

So, the solution to the inequality is

$$
x \leq 2
$$

or

$$
x \geq 5
$$

<a id="solving-quadratic-inequalities-that-require-rearrangement"></a>
## Solving Quadratic Inequalities That Require Rearrangement

Some inequalities require a rearrangement before applying the graphical method.

For example, let's find the solution of

$$
x^2 \ge 6-x
$$

To solve this inequality using the graphical method, we first move all the terms to the left-hand side, leaving only $0$ on the right-hand side of our inequality. This gives

$$
x^{2} + x - 6 \mid \ge 0
$$

So, we need to find the values of $x$ for which the parabola

$$
y = x^2 + x - 6
$$

lies above the $x$-axis or touches this axis. Let's find the roots of the parabola by factoring:

$$
\begin{aligned}
x^{2} + x - 6 &= 0 \\
(x + 3)(x - 2) &= 0
\end{aligned}
$$

We see that the roots are $x = -3$ and $x = 2$, so we can graph our parabola as follows:

![](<../Source/2.1.3. Solving Quadratic Inequalities Using the Graphical Method/Images/ba98912c3f10a44124d8d483a7881e54.png>)

Since we want to solve

$$
x^2 + x - 6 \ge 0
$$

we look for the part of the parabola that is *above* the $x$-axis or touches this axis.

Based on the graph, the solution is

$$
\color{blue}x \leq -3
$$

or

$$
\color{blue}x \geq 2
$$

We can also express our inequality in interval notation. In interval notation, our solution is

$[MATH: x \in {\color{blue}\left(-\infty,-3 \right]}\cup{\color{blue}\left[2, \infty\right)}.]$

## Solving Quadratic “Or Equal To” Inequalities That Require Rearrangement

**Example:** Find the solution of $2x^2-6 \le -4x$.

**Explanation**

To solve this inequality using the graphical method, we first need to move all of the numbers to the left-hand side so that the right-hand side is $0$.

$$
\begin{bmatrix}2x^{2} - 6 & \le - 4x \\ 2x^{2} + 4x - 6 & \le 0 \\ x^{2} + 2x - 3 & \le 0\end{bmatrix}
$$

So, we want to find the values of $x$ for which the parabola

$$
y=x^2+2x-3
$$

lies below the $x$-axis. Let's find the roots of the parabola by factoring:

$$
\begin{aligned}
x^{2} + 2x - 3 &= 0 \\
(x - 1)(x + 3) &= 0
\end{aligned}
$$

We see that the roots are $x=1$ and $x=-3$, and we can graph the parabola as follows:

![](<../Source/2.1.3. Solving Quadratic Inequalities Using the Graphical Method/Images/4927c4ddb9348af5ed197223c5719193.png>)

Since we are interested in solving

$$
x^2+2x-3 \le 0
$$

we look for the part of the parabola that is below the $x$-axis.

Based on the graph, the solution is

$$
-3 \le x \le 1
$$

Using interval notation, we write $x \in [-3,1]$.

## Solving Strict Quadratic Inequalities That Require Rearrangement

**Example:** Find the solution of $2x^2 < -4x$.

**Explanation**

To solve this inequality using the graphical method, we first need to move all of the numbers to the left-hand side so that the right-hand side is $0$.
$\begin{bmatrix}2x^{2} & < - 4x \\ 2x^{2} + 4x & < 0\end{bmatrix}$.

So, we want to find the values of $x$ for which the parabola

$$
y = 2x^2 + 4x
$$

lies below the $x$-axis. Let's find the roots of the parabola by factoring:

$$
\begin{aligned}
2x^{2} + 4x &= 0 \\
2x(x + 2) &= 0
\end{aligned}
$$

We see that the roots are $x = -2$ and $x = 0$, and we can graph the parabola as follows:

![](<../Source/2.1.3. Solving Quadratic Inequalities Using the Graphical Method/Images/bddb58670bbcb57b9f310b467227d839.png>)

Since we are interested in solving
$2x^2 + 4x \lt 0$,
we look for the part of the parabola that is below the $x$-axis.

Based on the graph, the solution is $-2 < x < 0$.

Using interval notation, we write

$$
x \in \left(-2, 0\right)
$$
