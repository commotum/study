## Introduction

Recall that a statement $\beta$ *follows* from statements $\alpha_1, \alpha_2, \ldots, \alpha_n$ if $\beta$ is true whenever *all* of $\alpha_1, \alpha_2, \ldots, \alpha_n$ are true. This is called a *logical inference*.

Let's consider another logical inference rule known as **disjunctive syllogism** (**disjunction elimination** or simply **elimination**). We can state this rule as follows:

$$
P∨Q; ¬P; ∴Q
$$

This rule reads as follows:

> *We have $P \lor Q$ and $\lnot P$. Therefore, $Q$.*

To check that the rule is valid, we can use a truth table:

|  |  |  | Premise 1 | Premise 2 | Conclusion |
| --- | ---: | ---: | ---: | ---: | ---: |
| $P$ | $Q$ |  | $P \lor Q$ | $\lnot P$ | $Q$ |
| $\textrm T$ | $\textrm T$ |  | $\textrm T$ | $\textrm F$ | $\textrm T$ |
| $\textrm T$ | $\textrm F$ |  | $\textrm T$ | $\textrm F$ | $\textrm F$ |
| $\textrm F$ | $\textrm T$ |  | $\color{blue} \textrm T$ | $\color{blue} \textrm T$ | $\color{red} \textrm T$ |
| $\textrm F$ | $\textrm F$ |  | $\textrm F$ | $\textrm T$ | $\textrm F$ |

Both $P \lor Q$ and $\lnot P$ have the truth value ${\color{blue}\mathrm{T}}$ (true) only in the third row of the table. For this row, $Q$ is also ${\color{red}\mathrm{T}}$ (true). So, according to the definition, we have a logical inference.

Since disjunction is commutative and the order of the premises does not matter, we have the following variants of the rule:

$$
P∨Q; ¬P; ∴Q
$$

<a id="a-concrete-example"></a>
## A Concrete Example

Let's complete the following logical inference:

$$
[math]x[/math] is positive or [math]x[/math] is less than [math]-1[/math]; [math]x[/math] is not positive; ∴A A A A A A A A A A A
$$

The logical inference rule of disjunctive syllogism asserts that if $P$ or $Q$ is true, yet $P$ is false, then $Q$ must be true.

Let's denote:

- $P(x)$: $x$ is positive
- $Q(x)$: $x$ is less than $-1$

Then, using the disjunctive syllogism rule, we obtain the following:

$$
P∨Q; ¬P; ∴Q
$$

Therefore, we have:

$$
[math]x[/math] is positive or [math]x[/math] is less than [math]-1[/math]; [math]x[/math] is not positive; ∴[math]x[/math] is less than [math]-1[/math]
$$

## Identifying Disjunction Elimination

**Example:** $¬K; K∨M; ∴A$
What is the missing part of the logical inference rule above?

**Explanation**

The logical inference rule of *disjunctive syllogism* asserts that if $P$ or $Q$ is true, yet $P$ is false, then $Q$ must be true.

In the case above, the disjunctive syllogism inference rule can be written as follows:

$$
¬K; K∨M; ∴M
$$

Therefore, the missing part is $M$.

## Logical Inference Using Disjunction Elimination

**Example:** According to the disjunctive syllogism inference rule, what is missing from the series of statements below?

$[math]x[/math] is divisible by [math]3[/math] or [math]x[/math] is prime; [math]x[/math] is not prime; [m a t h] x [/ m a t h] i s d i v i s i b l e b y [m a t h] 3 [/ m a t h]$.

**Explanation**

The logical inference rule of *disjunctive syllogism* asserts that if $P$ or $Q$ is true, yet $P$ is false, then $Q$ must be true.

Let's denote:

- $D(x)$: $x$ is divisible by $3$

Then, using our disjunctive syllogism inference rule, we obtain the following:

$$

$$

<a id="transitivity-of-implication"></a>
## Transitivity of Implication

Another important rule of logical inference is called **transitivity of implication** (**chain argument** or **hypothetical syllogism**):

$$
P⇒Q; Q⇒R; ∴P⇒R
$$

This rule is read as follows:

> *We have $P \Rightarrow Q$ and $Q \Rightarrow R$. Therefore, $P \Rightarrow R$.*

We can use a truth table to check this rule is valid:

|  |  |  |  | Premise 1 | Premise 2 | Conclusion |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $P$ | $Q$ | $R$ |  | $P \Rightarrow Q$ | $Q \Rightarrow R$ | $P \Rightarrow R$ |
| $\textrm T$ | $\textrm T$ | $\textrm T$ |  | ${\color{blue}\mathrm{T}}$ | ${\color{blue}\mathrm{T}}$ | ${\color{red}\mathrm{T}}$ |
| $\textrm T$ | $\textrm T$ | $\textrm F$ |  | $\textrm T$ | $\textrm F$ | $\textrm F$ |
| $\textrm T$ | $\textrm F$ | $\textrm T$ |  | $\textrm F$ | $\textrm T$ | $\textrm T$ |
| $\textrm T$ | $\textrm F$ | $\textrm F$ |  | $\textrm F$ | $\textrm T$ | $\textrm F$ |
| $\textrm F$ | $\textrm T$ | $\textrm T$ |  | ${\color{blue}\mathrm{T}}$ | ${\color{blue}\mathrm{T}}$ | ${\color{red}\mathrm{T}}$ |
| $\textrm F$ | $\textrm T$ | $\textrm F$ |  | $\textrm T$ | $\textrm F$ | $\textrm T$ |
| $\textrm F$ | $\textrm F$ | $\textrm T$ |  | ${\color{blue}\mathrm{T}}$ | ${\color{blue}\mathrm{T}}$ | ${\color{red}\mathrm{T}}$ |
| $\textrm F$ | $\textrm F$ | $\textrm F$ |  | ${\color{blue}\mathrm{T}}$ | ${\color{blue}\mathrm{T}}$ | ${\color{red}\mathrm{T}}$ |

Both $P \Rightarrow Q$ and $Q \Rightarrow R$ have the truth value ${\color{blue}\mathrm{T}}$ (true) in the first, fifth, seventh, and eighth rows of the table only. For these rows, $P \Rightarrow R$ also has the truth value ${\color{red}\mathrm{T}}$ (true). So, according to the definition, we have a logical inference.

Since the order of the premises does not matter, we have the following variants of the rule:

$$
P⇒Q; Q⇒R; ∴P⇒R
$$

<a id="a-concrete-example"></a>
## A Concrete Example

Let's complete the following logical inference:

$$
If [math]x[/math] is positive, then [math]2x[/math] is positive; If [math]2x[/math] is positive, then [math]2x+1[/math] is positive; ∴A A A A A A A A A A A
$$

The logical inference rule of *transitivity of implication* asserts that if $P$ implies $Q$ is true, and $Q$ implies $R$ is true, then $P$ implies $R$ must be true.

Let's denote:

- $P(x)$: $x$ is positive
- $Q(x)$: $2x$ is positive
- $R(x)$: $2x+1$ is positive

Then, using the transitivity of implication rule, we obtain the following:

$$
P⇒Q; Q⇒R; ∴P⇒R
$$

Therefore, we have:

$$
If [math]x[/math] is positive, then [math]2x[/math] is positive; If [math]2x[/math] is positive, then [math]2x+1[/math] is positive; ∴If [math]x[/math] is positive, then [math]2x+1[/math] is positive
$$

## Identifying Transitivity of Implication

**Example:** $L⇒M; K⇒L; ∴A A A$
What is the missing part of the logical inference rule above?

**Explanation**

The logical inference rule of *transitivity of implication* (also known as *hypothetical syllogism*) asserts that if $P$ implies $Q$ is true, and $Q$ implies $R$ is true, then $P$ implies $R$ must be true.

In this case, the hypothetical syllogism rule can be written as follows:

$$
L⇒M; K⇒L; ∴K⇒M
$$

Therefore, the missing part is $K \Rightarrow M$.

## Logical Inference Using Transitivity of Implication

**Example:** According to the rule of transitivity of implication, what is missing from the series of statements below?

$If [math]x[/math] is even, then [math]2 \mid x[/math]; If [math]2\mid x,[/math] then [math]2 \mid (x+8)[/math]; I f [m a t h] x [/ m a t h] i s e v e n, t h e n [m a t h] 2 ∣ (x + 8) [/ m a t h]$

**Explanation**

The logical inference rule of *transitivity of implication* (also known as *hypothetical syllogism*) asserts that if $P$ implies $Q$ is true, and $Q$ implies $R$ is true, then $P$ implies $R$ must be true.

Let's denote:

- $P(x)$: $x$ is even
- $Q(x)$: $2 \mid x$
- $R(x)$: $2 \mid (x+8)$

Then, using the transitivity of implication rule, we obtain the following:

$$
P⇒Q; Q⇒R; ∴P⇒R
$$

Therefore, we have:

$$
If [math]x[/math] is even, then [math]2 \mid x[/math]; If [math]2\mid x,[/math] then [math]2 \mid (x+8)[/math]; ∴If [math]x[/math] is even, then [math]2\mid (x+8)[/math]
$$
