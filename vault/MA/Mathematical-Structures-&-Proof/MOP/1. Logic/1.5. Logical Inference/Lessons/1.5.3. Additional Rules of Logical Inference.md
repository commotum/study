## Introduction

There are many inference rules in mathematical logic. In this lesson, we'll consider three more of them:

- The first of them is called **conjunction introduction**
$P; Q; ∴P∧Q$
It asserts that if $P$ and $Q$ are both true, then "$P$ and $Q$" is also true.
- The second one is **conjunction elimination**:
$P∧Q; ∴P$
It asserts that if "$P$ and $Q$" is true, then both $P$ and $Q$ are true.
- And the third one is called **disjunction introduction**:
$P; ∴P∨Q$
It asserts that if $P$ is true, then "$P$ or $Q$" is also true.

---

<a id="a-concrete-example"></a>
## A Concrete Example

Let's complete the following logical inference using conjunction elimination.

$$
[math]x[/math] is positive and irrational; ∴A A A A A A A A A A A
$$

Recall that conjunction elimination asserts that if "$P$ and $Q$" is true, then both $P$ and $Q$ are true.

Let's denote:

- $P(x)$: $x$ is positive
- $Q(x)$: $x$ is irrational

Then, using the conjunction elimination rule, we obtain the following:

$$
P∧Q; ∴Q
$$

Therefore, we have:

$$
[math]x[/math] is positive and irrational; ∴[math]x[/math] is irrational
$$

Since conjunction is commutative, $x$ is also a valid conclusion.

<a id="completing-an-inference-rule"></a>
## Completing an Inference Rule

**Example:** $P∧Q; ∴A$
Which of the following is the missing part of the logical inference rule above?

1. $P$
2. $\mathbf{t}$ (tautology)
3. $\lnot Q$

**Explanation**

The logical inference rule of *conjunction elimination* asserts that if "$P$ and $Q$" is true, then both $P$ and $Q$ are true.

The logical inference rule of *conjunction elimination* can be written as follows:
$P∧Q; ∴P$

We can also write the following:
$P∧Q; ∴Q$

Therefore, from the given options, the correct answer is "I only."

## Logical Inference Using the Additional Rules

**Example:** $[math]x[/math] is a perfect square and odd; ∴A A$

Which of the following is the missing part of the logical inference rule above?

1. $x$ is not a perfect square
2. $x$ is odd
3. $x$ is not odd

**Explanation**

The logical inference rule of *conjunction elimination* asserts that if "$P$ and $Q$" is true, then both $P$ and $Q$ are true.

Let's denote:

- $P(x)$: $x$ is a perfect square
- $Q(x)$: $x$ is odd

Then, using the conjunction elimination rule, we obtain the following:

$$
P∧Q; ∴Q
$$

Therefore, we have:

$$
[math]x[/math] is a perfect square and [math]x[/math] is odd; ∴[math]x[/math] is odd
$$

Hence, the correct answer is "II only."

## Combining the Rules of Logical Inference

The inference rules can be combined into multi-step derivations.

For example, suppose we are given the following facts:

- $n$ is positive and even
- If $n$ is even, then $6 \mid 3n$ is integer

Let's see what can be inferred from this.

Let's denote:

- $P(n)$: $n$ is positive
- $Q(n)$: $n$ is even
- $R(n)$: $6 \mid 3n$

With that in mind, let's apply some logical inference rules.

- Using the logical inference rule of *conjunction elimination*, we obtain the following:
$Missing \end{array}$
- Using the logical inference rule of *implication elimination* (also known as *modus ponens*) with the conclusion of the previous step, we get the following:
$Missing \end{array}$

In other words, given the above information, we can conclude that $3n$ must be divisible by $6$.

<a id="combining-inference-rules-in-symbolic-form"></a>
## Combining Inference Rules in Symbolic Form

**Example:** $P⇒¬Q; P; ∴¬Q; Q∨R; ∴A A A A$
Which of the following statements complete the above proof?

1. $R$
2. $\lnot R \lor Q$
3. $\lnot Q$

**Explanation**

Using the logical inference rule of implication elimination (also known as modus ponens), we obtain the following:
$P⇒¬Q; P; ∴¬Q$

Using the logical inference rule of disjunctive syllogism with the conclusion from the previous step, we get the following:
$¬Q; Q∨R; ∴R$

Therefore, the correct answer is "I only."

## Combining Rules of Inference

**Example:** $If [math]y[/math] is prime, then [math]y[/math] is not divisible by [math]3[/math]; [math]y[/math] is divisible by [math]3[/math]; ∴[math]y[/math] is not prime; [math]y[/math] is prime or [math]y \geq 3[/math]; ∴A A A A A A A A$

What is the missing part of the logical inference rule above?

**Explanation**

Let's denote:

- $P(y)$: $y$ is prime
- $Q(y)$: $y$ is divisible by $3$
- $R(y)$: $y\geq 3$

With that in mind, let's apply some logical inference rules.

- Using the logical inference rule of *denying the consequent* (also known as *modus tollens*), we obtain the following:
$Missing \end{array}$
- Using the logical inference rule of *disjunction elimination* (also known as *disjunctive syllogism*) with the conclusion from the previous step, we get the following:
$Missing \end{array}$

So, the missing part is

$$
y \geq 3
$$
