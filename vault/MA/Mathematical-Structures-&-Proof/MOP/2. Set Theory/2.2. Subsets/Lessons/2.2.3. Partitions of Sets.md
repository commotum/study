## Introduction

A **partition** of a set $A$ is a collection of non-empty subsets of $A$ where every element of $A$ is contained in *exactly* one subset.

In other words, none of the subsets can be the null set $(\emptyset)$, and every element of $A$ must be contained in one *and only one* subset.

For example, the following collections of subsets of

$$
X=\{1, 2, 3, 4, 5\}
$$

are all partitions:

- $X_1 = \{\{1, 2\}, \{3, 4 \}, \{5\} \}$
- $X_2 = \{\{1, 2, 3\}, \{4, 5\} \}$
- $X_3 = \{\{1, 3\}, \{2\}, \{4, 5\} \}$
- $X_4 = \{\{1, 4, 5\}, \{2, 3\} \}$
- $X_5 = \{\{1, 2, 3, 4\}, \{5\} \}$

However, the following collections are *not* partitions:

- $X_6 = \{\{1\}, \{3, 4 \}, \{5\} \}$ - the number $2$ is not included in any subset
- $X_7 = \{\emptyset, \{1, 2, 3\}, \{4, 5\} \}$ - includes $\emptyset$
- $X_8 = \{\{1, 3\}, \{2, 3\}, \{4, 5\} \}$ - the number $3$ is included in two different subsets
- $X_9 = \{\{1, 2 \}, \{2, 3\} \}$ - missing $4$ and $5$, and $2$ is included in two different subsets
- $X_{10} = \{1, 2, 3, 4, 5 \}$ - this not a collection of subsets

## Identifying the Missing Set to Form a Partition

**Example:** Consider the set $X = \{-4, -1, 2, 5, 8, 11, 14, 17 \}$. Which subset must be placed into the blank in the set below so that it represents a partition of $X$?

$\{\{-1, 5, 8 \}, \{-4, 11 \}, \{14 \}, \, \_\_\_\_ \, \}$

**Explanation**

A partition of a set $X$ is a collection of non-empty subsets of $X$ where every element of $X$ is contained in *exactly* one subset.

In order to find the subset that goes in the blank, we must identify which elements of $X$ are not yet contained within any of the given subsets.

Let's go through each element of $X$ and check:

- $-4 \in \{-4, 11 \} \quad \color{green}\checkmark$
- $-1 \in \{-1, 5, 8 \} \quad \color{green}\checkmark$
- $2$ does not belong to any of the given subsets $\quad \color{red}\times$
- $5 \in \{-1, 5, 8 \} \quad \color{green}\checkmark$
- $8 \in \{-1, 5, 8 \} \quad \color{green}\checkmark$
- $11 \in \{-4, 11 \} \quad \color{green}\checkmark$
- $14 \in \{14 \} \quad \color{green}\checkmark$
- $17$ does not belong to any of the given subsets $\quad \color{red}\times$

The elements $2$ and $17$ are not yet contained within any of the given subsets. Therefore, the subset that must go in the blank is $\{2,17 \}$.

## Identifying Partitions

**Example:** If $X = \{a, b, c, d, e, f, g \}$, which of the following collections of subsets of $X$ are partitions of $X$?

1. $\{a, b, \{c,d,e \}, \{f,g \} \}$
2. $\{\{a, b, c \}, \{d,e,f \}, \{g \} \}$
3. $\{\emptyset, \{a,b,c \}, \{f,g \} \}$

**Explanation**

A partition of a set $X$ is a collection of non-empty subsets of $X$ where every element of $X$ is contained in *exactly* one subset.

With that in mind, let's inspect each collection of subsets.

- Collection I is *not* a partition because $a$ and $b$ are not subsets.
- Collection II is a partition. All the subsets are non-empty, and every element of $X$ is contained in exactly one subset.
- Collection III is *not* a partition. The subset $\emptyset$ is empty, and the elements $d$ and $e$ do not appear in any subsets.

Therefore, the correct answer is "II only".

## Identifying Partitions of Large Sets

**Example:** If $X = \{5, 10, 15, \ldots, 50 \}$, which of the following collections of subsets of $X$ are partitions of $X$?

1. $\{\{5, 10 \}, \{15, 20, 25, \ldots, 45 \}, \{50 \} \}$
2. $\{\{5, 10, 15, \ldots, 30 \}, \{40, 45, 50 \} \}$
3. $\{\{5, 10, 15, \ldots, 50 \} \}$

**Explanation**

A partition of a set $X$ is a collection of non-empty subsets of $X$ where every element of $X$ is contained in *exactly* one subset.

With that in mind, let's inspect each collection of subsets.

- Collection I is a partition. All the subsets are non-empty, and every element of $X$ is contained in exactly one subset.
- Collection II is *not* a partition because the element $35$ does not appear in any subsets.
- Collection III is a partition. There is only one subset, but that is okay. The subset is non-empty, and every element of $X$ is contained in this subset.

Therefore, the correct answer is "I and III only".
