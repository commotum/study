## Introduction

Two sets are **equivalent** if they contain the same elements.

If two sets $A$ and $B$ are equivalent, then we write $A =B$. For example,

$$
\{1,2,3 \} = \{3,2,1 \}
$$

On the other hand, if two sets $A$ and $B$ are *not* equivalent, then we write

$$
A \neq B
$$

For example,

$$
\{1,2,3 \} \neq \{4 \}
$$

Remember that when comparing sets, we should ignore duplicate elements. So, for example, the following two sets are equivalent

$$
\{1,2,3\} = \{1,1,2,3,3\}
$$

because they contain the same elements, namely $1,2$, and $3$.

## Identifying Equivalent Sets

**Example:** Which of the following sets is equivalent to $S = \{2, 4, 8, 2, 4, 2\}$?

1. $\{\{2\},4,8\}$
2. $\{2,4,8\}$
3. $\{2,8\}$

**Explanation**

Two sets are equivalent if they contain the same elements. It doesn't matter if the elements are listed differently or if one set has duplicates and the other does not.

To determine which of the given sets is equivalent to $S$, we start by listing the elements of $S$, ignoring any duplicates:
$2, \qquad 4, \qquad 8$

Therefore, the only set equivalent to $S$ is $\{2,4,8\}$ since it contains the same elements as $S$.

The other sets are not equivalent to $S{:}$

- $\{\{2\},4,8\}$ has the element $\{2\}$ that is not in $S$. Note that $\{2\}\neq 2$.
- $\{2,8\}$ is missing the element $4$.

Therefore, the correct answer is "II only."

## Equivalent Sets Containing Sets

**Example:** Which of the following sets are equivalent to $S = \{a, \{b \}, c, \{b \}, a \}$?

1. $\{a, \{b\}, c \}$
2. $\{a, c, b, \{b\} \}$
3. $\{a, \{b\}, c, d \}$

**Explanation**

Two sets are equivalent if they contain the same elements. It doesn't matter if the elements are listed differently or if one set has duplicates and the other does not.

To determine which of the given sets is equivalent to $S$, we start by listing the elements of $S$, ignoring any duplicates:

$$
a, \qquad \{b\}, \qquad c
$$

Therefore, the only set equivalent to $S$ is $\{a, \{b\}, c \}$ since it contains the same elements as $S$.

The other sets are not equivalent to $S{:}$

- Set II *not* equivalent to $S$. It has an element $b$ that is not in $S$. Note that $\{b\} \neq b$.
- Set III is *not* equivalent to $S$. It has an element $d$ that is not in $S$.

Therefore, the correct answer is "I only".

## Equivalent Special Sets

Let's recall the table of special sets.

| Symbol | Meaning | Equivalent To |
| --- | ---: | ---: |
| $\emptyset$ | The empty set, $\{\}$ |  |
| $\mathbb{N}$ | The set of natural numbers, $\{1,2,3,...\}$ |  |
| $\mathbb{N}_0$ | The set of natural numbers and zero, $\{0,1,2,3,...\}$ |  |
| $\mathbb{Z}$ | The set of integers, $\{0,\pm1,\pm2,\pm3,...\}$ |  |
| $\mathbb{Z}^+$ | The set of positive integers, $\{1,2,3,...\}$. | $\mathbb N$ |
| $\mathbb{Z}_0^+$ | The set of positive integers and zero, $\{0,1,2,3,...\}$ | $\mathbb N_0$ |
| $\mathbb{Z}^-$ | The set of negative integers, $\{-1,-2,-3,...\}$ |  |
| $\mathbb{Z}_0^-$ | The set of negative integers and zero, $\{0,-1,-2,-3,...\}$ |  |
| $\mathbb{Q}$ | The set of rational numbers |  |
| $\mathbb{Q}^+$ | The set of positive rational numbers |  |
| $\mathbb{Q}_0^+$ | The set of positive rational numbers and zero |  |
| $\mathbb{Q}^-$ | The set of negative rational numbers |  |
| $\mathbb{Q}_0^-$ | The set of negative rational numbers and zero |  |
| $\mathbb{R}$ | The set of real numbers | $x\in (-\infty,\infty)$ |
| $\mathbb{R}^+$ | The set of positive real numbers | $x\in (0,\infty)$ |
| $\mathbb{R}_0^+$ | The set of positive real numbers and zero | $[MATH: x\in [0,\infty)]$ |
| $\mathbb{R}^-$ | The set of negative real numbers | $x\in (-\infty,0)$ |
| $\mathbb{R}_0^-$ | The set of negative real numbers and zero | $[MATH: x\in (-\infty,0]]$ |

As noted in the table, the following sets are equivalent:

- $\mathbb Z^+$ and $\mathbb N$
- $\mathbb Z_0^+$ and $\mathbb N_0$
- $x\in(-\infty,\infty)$ is the interval containing all real numbers, the same as $\mathbb R$.
- $x\in(0,\infty)$ is the interval containing all positive real numbers, the same as $\mathbb R^+$.
- $[MATH: x\in[0,\infty)]$ is the interval containing all positive real numbers and zero, the same as $\mathbb R_0^+$.
- $x\in(-\infty,0)$ is the interval containing all negative real numbers, the same as $\mathbb R^-$.
- $[MATH: x\in(-\infty,0]]$ is the interval containing all negative real numbers and zero, the same as $\mathbb R_0^-$.

<a id="identifying-equivalent-special-sets"></a>
## Identifying Equivalent Special Sets

**Example:** Which of the following sets are equivalent to $A = \{0, 1, 2, 3, \ldots\}$?

1. $\mathbb{N}$
2. $\mathbb{N}_{0}$
3. $\mathbb{Z}$
4. $\mathbb{Z}^{+}$

**Explanation**

The set $A$ is the set of positive integers and zero. It is denoted by $\mathbb{N}_{0}$.

Therefore, the correct answer is $\mathbb{N}_{0}$.

The other options are *not* equivalent to $A{:}$

- The set $\mathbb{N}$ does not include the element zero, and $0\in A$.
- The set $\mathbb{Z}$ includes the elements $-1,-2,-3,\ldots$, and $-1 \not \in A, -2\notin A, -3\notin A, \ldots\,$.
- The set $\mathbb{Z}^{+}$ does not include the element zero, and $0\in A$.
