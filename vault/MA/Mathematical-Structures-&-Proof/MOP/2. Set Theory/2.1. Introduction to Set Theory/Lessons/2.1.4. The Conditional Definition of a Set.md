## Introduction

Another way of describing a set is to use a so-called **conditional definition**.

Consider the following set:

$$
\begin{aligned}
A = \big\{n \in \mathbb{Z}: \mid 3n-1 &= 2 \big\}
\end{aligned}
$$

This notation tells us that the elements of $A$ are the *integers* $(n\in\mathbb Z)$ that satisfy the absolute value equation

$$
\mid 3n-1 \mid = 2
$$

To list the elements of this set, we start by solving this equation:

$$
\begin{aligned}
\mid 3n - 1 \mid &= 2 \\
3n - 1 &= ± 2 \\
3n &= 1 ± 2 \\
n &= \frac{1 ± 2}{3}
\end{aligned}
$$

So, the solutions to our equation are $n=1$ and

$$
n=-\dfrac13
$$

We now inspect each solution to see which of them (if any) are elements of $A{:}$

- The solution $n=1$ is an integer. Hence, this solution *is* a member of $A$.
- The solution $n=-\dfrac13$ is *not* an integer. Hence, this solution is *not* a member of $A$.

Therefore, the set $A$ contains only one element.

Finally, listing all elements of $A$, we have
$A = \{1\}$.

<a id="some-comments"></a>
## Some Comments

Let's go back to our set, written using a conditional definition:

$$
\begin{aligned}
A = \big\{n \in \mathbb{Z}: \mid 3n-1 &= 2 \big\}
\end{aligned}
$$

Note the following:

- Under this definition, $n\in\mathbb Z$ describes the universal set for the type of mathematical object we're considering. In this case, the universal set is the set of integers.
- The condition $\mid 3n-1 \mid = 2$ is a predicate that defines the set's internal logic. Therefore, $A$ is the set of integers that give a true statement when substituted into the equation $\mid 3n-1 \mid = 2$.
- Note that $A$ itself is *not* a predicate but a set; therefore, it does not have a truth value.
- When a set is written using a conditional definition, the symbol "$$:" is read as "such that." So, in words, we can describe the set $A$ as follows:$\qquad$ *$A$ is the set of integers $n$ **such that** $\mid 3n-1 \mid = 2$.*
- The variable $n$ is a dummy variable. Its purpose is to describe the logic behind the set's definition and can be replaced with any other variable.
- An alternative to the "conditional definition of a set" terminology is to say the set is written using **set-builder notation**.
- Instead of using a "$$:" symbol to separate the universal set from its predicate, it's common to use the "$\mid$" symbol, as follows:
$A = \big\{n \in \mathbb{Z}\:\mid\:\ \mid 3n-1|=2 \big\}$

## Sets Defined Using Linear Equations and Inequalities

**Example:** List the elements of the set $A = \{n \in \mathbb{N}: 5n - 2 \leq 21 \}$.

**Explanation**

The elements of the given set are the natural numbers that satisfy the inequality

$$
5n - 2 \leq 21
$$

So, we first need to solve our inequality for $n{:}$

$$
\begin{bmatrix}5n - 2 & \le 21 \\ 5n & \le 23 \\ n & \le \frac{23}{5}\end{bmatrix}
$$

The positive integer solutions of the inequality above are $1,2,3,4$. Therefore, the given set can be written as

$$
A = \{1,2,3,4\}
$$

## Sets Defined Using Quadratic Equations and Inequalities

**Example:** List the elements of the set $A = \{x \in \mathbb{Z}: x^2 - 9 \lt 0\}$.

**Explanation**

The elements of the given set are the integers that satisfy the inequality $x^2 - 9 < 0$.

So, we first need to solve our inequality for $x{:}$
$x^{2} - 9\begin{vmatrix}< 0 \\ x^{2}\end{vmatrix}< 9; \sqrt{x^{2}} \mid < \sqrt{9}; \mid x \mid \mid < 3; - 3 < x \mid < 3$

The integer solutions of the inequality above are $0,\pm1,\pm2$. Therefore, the given set can be written as

$$
A = \{0, \pm 1, \pm 2\}
$$

## Sets Defined Using Absolute Value Equations and Inequalities

**Example:** List the elements of the set $A=\{k \in \mathbb{Z}: \mid k-1 \mid \leq 4 \}$.

**Explanation**

The elements of the given set are the integers that satisfy the inequality

$$
\mid k-1 \mid \leq 4
$$

So, we first need to solve for $k{:}$

$$
\mid k - 1 \mid \le 4; - 4 \le k - 1 \le 4; - 3 \le k \le 5
$$

The integer solutions of the above inequality are $-3,-2,-1,0,1,2,3,4,5$.

Therefore, the given set can be written as

$$
A = \{0,\pm1,\pm2,\pm3,4,5 \}
$$

## Sets Defined Using Trigonometric Equations

**Example:** List the elements of the set $A = \left\{x\in \mathbb R \::\: \tan \left(\dfrac{\pi x}{2}\right) = 0 \right\}$.

**Explanation**

Notice that the solutions to the equation

$$
\tan \left(\dfrac{\pi x}{2}\right) = 0
$$

are given by

$$
\begin{aligned}
\frac{πx}{2} &= nπ \\
x &= 2n
\end{aligned}
$$

where $n\in\mathbb Z$.

Substituting different values of $n$, we see that the solutions are

$$
x = 0,\, \pm 2,\, \pm 4,\, \pm 6,\, \ldots
$$

Therefore, our set $A$ is equivalent to

$$
A= \{0,\, \pm 2,\, \pm 4,\, \pm 6,\, \ldots\}
$$
