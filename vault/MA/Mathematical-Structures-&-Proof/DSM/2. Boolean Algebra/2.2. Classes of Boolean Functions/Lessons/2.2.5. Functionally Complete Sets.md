## Introduction

A set of Boolean functions (logical operations) is **functionally complete** if any Boolean function can be expressed in terms of the functions (operations) from this set.

For example, the set
$\big\{\lnot,\: \land\big\}$
containing negation and conjunction is functionally complete. To prove this, we show that we can represent any arbitrary Boolean function using only $\lnot$ and $\land$, as follows:

> *Any Boolean function can be expressed in disjunctive normal form (DNF), i.e., as an expression consisting of variables and the operators $\lor, \land$, and $\lnot$ only.*
> *In this expression, we can keep $\lnot$ and $\land$, but replace any occurrence of a conjunction $\lor$ using De Morgan's law for disjunction:*
> $\lnot\left(A \lor B\right) \equiv \lnot A \land \lnot B$
> *The resulting expression uses only $\lnot$ and $\land$. Therefore, any Boolean function can be expressed in terms of $\lnot$ and $\land$,; hence, the set $\{\lnot, \land\}$ is functionally complete.*

Let's express

$$
x \lor \left(y \land z\right)
$$

using only $\lnot$ and $\land$.
First, we use the double negation rule, $A \equiv \lnot \lnot A{:}$

$$
x \lor \left(y \land z\right) \equiv \lnot\lnot\big(x \lor \left(y \land z\right)\big)
$$

Next, we use De Morgan's law for disjunction, $\lnot (A \lor B) \equiv \lnot A \land\lnot B$.
Substituting $x$ for $A$ and

$$
\left(y \land z\right)
$$

for $B$, we get

$$
\lnot\lnot\big(x \lor \left(y \land z\right)\big) \equiv \lnot \left(\lnot x \land \lnot \left(y \land z\right) \right)
$$

Therefore, expressed using only $\lnot$ and $\land$, we have

$$
x \lor \left(y \land z\right) \equiv \lnot \left(\lnot x \land \lnot \left(y \land z\right) \right)
$$

By similar reasoning, we can prove that the set containing negation and conjunction
$\big\{\lnot, \lor\big\}$
is also functionally complete. Let's see how to express a function using only the operations from this set in the following example.

## Expressing Boolean Functions Using Negation, Conjunction, and Disjunction

**Example:** Express $x \land y$ (conjunction) using only $\lnot$ (negation) and $\lor$ (disjunction).

**Explanation**

First, we use the double negation rule, $A \equiv \lnot \lnot A{:}$

$$
x∧y \mid ≡¬¬(x∧y)
$$

Next, we use De Morgan's law for conjunction, $\lnot (A \land B) \equiv \lnot A \lor\lnot B{:}$

$$
¬¬(x∧y) \mid ≡¬(¬x∨¬y)
$$

<a id="negation-and-implication"></a>
## Negation and Implication

The set containing negation and implication
$\big\{\lnot,\: \Rightarrow\big\}$
is a functionally complete. We can prove this as follows:

> *Since $\{\lnot, \lor\}$ is a functionally complete set, any Boolean function can be expressed in terms of only $\lnot$ and $\lor$.*
> *In this expression, we can keep $\lnot$, but replace any occurrence of a disjunction $\lor$ using the fact that*
> $\lnot A \lor B \equiv A \Rightarrow B$.
> *The resulting expression uses only $\lnot$ and $\Rightarrow$. Therefore, any Boolean function can be expressed in terms of $\lnot$ and $\Rightarrow$, and hence, the set $\{\lnot, \Rightarrow\}$ is functionally complete.*

Let's express $x \lor (y \land z)$ using only $\lnot$ and $\Rightarrow$.

First, we write the expression in terms of $\lnot$ and $\lor$. Using the double negation rule $A \equiv \lnot \lnot A$, we have
$x \lor (y \land z) \equiv x \lor \lnot\lnot(y \land z)$.

Then, we apply De Morgan's law for conjunction, $\lnot (A \land B) \equiv \lnot A \lor\lnot B{:}$

$$
x \lor \lnot\lnot(y \land z) \equiv x \lor \lnot\left(\lnot y \lor \lnot z\right)
$$

Now, we write the expression in terms of $\lnot$ and $\Rightarrow$. Using the commutativity of disjunction, $A\lor B\equiv B\lor A$, followed by the definition of implication $A \Rightarrow B \equiv \lnot A \lor B$, we get
$x∨¬(¬y∨¬z) \mid ≡¬(¬y∨¬z)∨x; ≡(¬y∨¬z)⇒x; ≡(y⇒¬z)⇒x$.

Therefore, expressed using only $\lnot$ and $\Rightarrow$, we have

$$
x \lor y \land z \equiv \left(y \Rightarrow \lnot z\right) \Rightarrow x
$$

<a id="expressing-boolean-functions-using-negation-and-implication"></a>
## Expressing Boolean Functions Using Negation and Implication

**Example:** Express $x \lor y \lor z$ using only $\lnot$ (negation) and $\Rightarrow$ (implication).

**Explanation**

First, we need to get the expression for $\lor$ using only $\lnot$ and $\Rightarrow$.

In the definition of implication $A \Rightarrow B \equiv \lnot A \lor B$, substitute $\lnot C$ for $A$ to get the following equivalence:

$$
\begin{bmatrix}¬C⇒B & ≡C∨B, or \\ C∨B & ≡¬C⇒B\end{bmatrix}
$$

Now, using the equivalence above, we substitute the expression for the first and second $\lor$ in the given expression:

$$
x∨y∨z \mid ≡x∨(y∨z); ≡¬x⇒(y∨z); ≡¬x⇒(¬y⇒z)
$$

<a id="peirce-arrow"></a>
## Peirce Arrow

The set $\{\downarrow\}$ (Peirce arrow) is functionally complete. Here's the proof:

> *Since $\{\lnot, \lor\}$ is a functionally complete set, any Boolean function can be expressed in terms of only $\lnot$ and $\lor$.*
> *In this expression, we can replace any occurrence of disjunction $\lor$ using the definition of Peirce arrow:*
> $A \downarrow B \equiv \lnot \left(A \lor B \right)$
> *Then, we can replace any occurrence of negation $\lnot$ using the definition of the Peirce arrow for two identical variables:*
> $A↓A \mid ≡¬(A∨A); ≡¬A$
> *The resulting expression uses only $\downarrow$. Therefore, any Boolean function can be expressed in terms of $\downarrow$, and hence, the set $\{\downarrow\}$ is functionally complete.*

Let's express $x \land \lnot y$ using only $\downarrow$.

First, we write the expression in terms of $\lnot$ and $\lor$. Using the double negation rule $A \equiv \lnot\lnot A$, we have
$x \land \lnot y \equiv \lnot\lnot (x \land \lnot y)$.

Then, we apply De Morgan's law for conjunction, $\lnot(A \land B) \equiv \lnot A \lor \lnot B$, followed by the double negation rule:
$¬¬(x∧¬y)≡¬(¬x∨¬¬y); ≡¬(¬x∨y)$

Now, we write the expression in terms of $\downarrow$. Using the definition of Peirce arrow,

$$
\lnot \left(A \lor B \right) \equiv A \downarrow B
$$

followed by the fact that $\lnot A \equiv A \downarrow A$, we get
$¬(¬x∨y) \mid ≡¬x↓y; ≡(x↓x)↓y$.

Therefore, expressed using only $\downarrow$, we have
$x \land \lnot y \equiv (x \downarrow x) \downarrow y$.

<a id="sheffer-stroke"></a>
## Sheffer Stroke

Similarly, the set $\{\mid\}$ (Sheffer stroke) is functionally complete. Here's the proof.

> *Since $\{\lnot, \land\}$ is a functionally complete set, any Boolean function can be expressed in terms of only $\lnot$ and $\land$.*
> *In this expression, we can replace any occurrence of conjunction $\land$ using the definition of Sheffer stroke:*
> $A \mid B \equiv \lnot \left(A \land B \right)$
> *Then, we can replace any occurrence of negation $\lnot$ using the definition of the Sheffer stroke for two identical variables:*
> $A∣A \mid ≡¬(A∧A); ≡¬A$
> *The resulting expression uses only $\mid$. Therefore, any Boolean function can be expressed in terms of $\mid$,; hence, the set $\{\mid\}$ is functionally complete.*

Let's demonstrate the functional completeness of the set $\{\mid\}$ in the following example.

<a id="expressing-boolean-functions-through-peirce-arrow-or-sheffer-stroke"></a>
## Expressing Boolean Functions Through Peirce Arrow or Sheffer Stroke

**Example:** Express $x \land y$ using only $\mid$ (Sheffer stroke).

**Explanation**

First, we use the double negation rule $A \equiv \lnot \lnot A{:}$

Second, we use the definition of Sheffer stroke

$$
A \mid B \equiv \lnot \left(A \land B\right){:}
$$

$$
¬¬(x∧y)≡¬(x∣y)
$$

Finally, recall that $\lnot A \equiv A \mid A{:}$

$$
¬(x∣y)≡(x∣y)∣(x∣y)
$$

<a id="minimal-functionally-complete-sets"></a>
## Minimal Functionally Complete Sets

A functionally complete set of Boolean functions is **minimal** if it has no functionally complete proper subset.
In other words, removing any single element results in a no longer functionally complete set.

For example, $\{\lnot, \land\}$ is a minimal functionally complete set. If we remove $\land$, then the Boolean function $f \equiv x \land y$ cannot be expressed using only $\lnot$.

On the other hand, $\{\lnot, \land, \lor\}$ is *not* a minimal functionally complete set. It has proper subsets that are also functionally complete, namely $\{\lnot, \land\}$ and $\{\lnot, \lor\}$.

The following is a list of all minimal functionally complete sets. There are no minimal functionally complete sets of more than three Boolean operators.

- Single-element minimal functionally complete sets:Peirce Arrow: $\{\downarrow\}$Sheffer Stroke: $\{\mid\}$
- Two-element minimal functionally complete sets:Negation and Conjunction: $\{\lnot, \land\}$Negation and Disjunction: $\{\lnot, \lor\}$Negation and Implication (or Converse Implication): $\{\lnot, \Rightarrow\}$ or $\{\lnot, \Leftarrow\}$Exclusive OR and Implication (or Converse Implication): $\{\oplus, \Rightarrow\}$ or $\{\oplus, \Leftarrow\}$
- Three-element minimal functionally complete sets:Conjunction, Equivalence, and Exclusive OR: $\{\land, \Leftrightarrow, \oplus\}$Disjunction, Equivalence, and Exclusive OR: $\{\lor, \Leftrightarrow, \oplus\}$
