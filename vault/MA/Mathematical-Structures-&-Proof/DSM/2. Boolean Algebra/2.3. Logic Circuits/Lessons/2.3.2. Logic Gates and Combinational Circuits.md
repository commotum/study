## Introduction

In a previous lesson, we saw how to represent a logic circuit using a switch circuit. In this lesson, we'll study how to represent logic circuits using **logic gates.**

Logic gates perform basic logical operations on one or more binary inputs to produce a binary output.

For instance, the **NOT gate** takes one binary input, $x$, and produces the binary output $\overline{x}{:}$

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/b703ca6c68fa6e37bd7389c07cd22b80.png>)

The **AND gate** takes two binary inputs, $x_1$ and $x_2$, and produces the binary output $x_1 \land x_2{:}$

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/32de24612d9e9c9630963ba99f89d223.png>)

All the logic gates that we will use are shown below.

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/394bb942091fc56e80d5c65ba3dbdd8b.png>)

A **combinational circuit** is a type of logic circuit that uses logic gates to implement Boolean functions.
For example, consider the following combinational circuit:

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/7a2d4ffa6622c30872f69973d61fb1fd.png>)

Let's find an expression representing this logic circuit. To do so, we examine each gate in turn.

- The inputs $x_1$ and $x_2$ go through the NAND gate. So, the output of this gate gives $x_1 \mid x_2$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/8a8d7e848193f646b371300046cc233a.png>)
- Another input $x_2$ goes through the NOT gate. So, the output of this gate gives $\overline{x_2}$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/d9ec26edf7106daf6151334cb981a2dd.png>)
- Finally, the output of the part corresponding to $x_1 \mid x_2$ and the output of $\overline{x_2}$ go through the AND gate.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/b6e558bef48b9debcf140919d8b129ed.png>)Therefore, the whole circuit can be represented by the expression
$(x_1 \mid x_2) \land \overline{x_2}$.

## Constructing a Logical Expression Given a Combinatorial Circuit

**Example:** Find an expression that represents the combinatorial circuit given above.

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/ea1192567a2714264b219b3cc07e3557.png>)

**Explanation**

Let's examine each gate of the circuit in turn.

- The inputs $x_1$ and $x_2$ go through the XOR gate. So, the output of this gate gives $x_1 \oplus x_2$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/b783bb8115cc8e4a561716340c1529a3.png>)

- The output of the part corresponding to $x_1 \oplus x_2$ and another input $x_2$ go through the AND gate. So, the output of this gate gives $(x_1 \oplus x_2) \land x_2$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/afbd65d141c8de04cbc66b89ef3c4e22.png>)

- The input ${x_3}$ go through the NOT gate. So, the output of this gate gives $\overline{x_3}$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/faa2b03434c64cac2b3dfd7449dbfe06.png>)

- Finally, the output of the part corresponding to $(x_1 \oplus x_2) \land x_2$ and the output $\overline{x_3}$ go through the NAND gate.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/5e7af25a152d43bc9be01d8fdc8c35ca.png>)
Therefore, the whole circuit can be represented by the expression
$((x_1\oplus x_2)\land x_2)\mid \overline{x_3}$.

## Constructing a Combinatorial Circuit Given a Logical Expression

**Example:** Construct a combinatorial circuit that represents the logical expression $(x_1 \mid \overline{x_2}) \oplus x_2$.

**Explanation**

To construct the corresponding circuit, we proceed as follows.

- We start by drawing the inputs $x_1$ and $x_2{:}$

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/4b7761f3bc335b21e9dbfdf69268b869.png>)

- Next, we draw the NOT gate corresponding to the negation $\overline{x_2}{:}$

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/f48c44bbfff17489f0c72bbbeb089d26.png>)

- Next, we draw the NAND gate, and forward $x_1$ and the output of $\overline{x_2}$ through that gate. This gives the circuit for $x_1 \mid \overline{x_2}{:}$

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/429a68e5a9d5bfbd8f2185452cff4947.png>)

- Finally, we draw the XOR gate and branch out one more $x_2$ input. After that, we forward this new branch and the output of the NAND gate through the XOR gate. This gives the circuit for the whole expression.

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/8d65d008c63d7e47155ab11919bca846.png>)

## Identifying Logic Gates by Their Form

Logic gates are typically not labeled with the symbol of the logical operator they represent.
Instead, we identify each operator by its distinct shape.
For instance, the NOT, AND, and OR gates have the following shapes:

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/78a1a3d01fd59b5091a64e7b7d1e41a4.png>)

An example of a combinational circuit without labels is given below, along with a label guide.

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/3fb0305e9b22560a787dfdf402d4445b.png>)

Let’s now examine each gate in the circuit in turn to find its corresponding Boolean expression.

- The input $x_1$ goes through the NOT gate. So, the output of this gate gives $\overline{x_1}$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/0bb41fe596086cc4e5ccc14950668fca.png>)
- The input $x_1$ and the input of $x_2$ go through the AND gate. So, the output of this gate gives $x_1 \land x_2$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/a0ed6c4629839649b64402cc294e248a.png>)

- Finally, the output of the part corresponding to $\overline{x_1}$ and the output of $x_1 \land x_2$ go through the OR gate.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/857ca46b459b3522e09380902bff1f24.png>)Therefore, the whole circuit can be represented by the expression
$\overline{x_1} \lor (x_1 \land x_2)$.

## Constructing a Logical Expression Using NOT, AND, and OR Gates

**Example:** Find an expression that represents the combinatorial circuit given above.

![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/eef5ee2f8d613cf1b560701036f09c70.png>)

**Explanation**

Let's examine each gate of the circuit in turn.

- The input $x_1$ and the input $x_2$ go through the OR gate. So, the output of this gate gives $x_1 \lor x_2$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/43c86012608f19d66efd1773030fa315.png>)
- The input $x_3$ goes through the NOT gate. So, the output of this gate gives $\overline{x_3}$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/0395eb3ba5e20dd16552af9f6e945874.png>)

- Finally, the output of the part corresponding to ${x_1}\lor {x_2}$ and the output of $\overline x_3$ go through the AND gate. So, the output of this gate gives $({x_1} \lor {x_2}) \land\overline{x_3}$, as shown below.![](<../Source/2.3.2. Logic Gates and Combinational Circuits/Images/30278b694bc59a3067c5feff7762d40b.png>)Therefore, the whole circuit can be represented by the expression
$(x_1\lor x_2) \land \overline{x_3}$.
