## Introduction

A **cumulative frequency table** is an extension of a regular frequency table that shows how frequencies *accumulate* across an *ordered data set*.

To demonstrate, let's fill in the missing values in the following cumulative frequency table.

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $3$ |  |
| $2$ | $2$ |  |
| $3$ | $1$ |  |
| $4$ | $7$ |  |

The cumulative frequency column shows the *running total* of the frequencies.

To complete the cumulative frequency column, we start with the first value. Then, we walk down the table, adding each new frequency to the cumulative frequency in the previous row.

For the first row, the cumulative frequency is simply equal to the frequency of that row.

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | ${\color{blue}3}$ | ${\color{blue}3}$ |
| $2$ | $2$ |  |
| $3$ | $1$ |  |
| $4$ | $7$ |  |

For each subsequent row, the cumulative frequency is found by adding the frequency of that row to the cumulative frequency *from the previous row*.

The cumulative frequency for the $2$nd row equals

$$
{\color{blue}2}+{\color{red}3}=5
$$

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $3$ | ${\color{red}3}$ |
| $2$ | ${\color{blue}2}$ | $5$ |
| $3$ | $1$ |  |
| $4$ | $7$ |  |

The cumulative frequency for the $3$rd row equals

$$
{\color{blue}1} + {\color{red}5}=6
$$

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $3$ | $3$ |
| $2$ | $2$ | ${\color{red}5}$ |
| $3$ | ${\color{blue}1}$ | $6$ |
| $4$ | $7$ |  |

The cumulative frequency for the $4$th row equals

$$
{\color{blue}7} + {\color{red}6} = 13
$$

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $3$ | $3$ |
| $2$ | $2$ | $5$ |
| $3$ | $1$ | ${\color{red}6}$ |
| $4$ | ${\color{blue}7}$ | $13$ |

This gives us our completed cumulative frequency table.

## Completing a Cumulative Frequency Table

**Example:** A teacher graded the results of a math test using a $4$-point scale. The distribution of the grades is shown in the table above. Find the missing values in the cumulative frequency column.

| Grade | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $5$ |  |
| $2$ | $2$ |  |
| $3$ | $7$ |  |
| $4$ | $6$ |  |

**Explanation**

The cumulative frequency column shows the running total of the frequencies.

To complete the cumulative frequency column, we start with the first value. Then, we walk down the table, adding each new frequency to the cumulative frequency in the previous row.

For the first row, the cumulative frequency is simply equal to the frequency of that row.

| Grade | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | ${\color{blue}5}$ | ${\color{blue}5}$ |
| $2$ | $2$ |  |
| $3$ | $7$ |  |
| $4$ | $6$ |  |

For each subsequent row, the cumulative frequency is found by adding the frequency of that row to the cumulative frequency *from the previous row*. So, we have the following:

The cumulative frequency for the $2$nd row in our table is equal to

$$
{\color{blue}2}+{\color{red}5}=7
$$

| Grade | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $5$ | ${\color{red}5}$ |
| $2$ | ${\color{blue}2}$ | $7$ |
| $3$ | $7$ |  |
| $4$ | $6$ |  |

The cumulative frequency for the $3$rd row equals

$$
{\color{blue}7} + {\color{red}7}=14
$$

| Grade | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $5$ | $5$ |
| $2$ | $2$ | ${\color{red}7}$ |
| $3$ | ${\color{blue}7}$ | $14$ |
| $4$ | $6$ |  |

The cumulative frequency for the $4$th row equals

$$
{\color{blue}6} + {\color{red}14} = 20
$$

| Grade | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $1$ | $5$ | $5$ |
| $2$ | $2$ | $7$ |
| $3$ | $7$ | ${\color{red}14}$ |
| $4$ | ${\color{blue}6}$ | $20$ |

## Calculating Missing Frequencies

**Example:** A group of students were asked how many snacks they purchased from the school vending machine last week. The frequency table below shows the distribution of responses. Fill in the missing values in the cumulative frequency table below.

| Snacks Bought | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $0$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{\phantom{11}}$ | $3$ |
| $1$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{\phantom{11}}$ | $12$ |
| $2$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{\phantom{11}}$ | $18$ |
| $3$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{\phantom{11}}$ | $25$ |

**Explanation**

The cumulative frequency column shows the running total of the frequencies:

- For the first row, the cumulative frequency is simply equal to the frequency of that row.
- For each subsequent row, the cumulative frequency is found by adding the frequency of that row to the cumulative total from the previous row.

Therefore, to find the frequency for each row except the first one, we subtract the previous cumulative frequency from the current cumulative frequency.

- The frequency for the $1$st row in our table is equal to $3$.
- The frequency for the $2$nd row in our table is equal to $12-3=9$.
- The frequency for the $3$rd row in our table is equal to $18-12=6$.
- The frequency for the $4$th row in our table is equal to $25-18=7$.

Let's add these values to our table.

| Snacks Bought | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $0$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{3}$ | $3$ |
| $1$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{9}=12-3$ | $12$ |
| $2$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{6}=18-12$ | $18$ |
| $3$ | $\qquad\bbox[4pt,border: 1px solid gainsboro]{7}=25-18$ | $25$ |
