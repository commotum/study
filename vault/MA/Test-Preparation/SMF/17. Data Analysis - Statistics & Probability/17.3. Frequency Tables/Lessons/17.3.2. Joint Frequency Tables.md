## Introduction

The following data set shows the total time, in hours, that a group of students spent studying for a final exam:

$$
0, \quad 1, \quad 1, \quad 1, \quad 2, \quad 3,\quad 3, \quad 3, \quad 3
$$

In a previous lesson, we saw that we can represent this data using a frequency table.

| Number of Hours Studied | Frequency |
| --- | ---: |
| $0$ | $\color{blue}1$ |
| $1$ | $\color{blue}3$ |
| $2$ | $\color{blue}1$ |
| $3$ | $\color{blue}4$ |

We interpret the data in this table as follows:

- $\color{blue}1$ student spent zero hours studying
- $\color{blue}3$ students spent one hour studying
- $\color{blue}1$ student spent two hours studying
- $\color{blue}4$ students spent three hours studying

This is an example of a **one-way frequency table** because it shows the relationship between a single *variable* (the number of hours studied) and the *frequency* of each value of the variable.

In this lesson, we'll learn how to represent data with two categorical variables.

<a id="two-way-frequency-tables"></a>
## Two-Way Frequency Tables

Suppose a gym surveys all of its members. They find that $25$ males and $24$ females exercise twice a week, and $15$ males and $18$ females exercise three times a week. How can we represent this information using a frequency table?

Notice that we now have *two* categorical variables, namely

- the gender of each member (male or female), and
- how often they exercise per week (twice a week or three times a week).

Since there are two categorical variables, we can organize this information using a **joint frequency table.**

To construct a joint frequency table, we first label the rows and columns using the possible values of our two categorical variables, as follows:

|  | Twice a week | Three times a week |
| --- | ---: | ---: |
| Males |  |  |
| Females |  |  |

Now, we fill in the cells using the information provided.

- We're told that $25$ males exercise twice a week. So, we write this number at the intersection of the "Males" row and the "Twice a week" column.

|  | Twice a week | Three times a week |
| --- | ---: | ---: |
| Males | $\bbox[2pt,Gainsboro]{\color{blue}25}$ |  |
| Females |  |  |

- We're told that $24$ females exercise twice a week. So, we write this number at the intersection of the "Females" row and the "Twice a week" column.

|  | Twice a week | Three times a week |
| --- | ---: | ---: |
| Males | $25$ |  |
| Females | $\bbox[2pt,Gainsboro]{\color{blue}24}$ |  |

- We're also told that $15$ males and $18$ females exercise three times a week. Adding this data to our table, we get the following joint frequency table.

|  | Twice a week | Three times a week |
| --- | ---: | ---: |
| Males | $25$ | $15$ |
| Females | $24$ | $18$ |

Note the following:

- The numbers $25$, $15$, $24$, and $18$ are called the **joint frequencies** because they each represent joint data from two categorical variables.
- Joint frequency tables are sometimes called **two-way frequency tables** or **contingency tables.**

<a id="marginal-frequencies"></a>
## Marginal Frequencies

|  | Twice a week | Three times a week |
| --- | ---: | ---: |
| Male | $25$ | $15$ |
| Female | $24$ | $18$ |

Now that we have our two-way frequency table, we can analyze the data set.

One question that we can ask is, "How many males attend the gym?" To answer this question, let's consider the data in the "male" row only:

|  | Twice a week | Three times a week |
| --- | ---: | ---: |
| Male | $25$ | $15$ |
| Female | $24$ | $18$ |

To determine the total number of males who attend the gym, we sum the joint frequencies in this row.

$$
25 + 15 = {\color{red}40}
$$

It's convenient to extend the joint frequency table to include the totals of each row and column. So let's add a "Totals" column and "Totals" row to the right and bottom of the table, and include the total number of males in the table as follows:

|  | Twice a week | Three times a week | Totals |
| --- | ---: | ---: | ---: |
| Male | $25$ | $15$ | $\bbox[2pt,Gainsboro]{\color{red}40}$ |
| Female | $24$ | $18$ |  |
| Totals |  |  |  |

Similarly, we can fill in the rest of the cells in the "Totals" row and "Totals" column by summing the entries in each row and column.

|  | Twice a week | Three times a week | Totals |
| --- | ---: | ---: | ---: |
| Male | $25$ | $15$ | $\bbox[2pt,Gainsboro]{40}$ |
| Female | $24$ | $18$ | $\bbox[2pt,Gainsboro]{42}$ |
| Totals | $\bbox[2pt,Gainsboro]{49}$ | $\bbox[2pt,Gainsboro]{33}$ |  |

The highlighted numbers, $40$, $42$, $49$, and $33$ are called the **marginal frequencies**. These numbers tell us that

- $40$ males attend the gym,
- $42$ females attend the gym,
- $49$ members exercise twice per week, and
- $33$ members exercise three times per week.

Another question we can ask is, "How many members attend the gym in total?" We can get this information by summing either the "Totals" row or the "Totals" column. Note that we'll get the same answer either way.

Summing the data in the "Totals" column, we have

$$
40 + 42 = 82
$$

Therefore, the gym has $82$ members. We can add this data to the bottom-right cell in the table, as follows:

|  | Twice a week | Three times a week | Totals |
| --- | ---: | ---: | ---: |
| Male | $25$ | $15$ | $40$ |
| Female | $24$ | $18$ | $42$ |
| Totals | $49$ | $33$ | $\bbox[2pt,Gainsboro]{\color{blue}82}$ |

<a id="completing-a-joint-frequency-table"></a>
## Completing a Joint Frequency Table

**Example:** The frequency table above describes some children's preferences for learning a second language. Determine the value of $w + y + z$.

|  | German | Spanish | French | Totals |
| --- | ---: | ---: | ---: | ---: |
| Boys | $8$ | $x$ | $14$ | $44$ |
| Girls | $12$ | $14$ | $y$ | $z$ |
| Totals | $t$ | $w$ | $29$ | $85$ |

**Explanation**

For each row/column in a joint frequency table:

- the sum of the joint frequencies equals the marginal frequency (or total) for that row/column, and
- the sum of the marginal frequencies in the totals row/column equals the total $(85)$.

With that in mind, let's examine each row/column:

- Looking at the first row, there are $44$ boys in total.
GermanSpanishFrenchTotalsBoys$8$$x$$14$$44$Girls$12$$14$$y$$z$Totals $t$ $w$ $29$$85$
Therefore:
$8 + x + 14|= 44; 22 + x|= 44; x|= 44 - 22; x|= 22$
We add this value to our table.
- Looking at the third column, we see that there are $29$ children who prefer to learn French.
GermanSpanishFrenchTotalsBoys$8$$22$$14$$44$Girls$12$$14$$y$$z$Totals $t$ $w$ $29$$85$
Therefore:
$14 + y|= 29; y|= 29 - 14; y|= 15$
We add this value to our table.

By similar reasoning, we can deduce the following:

- Considering the number of children who prefer to learn German, we get
$t|= 8 + 12 = 20$.
- Considering the number of children who prefer to learn Spanish, we get
$w|= 22 + 14 = 36$.
- Since there are $85$ children in total, we have
$44 + z|= 85; z|= 85 - 44; z|= 41$.

Our completed frequency table is as follows:

|  | German | Spanish | French | Totals |
| --- | ---: | ---: | ---: | ---: |
| Boys | $8$ | $22$ | $14$ | $44$ |
| Girls | $12$ | $14$ | $\bbox[2pt,Gainsboro]{\color{red}15}$ | $\bbox[2pt,Gainsboro]{\color{red}41}$ |
| Totals | $20$ | $\bbox[2pt,Gainsboro]{\color{red}36}$ | $29$ | $85$ |

Finally,

$$
w + y + z = 36 + 15 + 41 = 92
$$

## Deducing a Joint or Marginal Frequency

**Example:** Among $85$ surveyed cinema visitors,

- $15$ men and $21$ women like crime movies,
- $12$ women don't like crime movies.

Copy and complete the joint frequency table below, and use this to determine the total number of men surveyed.

|  | Like Crime Movies | Don't Like Crime Movies |
| --- | ---: | ---: |
| Men |  |  |
| Women |  |  |

**Explanation**

From the given information, we can fill in part of the table as follows:

|  | Like Crime Movies | Don't Like Crime Movies | Totals |
| --- | ---: | ---: | ---: |
| Men | $15$ |  |  |
| Women | $21$ | $12$ |  |
| Totals |  |  | $85$ |

For a given joint frequency table:

- the sum of the joint frequencies in any row/column equals the marginal frequency for that row/column, and
- the sum of the marginal frequencies in the "Totals" row/column equals the total $(85)$.

Therefore, filling in the remaining rows/columns, including the totals, we get the following:

|  | Like Crime Movies | Don't Like Crime Movies | Totals |
| --- | ---: | ---: | ---: |
| Men | $15$ | $37$ | $\bbox[2pt,Gainsboro]{\color{red}52}$ |
| Women | $21$ | $12$ | $33$ |
| Totals | $36$ | $49$ | $85$ |

Therefore, $52$ men were surveyed.

<a id="solving-word-problems-using-joint-frequency-tables"></a>
## Solving Word Problems Using Joint Frequency Tables

**Example:** The favorite activity among swimming, tanning, and playing volleyball for $100$ visitors to a public beach was surveyed. The interviewer notes the following:

- $20$ of the $45$ women chose swimming.
- $30$ visitors chose volleyball.
- $23$ men chose swimming.
- Of the men, 3 times as many selected to play volleyball as those who chose to tan.

Use a joint frequency table to determine how many women prefer volleyball.

**Explanation**

From the given information, we can fill in part of the table as follows:

|  | Swimming | Tanning | Volleyball | Totals |
| --- | ---: | ---: | ---: | ---: |
| Women | $20$ |  |  | $45$ |
| Men | $23$ | $x$ | $3x$ |  |
| Totals |  |  | $30$ | $100$ |

Note that we have let $x$ equal the number of men who plan to prefer to tan.

For a given joint frequency table:

- the sum of the joint frequencies in any row/column equals the marginal frequency for that row/column, and
- the sum of the marginal frequencies in the "Totals" row/column equals the total $(100)$.

Filling in some more rows/columns using this idea, we get the following:

|  | Swimming | Tanning | Volleyball | Totals |
| --- | ---: | ---: | ---: | ---: |
| Women | $20$ |  |  | $45$ |
| Men | $23$ | $x$ | $3x$ | $55$ |
| Totals | $43$ | $27$ | $30$ | $100$ |

From the second row, we have

$$
\begin{aligned}
23 + x + 3x &= 55 \\
4x + 23 &= 55 \\
4x &= 32 \\
x &= \frac{32}{4} \\
x &= 8
\end{aligned}
$$

Using this result and filling in the rest of the table, we finally arrive at the following:

|  | Swimming | Tanning | Volleyball | Totals |
| --- | ---: | ---: | ---: | ---: |
| Women | $20$ | $19$ | $\bbox[2pt,Gainsboro]{\color{red}6}$ | $45$ |
| Men | $23$ | $8$ | $24$ | $55$ |
| Totals | $43$ | $27$ | $30$ | $100$ |

Finally, we conclude that $6$ women prefer volleyball.
