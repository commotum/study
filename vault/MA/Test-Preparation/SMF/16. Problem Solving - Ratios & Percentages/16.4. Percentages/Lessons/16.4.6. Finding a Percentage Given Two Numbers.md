## Introduction

If we want to find the ratio of two numbers as a percentage, we can use the relationship between multiplication and division.

To demonstrate, let's determine the missing number below.

$$
0
$$

We can interpret the word "of" as multiplication:
$0$

Now, using the relationship between multiplication and division, we can write our problem as follows:
$0$

To write this fraction as a percentage, we write an equivalent fraction with $100$ as the denominator:

$$
\dfrac{7}{10} = \dfrac{7 \times 10}{10 \times 10} = \dfrac{70}{100}
$$

Now we can write this fraction as a percentage:

$$
\dfrac{70}{100} = 70\%
$$

Therefore,

$$
70 \% \,\,\text{of}\,\, 10 = 7
$$
