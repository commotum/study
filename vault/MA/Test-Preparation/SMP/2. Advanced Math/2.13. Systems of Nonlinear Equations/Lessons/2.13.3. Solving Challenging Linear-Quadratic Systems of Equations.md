## Solving Systems Where the Linear Equation Is Solved for a Variable

**Example:** ${u^{2} =-11u + v; v = 11u + 121$

A solution to the given system of equations is $(u, v)$. Which of the following is a possible value of $uv$?

**Explanation**

We are given a system of equations involving a quadratic and a linear equation. To solve, we substitute the second equation into the first:

$$
\begin{aligned}
u^{2} &= -11u + v \\
u^{2} &= -11u + (11u + 121) \\
u^{2} &= 121
\end{aligned}
$$

Now, we take the square root of both sides to solve for $u{:}$

$$
\begin{aligned}
\sqrt{u^{2}} &= \sqrt{121} \\
\mid u \mid &= 11 \\
u &= ± 11
\end{aligned}
$$

Next, we substitute each $u$-value into the second equation to find the corresponding $v$-values:

- If $u = 11$, then
$v|= 11u + 121; = 11(11) + 121; = 242$.
- If $u = -11$, then
$v|= 11(-11) + 121; =-121 + 121; = 0$.

Finally, we compute $uv$ in each case:

- If $u = 11,\ v = 242$, then
$uv = 11 \cdot 242 = 2662$.
- If $u = -11,\ v = 0$, then
$uv = -11 \cdot 0 = 0$.

Among the given answer choices, the only possible value of $uv$ is $0$.

## Solving Systems Where the Nonlinear Equation Is Solved for a Variable

**Example:** ${y = x^{2} - 5x + 3; x - y = 2$

If $(x_{1}, y_{1})$ and $(x_{2}, y_{2})$ are the two solutions to the system of equations above, what is the value of $y_{1} + y_{2}$?

**Explanation**

We are given a system of equations and asked to find $y_1 + y_2$, the sum of the $y$-coordinates of the two points where the graphs intersect.

First, we substitute the expression for $y$ into the second equation and simplify:

$$
\begin{aligned}
x - y &= 2 \\
x - (x^{2} - 5x + 3) &= 2 \\
- x^{2} + 6x - 3 &= 2 \\
- x^{2} + 6x - 5 &= 0 \\
x^{2} - 6x + 5 &= 0
\end{aligned}
$$

We solve this quadratic equation by factoring. We begin by finding two numbers that multiply to $5$ and add to $-6$. These are $-1$ and $-5{:}$

$$
\begin{aligned}
x^{2} - 6x + 5 &= 0 \\
x^{2} - 5x - x_(⏟)_(-6x) + 5 &= 0 \\
x(x - 5) - 1(x - 5) &= 0 \\
(x - 5)(x - 1) &= 0
\end{aligned}
$$

Applying the zero product rule, we obtain

$$
x = 5 \quad \text{or} \quad x = 1
$$

Now, we solve for $y$ using

$$
y = x^2 - 5x + 3{:}
$$

- If $x_1 = 5$, then
$y_1 = 5^2 - 5(5) + 3 = 25 - 25 + 3 = 3$
- If $x_2 = 1$, then
$y_2 = 1^2 - 5(1)+3=1 - 5 + 3 = -1$

Finally,

$$
y_1 + y_2 = 3 + (-1) = 2
$$

Which ordered pair is a solution to the system of equations above?

$$

$$

$$

Now, we solve for $y$ using

$$
y = x - 10{:}
$$

- If $x = 0$, then
$y = 0 - 10 = -10$.
- If $x = 2$, then
$y = 2 - 10 = -8$.

So the two solutions to the system are $(0, -10)$ and $(2, -8)$.

Among the given answer choices, we have solution $(2, -8)$.
