## Introduction

In this topic, we'll practice solving absolute value equations. In some cases, we need to first collect like terms that contain absolute value expressions before solving.

## Solving One-Step Absolute Value Equations

**Example:** Which of the following is a possible solution to the equation $\mid -x - 6 \mid = 5$?

1. $x = 1$
2. $x = -11$
3. $x = -6$

**Explanation**

To solve the equation

$$
\mid -x - 6 \mid = 5
$$

we consider both possible cases for the absolute value.

- If $\mid -x - 6 \mid = -x - 6$, then
$\mid - x - 6 \mid |= 5; - x - 6|= 5; - x|= 11; x|=-11$.
- If $\mid -x - 6 \mid = -(-x - 6)$, then
$\mid - x - 6 \mid |= 5; - (-x - 6)|= 5; x + 6|= 5; x|=-1$.

Therefore, the correct answer is "II only".

## Solving an Equation by Isolating an Absolute Value Expression

**Example:** What is the sum of the solutions to the equation given below?
$\left| s - \dfrac{7}{6} \right| - 11 = -5$

**Explanation**

First, we isolate the absolute value by adding $11$ to both sides:

$$
\begin{aligned}
\mid s - \frac{7}{6} \mid - 11 &= -5 \\
\mid s - \frac{7}{6} \mid &= 6
\end{aligned}
$$

Next, we consider both possible cases for the absolute value.

- If $\left| s - \dfrac{7}{6} \right| = s - \dfrac{7}{6}$, then
$\mid s - \frac{7}{6} \mid |= 6; s - \frac{7}{6}|= 6; s|= \frac{7}{6} + 6; s|= \frac{7}{6} + \frac{36}{6}; s|= \frac{43}{6}$.
- If $\left| s - \dfrac{7}{6} \right| = -\!\left(s - \dfrac{7}{6} \right)$, then
$\mid s - \frac{7}{6} \mid |= 6; - (s - \frac{7}{6})|= 6; - s + \frac{7}{6}|= 6; - s|= 6 - \frac{7}{6}; - s|= \frac{36}{6} - \frac{7}{6}; - s|= \frac{29}{6}; s|=-\frac{29}{6}$.

Therefore, the sum of the solutions is

$$
\dfrac{43}{6} + \left(-\dfrac{29}{6}\right) = \dfrac{14}{6} = \dfrac{7}{3}
$$

## Solving Two-Step Absolute Value Equations

**Example:** What is the sum of the solutions to the equation given below?
$\left| \dfrac{3}{5}x - \dfrac{11}{6} \right| = \dfrac{7}{3}$

**Explanation**

To solve this equation, we consider both possible cases for the absolute value.

- If $\left|\dfrac{3}{5}x - \dfrac{11}{6}\right| = \dfrac{3}{5}x - \dfrac{11}{6}$, then
$\mid \frac{3}{5}x - \frac{11}{6} \mid |= \frac{7}{3}; \frac{3}{5}x - \frac{11}{6}|= \frac{7}{3}; \frac{3}{5}x|= \frac{7}{3} + \frac{11}{6}; \frac{3}{5}x|= \frac{14}{6} + \frac{11}{6}; \frac{3}{5}x|= \frac{25}{6}; x|= \frac{25}{6} \cdot \frac{5}{3}; x|= \frac{125}{18}$.
- If $\left|\dfrac{3}{5}x - \dfrac{11}{6}\right| = -\left(\dfrac{3}{5}x - \dfrac{11}{6}\right)$, then
$\mid \frac{3}{5}x - \frac{11}{6} \mid |= \frac{7}{3}; - (\frac{3}{5}x - \frac{11}{6})|= \frac{7}{3}; - \frac{3}{5}x + \frac{11}{6}|= \frac{7}{3}; - \frac{3}{5}x|= \frac{7}{3} - \frac{11}{6}; - \frac{3}{5}x|= \frac{14}{6} - \frac{11}{6}; - \frac{3}{5}x|= \frac{3}{6}; x|= \frac{3}{6} \cdot (-\frac{5}{3}); x|=-\frac{15}{18}; x|=-\frac{5}{6}$.

Therefore, the sum of the solutions is

$$
\dfrac{125}{18} + \left(-\dfrac{5}{6}\right) = \dfrac{125}{18} - \dfrac{15}{18} = \dfrac{110}{18} = \dfrac{55}{9}
$$

## Solving Absolute Value Equations by Collecting Like Terms

**Example:** $3\begin{vmatrix}4 - a & -7 & 4 - a\end{vmatrix} = -60$
The positive solution of the equation given above is $a =$

**Explanation**

First, notice that the absolute value terms contain the same expression. So, by combining these like terms, the equation becomes

$$
\begin{aligned}
3\begin{vmatrix}4 - a & -7 & 4 - a\end{vmatrix} &= -60 \\
- 4 \mid 4 - a \mid &= -60
\end{aligned}
$$

Then, dividing both sides by $-4$, we get

$$
\mid 4 - a \mid = 15
$$

Next, we consider both possible cases for the absolute value.

- If $\mid 4 - a \mid = 4 - a$, then
$\mid 4 - a \mid |= 15; 4 - a|= 15; - a|= 11; a|=-11$.
- If $\mid 4 - a \mid = -(4 - a)$, then
$\mid 4 - a \mid |= 15; - (4 - a)|= 15; - 4 + a|= 15; a|= 19$.

Since the question asks for the positive solution, the correct answer is

$$
a=\bbox[4pt,border: 1px solid lightgray]{19}
$$
