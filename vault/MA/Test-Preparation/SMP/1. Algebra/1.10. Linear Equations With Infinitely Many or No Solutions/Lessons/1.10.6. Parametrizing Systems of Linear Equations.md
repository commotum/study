## Introduction

On the math section of the SAT exam, you may encounter systems of linear equations whose solutions can be expressed using parameters. To prepare, we'll go over writing systems in different parametric forms and determine which parametrizations in a given list are valid.

---

<a id="parametrizing-systems-using-the-form-t-yt"></a>
## Parametrizing Systems Using the Form (t, y(t))

**Example:** Given that the lines $-7x + y = 5$ and $-14x + 2y = 10$ intersect at an infinite number of points, which of the following describes the intersection points, where $t$ is a real number?

1. $\left(t,7t-5 \right)$
2. $\left(t,-7t+5 \right)$
3. $\left(t,7t+5 \right)$
4. $\left(t,5t+7 \right)$

**Explanation**

We're given that the two lines intersect at an infinite number of points.

We want to find an expression that represents every point of intersection. Notice that we're required to write our solution in the form
$\big(t, f(t)\big)$.

Therefore, we can find our solution as follows:

- First, we set $x=t$.
- Then, we find the corresponding $y$-coordinate for each $x$-coordinate by solving one of the lines for $y$.
- Finally, we write the final result in terms of $t$.

So, we pick the line

$$
-7x + y = 5
$$

solve it for $y$, and then substitute $x = t$, as follows:

$$
\begin{aligned}
-7x + y &= 5 \\
y &= 7x + 5 \\
y &= 7t + 5
\end{aligned}
$$

So, the intersection points are

$$
\left(t,7t+5 \right)
$$

where $t$ is any number.

Therefore, the correct answer is **only III.**

## Parametrizing Systems Using the Forms (x(y), y) or (x(t), t)

**Example:** Given that the lines $5x - 10y = 15$ and $x - 2y = 3$ intersect at an infinite number of points, which of the following describes the intersection points, where $t$ is a real number?

1. $\left(3t+3,t\right)$
2. $\left(2t-3,t\right)$
3. $\left(2t+2,t\right)$
4. $\left(2t+3,t\right)$

**Explanation**

We're given that the two lines intersect at an infinite number of points.

We want to find an expression that represents every point of intersection. Notice that we're required to write our solution in the form
$\big(f(t), t\big)$.

Therefore, we can find our solution as follows:

- First, we set $y=t$.
- Then, we find the corresponding $x$-coordinate for each $y$-coordinate by solving one of the lines for $x$.
- Finally, we write the final result in terms of $t$.

So, we pick the line $x - 2y = 3$, solve it for $x$, and then substitute $y = t$, as follows:

$$
\begin{aligned}
x - 2y &= 3 \\
x &= 2y + 3 \\
x &= 2t + 3
\end{aligned}
$$

So, the intersection points are

$$
\left(2t+3,t\right)
$$

where $t$ is any number.

Therefore, the correct answer is **only IV.**

## Parametrizing Systems Using the Form (x(t), y(t))

**Example:** Given that the lines $x - y = 4$ and $2x - 2y = 8$ intersect at an infinite number of points, fill in the blanks to describe these points in terms of the real parameter $t$ such that $y=6t$.

The intersection points are $\Big(\, \bbox[3pt,border:solid black 1pt]{\phantom{XXXX}},\,6t\Big)$.

**Explanation**

We're given that the two lines intersect at an infinite number of points.

We want to find an expression that represents every point of intersection. Notice that we're required to write our solution in the form
$\big(f(t), 6t\big)$.

Therefore, we can find our solution as follows:

- First, we set $y=6t$.
- Then, we find the corresponding $x$-coordinate for each $y$-coordinate by solving one of the lines for $x$.
- Finally, we write the final result in terms of $t$.

So, we pick the line $x - y = 4$, solve it for $x$, and then substitute $y = 6t$, as follows:

$$
\begin{aligned}
x - y &= 4 \\
x &= y + 4 \\
x &= 6t + 4
\end{aligned}
$$

Therefore, the intersection points are

$$
\left(\,\bbox[4pt,border: 1px solid lightgray]{6t+4}, 6t\right)
$$

where $t$ is any number.

## Determining Valid Parametrizations

**Example:** ${6x - 3y = 9; 12x - 6y = 18$
Consider the system of equations above. Given that this system has infinitely many solutions $(x,y)$, which of the following are valid parametrizations of the solutions?

1. $(t,\, 2t-3)$
2. $(3t-9,\, t)$
3. $(4t,\, 8t-3)$

**Explanation**

Since there are infinitely many solutions to the system, both equations have the same set of solutions $(x,y)$. Therefore, we only need to consider the solution set of one of the equations.

Let's consider each answer choice in turn.

- First, we must construct a parametrization of the form $(t, f(t))$. So, we set $x = t$ and solve the equation $6x-3y = 9$ for $y$, as follows:
$6x - 3y|= 9; - 3y|=-6x + 9; 3y|= 6x - 9; y|= \frac{6x - 9}{3}; y|= 2x - 3; y|= 2t - 3$
Hence, $(t,\, 2t-3)$ is a valid parametrization. $\color{green}{\checkmark}$
- Next, we must construct a parametrization of the form $(g(t), t)$. So, we set $y = t$ and solve the equation $6x-3y = 9$ for $x$, as follows:
$6x - 3y|= 9; 6x|= 3y + 9; x|= \frac{3y + 9}{6}; x|= \frac{1}{2}y + \frac{3}{2}; x|= \frac{1}{2}t + \frac{3}{2}$
This gives $\left(\dfrac{1}{2}t + \dfrac{3}{2},\, t\right)$, which is *not* the same as $(3t-9,\, t)$. Hence, $(3t-9,\, t)$ is **NOT** a valid parametrization. $\color{red}{\times}$
- Finally, we must construct a parametrization of the form $(4t,h(t))$. So, we set $x=4t$ and solve the equation $6x-3y=9$ for $y$, as follows:
$6x - 3y|= 9; - 3y|=-6x + 9; 3y|= 6x - 9; y|= \frac{6x - 9}{3}; y|= 2x - 3; y|= 2(4t) - 3; y|= 8t - 3$
which holds for all $t$. Hence, $(4t,\, 8t-3)$ is a valid parametrization. $\color{green}{\checkmark}$

Therefore, the correct answer is **only I and III.**
