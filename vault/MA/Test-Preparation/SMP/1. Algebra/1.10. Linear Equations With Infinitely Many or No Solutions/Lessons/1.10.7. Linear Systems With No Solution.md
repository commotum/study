## Identifying a Possible Second Equation in a System With No Solutions

**Example:** One of the two equations in a linear system is $-8x - 4y = 12$. The system has no solution. Which of the following could be the other equation in the system?

1. $2x + y = 5$
2. $8x + 4y = -12$
3. $-2x + y = 7$
4. $x - 2y = 1$

**Explanation**

A system of linear equations has no solution if the equations represent parallel lines that never intersect. This occurs when both equations have the same slope but different $y$-intercepts.

Let’s start by rewriting the given equation in slope-intercept form,

$$
y = mx + b{:}
$$

$$
\begin{aligned}
-8x - 4y &= 12 \\
- 4y &= 8x + 12 \\
y &= -2x - 3
\end{aligned}
$$

So the given equation has slope $-2$ and $y$-intercept $-3$.

Let's now look for a second equation among the choices that has the same slope but a different $y$-intercept. We consider the choices in turn.

- Consider the equation $8x + 4y = -12$ and rewrite it in slope-intercept form:
$y = -2x - 3$
This equation has the same slope and the same $y$-intercept as the given equation. It is not valid.
- Consider the equation $-2x + y = 7$ and rewrite it in slope-intercept form:
$y = 2x + 7$
This equation has a different slope, $m = 2 \ne -2$. Therefore, it is not valid.
- Consider the equation $x - 2y = 1$ and rewrite it in slope-intercept form:
$y = \dfrac{1}{2}x - \dfrac{1}{2}$
This equation has a different slope, $m = \dfrac{1}{2} \ne -2$. Therefore, it is not valid.
- Consider the equation $2x + y = 5$ and rewrite it in slope-intercept form:
$y = -2x + 5$.
This equation has the same slope, $m = -2$, and a different $y$-intercept, $b=5\neq - 3$. Therefore, it is valid.

Consequently, the second equation in the system could be

$$
2x + y = 5
$$

Therefore, the correct answer is **only I.**

## Identifying a System With No Solution

**Example:** Which of the following systems of linear equations has no solution?

${y =-3; y = x - 3$

${y = 5x + 9; y = 5x - 4$

${x = 6; y =-1$

${y =-2x + 3; y = 2x - 5$

**Explanation**

A system of linear equations has no solution if the equations represent parallel lines that never intersect. This occurs when both equations have the same slope but different $y$-intercepts.

Let’s analyze each system:

- ${y =-3; y = x - 3$
The first equation is a horizontal line, so it has slope $0$; the second has slope $1$. The slopes are different, so the lines intersect at one point.

$\qquad$ Thus, this system has one solution.

- ${y =-2x + 3; y = 2x - 5$
The slopes are different ($-2$ and $2$), so the lines intersect at one point.

$\qquad$ Thus, this system has one solution.

- ${x = 6; y =-1$
This system contains a vertical line and a horizontal line. These lines intersect at exactly one point.

$\qquad$ Thus, this system has one solution.

- ${y = 5x + 9; y = 5x - 4$
Both equations have slope $5$, but different $y$-intercepts ($9$ and $-4$). These lines are parallel and distinct, so they never intersect.

$\qquad$ Thus, this system has **no** solution.

Therefore, the correct answer is **only II.**

## Finding a Slope Parameter in a System With No Solutions

**Example:** ${y = \frac{1}{4}x - 5; y = dx + 9$

In the system of equations above, $d$ is a constant. If the system has no solution, what is the value of $d$?

**Explanation**

A system of linear equations has no solution if the equations represent parallel lines that never intersect. This occurs when both equations have the same slope but different $y$-intercepts.

Both equations are in slope-intercept form,

$$
y = mx + b
$$

where $m$ is the slope and $b$ is the $y$-intercept.

- The first equation $y = \dfrac{1}{4}x - 5$ has slope $\dfrac{1}{4}$ and $y$-intercept $-5$.
- The second equation $y = dx + 9$ has slope $d$ and $y$-intercept $9$.

Since the equations have different $y$-intercepts ($-5$ and $9$), the slopes must be equal for the system to have no solution.

Equating the slopes, we get

$$
d = \dfrac{1}{4}
$$

## Finding an Unknown Parameter in a Mixed System With No Solutions

**Example:** Consider the system of equations below, where $a$ is a constant.
${7 - 9m = aw; - 9m + 6w =-\frac{3}{2}$
If the system has no solution, what is the value of $a$?

**Explanation**

A system of linear equations has no solution if the equations represent parallel lines that never intersect. This occurs when both equations have the same slope but different $y$-intercepts.

Let’s start by rewriting the equations in slope-intercept form,

$$
m = kw + b
$$

where $k$ is the slope and $b$ is the $y$-intercept:

- First equation:
$7 - 9m|= aw; - 9m|= aw - 7; m|=-\frac{a}{9}w + \frac{7}{9}$
- Second equation:
$-9m + 6w|=-\frac{3}{2}; - 9m|=-6w - \frac{3}{2}; m|= \frac{2}{3}w + \frac{1}{6}$

Since the equations have different $y$-intercepts

$$
\left(\dfrac{7}{9}\right
$$

and

$$
\left.\dfrac{1}{6}\right)
$$

the slopes must be equal for the system to have no solution.

Therefore, we match the slopes and solve for $a{:}$

$$
\begin{aligned}
-\frac{a}{9} &= \frac{2}{3} \\
- a &= 6 \\
a &= -6
\end{aligned}
$$

## Finding an Unknown Parameter by Solving a Rational Equation

**Example:** Consider the system of equations below, where $q$ is a constant.
${15x + 10y =-25; y - 8qy = \frac{7}{5} + 6x$
Given that the system has no solution, what is the value of $q$?

**Explanation**

A system of linear equations has no solution if the equations represent parallel lines that never intersect. This occurs when both equations have the same slope but different $y$-intercepts.

Let’s start by rewriting the equations in slope-intercept form,

$$
y = mx + b
$$

where $m$ is the slope and $b$ is the $y$-intercept.

- First equation:
$15x + 10y|=-25; 10y|=-15x - 25; y|= \frac{-15}{10}x + \frac{-25}{10}; y|=-\frac{3}{2}x - \frac{5}{2}$
- Second equation:
$y - 8qy|= \frac{7}{5} + 6x; (1 - 8q)y|= 6x + \frac{7}{5}; y|= (6)/((1 - 8q))x + (7)/(5(1 - 8q))$

Therefore, for this equation to have the same slope as the first equation, we match the slopes and solve for $q{:}$

$$
\begin{aligned}
(6)/((1 - 8q)) &= -\frac{3}{2} \\
6 \cdot 2 &= -3(1 - 8q) \\
12 &= -3 + 24q \\
24q &= 15 \\
q &= \frac{5}{8}
\end{aligned}
$$

Consequently, the system has no solution for

$$
q = \dfrac{5}{8}
$$
