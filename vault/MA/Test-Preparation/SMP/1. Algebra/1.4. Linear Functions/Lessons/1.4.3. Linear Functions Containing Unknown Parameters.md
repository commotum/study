## Introduction

A common theme on the math section of the SAT is solving problems with linear functions that have unknown parameters.

The key is to treat unknown parameters as ordinary numbers. Let's practice finding their values and evaluating the functions once those values are known.

## Determining an Unknown Parameter in a Linear Function

**Example:** The function $q$ is defined by $q(x) = -x + c$, where $c$ is a constant. If $q(0) = 17$, what is the value of $c$?

**Explanation**

Substituting $x=0$ into the expression for $q(x)$ and using the fact that $q(0) = 17$, we can find the value of $c$, as follows:

$$
\begin{aligned}
q(x) &= -x + c \\
q(0) &= -0 + c \\
17 &= c \\
c &= 17
\end{aligned}
$$

## Evaluating a Function Containing an Unknown Parameter

**Example:** The function $p$ is defined by $p(x) = nx - 10$, where $n$ is a constant. If $p(1) = 5$, what is the value of $p(-2)$?

**Explanation**

First, we calculate the value of $n$.

Substituting $x=1$ into the expression for $p(x)$ and using the fact that $p(1) = 5$, we can find $n$, as follows:

$$
\begin{aligned}
p(x) &= nx - 10 \\
p(1) &= n(1) - 10 \\
5 &= n - 10 \\
5 + 10 &= n \\
n &= 15
\end{aligned}
$$

Now, we can obtain the value of $p(-2)$ by substituting $x = -2$ and $n = 15$ into the expression for $p(x)$, as follows:

$$
\begin{aligned}
p(x) &= nx - 10 \\
p(-2) &= 15(-2) - 10 \\
&=-30 - 10 \\
&=-40
\end{aligned}
$$

## Evaluating a Function With a Binomial and an Unknown Parameter

**Example:** The function $g$ is defined by
$g(x) = 2x + m(x + 3)$,
where $m$ is a constant. If $g(-2) = -4$, what is the value of $g(1)$?

**Explanation**

First, we calculate the value of $m$.

Substituting $x = -2$ into the expression for $g(x)$ and using the fact that $g(-2) = -4$, we can find $m$, as follows:

$$
\begin{aligned}
g(x) &= 2x + m(x + 3) \\
g(-2) &= 2(-2) + m(-2 + 3) \\
- 4 &= -4 + m(1) \\
- 4 + 4 &= m \\
0 &= m
\end{aligned}
$$

Now, we can obtain the value of $g(1)$ by substituting $x = 1$ and $m = 0$ into the expression for $g(x)$, as follows:

$$
\begin{aligned}
g(x) &= 2x + m(x + 3) \\
g(1) &= 2(1) + 0(1 + 3) \\
&= 2 + 0 \\
&= 2
\end{aligned}
$$

## Determining an Unknown Parameter in Functions Containing Two Unknown Parameters

**Example:** The function $g$ is defined by $g(x) = mx + c$, where $m$ and $c$ are constants. If $g(0) = 5$ and $g(4) = -3$, what is the value of $m$?

**Explanation**

We are given that $g(0) = 5$. Therefore, we can determine the value of $c$, as follows:

$$
\begin{aligned}
g(x) &= mx + c \\
g(0) &= m(0) + c \\
5 &= 0 + c \\
c &= 5
\end{aligned}
$$

We are also given that $g(4) = -3$. Since $c = 5$, we can find the value of $m$, as follows:

$$
\begin{aligned}
g(x) &= mx + c \\
g(4) &= m(4) + 5 \\
- 3 &= 4m + 5 \\
4m &= -3 - 5 \\
4m &= -8 \\
m &= \frac{-8}{4} \\
m &= -2
\end{aligned}
$$
