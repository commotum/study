## Introduction

A common question on the math section of the SAT is modeling real-world situations with two-variable linear inequalities. In this topic, you will practice writing inequalities that represent real-world constraints, using both strict and non-strict inequalities.

---

<a id="modeling-using-inequalities-containing-no-coefficients"></a>
## Modeling Using Inequalities Containing No Coefficients

**Example:** Two fitness trainers are running workout stations. Each trainer completes a number of rounds with clients. They must complete fewer than $40$ rounds in total. Find the inequality that represents this situation, where $r_1$ is the number of rounds completed by Trainer $1$ and $r_2$ is the number completed by Trainer $2$.

**Explanation**

Let $r_1$ represent the number of rounds completed by Trainer $1$ and $r_2$ the number completed by Trainer $2$. The total number of rounds is:
$r_1 + r_2$

We are told the trainers must complete *fewer than* $40$ rounds.

So, the inequality representing this scenario is
$r_1 + r_2 < 40$.

## Modeling With Strict Inequalities

**Example:** At an airport, two luggage scanners are used. Scanner $\textrm{A}$ processes $90$ bags per hour, while Scanner $\textrm{B}$ processes $120$ bags per hour. If Scanner $\textrm{A}$ is used for $a$ hours and Scanner $\textrm{B}$ is used for $b$ hours, and more than $1,\!800$ bags must be scanned, find the inequality that represents this situation.

**Explanation**

The total number of bags scanned is the sum from both scanners:

- Scanner $\textrm{A}$ processes $90$ bags per hour for $a$ hours, so the number of bags scanned is $90a$.
- Scanner $\textrm{B}$ processes $120$ bags per hour for $b$ hours, so the number of bags scanned is $120b$.

Thus, the total number of bags scanned is
$90a + 120b$.

Since the total must be *more than* $1,\!800$ bags, we have the inequality
$90a + 120b > 1{,}800$.

Hence, the inequality is
$90a + 120b > 1{,}800$.

## Modeling With Non-Strict Inequalities

**Example:** A factory worker is assembling products. Each widget of type $\textrm{X}$ requires $\[math]15$ in parts, and each widget of type $\textrm{Y}$ requires $\[/math]12$. The total value of parts used must be no less than $\[math]360$. If $x$ represents the number of type $\textrm{X}$ widgets and $y$ represents the number of type $\textrm{Y}$ widgets, find the inequality that represents this situation.

**Explanation**

The worker is building $x$ type $\textrm{X}$ widgets at $\[math]15$ each and $y$ type $\textrm{Y}$ widgets at $\[/math]12$ each.

So, the total cost is
$15x + 12y$.

We are told the value must be *no less than* $\[math]360$, and so we have

$$
15x + 12y \geq 360
$$

Thus, the correct inequality is

$$
15x + 12y \geq 360
$$

## Modeling With Non-Strict Inequalities: Additional Steps Required

**Example:** An email system allows attachments totaling at most $25$ MB. A required system log of $3$ MB is automatically attached. Images are $2$ MB each and video clips are $7$ MB each. Find the inequality that represents the possible combinations of images, $i$, and clips, $c$, that can be sent.

**Explanation**

We are told that

- The total attachment size must not exceed $25$ MB.
- The system log already uses $3$ MB.

This means the remaining size available is:
$25 - 3 = 22$

Each image uses $2$ MB, and each clip uses $7$ MB. If $i$ is the number of images and $c$ is the number of clips, the variable attachment size is:
$2i + 7c$

Since the variable attachments must not exceed $22$ MB, we write the inequality:

$$
2i + 7c \leq 22
$$
