## Introduction

In this topic, we'll practice analyzing systems of two-variable inequalities. This involves identifying relationships between systems and their solutions, determining parameter values, and describing the possible range of variables that satisfy the inequalities.

---

<a id="identifying-a-system-given-a-solution"></a>
## Identifying a System Given a Solution

**Example:** The point $(3, -7)$ in the $xy$-plane is a solution to which of the following systems of inequalities?

1. $x < 0, \; y > 0$
2. $x < 0, \; y < 0$
3. $x > 0, \; y < 0$
4. $x > 0, \; y > 0$

**Explanation**

We analyze the coordinates $(3, -7)$.

- Since $x = 3$, we have $x > 0$.
- Since $y = -7$, we also have $y < 0$.

Therefore, the point $(3, -7)$ satisfies the system

$$
x > 0, \quad y < 0
$$

## Identifying a Solution Given a System

**Example:** Which of the following ordered pairs $(x, y)$ is a solution to the following system of inequalities?
${y > 2x - 1; x + y < 4$

1. $(2,3)$
2. $(1,1)$
3. $(2,2)$
4. $(1,2)$

**Explanation**

We substitute each ordered pair into the inequalities to check which one satisfies both conditions.

- For $(2, 3)$:
$\begin{bmatrix}y > 2x - 1 & ⇒3 > 2(2) - 1 = 3\cdot \\ x + y < 4 & ⇒2 + 3 = 5 < 4\cdot\end{bmatrix}$
- For $(1, 1)$:
$\begin{bmatrix}y > 2x - 1 & ⇒1 > 2(1) - 1 = 1\cdot \\ x + y < 4 & ⇒1 + 1 = 2 < 4✓\end{bmatrix}$
- For $(2, 2)$:
$\begin{bmatrix}y > 2x - 1 & ⇒2 > 2(2) - 1 = 3\cdot \\ x + y < 4 & ⇒2 + 2 = 4 < 4\cdot\end{bmatrix}$

- For $(1, 2)$:
$\begin{bmatrix}y > 2x - 1 & ⇒2 > 2(1) - 1 = 1✓ \\ x + y < 4 & ⇒1 + 2 = 3 < 4✓\end{bmatrix}$

Therefore, only the pair $(1, 2)$ satisfies both inequalities.

## Identifying a Table of Values Corresponding to a System

**Example:** Consider the following system of inequalities:

${v > u + 1; u > 8$

Which of the following tables contains only points $(u, v)$ that satisfy this system?

I

| $u$ | $v$ |
| --- | ---: |
| $9$ | $10$ |
| $10$ | $12$ |
| $12$ | $15$ |

II

| $u$ | $v$ |
| --- | ---: |
| $9$ | $11$ |
| $10$ | $12$ |
| $12$ | $15$ |

III

| $u$ | $v$ |
| --- | ---: |
| $8$ | $12$ |
| $9$ | $11$ |
| $10$ | $12$ |

IV

| $u$ | $v$ |
| --- | ---: |
| $9$ | $11$ |
| $8$ | $12$ |
| $10$ | $11$ |

**Explanation**

We are asked to determine which table contains only points that satisfy the system of inequalities $v > u + 1$ and $u > 8$. To do this, we check that each point satisfies both conditions.

The correct table is the following:

| $u$ | $v$ |
| --- | ---: |
| $9$ | $11$ |
| $10$ | $12$ |
| $12$ | $15$ |

Notice that for the points $(9, 11)$, $(10, 12)$, and $(12, 15)$, we have:

$$
\begin{bmatrix}11 & > 9 + 1 = 10✓ \\ 12 & > 10 + 1 = 11✓ \\ 15 & > 12 + 1 = 13✓\end{bmatrix}
$$

and
$\begin{bmatrix}9 & > 8✓ \\ 10 & > 8✓ \\ 12 & > 8✓\end{bmatrix}$

Both inequalities are satisfied for all points.

## Finding an Unknown Parameter Given a System and Its Solution

**Example:** Consider the following system of inequalities:
${y \le 12; y > \frac{x}{2} + 2$

The point $(x, 10)$ is a solution to the system of inequalities in the $xy$-plane. Which of the following could be the value of $x$?

1. $15\qquad$ II. $20\qquad$ III. $25 \qquad$ IV. $30$

**Explanation**

We substitute $y = 10$ into each inequality to determine which $x$-values satisfy the system of inequalities.

- Substituting $y = 10$ into the first inequality, we obtain
$10 \leq 12. \quad \color{green}\checkmark$
- Substituting $y = 10$ into the second inequality $y > \dfrac{x}{2} + 2$ and solving for $x$, we get:
$\begin{bmatrix}10 & > \frac{x}{2} + 2 \\ 8 & > \frac{x}{2} \\ x & < 16\end{bmatrix}$

Therefore, among the answer choices, only $x = 15$ satisfies both inequalities.

## Determining the Range of a Variable Given a System of Inequalities

**Example:** Consider the following system of inequalities:

${y < 5x - 3; x < - 2$

Which of the following consists of the $y$-coordinates of all the points that satisfy the system of inequalities above?

1. $y < -7$
2. $y < -9$
3. $y < -11$
4. $y < -13$

**Explanation**

We want to find all possible values of $y$ such that the point $(x, y)$ satisfies both inequalities.

Since $x < -2$, the largest possible value of $5x - 3$, which serves as the upper bound for $y$, occurs as $x$ is near $-2$.

To identify this boundary value, we substitute $x = -2$ into the expression:
$\begin{bmatrix}y & < 5x - 3 \\ y & < 5(-2) - 3 \\ y & < - 13\end{bmatrix}$

So, the values of $y$ that satisfy the system are $y < -13$.
