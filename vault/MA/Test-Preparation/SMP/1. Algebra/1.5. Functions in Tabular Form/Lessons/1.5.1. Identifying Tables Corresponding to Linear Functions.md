## Introduction

In this lesson, we'll practice constructing tables corresponding to linear relationships, whether shown graphically as lines, written as functions, or expressed as equations. Dealing with functions expressed in tabular form is a common theme of the math section of the SAT exam.

## Identifying a Table Corresponding to a Line

**Example:** The graph shows a straight line in the coordinate plane. Write a table that gives three $x$-values and their corresponding $y$-values for points that lie on the line.

![](<../Source/1.5.1. Identifying Tables Corresponding to Linear Functions/Images/53ee86c224b49ae9e46304049868fd43.png>)

**Explanation**

From the graph, we can see that the points $(-3, 2)$, $(0, -4)$, and $(-2, 0)$ lie on the line.

Now, we’ll analyze each of these points in turn:

- For $(-3, 2)$: when $x = -3$, the corresponding $y$-value is $2$.
- For $(0, -4)$: when $x = 0$, the corresponding $y$-value is $-4$.
- For $(-2, 0)$: when $x = -2$, the corresponding $y$-value is $0$.

Therefore, the table is:

| $x$ | $y$ |
| --- | ---: |
| $-3$ | $2$ |
| $-2$ | $0$ |
| $0$ | $-4$ |

## Identifying a Table Corresponding to a Function

**Example:** $f(x) = 6x - 1$

For the linear function $f$, write a table that shows the corresponding values of $f(x)$ for $x=-1,1,2$

**Explanation**

To write the table, substitute each $x$ into

$$
f(x) = 6x - 1
$$

For $x = -1{:}$

$$
\begin{aligned}
f(-1) &= 6(-1) - 1 \\
&=-6 - 1 \\
&=-7
\end{aligned}
$$

For $x = 1{:}$

$$
\begin{aligned}
f(1) &= 6(1) - 1 \\
&= 6 - 1 \\
&= 5
\end{aligned}
$$

For $x = 2{:}$

$$
\begin{aligned}
f(2) &= 6(2) - 1 \\
&= 12 - 1 \\
&= 11
\end{aligned}
$$

Therefore, the table is the following:

| $x$ | $f(x)$ |
| --- | ---: |
| $-1$ | $-7$ |
| $1$ | $5$ |
| $2$ | $11$ |

## Identifying a Table Corresponding to a Constant Function

**Example:** $f(x) = 15$

For the given linear function $f$, write a table that gives the corresponding values of $f(x)$ for $x=0,1,2$.

**Explanation**

The function

$$
f(x) = 15
$$

is a linear function where the output is always $15$ for any value of $x$.
That means every point on the graph has a $y$-coordinate of $15$.

Now, we’ll analyze each of the given values of $x$ in turn:

- For $x = 0$, we have $f(0) = 15$.
- For $x = 1$, we have $f(1) = 15$.
- For $x = 2$, we have $f(2) = 15$.

Therefore, the table is

| $x$ | $f(x)$ |
| --- | ---: |
| $0$ | $15$ |
| $1$ | $15$ |
| $2$ | $15$ |

## Identifying a Table Corresponding to a "Totals" Equation

**Example:** $\dfrac{1}{2}x + \dfrac{3}{4}y = -5$

Write a table that gives the corresponding values of $y$ for the given equation with $x=0,3,6$.

**Explanation**

To write the table, we first express $y$ as a function of $x{:}$

$$
\begin{aligned}
\frac{3}{4}y &= -5 - \frac{1}{2}x \\
y &= \frac{4}{3}(-5 - \frac{1}{2}x) \\
y &= -\frac{20}{3} - \frac{2}{3}x
\end{aligned}
$$

Now, we’ll analyze each of the given values of $x$ in turn.

- Consider $x = 0$.
$y|=-\frac{20}{3} - \frac{2}{3}(0); =-\frac{20}{3}$
- Consider $x = 3$.
$y|=-\frac{20}{3} - \frac{2}{3}(3); =-\frac{20}{3} - 2; =-\frac{26}{3}$
- Consider $x = 6$.
$y|=-\frac{20}{3} - \frac{2}{3}(6); =-\frac{20}{3} - 4; =-\frac{32}{3}$

Therefore, the table is the following:

| $x$ | $y$ |
| --- | ---: |
| $0$ | $\displaystyle -\dfrac{20}{3}$ |
| $3$ | $\displaystyle -\dfrac{26}{3}$ |
| $6$ | $\displaystyle -\dfrac{32}{3}$ |
