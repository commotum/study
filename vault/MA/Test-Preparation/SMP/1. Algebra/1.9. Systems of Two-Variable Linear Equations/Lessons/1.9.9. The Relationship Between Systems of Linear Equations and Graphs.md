In this topic, we'll practice analyzing the relationship between systems of linear equations and their graphs by identifying systems that correspond to given graphs and interpreting graphs that represent particular systems.

## Identifying the Simplified System of Linear Equations Given a Graph

**Example:** Which of the following systems of equations has the same solution as the system of equations graphed above?

![](<../Source/1.9.9. The Relationship Between Systems of Linear Equations and Graphs/Images/b8d52c311d23bb41246b0458a0dd28df.png>)

${x =-4; y = 1$

${x = 4; y =-1$

${x = 1; y =-4$

${x =-1; y = 4$

**Explanation**

The solution to a system of two linear equations corresponds to the point where the two lines intersect.

By inspecting the graph, we can see that the lines intersect at the point $(1, -4)$.

So, the solution can be written as follows:

$$
{x = 1; y =-4
$$

Therefore, the correct answer is **only III.**

## Identifying the Graph Given a System of Linear Equations

**Example:** Which of the graphs above represents the following system of linear equations?
${x + 3y =-3; 2x - 5y = 10$

![](<../Source/1.9.9. The Relationship Between Systems of Linear Equations and Graphs/Images/3f70249ff8f897e197fc6c4c1c912447.png>)

**Explanation**

To determine which graph represents this system, we first rewrite each equation in slope-intercept form.

- For the first equation, we have the following:
$x + 3y|=-3; 3y|=-x - 3; y|=-\frac{1}{3}x - 1$
This line has a slope of $-\dfrac{1}{3}$ and a $y$-intercept of $-1$.
- For the second equation, we have the following:
$2x - 5y|= 10; - 5y|=-2x + 10; y|= \frac{2}{5}x - 2$
This line has a slope of $\dfrac{2}{5}$ and a $y$-intercept of $-2$.

Now, we draw both lines on the same graph.

- For the first line, $y = -\dfrac{1}{3}x - 1{:}$If $x = 0$, then $y = -1$.If $y = 0$, then $x = -3$.So, the line passes through points $(0, -1)$ and $(-3, 0)$.
- For the second line, $y = \dfrac{2}{5}x - 2{:}$If $x = 0$, then $y = -2$.If $y = 0$, then $x = 5$.So, the line passes through points $(0, -2)$ and $(5, 0)$.

Therefore, we obtain the following graph, where the intersection of the lines represents the solution to our system.

![](<../Source/1.9.9. The Relationship Between Systems of Linear Equations and Graphs/Images/950712d19cd19014d648f6ab2f3b9ee1.png>)

Therefore, the correct answer is graph II.

## Identifying the System of Linear Equations Given a Graph

**Example:** What system of linear equations represents the graph shown above?

![](<../Source/1.9.9. The Relationship Between Systems of Linear Equations and Graphs/Images/97d4355a3c91a48722e4bd3e5451713e.png>)

${-2x + y =-5; x + 2y = 0$

${2x - y = 5; x - 2y = 0$

${x + 2y = 5; 2x + y = 0$

${2x - y =-5; x - 2y = 0$

**Explanation**

Recall that each equation of a linear system defines a straight line. The solution to the system corresponds to the point where the two lines intersect.

Let’s find the equations of the lines.

- For the first (orange) line, we pick two points on the line.
For example, this line passes through $(0, -5)$ and $(1, -3)$.Now, we compute the slope:
$m = \frac{-3 - (-5)}{1 - 0} = \frac{2}{1} = 2$
Using the slope and the point $(0, -5)$, we can write the equation in slope-point form:
$y + 5|= 2(x - 0); y|= 2x - 5$
and rewrite it in standard form:
$y|= 2x - 5; - 2x + y|=-5$
- For the second (blue) line, we pick two points on the line.
This line passes through $(0, 0)$ and $(2, -1)$.Now, we compute the slope:
$m = \frac{-1 - 0}{2 - 0} = -\frac{1}{2}$
Using the slope and the point $(0, 0)$, we can write the equation in slope-point form:
$y|=-\frac{1}{2}x$
and rewrite it in standard form:
$y|=-\frac{1}{2}x; 2y|=-x; x + 2y|= 0$

So, the system that matches the graph is the following:

$$
{-2x + y =-5; x + 2y = 0
$$

Therefore, the correct answer is **only I.**
