## Determining a Possible Exponential Base From a Model

**Example:** The scatterplot shows the relationship between two variables, $x$ and $y$. An exponential model for the curve can be written as $y=a(b)^{x}$ with $a>0$ and $b>0$. Which of the following is closest to the value of $b$?

![](<../Source/4.7.5. Quadratic vs. Exponential Models/Images/999808ae5293d63c23deff5ac571fa43.png>)

1. $0.48$
2. $1.06$
3. $1.21$
4. $4.48$

**Explanation**

We are given that an equation for the exponential model shown can be written as $y=a(b)^{x}$, where $a>0$ and $b>0$. For an exponential model in this form, if $b$ is between $0$ and $1$, the model is decreasing. If $b$ is greater than $1$, the model is increasing.

Because our exponential model is decreasing, the value of $b$ must be between $0$ and $1$. Of the given choices, only $0.48$ satisfies this condition. Therefore, $0.80$ is closest to the value of $b$.

## Identifying a Possible Quadratic Best-Fit Curve

**Example:** The scatterplot shows the relationship between two variables, $x$ (time) and $y$ (revenue). Of the following equations, which best models the data in the scatterplot?

![](<../Source/4.7.5. Quadratic vs. Exponential Models/Images/cbaeb78aacf9b5719c78e9175ce3ab73.png>)

1. $y=-2.28x^{2}+20.2x+652.76$
2. $y=2.28x^{2}+20.2x+652.76$
3. $y=-2.28x^{2}-20.2x+652.76$
4. $y=-2.28x^{2}+20.2x-652.76$

**Explanation**

We want to find the best model for the scatterplot data shown, in the quadratic form

$$
y = ax^2+bx+c
$$

where $a$, $b$, and $c$ are constants, with

$$
a \neq 0
$$

- The data in the scatterplot appear to form a downward-opening parabola. Therefore, the leading coefficient $a$ must be negative.
- The points look symmetric about the line $x=4$. Using the axis of symmetry formula $x=-\dfrac{b}{2a}$ and solving for $b$, we get
$x|=-\frac{b}{2a}; 4|=-\frac{b}{2a}; b|=-8a$.
Since $a$ is negative, the coefficient of the linear term should be positive.
- The $y$-intercept of the quadratic model is near $(0,650)$.

Therefore, of the given choices, only choice

$$
y = -2.28x^{2} + 20.2x+652.76
$$

is the best quadratic model for the data in the scatterplot.
