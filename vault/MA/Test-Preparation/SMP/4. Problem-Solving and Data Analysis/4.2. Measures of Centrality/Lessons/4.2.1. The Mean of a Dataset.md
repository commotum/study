## Finding the Mean of a Dataset (Integer Mean)

**Example:** $5,\: 10,\: 15,\: 20,\: 25$

What is the mean of the data set given above?

**Explanation**

The mean (or average) is calculated by dividing the sum of all the data values by the number of values.

First, we add all the numbers:

$$
5 + 10 + 15 + 20 + 25 = 75
$$

Then, we divide the total by the number of data points. Since there are $5$ values, the mean of the data set is

$$
\text{Mean} = \dfrac{75}{5} = 15
$$

## Finding the Mean of a Dataset (Rational Mean)

**Example:** $2,\: 3,\: 5,\: 7,\: 6,\: 8,\: 4,\: 3$

What is the mean of the data points given above?

**Explanation**

The mean (or average) is calculated by dividing the sum of all the data values by the number of values.

First, we add all the numbers:

$$
2 + 3 + 5 + 7 + 6 + 8 + 4 + 3 = 38
$$

Then, we divide the total by the number of data points. Since there are $8$ values, the mean of the data set is

$$
\text{Mean} = \dfrac{38}{8} = 4.75
$$

## Finding the Mean of a Dataset (Word Problems)

**Example:** The data set below contains the length, in centimeters, of different rods:

$120,\: 124,\: 128,\: 132,\: 136,\: 140,\: 144,\: 148,\: 152,\: 156$

What is the mean length of these rods?

**Explanation**

The mean (or average) is calculated by dividing the sum of all the data values by the number of values.

First, we add all the values:

$$
120 + 124 + 128 + 132 + 136 + 140 + 144 + 148 + 152 + 156 = 1380
$$

Then, we divide the total by the number of data points. Since there are $10$ values, the mean of the data set is

$$
\text{Mean} = \dfrac{1380}{10} = 138
$$

Therefore, the mean length of the rods is $\bbox[4pt,border: 1px solid lightgray]{138}\,\textrm{cm}$.

## Finding the Mean of a Dataset of Large Numbers (Word Problems)

**Example:** The dataset below shows the file sizes, in megabytes (MB), of four different software packages:

$1\,580,\: 1\,620,\: 1\,600,\: 1\,610$

What is the mean file size?

**Explanation**

The mean (or average) is calculated by dividing the sum of all the data values by the number of values.

First, we add all the file sizes:

$$
1\,580 + 1\,620 + 1\,600 + 1\,610 = 6\,410
$$

Then, we divide this total by the number of values. Since there are $4$ values, the mean is

$$
\textrm{Mean} = \dfrac{6\,410}{4} = 1\,602.5
$$

Therefore, the mean file size is $1\,602.5\textrm{MB}$.
