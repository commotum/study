## Finding Means From Frequency Tables

**Example:** Each of the following frequency tables represents a data set. Which one has the greatest mean? Round to two decimal places where necessary.

**I.**

| Value | Frequency |
| --- | ---: |
| $2$ | $1$ |
| $5$ | $2$ |
| $8$ | $2$ |
| $11$ | $3$ |

**II.**

| Value | Frequency |
| --- | ---: |
| $2$ | $2$ |
| $5$ | $2$ |
| $8$ | $2$ |
| $11$ | $2$ |

**III.**

| Value | Frequency |
| --- | ---: |
| $2$ | $3$ |
| $5$ | $2$ |
| $8$ | $2$ |
| $11$ | $1$ |

**IV.**

| Value | Frequency |
| --- | ---: |
| $2$ | $2$ |
| $5$ | $3$ |
| $8$ | $2$ |
| $11$ | $1$ |

**Explanation**

The mean (or average) is calculated by dividing the sum of all the data values by the number of values.

We proceed to determine the mean of the data sets from each of the given frequency tables.

- For the table
ValueFrequency$2$$1$$5$$2$$8$$2$$11$$3$
the mean of the data set is
$mean|= (2(1) + 5(2) + 8(2) + 11(3))/(8); = \frac{61}{8}; \approx 7.63$.
- For the table
ValueFrequency$2$$2$$5$$2$$8$$2$$11$$2$
the mean of the data set is
$mean|= (2(2) + 5(2) + 8(2) + 11(2))/(8); = \frac{52}{8}; = 6.5$.
- For the table
ValueFrequency$2$$3$$5$$2$$8$$2$$11$$1$
the mean of the data set is
$mean|= (2(3) + 5(2) + 8(2) + 11(1))/(8); = \frac{43}{8}; \approx 5.38$.
- For the table
ValueFrequency$2$$2$$5$$3$$8$$2$$11$$1$
the mean of the data set is
$mean|= (2(2) + 5(3) + 8(2) + 11(1))/(8); = \frac{46}{8}; = 5.75$.
- For the table
ValueFrequency$2$$2$$5$$2$$8$$1$$11$$3$
the mean of the data set is
$mean|= (2(2) + 5(2) + 8(1) + 11(3))/(8); = \frac{55}{8}; \approx 6.88$.

Therefore, the frequency table whose data set has the greatest mean is as follows:

| Value | Frequency |
| --- | ---: |
| $2$ | $1$ |
| $5$ | $2$ |
| $8$ | $2$ |
| $11$ | $3$ |

## Finding Medians From Frequency Tables

**Example:** The table below shows the number of daily users for each of the $35$ different mobile apps reviewed in a tech report.

| Number of daily users | Number of apps |
| --- | ---: |
| $100$ to $199$ | $5$ |
| $200$ to $299$ | $4$ |
| $300$ to $399$ | $6$ |
| $400$ to $499$ | $5$ |
| $500$ to $599$ | $6$ |
| $600$ to $699$ | $5$ |
| $700$ to $799$ | $4$ |

Which of the following could be the median number of daily users per app?

1. $450$
2. $350$
3. $600$
4. $250$

**Explanation**

The median is the middle value of a data set when the values are arranged in order from smallest to greatest.

Since there are $35$ different apps included in the data set, and the numbers of daily users are listed in ascending order, it follows that the $18$th app in the list will represent the median number of users.

Now, let's find the cumulative frequencies to locate the $18$th app.

- The first $5$ apps have $100$ to $199$ users (apps $1-5$).
- The next $4$ apps have $200$ to $299$ users (apps $6-9$).
- The next $6$ apps have $300$ to $399$ users (apps $10-15$).
- The next $5$ apps have $400$ to $499$ users (apps $16-20$).
- The next $6$ apps have $500$ to $599$ users (apps $21-26$).
- The next $5$ apps have $600$ to $699$ users (apps $27-31$).
- The last $4$ apps have $700$ to $799$ users (apps $32-35$).

The $18$th app falls within the range of $400$ to $499$ users, because apps $16$ through $20$ are in this category.

Since the median falls within the $400$ to $499$ range, the median number of users could be any value within this range. Therefore, among the answer options given, $450$ could be the median number of daily users per app.

## Comparing the Mean and the Median Given a Frequency Table With Unknown Frequencies

**Example:** The frequency table above displays a set of data, where $z$ is a positive integer. By how much does the mean of the data set exceed the median?

| Value | Frequency |
| --- | ---: |
| $9$ | $z$ |
| $19$ | $3z$ |
| $29$ | $6z$ |
| $39$ | $3z$ |
| $49$ | $z$ |

**Explanation**

We observe that the set of data has a distribution symmetric around the central value of $29$. Indeed,

- $9$ and $49$ each have a frequency of $z$,
- $19$ and $39$ each have a frequency of $3z$, and
- $29$ has a frequency of $6z$.

In any symmetric distribution, the mean and median are equal. Consequently, the mean does not exceed the median.

Therefore, the correct answer is $0$.

## Ordering Measures of Center Given a Frequency Table

**Example:** The table above shows the monthly rental costs (in hundreds of dollars) for $20$ units in an apartment complex. Which of the following gives the correct order of the mean, median, and mode of the rent amounts?

| Rent | Frequency |
| --- | ---: |
| $7$ | $2$ |
| $8$ | $3$ |
| $9$ | $6$ |
| $10$ | $5$ |
| $11$ | $3$ |
| $15$ | $1$ |

1. $\text{mode} = \text{median} < \text{mean}$
2. $\text{median} < \text{mean}$
3. $\text{mean} < \text{median}$
4. $\text{median} = \text{mean} = \text{mode}$

**Explanation**

We proceed to calculate the mean, median, and mode separately.

- The mean (or average) is calculated by dividing the sum of all the data values by the number of values.Therefore, for our data set, the mean is
$mean|= (7(2) + 8(3) + 9(6) + 10(5) + 11(3) + 15(1))/(20); = \frac{14 + 24 + 54 + 50 + 33 + 15}{20}; = \frac{190}{20}; = 9.5$.
- The median is the middle value of a data set when the values are arranged in order from smallest to greatest.Since there are $20$ rent amounts ordered, the median is the average of the two middle values, the $10$th and $11$th, which for these data are both $9$. Then, the median is
$median|= \frac{9 + 9}{2}; = \frac{18}{2}; = 9$.
- The mode is the value that occurs most often in the data set.For the data shown, we have
$\textrm{mode} = 9$.

Therefore, the correct order is

$$
\text{mode} = \text{median} < \text{mean}
$$
