## Constructing a Frequency Table

**Example:** $6, \: 6, \: 6, \: 6, \: 7, \: 8, \: 8, \: 9, \: 9, \: 9$

Construct a frequency table to summarize the data above.

**Explanation**

To create a frequency table, we first count the number of times each value appears in the data set. This count is known as the frequency of a value.

- The frequency of $6$ is $4$ because the value $6$ appears $4$ times in the data set.
- The frequency of $7$ is $1$ because the value $7$ appears $1$ time in the data set.
- The frequency of $8$ is $2$ because the value $8$ appears $2$ times in the data set.
- The frequency of $9$ is $3$ because the value $9$ appears $3$ times in the data set.

Therefore, the frequency table is as follows:

| Number | Frequency |
| --- | ---: |
| $6$ | $4$ |
| $7$ | $1$ |
| $8$ | $2$ |
| $9$ | $3$ |

## Joint Frequency Tables

**Example:** A local survey polled $1,300$ voters about whether they support a new bond measure. The table below summarizes all $1,300$ responses.

|  | Under $40$ | $40$ and Over |
| --- | ---: | ---: |
| Support | $370$ | $380$ |
| Do Not Support | $$? | $300$ |

How many of the voters under $40$ surveyed responded that they do not support the bond measure?

**Explanation**

Let $x$ be the number of voters under $40$ who do not support the measure.
A total of $1,300$ voters were surveyed.

Furthermore, the total number of voters surveyed is the sum of the total number of voters under $40$ and the total number of voters $40$ and over.
So, we can set up the following equation, and solve for $x{:}$

$$
\begin{aligned}
370 + x + 380 + 300 &= 1, 300 \\
x + 1, 050 &= 1, 300 \\
x &= 1, 300 - 1, 050 \\
&= 250
\end{aligned}
$$

Therefore, the number of voters under $40$ who do not support the measure is $250$.

## Interpreting Values in a Frequency Table

**Example:** Based on the table above, how many more million users does Platform X have compared to Platform Z?

| Streaming platform | Average monthly users (millions) |
| --- | ---: |
| Platform X | $215$ |
| Platform Y | $160$ |
| Platform Z | $95$ |

**Explanation**

To determine how many more million users Platform X has than Platform Z, we subtract the number of users on Platform Z from the number on Platform X.

From the table, we can see that

- Platform X has $215$ million users, and
- Platform Z has $95$ million users.

Therefore, Platform X has

$$
215 - 95 = 120
$$

more million users than Platform Z.

## Determining Ranges From Frequency Tables

**Example:** A librarian recorded the number of books read by each student in a reading club. The results are shown in the table below.

| Student | Books read |
| --- | ---: |
| 1 | $5$ |
| 2 | $8$ |
| 3 | $6$ |
| 4 | $9$ |
| 5 | $4$ |
| 6 | $7$ |
| 7 | $10$ |

What is the range of the number of books read among the $7$ students?

**Explanation**

The range of a data set is the difference between the greatest and smallest values.

In this case, the greatest value is $10$ and the smallest value is $4$.

Therefore, the range of the number of books read is
$10 - 4 = 6$.

## Finding a Maximum or Minimum From a Frequency Table

**Example:** The table below summarizes the frequency of values in a data set.

| Value | Frequency |
| --- | ---: |
| $99$ | $3$ |
| $101$ | $2$ |
| $98$ | $4$ |
| $100$ | $1$ |
| $97$ | $1$ |

What is the minimum value of the data set?

**Explanation**

To find the minimum value of the data in the set, we must identify the smallest number in the "Value" column of the table.

The table shows that the unique values in the data set are $99, 101, 98, 100$, and $97$. Of these values, $97$ is the smallest value that appears at least once.

Therefore, the smallest data value that appears in the data set is ${97}$.
