## Introduction

In this topic, we will find lower and upper bounds for the mean, median, and range from frequency tables or histograms, and determine the largest or smallest possible differences between related statistics.

## Finding a Lower or Upper Bound for the Median

**Example:** The histogram above shows the number of values in a dataset that fall into each group. What is the smallest possible value of the median?

![](<../Source/4.3.6. Bounding Statistical Metrics/Images/f379d4abb3b379e2b2833d6977249ffd.png>)

**Explanation**

To estimate the median from a histogram, we first convert the histogram into a frequency table.

On a histogram with groups, the horizontal axis shows the value groups, and the vertical axis tells us how many values fall into each group.

In our case, we build the frequency table below and compute cumulative frequencies.

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $15-18$ | $7$ | $7$ |
| $18-21$ | $5$ | $12$ |
| $21-24$ | $3$ | $15$ |
| $24-27$ | $2$ | $17$ |
| $27-30$ | $2$ | $19$ |

Thus, the total number of values is

$$
7+5+3+2+2=19
$$

Since this is an odd number, the median is the value in position

$$
\dfrac{19+1}{2}=\dfrac{20}{2}=10
$$

Now we determine where the $10$th value falls. Looking at the cumulative frequency column in our table, we see the following:

- Up to the first row, the table covers $7$ positions in total.
- Up to the second row, the table covers $12$ positions in total.

Therefore, the $10$th value falls in the second interval, which is
$18 - 21$
as shown below.

| Value | Frequency | Cumulative Frequency |
| --- | ---: | ---: |
| $15-18$ | $7$ | $7$ |
| $18-21$ | $5$ | $12$ |
| $21-24$ | $3$ | $15$ |
| $24-27$ | $2$ | $17$ |
| $27-30$ | $2$ | $19$ |

Therefore, the smallest possible value of the median is $18$.

## Finding a Lower or Upper Bound for the Range

**Example:** The histogram above shows the number of values in a dataset that fall into each group. What is the smallest possible value of the range?

![](<../Source/4.3.6. Bounding Statistical Metrics/Images/d96230322bf2927cdde0dc227a07a8d8.png>)

**Explanation**

To calculate the smallest possible range, we take the smallest possible maximum value and subtract the largest possible minimum value.

Let's start by turning our histogram into a frequency table.

| Value | Frequency |
| --- | ---: |
| $30-\bbox[3pt, gainsboro]{35}$ | $6$ |
| $36-37$ | $8$ |
| $38-40$ | $10$ |
| $41-43$ | $7$ |
| $\bbox[3pt, gainsboro]{44}-51$ | $4$ |

Looking at the table,

- the smallest possible maximum value is $44$, and
- the largest possible minimum value is $35$.

Therefore, the smallest possible range is

$$
44 - 35 = 9
$$

## Finding a Lower or Upper Bound for the Mean

**Example:** The frequency table above shows the number of values in a dataset that fall into each group. Rounded to one decimal place, what is the largest possible value of the mean?

| Value $(x)$ | Frequency $(f)$ |
| --- | ---: |
| $22-25$ | $4$ |
| $25-28$ | $7$ |
| $28-31$ | $2$ |
| $31-34$ | $5$ |
| $34-37$ | $3$ |

**Explanation**

To estimate the mean from grouped data, we first use the frequency table.

Since we wish to find the *largest possible value* of the mean, we record $x_{\textrm{max}}$, the largest possible value of $x$ for each group.

Then, we calculate $f\cdot x_{\textrm{max}}$ for each row.

| Value $(x)$ | Frequency $(f)$ | $x_{\textrm{max}}$ | $f\cdot x_{\textrm{max}}$ |
| --- | ---: | ---: | ---: |
| $22-25$ | $4$ | $25$ | $4\cdot 25 = 100$ |
| $25-28$ | $7$ | $28$ | $7\cdot 28 = 196$ |
| $28-31$ | $2$ | $31$ | $2\cdot 31 = 62$ |
| $31-34$ | $5$ | $34$ | $5\cdot 34 = 170$ |
| $34-37$ | $3$ | $37$ | $3\cdot 37 = 111$ |

Therefore, the largest possible value of the mean is

$$
\begin{aligned}
largest possible mean &= \frac{100 + 196 + 62 + 170 + 111}{4 + 7 + 2 + 5 + 3} \\
&= \frac{639}{21} \\
&\approx 30.4
\end{aligned}
$$

rounded to one decimal place.

## Finding the Largest or Smallest Possible Difference Between Two Statistics

**Example:** The histograms above show the distribution of two datasets. Rounded to one decimal place, what is the **smallest possible difference** between the **mean** of dataset $B$ and the **median** of dataset $A$?

![](<../Source/4.3.6. Bounding Statistical Metrics/Images/4dcaecbde9af9a5158303caaf6eb90fb.png>)

**Explanation**

To find the *smallest possible difference* between the mean of $B$ and the median of $A$, we must find the difference between

- the *smallest* possible mean of dataset $B$, and
- the *largest* possible median of dataset $A$.

The difference we wish to find can be written as follows:

$$
\min\left(\textrm{mean}(B)\right) - \max\left(\textrm{median}(A)\right)
$$

Let's compute each of these values in turn.

- First, we find the smallest possible mean of dataset $B$. We start by writing down our dataset as a frequency table. Since we wish to find the *smallest possible value* of the mean, we record $x_{\textrm{min}}$, the *smallest* possible value of $x$ for each group. Then, we calculate $f \cdot x_{\textrm{min}}$ for each row.The results are shown below.Value $(x)$Frequency $(f)$$x_{\textrm{min}}$$f \cdot x_{\textrm{min}}$$55-57$$4$$55$$4\cdot 55 = 220$$57-59$$6$$57$$6\cdot 57 = 342$$59-61$$10$$59$$10\cdot 59= 590$$61-63$$7$$61$$7\cdot 61 = 427$$63-65$$3$$63$$3\cdot 63 = 189$Therefore, the smallest possible value of the mean is
$min(mean(B))|= \frac{220 + 342 + 590 + 427 + 189}{4 + 6 + 10 + 7 + 3}; = \frac{1768}{30}; \approx 58.933$
rounded to three decimal places.
- Next, we compute the largest possible median of $A{:}$Since the histogram for dataset $A$ is symmetric, the median must lie in the group $24-26$. Therefore, the smallest possible value of the median is
$\max\left(\textrm{median}(A)\right) = 26$.

Finally, we conclude that the smallest possible difference between the mean of $B$ and the median of $A$ is

$$
\begin{aligned}
min(mean(B)) - max(median(A)) &= 58.933 - 26.0 \\
&\approx 32.9
\end{aligned}
$$

rounded to one decimal place.
