## Introduction

A typical question that often crops up on the SAT math section involves understanding how modifying data affects statistical measures.

In this topic, we will practice determining how adding, subtracting, or adjusting values changes statistics such as the mean, median, range, and standard deviation.

## Determining the Effects of Data Change Given a Dot Plot

**Example:** The dot plot above shows the $19$ values in the data set $C$. Data set $D$ is formed by subtracting $12$ to every value in data set $C$. Write the statement that compares the medians and the ranges of data sets $C$ and $D$.

![](<../Source/4.4.5. Comparing Statistical Effects of Data Change/Images/a0826a1cb53df8a509c56fa74667c708.png>)

**Explanation**

Let's compare the medians and ranges of data sets $C$ and $D{:}$

- Medians:There are $19$ values, so the median of $C$ is the $10$th value when ordered. Counting frequencies across $9,10,11,12,13$ gives cumulative counts $3,7,12,16,19$, so the $10$th value lies at
$\text{Median}(C)=11$.After subtracting $12$ from each value in data set $C$, the median of $D$ will still be the $10$th value, but shifted down by $12{:}$
$\text{Median}(D)=11-12=-1$.Thus, the median of data set $D$ is smaller than the median of data set $C$.
- Ranges: The range of data set $C{:}$
$\text{Range}(C)=\max(C)-\min(C)=13-9=4$.After subtracting $12$ from each value in data set $C$, the range of data set $D{:}$
$Range(D)|= (max(C) - 12) - (min(C) - 12); = max(C) - 12 - min(C) + 12; = max(C) - min(C); = Range(C)$.Thus, the ranges are equal.

Therefore, the correct statement is “The median of data set $D$ is smaller than the median of data set $C$, and the range of data set $D$ is equal to the range of data set $C$.”

## Determining Which Statistics Are Unaffected by a Data Transformation

**Example:** A dataset of $19$ different grocery basket totals (in dollars) has a mean of $\[math]50$ and a median of $\[/math]50$. A new dataset is created by multiplying each total by $2$. Which of the following measures has the same value in both the original and new datasets?

1. Mean
2. Median
3. Range
4. Standard deviation

**Explanation**

When every data value is multiplied by a constant, each statistic responds as follows:

- For $19$ *different* values, there is exactly one middle value (the $10$th value) of $50$. Multiplying every value by $2$ will also scale the middle value by $2$. So, the median changes.
- The mean depends on every value, so multiplying every value by the same constant scales the mean by the same factor.If we denote the $19$ different totals by $t_1, t_2, \ldots, t_{19}$ and multiply each by $2$, then the new mean is:
$\frac{2t_{1} + 2t_{2} + ⋯ + 2t_{19}}{19}|= (2 \cdot (t_{1} + t_{2} + ⋯ + t_{19}))/(19); = 2 \cdot 50; = 100$
So, the mean also changes.
- The range depends only on the difference between the largest and the smallest values. Multiplying both by the same positive constant multiplies that difference by the same constant. Thus, the range is scaled by $2$, so it changes.
- The standard deviation measures the spread about the mean. Since every value (and thus the mean) is multiplied by $2$, each deviation from the mean is also multiplied by $2$; hence the variance scales by $4$ and the standard deviation by $2$.

Therefore, the correct answer is "None".

## Determining Which Statistics Are Affected by a Data Transformation

**Example:** The delivery times (in minutes) for $22$ parcels were recorded, and the mean, median, range, and standard deviation were calculated. Later, it was discovered that the shortest delivery time had been reported as $9$ minutes too high.
Which of the following measures does **NOT** have the same value in both the original and new datasets?

1. Mean
2. Median
3. Range
4. Standard deviation

**Explanation**

When a single data value is corrected, each of the four statistics may respond differently:

- The mean depends on every value, so changing one value will change the mean.
- The median depends only on the middle value(s). In this case, adjusting the shortest time to be smaller than it originally was does not affect the order of the middle values, so the median remains unchanged.
- The range depends only on the largest minus the smallest. Here, since the smallest value decreases, the range becomes larger.
- The standard deviation measures the spread from the mean, and changing one value changes both the mean and the spread.

Therefore, the correct answer is "I, III and IV only".
