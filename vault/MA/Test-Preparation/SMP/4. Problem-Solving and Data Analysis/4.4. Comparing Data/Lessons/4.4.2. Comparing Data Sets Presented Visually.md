## Comparing Standard Deviations of Dot Plots Over Different Ranges

**Example:** The dot plots above show the times (in minutes) it took students to complete a mile run in two different PE classes, Group $P$ and Group $Q$. Which statement best compares the standard deviations of the two groups?

![](<../Source/4.4.2. Comparing Data Sets Presented Visually/Images/39e10fedf5f05b97eb77ee97130d3746.png>)

1. The standard deviation for Group $P$ is equal to the standard deviation for Group $Q$.
2. The standard deviation for Group $P$ is less than the standard deviation for Group $Q$.
3. The standard deviation for Group $P$ is greater than the standard deviation for Group $Q$.
4. There is not enough information to compare these standard deviations.

**Explanation**

Standard deviation is a measure of the spread of a data set from its mean.

The two dot plots have identical shapes and frequencies. Group $Q$ is obtained by adding the constant $5$ to every value in Group $P$, which produces a horizontal shift to the right.

Adding $5$ to all data values increases the mean by $5$ but does not affect deviations from the mean, so the standard deviation remains unchanged.

Therefore, the correct statement is that “The standard deviation for Group $P$ is equal to the standard deviation for Group $Q$.”

## Comparing Standard Deviations of Visual Data Over Identical Ranges

**Example:** A server engineer recorded the response payload sizes, in kilobytes (KB), for two APIs. This information is displayed using the dot plots shown above. Select the correct options in the reasoning below.

![](<../Source/4.4.2. Comparing Data Sets Presented Visually/Images/3846c675863aa1052cbfb76031eb857c.png>)

1. The standard deviation of API $\text{A}$ is greater than the standard deviation of API $\text{B}$.
2. The standard deviation of API $\text{A}$ is smaller than the standard deviation of API $\text{B}$.
3. The standard deviation of API $\text{A}$ is equal to the standard deviation of API $\text{B}$.
4. The mean of API $\text{A}$ is smaller than the mean of API $\text{B}$.

**Explanation**

Standard deviation is a statistical measure that indicates how much the values in a dataset deviate from the mean.

A larger standard deviation means the data points are more spread out, while a smaller standard deviation indicates that the data points are clustered more closely around the mean.

![](<../Source/4.4.2. Comparing Data Sets Presented Visually/Images/902679ca85d993655e546179d47cc8fe.png>)

In our case, the ranges of the datasets are the same, but the dot plots have different shapes.

Notice that the data points corresponding to API $\text{A}$ are concentrated further from the mean than the data points of API $\text{B}$.

Therefore, the correct answer is:

> The standard deviation of API $\text{A}$ is greater than the standard deviation of API $\text{B}$.

Note: The data sets have equal means since they're both symmetric and defined over the same range.

## Comparing Statistics Given Two Dot Plots

**Example:** Which of the following statements must be true?

![](<../Source/4.4.2. Comparing Data Sets Presented Visually/Images/6ebe5c09bd947d1f9963cc608c32bf1a.png>)

1. The median of data set $A$ is equal to the median of data set $B$.
2. The standard deviation of data set $A$ is equal to the standard deviation of data set $B$.

**Explanation**

In a dot plot, the median is the middle value when the data are ordered.

Let's check each statement:

- Statement I:Each data set has $6$ values, an even number, so the median is the average of the $3$rd and $4$th values. For data set $A$: the values in order are $91,91,92,94,95,95$ so the $3$rd and $4$th values are $92$ and $94$, making the median $93$.For data set $B$: identical to data set $A$, so the median is also $93$. Thus, the medians are equal, and statement I is true.
- Statement II:Since the plots are identical, both the means and the spreads are the same. Thus, their standard deviations are equal, and statement II is true.

Therefore, the correct answer is “I and II.”

## Ordering Data Sets According to Standard Deviation

**Example:** Three classrooms recorded how many pages each student read during a $1$-hour sprint. The information is summarized on the dot plots above. Put the corresponding standard deviations in order from the smallest to the largest.

![](<../Source/4.4.2. Comparing Data Sets Presented Visually/Images/af2b953f8ff7a423f287f52d13183016.png>)

**Explanation**

Standard deviation is a statistical measure that indicates how much the values in a dataset deviate from the mean.

A larger standard deviation means the data points are more spread out, while a smaller standard deviation indicates that the data points are clustered more closely around the mean.

In our case:

- The most spread-out dataset corresponds to Classroom B (notice the heavier counts toward the ends).
- A slightly less spread-out dataset corresponds to Classroom C (more mass near the center, but still some spread).
- Finally, the data corresponding to Classroom A is mostly concentrated near the mean.

Therefore, we can put the standard deviations in order from the smallest to the largest, as follows:

$$
{\text{Classroom A}} < {\text{Classroom C}} < {\text{Classroom B}}
$$
