## Finding a Missing Value in a Dataset

**Example:** The data set $G$ is given by
$52, \: 55, \: 58, \: 61, \: 64$,
and the data set $H$ is given by
$40, \: 57, \: 60, \: 63, \: y$,
contain $5$ values each. If the mean of data set $G$ is the same as the mean of data set $H$, what is the value of $y$?

**Explanation**

Symmetric data is characterized by values that occur with regular frequencies, forming a balanced, mirror-image shape around a central point.

In a symmetric distribution, the mean is equal to the center of the data set. Otherwise, the mean is found by dividing the sum of all data values by the number of values.

With this in mind, we proceed to calculate the mean for each data set.

- Data set $G$ is symmetric with $5$ values (an odd number), so its mean is the $3$rd data value in the list:
$\textrm{Mean}(G) = 58$
- Data set $H$ is not symmetric, so its mean is
$Mean(H)|= \frac{40 + 57 + 60 + 63 + y}{5}; = \frac{220 + y}{5}$.

Since the mean of the data set $G$ is the same as the mean of the data set $H$, we equate them and solve for $y{:}$

$$
\begin{aligned}
Mean(H) &= Mean(G) \\
\frac{220 + y}{5} &= 58 \\
220 + y &= 58 \cdot 5 \\
220 + y &= 290 \\
y &= 70
\end{aligned}
$$

Therefore, the value of $y$ is $70$.

## Comparing the Means of Two Datasets

**Example:** The data $P$ is given by
$8, \: 12, \: 12, \: 16$,
and the data set $Q$ is given by
$8, \: 12, \: 12, \: 16, \: 32$.
Write the statement that compares the means of data set $P$ and data set $Q$?

1. The mean of the data set $P$ is less than the mean of the data set $Q$.
2. The mean of the data set $P$ is greater than the mean of the data set $Q$.
3. The means of the data set $P$ and data set $Q$ are equal.
4. The mean of each data set is $15$.

**Explanation**

Symmetric data is characterized by values that occur with regular frequencies, forming a balanced, mirror-image shape around a central point.

In a symmetric distribution, the mean is equal to the center of the data set. Otherwise, the mean is found by dividing the sum of all data values by the number of values.

With this in mind, we proceed to calculate the mean for each data set.

- Data set $P$ is symmetric with $4$ data values in ascending order; it follows that the mean is between the second and third data values, that is, its mean is $12$.
- Data set $Q$ is not symmetric, so its mean is
$Mean(Q)|= \frac{8 + 12 + 12 + 16 + 32}{5}; = \frac{80}{5}; = 16$.

Therefore, since $\textrm{Mean}(P) < \textrm{Mean}(Q)$, the correct answer is "I only".

## Comparing a Dataset's Mean and Median

**Example:** For which of the following data sets is the mean greater than the median?

1. $12,\: 12,\: 12,\: 12,\: 12,\: 12,\: 12$
2. $3,\: 6,\: 12,\: 24,\: 48,\: 96,\: 192$
3. $15,\: 25,\: 35,\: 45,\: 55,\: 65,\: 75$
4. $7,\: 17,\: 27,\: 37,\: 47,\: 57,\: 67$

**Explanation**

Symmetric data is characterized by values that occur with regular frequencies, forming a balanced, mirror-image shape around a central point.

In a symmetric distribution, the mean and median are equal to the center of the data set. Otherwise, the mean is found by dividing the sum of all data values by the number of values, while the median is the middle value of the data set when the values are arranged in order from smallest to greatest.

With this in mind, we proceed to calculate the mean and median for each data set.

- Data set I is symmetric with $7$ values (an odd number). Thus, the mean and median of this data set are the $4$th element, which is equal to $12$.
- Data set II is not symmetric, so its mean is
$Mean|= \frac{3 + 6 + 12 + 24 + 48 + 96 + 192}{7}; \approx 54.4$.
On the other hand, since it contains $7$ ordered from smallest to greatest elements, its median is
$\textrm{Median} = 24$.
So, $\text{Mean}>\text{Median}$.
- Data set III is symmetric with $7$ values (an odd number). Thus, the mean and median of this data set are the $4$th element, which is equal to $45$.
- Data set IV is symmetric with $7$ values (an odd number). Thus, the mean and median of this data set are the $4$th element, which is equal to $37$.

Therefore, the correct answer is "II only."

## Comparing a Dataset's Mean and Median From Tabular Data

**Example:** The table above shows the number of visitors at two museums in each of the five years. No visitor was counted at both museums.

| Museum | $2012$ | $2013$ | $2014$ | $2015$ | $2016$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| North Museum | $540$ | $460$ | $520$ | $500$ | $480$ |
| South Museum | $300$ | $480$ | $500$ | $510$ | $520$ |

Which of the following statements are true about the number of visitors over the $5$ years shown?

1. The mean number from North Museum is greater than the mean number from South Museum.
2. The median number from North Museum is greater than the median number from South Museum.

**Explanation**

Symmetric data is characterized by values that occur with regular frequencies, forming a balanced, mirror-image shape around a central point.

In a symmetric distribution, the mean and median are equal to the center of the data set. Otherwise, the mean is found by dividing the sum of all data values by the number of values, while the median is the middle value of the data set when the values are arranged in order from smallest to greatest.

With this in mind, we proceed to calculate the mean and median for each data set associated with each museum.

- North Museum data points are not ordered, so we order them first from smallest to largest:
$480,\: 500,\: 520, \: 540, \: 560$
This data set is symmetric and contains $5$ elements, which is an odd number, so the mean and median are both equal to the $3$rd element:
$\textrm{Mean}(N) = \textrm{Median}(N) = 520$
- South Museum data points are already ordered from smallest to largest:
$300, \: 480, \: 500, \: 510, \: 520$
This data set is not symmetric, so its mean is
$Mean(S)|= \frac{300 + 480 + 500 + 510 + 520}{5}; = \frac{2310}{5}; = 462$.
Since it contains $5$ elements, its median is the $3$rd element:
$\textrm{Median}(S) = 500$

Since North Museum has a higher mean and median than South Museum, both statements are true.

Therefore, the correct answer is "I and II".
