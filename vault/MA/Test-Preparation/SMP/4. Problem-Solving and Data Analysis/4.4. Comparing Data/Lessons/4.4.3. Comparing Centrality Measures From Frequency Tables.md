## Comparing Means From Frequency Tables

**Example:** Data set $A$ and data set $B$ each contain $27$ values. The table shows the frequencies of the values for each data set. Which of the following statements best compares the means of the two data sets? Round to two decimal places where necessary.

| Value | Data set A frequency | Data set B frequency |
| --- | ---: | ---: |
| $12$ | $5$ | $3$ |
| $16$ | $6$ | $5$ |
| $20$ | $7$ | $6$ |
| $24$ | $5$ | $7$ |
| $28$ | $4$ | $6$ |

1. The mean of the data set $A$ is less than the mean of the data set $B$.
2. The mean of the data set $A$ is equal to the mean of the data set $B$.
3. The mean of the data set $A$ is greater than the mean of the data set $B$.
4. There is not enough information to compare the means of the two datasets.

**Explanation**

The mean (or average) in a data set is calculated by dividing the sum of all the data values by the number of values.

Since the table shows the frequencies of the values for each data set, we find the total sum by multiplying each data value by its frequency and then adding all these products together.

With this in mind, we proceed to calculate the mean of each data set:

- The mean of the data set $A$ is
$Mean(A)|= (12(5) + 16(6) + 20(7) + 24(5) + 28(4))/(27); = \frac{528}{27}; \approx 19.56$,
rounded to two decimal places.
- The mean of the data set $B$ is
$Mean(B)|= (12(3) + 16(5) + 20(6) + 24(7) + 28(6))/(27); = \frac{572}{27}; \approx 21.19$,
rounded to two decimal places.

Therefore, since $\textrm{Mean}(A) < \textrm{Mean}(B)$, the correct answer is "I only".

## Comparing Medians From Frequency Tables

**Example:** In a midterm exam, each student receives a score between $50$ and $100$. The table below shows the score distribution for the $13$ students in Class $M$ and the $11$ students in Class $N$.

| Score | Class $M$ | Class $N$ |
| --- | ---: | ---: |
| $50$ | $1$ | $0$ |
| $55$ | $1$ | $1$ |
| $60$ | $2$ | $1$ |
| $65$ | $2$ | $1$ |
| $70$ | $3$ | $2$ |
| $75$ | $2$ | $3$ |
| $80$ | $1$ | $1$ |
| $90$ | $1$ | $1$ |
| $100$ | $0$ | $1$ |
| Total | $13$ | $11$ |

The median score for Class $N$ is how many points greater than the median score for Class $M$?

**Explanation**

The median of a data set is the middle value, meaning half of the data points lie above it and half lie below it, when the values are arranged from smallest to largest.

Since the table shows the frequencies of the scores for each class, to list the data set we write each score from the table, repeating it as many times as its frequency indicates.

With this in mind, we proceed to find the median for each data:

- Class $M$ has $13$ students, which can be listed from lowest to highest as:
$50,\: 55,\: 60,\: 60,\: 65,\: 65,\: 70,\: 70,\: 70,\: 75,\: 75,\: 80,\: 90$
Since there are $13$ scores (an odd number), the median is the $7$th element:
$\textrm{Median}(M) = 70$
- Class $N$ has $11$ students, which can be listed from lowest to highest as:
$55,\: 60,\: 65,\: 70,\: 70,\: 75,\: 75,\: 75,\: 80,\: 90,\: 100$
Since there are $11$ scores (an odd number), the median is the $6$th element:
$\textrm{Median}(N) = 75$

So, the difference between the medians is

$$
\begin{aligned}
Median(N) - Median(M) &= 75 - 70 \\
&= 5
\end{aligned}
$$

Therefore, the median score for Class $N$ is $\bbox[4pt,border: 1px solid lightgray]{5}$ points greater than the median score for Class $M$.
