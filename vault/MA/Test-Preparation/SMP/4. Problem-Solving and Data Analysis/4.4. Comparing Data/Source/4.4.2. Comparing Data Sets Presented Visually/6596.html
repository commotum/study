Example: Comparing Standard Deviations of Dot Plots Over Different Ranges
?

The dot plots above show the times (in minutes) it took students to complete a mile run in two different PE classes, Group and Group Which statement best compares the standard deviations of the two groups?

  1. The standard deviation for Group is equal to the standard deviation for Group
  2. The standard deviation for Group is less than the standard deviation for Group
  3. The standard deviation for Group is greater than the standard deviation for Group
  4. There is not enough information to compare these standard deviations.
EXPLANATION

Standard deviation is a measure of the spread of a data set from its mean.

The two dot plots have identical shapes and frequencies. Group is obtained by adding the constant to every value in Group which produces a horizontal shift to the right.

Adding to all data values increases the mean by but does not affect deviations from the mean, so the standard deviation remains unchanged.

Therefore, the correct statement is that “The standard deviation for Group is equal to the standard deviation for Group ”

Example: Comparing Standard Deviations of Visual Data Over Identical Ranges
?

A server engineer recorded the response payload sizes, in kilobytes (KB), for two APIs. This information is displayed using the dot plots shown above. Select the correct options in the reasoning below.

  1. The standard deviation of API is greater than the standard deviation of API
  2. The standard deviation of API is smaller than the standard deviation of API
  3. The standard deviation of API is equal to the standard deviation of API
  4. The mean of API is smaller than the mean of API
EXPLANATION

Standard deviation is a statistical measure that indicates how much the values in a dataset deviate from the mean.

A larger standard deviation means the data points are more spread out, while a smaller standard deviation indicates that the data points are clustered more closely around the mean.

In our case, the ranges of the datasets are the same, but the dot plots have different shapes.

Notice that the data points corresponding to API are concentrated further from the mean than the data points of API

Therefore, the correct answer is:

The standard deviation of API is greater than the standard deviation of API

Note: The data sets have equal means since they're both symmetric and defined over the same range.

?

Which of the following statements must be true?

  1. The median of data set is equal to the median of data set
  2. The standard deviation of data set is equal to the standard deviation of data set
EXPLANATION

In a dot plot, the median is the middle value when the data are ordered.

Let's check each statement:

  • Statement I:

    Each data set has values, an even number, so the median is the average of the rd and th values.

    • For data set : the values in order are so the rd and th values are and making the median

    • For data set : identical to data set so the median is also

    Thus, the medians are equal, and statement I is true.

  • Statement II:

    Since the plots are identical, both the means and the spreads are the same. Thus, their standard deviations are equal, and statement II is true.

Therefore, the correct answer is “I and II.”
