## Introduction

The domain of a vector-valued function $\mathbf f(t)$ is the set of values of $t$ for which the function is well-defined.

A function is well-defined at some value $t = t_0$ if all its component functions are defined at $t_0$. Thus, the domain of $\mathbf f$ is the *intersection* of the domains of its component functions.

Let's find the domain of the following function:

$$
\mathbf{f}(t) = \dfrac{1}{3+t} \: \mathbf i + t^2 \: \mathbf j + \sqrt{-t} \: \mathbf k
$$

First, we find the domains of the component functions:

- The domain of $\dfrac{1}{3+t}$ is $t \in (-\infty,-3) \cup (-3,\infty)$.
- The domain of $t^2$ is $t \in (-\infty,\infty)$.
- The domain of $\sqrt{-t}$ is $[MATH: t \in (-\infty, 0].]$

To find the domain of $\mathbf{f}$, we need the intersection of the component functions' domains. This intersection is illustrated in the diagram below.

![](<MA/Mathematical-Methods-for-the-Physical-Sciences/PS1/7. Vector Functions and Vector Fields/7.1. Vector-Valued Functions/Source/7.1.1. The Domain of a Vector-Valued Function/Images/5604d3cced6c1a7e7186e8909842370a.png>)

Therefore, the domain of the function $\mathbf{f}(t)$ is $[MATH: t \in (-\infty,-3) \cup (-3,0].]$

## Domains of Functions With Reciprocal and Radical Components

**Example:** Find the domain of the vector-valued function $\mathbf f(t) = \left\langle \sqrt{t+3}, \: t^3-t^2, \: \dfrac{1}{t+1}\right\rangle$.

**Explanation**

To find the domain of $\mathbf{f}$, we need the intersection of the domains of the individual components.

- The domain of the 1st component $\sqrt{t+3}$ is $[MATH: t \in [-3,\infty).]$
- The domain of the 2nd component $t^3-t^2$ is $t \in (-\infty,\infty)$.
- The domain of the 3rd component $\dfrac{1}{t+1}$ is $t \in (-\infty,-1)\cup(-1,\infty)$.

The intersection is illustrated in the diagram below.

![](<MA/Mathematical-Methods-for-the-Physical-Sciences/PS1/7. Vector Functions and Vector Fields/7.1. Vector-Valued Functions/Source/7.1.1. The Domain of a Vector-Valued Function/Images/5af0a18236943f5ed868820bafbe061b.png>)

Therefore, the domain of the vector-valued function $\mathbf{f}(t)$ is $[MATH: t \in [-3,-1)\cup(-1,\infty).]$

## Domains of Functions With Exponential and Logarithmic Components

**Example:** Find the domain of the vector-valued function $\mathbf f(t)$, given by
$\mathbf{f} (t) = \ln{t} \, \mathbf{i} + \frac{1}{t-2} \, \mathbf{j} + e^{2t} \, \mathbf{k}$.

**Explanation**

To find the domain of $\mathbf{f}$, we need the intersection of the domains of the individual components.

- The domain of the 1st component $\ln{t}$ is $t \in (0, \infty)$.
- The domain of the 2nd component $\dfrac{1}{t-2}$ is $t \in (-\infty,2)\cup(2,\infty)$.
- The domain of the 3rd component $e^{2t}$ is $t \in (-\infty,\infty)$.

The intersection is illustrated in the diagram below.

![](<MA/Mathematical-Methods-for-the-Physical-Sciences/PS1/7. Vector Functions and Vector Fields/7.1. Vector-Valued Functions/Source/7.1.1. The Domain of a Vector-Valued Function/Images/40ca4990aa765c6a975686a987f4f47c.png>)

Therefore, the domain of the vector-valued function $\mathbf{f}(t)$ is $t \in (0,2)\cup (2,\infty)$.

## Domains of Functions With Trigonometric Components

**Example:** The domain of the vector-valued function $\mathbf f (t) = \tan\left(t+\dfrac{\pi}{6} \right) \, \mathbf i + t^3 \,\mathbf j + e^t \,\mathbf k$ is
$t\in (-\infty,\infty), \quad t \neq \bbox[5pt, border:1pt solid black]{\phantom{AAAAA}}$.
What is the missing expression?

**Explanation**

To find the domain of $\mathbf{f}$, we need the intersection of the domains of the individual components.

- The domain of the 1st component $\tan\left(t+\dfrac{\pi}{6} \right)$ is $t \in (-\infty,\infty)$, except for the values of $t$ for which
$t+\dfrac{\pi}{6} = \dfrac{\pi}{2} + n\pi \qquad\Longrightarrow\qquad t = \dfrac{\pi}{3} + n\pi$,
where $n$ is an integer.
- The domain of the 2nd component $t^3$ is $t \in (-\infty,\infty)$.
- The domain of the 3rd component $e^{t}$ is $t \in (-\infty,\infty)$.

Therefore, the domain of the vector-valued function $\mathbf{f}(t)$ is

$$
t\in (-\infty,\infty), \quad t \neq \bbox[2pt,Gainsboro]{\color{blue}\dfrac{\pi}{3} + n\pi}
$$

where $n$ is an integer.
