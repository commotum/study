## Introduction

The structure $\mathbb{R}^n$ is called a **vector space**. However, many other structures possess properties similar to $\mathbb{R}^n$. These other structures can be called vector spaces too.

In this lesson, we'll learn about some important properties used to construct vector spaces. We begin by discussing what it means for a set to be **closed** under addition and scalar multiplication.

As an example, consider the set $\mathrm{M}_2(\mathbb{R})$ of all $2 \times 2$ matrices with real entries:

$$
\begin{bmatrix}a & b \\ c & d\end{bmatrix}
$$

For this set of matrices, we can define two operations:

- the addition of two matrices, and
- the multiplication of a matrix by a real number (called a scalar).

Now, notice the following:

- $\mathrm{M}_2(\mathbb{R})$ is **closed under addition**. This means that the sum of *any* two matrices from $\mathrm{M}_2(\mathbb{R})$ is also a matrix in $\mathrm{M}_2(\mathbb{R})$.
- $\mathrm{M}_2(\mathbb{R})$ is **closed under scalar multiplication**. This means that the product of *any* scalar and *any* matrix from $\mathrm{M}_2(\mathbb{R})$ is also a matrix in $\mathrm{M}_2(\mathbb{R})$.

Identifying that a set is closed under addition and scalar multiplication is an essential first step in determining whether a set can form a vector space.

---

<a id="sets-that-are-not-closed"></a>
## Sets That Are Not Closed

It's important to realize that not all sets are closed under addition and scalar multiplication. Sets not closed under addition and scalar multiplication *cannot* be vector spaces.

For instance, let $S$ be the set of all polynomials with real coefficients whose degree is greater than or equal to $5$.

We note that $S$ is not closed under addition. To see why this is the case, let's define the polynomials $p(x),q(x)\in S$ as

$$
p(x) = x^5, \qquad q(x) = 1-x^5
$$

Adding the two polynomials using regular polynomial addition, we get

$$
p(x) + q(x) = x^5 + (1-x^5) = 1\notin S
$$

The sum $p(x) + q(x)$ is not in $S$ because it is a polynomial of degree zero, which is less than $5$.

Therefore, we conclude that our set $S$ is *not* closed under addition.

<a id="identifying-sets-closed-under-addition-and-scalar-multiplication"></a>
## Identifying Sets Closed Under Addition and Scalar Multiplication

**Example:** Let $M$ be the set of all $2\times2$ real matrices whose entries are non-negative. Then, which of the following statements are true?

1. $I_2 \in M$
2. For any $A \in M$ and $\alpha \in \mathbb{R}$, we have $\alpha \cdot A \in M$.
3. The set is closed under scalar multiplication.

**Explanation**

Let's verify the statements one by one.

- Statement I is true. Indeed, $\begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}$ because all its entries are non-negative.
- Statement II is false. There exists a $2\times2$ real matrix in $M$ that has a scalar multiple not in $M$. For example, let $\begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}$ and $\alpha=-1\in\mathbb{R}$. Notice that $A$ belongs to $M$ since statement I is true. However,
$\begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}$
Since the entries on the main diagonal are negative, we conclude that $-1 \cdot A \notin M$.
- Statement III is false. Since statement II is false, the set is *not* closed under scalar multiplication.

Therefore, the correct answer is "I only."

<a id="addition-of-vectors"></a>
## Addition of Vectors

Let's now compare some properties of addition in $\mathbb{R}^2$ and $\text{M}_2(\mathbb{R})$.
It turns out that the addition of two matrices in $\mathrm{M}_2(\mathbb{R})$ is *very* similar to the addition of two vectors in $\mathbb{R}^n$. See the table below.

|  | **$\mathbb{R}^2$** | **$\text{M}_2(\mathbb{R})$** |
| --- | ---: | ---: |
| **Addition is Commutative:** |  |  |
| A1 | For any vectors $\mathbf{u}, \mathbf{v} \in \mathbb{R}^2$, we have $\color{blue}\mathbf{u}+\mathbf{v} = \mathbf{v}+\mathbf{u}$ | For any matrices $A, B \in \text{M}_2(\mathbb{R})$, we have $\color{blue}A+B = B+A$ |
| **Addition is Associative:** |  |  |
| A2 | For any vectors $\mathbf{u}, \mathbf{v}, \mathbf{w} \in \mathbb{R}^2$, we have $\color{blue}(\mathbf{u}+\mathbf{v})+\mathbf{w} = \mathbf{u}+(\mathbf{v}+\mathbf{w})$ | For any matrices $A, B, C \in \text{M}_2(\mathbb{R})$, we have $\color{blue}(A+B) + C = A + (B+C)$ |
| **Existence of a Unique Zero Element:** |  |  |
| A3 | For the zero-vector $\mathbf{0}$ and any $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} \mathbf{u} + \mathbf{0} = \mathbf{u}$ | For the zero-matrix $O$ and any $A \in \text{M}_2(\mathbb{R})$, we have $\color{blue} A + O = A$ |
| **Existence of a Unique Opposite Element:** |  |  |
| A4 | For any vector $\mathbf{u} \in \mathbb{R}^2$ we can find the corresponding negative vector $-\mathbf{u} \in \mathbb{R}$ such that $\color{blue} \mathbf{u} + (-\mathbf{u}) = \mathbf{0}$ | For any matrix $A \in \text{M}_2(\mathbb{R})$ we can find the corresponding negative matrix $-A \in \text{M}_2(\mathbb{R})$ such that $\color{blue} A + (-A) = O$ |

And it's not just matrices that have additive properties similar to those of $\mathbb R^n$. Many mathematical structures do. Let's see some more examples.

<a id="verifying-properties-involving-vector-addition"></a>
## Verifying Properties Involving Vector Addition

**Example:** Let $L$ be the set of all polynomials with real coefficients whose degree is less than or equal to $2$. Which of the following statements are true?

1. For any $p(x),q(x) \in L$, we have $p(x)+q(x) = q(x)+p(x)$.
2. For any $p(x),q(x),r(x) \in L$, we have $[p(x)+q(x)]+r(x) = p(x)+[q(x)+r(x)]$.
3. For each $p(x) \in L$, we have $-p(x) \in L$ such that $p(x)+(-p(x))=0$.

**Explanation**

Let's examine our statements one at a time.

- Statement I is true. Indeed, for any polynomials $p(x), q(x) \in L$, we obtain that
$p(x) + q(x)= q(x) +p(x)$
since polynomial addition is commutative.
- Statement II is true. Indeed, for any polynomials $p(x),q(x),r(x) \in L$, we obtain that
$[p(x) + q(x)] + r(x) = p(x) + [q(x) + r(x)]$
since polynomial addition is associative.
- Statement III is true. Indeed, for any polynomial $p(x) \in L$, there is a corresponding negative polynomial $-p(x)$ such that
$p(x) + (-p(x))= p(x) - p(x) = 0$.
Notice that
$\deg(-p(x)) = \deg(p(x)) \leq 2$,
hence $-p(x) \in L$.

Therefore, the correct answer is "I, II, and III."

## Scalar Multiplication and the Distributive Laws

Let's also compare some properties of scalar multiplication in $\mathbb{R}^2$ and $\text{M}_2(\mathbb{R})$. It turns out that the multiplication of a matrix in $\mathrm{M}_2(\mathbb{R})$ by a scalar is *very* similar to the multiplication of a vector in $\mathbb{R}^n$ by a real number. See the table below.

|  | **$\mathbb{R}^2$** | **$\text{M}_2(\mathbb{R})$** |
| --- | ---: | ---: |
| **Invariance Under Multiplication by $1$:** |  |  |
| A5 | For any vector $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} 1 \cdot \mathbf{u} = \mathbf{u}$ | For any matrix $A \in \text{M}_2(\mathbb{R})$, we have $\color{blue} 1 \cdot A = A$ |
| **Scalar Multiplication is Associative:** |  |  |
| A6 | For any numbers $\alpha, \beta$ and any vector $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} \alpha (\beta \mathbf{u}) = (\alpha\beta) \mathbf{u}$ | For any numbers $\alpha, \beta$ and any matrix $A \in \text{M}_2(\mathbb{R})$, we have $\color{blue} \alpha (\beta A) = (\alpha\beta) A$ |
| **Distributive Laws:** |  |  |
| A7 | For any numbers $\alpha, \beta$ and any vector $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} (\alpha + \beta)\mathbf{u} = \alpha \mathbf{u} + \beta \mathbf{u}$ | For any numbers $\alpha, \beta$ and any matrix $A \in \text{M}_2(\mathbb{R})$, we have $\color{blue} (\alpha + \beta)A = \alpha A + \beta A$ |
| A8 | For any number $\alpha$ and any vectors $\mathbf{u}, \mathbf{v} \in \mathbb{R}^2$, we have $\color{blue} \alpha (\mathbf{u} + \mathbf{v}) = \alpha \mathbf{u} + \alpha \mathbf{v}$ | For any number $\alpha$ and any matrices $A, B \in \text{M}_2(\mathbb{R})$, we have $\color{blue} \alpha (A + B) = \alpha A + \alpha B$ |

<a id="verifying-properties-involving-scalar-multiplication-and-the-distributive-laws"></a>
## Verifying Properties Involving Scalar Multiplication and the Distributive Laws

**Example:** Let $P$ be the set of all $2\times 2$ real matrices $A= (a_{ij})$ such that $a_{11} + a_{22} > 0$. Which of the following properties are true?

1. For any $A \in P$, we have $1 \cdot A = A$.
2. For any $A \in P$ and $\alpha,\beta \in \mathbb{R}$, we have $\alpha(\beta A) = (\alpha\beta) A$.
3. For any $A \in P$ and $\alpha,\beta \in \mathbb{R}$, we have $(\alpha+\beta) A= \alpha A + \beta A$.

**Explanation**

Let's verify the statements one by one.

- Statement I is true. Indeed, for any $2\times 2$ matrix $A = (a_{ij}) \in P$, the entries are just real numbers. Thus, we have
$1 \cdot a_{ij} = a_{ij}$,
and hence,
$1\cdot A=A$.
- Statements II is true. Indeed, for any $2\times 2$ matrix $A = (a_{ij}) \in P$, the entries are just real numbers. Thus, for any $\alpha, \beta \in \mathbb{R}$, we obtain that
$\alpha(\beta a_{ij}) = (\alpha\beta) a_{ij}$,
and hence,
$\alpha(\beta A) = (\alpha\beta) A$.
- Statements III is true. Indeed, for any $2\times 2$ matrix $A = (a_{ij}) \in P$, the entries are just real numbers. Thus, for any $\alpha, \beta \in \mathbb{R}$, we obtain that
$(\alpha+\beta) a_{ij} = \alpha a_{ij} + \beta a_{ij}$,
and hence,
$(\alpha+\beta) A= \alpha A + \beta A$.

Therefore, the correct answer is "I, II, and III."

## A Summary of the Addition and Scalar Multiplication Properties of Euclidian Space

In this lesson, we discussed several properties exhibited by vectors in $\mathbb R^n$ and other sets.
Let's consolidate these properties into a single list.

| **Label** | **Name** | **Description** |
| --- | ---: | ---: |
| A1 | **Addition is Commutative** | For any vectors $\mathbf{u}, \mathbf{v} \in \mathbb{R}^2$, we have $\color{blue}\mathbf{u}+\mathbf{v} = \mathbf{v}+\mathbf{u}$ |
| A2 | **Addition is Associative** | For any vectors $\mathbf{u}, \mathbf{v}, \mathbf{w} \in \mathbb{R}^2$, we have $\color{blue}(\mathbf{u}+\mathbf{v})+\mathbf{w} = \mathbf{u}+(\mathbf{v}+\mathbf{w})$ |
| A3 | **Existence of a Unique Zero Element** | For the zero-vector $\mathbf{0}$ and any $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} \mathbf{u} + \mathbf{0} = \mathbf{u}$ |
| A4 | **Existence of a Unique Opposite Element** | For any vector $\mathbf{u} \in \mathbb{R}^2$ we can find the corresponding negative vector $-\mathbf{u} \in \mathbb{R}$ such that $\color{blue} \mathbf{u} + (-\mathbf{u}) = \mathbf{0}$ |
| A5 | **Invariance Under Multiplication by $1$** | For any vector $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} 1 \cdot \mathbf{u} = \mathbf{u}$ |
| A6 | **Scalar Multiplication is Associative** | For any numbers $\alpha, \beta$ and any vector $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} \alpha (\beta \mathbf{u}) = (\alpha\beta) \mathbf{u}$ |
| A7 | **Distributive Laws:** | For any numbers $\alpha, \beta$ and any vector $\mathbf{u} \in \mathbb{R}^2$, we have $\color{blue} (\alpha + \beta)\mathbf{u} = \alpha \mathbf{u} + \beta \mathbf{u}$ |
| A8 | **Distributive Laws:** | For any number $\alpha$ and any vectors $\mathbf{u}, \mathbf{v} \in \mathbb{R}^2$, we have $\color{blue} \alpha (\mathbf{u} + \mathbf{v}) = \alpha \mathbf{u} + \alpha \mathbf{v}$ |

We'll meet these properties again in a future lesson, where we'll formally define what we mean by a vector space.
