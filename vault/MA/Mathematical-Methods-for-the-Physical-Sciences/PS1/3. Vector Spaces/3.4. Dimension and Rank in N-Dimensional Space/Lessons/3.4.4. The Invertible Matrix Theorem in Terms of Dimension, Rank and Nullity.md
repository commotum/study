## Introduction

Suppose we are given an $n \!\times\! n$ invertible matrix $A$. Remember that if $A$ is invertible, then the equation

$$
A\mathbf{x}=\mathbf{0}
$$

has only the trivial solution

$$
\mathbf{x}=\mathbf{0}
$$

Let's extract all possible information from this fact using the vector spaces related to the matrix, namely, the *column space* and the *null space*.

- The fact that the unique solution to $A\mathbf{x}=\mathbf{0}$ is $\mathbf{x}=\mathbf{0}$ tells us that $\textrm{Null}(A)=\{\mathbf{0} \}$, or alternatively, $\textrm{dim(Null}(A)) = \textrm{nullity}(A)=0$.
- Furthermore, if $\textrm{dim(Null}(A))=0$ then $A$ has no *non-pivot* columns, or equivalently, all the columns of $A$ are *pivot columns*. So $\textrm{dim(Col}(A))=\textrm{rank}(A)=n$.
- Finally, since $\textrm{Col}(A)$ is a subspace of $\mathbb{R}^n$ and its basis has $n$ linearly independent vectors, we can conclude that $\textrm{Col}(A)=\mathbb{R}^n$.

All the results mentioned above can be summarized in the following theorem, called the **invertible matrix theorem**:

> *Let $A$ be an $n \!\times\! n$ matrix. Then we have the following equivalence:*
> $Col(A) = R^{n}; dim(Col(A)) = n = rank(A); Null(A) = {0}; dim(Null(A)) = 0 = nullity(A)$

## Identifying True Statements Using the Invertible Matrix Theorem

**Example:** Which of the following statements are true, given that $A$ is a $4 \times 4$ matrix, and
$\begin{bmatrix}x_{1} \\ 2x_{1} \\ 0 \\ -x_{1}\end{bmatrix}$

1. $A$ is not invertible
2. $\textrm{Col}(A)=\mathbb{R}^4$
3. $\textrm{rank}(A)=4$

**Explanation**

Since $A$ is a $4 \times 4$ matrix, the invertible matrix theorem states the following:

$$
Col(A) = R^{4}; dim(Col(A)) = 4 = rank(A); Null(A) = {0}; dim(Null(A)) = 0 = nullity(A)
$$

With that in mind, let's examine each statement in turn.

- Statement I is true. Since
$\begin{bmatrix}1 \\ 2 \\ 0 \\ -1\end{bmatrix}$
we conclude that
$\textrm{dim(Null}(A))=1 \neq 0$.
So, according to the invertible matrix theorem, the matrix $A$ is not invertible.
- Statement II is false. Since the matrix $A$ is not invertible, then by the invertible matrix theorem, we must have $\textrm{Col}(A) \neq \mathbb{R}^4$.
- Statement III is false. Since $A$ is not invertible, then by the invertible matrix theorem, we must have $\textrm{rank}(A) \neq 4$.

Therefore, the correct answer is "I only."

## Сompleting a Sentence Using the Invertible Matrix Theorem

**Example:** Consider the following sentence:

> *If $A$ is a $n\times n$ matrix and $\textrm{Null}(A) = \{\mathbf{0}\}$, then $\text{__________}\,$.*

Which of the following can be placed into the blank space to make a true statement?

1. $\det(A) = 0$
2. $\textrm{rank}(A) = n$
3. $A$ has $n$ pivot columns

**Explanation**

The invertible matrix theorem states the following:

> $A$ is invertible $Col(A) = R^{n}; dim(Col(A)) = n = rank(A); Null(A) = {0}; dim(Null(A)) = 0 = nullity(A)$

With that in mind, let's examine each of the options separately.

- The following statement is false:$\qquad$ *If $A$ is a $n\times n$ matrix and $\textrm{Null}(A) = \{\mathbf{0}\}$, then $\det(A) = 0$.* $\:{\color{red}\times}$Since $\textrm{Null}(A) = \{\mathbf{0}\}$, then according to the invertible matrix theorem, the matrix $A$ must be invertible, which means $\det(A) \ne 0$.
- The following statement is true:$\qquad$ *If $A$ is a $n\times n$ matrix and $\textrm{Null}(A) = \{\mathbf{0}\}$, then $\textrm{rank}(A) = n$.* $\:{\color{green}\checkmark}$Indeed, since $A$ is invertible, then according to the invertible matrix theorem, we have $\textrm{rank}(A)=n$.
- The following statement is true:$\qquad$ *If $A$ is a $n\times n$ matrix and $\textrm{Null}(A) = \{\mathbf{0}\}$, then $A$ has $n$ pivot columns.* $\:{\color{green}\checkmark}$ Indeed, since $A$ is invertible, then according to the invertible matrix theorem, we have $\textrm{dim(Col}(A))=n$, which means that $A$ has exactly $n$ pivot columns.

Therefore, the correct answer is "II and III only."
