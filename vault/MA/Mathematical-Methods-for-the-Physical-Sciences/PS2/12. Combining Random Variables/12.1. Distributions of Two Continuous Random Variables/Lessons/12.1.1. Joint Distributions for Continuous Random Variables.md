## Introduction

We've already seen how to work with bivariate distributions for *discrete* random variables. This lesson will examine the case where the random variables are *continuous.*

A function $f(x,y)$ is a **joint probability density function** (or **joint PDF**) for the two continuous random variables $X$ and $Y$ if the following three conditions are satisfied:

- $f(x,y) \geq 0$ for all $(x,y) \in \mathbb{R}^2$
- $\displaystyle \iint_{\mathbb R^2} f(x,y) \,\textrm{d}x\textrm{d}y = 1$
- $P\left((X,Y)\in A\right) = \displaystyle \iint_{A} f(x,y) \,\textrm{d}x\textrm{d}y$, where $A$ is a subset of $\mathbb R^2$.

There is some nice intuition to these conditions.

- The first condition states that $f$ must be nonnegative everywhere.
- The second condition states that the sum (integral) of $f$ over possible values of $X$ and $Y$ must add up to $1$.
- The third condition states that we compute the probability of an event $A$ by summing (integrating) $f$ over all regions associated with $A$.

It's worth taking a minute to compare these conditions with those we've seen previously. Firstly, they are the continuous analog of those for the joint PMF of two discrete random variables. Secondly, they are the two-dimensional analog of those for the PDF $f(x)$ of a (single) continuous random variable $X$.

It's also worth noting that these conditions can be generalized to multivariate distributions $(X_1, X_2, \ldots, X_n)$ of $n$ continuous random variables.

Let's now take a look at a concrete example.

<a id="verifying-that-a-function-is-a-valid-joint-pdf"></a>
## Verifying That a Function Is a Valid Joint PDF

Let's show that the following function is a valid joint PDF:

$$
{\frac{3}{2}(x^{2} + y^{2}),\begin{vmatrix}0 \le x \le 1, 0 \le y \le 1 \\ 0,\end{vmatrix}otherwise
$$

We only need to check the first two conditions to show that this is a valid joint PDF for *some* pair of random variables. So let's do that:

- Clearly $f(x,y) \geq 0$ for all $(x,y) \in \mathbb{R}^2$, so the first condition is satisfied. $\quad{\color{green}{\checkmark}}$
- To check the second condition, let's first define a region $D$ where $f(x)$ is nonzero:
$D = \{(x,y) \::\: 0 \leq x \leq 1,\,0 \leq y\leq 1\}$
A sketch of this region is shown below.![](<../Source/12.1.1. Joint Distributions for Continuous Random Variables/Images/32bdb1266936701e805a53790ad7ee06.png>)Let's now integrate $f(x,y)$ over $\mathbb R^2$. By doing this, we get
$∬_{R^{2}}f(x, y)dydx|= ∬_{D}f(x, y)dydx; = ∫_{0}^{1}∫_{0}^{1}\frac{3}{2}(x^{2} + y^{2})dydx; = \frac{3}{2}∫_{0}^{1}∫_{0}^{1}x^{2} + y^{2}dydx; = \frac{3}{2}∫_{0}^{1}[x^{2}y + \frac{y^{3}}{3}]_{y = 0}^{y = 1}dx; = \frac{3}{2}∫_{0}^{1}(x^{2} + \frac{1}{3})dx; = \frac{3}{2}[\frac{x^{3}}{3} + \frac{x}{3}]_{0}^{1}; = \frac{3}{2}(\frac{1}{3} + \frac{1}{3}); = 1.✓$
Therefore, the second condition is satisfied too.

Hence, $f(x,y)$ is a valid joint probability density function.

We'll learn how to compute probabilities using the joint PDF later in this lesson.

<a id="joint-pdfs-for-continuous-random-variables-rectangular-domains"></a>
## Joint PDFs for Continuous Random Variables: Rectangular Domains

**Example:** The random variables $X$ and $Y$ have the joint probability density function
${c\sin (x + y),\begin{vmatrix}0 < x < \frac{π}{2}, 0 < y < \frac{π}{2} \\ 0,\end{vmatrix}otherwise$
where $c$ is a positive real number. Find the value of $c$.

**Explanation**

To verify that $f(x,y)$ is a valid joint probability density function, we must check the following conditions:

- $f(x,y) \geq 0$ for all $(x,y)\in \mathbb R^2$
- $\displaystyle \iint_{\mathbb R^2} f(x,y) \;\textrm{d}x\textrm{d}y= 1$

First, let's sketch the region

$$
D = \left\{(x,y) \::\: 0\lt x\lt \dfrac{\pi}{2},0\lt y \lt \dfrac{\pi}{2} \right\}
$$

![](<../Source/12.1.1. Joint Distributions for Continuous Random Variables/Images/f9bda8492314ef0374cbb01c5b669ef2.png>)

Now, let's check our conditions:

- Since $c > 0$, we clearly have $f(x,y) \geq 0$ for all $(x,y)\in \mathbb R^2$. So the first condition is satisfied.
- For the second condition to be satisfied, we must have
$\int_{0}^{\pi/2}\int_{0}^{\pi/2}c\sin (x+y) \;\textrm{d}y\,\textrm{d}x= 1$.
We evaluate the inner integral by integrating with respect to $y$, treating $x$ as a constant:
$∫_{0}^{π/2}[∫_{0}^{π/2}c\sin (x + y)dy]dx|= c∫_{0}^{π/2}[∫_{0}^{π/2}\sin (x + y)dy]dx; = c∫_{0}^{π/2}[- \cos (x + y)]_{y = 0}^{y = π/2}dx; = c∫_{0}^{π/2}(-\cos (x + \frac{π}{2}) + \cos x)dx; = c∫_{0}^{π/2}\cos x - \cos (x + \frac{π}{2})dx$
Then, we integrate with respect to $x$:
$c∫_{0}^{π/2}\cos x - \cos (x + \frac{π}{2})dx|= c[\sin x - \sin (x + \frac{π}{2})]_{0}^{π/2}; = c[(\sin (\frac{π}{2}) - \sin π) - (\sin (0) - \sin (\frac{π}{2}))]; = c[(1 - 0) - (0 - 1)]; = c[1 - (-1)]; = 2c$

Hence,

$$
2c=1 \qquad \Longrightarrow \qquad c=\dfrac{1}{2}
$$

## Joint PDFs for Continuous Random Variables: Non-Rectangular Domains

**Example:** The random variables $X$ and $Y$ have the joint probability density function
${(c)/((1 + x + y)^{3}),\begin{vmatrix}0 \le x < y \\ 0,\end{vmatrix}otherwise$
where $c$ is a positive real number. Find the value of $c$.

**Explanation**

To verify that $f(x,y)$ is a valid joint probability density function, we must check the following conditions:

- $f(x,y) \geq 0$ for all $(x,y)\in \mathbb R^2$
- $\displaystyle \iint_{\mathbb R^2} f(x,y) \;\textrm{d}x\,\textrm{d}y= 1$

First, let's sketch the region

$$
D = \{(x,y) \::\: 0 \leq x \lt y \}
$$

![](<../Source/12.1.1. Joint Distributions for Continuous Random Variables/Images/f7c3d4d867e4cd8c83125f9b879c525e.png>)

Now, let's check our conditions:

- Since $c > 0$, we clearly have $f(x,y) \geq 0$ for all $(x,y)\in \mathbb R^2$. So the first condition is satisfied.
- For the second condition to be satisfied, we must have
$\displaystyle \iint_{\mathbb R^2} f(x,y) \;\textrm{d}x\textrm{d}y = \iint_{D} f(x,y) \;\textrm{d}x\textrm{d}y = \int_{0}^{\infty}\int_{x}^{\infty} \dfrac{c}{(1+x+y)^3} \;\textrm{d}y\,\textrm{d}x= 1$.
We evaluate the inner integral by integrating with respect to $y$, treating $x$ as a constant:

$$
\begin{aligned}
∫_{0}^{∞}[∫_{x}^{∞}(c)/((1 + x + y)^{3})dy]dx &= c∫_{0}^{∞}[∫_{x}^{∞}(1 + x + y)^{-3}dy]dx \\
&= c∫_{0}^{∞}[- \frac{1}{2}(1 + x + y)^{-2}]_{y = x}^{y = ∞}dx \\
&=-\frac{c}{2}∫_{0}^{∞}[(1 + x + y)^{-2}]_{y = x}^{y = ∞}dx \\
&=-\frac{c}{2}∫_{0}^{∞}0 - (1 + 2x)^{-2}dx \\
&=-\frac{c}{2}∫_{0}^{∞} - (1 + 2x)^{-2}dx \\
&= \frac{c}{2}∫_{0}^{∞}(1 + 2x)^{-2}dx
\end{aligned}
$$

> Then, we integrate with respect to $x{:}$
> $\frac{c}{2}∫_{0}^{∞}(1 + 2x)^{-2}dx|= \frac{c}{2}[- \frac{1}{2}(1 + 2x)^{-1}]_{0}^{∞}; =-\frac{c}{4}[\frac{1}{1 + 2x}]_{0}^{∞}; =-\frac{c}{4}[0 - 1]; = \frac{c}{4}$

Hence,

$$
\dfrac{c}{4}=1 \qquad \Longrightarrow \qquad c=4
$$

<a id="finding-probabilities-using-joint-pdfs"></a>
## Finding Probabilities Using Joint PDFs

Suppose that $f(x,y)$ is a joint probability density function for two continuous random variables $X$ and $Y$. As previously discussed, for any subset $A$ of $\mathbb{R}^2$, we have

$$
P\big((X,Y) \in A \big) = \iint_A f(x, y) \;\textrm{d}x\textrm{d}y
$$

In particular, if $A$ is the event defined as

$$
A = \big\{(X,Y) \: \mid \: a \leq X \leq b, \, c \leq Y \leq d \big\}
$$

then the corresponding probability can be computed as

$$
P(a \leq X \leq b, c \leq Y \leq d) = \int^{d}_{c} \int^{b}_{a} f(x,y) \;\textrm{d}x \: \textrm{d}y = \int^{b}_{a} \int^{d}_{c} f(x,y) \;\textrm{d}y \: \textrm{d}x
$$

Finally, analogously to the case of a single continuous random variable, the probability that $(X,Y)$ takes on any particular value $(x,y)$ is zero, i.e.,

$$
P(X = x, Y=y) = 0
$$

Let's see an example of how to compute a probability in practice.

<a id="computing-a-probability-using-a-joint-pdf"></a>
## Computing a Probability Using a Joint PDF

**Example:** The random variables $X$ and $Y$ have the joint probability density function
${\frac{1}{6},\begin{vmatrix}0 \le x \le 3, 0 \le y \le 2, \\ 0,\end{vmatrix}otherwise$.

Find $P(X > 1, Y < 1)$.

**Explanation**

If $f(x,y)$ is a joint probability density function for the random variables $X$ and $Y$ and $A\subset \mathbb R^2$, then

$$
P\left((X,Y)\in A\right) = \iint_A f(x,y)\,\textrm d x\textrm d y
$$

Notice that $f(x,y)$ is nonnegative in the region

$$
D = [0,3]\times [0,2]
$$

and the event

$$
A = \left\{X > 1, Y < 1\right\}
$$

corresponds to a subset of $D$, shown as the shaded region below:

![](<../Source/12.1.1. Joint Distributions for Continuous Random Variables/Images/a5d3eeb749188c014bfe84991e95ddc8.png>)

Therefore,

$$
\begin{aligned}
P(X > 1, Y < 1) &= ∬_{A}f(x, y)dxdy \\
&= \frac{1}{6}∬_{A}dxdy \\
&= \frac{1}{6}Area(A) \\
&= \frac{1}{6} \cdot (3 - 1) \cdot (1 - 0) \\
&= \frac{1}{6} \cdot 2 \cdot 1 \\
&= \frac{1}{3}
\end{aligned}
$$
