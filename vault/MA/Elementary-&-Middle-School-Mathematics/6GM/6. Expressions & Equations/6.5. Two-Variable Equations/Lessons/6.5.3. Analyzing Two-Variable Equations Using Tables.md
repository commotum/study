## Introduction

We can represent two-variable equations using tables. For example, consider the following equation:

$$
y = 5 + x
$$

Notice that:

- If $x=0$, then $y=5 + 0 = 5$.
- If $x=1$, then $y=5 + 1 = 6$.
- If $x=2$, then $y=5 + 2 = 7$.
- If $x=3$, then $y=5 + 3 = 8$.

We can organize these results in the table below:

| $x$ | $y$ |
| --- | ---: |
| $0$ | $5$ |
| $1$ | $6$ |
| $2$ | $7$ |
| $3$ | $8$ |

## Finding the Missing Constant in an Equation With Addition and Subtraction

**Example:** The equation that represents the relationship between $y$ and $x$ is $0$ What is the missing number?

| $x$ | $y$ |
| --- | ---: |
| $4$ | $0$ |
| $6$ | $2$ |
| $8$ | $4$ |
| $10$ | $6$ |

**Explanation**

We notice that, for every $x$ value, we subtract $4$ to get the corresponding $y$ value.

| $x$ | $y$ |
| --- | ---: |
| $4$ | $4 - {\color{blue}4} = 0$ |
| $6$ | $6 - {\color{blue}4}=2$ |
| $8$ | $8-{\color{blue}4}=4$ |
| $10$ | $10-{\color{blue}4}=6$ |

Therefore, the equation is

$$
y = x - {\color{blue}4}
$$

So the missing number is $4$.

## Finding the Missing Constant in an Equation With Multiplication and Division

**Example:** The equation that represents the relationship between $b$ and $a$ is $0$ Find the missing number.

| $a$ | $b$ |
| --- | ---: |
| $10$ | $2$ |
| $20$ | $4$ |
| $30$ | $6$ |
| $40$ | $8$ |

**Explanation**

We notice that, for every $a$-value, we divide by $\color{blue}5$ to get the corresponding $b$-value.

| $a$ | $b$ |
| --- | ---: |
| $10$ | $\dfrac{10}{\color{blue}5} = 2$ |
| $20$ | $\dfrac{20}{\color{blue}5}=4$ |
| $30$ | $\dfrac{30}{\color{blue}5}=6$ |
| $40$ | $\dfrac{40}{\color{blue}5}=8$ |

Therefore, the equation is

$$
b = \dfrac{a}{\color{blue}5}
$$

So the missing number is $5$.

## Finding Missing Values in a Table Given the Independent Variable

Consider the table with missing values below that represents the equation

$$
b = a + 5
$$

| $a$ | $b$ |
| --- | ---: |
| $8$ | $13$ |
| $6$ | $11$ |
| $4$ |  |
|  | $7$ |

To calculate the missing value of $b$, we substitute $a = 4$ into the relationship

$$
b = a + 5{:}
$$

$$
b = 4 + 5 = {\color{blue}{9}}
$$

Let's add it to our table.

| $a$ | $b$ |
| --- | ---: |
| $8$ | $13$ |
| $6$ | $11$ |
| $4$ | ${\color{blue}9}$ |
|  | $7$ |

Next, let's find the second missing value.

<a id="finding-missing-values-in-a-table-given-the-dependent-variable"></a>
## Finding Missing Values in a Table Given the Dependent Variable

| $a$ | $b$ |
| --- | ---: |
| $8$ | $13$ |
| $6$ | $11$ |
| $4$ | ${\color{blue}9}$ |
|  | $7$ |

To find the missing value of $a$, we substitute $b = 7$ into the relationship

$$
b = a + 5{:}
$$

$$
7 = a + 5
$$

Now, we solve this equation by subtracting $5$ from both sides:

$$
\begin{aligned}
7 &= a + 5 \\
7 - 5 &= a + 5 - 5 \\
2 &= a + 0 \\
2 &= a
\end{aligned}
$$

So, the second missing number is $2$.

| $a$ | $b$ |
| --- | ---: |
| $8$ | $13$ |
| $6$ | $11$ |
| $4$ | ${\color{blue}9}$ |
| ${\color{red}2}$ | $7$ |

## Constructing a Table Given an Equation

**Example:** The table represents the equation $q = 4p$. From **top to bottom**, what are the missing numbers?

| $p$ | $q$ |
| --- | ---: |
| $2$ |  |
| $3$ | $12$ |
| $4$ | $16$ |
|  | $20$ |

**Explanation**

To calculate the missing value of $q$, we substitute $p=2$ into the relationship $q = 4p{:}$

$$
q = 4 \times 2 = {\color{blue}{8}}
$$

To find the second missing value, we substitute $q=20$ into the relationship $q = 4p{:}$
$20 = 4p$

Now, we solve this equation by dividing both sides by $4{:}$

$$
\begin{aligned}
20 &= 4p \\
\frac{20}{4} &= \frac{4p}{4} \\
5 &= \frac{4p}{4} \\
5 &= p
\end{aligned}
$$

So, from top to bottom, the missing numbers are $8$ and $5$.

| $p$ | $q$ |
| --- | ---: |
| $2$ | ${\color{blue}{8}}$ |
| $3$ | $12$ |
| $4$ | $16$ |
| ${\color{red}{5}}$ | $20$ |

## Identifying an Equation Given a Table

**Example:** What equation represents the relationship between $z$ and $t$?

| $z$ | $t$ |
| --- | ---: |
| $3$ | $1$ |
| $6$ | $2$ |
| $9$ | $3$ |
| $12$ | $4$ |

**Explanation**

Note that, for every $z$-value, we divide by $\color{blue}3$ to get the corresponding $t$-value.

| $z$ | $t$ |
| --- | ---: |
| $3$ | $3 \div {\color{blue}3} = 1$ |
| $6$ | $6 \div {\color{blue}3} = 2$ |
| $9$ | $9 \div {\color{blue}3} = 3$ |
| $12$ | $12 \div {\color{blue}3} = 4$ |

Therefore, the equation is

$$
t = \dfrac{z}{3}
$$
