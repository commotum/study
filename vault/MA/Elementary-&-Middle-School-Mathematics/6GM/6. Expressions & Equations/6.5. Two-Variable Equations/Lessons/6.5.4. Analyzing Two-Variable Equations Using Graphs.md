## Introduction

We can represent two-variable equations using graphs. For example, consider the following equation:

$$
y = x + 5
$$

A point $(x, y)$ is a solution to this equation if substituting the $x$-value into the equation gives the correct $y$-value.

To find some solution points, we can choose several $x$-values and compute the corresponding $y$-values.
Notice that:

- If $x=0$, then $y=0 + 5 = 5$.
- If $x=1$, then $y=1 + 5 = 6$.
- If $x=2$, then $y=2 + 5 = 7$.
- If $x=3$, then $y=3 + 5 = 8$.

We can organize these results in the table below:

| $x$ | $y$ |
| --- | ---: |
| $0$ | $5$ |
| $1$ | $6$ |
| $2$ | $7$ |
| $3$ | $8$ |

So, we have the following points:
$(0,5),\: (1,6),\: (2,7),\: (3,8)$

To graph the equation, we plot these points on the coordinate plane and draw a straight line through them.

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/5857db47f833dd7ea2420de6b9ef91b5.png>)

Every point $(x,y)$ on the line satisfies the equation.

## Reading Graphs

Graphs can help us solve word problems involving two quantities.

The graph below shows the relationship between the number of notebooks purchased and the total cost.

- The horizontal axis shows the number of notebooks $n$.
- The vertical axis shows the total cost $c$ (in dollars).

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/1ba2a4d56620051e3bcf27fba380b505.png>)

The graph contains many points. Each point on the graph matches a value of $n$ with its corresponding value of $c$.

Suppose we want to find the total cost when $2$ notebooks are purchased. To do so, we:

- find $n={\color{blue}2}$ on the *horizontal* axis,
- move *vertically* from this point until we reach the graph, and
- move *horizontally left* from the graph, and read off the $c$-value.

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/ca4465e7963aa1400114018bce3f93c8.png>)

The corresponding value on the vertical axis is

$$
c = {\color{red}5}
$$

Therefore, the cost for $2$ notebooks is $\[math]5$.

When reading a graph, be careful to match each axis to the correct quantity. This is because, if we are given a value on the *vertical* axis, we must work in the other direction to find the corresponding value on the *horizontal* axis.

Let's see an example of this in the next slide.

## Solving a Word Problem Given a Graph

**Example:** The graph shows the number of hotcakes $h$ that Esther can make with $e$ eggs. How many eggs does Esther need to make $15$ hotcakes?

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/b326c6b2c0058ddb49c73d052c3dea47.png>)

**Explanation**

Since Esther wants to make $15$ hotcakes, we have that $h = 15$.

We need to locate the $e$ value that corresponds to $h = 15$ on the graph. To do this, we:

- find $h = {\color{blue}15}$ on the vertical axis,
- move horizontally from this point until we reach the graph, and
- move vertically down from the graph and read off the $e$-value.

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/8259df59ecea5d7284e2ddf80226077d.png>)

The corresponding value on the horizontal axis is

$$
e = {\color{red}5}
$$

Therefore, Esther needs $5$ eggs to make $15$ hotcakes.

## Determining the Equation Given a Graph

Sometimes we are given a graph and asked to find a value that is not shown directly on the graph. To solve this problem, we must first determine the equation of the graph.

To demonstrate, suppose a parking garage charges a flat entry fee plus a cost per hour.
The total cost $c$ (in dollars) after $h$ hours is shown in the graph below.

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/84374f8a6dfe161d2105c318eda58384.png>)

Suppose we want to find the total cost after $4.5$ hours.

Since $h=4.5$ is not one of the labeled points on the graph, we cannot read the value directly.
Instead, we will find the equation that relates $c$ and $h$.

From the graph, we can pick out the following coordinates:
$(0,6),\: (4,10),\: (6,12)$

Now, let's put these coordinates into a table:

| $h$ | $c$ |
| --- | ---: |
| $0$ | $6$ |
| $4$ | $10$ |
| $6$ | $12$ |

Notice that each $c$-value is $6$ more than the corresponding $h$-value.

| $h$ | $c$ |
| --- | ---: |
| $0$ | $0 + {\color{blue}6} = 6$ |
| $4$ | $4 + {\color{blue}6} = 10$ |
| $6$ | $6 + {\color{blue}6} = 12$ |

Hence, the equation that relates $c$ and $h$ is

$$
c = h + {\color{blue}6}
$$

So, for $h=4.5$, we have

$$
\begin{aligned}
c &= 4.5 + 6 = 10.5
\end{aligned}
$$

Therefore, after $4.5$ hours, the total cost is $\[math]10.50$.

## Identifying the Equation Given a Graph

**Example:** The graph below represents the relationship $0$ What is the missing number?

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/76e2418f10a52ac55e07471d2d20b0ef.png>)

**Explanation**

From the graph, we can pick out the following coordinates:
$(2,1),\: (4,2),\: (6,3),\: (8,4)$

Now let's put these coordinates into the table:

| $x$ | $y$ |
| --- | ---: |
| $2$ | $1$ |
| $4$ | $2$ |
| $6$ | $3$ |
| $8$ | $4$ |

Notice that for every $x$-value, we divide by $2$ to get the corresponding $y$-value.

| $x$ | $y$ |
| --- | ---: |
| $2$ | $\dfrac2{\color{blue}2} = 1$ |
| $4$ | $\dfrac4{\color{blue}2} = 2$ |
| $6$ | $\dfrac6{\color{blue}2} = 3$ |
| $8$ | $\dfrac8{\color{blue}2} = 4$ |

Therefore, the equation is

$$
y = \dfrac{x}{\bbox[4pt,border: 1px solid lightgray]{\color{blue}2}}
$$

So the missing number is ${\color{blue}{2}}$.

<a id="solving-a-word-problem-by-identifying-the-equation-given-a-graph"></a>
## Solving a Word Problem by Identifying the Equation Given a Graph

**Example:** Moises charges his laptop. The percentage charge $p$ of the laptop's battery after $t$ minutes is shown in the graph. What will be the battery's charge percentage after $23$ minutes?

![](<../Source/6.5.4. Analyzing Two-Variable Equations Using Graphs/Images/09ccc0455a11b80385259fbd33c53e8e.png>)

**Explanation**

Since the laptop charges for $23$ minutes, we have that $t=23$.

On the graph, we can't identify a point corresponding to $t=23$, so we will need to find the equation relating $p$ and $t$.

From the graph, we can pick out the following coordinates:
$(5,10),\: (10,20),\: (15,30)$

Now, let's put these coordinates into a table:

| $t$ | $p$ |
| --- | ---: |
| $5$ | $10$ |
| $10$ | $20$ |
| $15$ | $30$ |

Notice that for every $t$-value, we multiply by $2$ to get the corresponding $p$-value.

| $t$ | $p$ |
| --- | ---: |
| $5$ | ${\color{blue}2}\cdot5=10$ |
| $10$ | ${\color{blue}2}\cdot10=20$ |
| $15$ | ${\color{blue}2}\cdot15=30$ |

Hence, the equation that relates $p$ and $t$ is

$$
p={\color{blue}2}t
$$

So, for $t=23$, we have

$$
\begin{aligned}
p &= 2 \cdot 23 = 46
\end{aligned}
$$

Therefore, after $23$ minutes, the charge level will be $46\%$.
