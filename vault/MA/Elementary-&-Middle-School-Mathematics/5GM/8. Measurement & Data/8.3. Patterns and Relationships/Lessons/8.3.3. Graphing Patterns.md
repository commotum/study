## Introduction

We can plot the relationship between two patterns, such as those given in the table below, in a coordinate plane.

| Pattern A: add $1$ | $0$ | $1$ | $2$ | $3$ | $4$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pattern B: add $5$ | $0$ | $5$ | $10$ | $15$ | $20$ |

To do this, we choose the horizontal axis ($x$-axis) to correspond to pattern A and the vertical axis ($y$-axis) to correspond to pattern B.

We add one more row to the table that contains the ordered pairs corresponding to each point. Here, the $x$ and $y$-coordinates are the terms from patterns A and B, respectively.

| Pattern A: add $1$ | $\color{blue}0$ | $\color{blue}1$ | $\color{blue}2$ | $\color{blue}3$ | $\color{blue}4$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pattern B: add $5$ | $\color{red}0$ | $\color{red}5$ | $\color{red}10$ | $\color{red}15$ | $\color{red}20$ |
| Ordered pair | $({\color{blue}0},{\color{red}0})$ | $({\color{blue}1},{\color{red}5})$ | $({\color{blue}2},{\color{red}10})$ | $({\color{blue}3},{\color{red}15})$ | $({\color{blue}4},{\color{red}20})$ |

Plotting each ordered pair in the coordinate plane, we get the following graph:

![](<../Source/8.3.3. Graphing Patterns/Images/175ddce9b11c9feaba02e4327f915558.png>)

## Plotting a Graph Given a Table Containing Two Patterns

**Example:** Find the numbers for the patterns shown in the table below and plot the corresponding graph.

| Pattern A: add $2$ | $1$ |  |  |  |
| --- | ---: | ---: | ---: | ---: |
| Pattern B: multiply by $2$ | $1$ |  |  |  |

**Explanation**

The rule of pattern A is "add $2$", and the first number is $1$. So, we have the following pattern:

![](<../Source/8.3.3. Graphing Patterns/Images/44acea1003d154f12e611e21a4fb0329.png>)

The rule of pattern B is "multiply by $2$", and the first number is $1$. So, we have the following pattern:

![](<../Source/8.3.3. Graphing Patterns/Images/39f3caa97aae59f0fc1a5755b8ce7deb.png>)

Let's fill in the table:

| Pattern A: add $2$ | $1$ | $3$ | $5$ | $7$ |
| --- | ---: | ---: | ---: | ---: |
| Pattern B: multiply by $2$ | $1$ | $2$ | $4$ | $8$ |

We choose the horizontal axis ($x$-axis) to correspond to pattern A and the vertical axis ($y$-axis) to correspond to pattern B. We add one more row to the table with ordered pairs corresponding to each point.

| Pattern A: add $2$ | $1$ | $3$ | $5$ | $7$ |
| --- | ---: | ---: | ---: | ---: |
| Pattern B: multiply by $2$ | $1$ | $2$ | $4$ | $8$ |
| Ordered pair | $(1,1)$ | $(3,2)$ | $(5,4)$ | $(7,8)$ |

Plotting each ordered pair on the coordinate plane, we get the following graph:

![](<../Source/8.3.3. Graphing Patterns/Images/e3c5daa55f2e1d46e561d0ded4e13f1e.png>)

## Constructing a Table of Two Patterns Given a Graph

**Example:** Create a table that gives the pattern shown in the graph above.

![](<../Source/8.3.3. Graphing Patterns/Images/b1d8f32d9ad53f7a8f3e97bd38bc9357.png>)

**Explanation**

The horizontal axis ($x$-axis) corresponds to pattern A, and the vertical axis ($y$-axis) corresponds to pattern B. We have the following coordinates of points:
$(1,10),\, (3,8),\, (5,6),\, (7,4),\, (9,2)$

So, we can fill the table:

| Ordered pair | $(1,10)$ | $(3,8)$ | $(5,6)$ | $(7,4)$ | $(9,2)$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pattern A | $1$ | $3$ | $5$ | $7$ | $9$ |
| Pattern B | $10$ | $8$ | $6$ | $4$ | $2$ |

Removing the first row, we get:

| Pattern A | $1$ | $3$ | $5$ | $7$ | $9$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pattern B | $10$ | $8$ | $6$ | $4$ | $2$ |

<a id="forming-a-statement-of-comparison-given-a-graph"></a>
## Forming a Statement of Comparison Given a Graph

**Example:** What is missing from the following statement?

$\qquad$ Each term in pattern B is $\underline{\phantom{{}^{000000000000000000000}}}$ than the corresponding term in pattern A.

![](<../Source/8.3.3. Graphing Patterns/Images/f03bde57b4d21ccd8af387517cdba7ba.png>)

**Explanation**

The horizontal axis ($x$-axis) corresponds to pattern A, and the vertical axis ($y$-axis) corresponds to pattern B. We have the following coordinates of points:

$$
(2,0),\, (3,1),\, (4,2),\, (5,3)
$$

So, we can fill the table:

| Ordered pair | $(2,0)$ | $(3,1)$ | $(4,2)$ | $(5,3)$ |
| --- | ---: | ---: | ---: | ---: |
| Pattern A | $2$ | $3$ | $4$ | $5$ |
| Pattern B | $0$ | $1$ | $2$ | $3$ |

Comparing the terms in both patterns, we note that we can add $2$ to each term of pattern B to get the corresponding term in pattern A:

$$
\begin{aligned}
0 + 2 &= 2 \\
1 + 2 &= 3 \\
2 + 2 &= 4 \\
3 + 2 &= 5
\end{aligned}
$$

Therefore, the correct statement is:

$\qquad$ Each term in pattern B is **$2$ smaller** than the corresponding term in pattern A.
