## Introduction

How do we write the following expression in words?

$$
(9\times 5) - 6
$$

The order of operations can help! Since our expression uses parentheses, this operation comes first:

$$
(9\times 5)
$$

So first, we say: *"Multiply $9$ and $5$"*.

The next operation is:

$$
(9\times 5) \,\color{red}{-\, 6}
$$

So next, we say: *"then subtract $6$"*.

Combining our phrases, we get: *"Multiply $9$ and $5$, then subtract $6$."*

---

<a id="writing-an-expression-in-words"></a>
## Writing an Expression in Words

**Example:** What phrase represents the expression $(9 - 7) \times 2$?

**Explanation**

Since the expression uses parentheses, this operation comes first. So first, we should "*Subtract $7$ from $9$*".

The $\times\,2$ means that we should "*then multiply by $2$*".

So, the given expression is equivalent to "*Subtract $7$ from $9$, then multiply by $2$.*"

## Creating Numerical Expressions

We can create a numerical expression when information is given to us in words.

For example, let's create an expression that represents the sentence "*Add $1$ and $11$, then divide by $4$*".

Checking our sentence carefully, we need to add $1$ and $11$ *before* dividing by $4$.

For the phrase "*Add $1$ and $11$*", this means:
$1 + 11$

Since this operation comes first, we use parentheses:
$(1 + 11)$

Adding parentheses will help us to avoid mistakes with the order of operations.

For the phrase "*then divide by $4$*", this means that we should divide the above expression by $4$. So we get:
$(1 + 11) \div 4$

<a id="creating-an-expression-from-a-sentence"></a>
## Creating an Expression From a Sentence

**Example:** What expression represents the phrase "*Subtract $5$ from $7$, then multiply by $2$*"?

**Explanation**

Checking our phrase carefully, we need to subtract $5$ from $7$ *before* multiplying by $2$.

For the phrase "*Subtract $5$ from $7$*", this means:
$7-5$

Since this operation comes first, we use parentheses:
$(7 - 5)$

For the phrase "*then multiply by $2$*", this means that we should multiply the above expression by $2$. So we get:

$$
(7-5)\times 2
$$

## Using Double, Triple, and Quadruple

Some special multiplication words occur in everyday language. You probably know them already.

- To **double** something means to multiply it by $2$.
- To **triple** something means to multiply it by $3$.
- To **quadruple** something means to multiply it by $4$.

Let's see how to convert a sentence with these special words into an algebraic expression.

---

<a id="using-double-triple-and-quadruple"></a>
## Using Double, Triple, and Quadruple

**Example:** Find an expression that represents "*add $7$ and $1$, then triple the result.*"

**Explanation**

Looking carefully, we see that "*add $7$ and $1$*" comes first.

$$
(7+1)
$$

Next, "*then triple the result*" means we need to multiply the above expression by $3$. This gives:

$$
(7+1)\times 3
$$

<a id="creating-an-expression-from-a-context"></a>
## Creating an Expression From a Context

**Example:** Two children, Charlie and Maria, have $3$ dogs and $2$ cats each. Write an expression represents the total number of pets that they have?

**Explanation**

We need to write an expression to represent the total number of pets.

Since each of them has $3$ dogs and $2$ cats, the number of pets each child has is:

$$
\underbrace{3}_{\text{dogs}}+\underbrace{2}_{\text{cats}}
$$

Since *each* child has this number of pets, and there are $2$ children, we must multiply the number of pets by $2$. Therefore, the total number of pets is:

$$
\underbrace{(3 + 2)}_{\text{pets per child}}\times \underbrace{2}_{\text{children}}
$$
