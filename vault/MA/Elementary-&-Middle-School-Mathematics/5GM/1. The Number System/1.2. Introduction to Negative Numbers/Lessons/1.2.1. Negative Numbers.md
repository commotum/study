## Introduction

**Negative numbers** are numbers to the *left* of $0$ on the number line.

![](<../Source/1.2.1. Negative Numbers/Images/c393d711800f5d5522d9fd80090e773e.png>)

We write a negative number as a number with a $-$ sign in front of it.

To find the number, we count the number of jumps between zero and the point on the line.

For example, to represent $-3$ on a number line, we start at zero and move $3$ places to the left:

![](<../Source/1.2.1. Negative Numbers/Images/78c2d5c4a66df01e559391b9be203c12.png>)

So the red dot on the number line above represents the number $-3$.

## Representing Negative Numbers on a Number Line Using Steps Larger Than One

Sometimes, each jump on the number line can represent a distance greater than $1$. For example, what number is represented by the red dot on the number line below?

![](<../Source/1.2.1. Negative Numbers/Images/4686a1689ca670eca3b633d123000501.png>)

To find the number, we count the number of jumps between zero and the red circle.

![](<../Source/1.2.1. Negative Numbers/Images/58feefc6bc09e05e97fb43cd6f37ae31.png>)

There are $3$ jumps between zero and the red circle, and each jump represents a distance of $4$. So the number shown is $-12$.

## Finding Missing Values on a Number Line Using Steps Larger Than One

**Example:** From left to right, what are the missing numbers in the number line below?

![](<../Source/1.2.1. Negative Numbers/Images/cebd26027b4db45de60f305a69b69128.png>)

**Explanation**

The first number is negative because it is to the *left* of zero. To find this number, we count the number of jumps between zero and the number.

![](<../Source/1.2.1. Negative Numbers/Images/a20e89fb0e2c60e6df2d45f003be85aa.png>)

Each jump represents a distance of $5$, and we have $3$ jumps. Therefore, this number $\color{blue}{-15}$.

The second number is also negative because it is to the *left* of zero. To find this number, we count the number of jumps between zero and the number.

![](<../Source/1.2.1. Negative Numbers/Images/e9580820a16d41bc93da9d3bc8a4cff4.png>)

Each jump represents a distance of $5$, and we have $1$ jump. Therefore, this number $\color{red}{-5}$.

Therefore, the numbers are $-15$ and $-5$.
