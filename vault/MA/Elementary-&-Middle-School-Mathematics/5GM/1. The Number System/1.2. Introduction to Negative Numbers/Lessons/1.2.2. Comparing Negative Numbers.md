## Introduction

Let's consider the number $-1$. We can plot it on a number line, as follows:

![](<../Source/1.2.2. Comparing Negative Numbers/Images/f9c9f1a2ed9f2c20547990ff1da72d1f.png>)

All of the numbers to the *left* of $-1$ are *less than* $-1$.

![](<../Source/1.2.2. Comparing Negative Numbers/Images/38f0396b9a48d1f902385b54b9c4665f.png>)

On the other hand, any number to the *right* of $-1$ is *greater than* $-1$.

![](<../Source/1.2.2. Comparing Negative Numbers/Images/3b6c91cb7f9cb0e0a459fb8a4092232a.png>)

The same idea is true for all numbers. For any given number:

- all numbers to the left on a number line are *smaller*
- all numbers to the right on a number line are *larger*

## Comparing a Positive and Negative Number

**Example:** Which symbols could replace the empty box below to make the statement true?
$1 \,\,\square\,\, -2$

**Explanation**

First, we plot both numbers on a number line.

![](<../Source/1.2.2. Comparing Negative Numbers/Images/aed7e7f34ba71809da7de872e45d3e3b.png>)

We see that $1$ is to the right of $-2$. Therefore, $1$ is *greater than* $-2$.

So, the correct statement must be:
$1 > -2$

## Comparing Two Points on a Number Line

**Example:** Which of the following is true regarding numbers $A$ and $B$?

![](<../Source/1.2.2. Comparing Negative Numbers/Images/696e9ed336e5580cb8c3176feb05402f.png>)

1. $A < 0$
2. $0 > B$
3. $B < A$

**Explanation**

Let's analyze each statement in turn.

- Statement I is true. The number $A$ is to the left of zero. Therefore, $A$ is *smaller than* $0$, which we write as
$A < 0$.
- Statement II is true. The number $B$ is to the left of zero. Therefore, $B$ is *smaller than* $0$, which we write as
$B < 0$.
This is the same as saying that $0$ is *greater than* $B$, which we write as
$0 > B$.
- Statement III is false. The number $A$ is to the left of $A$. Therefore, $A$ is *smaller than* $B$, which we write as
$A < B$.

Therefore, the correct answer is "I and II only."
