## Introduction

When we write down a whole number, the place of each digit has a name. This idea is also true with decimals.

For example, for the number $5.{\color{blue}2}{\color{red}4}$, we can write the digits in a place value chart as follows:

| **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: |
| $5$ | **.** | $\color{blue}2$ | $\color{red}4$ |

We say that

- the digit $5$ is in the ones place,
- the digit $\color{blue}2$ is in the **tenths place**, and
- the digit $\color{red}4$ is in the **hundredths place**.

Notice that there is a column for the decimal point, too. However, the decimal point does *not* correspond to a place value.

---

<a id="identifying-a-digit-in-the-tenths-place"></a>
## Identifying a Digit in the Tenths Place

**Example:** In $21.73$, which digit is in the tenths place?

**Explanation**

Let's write down the place values:

| **tens** | **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: | ---: |
| $2$ | $1$ | **.** | $\color{blue}7$ | $3$ |

In the tenths place, we have ${\color{blue}{7}}$.

## Identifying a Digit in the Hundredths Place

**Example:** Which digit is in the hundredths place in $528.60$?

**Explanation**

Let's write down the place values:

| **hundreds** | **tens** | **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: | ---: | ---: |
| $5$ | $2$ | $8$ | **.** | $6$ | $\color{blue}0$ |

In the hundredths place, we have ${\color{blue}{0}}$.

<a id="numbers-with-three-digits-after-the-decimal-point"></a>
## Numbers With Three Digits After the Decimal Point

Let's consider the number $70.263$. Its place value chart is below:

| **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: |
| $7$ | $0$ | **.** | $2$ | $6$ | $\color{blue}3$ |

Notice that this table has a new column, which we call the **thousandths** column.

In this case, we say that $70.263$ has:

- $7$ tens
- $0$ ones
- $2$ tenths
- $6$ hundredths
- $\color{blue}3$ **thousandths**

<a id="identifying-a-digit-in-the-thousandths-place"></a>
## Identifying a Digit in the Thousandths Place

**Example:** Complete the statement:

$\qquad$ The number $98.654$ has $4$ $\underline{\phantom{{}^{55555555555}}}$.

**Explanation**

Let's write down the place values:

| **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: |
| $9$ | $8$ | **.** | $6$ | $5$ | $\color{blue}4$ |

We have $\color{blue}4$ in thousandths place, so the complete statement is "The number $98.654$ has $4$ thousandths".

<a id="writing-down-a-number-from-a-description"></a>
## Writing Down a Number From a Description

**Example:** What number has $8$ ten thousands, $5$ tens, and $1$ thousandths?

**Explanation**

Let's write down the place values. We have $8$ ten thousands, $5$ tens, and $1$ thousandths. For the other place values, we just write zero.

| **ten thousands** | **thousands** | **hundreds** | **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $8$ | $0$ | $0$ | $5$ | $0$ | **.** | $0$ | $0$ | $1$ |

So, $80,050.001$ is our number.
