## Introduction

We can use place values to express decimals in words in a systematic way.

For instance, let's figure out how to express $0.4$ in words. We start with its place value chart.

| **ones** |  | **tenths** |
| --- | ---: | ---: |
| $\color{red}0$ | **.** | $\color{blue}4$ |

To write a decimal (less than $1$) in words, we perform the following steps:

- First, since the whole number part is $\color{red}0$, we ignore it.
- Next, we write the decimal part as a whole number. Here, the decimal part is ${\color{blue}4}$, so we write *four*.
- Finally, we write the place name of the rightmost digit. Here, the rightmost digit is ${\color{blue}4}$, which has the place name *tenths*.

Putting these all together, we conclude that $0.4$ expressed in words is *four tenths*.

## Writing a Decimal With No Whole Number Part in Words

**Example:** What is $0.14$ written in words?

**Explanation**

Let's start by writing down the place values:

| **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: |
| $\color{red}0$ | **.** | $\color{blue}1$ | $\color{blue}4$ |

We have the following:

- The whole part of the number is ${\color{red}0}$. So, we ignore it.
- The decimal part of the number is $\color{blue}14$ (*fourteen*), and the rightmost digit sits at the *hundredths* place. So, we write it as *fourteen hundredths*.

Therefore, $0.14$ is *fourteen hundredths*.

## Writing Decimals With a Whole Number Part in Words

When we want to express a decimal containing a whole number part in words, we write the whole number first. Then, we proceed as usual with the decimal part.

To demonstrate, let's express the decimal $9.1$ in words. The place value chart for this number is given below.

| **ones** |  | **tenths** |
| --- | ---: | ---: |
| $\color{red}9$ | **.** | $\color{blue}1$ |

To write this decimal in words, we perform the following steps:

- First, we write the whole number part. Here, the whole part of the number is ${\color{red}9}$, so we first write *nine*.
- Then, we write *and* to represent the decimal point.
- Finally, we write the decimal part as before. The decimal part of the number is $\color{blue}1$ (*one*), and the rightmost digit sits at the *tenths* place. So, we write it as *one tenth*.

Therefore, $9.1$ expressed in words is *nine and one tenth*.

## Writing a Decimal With a Whole Number Part in Words

**Example:** What is $27.05$ written in words?

**Explanation**

Let's start by writing down the place values:

| **tens** | **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: | ---: |
| $\color{red}2$ | $\color{red}7$ | **.** | $\color{blue}0$ | $\color{blue}5$ |

We have the following:

- The whole part of the number is ${\color{red}27}$. So, we write it as *twenty-seven*.
- The decimal part of the number is $\color{blue}05$ or just $\color{blue}5$ (*five*), and the rightmost digit sits at the *hundredths* place. So, we write it as *five hundredths*.

Therefore, $27.05$ expressed in words is *twenty-seven and five hundredths*.

## Reading a Decimal With No Whole Number Part Written in Words

**Example:** What is "sixty-three hundredths" written as a decimal?

**Explanation**

We have the following:

- The whole number part is absent. We write this in a place value chart as follows:

| **hundreds** | **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
|  |  | $\color{red}0$ | **.** |  |  |  |

- The decimal part of the number is *sixty-three hundredths*, or $\color{blue}63$ *hundredths*. The key word here is **hundredths**. So, the rightmost digit ($3$) must sit at the *hundredths* place, as shown below.

| **hundreds** | **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
|  |  | $\color{red}0$ | **.** | $\color{blue}6$ | $\color{blue}3$ |  |

Therefore, *sixty-three hundredths* is $0.63$

## Reading a Decimal With a Whole Number Part Written in Words

**Example:** What is "two and ninety-four thousandths" written as a decimal?

**Explanation**

We have the following:

- The whole part is *two* $({\color{red}2})$. We write this in a place value chart as follows:

| **hundreds** | **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
|  | $\color{red}$ | $\color{red}2$ | **.** |  |  |  |

- The decimal part of the number is *ninety-four thousandths* or $\color{blue}94$ *thousandths*. The key word here is **thousandths**. So, the rightmost digit ($4$) must sit at the *thousandths* place, as shown below.

| **hundreds** | **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
|  | $\color{red}$ | $\color{red}2$ | **.** | $\color{blue}0$ | $\color{blue}9$ | $\color{blue}4$ |

Notice that the cell corresponding to the *tenths* place is filled with a zero.

Therefore, *two and ninety-four thousandths* is $2.094$
