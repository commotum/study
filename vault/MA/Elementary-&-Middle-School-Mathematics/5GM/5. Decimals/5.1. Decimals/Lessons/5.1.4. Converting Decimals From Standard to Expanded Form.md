## Introduction

The **expanded form** of a decimal number expresses the number as a sum of each digit multiplied by its place value.

To illustrate, let's write the decimal number $85.92$ in expanded form. We start by writing down the place values:

| **tens** | **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: | ---: |
| $8$ | $5$ | **.** | $9$ | $2$ |

To write the number in expanded form, we multiply each digit by its place value and add them up. So in our case, this gives:

$$
(8\times10) + (5\times 1) + \left(9\times \dfrac{1}{10}\right) + \left(2\times\dfrac{1}{100}\right)
$$

## Writing a Decimal Number in Standard Form Using Decimal Fractions

**Example:** Write $3.729$ in expanded form.

**Explanation**

We start by writing down the place values:

| **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: |
| $3$ | **.** | $7$ | $2$ | $9$ |

Now, to write the number in expanded form, we multiply each digit by its place value and add them up:

$$
(3\times 1) + \left(7\times \dfrac{1}{10}\right) + \left(2\times\dfrac{1}{100}\right) + \left(9\times\dfrac{1}{1,000}\right)
$$

## Writing a Decimal Number in Standard Form as a Sum of Decimals

Earlier, we expressed the decimal number $85.92$ in expanded form using fractions, as follows:

$$
(8\times10) + (5\times 1) + \left(9\times \dfrac{1}{10}\right) + \left(2\times\dfrac{1}{100}\right)
$$

We can also represent the same number in standard form using decimals instead of fractions. To do this, we start by writing each fraction as an equivalent decimal:

$$
(8\times10) + (5\times 1) + \left(9\times 0.1\right) + \left(2\times0.01\right)
$$

Dropping the parentheses, we get:

$$
8\times10 + 5\times 1 + 9\times 0.1 + 2\times0.01
$$

As a final answer, this is often perfectly acceptable.

Sometimes, we might want to simplify this answer even further by evaluating each of the products. By doing this, we get

$$
80 + 5 + 0.9 + 0.02
$$

## Writing a Decimal Number in Standard Form Using Decimals

**Example:** Write $6.42$ in expanded form.

**Explanation**

We need to convert the given number from standard form to expanded form.

Let's start by writing down the place values of $6.42$:

| **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: |
| $6$ | **.** | $4$ | $2$ |

From the table:

- $6$ ones is $6$, which we can write as $6\times 1$
- $4$ tenths is $0.4$, which we can write as $4\times 0.1$
- $2$ hundredths is $0.02$, which we can write as $2\times 0.01$

Therefore:

$$
6.42 = 6\times 1 + 4\times 0.1 + 2\times 0.01
$$

## Converting From Standard Form With Zeros to Expanded Form

When zeros appear in the standard form of a decimal, they do not appear in the expanded form.

For example, $1.{\color{blue}0}5$ has a $\color{blue}0$ in the tenths place.

To convert this into expanded form, we start by writing down the place values.

| **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: |
| $1$ | **.** | $\color{blue}0$ | $5$ |

We have:

$\qquad$ $1$ one is $1$

$\qquad$ $\color{blue}0$ tenths is $\color{blue}0$

$\qquad$ $5$ hundredths is $0.05$

Therefore, we get

$$
1.05 = 1 + {\color{blue}0} + 0.05
$$

But adding zero doesn't change a number, so we can remove it. Hence, our final answer is:

$$
1.05 = 1 + 0.05
$$

## Writing a Decimal Number in Expanded Form With Fractions When a Digit is Zero

**Example:** Write $81.303$ in expanded form.

**Explanation**

Let's start by writing down the place values.

| **tens** | **ones** |  | **tenths** | **hundredths** | **thousandths** |
| --- | ---: | ---: | ---: | ---: | ---: |
| $8$ | $1$ | **.** | $3$ | $0$ | $3$ |

Now, to write the number in expanded form, we multiply each digit by its place value and add them up:

$$
81.303 = (8\times10) + ({1 \times 1}) + \left(3 \times\dfrac{1}{10}\right) +\left(0 \times\dfrac{1}{100}\right) +\left(3 \times\dfrac{1}{1,000}\right)
$$

Since

$$
0 \times\dfrac{1}{100} = 0
$$

we can simplify as follows:

$$
81.303 = (8\times10) + ({1 \times 1}) + \left(3 \times\dfrac{1}{10}\right) +\left(3 \times\dfrac{1}{1,000}\right)
$$

## Writing a Decimal Number in Standard Form With Decimals When a Digit is Zero

**Example:** What is the missing number in the following equality?

$562.01 = 5 \times 100 + 6 \times 10 + 2 \times 1 + \underline{\phantom{{}^{55555555555}}}$

**Explanation**

We need to convert the given number from standard form to expanded form.

Let's start by writing down the place values of $562.01$:

| **hundredts** | **tens** | **ones** |  | **tenths** | **hundredths** |
| --- | ---: | ---: | ---: | ---: | ---: |
| $5$ | $6$ | $2$ | **.** | $0$ | $1$ |

$\qquad$ $5$ hundreds is $500$, which we can write as $5 \times 100$

$\qquad$ $6$ tens is $60$, which we can write as $6 \times 10$

$\qquad$ $2$ ones is $2$, which we can write as $2 \times 1$

$\qquad$ $0$ tenths is $0$

$\qquad$ $1$ hundredth is $0.01$, which we can write as $1 \times 0.01$

Hence:

$$
562.01 = 5 \times 100 + 6 \times 10 + 2 \times 1 + 1\times 0.01
$$

So, the missing number is $1 \times 0.01$.
