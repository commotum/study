## Introduction

We can use the standard algorithm to divide three-digit decimals by two-digit decimals.

As an example, let's solve the following division problem:

$$
92.4 \div 22
$$

We start by writing down our problem using long division notation, keeping the decimal point in the dividend:

| $22$$\!\require{enclose}\enclose{longdiv}{9 {\:\phantom{\mid}} 2 {\,\bbox[2px, lightgray]{\color{blue}.}\,} 4}$ |
| --- |

We also bring the decimal point up into the quotient, placing it directly above the decimal point in the dividend:

| $\: \phantom{0} {\:\phantom{\mid}} \phantom{0} {\:\phantom{\mid}} \bbox[2px, lightgray]{\color{blue}.}$$22$$\!\require{enclose}\enclose{longdiv}{9 {\:\phantom{\mid}} 2 {\,\bbox[2px, lightgray]{\color{blue}.}\,} 4}$ |
| --- |

Now, сarrying out the long division process, as usual, we get:

| $4$$\!\!\!. 2$$22$$\!\require{enclose}\enclose{longdiv}{9 {\:\phantom{\mid}} 2 {\,. \,} 4}$$-\!\!\!\!$$8$$8$$4$$4$$-\!\!\!\!$$4$$4$$0$ |
| --- |

Therefore, we conclude that

$$
92.4 \div 22 = 4.2\,
$$

## Dividing Decimals by Decimals Using the Standard Algorithm

Using the standard algorithm requires the divisor to be a whole number. However, we can often manipulate a division problem using our understanding of fractions to give an equivalent problem where the standard algorithm *can* be applied.

As an example, let's consider the following division problem:

$$
8.82 \div 2.5
$$

We cannot apply the standard algorithm because the divisor $(2.5)$ is not a whole number.

However, if we express this division problem as a fraction, we get

$$
\dfrac{8.82}{2.5}
$$

Now, we need to create a whole number in the denominator. To do this, we make an equivalent fraction by multiplying both the numerator and denominator by $10$:

$$
\dfrac{8.82 \times 10}{2.5 \times 10} = \dfrac{88.2}{25}
$$

So, instead of our original problem, we can now solve the equivalent problem

$$
88.2 \div 25
$$

Let's write down the problem using long division notation, keeping the decimal point in the dividend:

| $25$$\!\require{enclose}\enclose{longdiv}{8 {\:\phantom{\mid}}8 {\,\bbox[2px, lightgray]{\color{blue}.}\,} 2}$ |
| --- |

We also bring the decimal point up into the quotient, placing it directly above the decimal point in the dividend:

| $\:\: {\:\phantom{\mid \mid}} {\:\phantom{\mid \mid}} {\phantom{\mid \mid}} \bbox[2px, lightgray]{\color{blue}.}$$25$$\!\require{enclose}\enclose{longdiv}{8 {\:\phantom{\mid}}8 {\,\bbox[2px, lightgray]{\color{blue}.}\,} 2}$ |
| --- |

Now, сarrying out the long division process, as usual, we get:

| $3$$\!\!. 5$$2$$8$$\!25$$\!\!\require{enclose}\enclose{longdiv}{\,8 {\:\phantom{\mid}} 8 {\,. \,}2 {\:\phantom{\mid}} 0 {\:\phantom{\mid}} 0}$$-\!\!\!\!$$7$$5$$1$$3$$2$$-\!\!\!\!$$1$$2$$5$$7$$0$$-\!\!\!\!$$5$$0$$2$$0$$0$$-\!\!\!\!$$2$$0$$0$$0$ |
| --- |

Therefore, we conclude that

$$
8.82 \div 2.5 = 3.528 \,
$$

## Dividing Decimals by Decimals

**Example:** Dave was paid $\[math]7.47$ for $1.2$ hours of work. What was Dave's hourly rate?

**Explanation**

To determine Dave's hourly rate, we have to calculate

$$
7.47 \div 1.2
$$

We can write this division problem as a fraction, as follows:

$$
\dfrac{7.47}{1.2}
$$

Multiplying the numerator and denominator by $10$, we get a whole number in the denominator:

$$
\dfrac{7.47 \times 10}{1.2 \times 10} = \dfrac{74.7}{12}
$$

So the problem is equivalent to $74.7 \div 12$.

Next, we write down the problem using long division notation, keeping the decimal point in the dividend:

| $12$$\!\require{enclose}\enclose{longdiv}{7 {\:\phantom{\mid}} 4 {\,\bbox[2px, lightgray]{\color{blue}.}\,} 7}$ |
| --- |

We also bring the decimal point up into the quotient, placing it directly above the decimal point in the dividend:

| $\:\:\: \phantom{0} {\:\phantom{\mid}} \phantom{0} {\:\phantom{\mid}} \bbox[2px, lightgray]{\color{blue}.}$$12$$\!\require{enclose}\enclose{longdiv}{7 {\:\phantom{\mid}} 4 {\,\bbox[2px, lightgray]{\color{blue}.}\,} 7}$ |
| --- |

Now, сarrying out the long division process, as usual, we get:

| $6$$\!\!. 2$$2$$5$$12$$\!\!\require{enclose}\enclose{longdiv}{7 {\:\phantom{\mid}} 4 {\,. \,} 7 {\:\phantom{\mid}} 0 {\:\phantom{\mid}} 0}$$-\!\!\!\!$$7$$2$$2$$7$$-\!\!\!$$2$$4$$3$$0$$-\!\!\!$$2$$4$$6$$0$$-\!\!\!$$6$$0$$0$ |
| --- |

So,

$$
7.47 \div 1.2 = 6.225
$$

Therefore, Dave was paid $\[math]6.225$ per hour.
