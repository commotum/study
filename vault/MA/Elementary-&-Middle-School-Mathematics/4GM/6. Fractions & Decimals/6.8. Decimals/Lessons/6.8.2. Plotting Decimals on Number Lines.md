## Introduction

We can plot decimals on number lines, just as we do with fractions and mixed numbers.

To demonstrate how this works, let's plot the following decimal on a number line:

$$
0.8
$$

First, since $0.8$ lies between the whole numbers $0$ and $1$, we start by creating a number line between these two whole numbers.

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/3f7dcc16ae1d791fcc7ae33d511ec192.png>)

Now, notice that $0.8$ has one decimal place. In other words, the decimal part goes up to *tenths.* So, we split the line segment between $0$ and $1$ into $10$ equal parts. Each part gives

$$
\dfrac{1}{10} = 0.1
$$

(one-tenth) of a whole.

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/611364ce4c09179699910ebbc5a5976f.png>)

The decimal ${\color{red}0}.\!{\color{blue}8}$ has ${\color{red}0}$ ones and ${\color{blue}8}$ tenths.
So, we start at the point $\color{red}0$ and move $\color{blue}8$ steps to the right:

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/21bd33796170aeab30a24c5bd696e64d.png>)

Therefore, we conclude that the decimal $0.8$ plotted on a number line looks as follows:

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/4c8ebcb6bca27b01fdf839dfadceae49.png>)

Let's now look at an example of a decimal containing a whole number part *and* a decimal part.

## Plotting Decimals Up to Hundredths on a Number Line

We can plot decimals up to hundredths on a number line in a similar way.

For example, let's plot the following decimal on a number line:

$$
1.26
$$

First, notice that $1.26$ lies between two *tenths*, namely $1.2$ and $1.3$. So, we start by creating a number line between these tenths.

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/6e836fec790d70a1c00c31d47719f124.png>)

Now, notice that $1.26$ has *two* decimal places. In other words, the decimal part goes up to *hundredths.* So, we split the line segment between $1.2$ and $1.3$ into $10$ equal parts. Each part gives

$$
\dfrac{1}{100} = 0.01
$$

(one-hundredth) of a whole.

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/cbf1ca7120307b923418c65d74d5073b.png>)

The decimal ${\color{red}1}.\!{\color{red}2}{\color{blue}6}$ has ${\color{red}1}$ one, ${\color{red}2}$ tenths, and $\color{blue}6$ hundredths.
So, we start at the point $\color{red}1.2$ and move $\color{blue}6$ steps to the right:

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/8f555f4b9c2a9cd0402c10c612580c96.png>)

Therefore, we conclude that the decimal $1.26$ plotted on a number line looks as follows:

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/2e25ec18fb140c4b6e89ec1149e895a6.png>)

## Plotting Decimals Up to Hundredths

**Example:** What decimal is shown as the plotted point on the number line below?

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/21cc24813f35f9ce32ae213fd8f2b885.png>)

**Explanation**

The line segment between each tenth is split into $10$ equal parts. So, each part gives

$$
\dfrac{1}{100} = 0.01
$$

(one-hundredth) of a whole.

Notice that our point is $\color{blue}4$ steps to the right of ${\color{red}0.0}$.

![](<../Source/6.8.2. Plotting Decimals on Number Lines/Images/3f9dbec94266b8598113a662b6aab1ac.png>)

Hence, the decimal has ${\color{red}0}$ ones, ${\color{red}0}$ tenths, and ${\color{blue}4}$ hundredths. Therefore, the point represents the decimal $\bbox[3pt, Gainsboro]{\color{blue}{\color{red}0.0}{\color{blue}4}}$.
