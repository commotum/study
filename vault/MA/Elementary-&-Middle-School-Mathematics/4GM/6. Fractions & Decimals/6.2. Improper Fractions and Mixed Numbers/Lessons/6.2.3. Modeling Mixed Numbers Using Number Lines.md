## Introduction

We can represent mixed numbers with number lines.

For example, let's write the number shown on the number line below as a mixed number.

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/fb88c92d4c5779868600d0189699d514.png>)

First, notice that the line segment from $0$ to $1$ is split into $\color{blue}3$ equal parts.

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/b5df9d555e3e5d2465966022cfc4426a.png>)

We can land on our point by making $\color{red}1$ whole step plus $\color{blue}2$ part steps (out of a possible ${\color{blue}{3}})$.

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/8e350f825fa881f5181f90439808a8dd.png>)

Therefore, the mixed number is

$$
{\color{red}1}{\color{blue}\dfrac{2}{3}}
$$

<a id="identifying-mixed-numbers-using-number-lines"></a>
## Identifying Mixed Numbers Using Number Lines

**Example:** What mixed number is shown on the number line?

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/c5d5506c4844efccf3a73c2f6fa59722.png>)

**Explanation**

The line segment from $0$ to $1$ is split into $\color{blue}6$ equal parts. Each part represents

$$
\dfrac{1}{\color{blue}6}
$$

of a whole.

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/1cf32f123e3f1f58047b7226300ad5f1.png>)

Starting from zero, we land on our point by making $\color{red}2$ whole steps plus $\color{blue}1$ part step:

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/94e3752ec43416082cc2e879baa027fc.png>)

Therefore, the mixed number is

$$
{\color{red}2}{\color{blue}\dfrac{1}{6}}
$$

## Identifying Mixed Numbers With Non-Unit Fractional Parts

**Example:** What mixed number is shown on the number line?

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/ad95ce2f27751c9f5670050fc0f37a9e.png>)

**Explanation**

The line segment from $0$ to $1$ is split into $\color{blue}4$ equal parts. Each part represents

$$
\dfrac{1}{\color{blue}4}
$$

of a whole.

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/4ae3565a5ac4a7f72efd178a58d7f08b.png>)

Starting from zero, we land on our point by making $\color{red}2$ whole steps plus $\color{blue}3$ part steps (out of a possible ${\color{blue}{4}}$).

![](<../Source/6.2.3. Modeling Mixed Numbers Using Number Lines/Images/0a8aa860c2f5555ac4a81e4c027e5267.png>)

Therefore, the mixed number is

$$
{\color{red}2}{\color{blue}\dfrac{3}{4}}
$$
