## Using Area Models to Represent Multiplication Problems

We can use area models to represent two-digit by two-digit multiplication problems.

For example, let's consider the following area model:

![](<../Source/4.3.5. Two-Digit by Two-Digit Multiplication Using Area Models/Images/761c501e6dad0361d156fbb8518ee2df.png>)

Now, let's look at the big rectangle:

- its length is $10+2=12$
- its width is $10+5=15$
- its area is $100 + 20 + 50 + 10 = 180$

Therefore, this area model can be used to represent the following multiplication problem:

$$
12 \times 15 = 180
$$

## Interpreting an Area Model

**Example:** The area model above can be used to represent the following multiplication problem:

![](<../Source/4.3.5. Two-Digit by Two-Digit Multiplication Using Area Models/Images/de3e3de30f7847b2007cd63d9e6f607f.png>)

$00$

What is the missing number?

**Explanation**

Let's look at the big rectangle:

- its length is $30+9=39$
- its width is $20+3=23$
- its area is $600 + 180 + 90 + 27 = 897$

Hence, this area model can be used to represent the following multiplication problem:

$$
39 \times 23= \fbox{897}
$$

Therefore, the missing number is $897$.

## Using an Area Model To Multiply Two-Digit Numbers

**Example:** Using the area model below, find the value of $97 \times 51$.

![](<../Source/4.3.5. Two-Digit by Two-Digit Multiplication Using Area Models/Images/12af3d448f5539887486c4999824085a.png>)

**Explanation**

First, we set up the model. The numbers $97$ and $51$ can be expressed in expanded form as ${\color{blue}90}+{\color{blue}7}$ and ${\color{red}50}+{\color{red}1}$.
So, we place ${\color{blue}90}$ and ${\color{blue}7}$ above the rectangles and ${\color{red}50}$ and ${\color{red}1}$ to the left of the rectangles.

![](<../Source/4.3.5. Two-Digit by Two-Digit Multiplication Using Area Models/Images/ac6b7dfbd40dcd882e54e55fb5a2ca2b.png>)

Next, we compute the missing values. This gives the following picture:

![](<../Source/4.3.5. Two-Digit by Two-Digit Multiplication Using Area Models/Images/683e04f33a04bf14904da11a9c9982ad.png>)

Now, notice the following regarding the big rectangle:

- its length is $90+7=97$
- its width is $50+1=51$
- its area is $4,500 + 350 + 90 + 7 = 4,947$

Therefore, this area model can be used to represent the following multiplication problem:

$$
97 \times 51 = 4,947
$$
