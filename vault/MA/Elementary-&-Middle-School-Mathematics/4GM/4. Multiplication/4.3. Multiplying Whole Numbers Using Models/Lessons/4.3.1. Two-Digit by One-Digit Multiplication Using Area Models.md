## Introduction

An **area model** is a large rectangle containing two (or more) smaller rectangles. A sketch of a typical area model is shown below:

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/f5ce1648c064b626d55775486049673d.png>)

We complete this area model by finding the areas of the blue and pink rectangles and placing these values on our diagram:

- Let's first look at the blue rectangle (the one on the left-hand side). Its length is $10$, and its width is $4$. Therefore, the area of this rectangle must be
$10 \times 4 = {\color{blue}40}$.
Let's add this to our model:![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/c94ab98f8fd2d4271c80474a6128d980.png>)
- Now, let's look at the pink rectangle (the one on the right-hand side). Its length is $6$, and its width is $4$. Therefore, the area of this rectangle must be
$6 \times 4 = {\color{blue}24}$.
Let's add this to our model:![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/6ee89207b2cc61114d0559599956f0c4.png>)

And we're done!

**Note**: Area models are not usually drawn to scale. In other words, the lengths shown on the model might not be in the correct proportion.

## Using Area Models to Represent Multiplication Problems

Area models can be used to represent multiplication problems.

For example, let's return to the following area model:

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/1f1e1a399fa3ab9f598607de8b4044d2.png>)

Now, let's look at the big rectangle:

- its length is $10+6=16$
- its width is $4$
- its area is ${\color{blue}{40}}+{\color{blue}{24}}=64$

Since the area of the big rectangle equals its length multiplied by its width, this model represents the following multiplication problem:

$$
16 \times 4= 64
$$

<a id="interpreting-an-area-model"></a>
## Interpreting an Area Model

**Example:** The area model above can be used to represent the following multiplication problem:

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/ab1859ce4f7fba19d0cc9a543b8538ff.png>)

$00$

What is the missing number?

**Explanation**

Let's look at the big rectangle:

- its length is $30+2=32$
- its width is $6$
- its area is $180+12=192$

Hence, this area model can be used to represent the following multiplication problem:

$$
32 \times \fbox{6}= 192
$$

Therefore, the missing number is $6$.

<a id="multiplying-one-digit-numbers-by-two-digit-numbers-using-area-models"></a>
## Multiplying One-Digit Numbers by Two-Digit Numbers Using Area Models

Let's solve the following multiplication problem using an area model:

$$
{\color{blue}{16}} \times {\color{red}{8}}
$$

The number $16$ in expanded form is

$$
{\color{blue}{16}} = {\color{blue}10}+{\color{blue}6}
$$

So, we place ${\color{blue}10}$ and ${\color{blue}6}$ above the left and right rectangles, and ${\color{red}8}$ to the left of the big rectangle.

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/74c6922b1eee202a743eeadd3fe731cb.png>)

Next, we compute the areas of the blue and pink rectangles. This gives the following picture:

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/3fbce27a9177263c38d07407883ecdd0.png>)

Now, notice the following regarding the big rectangle:

- its length is $10 + 6 = 16$
- its width is $8$
- its area is $80 + 48 = 128$

Therefore, this area model can be used to represent the following multiplication problem:

$$
16 \times 8 = 128
$$

## Multiplying Two-Digit Numbers by One-Digit Numbers

**Example:** Using the area model below, find the value of $53 \times 8$.

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/97bda6c0f56a68f89804a5bc5226b833.png>)

**Explanation**

First, we set up the model. The number $53$ can be expressed in expanded form as ${\color{blue}50}+{\color{blue}3}$. So, we place ${\color{blue}50}$ and ${\color{blue}3}$ above the left and right rectangles, respectively, and ${\color{red}8}$ to the left of the big rectangle.

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/d43f24d6f36271ac80362a23a2c65d0d.png>)

Next, we compute the areas of the blue and pink rectangles. This gives the following picture:

![](<../Source/4.3.1. Two-Digit by One-Digit Multiplication Using Area Models/Images/6be0c7a59162730bd012a7bac1fc8156.png>)

Now, notice the following regarding the big rectangle:

- its length is $50 + 3 = 53$
- its width is $8$
- its area is $400 + 24 = 424$

Therefore, this area model can be used to represent the following multiplication problem:

$$
53 \times 8 = 424
$$
