## Introduction

Let's consider the following area model:

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/058da50af7d5bb27f7a3732ff819a491.png>)

To complete this area model, we need to look at the blue, pink, and orange rectangles:

- Let's first look at the blue rectangle (the one on the left-hand side). Its length is $500$, and its width is $2$. Therefore, the area of this rectangle must be
$500 \times 2 = {\color{blue}1,000}$.
Let's add this to our model.![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/a8f0726b4817cf802a30bdbc63710348.png>)
- Now, let's look at the pink rectangle (the one in the center). Its length is $90$, and its width is $2$. Therefore, the area of this rectangle must be
$90 \times 2 = {\color{blue}180}$.
Let's add this to our model.![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/6051d1991e56cfc983f38fa43f97b2d8.png>)
- Finally, let's look at the orange rectangle (the one on the right-hand side). Its length is $6$, and its width is $2$. Therefore, the area of this rectangle must be
$6 \times 2 = {\color{blue}12}$.
Let's add this to our model.![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/612ec6dc94fa59aa26f67b8da290783d.png>)

And we're done!

**Note**: Remember, area models are usually not drawn to scale.

## Interpreting an Area Model

**Example:** The area model above can be used to represent the following multiplication problem:
$00$

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/3928b12b5e23526a5ec79b24e945dbc1.png>)

What is the missing number?

**Explanation**

Let's look at the big rectangle:

- its length is $200 + 30 + 7 = 237$
- its width is $6$
- its area is $1,200 + 180 + 42 = 1,422$

Hence, this area model can be used to represent the following multiplication problem:
$1, 422$

Therefore, the missing number is $1,422$.

## Multiplying Numbers Using a Partially Filled Area Model

**Example:** Using the area model below, find the value of $223 \times 5$.

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/0132f5439f43688510172fc446aab2d3.png>)

**Explanation**

First, we compute the areas of the blue, pink, and orange rectangles. This gives the following picture:

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/39f8546b3c466e76bc8069d1d6bd830e.png>)

Now, notice the following regarding the big rectangle:

- its length is $200 + 20 + 3 = 223$
- its width is $5$
- its area is $1,000 + 100 + 15 = 1,115$

Therefore, this area model can be used to represent the following multiplication problem:

$$
223 \times 5 = 1,115
$$

<a id="multiplying-three-digit-numbers-by-one-digit-numbers"></a>
## Multiplying Three-Digit Numbers by One-Digit Numbers

**Example:** Using the area model below, find the value of $754 \times 3$.

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/360e08e5ec70337e0265c749cbd3ba0e.png>)

**Explanation**

First, we set up the model. The number $754$ can be expressed in expanded form as ${\color{blue}700} + {\color{blue}50} + {\color{blue}4}$. So, we place ${\color{blue}700}$, ${\color{blue}50}$, and ${\color{blue}4}$ above the left, center, and right rectangles, respectively, and ${\color{red}3}$ to the left of the big rectangle.

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/d3a7406b6e5dc44ad507627ff0d6f40f.png>)

Next, we compute the areas of the blue, pink, and orange rectangles. This gives the following picture:

![](<../Source/4.3.2. Multi-Digit by One-Digit Multiplication Using Area Models/Images/e74e94eb885e745fb1cdb4e0b5c67ffa.png>)

Now, notice the following regarding the big rectangle:

- its length is $700 + 50 + 4 = 754$
- its width is $3$
- its area is $2,100+150 + 12 = 2,262$

Therefore, this area model can be used to represent the following multiplication problem:

$$
754 \times 3 = 2,262
$$
