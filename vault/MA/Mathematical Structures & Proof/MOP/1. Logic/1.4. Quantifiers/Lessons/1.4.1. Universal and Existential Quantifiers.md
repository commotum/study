## Introduction

A quantifier is a special symbol (operation) that may transform a predicate into a statement.

The **universal quantifier** "$\forall$" means "for all." The formula
$\forall x \in U, \, P(x)$
means that *every* $x$ in the universal set $U$ gives a true statement when substituted into the predicate $P$.

For example,

$$
\forall a \in \mathbb{R}^+,\, \sqrt{a} > 0
$$

reads as follows:

$\qquad$ **For all** $a \in \mathbb{R}^+$, $\sqrt{a} > 0$

This can be further rephrased using plain English as simply:

$\qquad$ *The square root of any positive real number is positive.*

Sometimes, we can omit the "$\in U$" part if the domain is clear from the context and write $\forall x, \, P(x)$.

For example, if it's clear that $n$ is an integer, then the following is a valid statement involving the universal quantifier:

$$
\forall n,\, (2 \mid n)
$$

In plain English, we might say the following:

$\qquad$ *The number two divides any integer.*

Note that this statement is *false*.

## Translating Statements Involving Universal Quantifiers

**Example:** $\qquad$ $\forall x \in \mathbb{Q}, \,$ $\pi x$ is irrational

Which of the following expresses the statement given above?

1. There are rational numbers such that $\pi x$ is irrational.
2. The product of any rational number and $\pi$ is irrational
3. There exists a rational number $x$ such that $\pi x$ is rational.

**Explanation**

The universal quantifier "$\forall$" means "for all." So, our quantified statement reads as follows:

$\qquad$ **For all** $x \in \mathbb{Q}, \,$ $\pi x$ is irrational.

This can be further simplified as follows:

$\qquad$ The product of any rational number and $\pi$ is irrational.

Therefore, the answer is "II only."

**Note:** This statement is false since zero is rational and $\pi\cdot 0$ is also rational.

## The Formal Definition of the Universal Quantifier

Let's now consider the formal definition of the universal quantifier in connection to predicates of one variable.

The **universal quantification** of a predicate $P(x)$, defined over the universal set $U$, transforms this predicate into a statement that we write as
$\forall x \in U, \, P(x)$.
This statement is true if the predicate $P(x)$ is true on the *entire* universal set $U$, i.e. if the truth set $T_P$ of the predicate equals the universal set $U{:}$
$T_P = U$

For example, consider the quantified statement

$$
\forall a \in \mathbb{R},\, \sqrt{a} > 0
$$

Notice that the universal set is

$$
U = \mathbb{R}
$$

and the truth set of the underlying predicate

$$
P(a): \:\: \sqrt{a} > 0
$$

is

$$
T_P = (0,\infty)
$$

Since $T_P$ doesn't coincide with the universal set, the statement $\forall a \in \mathbb{R},\, \sqrt{a} > 0$ is false.

<a id="identifying-true-statements-involving-universal-quantifiers"></a>
## Identifying True Statements Involving Universal Quantifiers

**Example:** $\qquad$ $P(n)$: $\dfrac{n}{3} \in \mathbb{Q}$ or $\sqrt{n}\in \mathbb{N}$.

Given that the above predicate is defined over the universal set $\mathbb{N}$, which of the following statements are true?

1. The truth set of $P(n)$ is $\emptyset$.
2. The truth set of $P(n)$ is $\mathbb{N}$.
3. $\forall n \in \mathbb{N}, \, P(n)$.

**Explanation**

The *universal quantification* of a predicate $P(x)$, defined over the universal set $U$, transforms this predicate into a statement that we write as
$\forall x \in U, \, P(x)$.
This statement is true if the predicate $P(x)$ is true on the entire universal set $U$, i.e. if the truth set $T_P$ of the predicate coincides with the universal set $U{:}$
$T_P = U$

First, notice that:

- the truth set of "$\dfrac{n}{3} \in \mathbb{Q}$" is $\mathbb{N}$, and
- the truth set of "$\sqrt{n}\in \mathbb{N}$" is $\{n=m^2: m \in \mathbb{N} \} = \{1,4,9,16, 25, \ldots \}$.

So, the truth set of our predicate is

$$
T_P = \mathbb{N} \cup \{1,4,9,16, 25, \ldots \} =\mathbb N
$$

With that in mind, let's inspect each of the given statements.

- Statement I is false. The truth set is *not* empty.
- Statement II is true. Indeed, $T_P= \mathbb{N}$.
- Statement III is true. Since $T_P$ coincides with the universal set, the statement $\forall n \in \mathbb{N}, \, P(n)$ is true.

Therefore, the correct answer is "II and III only."

<a id="the-existential-quantifier"></a>
## The Existential Quantifier

The existential quantifier "$\exists$" means "there exists". The formula

$\exists x \in U, \, P(x)$
means that there is *at least one* element in the universal set $U$ that gives a true statement when substituted into the predicate $P$.

For example,
$\exists n \in \mathbb{Z}, \, 2 \not\mid n$
reads as follows:

$\qquad$ **There exists** $n \in \mathbb{Z}$ **such that** $2 \not\mid n$.

This can be further rephrased using plain English as simply:

$\qquad$ *There is an integer that is odd.*

Similar to the universal quantifier, we can simply write $\exists x, \, P(x)$ if $U$ is clear from the context.

<a id="translating-statements-involving-existential-quantifiers"></a>
## Translating Statements Involving Existential Quantifiers

**Example:** $\qquad$ $\exists\, a \in \mathbb{R}, \, \sqrt{a} > a^2$.

Which of the following expresses the statement given above?

1. There does not exist a real number whose square root is greater than its square.
2. For every real number, its square root is greater than its square.
3. There exists a real number whose square root is greater than its square

**Explanation**

The existential quantifier "$\exists$" means "there exists." So, our quantified statement reads as follows:

$\qquad$ **There exists** $a \in \mathbb{R}$ **such that** $\sqrt{a} > a^2$.

This can be further simplified as follows:

$\qquad$ There exists a real number whose square root is greater than its square.

Therefore, the correct answer is "III only."

**Note:** This statement is true.

<a id="the-formal-definition-of-the-existential-quantifier"></a>
## The Formal Definition of the Existential Quantifier

Finally, let's consider the formal definition of the existential quantifier.

The **existential quantification** of a predicate $P(x)$, defined over the universal set $U$, transforms this predicate into a statement that we write as
$\exists x \in U, \, P(x)$.
This statement is true if the predicate $P(x)$ is true for at least one element $x\in U$, i.e., if the truth set $T_P$ of the predicate is not empty:

$$
T_P \neq \emptyset
$$

For example, consider the quantified statement

$$
\exists n \in \mathbb{Z}, \, 2 \not\mid n
$$

Notice that the universal set is

$$
U = \mathbb{Z}
$$

and the truth set of the underlying predicate

$$
P(n): \:\: 2 \not\mid n
$$

is

$$
T_P = \{\pm 1,\pm 3, \pm 5, \ldots \}
$$

the set of odd numbers. Since $T_P$ is not empty, the statement $\exists n \in \mathbb{Z}, \, 2 \not\mid n$ is true.

<a id="identifying-true-statements-involving-existential-quantifiers"></a>
## Identifying True Statements Involving Existential Quantifiers

**Example:** Consider the following predicate:

$\qquad$ $P(x)$: $x^2 \in \mathbb{N}$ and $x \geq 0$

Given that this predicate is defined over the universal set $\mathbb{Z}$, which of the following statements are true?

1. The truth set of $P(x)$ is $\emptyset$.
2. The truth set of $P(x)$ is $\mathbb{Z}^+$.
3. $\exists x \in \mathbb{Z}, \, P(x)$.

**Explanation**

The *existential quantification* of a predicate $P(x)$, defined over the universal set $U$, transforms this predicate into a statement that we write as
$\exists x \in U, \, P(x)$.
This statement is true if the predicate $P(x)$ is true for a single element $x\in U$, i.e., if the truth set $T_P$ of the predicate is not empty:

$$
T_P \neq \emptyset
$$

First, notice that:

- the truth set of "$x^2 \in \mathbb{N}$" is the set $\mathbb{Z}\setminus \{0\}$, and
- the truth set of "$x \geq 0$" is $\mathbb{Z}_{0}^+$.

So, the truth set of our predicate is

$$
T_P = \big(\mathbb{Z}\setminus \{0\} \big) \cap \mathbb{Z}_{0}^+ = \mathbb{Z}^+
$$

With that in mind, let's inspect each of the given statements.

- Statement I is false. The truth set is *not* empty.
- Statement II is true. Indeed, $T_P = \mathbb{Z}^+$.
- Statement III is true. Since $T_P$ is *not* empty, the statement $\exists x \in \mathbb{Z}, \, P(x)$ is true.

Therefore, the correct answer is "II and III only."
