## Introduction

Recall that the distance between vertices $u$ and $v$ in an unweighted undirected graph, $d(u,v)$, is the length (i.e., the number of edges) of the shortest path from $u$ to $v$. If no path from $u$ to $v$ exists, we say that the distance is $\infty$.

In a simple undirected unweighted graph $G=(V,E)$ with $n$ vertices $v_1, v_2, \ldots, v_n$, the **distance matrix** $D$ of the graph is an $n \times n$ matrix (table), where the entry $a_{ij}$ at the intersection of the $i$th row and the $j$th column equals the *distance* between the vertices $v_i$ and $v_j$.

Notice that, according to this definition:

- If no path exists between $v_i$ and $v_j$, then the entry $a_{ij}$ is $\infty$.
- If $i=j$ (i.e., it is the same vertex), then the entry $a_{ii}$ is $0$.
- The distance matrix of an undirected graph is symmetric about the main diagonal.

Let's look at an example of how to build the distance matrix for the graph below.

![](<../Source/7.4.4. Distance Matrices/Images/573f222dae5b9df7c51804281128625a.png>)

We start with a square $4 \times 4$ matrix with $0$s on the main diagonal and examine every pair of vertices to determine the remaining matrix entries.

- The path $v_2-v_3-v_4$ has two edges and is the shortest path between $v_2$ and $v_4$. Hence, we write $2$ in the entry $a_{24}$ and, by symmetry, in the entry $a_{42}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  |  |
| $v_2$ |  | $0$ |  | $2$ |
| $v_3$ |  |  | $0$ |  |
| $v_4$ |  | $2$ |  | $0$ |

- Since the vertices $v_2$ and $v_3$ are adjacent, the shortest path between them is $1$. Hence, we write $1$ in the entry $a_{23}$ and, by symmetry, in the entry $a_{32}$. Similarly, since $v_3$ and $v_4$ are adjacent, we write $1$ in the entry $a_{34}$ and $a_{43}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  |  |
| $v_2$ |  | $0$ | $1$ | $2$ |
| $v_3$ |  | $1$ | $0$ | $1$ |
| $v_4$ |  | $2$ | $1$ | $0$ |

- Since the vertex $v_1$ is isolated, the distance from it to any other vertex is $\infty$. Hence, we write $\infty$ in every entry of the $1$st row and in every entry of the $1$st column, except for $a_{11}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ | $\infty$ | $\infty$ | $\infty$ |
| $v_2$ | $\infty$ | $0$ | $1$ | $2$ |
| $v_3$ | $\infty$ | $1$ | $0$ | $1$ |
| $v_4$ | $\infty$ | $2$ | $1$ | $0$ |

The distance matrix is completed. In regular matrix notation, we can write this distance matrix as follows:

$$
\begin{bmatrix}0 & ∞ & ∞ & ∞ \\ ∞ & 0 & 1 & 2 \\ ∞ & 1 & 0 & 1 \\ ∞ & 2 & 1 & 0\end{bmatrix}
$$

## Building the Distance Matrix of a Graph

**Example:** Consider the following disconnected graph.

![](<../Source/7.4.4. Distance Matrices/Images/de10cb019137d7c57472407d9f398e01.png>)

Fill in the missing values in the following distance matrix for the graph above.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ | $v_5$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $v_1$ |  | $1$ | $1$ | $\infty$ |  |
| $v_2$ | $1$ | $0$ | $1$ |  | $1$ |
| $v_3$ | $1$ | $1$ | $0$ | $\infty$ | $1$ |
| $v_4$ | $\infty$ |  | $\infty$ | $0$ | $\infty$ |
| $v_5$ | $2$ | $1$ | $1$ | $\infty$ | $0$ |

**Explanation**

Given a fixed order of vertices $v_1, v_2, \ldots, v_n$ in an undirected graph, the *distance matrix* $D$ of the graph is an $n \times n$-matrix (table), where the element $d_{ij}$ at the intersection of the $i$th row and the $j$th column equals the distance between the vertices $v_i$ and $v_j$.

If there is no path form $v_i$ and $v_j$, we define

$$
d_{ij}=\infty
$$

The distances are calculated as follows:

- First, the entry $d_{11}$ is the distance from $v_1$ to itself, which is always zero. Hence,
$d_{11} = 0$.
- Now, recall that the distance matrix of an undirected graph is symmetric about the main diagonal. Hence, by symmetry, we have
$d_{15} = d_{51} = 2$.
- Finally, the distance from $v_2$ to $v_4$ is $\infty$ because there is no path from $v_2$ to $v_4$. Hence, we have
$d_{24} = d_{42} = \infty$.

Therefore, the distance matrix is as follows:

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ | $v_5$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $v_1$ | $\bbox[3pt,Gainsboro]{\color{blue}0}$ | $1$ | $1$ | $\infty$ | $\bbox[3pt,Gainsboro]{\color{blue}2}$ |
| $v_2$ | $1$ | $0$ | $1$ | $\bbox[3pt,Gainsboro]{\color{blue}\infty}$ | $1$ |
| $v_3$ | $1$ | $1$ | $0$ | $\infty$ | $1$ |
| $v_4$ | $\infty$ | $\bbox[3pt,Gainsboro]{\color{blue}\infty}$ | $\infty$ | $0$ | $\infty$ |
| $v_5$ | $2$ | $1$ | $1$ | $\infty$ | $0$ |

## Distance Matrix of a Directed Graph

Recall that the distance between vertices $u$ and $v$ in an unweighted directed graph, $d(u,v)$, is the length (i.e., the number of edges) of the shortest path from $u$ to $v$. If no path from $u$ to $v$ exists, we say that the distance is $\infty$.

In a simple directed unweighted graph $G=(V,E)$ with $n$ vertices $v_1, v_2, \ldots, v_n$, the **distance matrix** $D$ of the graph is an $n \times n$ matrix, where the entry $a_{ij}$ at the intersection of the $i$th row and the $j$th column represents the *distance* between the vertices $v_i$ and $v_j$.

Notice that, according to this definition:

- If no path exists between $v_i$ and $v_j$, then the entry $a_{ij}$ is $\infty$.
- If $i=j$ (i.e., it is the same vertex), then the entry $a_{ii}$ is $0$.
- The distance matrix of a directed graph is *not* symmetric about the main diagonal in general.

Let's look at an example of how to build the distance matrix for the graph below.

![](<../Source/7.4.4. Distance Matrices/Images/e1067a2ada4c6ba237654e8737c43670.png>)

We start with a square $4 \times 4$ matrix with $0$s on the main diagonal and examine every pair of vertices to determine the remaining matrix entries.

- The path $v_1 \to v_2 \to v_3 \to v_4$ has three edges and is the shortest path between $v_1$ and $v_4$. Hence, we write $3$ in the entry $a_{14}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  | $3$ |
| $v_2$ |  | $0$ |  |  |
| $v_3$ |  |  | $0$ |  |
| $v_4$ |  |  |  | $0$ |

- Similarly, the path $v_2 \to v_3 \to v_4$ has two edges and is the shortest path between $v_2$ and $v_4$. Hence, we write $2$ in the entry $a_{24}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  | $3$ |
| $v_2$ |  | $0$ |  | $2$ |
| $v_3$ |  |  | $0$ |  |
| $v_4$ |  |  |  | $0$ |

- Similarly, the path $v_4 \to v_2 \to v_3$ has two edges and is the shortest path between $v_4$ and $v_3$. Hence, we write $2$ in the entry $a_{43}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  | $3$ |
| $v_2$ |  | $0$ |  | $2$ |
| $v_3$ |  |  | $0$ |  |
| $v_4$ |  |  | $2$ | $0$ |

- We write $1$ in every entry that represents a vertex pair connected by a direct edge: $a_{12}, a_{23}, a_{34}$, and $a_{42}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ | $1$ |  | $3$ |
| $v_2$ |  | $0$ | $1$ | $2$ |
| $v_3$ |  |  | $0$ | $1$ |
| $v_4$ |  | $1$ | $2$ | $0$ |

- Finally, we write $\infty$ in all other empty cells to indicate that no paths exist between the corresponding vertex pairs.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ | $1$ | $\infty$ | $3$ |
| $v_2$ | $\infty$ | $0$ | $1$ | $2$ |
| $v_3$ | $\infty$ | $\infty$ | $0$ | $1$ |
| $v_4$ | $\infty$ | $1$ | $2$ | $0$ |

The distance matrix is completed. In regular matrix notation, we can write this distance matrix as follows:

$$
\begin{bmatrix}0 & 1 & ∞ & 3 \\ ∞ & 0 & 1 & 2 \\ ∞ & ∞ & 0 & 1 \\ ∞ & 1 & 2 & 0\end{bmatrix}
$$

## Building the Distance Matrix of a Directed Graph

**Example:** Consider the following graph.

![](<../Source/7.4.4. Distance Matrices/Images/743cdb7557e41cadd5dd2b2fef191871.png>)

| --- | ---: | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  | $3$ | $4$ |
| $v_2$ | $2$ | $0$ | $1$ | $2$ | $3$ |
| $v_3$ | $1$ | $2$ |  | $1$ | $2$ |
| $v_4$ | $2$ | $3$ | $4$ | $0$ | $1$ |
| $v_5$ | $1$ |  | $3$ | $4$ | $0$ |

**Explanation**

Given a fixed order of vertices $v_1, v_2, \ldots, v_n$ in a directed graph, the *distance matrix* $D$ of the graph is an $n \times n$-matrix (table), where the element $d_{ij}$ at the intersection of the $i$th row and the $j$th column equals the distance from the vertex $v_i$ to the vertex $v_j$.

In our case, the vertices are arranged as $v_1,v_2,v_3,v_4$, and $v_5$. Let's determine the distances.

Recall that the distance matrix of a directed graph is not symmetric in general. Some of the distances are calculated as follows:

- The distance from $v_1$ to $v_2$ is $1$ since the shortest path from $v_1$ to $v_2$ (namely, $v_1 \to v_2$) has a length of $1$. Hence, we have
$d_{12} = 1$.
- The distance from $v_1$ to $v_3$ is $2$ since the shortest path from $v_1$ to $v_3$ (namely, $v_1 \to v_2 \to v_3$) has a length of $2$. Hence, we have
$d_{13} = 2$.

$d_{33} = 0$.
- The distance from $v_5$ to $v_2$ is $2$ since the shortest path from $v_5$ to $v_2$ (namely, $v_5 \to v_1 \to v_2$) has a length of $2$. Hence,
$d_{52} = 2$.

Therefore, the distance matrix is as follows:

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ | $v_5$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ | $\bbox[3pt,Gainsboro]{\color{blue}1}$ | $\bbox[3pt,Gainsboro]{\color{blue}2}$ | $3$ | $4$ |
| $v_2$ | $2$ | $0$ | $1$ | $2$ | $3$ |
| $v_3$ | $1$ | $2$ | $\bbox[3pt,Gainsboro]{\color{blue}0}$ | $1$ | $2$ |
| $v_4$ | $2$ | $3$ | $4$ | $0$ | $1$ |
| $v_5$ | $1$ | $\bbox[3pt,Gainsboro]{\color{blue}2}$ | $3$ | $4$ | $0$ |

## Distance Matrix of a Weighted Graph

Recall that the distance between vertices $u$ and $v$ in a weighted graph, $d(u,v)$, is the length (i.e., sum of the weights of edges) of the shortest path from $u$ to $v$. If no path from $u$ to $v$ exists, we say that the distance is $\infty$.

In a weighted graph $G=(V,E)$ with $n$ vertices $v_1, v_2, \ldots, v_n$, the **distance matrix** $D$ of the graph is an $n \times n$ matrix, where the entry $a_{ij}$ at the intersection of the $i$th row and the $j$th column equals the *distance* between the vertices $v_i$ and $v_j$. Here $G$ can be either directed or undirected.

Notice that, according to this definition:

- If no path exists between $v_i$ and $v_j$, then the entry $a_{ij}$ is $\infty$.
- If $i=j$ (i.e., it is the same vertex), then the entry $a_{ii}$ is $0$.
- The distance matrix of an undirected weighted graph is symmetric about the main diagonal, but the distance matrix of a directed weighted graph is *not* symmetric in general.

Let's look at an example of how to build the distance matrix for the directed weighted graph below.

![](<../Source/7.4.4. Distance Matrices/Images/e7743d89335b75e3a757b09cb9f5e69a.png>)

We start with a square $4 \times 4$ matrix with $0$s on the main diagonal and examine every pair of vertices to determine the remaining matrix entries.

- The detour path $v_1 \to v_2 \to v_3 \to v_4$ has a weight of $2+1+5=8$ and is the shortest path between $v_1$ and $v_4$. (Notice that the alternative path $v_1 \to v_2 \to v_4$, which has fewer edges, has a greater weight of $2+7=9$.) Hence, we write $8$ in the entry $a_{14}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  | $8$ |
| $v_2$ |  | $0$ |  |  |
| $v_3$ |  |  | $0$ |  |
| $v_4$ |  |  |  | $0$ |

- Similarly, the path $v_2 \to v_3 \to v_4$ has a weight of $1+5=6$ and is the shortest path between $v_2$ and $v_4$. Hence, we write $6$ in the entry $a_{24}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ |  |  | $8$ |
| $v_2$ |  | $0$ |  | $6$ |
| $v_3$ |  |  | $0$ |  |
| $v_4$ |  |  |  | $0$ |

- We write the weight of an edge in the entry corresponding to a vertex pair connected by a direct edge with no shorter detours exist: $a_{12}, a_{23}$, and $a_{34}$.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ | $2$ |  | $8$ |
| $v_2$ |  | $0$ | $1$ | $6$ |
| $v_3$ |  |  | $0$ | $5$ |
| $v_4$ |  |  |  | $0$ |

- Finally, we write $\infty$ in all other empty cells to indicate that no paths exist between the corresponding vertex pairs.

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ |
| --- | ---: | ---: | ---: | ---: |
| $v_1$ | $0$ | $2$ | $\infty$ | $8$ |
| $v_2$ | $\infty$ | $0$ | $1$ | $6$ |
| $v_3$ | $\infty$ | $\infty$ | $0$ | $5$ |
| $v_4$ | $\infty$ | $\infty$ | $\infty$ | $0$ |

The distance matrix is completed. In regular matrix notation, we can write this distance matrix as follows:

$$
\begin{bmatrix}0 & 2 & ∞ & 8 \\ ∞ & 0 & 1 & 6 \\ ∞ & ∞ & 0 & 5 \\ ∞ & ∞ & ∞ & 0\end{bmatrix}
$$

![](<../Source/7.4.4. Distance Matrices/Images/d2117f3b84863f4e84ee864fe0c53364.png>)

| $v_1$ |  | $3$ |  | $6$ | $11$ |
| $v_2$ | $\infty$ | $0$ | $4$ | $3$ |  |
| $v_3$ | $\infty$ |  | $0$ | $6$ | $11$ |
| $v_4$ | $\infty$ | $\infty$ | $\infty$ | $0$ | $5$ |
| $v_5$ | $\infty$ | $\infty$ | $\infty$ | $\infty$ | $0$ |

**Explanation**

Given a fixed order of vertices $v_1, v_2, \ldots, v_n$ in a directed weighted graph, the *distance matrix* $D$ of the graph is an $n \times n$-matrix (table), where the element $d_{ij}$ at the intersection of the $i$th row and the $j$th column equals the distance between the vertices $v_i$ and $v_j$.

If there is no path from $v_i$ to $v_j$, we define

$$
d_{ij}=\infty
$$

In our case, the vertices are arranged as $v_1,v_2,v_3,v_4$, and $v_5$. Some of the distance calculations are here as follows:

- The entry $d_{11}$ is the distance from $v_1$ to itself, which is always zero. Hence,
$d_{11} = 0$.
- The distance from $v_1$ to $v_3$ is $7$ because the shortest path between these vertices (namely, $v_1 \to v_2 \to v_3$, not $v_1 \to v_3$) has a total length of $3+4=7$. Hence, we have
$d_{13} = 7$.
- The distance from $v_2$ to $v_5$ is $8$ because the shortest path between these vertices (namely, $v_2 \to v_4 \to v_5$) has a total length of $3+5=8$. Hence, we have
$d_{25} = 8$.
- The distance from $v_3$ to $v_2$ is $\infty$ because there is no path from $v_3$ to $v_3$. Hence, we have
$d_{32} = \infty$.

Therefore, the distance matrix is as follows:

|  | $v_1$ | $v_2$ | $v_3$ | $v_4$ | $v_5$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $v_1$ | $\bbox[3pt,Gainsboro]{\color{blue}0}$ | $3$ | $\bbox[3pt,Gainsboro]{\color{blue}7}$ | $6$ | $11$ |
| $v_2$ | $\infty$ | $0$ | $4$ | $3$ | $\bbox[3pt,Gainsboro]{\color{blue}8}$ |
| $v_3$ | $\infty$ | $\bbox[3pt,Gainsboro]{\color{blue}\infty}$ | $0$ | $6$ | $11$ |
| $v_4$ | $\infty$ | $\infty$ | $\infty$ | $0$ | $5$ |
| $v_5$ | $\infty$ | $\infty$ | $\infty$ | $\infty$ | $0$ |
