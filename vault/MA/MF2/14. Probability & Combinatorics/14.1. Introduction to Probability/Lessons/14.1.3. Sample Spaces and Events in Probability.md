## Introduction

**Probability theory** is about repeatable processes whose outcomes cannot be predicted with certainty. These processes are called **experiments** or **trials**.

- For instance, tossing a coin is a probability experiment because we don't know beforehand whether the coin will land on heads or tails.
- Likewise, rolling a die is a probability experiment because we don't know beforehand what number the die will land on.

The set of all the possible outcomes of an experiment is called the **sample space** and is usually denoted by $\mathcal{S}$. Any **subset** $E$ of the sample space $\mathcal{S}$ is called an **event**.

- In the experiment of tossing a coin, the only possible outcomes are $H$ (heads) and $T$ (tails). So, the sample space is
$\mathcal{S} = \{H, T\}$.
An example of an event is $E = \{H\}$, which refers to the event that the coin lands on heads.

- In the experiment of rolling a die, the possible outcomes are numbers $1$ through $6$. So, the sample space is
$\mathcal{S} = \{1, 2, 3, 4, 5, 6 \}$.
An example of an event is $E = \{1, 3, 5\}$, which refers to the event that an odd number is rolled.

Lastly, an experiment is said to be **deterministic** if it has only one possible outcome. For example, if a bowl contains $3$ apples and nothing else, and the experiment involves picking an item from the bowl, then the only possible outcome is that we pick an apple. So, this experiment is deterministic.

Deterministic experiments are *not* probability experiments. Unlike probability experiments, we can predict deterministic experiments with certainty.

## Identifying Probability Experiments

**Example:** Which of the following is a probability experiment or trial?

1. Calculating the value of $3^x$ for $x=2$.
2. Counting the number of continents on Earth.
3. Selecting a newborn child at random and measuring its weight.

**Explanation**

Remember that an experiment or trial is a repeatable process whose outcome cannot be predicted with certainty. With this in mind, let's inspect each process.

- I is *not* a probability experiment because it is deterministic. No matter how many times we calculate the value of $3^x$ for $x=2$, we will get the same outcome $(3^2)$ each time.
- II is *not* a probability experiment because it is deterministic. No matter how many times we count, we will get the same outcome each time.
- III is a probability experiment. Each time we repeat the experiment, we can select different children and get different weights.

In conclusion, the correct answer is "III only."

## Identifying the Sample Space of a Probability Experiment

**Example:** Richard rolls $2$ standard $6$-face dice and sums the outcomes. What is the sample space of this experiment?

**Explanation**

The sample space is the set of all the possible outcomes of the experiment.

- The lowest possible sum occurs if both dice land on $1$, in which case the sum is $1+1=2$.
- The highest possible sum occurs if both dice land on $6$, in which case the sum is $6+6=12$.

It's possible to make any integer number from $2$ to $12$ by adding the rolls of two dice. Therefore, the sample space is

$$
\mathcal S=\{2, 3, \ldots, 12\}
$$

<a id="using-probability-for-prediction"></a>
## Using Probability for Prediction

If we're given the probability of an event, and we conduct multiple experiments, then we can use the probability to predict how many times the event will occur.

For example, suppose we're flipping a coin $100$ times, and we know that the probability of the coin landing heads up is $0.5$. Based on this information, we can predict how many times (out of the $100$ flips) the coin will land heads up.

All we need to do is multiply the number of flipping experiments $(100)$ by the probability of the coin landing heads up $(0.5)$. Doing this, we get

$$
100 \times (0.5) = 50
$$

Therefore, if we flip the coin $100$ times, we expect that the coin will land heads up $50$ times.

<a id="computing-the-expected-outcome-of-a-probability-experiment"></a>
## Computing the Expected Outcome of a Probability Experiment

**Example:** If we draw $5$ cards from a standard $52$-card deck, the probability of getting two cards of the same kind is approximately $0.42$.
If we repeat this experiment $50$ times and shuffle the cards after each drawing, how many times do we expect to get two cards of the same kind?

**Explanation**

To find the expected number of occurrences of an event, we can multiply the number of experiments by the probability of the event occurring on a given experiment.

Here, there are $50$ experiments (in which we draw $5$ cards), and the probability of getting two cards of the same kind is $0.42$.

Therefore, we expect to get two cards of the same kind

$$
0.42\times 50 = 21
$$

times.

## Describing the Likelihood of an Event

Given the probability of an event, we can describe the likelihood using words. If $p$ is the probability of the event, then we have the following categories:

- If $p=0$, then the event is **impossible**.
- If $0 < p < \dfrac{1}{2}$, then the event is **unlikely**.
- If $\dfrac{1}{2} < p < 1$, then the event is **likely**.
- If $p=1$, then the event is **certain**.

If

$$
p=\dfrac{1}{2}
$$

the event has an equal likelihood of occurring or not occurring.

---

<a id="describing-the-likelihood-of-an-event-given-its-probability"></a>
## Describing the Likelihood of an Event Given Its Probability

**Example:** An event has probability $\dfrac{3}{5}$. Is the event impossible, unlikely, likely, or certain?

**Explanation**

Remember that if $p$ is the probability of the event, then we have the following categories:

- If $p=0$, then the event is *impossible*.
- If $0 < p < \dfrac{1}{2}$, then the event is *unlikely*.
- If $\dfrac{1}{2} < p < 1$, then the event is *likely*.
- If $p=1$, then the event is *certain*.

Here, we have

$$
p=\dfrac{3}{5}
$$

and we know that

$$
\dfrac{1}{2} < \dfrac{3}{5} < 1
$$

Therefore, the event is likely.
