## Introduction

Let's consider the system of linear equations given by

$$
{y = 9 - 0.5x; 3x - y = 7
$$

The straight lines corresponding to the two equations are given below.

![](<../Source/2.3.12. Approximating Solutions to Systems of Linear Equations/Images/804a6f2a5ec97fd44a7baff1ce87ca92.png>)

The solution of the system corresponds to the point of intersection of the lines. We cannot tell the exact intersection point from the graph, but we can *approximate* it.

![](<../Source/2.3.12. Approximating Solutions to Systems of Linear Equations/Images/31a6cc29caa45d44803dbe300645de6f.png>)

Notice that:

- The $x$-coordinate of the solution lies between $x=4$ and $x=5$, and is slightly closer to $5$. So, $x \approx 4.6$.
- The $y$-coordinate of the solution lies between $y=6$ and $y=7$, and is closer to $7$. So, $y \approx 6.7$.

Therefore, the approximate solution to our original system of equations is $(4.6, 6.7)$.

## Finding an Approximate Solution Using a Table

Let's consider the following system of equations.

$$
{y = x + 1; y = 4x - 3
$$

The graph corresponding to the system is shown below:

![](<../Source/2.3.12. Approximating Solutions to Systems of Linear Equations/Images/fcca787dddf02a975870b12e50cf9659.png>)

We can see from the graph that the $x$-value that satisfies the system lies somewhere between $1.0$ and $1.5$.

We can get a better approximation by setting up a table of values, like the one shown below.

| $x$ | $1.0$ | $1.1$ | $1.2$ | $1.3$ | $1.4$ | $1.5$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $y_1=x+1$ |  |  |  |  |  |  |
| $y_2=4x-3$ |  |  |  |  |  |  |
| $\mid y_1-y_2 \mid$ |  |  |  |  |  |  |

Now, we fill in the table as follows:

- First, we calculate the $y$-values on both lines for our different values of $x$.
- Then, we calculate $\mid y_2 - y_1 \mid$ for each value of $x$. We call this the **error.**

For example, consider the first column of the table, which corresponds to $x=1.0$. Substituting $x=1.0$ into the expressions for $y_1$ and $y_2$, we get the following:

$$
\begin{aligned}
y_{1} &= x + 1 \\
&= 1.0 + 1 \\
&= 2.0 \\
y_{2} &= 4x - 3 \\
&= 4(1.0) - 3 \\
&= 1.0
\end{aligned}
$$

Then, we find the corresponding error:

$$
\begin{aligned}
\begin{vmatrix}y_{1} - y_{2} & &= & 2.0 - 1.0\end{vmatrix} \\
&= \mid 1.0 \mid \\
&= 1.0
\end{aligned}
$$

We fill this information into the first column:

| $x$ | $1.0$ | $1.1$ | $1.2$ | $1.3$ | $1.4$ | $1.5$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $y_1=x+1$ | $2.0$ |  |  |  |  |  |
| $y_2=4x-3$ | $1.0$ |  |  |  |  |  |
| $\mid y_1-y_2 \mid$ | $1.0$ |  |  |  |  |  |

Repeating this procedure for each column in the table, we arrive at the following result.

| $x$ | $1.0$ | $1.1$ | $1.2$ | $1.3$ | $1.4$ | $1.5$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $y_1=x+1$ | $2.0$ | $2.1$ | $2.2$ | $2.3$ | $2.4$ | $2.5$ |
| $y_2=4x-3$ | $1.0$ | $1.4$ | $1.8$ | $2.2$ | $2.6$ | $3.0$ |
| $\mid y_1-y_2 \mid$ | $1.0$ | $0.7$ | $0.4$ | $0.1$ | $0.2$ | $0.5$ |

Finally, we look for the smallest error. In the bottom row of the table, we see that $0.1$ is the smallest error. This corresponds to $x=1.3$.

Therefore,

$$
x\approx1.3
$$

is our approximate solution.

## Finding an Approximate Solution Using a Table

**Example:** Fill in the table below, and use this to find a value of $x$ that corresponds to an approximate solution of the system
${y =-4x + 2; y = 2x - 5$.

| $x$ | $0.8$ | $1.0$ | $1.2$ | $1.4$ | $1.6$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $y_1=-4x+2$ | $-1.2$ |  |  | $-3.6$ |  |
| $y_2=2x-5$ | $-3.4$ |  |  | $-2.2$ |  |
| $\mid y_1-y_2 \mid$ | $2.2$ |  |  | $1.4$ |  |

**Explanation**

We fill in the table as follows:

- First, we calculate the $y$-values on both lines for our different values of $x$.
- Then, we calculate the error $\mid y_2 - y_1 \mid$ for each value of $x$.

For example, consider the third column of the table, which corresponds to $x=1.2$. Substituting $x=1.2$ into the expressions for $y_1$ and $y_2$, we get the following:

$$
\begin{aligned}
y_{1} &= -4x + 2 \\
&=-4(1.2) + 2 \\
&=-2.8 \\
y_{2} &= 2x - 5 \\
&= 2(1.2) - 5 \\
&=-2.6
\end{aligned}
$$

Then, we find the corresponding error:

$$
\begin{aligned}
\begin{vmatrix}y_{1} - y_{2} & &= & -2.8 - (-2.6)\end{vmatrix} \\
&= \mid - 0.2 \mid \\
&= 0.2
\end{aligned}
$$

We fill this information into the corresponding column:

| $x$ | $0.8$ | $1.0$ | $1.2$ | $1.4$ | $1.6$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $y_1=-4x+2$ | $-1.2$ |  | $-2.8$ | $-3.6$ |  |
| $y_2=2x-5$ | $-3.4$ |  | $-2.6$ | $-2.2$ |  |
| $\mid y_1-y_2 \mid$ | $2.2$ |  | $0.2$ | $1.4$ |  |

Repeating this procedure for each column in the table, we arrive at the following result.

| $x$ | $0.8$ | $1.0$ | $1.2$ | $1.4$ | $1.6$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $y_1=-4x+2$ | $-1.2$ | $-2$ | $-2.8$ | $-3.6$ | $-4.4$ |
| $y_2=2x-5$ | $-3.4$ | $-3$ | $-2.6$ | $-2.2$ | $-1.8$ |
| $\mid y_1-y_2 \mid$ | $2.2$ | $1$ | $0.2$ | $1.4$ | $2.6$ |

The smallest error is $0.2$, which corresponds to $x=1.2$. Therefore,

$$
x\approx 1.2
$$

is our approximate solution.

## Approximating the Solution to a Word Problem

**Example:** The temperature, in ${}^{\circ}\textrm{C}$, of object $A$ and object $B$ are given by the equations $y=0.43x+6$ and $y=0.65x+3$, respectively, where $x$ is the time, in hours, since the beginning of the day. Using the graph above and the table below, find a value for $x$ that corresponds to an approximation of when both objects have the same temperature.

![](<../Source/2.3.12. Approximating Solutions to Systems of Linear Equations/Images/492537eeae4b450e60dbbec054c03f1d.png>)

| $x$ | $12.1$ | $12.2$ | $13.2$ | $13.6$ | $14.6$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $y_1=0.43x+6$ |  |  |  |  |  |
| $y_2=0.65x+3$ |  |  |  |  |  |
| $\mid y_1-y_2 \mid$ |  |  |  |  |  |

**Explanation**

We need to find the point of intersection of the two lines.

From the graph, we can see that the solution should lie between $x=13$ and $x=14$. So, we can disregard all values of $x$ that are not between $13$ and $14$.

Now, we evaluate the table entries for $x=13.2$ and $x=13.6$, as follows:

- Substituting $x=13.2$ into the expressions for $y_1$ and $y_2$, we get the following:
$y_{1}|= 0.43x + 6; = 0.43(13.2) + 6; = 11.676; y_{2}|= 0.65x + 3; = 0.65(13.2) + 3; = 11.58$
Then, we find the corresponding error:
$\begin{vmatrix}y_{1} - y_{2} & |= & 11.676 - 11.58\end{vmatrix}; = \mid 0.096 \mid; = 0.096$
- Substituting $x=13.6$ into the expressions for $y_1$ and $y_2$, we get the following:
$y_{1}|= 0.43x + 6; = 0.43(13.6) + 6; = 11.848; y_{2}|= 0.65x + 3; = 0.65(13.6) + 3; = 11.84$
Then, we find the corresponding error:
$\begin{vmatrix}y_{1} - y_{2} & |= & 11.848 - 11.84\end{vmatrix}; = \mid 0.008 \mid; = 0.008$

We fill this information into the table:

| $x$ | $13.2$ | $13.6$ |
| --- | ---: | ---: |
| $y_1=0.43x+6$ | $11.676$ | $11.848$ |
| $y_2=0.65x+3$ | $11.58$ | $11.84$ |
| $\mid y_1-y_2 \mid$ | $0.096$ | $0.008$ |

The smallest error is $0.008$, which corresponds to $x=13.6$. Therefore,

$$
x\approx 13.6
$$

is our approximate solution.
