## Introduction

It's often necessary to simplify a rational function to determine its behavior near a vertical asymptote. In this lesson, we'll discuss the general process.

As an example, let's consider the following rational function:

$$
f(x) = \dfrac{x}{x^2 - 4}
$$

First, we factor the numerator and denominator. This gives

$$
\begin{aligned}
f(x) &= (x)/((x + 2)(x - 2))
\end{aligned}
$$

At this point, we would usually cancel any common factors in the numerator and denominator. However, in this case, there are no common factors, so we can now determine its unbounded behavior using the usual methods.

We see that $f(x)$ has vertical asymptotes at $x=\pm 2$. Let's determine its behavior as we approach $x=-2$ *from the left.* For this, we use a table of values:

|  | Approaching $-2$ (from the *left*) $\quad\large\longrightarrow$ |  |  |  |  |  |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **$x$** | $-2.1$ | $-2.01$ | $-2.001$ | $-2.0001$ | $\cdots$ | $-2$ |
| $f(x)$ | $-5.12$ | $-50.12$ | $-500.12$ | $-5\,000.12$ | $\cdots$ | undefined |
|  | Decreasing to $\color{red}-\infty$ $\quad\large\longrightarrow$ |  |  |  |  |  |

Notice that all the values of $f(x)$ in our table are *negative*, and they *decrease* as we approach $x = -2$.

Therefore, we conclude that

$$
f(x) \rightarrow {\color{red}{-\infty}} \quad\textrm{as}\quad x \rightarrow -2^-
$$

**Note**: In our table, we calculated the value of $f(x)$ at four points. After some practice, you'll only need to compute $f(x)$ at one or two points to determine its behavior near an asymptote.

## Calculating a Left-Sided Infinite Limit for a Rational Function with an Expanded Denominator

**Example:** Given that $f(x)= -\dfrac{2x+4}{x^2+x - 2} \to a$ as $x \to 1^{-}$, what is the value of $a$?

**Explanation**

We wish to determine the behavior of $f(x)$ as $x$ approaches $1$ from the *left*.

Factoring the numerator and denominator and canceling any common factors, we get

$$
\begin{aligned}
f(x) &= -\frac{2x + 4}{x^{2} + x - 2} \\
&= - (2(x + 2))/((x + 2)(x - 1)) \\
&= - (2(x + 2))/((x + 2)(x - 1)) \\
&=-\frac{2}{x - 1}
\end{aligned}
$$

Now, note the following:

- the function $f(x)$ has a vertical asymptote at $x = 1$,
- therefore, $f(x)$ can approach *either* $\color{blue}\infty$ *or* $\color{red}-\infty$ as $x$ approaches $1$ from the left.

We can see how $f(x)$ behaves as $x$ approaches $1$ from the left using a table of values.

|  | Approaching $1$ (from the *left*) $\quad\large\longrightarrow$ |  |  |  |  |  |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **$x$** | $0.9$ | $0.99$ | $0.999$ | $0.9999$ | $\cdots$ | $1$ |
| $f(x)$ | $20$ | $200$ | $2\,000$ | $20\,000$ | $\cdots$ | undefined |
|  | Increasing to $\color{blue}\infty$ $\quad\large\longrightarrow$ |  |  |  |  |  |

Notice that all the values of $f(x)$ in our table are *positive*, and they *increase* as we approach $x=1$.

Therefore, $f(x) \rightarrow {\color{blue}{\infty}}$ as $x\rightarrow 1^-$, which means that

$$
a={\color{blue}{\infty}}
$$

## Calculating a Right-Sided Infinite Limit for a Rational Function with an Expanded Denominator

**Example:** Given that $f(x) = \dfrac{2x+10}{25 - x^2} \to a$ as $x \rightarrow 5^{+}$, what is the value of $a$?

**Explanation**

We wish to determine the behavior of $f(x)$ as $x$ approaches $5$ from the *right*.

Factoring the numerator and denominator and canceling any common factors (if any), we get

$$
\begin{aligned}
f(x) &= \frac{2x + 10}{25 - x^{2}} \\
&= (2(x + 5))/((5 + x)(5 - x)) \\
&= (2(x + 5))/((5 + x)(5 - x)) \\
&= \frac{2}{5 - x}
\end{aligned}
$$

Now, note the following:

- the function $f(x)$ has a vertical asymptote at $x = 5$,
- therefore, $f(x)$ can approach *either* $\color{blue}\infty$ *or* $\color{red}-\infty$ as $x$ approaches $5$ from the right.

We can see how $f(x)$ behaves as $x$ approaches $5$ from the right using a table of values.

|  |  | $\large\longleftarrow\quad$ Approaching $5$ (from the *right*) |  |  |  |  |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **$x$** | $5$ | $\cdots$ | $5.0001$ | $5.001$ | $5.01$ | $5.1$ |
| $f(x)$ | undefined | $\cdots$ | $-20\,000$ | $-2\,000$ | $-200$ | $-2$ |
|  |  | $\large\longleftarrow\quad$ Decreasing to $\color{red}-\infty$ |  |  |  |  |

Notice that all the values of $f(x)$ in our table are *negative*, and they *decrease* as we approach $x = 5$.

Therefore, $f(x) \rightarrow {\color{red}{-\infty}}$ as $x \rightarrow 5^+$, which means that

$$
a = {\color{red}{-\infty}}
$$

## The Connection Between Infinite Limits and One-Sided Limits

Let's determine the behavior of the following function near its asymptotes:

$$
f(x) = \dfrac{1}{x^2 - 2x + 1}
$$

First, we factor the function and cancel the common factors (if any):

$$
\begin{aligned}
f(x) &= \frac{1}{x^{2} - 2x + 1} \\
&= (1)/((x - 1)^{2})
\end{aligned}
$$

The function $f(x)$ has a vertical asymptote at $x=1$. We will now consider the behavior of this function as $x$ approaches $1$ from the left *and* from the right.

First, we create a table of values:

| Approaching $1$ (from the *left*) $\quad\large\longrightarrow$ |  | $\large\longleftarrow\quad$ Approaching $1$ (from the *right*) |  |  |  |  |  |  |  |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **$x$** | $0.9$ | $0.99$ | $0.999$ | $\cdots$ | $1$ | $\cdots$ | $1.001$ | $1.01$ | $1.1$ |
| $f(x)$ | $100$ | $10\,000$ | $1\,000\,000$ | $\cdots$ | undefined | $\cdots$ | $1\,000\,000$ | $10\,000$ | $100$ |
| Increasing to $\color{blue}\infty$ $\quad\large\longrightarrow$ |  | $\large\longleftarrow\quad$ Increasing to $\color{blue}\infty$ |  |  |  |  |  |  |  |

We now analyze our results:

- The values of $f(x)$ in our table are *positive* for $x < 1$, and they *increase* as we approach $x=1$ from the *left*. Therefore,
$f(x)\to{\color{blue}{\infty}}\quad{\textrm{as}}\quad x\to 1^-$.
- The values of $f(x)$ in our table are *positive* for $x > 1$, and they *increase* as we approach $x=1$ from the *right.* Therefore,
$f(x)\to{\color{blue}{\infty}}\quad{\textrm{as}}\quad x\to 1^+$.

Now, since $f(x)$ approaches ${\color{blue}{\infty}}$ from the left *and* from the right, we say that *"$f(x)$ approaches ${\color{blue}{\infty}}$ as $x$ approaches $1$*", and we write

$$
f(x) \to {\color{blue}{\infty}} \quad \textrm{as}\quad \quad x \to 1
$$

This statement indicates that the behavior of $f(x)$ near the asymptote *does not depend* on the direction in which we approach the asymptote.

## Identifying True Statements Regarding Infinite Limits of Factored Rational Functions

**Example:** Given that $f(x) =\dfrac{2x+1}{(x-1)(x-3)}$, which of the following statements are true?

1. $f(x)\to \infty$ as $x\to 3^-$
2. $f(x)\to \infty$ as $x\to 3^+$
3. $f(x)\to \infty$ as $x\to 3$

**Explanation**

We wish to determine the behavior of $f(x)$ as $x$ approaches $3$.

Note the following:

- the function $f(x)$ has a vertical asymptote at $x=3$,
- therefore, $f(x)$ can approach *either* $\color{blue}\infty$ *or* $\color{red}-\infty$ as $x$ approaches $3$ from the *left*,
- similarly, $f(x)$ can approach *either* $\color{blue}\infty$ *or* $\color{red}-\infty$ as $x$ approaches $3$ from the *right*.

We can see how $f(x)$ behaves as $x$ approaches $3$ using a table of values.

| Approaching $3$$\quad\large\longrightarrow$ |  | $\large\longleftarrow\quad$ Approaching $3$ |  |  |  |  |  |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **$x$** | $2.99$ | $2.999$ | $\cdots$ | $3$ | $\cdots$ | $3.001$ | $3.01$ |
| $f(x)$ | $-350.75$ | $-3500.75$ | $\cdots$ | undefined | $\cdots$ | $3499.25$ | $349.25$ |
| Decreasing to $\color{red}-\infty$ $\quad\large\longrightarrow$ |  | $\large\longleftarrow\quad$ Increasing to $\color{blue}\infty$ |  |  |  |  |  |

Let's now analyze each of the statements in turn:

- Statement I is false. The values of $f(x)$ in our table are *negative* for $x < 3$, and they *decrease* as we approach $x=3$ from the *left*.
Therefore,
$f(x)\to {\color{red}{-\infty}} \quad\textrm{as}\quad x\to 3^{-}$.
- Statement II is true. The values of $f(x)$ in our table are *positive* for $x >3$, and they *increase* as we approach $x= 3$ from the *right*.
$f(x)\to {\color{blue}{\infty}} \quad\textrm{as}\quad x\to 3^{+}$
- Statement III is false. Since statement II is true yet statement I is false, we conclude that
$f(x) \nrightarrow \infty \quad\textrm{as}\quad x\to 3$.

Therefore, the correct answer is "II only."
