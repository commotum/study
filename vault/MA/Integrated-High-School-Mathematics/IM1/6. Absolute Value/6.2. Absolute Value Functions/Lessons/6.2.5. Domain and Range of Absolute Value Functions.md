## Introduction

Let's consider the function

$$
y= \mid x \mid
$$

shown below.

![](<../Source/6.2.5. Domain and Range of Absolute Value Functions/Images/9804034cacec20a268260c39f553fb8b.png>)

Notice that this function is defined for all values of $x$. Therefore, its domain is

$$
x \in (-\infty, \infty)
$$

The domain of an absolute value function does not change whenever we shift or stretch the function. For example, the domain of

$$
f(x) = 2 \mid x-1 \mid + 3
$$

is also $x \in (-\infty, \infty)$.

---

<a id="finding-the-domain-of-a-transformed-absolute-value-function"></a>
## Finding the Domain of a Transformed Absolute Value Function

**Example:** What is the domain of the function $f(x)=-\mid x \mid -5$?

**Explanation**

A shifted and reflected absolute value function is defined for all real numbers.

Therefore, the domain of $f(x)$ is $x\in(-\infty,\infty)$.

<a id="the-range-of-a-transformed-absolute-value-function"></a>
## The Range of a Transformed Absolute Value Function

The range of an absolute value function can change depending on the types of transformations applied to the function.

As an example, let's determine the range of the following function:

$$
f(x) = \mid x+1 \mid +2
$$

We'll plot $f(x)$ using graph transformations and then deduce its range from the graph.

Let's start with the function

$$
y= \mid x \mid
$$

![](<../Source/6.2.5. Domain and Range of Absolute Value Functions/Images/c07fe946ed5702b6b7fbe002acbe490e.png>)

To plot

$$
y= \mid x+1 \mid
$$

we shift the graph of

$$
y= \mid x \mid
$$

by one unit to the left:

![](<../Source/6.2.5. Domain and Range of Absolute Value Functions/Images/bba8396387fa111f0cfdc6415d8a6ea0.png>)

Finally, we plot

$$
y = f(x) = \mid x+1 \mid + 2
$$

by shifting the graph above *up* by two units:

![](<../Source/6.2.5. Domain and Range of Absolute Value Functions/Images/7abc183d25ca9c54cd46409ebc402123.png>)

From here, we see that $f(x)$ has a minimum value of ${\color{red}{2}}$, and there is no maximum value. Therefore, its range is $[MATH: f(x) \in [2,\infty).]$

---

<a id="deducing-the-range-by-manipulating-inequalities"></a>
## Deducing the Range By Manipulating Inequalities

Deducing the range of an absolute value function using graph transformations will get us the correct answer. However, there is a faster way.

Let's once again calculate the range of the function

$$
f(x) = \mid x+1 \mid + 2
$$

First, we recall that the range of $\mid x \mid$ is given by

$$
\mid x \mid \ge 0
$$

We know that horizontal shifts do not affect the range. So,

$$
\mid x+1 \mid \ge 0
$$

Finally, adding $2$ to the above inequality, we get

$$
\mid x + 1 \mid \mid \ge 0;\begin{vmatrix}x + 1 & + 2\end{vmatrix}\ge 2; f(x) \mid \ge 2
$$

Therefore, the range is $[MATH: f(x) \in [2,\infty),]$ as before.

<a id="finding-the-range-of-a-transformed-absolute-value-function"></a>
## Finding the Range of a Transformed Absolute Value Function

**Example:** What is the range of $f(x) = 3 \mid x-2 \mid +4$?

**Explanation**

The range of $\mid x \mid$ is given by

$$
\mid x \mid \ge 0
$$

Horizontal shifts do not affect the range. So,

$$
\mid x-2 \mid \ge 0
$$

Multiplying the above inequality by $3$, we get

$$
\begin{bmatrix}3 \cdot & x - 2 & \ge 3 \cdot 0 \\ 3 & x - 2 & \ge 0\end{bmatrix}
$$

Finally, by adding $4$ to the above inequality, we get

$$
3 \mid x - 2 \mid \mid \ge 0; 3\begin{vmatrix}x - 2 & + 4\end{vmatrix}\ge 4; f(x) \mid \ge 4
$$

Therefore, the range of the given function is $[MATH: f(x) \in [4,\infty).]$

We can also see this is true from the graph of the function. The graph of $y=f(x)$ is shown below.

![](<../Source/6.2.5. Domain and Range of Absolute Value Functions/Images/152fee56b9c58f1df4fcb7baf7d13d58.png>)

## Finding the Range of a Transformed Absolute Value Function: Negative Multiple Case

**Example:** What is the range of $f(x) = -3 \mid x+2 \mid -1$?

**Explanation**

The range of $-\mid x \mid$ is

$$
-\mid x \mid \le 0
$$

Horizontal shifts do not affect the range. So, we have

$$
-\mid x+2 \mid \le 0
$$

Multiplying the above inequality by $3$, we get

$$
-3 \mid x+2 \mid \le 0
$$

Finally, subtracting $1$ from the above inequality, we get

$$
-3\begin{vmatrix}x + 2 & -1\end{vmatrix}\le - 1; f(x) \mid \le - 1
$$

Therefore, the range of the given function is $[MATH: f(x) \in (-\infty,-1].]$

We can also see that this is true from the graph of the function. The graph of $y=f(x)$ is shown below.

![](<../Source/6.2.5. Domain and Range of Absolute Value Functions/Images/a23e9263cf504eb05a6ce18782019621.png>)
