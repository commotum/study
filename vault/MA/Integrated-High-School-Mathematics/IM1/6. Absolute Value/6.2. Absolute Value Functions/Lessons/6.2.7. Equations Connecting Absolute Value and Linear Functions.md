## Introduction

Sometimes, we must solve an absolute value equation containing variables on both sides. For example,

$$
\left\vert 5x +7\right\vert = 3x +9
$$

Geometrically, these solutions correspond to the $x$-coordinates of the intersection points of the curves

$$
y= \mid 5x+7 \mid
$$

and

$$
y=3x+9
$$

shown as the points $P$ and $Q$ below.

![](<../Source/6.2.7. Equations Connecting Absolute Value and Linear Functions/Images/6b717ad6792087d8a375388e2b3b4b5f.png>)

**Note:** *Image not drawn to scale.*

Let's now discuss how to find these intersection points algebraically.

<a id="a-worked-example"></a>
## A Worked Example

We wish to find the solution to the equation

$$
\vert 5x + 7 \vert = 3x +9
$$

For this equation to be true, either the positive or negative of the expression inside the absolute value must be equal to the right-hand side of the equation.

Therefore, we have the following two cases:

$$
\begin{vmatrix}5x+7 & = 5x+7 \qquad \textrm{and}\qquad & 5x+7\end{vmatrix} = -(5x+7)
$$

We now consider these two cases separately:

- If $\mid 5x +7|=5x +7$, we obtain the following equation:
$5x +7 = 3x +9$
We now solve this equation using the usual methods:
$5x + 7|= 3x + 9; 2x + 7|= 9; 2x|= 2; x|= 1$
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 5x + 7 \mid |= 3x + 9; \mid 5(1) + 7 \mid |= 3(1) + 9; \mid 5 + 7 \mid |= 3 + 9; \mid 12 \mid |= 12; 12|= 12✓$
Since $x=1$ satisfies the original equation, it's a valid solution.
- If $\mid 5x +7|=-(5x +7)$, we obtain the following equation:
$-(5x +7)=3x +9$
We now solve this equation using the usual methods:
$- (5x + 7)|= 3x + 9; - 5x - 7|= 3x + 9; - 7|= 8x + 9; - 16|= 8x; - 2|= x; x|=-2$
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 5x + 7 \mid |= 3(-2) + 9; \mid 5(-2) + 7 \mid |= 3(-2) + 9; \mid - 10 + 7 \mid |=-6 + 9; \mid - 3 \mid |= 3; 3|= 3✓$
Since $x=-2$ satisfies the original equation, it's a valid solution.

Therefore, the solutions of our equation are $x=-2, \, 1$.

<a id="the-number-of-solutions"></a>
## The Number of Solutions

The intersection points between the absolute value graph

$$
y= \mid ax+b \mid
$$

and the line

$$
y=cx+d
$$

correspond to the solutions of the equation

$$
\begin{aligned}
\mid ax+b &= cx+d
\end{aligned}
$$

Depending on the positions of the respective graphs, there are typically two, one, or no solutions to this equation.

![](<../Source/6.2.7. Equations Connecting Absolute Value and Linear Functions/Images/03f281c2d791755ff0f38cf8e3f6d0d9.png>)

For the remainder of this lesson, we'll consider only the cases where two intersection points exist between the absolute value function and the line. Cases with only one or no intersection points will be dealt with in a future lesson.

## Solving Absolute Value Equations With Two Solutions

**Example:** Solve the equation $\mid 5x+1|=-x+7$.

**Explanation**

We have the following two cases:

- If $\mid 5x+1|=5x+1$, we obtain
$\mid 5x + 1 \mid |=-x + 7; 5x + 1|=-x + 7; 6x + 1|= 7; 6x|= 6; x|= 1$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 5x + 1 \mid |=-x + 7; \mid 5(1) + 1 \mid |= - (1) + 7; \mid 6 \mid |= 6; 6|= 6✓$
Since $x=1$ satisfies the original equation, it's a valid solution.
- If $\mid 5x+1|=-(5x+1)$, we obtain
$\mid 5x + 1 \mid |=-x + 7; - (5x + 1)|=-x + 7; - 5x - 1|=-x + 7; - 1|= 4x + 7; - 8|= 4x; - 2|= x; x|=-2$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 5x + 1 \mid |=-x + 7; \mid 5(-2) + 1 \mid |= - (-2) + 7; \mid - 10 + 1 \mid |= 2 + 7; \mid - 9 \mid |= 9; 9|= 9✓$
Since $x=-2$ satisfies the original equation, it's a valid solution.

Therefore, the solutions of our equation are $x=-2, \, 1$.

<a id="isolating-an-absolute-value"></a>
## Isolating an Absolute Value

**Example:** Solve the equation $\vert 2 -6q \vert + 2q = 6$.

**Explanation**

We start by isolating the absolute value on the left side:

$$
\begin{aligned}
\mid 2 - 6q \mid + 2q &= 6 \\
\mid 2 - 6q \mid &= -2q + 6
\end{aligned}
$$

Now, we have the following two cases:

- If $\mid 2-6q|=2-6q$, we obtain
$\mid 2 - 6q \mid |=-2q + 6; 2 - 6q|=-2q + 6; 2|= 4q + 6; - 4|= 4q; - 1|= q; q|=-1$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2 - 6q \mid |=-2q + 6; \mid 2 - 6(-1) \mid |=-2(-1) + 6; \mid 2 + 6 \mid |= 2 + 6; \mid 8 \mid |= 8; 8|= 8✓$
Since $q=-1$ satisfies the original equation, it's a valid solution.
- If $\mid 2-6q|=-(2-6q)$, we obtain
$\mid 2 - 6q \mid |=-2q + 6; - (2 - 6q)|=-2q + 6; - 2 + 6q|=-2q + 6; 8q - 2|= 6; 8q|= 8; q|= 1$.
This *potential* solution is valid only if it actually solves the original equation. So, let's plug it back in:
$\mid 2 - 6q \mid |=-2q + 6; \mid 2 - 6(1) \mid |=-2(1) + 6; \mid 2 - 6 \mid |=-2 + 6; \mid - 4 \mid |= 4; 4|= 4✓$
Since $q=1$ satisfies the original equation, it's a valid solution.

Therefore, our equation has two solutions $q=-1$ and $q=1$.

<a id="finding-points-of-intersection"></a>
## Finding Points of Intersection

**Example:** Find the $x$-coordinates of the points $A$ and $B$ above.

![](<../Source/6.2.7. Equations Connecting Absolute Value and Linear Functions/Images/b01afb9702e1056c6c609facadc2c074.png>)

**Explanation**

To find the $x$-coordinates of the intersections of

$$
y= \mid 2x+3 \mid
$$

and

$$
y=x+3
$$

we need to solve the following equation for $x{:}$

$$
\mid 2x+3 \mid = x+3
$$

The absolute value graph

$$
y= \mid 2x+3 \mid
$$

has two branches:

- where $\mid 2x+3 \mid = -(2x+3)$, which has a negative slope, and
- where $\mid 2x+3 \mid = 2x+3$, which has a positive slope.

Now, let's consider each branch in turn:

- The point $A$ lies on the branch with a negative slope. So, if $\mid 2x+3 \mid = -(2x+3)$, we obtain:
$- (2x + 3)|= x + 3; - 2x - 3|= x + 3; - 3|= 3x + 3; - 6|= 3x; - 2|= x; x|=-2$
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x + 3 \mid |= x + 3; \mid 2(-2) + 3 \mid |= (-2) + 3; \mid - 4 + 3 \mid |= 1; \mid - 1 \mid |= 1; 1|= 1✓$
Since $x=-2$ satisfies the original equation, the $x$-coordinate of $A$ is $x=-2$.

- The point $B$ lies on the branch with a positive slope. So, if $\mid 2x+3 \mid = 2x+3$, we obtain:
$2x + 3|= x + 3; x + 3|= 3; x|= 0$
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x + 3 \mid |= x + 3; \mid 2(0) + 3 \mid |= (0) + 3; \mid 0 + 3 \mid |= 3; \mid 3 \mid |= 3; 3|= 3✓$
Since $x=0$ satisfies the original equation, the $x$-coordinate of $B$ is $x=0$.

Therefore, the $x$-coordinates of $A$ and $B$, respectively, are $-2$ and $0$.
