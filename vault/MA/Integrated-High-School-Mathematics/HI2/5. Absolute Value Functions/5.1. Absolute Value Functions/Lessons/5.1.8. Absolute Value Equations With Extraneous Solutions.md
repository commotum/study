## Introduction

Let's now consider the following equation:

$$
\vert x + 1 \vert = 2x - 4
$$

Geometrically, solving this equation gives us the $x$-coordinate of the point of intersection $P$ of the curves

$$
y = \mid x+1 \mid
$$

and $y=2x-4$.

![](<../Source/5.1.8. Absolute Value Equations With Extraneous Solutions/Images/eb1265b74d69192bc48f8bbb2b4634c6.png>)

Let's now discuss how to find the intersection point algebraically.

---

<a id="a-worked-example"></a>
## A Worked Example

We wish to find the solution to the equation

$$
\vert x + 1 \vert = 2x - 4
$$

For this equation to be true, either the positive or negative of the expression inside the absolute value must be equal to the right-hand side of the equation.

Therefore, we have the following two cases:

$$
\begin{vmatrix}x+1 & = x+1 \qquad \textrm{and}\qquad & x+1\end{vmatrix} = -(x+1)
$$

We now consider these two cases separately:

- If $\mid x + 1|=x + 1$, we obtain the following equation:
$x+1 = 2x-4$
We now solve this equation using the usual methods:
$x + 1|= 2x - 4; 1|= x - 4; 5|= x; x|= 5$
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid x + 1 \mid |= 2x - 4; \mid 5 + 1 \mid |= 2(5) - 4; \mid 6 \mid |= 10 - 4; 6|= 6✓$
Since $x=5$ satisfies the original equation, it's a valid solution.
- If $\mid x + 1|=-(x + 1)$, we obtain
$\mid x + 1 \mid |= 2x - 4; - (x + 1)|= 2x - 4; - x - 1|= 2x - 4; - 1|= 3x - 4; 3|= 3x; 1|= x; x|= 1$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid x + 1 \mid |= 2x - 4; \mid 1 + 1 \mid |= 2(1) - 4; \mid 2 \mid |= 2 - 4; 2|=-2\cdot$
Since $x=1$ does *not* satisfy the original equation, it's *not* a valid solution. It's called an **extraneous** solution.

Therefore, the *only* solution of our equation is $x = 5$. This solution corresponds to the point $P$, shown below.

![](<../Source/5.1.8. Absolute Value Equations With Extraneous Solutions/Images/0245f6dda01d9e9a49323fc33b913fa5.png>)

**Watch out!** Whenever we want to solve an absolute value equation where the variable is on both sides, we must *always* check that the solutions satisfy the original equation.

Some absolute value equations have no solutions at all! Let's see an example.

---

<a id="solving-absolute-value-equations-with-extraneous-solutions"></a>
## Solving Absolute Value Equations With Extraneous Solutions

**Example:** Solve the equation $\vert 2x-3 \vert = -x+1$.

**Explanation**

We have the following two cases:

- If $\mid 2x-3|=2x-3$, we obtain
$\mid 2x - 3 \mid |=-x + 1; 2x - 3|=-x + 1; 2x|=-x + 4; 3x|= 4; x|= \frac{4}{3}$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x - 3 \mid |=-x + 1; \mid 2 \cdot \frac{4}{3} - 3 \mid |= - (\frac{4}{3}) + 1; \mid \frac{8}{3} - 3 \mid |=-\frac{4}{3} + 1; \mid \frac{8}{3} - \frac{9}{3} \mid |=-\frac{4}{3} + \frac{3}{3}; \mid - \frac{1}{3} \mid |=-\frac{1}{3}; \frac{1}{3}|=-\frac{1}{3}\cdot$
Since $x=-\dfrac 43$ does *not* satisfy the original equation, it's *not* a valid solution.
- If $\mid 2x-3|=-(2x-3)$, we obtain
$\mid 2x - 3 \mid |=-x + 1; - (2x - 3)|=-x + 1; - 2x + 3|=-x + 1; 3|= x + 1; 2|= x; x|= 2$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x - 3 \mid |=-x + 1; \mid 2(2) - 3 \mid |= - (2) + 1; \mid 4 - 3 \mid |=-2 + 1; \mid 1 \mid |=-1; 1|=-1\cdot$
Since $x=2$ does *not* satisfy the original equation, it's *not* a valid solution.

Therefore, our equation has no solutions.

<a id="isolating-an-absolute-value"></a>
## Isolating an Absolute Value

**Example:** Solve the equation $\mid 2x +5 \mid - 4x = 1$.

**Explanation**

We start by isolating the absolute value on the left-hand side:

$$
\begin{aligned}
\mid 2x + 5 \mid - 4x &= 1 \\
\mid 2x + 5 \mid &= 4x + 1
\end{aligned}
$$

Now, we have two cases:

- If $\mid 2x + 5|=2x+ 5$, we obtain
$\mid 2x + 5 \mid |= 4x + 1; 2x + 5|= 4x + 1; 5|= 2x + 1; 4|= 2x; x|= 2$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x + 5 \mid |= 4x + 1; \mid 2(2) + 5 \mid |= 4(2) + 1; \mid 4 + 5 \mid |= 8 + 1; \mid 9 \mid |= 9; 9|= 9✓$
Since $x=2$ satisfies the original equation, it's a valid solution.
- If $\mid 2x+5|=-(2x+5)$, we obtain
$\mid 2x + 5 \mid |= 4x + 1; - (2x + 5)|= 4x + 1; - 2x - 5|= 4x + 1; - 5|= 6x + 1; - 6|= 6x; x|=-1$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x + 5 \mid |= 4x + 1; \mid 2(-1) + 5 \mid |= 4(-1) + 1; \mid - 2 + 5 \mid |=-4 + 1; \mid 3 \mid |=-3; 3|=-3\cdot$
Since $x=-1$ does *not* satisfy the original equation, it's *not* a valid solution.

Therefore, the solution of our equation is $x = 2$.

<a id="finding-points-of-intersection"></a>
## Finding Points of Intersection

**Example:** Find the points of intersection of $y = \vert 2x+1 \vert$ and $y = -3x+11$.

**Explanation**

The $x$-coordinates of the intersection points correspond to solutions of the equation

$$
\mid 2x+1 \mid = -3x+11
$$

Now, we have the following two cases:

- For the branch with a negative slope, where $\mid 2x+1 \mid = -(2x+1)$, we obtain
$\mid 2x + 1 \mid |=-3x + 11; - (2x + 1)|=-3x + 11; - 2x - 1|=-3x + 11; x - 1|= 11; x|= 12$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x + 1 \mid |=-3x + 11; \mid 2(12) + 1 \mid |=-3(12) + 11; \mid 24 + 1 \mid |=-36 + 11; \mid 25 \mid |=-25; 25|=-25\cdot$
Since $x=12$ does *not* satisfy the original equation, it is not the $x$-coordinate of a point of intersection.

- For the branch with a positive slope, where $\mid 2x+1 \mid = 2x+1$, we obtain
$\mid 2x + 1 \mid |=-3x + 11; 2x + 1|=-3x + 11; 5x + 1|= 11; 5x|= 10; x|= 2$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$\mid 2x + 1 \mid |=-3x + 11; \mid 2(2) + 1 \mid |=-3(2) + 11; \mid 4 + 1 \mid |=-6 + 11; \mid 5 \mid |= 5; 5|= 5✓$
Since $x=2$ satisfies the original equation, it is an $x$-coordinate of a point of intersection.

So, the $x$-coordinate of the point of intersection is $x=2$.

Finally, we can find the $y$-coordinate of the intersection point by substituting our solution back into either of the curves. Let's use the line

$$
y=-3x+11
$$

$$
\begin{aligned}
y &= -3x + 11 \\
&=-3(2) + 11 \\
&=-6 + 11 \\
&= 5
\end{aligned}
$$

Therefore, the point of intersection has coordinates $(2,5)$.

## Finding Points of Intersection With Negative Absolute Value Curves

**Example:** Determine the $x$-coordinate of point $A$ shown in the graph above.

![](<../Source/5.1.8. Absolute Value Equations With Extraneous Solutions/Images/98bbcf515bdad785ddcc44a4d70bbc99.png>)

**Explanation**

The $x$-coordinate of $A$ corresponds to a solution of the equation

$$
-\mid x-2 \mid = -2x+6
$$

The absolute value graph

$$
y=-\mid x-2 \mid
$$

has two branches:

- where $-\mid x-2 \mid = -(x-2)$, which has a negative slope, and
- where $-\mid x-2|=x-2$, which has a positive slope.

Now, let's consider each branch in turn:

- No points of intersection lie on the branch with a positive slope, so we can ignore this branch.
- The point $A$ lies on the branch with a negative slope. So, if $-\mid x-2 \mid = -(x-2)$, we obtain
$- (x - 2)|=-2x + 6; - x + 2|=-2x + 6; x + 2|= 6; x|= 4$.
This *potential* solution is valid only if it solves the original equation. So, let's plug it back in:
$-\begin{vmatrix}x - 2 & |=-2x + 6 \\ - & 4 - 2\end{vmatrix}|=-2(4) + 6; -\begin{vmatrix}2 & |=-8 + 6 \\ - & 2\end{vmatrix}|=-2; - 2|=-2✓$
Since $x=4$ satisfies the original equation, the $x$-coordinate of $A$ is $x=4$.

Therefore, the $x$-coordinate of $A$ is $4$.
