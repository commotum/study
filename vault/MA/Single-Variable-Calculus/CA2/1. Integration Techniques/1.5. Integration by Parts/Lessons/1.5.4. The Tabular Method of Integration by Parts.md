## Introduction

Suppose we want to evaluate $\displaystyle \int x^3e^{x/2} \textrm{d}x$. We can do it by applying integration by parts three times, but the calculation is pretty long. How can we speed it up?

Multiple applications of integration by parts becomes quick and easy if we use the **tabular method**.

Let's start by picking our $u$ and

$$
\dfrac{\textrm{d}v}{\textrm{d}x}
$$

as normal:

$$
u = x^3\,,\quad \dfrac{\textrm{d}v}{\textrm{d}x} = e^{x/2}\,
$$

We put this in a table, as shown below:

| **Derivatives** | **Integrals** | **Sign** | **Same Color Products** |
| --- | ---: | ---: | ---: |
| $\color[rgb]{1,0,0} x^3$ | $e^{x/2}$ |  |  |

To fill in the second row of the table, we differentiate the function in the first column and integrate the function in the second column. Doing this, we find

$$
\dfrac{\textrm{d}}{\textrm{d}x}\left(x^3\right) = 3x^2\,,\quad \int e^{x/2} \textrm{d}x = 2e^{x/2}\,
$$

Filling in our table, we get the following:

| **Derivatives** | **Integrals** | **Sign** | **Same Color Products** |
| --- | ---: | ---: | ---: |
| $\color[rgb]{1,0,0} x^3$ | $e^{x/2}$ |  |  |
| $\color[rgb]{0.77,0.45,0.06} 3x^2$ | $\color[rgb]{1,0,0}2e^{x/2}$ | $\color[rgb]{1,0,0} +$ |  |

At this step, we begin filling the third column. It always starts with a "$+$" and then the signs alternate at each subsequent step.

We continue by differentiating the expression in the first column and integrating the expression in the second column until we get zero in the first column.

| **Derivatives** | **Integrals** | **Sign** | **Same Color Products** |
| --- | ---: | ---: | ---: |
| $\color[rgb]{1,0,0} x^3$ | $e^{x/2}$ |  |  |
| $\color[rgb]{0.77,0.45,0.06} 3x^2$ | $\color[rgb]{1,0,0}2e^{x/2}$ | $\color[rgb]{1,0,0} +$ | $\color[rgb]{1,0,0}$ |
| $\color[rgb]{0,0,1} 6x$ | $\color[rgb]{0.77,0.45,0.06} 4e^{x/2}$ | $\color[rgb]{0.77,0.45,0.06} -$ | $\color[rgb]{0,0.5,0}$ |
| $\color[rgb]{1,0,1} 6$ | $\color[rgb]{0,0,1} 8e^{x/2}$ | $\color[rgb]{0,0,1} +$ | $\color[rgb]{0,0,1}$ |
| $0$ | $\color[rgb]{1,0,1}16e^{x/2}$ | $\color[rgb]{1,0,1} -$ | $\color[rgb]{1,0,1}$ |

Now we multiply the same colored terms along with the same colored sign. Specifically we multiply $\color[rgb]{1,0,0} x^3$ with ${\color[rgb]{1,0,0} 2e^{x/2}}$, $\color[rgb]{0.77,0.45,0.06}3x^2$ with $\color[rgb]{0.77,0.45,0.06}4e^{x/2}$, and so on. We get

| **Derivatives** | **Integrals** | **Sign** | **Same Color Products** |
| --- | ---: | ---: | ---: |
| $\color[rgb]{1,0,0} x^3$ | $e^{x/2}$ |  |  |
| $\color[rgb]{0.77,0.45,0.06}3x^2$ | $\color[rgb]{1,0,0}2e^{x/2}$ | $\color[rgb]{1,0,0} +$ | $\color[rgb]{1,0,0} 2x^3e^{x/2}$ |
| $\color[rgb]{0,0,1} 6x$ | $\color[rgb]{0.77,0.45,0.06} 4e^{x/2}$ | $\color[rgb]{0.77,0.45,0.06} -$ | $\color[rgb]{0.77,0.45,0.06} -12x^2e^{x/2}$ |
| $\color[rgb]{1,0,1} 6$ | $\color[rgb]{0,0,1} 8e^{x/2}$ | $\color[rgb]{0,0,1} +$ | $\color[rgb]{0,0,1} 48xe^{x/2}$ |
| $0$ | $\color[rgb]{1,0,1}16e^{x/2}$ | $\color[rgb]{1,0,1} -$ | $\color[rgb]{1,0,1} -96e^{x/2}$ |

Finally, we add up all the terms of the last column to get the answer for our integral. We get

$$
\begin{aligned}
∫x^{3}e^{x/2}dx &= 2x^{3}e^{x/2} - 12x^{2}e^{x/2} + 48xe^{x/2} - 96e^{x/2} + C \\
&= e^{x/2}(2x^{3} - 12x^{2} + 48x - 96) + C
\end{aligned}
$$

## Integrating a Trigonometric Expression Using the Tabular Method of Integration by Parts

**Example:** Evaluate $\displaystyle \int (x^4-3x) \cos(x) \textrm{d}x$.

**Explanation**

For this integral we choose $u = x^4-3x$ and

$$
\dfrac{\textrm{d}v}{\textrm{d}x} = \cos(x)
$$

Filling in the table gives the following:

| **Derivatives** | **Integrals** | **Sign** | **Same-color Products** |
| --- | ---: | ---: | ---: |
| $\color[rgb]{1,0,0} x^4-3x$ | $\cos(x)$ |  |  |
| $\color[rgb]{0.77,0.45,0.06} 4x^3-3$ | $\color[rgb]{1,0,0} \sin(x)$ | $\color[rgb]{1,0,0} +$ | $\color[rgb]{1,0,0} (x^4-3x)\sin(x)$ |
| $\color[rgb]{0,0,1} 12x^2$ | $\color[rgb]{0.77,0.45,0.06} -\cos(x)$ | $\color[rgb]{0.77,0.45,0.06} -$ | $\color[rgb]{0.77,0.45,0.06} -(4x^3-3)(-\cos(x))$ |
| $\color[rgb]{1,0,1} 24x$ | $\color[rgb]{0,0,1} -\sin(x)$ | $\color[rgb]{0,0,1} +$ | $\color[rgb]{0,0,1} 12x^2(-\sin(x))$ |
| $\color[rgb]{0,0.5,1} 24$ | $\color[rgb]{1,0,1} \cos(x)$ | $\color[rgb]{1,0,1} -$ | $\color[rgb]{1,0,1}- 24x\cos(x)$ |
| $0$ | $\color[rgb]{0,0.5,1} \sin(x)$ | $\color[rgb]{0,0.5,1}+$ | $\color[rgb]{0,0.5,1} 24\sin(x)$ |

We add up all the terms of the last column to get the answer for our integral.

$$
\begin{aligned}
∫(x^{4} - 3x)\cos (x)dx &= (x^{4} - 3x)\sin (x) + (4x^{3} - 3)\cos (x) \\
&=-12x^{2}\sin (x) - 24x\cos (x) + 24\sin (x) + C \\
&= (x^{4} - 12x^{2} - 3x + 24)\sin (x) \\
&= + (4x^{3} - 24x - 3)\cos (x) + C
\end{aligned}
$$

## Integrating Algebraic and Exponential Expressions Using the Tabular Method of Integration by Parts

**Example:** Evaluate $\displaystyle \int (x^2-1)(x+2)^5 \textrm{d}x$.

**Explanation**

For this integral, we choose $u = x^2-1$ and

$$
\dfrac{\textrm{d}v}{\textrm{d}x} =(x+2)^5
$$

Filling in our table gives the following:

| **Derivatives** | **Integrals** | **Sign** | **Same-color Products** |
| --- | ---: | ---: | ---: |
| $\color[rgb]{1,0,0} x^2-1$ | $(x+2)^5$ |  |  |
| $\color[rgb]{0.77,0.45,0.06} 2x$ | $\color[rgb]{1,0,0}\dfrac{(x+2)^6}{6}$ | $\color[rgb]{1,0,0} +$ | $\color[rgb]{1,0,0}\dfrac{(x^2-1)(x+2)^6}{6}$ |
| $\color[rgb]{0,0,1} 2$ | $\color[rgb]{0.77,0.45,0.06} \dfrac{(x+2)^7}{42}$ | $\color[rgb]{0.77,0.45,0.06} -$ | $\color[rgb]{0.77,0.45,0.06} -\,\dfrac{x(x+2)^7}{21}$ |
| $0$ | $\color[rgb]{0,0,1}\dfrac{(x+2)^8}{336}$ | $\color[rgb]{0,0,1} +$ | $\color[rgb]{0,0,1} \dfrac{(x+2)^8}{168}$ |

We add up all the terms of the last column to get the answer for our integral.

$$
\begin{aligned}
∫(x^{2} - 1)(x + 2)^{5}dx &= ((x^{2} - 1)(x + 2)^{6})/(6) - (x(x + 2)^{7})/(21) + ((x + 2)^{8})/(168) + C \\
&= ((x + 2)^{6})/(168)(28(x^{2} - 1) - 8x(x + 2) + (x + 2)^{2}) + C \\
&= ((x + 2)^{6})/(168)(21x^{2} - 12x - 24) + C
\end{aligned}
$$
