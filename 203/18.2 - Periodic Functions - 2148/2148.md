## Introduction

**Periodic functions** are special functions that repeat themselves every $c$ units. The smallest positive value of $c$ that has this property is called the **period** of the function.

Let's take the following periodic function as an example:

![](Source/Images/297884a427a047f5b0209ac6933e06b2.png)

This function repeats itself with a period of $2$. To illustrate, first focus on the part of the graph shown in blue below.

![](Source/Images/f553c854f69e02657b402b40469a7078.png)

If we shift this part $2$ units to the right, the graph remains unchanged!

![](Source/Images/90b02afb5183c653fe9bc0e6bff04426.png)

The same would happen if we shifted the part $2$ units to the left.

By knowing the period of a periodic function, we can use a value of the function to infer many other values of the function. For example, in the function above, note that

$$
f(4)=0
$$

Since the period is $2$, if we add (or subtract) any multiple of $2$ from the input, the output stays the same. We can write this as

$$
f(4+2n) = 0
$$

where $n$ is an integer.

For example, setting

$$
n=1,2,3\ldots
$$

gives the following:

$$
\begin{aligned}
n = 1: f(4 + 2(1)) &= f(6) = 0 \\
n = 2: f(4 + 2(2)) &= f(8) = 0 \\
n = 3: f(4 + 2(3)) &= f(10) = 0 \\
&= ⋮
\end{aligned}
$$

The same is true for negative values of $n$. Setting

$$
n=-1,-2,-3\ldots
$$

gives the following:

$$
\begin{aligned}
n =-1: f(4 + 2(-1)) &= f(2) = 0 \\
n =-2: f(4 + 2(-2)) &= f(0) = 0 \\
n =-3: f(4 + 2(-3)) &= f(-2) = 0 \\
&= ⋮
\end{aligned}
$$

## Identifying the Period of a Function Given Its Graph

**Example:** What is the period of the function shown below?

![](Source/Images/7115d1662b3266415ff41692e594b7fe.png)

**Explanation**

Note that if we shift the graph $3$ units left or right, the graph remains unchanged.

On the other hand, if we shift the graph horizontally by any distance other than $3$ (or a multiple of $3$), we get a different graph.

Therefore, the period of the function is $3$.

## Drawing the Graph of a Periodic Function

**Example:** Part of the graph of a function $y=f(x)$ with period $2$ is shown below. What is the graph of $y=f(x)$ on the interval $-4\leq x \leq 4$?

![](Source/Images/ad24b9e538e0ef3e63637e496cfb9032.png)

**Explanation**

The graph above shows the function in the interval

$$
0 \leq x \leq 2
$$

Since this interval has length $2$, and the period of the function is also $2$, this interval represents a single period of the function.

Therefore, the function will consist of many copies of the shape shown above, shifted horizontally by multiples of $2$.

![](Source/Images/bbdf4591cae648aba3d16286f3fd7d54.png)

## Inferring Values of a Periodic Function Given Its Graph

**Example:** The graph of $y=f(x)$ is shown below. Given that $f$ is periodic with period $4$, what is the value of $f(84)$?

![](Source/Images/4250bf9ee2ce9af841aca5d1ecb7be51.png)

**Explanation**

Since the period is $4$, if we add (or subtract) any multiple of $4$ from the input, the output stays the same.

So, we can keep subtracting $4$ from the input until we get to an input that we see in the graph:

$$
\begin{aligned}
f(84) &= f(84 - 4) \\
&= f(84 - 2 \cdot 4) \\
&= ⋯ \\
&= f(84 - 20 \cdot 4) \\
&= f(4) \\
&= 0
\end{aligned}
$$
